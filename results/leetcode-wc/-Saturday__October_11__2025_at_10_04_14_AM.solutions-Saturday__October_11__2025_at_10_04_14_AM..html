Intuition

Find endi

  • Try to find feasible end for each start of the string, that is, for each i,
    find its corresponding endi, making substring between [i, endi] satisfying the requirement of k
  • For example: s = "010101", k = 1, we can find endi = {2, 3, 4, 5, 5, 5}
  • And we can plot the points on the graph, like this:
  • Instead of the nested for-loop approach which is O(n2),
    we can use the sliding-window approace which is O(n)

Query

  • We can easily count the points for a query (start, end) in the region surrounded by:
    • i <= endi
    • i >= start
    • endi <= end
  • For example, for the query (0, 4), we have:
  • 3 + 3 + 3 + 2 + 1 = 12

Threashold

  • Actually, we can separate the points into 2 groups, like this:
  • We can find a threshold th such that first endi (from 0 to n-1) >= end
  • There are different ways to find the th:
    • Checking every endi for each i from 0 to n-1 one by one => O(n)
    • Binary-search approach => O(logn)
    • Pre-computed approach, use thresholdEndWith to keep values as:
      for each i, find minimum j, such that endj >= i,
      thresholdEndWith can be computed by sliding-window approach
      => O(1)
  • Since endi is non-decreasing, for each i >= th, endi >= end,
    that is, endi must be limited by end for each i >= th
  • So the right (blue-background) part must be a triangle,
    we can easily count the points with the mathematical formula

PreSum

  • To count the points in the left (pink-background) part,
    we can sum up every endi where start <= i < th for each query
  • But it is a O(n) approach for each query, that is to say it is a O(n2) approach for the solution
  • A better way is the PreSum, the points in pink region can be done in O(1)

Main solution

  • long[] ans = new long[m];
for (int i = 0; i < m; i++) {
    int[] q = queries[i];
    int th = Math.max(q[0], thresholdEndWith[q[1]]);
    if (q[0] < th) {
        // left (pink-background) part, by presum approach
        ans[i] = presum[th - 1] - (q[0] == 0 ? 0 : presum[q[0] - 1]);
    }
    // right (blue-background) part, by mathematical fomula
    ans[i] += (long)(q[1] - th + 2) * (q[1] - th + 1) / 2;
    return ans;
}

Complexity

Time complexity: O(N + M)
Space complexity for computing: O(N)
Space complexity for answer: O(M)

where N is the length of s, and M is the length of queries

class Solution {
    public long[] countKConstraintSubstrings(String s, int k, int[][] queries) {
        int n = s.length(), m = queries.length;
        
        int[] data = new int[n];
        for (int i = 0; i < n; i++) {
            data[i] = s.charAt(i) - '0';
        }
        
        long pre = 0;
        long[] presum = new long[n];
        int[] thresholdEndWith = new int[n];
        int[] runningCounts = new int[2];
        for (int i = 0, j = 0; i < n; i++) {
            while (j < n) {
                runningCounts[data[j]]++;
                if (runningCounts[0] <= k || runningCounts[1] <= k) {
                    thresholdEndWith[j] = i;
                    j++;
                } else {
                    runningCounts[data[j]]--;
                    break;
                }
            }
            pre = presum[i] = pre + (j - i);
            runningCounts[data[i]]--;
        }
        
        long[] ans = new long[m];
        for (int i = 0; i < m; i++) {
            int[] q = queries[i];
            int th = Math.max(q[0], thresholdEndWith[q[1]]);
            if (q[0] < th) {
                // left (pink-background) part, by presum approach
                ans[i] = presum[th - 1] - (q[0] == 0 ? 0 : presum[q[0] - 1]);
            }
            // right (blue-background) part, by mathematical fomula
            ans[i] += (long)(q[1] - th + 2) * (q[1] - th + 1) / 2;
        }
        return ans;
    }
}

Intuition

Find contribution to answer for each index

Approach

We find maximum location till when either count of zero or count of one is under k.
For that particular index, its contribution to answer(number of substring starting from index i) is max_location - i, but we store only max_location and we do -i for each index in the query range later using formula of sum of consecutive integers.

But this method works for query of entire array [0..n-1], if range is like [0..n-5] or any query other than [0..n-1], then this solution will fail because array containing max_location assumes entire array is available, max_location in this can be only till [n-5], we use binary search on array to get number of elements greater than n-5, subtract excessive sum from sum of [0..n-5], add [n-5](number of excessive elements for the query). Dont forget to subtract -i from each element, to do that for [a..b] query we subtract -(a+a+1+a+2..b-2+b-1+b) which is (b-a+1)(b+a)/2 (AP Sum) to get final answer

Complexity

  • Time complexity:

O(NLogN)

  • Space complexity:

O(N)

class Solution {
    public long[] countKConstraintSubstrings(String s, int k, int[][] q) {
        List<Integer> zero = new ArrayList<>(), one = new ArrayList<>();
        Map<Integer, Long> prefix = new HashMap<>();
        prefix.put(-1, 0L);
        long sum = 0;
        int n = s.length(), m = q.length;
        long[] result = new long[m], cur = new long[n];

        for(int i = 0; i < n; i++) {
            if(s.charAt(i)=='0') zero.add(i);
            else one.add(i);
        }

        for(int i = 0, i0 = 0, i1 = 0; i < n; i++) {
            int nextone = n, nextzero = n;
            if(i1+k < one.size()) nextone = one.get(i1+k);
            if(i0+k < zero.size()) nextzero = zero.get(i0+k);
            if(s.charAt(i) == '0') i0++;
            else i1++;
            cur[i] = (long)Math.max(nextzero, nextone);
            sum += cur[i];
            prefix.put(i, sum);
            // System.out.println(i + " " + nextzero + " " + nextone + " " + cur[i]);
        }

        for(int i = 0; i < m; i++) {
            int u = q[i][0], v = q[i][1];
            result[i] = prefix.get(v) - prefix.get(u-1);
            int left = u, right = v;
            while(left <= right) {
                int mid = left + (right - left)/2;
                if(cur[mid] > v+1) right = mid - 1;
                else left = mid + 1;
            }
            // System.out.println(result[i]);
            // System.out.println("BS: "  + i + " " + left + " " + right);
            if(left <= v) {
                result[i] -= prefix.get(v) - prefix.get(left-1);
                // System.out.println(result[i]);
                result[i] += (long)(v+1)*(v-left+1);
                // System.out.println(result[i]);
            }
            result[i] -= ((((long)v-u+1)*(u+v))/2);
            // System.out.println(result[i]);
        }

        return result;
    }
}
