Explanation

For any given bitmask m,
dp[m] will store the largest number from the original array that is a submask of m.
In math dp[m] = a, where a is the biggest number in A that m | a = m.

For each a in A,
we find the complement of a,
the biggest a * b is a * dp[complement].

Complexity

Time O(max(A))
Space O(max(A))

    def maxProduct(self, A: List[int]) -> int:
        k = max(A).bit_length()
        mask = 1 << k
        dp = [0] * mask
        for a in A:
            dp[a] = a
        for i in range(mask):
            if dp[i]: continue
            for j in range(k):
                if i & (1 << j):
                    if dp[i ^ (1 << j)] > dp[i]:
                        dp[i] = dp[i ^ (1 << j)]
        return max(a * dp[(mask - 1) ^ a] for a in A)

Understanding the Trie-based Max Product Finder

? What This Code Does (Story Mode)

Imagine you have a bag of numbers and you want to pick two numbers that give the largest product when multiplied. But here’s a twist: Instead of checking every possible combination (which is slow), we build a special tree-like structure called a Trie to speed things up.

1. ? Trie Node (TNode)

A TNode is like a branch in a binary tree. Each node:

  • children[0] ? Represents a 0 bit.
  • children[1] ? Represents a 1 bit.
  • isEOW ? Marks the end of a number.

So, each number is stored bit by bit in this tree.

2. ? Trie Class

The Trie is the entire binary tree structure that stores numbers in their binary (0/1) form.

  • a) insert(num)

We take a number and write it in binary. Example: 5 ? 101 Then we create a path in the tree for each bit (0 or 1).

  • b) findPair(num)

This finds the best matching number in the Trie for a given num. We want a number whose bits differ as much as possible because opposite bits lead to larger products.

3. ? DFS Search (Depth-First Search)

The dfs function walks down the tree bit by bit:

  • If the current bit is 1, we try to match with a 0.
  • If the current bit is 0, we try to match with a 1, but settle for 0 if needed.

This way, we find a number that maximizes differences, increasing chances of a larger product.

4. ?? Main Logic in Solution

  1. Find the largest number to know how many bits are needed.
  2. Store all numbers in a HashSet to remove duplicates.
  3. Insert all numbers into the Trie.
  4. For each number, find its best pair and calculate the product.
  5. Keep track of the maximum product found.

Example

Suppose the numbers are [5, 2, 8]. Their binary forms:

  • 5 ? 101
  • 2 ? 010
  • 8 ? 1000

The Trie stores these binary numbers, and we search for pairs that maximize the product.

Step-by-Step Insertion Example

Let’s insert the number 5 (binary 101) into the Trie:

Root
 ??? 1  (First bit of 5)
 ?    ??? 0  (Second bit of 5)
 ?         ??? 1  (Third bit of 5)
 ?              (End of number)

After inserting 2 (010) and 8 (1000), the Trie has branches for these binary paths as well.

Simplified Logic

1. Insert all numbers into a bit-based Trie.
2. For each number, search for the best match in the Trie.
3. Keep track of the highest product.

Why Use a Trie?

Checking every pair is slow for large lists. The Trie lets us quickly search for the best possible match by comparing bits step by step, making the solution much faster and more efficient.

// Create a Trie Node
class TNode{
    boolean isEOW = false;
    TNode children[] = new TNode[2];
}

// Create a Trie Class
class Trie{
    TNode root;
    int maxBits;
    public Trie(int maxBits){
        root = new TNode();
        this.maxBits = maxBits;
    }

    public void insert(int num){
        TNode temp = root;
        for(int i = maxBits; i >=0; i--){
            int idx = ((num & (1 << i)) != 0)? 1 : 0;
            if(temp.children[idx] == null) temp.children[idx] = new TNode();
            temp = temp.children[idx];
        }
        temp.isEOW = true;
    }

    public int findPair(int num){
        return dfs(root, num, maxBits, 0);
    }

    public int dfs(TNode root, int num, int maxBits, int curr){
        if(root == null) return -1;
        if(maxBits < 0){
            // Found exactly opposite bits and reached end of the trie
            if((num & curr) == 0 && root.isEOW) return curr;
            return -1;
        }
        
        int bit = ((num & (1 << maxBits)) != 0)? 1 : 0;
        
        if(bit == 1){ // Our current bit is one
            // Strictly want a zero
            return dfs(root.children[0], num, maxBits - 1, curr);
        } else { // Our current bit is zero
            // Try for 1, else settle for zero
            int left = dfs(root.children[1], num, maxBits - 1, (curr | (1 << maxBits)));
            if(left != -1) return left;

            // Settle for zero
            int right = dfs(root.children[0], num, maxBits - 1, curr);
            return right;
        }
    }
}
class Solution {
    public long maxProduct(int[] nums) {
        int maxElem = findMax(nums);
        // Take the bits of maximum number, only to reduce redundancy
        int maxBits =  (int) Math.floor(Math.log(maxElem) / Math.log(2));

        // Add everything into a HashSet to avoid duplicates
        Set<Integer> st = new HashSet<>();
        for(int i : nums) st.add(i);

        // Create a trie and add all the bits
        Trie t = new Trie(maxBits);
        for(Integer i : st){
            t.insert(i);
        }

        // For every integer, check for a possible pair, if a pair is found, multiply and take the maximum
        long maxi = 0L;
        for(Integer i : st){
            int pairNum = t.findPair(i);
            if(pairNum != -1){
                maxi = Math.max(maxi, 1L * i * pairNum);
            }
        }
        return maxi;
    }

    // Find the maximum number from array to get the maximum possible bits
    public int findMax(int[] nums){
        int maxi = -1;
        for(int i : nums) maxi = Math.max(maxi, i);
        return maxi;
    }
}

class Solution {
    public long maxProduct(int[] nums) {
        int max=0;
        for(int val:nums)max=Math.max(max,val);
        int totalBit=(int)(Math.log(max)/Math.log(2) + 1);
        int maxMask=(1<<totalBit)-1;

        /*dp[val] tells if we represent val in binary number then all set bit everytime goes to unset
        then from all subset take max of them and store in dp[val]
        eg: comp=0101 take all combination of set bit to unset means place 1->0 or no change(means itself)
        [0100,0001,0000,itself 0101]*/
        int[] dp=new int[maxMask+1];
        for(int val:nums)dp[val]=val;
        
        for(int i=0; i<totalBit; i++){
            for(int val=1; val<=maxMask; val++){
                /*every time every set bit goes to unset and we take maximum from all of them*/
                if((val & (1<<i) )!=0){//only for set bit we need to unset
                    int offBitNumber=(val ^ (1<<i));//set bit -> unset
                    dp[val]=Math.max(dp[val],dp[offBitNumber]);
                }
            }
        }
        long ans=0;
        for(int val:nums){
            /*take complement of val and look for dp[comp] which tells all subset including itself 
            gives max where in every subset every alter set bit goes to unset
            eg: val=1010 comp=0101 take all combination of set bit in comp means place 1->0
            [0100,0001,0000,itself 0101]*/ 
            int comp=(maxMask ^ val);
            ans=Math.max(ans,(long)val*dp[comp]);
        }
        return ans;
    }
} 
//Time=> O(N*Log(Max(Nums)))
//Space=> O(Max(Nums))
