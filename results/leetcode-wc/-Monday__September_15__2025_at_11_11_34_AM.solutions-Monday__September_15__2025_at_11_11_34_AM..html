First of all if the first character of the string is zero than return 0. Obvious. If the string's length is less or equal to 1 then return 1.

Let's imagine we know number of ways to split characters according to the rules before each position in the string and all possible lengths of the previous part. Then for the next position the number of ways to split characters from start to this position can be calculated recursively.

And what if we know for each position in the string number of ways to split it in parts no longer than M. Then for M+1 we can calculate it from previous values for each position.

**TL;DR: **I wrote three solutions. First is the basic solution, used to demonstrate main dp idea. Two other are much faster , and there is time-space tradeoff in them.

Basic solution passes 255/256 tests. The second and the third solution passes all tests and have 100% in space (second solution), time - (third solution).

Used algo:
Kärkkäinen, Sanders algorithm to build suffix array in O(n)
Kasai, Arimura, Arikawa, Lee, Park algorithm to build LCP array in O(n)
Segment tree to calculate value of function on ranges

1. Naive approach

class Solution {
    private static final int p = 1_000_000_007;

    public int numberOfCombinations(String num) {
        int n = num.length();
        if (num.charAt(0) == '0') return 0;
        if (n == 1) return 1;
        long[] prev = new long[n + 1], next = new long[n + 1], tmp;
        prev[0] = 1;
        next[0] = 1;

        for (int d = 1; d <= n; d++) {
            System.arraycopy(prev, 1, next, 1, n);
            for (int j1 = 0, i1 = j1 - d, j2 = j1 + d; j2 <= n; j1++, j2++, i1++) {
                if (num.charAt(j1) != '0') {
                    if (i1 < 0 || num.charAt(i1) != '0' && ok(num, i1, j1, d)) next[j2] += next[j1];
                    else next[j2] += prev[j1];
                    if (next[j2] >= p) next[j2] -= p;
                }
            }
            tmp = prev;
            prev = next;
            next = tmp;
        }
        return (int) prev[n];
    }

    private static boolean ok(String num, int start1, int start2, int len) {
        while (len-- > 0) {
            char c1 = num.charAt(start1++), c2 = num.charAt(start2++);
            if (c1 > c2) return false;
            if (c1 < c2) return true;
        }
        return true;
    }
}

We call function ok like O(n^2) times and each call takes O(n).
It's a very good start. Time complexity - O(n^3), space - O(n).

2. Acceleration of function ok

To quickly find out which substring is greater we will use Suffix Arrays, Longest Common Prefix and Segment Tree.
Construction of Suffix Arrays is pretty hard theme, so I won't explain it here. You can read about them at other resources.
We will use fact that LCP(i,k)=min(LCP(i,j),LCP(j,k)), there i,j,k - are positions of suffixes in lexiographically order.

class Solution2 {
    private static final int p = 1_000_000_007;

    public int numberOfCombinations(String num) {
        int n = num.length();
        if (num.charAt(0) == '0') return 0;
        if (n == 1) return 1;

        int[] arr = new int[n];
        for (int i = 0; i < n; i++) arr[i] = num.charAt(i) - '0' + 1;

        int[] suffixArray = SuffixArrayTools.buildSuffixArray(arr, 10);
        int[] invSuffixArray = SuffixArrayTools.inverseSuffixArray(suffixArray);
        int[] lcp = SuffixArrayTools.buildLongestCommonPrefixArray(arr, suffixArray, invSuffixArray);
        SegmentTree tree = new SegmentTree(lcp);

        long[] prev = new long[n + 1], next = new long[n + 1], tmp;
        prev[0] = 1;
        next[0] = 1;

        for (int d = 1; d <= n; d++) {
            System.arraycopy(prev, 1, next, 1, n);
            for (int j1 = 0, i1 = j1 - d, j2 = j1 + d; j2 <= n; j1++, j2++, i1++) {
                if (arr[j1] != 1) {
                    if (i1 < 0 || arr[i1] != 1 && ok(i1, j1, d, invSuffixArray, lcp, tree))
                        next[j2] += next[j1];
                    else next[j2] += prev[j1];
                    if (next[j2] >= p) next[j2] -= p;
                }
            }
            tmp = prev;
            prev = next;
            next = tmp;
        }
        return (int) prev[n];
    }


    private static boolean ok(int start1, int start2, int len, int[] inv, int[] lcp, SegmentTree tree) {
        return inv[start1] < inv[start2] ||
                inv[start1] - 1 == inv[start2] && lcp[inv[start2]] >= len ||
                tree.query(inv[start2], inv[start1]) >= len;
    }

    private static class SuffixArrayTools {
        // s.length>=2, s[i]>=1, s[i]<=maxValue
        static int[] buildSuffixArray(int[] arr, int K) {
            int n = arr.length;
            int[] s = Arrays.copyOf(arr, n + 3);
            int[] SA = new int[n];
            suffixArray(s, SA, n, K);
            return SA;
        }

        static int[] inverseSuffixArray(int[] suffixArray) {
            int n = suffixArray.length;
            int[] ans = new int[n];
            for (int i = 0; i < n; i++) ans[suffixArray[i]] = i;
            return ans;
        }

        static int[] buildLongestCommonPrefixArray(int[] arr, int[] suffixArray, int[] invSuffixArray) {
            int n = arr.length;
            int[] lcp = new int[n - 1];
            int k = 0;
            for (int i = 0; i < n; i++) {
                if (k > 0) k--;
                if (invSuffixArray[i] == n - 1) {
                    k = 0;
                } else {
                    int j = suffixArray[invSuffixArray[i] + 1];
                    while (i + k < n && j + k < n && arr[i + k] == arr[j + k]) k++;
                    lcp[invSuffixArray[i]] = k;
                }
            }
            return lcp;
        }

        //Lexicographic order for pairs.
        static boolean leq(int a1, int a2, int b1, int b2) {
            return (a1 < b1 || (a1 == b1 && a2 <= b2));
        }

        //Lexicographic order for triples.
        static boolean leq(int a1, int a2, int a3, int b1, int b2, int b3) {
            return (a1 < b1 || (a1 == b1 && leq(a2, a3, b2, b3)));
        }

        static void suffixArray(int[] s, int[] SA, int n, int K) {
            int n0 = (n + 2) / 3, n1 = (n + 1) / 3, n2 = n / 3, n02 = n0 + n2;
            int[] s12 = new int[n02 + 3], SA12 = new int[n02 + 3], s0 = new int[n0], SA0 = new int[n0];

            for (int i = 0, j = 0; i < n + (n0 - n1); i++) if (i % 3 != 0) s12[j++] = i;

            radixPass(s12, SA12, s, 2, n02, K);
            radixPass(SA12, s12, s, 1, n02, K);
            radixPass(s12, SA12, s, 0, n02, K);

            // find lexicographic names of triples
            int name = 0, c0 = -1, c1 = -1, c2 = -1;
            for (int i = 0; i < n02; i++) {
                if (s[SA12[i]] != c0 || s[SA12[i] + 1] != c1 || s[SA12[i] + 2] != c2) {
                    name++;
                    c0 = s[SA12[i]];
                    c1 = s[SA12[i] + 1];
                    c2 = s[SA12[i] + 2];
                }
                if (SA12[i] % 3 == 1) {
                    s12[SA12[i] / 3] = name;
                } // left half
                else {
                    s12[SA12[i] / 3 + n0] = name;
                } // right half
            }

            // recurse if names are not yet unique
            if (name < n02) {
                suffixArray(s12, SA12, n02, name);
                // store unique names in s12 using the suffix array
                for (int i = 0; i < n02; i++) s12[SA12[i]] = i + 1;
            } else // generate the suffix array of s12 directly
                for (int i = 0; i < n02; i++) SA12[s12[i] - 1] = i;

            // stably sort the mod 0 suffixes from SA12 by their first character
            for (int i = 0, j = 0; i < n02; i++) if (SA12[i] < n0) s0[j++] = 3 * SA12[i];
            radixPass(s0, SA0, s, 0, n0, K);

            // merge sorted SA0 suffixes and sorted SA12 suffixes
            for (int p = 0, t = n0 - n1, k = 0; k < n; k++) {
                int i = getI(SA12, n0, t); // pos of current offset 12 suffix
                int j = SA0[p]; // pos of current offset 0 suffix
                if (SA12[t] < n0 ? // different compares for mod 1 and mod 2 suffixes
                        leq(s[i], s12[SA12[t] + n0], s[j], s12[j / 3]) :
                        leq(s[i], s[i + 1], s12[SA12[t] - n0 + 1], s[j], s[j + 1], s12[j / 3 + n0])
                ) {// suffix from SA12 is smaller
                    SA[k] = i;
                    t++;
                    if (t == n02) // done --- only SA0 suffixes left
                        for (k++; p < n0; p++, k++) SA[k] = SA0[p];
                } else {// suffix from SA0 is smaller
                    SA[k] = j;
                    p++;
                    if (p == n0) // done --- only SA12 suffixes left
                        for (k++; t < n02; t++, k++) SA[k] = getI(SA12, n0, t);
                }
            }
        }

        static int getI(int[] SA12, int n0, int t) {
            return SA12[t] < n0 ? SA12[t] * 3 + 1 : (SA12[t] - n0) * 3 + 2;
        }

        static void radixPass(int[] a, int[] b, int[] r, int shift, int n, int K) {
            int[] c = new int[K + 1]; // counter array
            for (int i = 0; i < n; i++) c[r[a[i] + shift]]++; // count occurrences
            for (int i = 0, sum = 0; i <= K; i++) { // exclusive prefix sums
                int t = c[i];
                c[i] = sum;
                sum += t;
            }
            for (int i = 0; i < n; i++) b[c[r[a[i] + shift]]++] = a[i];
        }
    }

    private static class SegmentTree {
        private final int[] t;
        private final int n;

        SegmentTree(int[] arr) {
            this.n = nextPow2(arr.length);
            this.t = new int[n * 2 - 1];
            Arrays.fill(t, Integer.MAX_VALUE);
            System.arraycopy(arr, 0, t, n - 1, arr.length);
            for (int i = n - 2; i >= 0; i--) t[i] = Math.min(t[2 * i + 1], t[2 * i + 2]);
        }

        int query(int l, int r) {
            return query(0, 0, n, l, r);
        }

        private int query(int v, int l, int r, int ql, int qr) {
            if (l >= qr || r <= ql) return Integer.MAX_VALUE;
            if (ql <= l && r <= qr) return t[v];
            int mid = (l + r) / 2;
            return Math.min(
                    query(v * 2 + 1, l, mid, ql, qr),
                    query(v * 2 + 2, mid, r, ql, qr)
            );
        }
    }

    private static int nextPow2(int n) {
        if ((n & (n - 1)) == 0) return n;
        else return Integer.highestOneBit(n) << 1;
    }
}

Now function ok takes O(logN) time.
So this solution has O(n^2 logN) time complexity and O(N) space complexity.

3. Memory to time tradeoff.

We can precompute for each valid arguments ok function value and store it.

        for (int i = 0; i < n - 2; i++) {
            for (int j = i + 1; j < n - 1; j++) {
                lcpMat[i][j] = Math.min(lcpMat[i][j - 1], lcpMat[j][j]);
            }

class Solution {
    int n, mod = 1000000007;
    int[] arr;
    int[][] rank;
    long[][] store;
    
    /*
    store[i][j] is the "ans" for num.substring(i, n) with the very first element at least [j+1] digits long
    Example: for "327", store[1][0] is the number of ways to split "27" with the first element having at least 1 digit
    We finally return store[0][0] as the answer
    */
    public int numberOfCombinations(String num) {
        init(num);
        for(int i=n-1; i>-1; --i)
            if(arr[i] > 0)
            // If the ith digit is '0', there is nothing to compute for the entire row store[i]
                for(int j=n-1-i; j>-1; --j) {
                // We run both loops backwards because the recursive relation is "forward looking" and we need the subproblems already solved
                    if(j < n-1-i) { // If there are digits beyond [i+j]
                        store[i][j] = store[i][j+1]; // When the first element is strictly longer than [j+1]
                        int k = i + j + 1; // The starting index of the second element if the first element is exactly [j+1] digits long
                        if(k+j < n) {
							// Check for possibility of non-decreasing next element of same length [j+1]
                            if(rank[i][j] <= rank[k][j]) // Idea of rank is explained below
                                store[i][j] += store[k][j];
                            else if(k+j+1 < n) // Else, fall back to the case where length(second element) >= [j+2]
                                store[i][j] += store[k][j+1];
                            if(store[i][j] > mod)
                                store[i][j] -= mod;
                        }
                    } else store[i][j] = 1; // If no digits beyond [i+j], we have a "single-element answer"
                }
        return (int) store[0][0];
    }
    
    /*
    Make n and arr available for the entire class
    Initializes the triangle matrices - store and rank
    */
    private void init(String num) {
        n = num.length();
        arr = new int[n];
        int index = 0;
        for(char c: num.toCharArray())
            arr[index++] = (c - '0');
        rank = new int[n][];
        store = new long[n][];
        for(int i=0; i<n; ++i) {
            rank[i] = new int[n-i];
            store[i] = new long[n-i];
        }
        initRank();
    }
    
    /*
    rank[i][j] is the lexicographical rank of the [j+1] sized substring starting at i (amongst all [j+1] sized substring)
    rank is a triangle matrix (because there are n substrings starting at index 0 but just 1 substring starting with at n-1)
    
    */
    private void initRank() {
        List<List<Integer>> groups = getSingleBucket();
        for(int j=0; j<n; ++j) {
            List<List<Integer>> newGroups = new LinkedList<>();
            for(List<Integer> group: groups) {
                List<Integer>[] buckets = new List[10];
                for(int i: group) {
                    int k = i + j;
                    if(k < n) {
                        int d = arr[k];
                        if(buckets[d] == null)
                            buckets[d] = new LinkedList<>();
                        buckets[d].add(i);
                    }
                }
                for(List<Integer> bucket: buckets) if(bucket != null)
                    newGroups.add(bucket);
            }
            int r = 0;
            for(List<Integer> group: newGroups) {
                for(int i: group) rank[i][j] = r;
                ++r;
            }
            groups = newGroups;
        }
    }
    
    private List<List<Integer>> getSingleBucket() {
        List<List<Integer>> groups = new LinkedList<>();
        List<Integer> seed = new LinkedList<>();
        for(int i=0; i<n; ++i)
            seed.add(i);
        groups.add(seed);
        return groups;
    }
}
