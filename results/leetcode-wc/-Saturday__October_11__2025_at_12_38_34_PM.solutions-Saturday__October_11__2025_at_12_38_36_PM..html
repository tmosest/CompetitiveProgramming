? Problem Understanding and Intuition

The problem is about calculating the minimum number of operations needed to move all balls to each box in a binary string, where:

  • 1 indicates the presence of a ball in the box.
  • 0 indicates the box is empty.

? Key Insight:

Instead of calculating the operations naively for every box (which would result in O(n2) time complexity), we can optimize by:

  1. Splitting the calculation into prefix traversal (left-to-right) and suffix traversal (right-to-left).
  2. Using cumulative counts and distances to compute the result in O(n) time.

Approach

Key Idea:

We can calculate the minimum operations for each box by summing:

  1. Operations to move balls from the left side (prefix traversal).
  2. Operations to move balls from the right side (suffix traversal).

Steps:

  1. Initialize Variables:

    • A distances array to store the result for each box.
    • Two sets of counters:
      • prefixCount and prefixSum for the left-to-right traversal.
      • suffixCount and suffixSum for the right-to-left traversal.

  2. Prefix Traversal (Left to Right):

    • Traverse the string from left to right.
    • Maintain prefixCount (number of balls encountered so far) and prefixSum (total operations for all balls encountered so far).
    • For each box:
      • Calculate the operations needed to bring all balls to this box based on prefixCount and prefixSum.
        The prefix formula calculates the minimum number of moves to bring all balls to box i.
        It uses the formula: distances[i] = prefixCount * i - prefixSum.
  • prefixCount counts how many balls are to the left of box i.
  • prefixSum accumulates the sum of the indices of boxes with balls to the left of i.
    This formula efficiently computes the result by considering how far each ball needs to move.

  1. Suffix Traversal (Right to Left):

    • Traverse the string from right to left.
    • Maintain suffixCount (number of balls encountered so far) and suffixSum (total operations for all balls encountered so far).
    • For each box:
      • Add the operations needed to bring all balls from the right to this box.

  2. Combine Results:

    • The total operations for each box are the sum of operations from the prefix and suffix traversals.

Complexity

  • Time complexity:
    O(n)

    • We perform two linear traversals of the string.

  • Space complexity:
    O(n)

    • We use an auxiliary array (distances) to store the results.

class Solution {
public:
    vector<int> minOperations(string boxes) {
        int n = boxes.size();
        vector<int> left(n, 0), right(n, 0), res(n, 0);
        int count = (boxes.at(0) == '1' ? 1 : 0);

        for (int i = 1; i < n; i++) {
            left[i] = left[i - 1] + count;
            count += (boxes.at(i) == '1' ? 1 : 0);
        }

        count = (boxes.at(n-1) == '1' ? 1 : 0);

        for (int i = n - 2; i >= 0; i--) {
            right[i] = right[i + 1] + count;
            count += (boxes.at(i) == '1' ? 1 : 0);
        }

        for (int i = 0; i < n; i++) {
            res[i] = left[i] + right[i];
        }

        return res;
    }
};

class Solution {
public:
    vector<int> minOperations(string boxes) {
         int n = boxes.length();
    vector<int> distances(n, 0);

    int prefixCount = 0;  
    int prefixSum = 0;    

    for (int i = 0; i < n; ++i) {
        distances[i] = prefixCount * i - prefixSum;
        if (boxes[i] == '1') {
            ++prefixCount;
            prefixSum += i;
        }
    }

    int suffixCount = 0;  
    int suffixSum = 0;    

    for (int i = n - 1; i >= 0; --i) {
        distances[i] += suffixSum - suffixCount * i;
        if (boxes[i] == '1') {
            ++suffixCount;
            suffixSum += i;
        }
    }

    vector<int> ans;
    for (int dist : distances) {
       ans.push_back(dist);
    }

    return ans;
    }
};

class Solution:
    def minOperations(self, boxes: str) -> List[int]:
        n = len(boxes)
        left = [0] * n
        right = [0] * n
        cnt = 0
        for i in range(1, n):
            if boxes[i - 1] == '1':
                cnt += 1
            left[i] = left[i - 1] + cnt
        cnt = 0
        for i in range(n - 2, -1, -1):
            if boxes[i + 1] == '1':
                cnt += 1
            right[i] = right[i + 1] + cnt
        return [a + b for a, b in zip(left, right)]

Intuition

Each box may contain balls. To move all balls to a target box, we need to calculate the distance of every ball from that box. The goal is to compute the total moves required for each box.

Approach

  1. Initialize an array res of the same length as boxes to store results.
  2. Loop through each box index i:

  • Initialize moves = 0.

  • Loop through all box indices j:

    • If boxes[j] == '1' (ball present), add Math.abs(i - j) to moves.

  • Store moves in res[i].

  1. Return the res array containing total moves for each box.

Complexity

  • Time complexity: O(n^2)

Two nested loops over the boxes string of length n.

  • Space complexity: O(n)

For storing the res array.

class Solution {
    public int[] minOperations(String boxes) {
        int [] res = new int [boxes.length()];

        for(int i=0;i<boxes.length();i++)
        {
            int moves  = 0;
            for(int j=0;j<boxes.length();j++)
            {
                if(boxes.charAt(j)=='1')
                {
                    moves = moves + Math.abs(i-j);
                }
            }
            res[i] = moves;
        }
      
        return res;
    }
}
