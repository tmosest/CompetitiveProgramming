? Problem: Find Maximum Path Score Within Limit K

? Description

You are given:

  • A graph with n nodes (0 to n-1) and weighted edges: edges[i] = [u, v, cost]
  • A boolean array online[i], where online[i] == true if node i is active
  • An integer k, which is the maximum allowed total cost

Objective

Find the maximum edge score X such that:

  • You can reach from node 0 to node n - 1
  • Only use online nodes and edges with score ≥ X
  • The total path cost is ≤ k

Return the maximum X that satisfies all conditions, or -1 if impossible.

? Approach

1. Binary Search on Edge Score

  • Set low = 0 and high = 1e9 (maximum edge weight)

  • For each mid (potential threshold):

    • Filter edges that have score >= mid and only connect online nodes
    • Construct the graph with these edges
    • Run Dijkstra from node 0 to node n - 1
    • If a path is found within cost k, update best = mid, and try for higher values
    • Else, try lower values

2. Dijkstra’s Algorithm

  • Use a min-heap (priority queue) to find the shortest path from source to target
  • Stop early once we reach the destination
  • If unreachable, return INF

? Example

Input:

edges = [[0,1,4],[1,2,3],[2,3,5],[3,4,2]]
online = [true, true, true, true, true]
k = 10

Step-by-step:

Let’s try binary search on minEdgeWeight. We are looking for the maximum possible minimum edge weight on a path from 0 to 4, such that total path cost ≤ 10.

Try mid = 4:

  • Filter edges with weight ≥ 4: [[0,1,4], [2,3,5]]
  • Build graph: 0?1, 2?3 (but no way to reach node 4)
  • Dijkstra ? No valid path

Try mid = 2:

  • Filter edges: all edges remain
  • Dijkstra finds path: 0?1?2?3?4 with cost 4+3+5+2 = 14 > k ? not valid

Try mid = 3:

  • Filtered: [[0,1,4],[1,2,3],[2,3,5]]
  • Dijkstra path: 0?1?2?3 ? no edge to 4 (no valid path)

Try mid = 1:

  • All edges included
  • Valid path with cost 14 ? still > k

Eventually binary search finds best edge weight where a path exists and cost ≤ k.

? Suppose we try mid = 2, and a valid path is found with total cost 10 ? return 2

? Time Complexity

Let V = n, E = edges.length, logW = log(1e9) ≈ 30

  • Binary Search: O(logW)

  • For each threshold:

    • Filtering edges: O(E)
    • Dijkstra: O((V + E) log V)

  • Total Complexity: O(logW * ((V + E) log V))

typedef long long ll;
class Solution {
public:
    ll solve(int src,int target ,vector<vector<pair<int,int>>>& adj,int n ){
        ll maxi = LLONG_MAX/4;
        vector<ll>dist(n,maxi);
        dist[src]=0;
        priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>>pq;
        pq.emplace(0,src);
        while(!pq.empty()){
            auto [d,u] = pq.top(); pq.pop();
            if(d>dist[u]) continue;
            if(u==target) return d;
            for(auto [v,w]: adj[u]){
                if(dist[v]>d+w){
                    dist[v] = d+w;
                    pq.emplace(dist[v],v);
                }
            }
        }
        return maxi;
    }

    int findMaxPathScore(vector<vector<int>>& edges, vector<bool>& online, long long k) {
        int n = online.size();
        ll l = 0, h = 1e9, best = -1;
        while (l <= h) {
            ll mid = l + (h - l) / 2;
            vector<vector<pair<int,int>>> adj(n);
            for (auto& e : edges) {
                int u = e[0], v = e[1], c = e[2];
                if (c >= mid && online[u] && online[v]) {
                    adj[u].emplace_back(v,c);
                }
            }
            ll dist = solve(0, n - 1, adj, n);
            if (dist <= k) {
                best = mid;
                l = mid + 1;
            } else {
                h = mid - 1;
            }
        }
        return best;
    }
};
