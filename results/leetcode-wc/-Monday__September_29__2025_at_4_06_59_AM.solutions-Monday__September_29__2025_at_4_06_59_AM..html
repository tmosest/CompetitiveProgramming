Intuition

We are asked to climb from step 0 to step n.
At each step:

  • We can move 1 step forward ? pay cost[i] + 1.
  • We can move 2 steps forward ? pay cost[i+1] + 4.
  • We can move 3 steps forward ? pay cost[i+2] + 9.

This is a minimum path cost problem ? solved via recursion + memoization (top-down DP).

Approach

  1. Use recursion (solve(i)) to compute the minimum cost to reach step n from step i.
  2. If i == n ? cost = 0 (we reached the top).
  3. Try all possible moves (1, 2, 3 steps) while staying within bounds.
  4. Add the respective step cost + jump penalty.
  5. Memoize results in dp[i] to avoid recomputation.
  6. Return dp[0].

Complexity

  • Time Complexity: O(n) ? each state solved once.
  • Space Complexity: O(n) for recursion stack + DP array.

Code

Java
C++

class Solution {
    public int climbStairs(int n, int[] costs) {
        int[] dp = new int[n + 1];
        Arrays.fill(dp, -1);
        return solve(0, n, costs, dp);
    }

    private int solve(int i, int n, int[] costs, int[] dp) {
        if (i > n) return Integer.MAX_VALUE;  // invalid jump
        if (i == n) return 0; // reached top

        if (dp[i] != -1) return dp[i];

        int oneStep = (costs[i] + 1) + solve(i + 1, n, costs, dp);
        int twoStep = i + 2 <= n ? (costs[i + 1] + 4) + solve(i + 2, n, costs, dp) : Integer.MAX_VALUE;
        int threeStep = i + 3 <= n ? (costs[i + 2] + 9) + solve(i + 3, n, costs, dp) : Integer.MAX_VALUE;

        return dp[i] = Math.min(oneStep, Math.min(twoStep, threeStep));
    }
}

Approach 2

Intuition

We want to climb from step 0 to step n with minimum cost.
At each step:

  • Move 1 step ? pay cost[i] + 1.
  • Move 2 steps ? pay cost[i] + 4.
  • Move 3 steps ? pay cost[i] + 9.

We can solve this using iterative DP where dp[j] stores the minimum cost to reach step j.

Approach

  • Initialize dp[0] = 0 (starting point).
  • For each step j from 1 to n:
    • Jump from j-1 ? cost dp[j-1] + costs[j-1] + 1.
    • Jump from j-2 ? cost dp[j-2] + costs[j-1] + 4.
    • Jump from j-3 ? cost dp[j-3] + costs[j-1] + 9.
    • Take the minimum among valid jumps.
  • Return dp[n].

Complexity

  • Time Complexity: O(n)
  • Space Complexity: O(n)

Code

Java
C++
Python
class Solution {
    public int climbStairs(int n, int[] costs) {
        int[] dp = new int[n + 1];
        dp[0] = 0;

        for (int j = 1; j <= n; j++) {
            dp[j] = Integer.MAX_VALUE;

            if (j - 1 >= 0) dp[j] = Math.min(dp[j], dp[j - 1] + costs[j - 1] + 1);
            if (j - 2 >= 0) dp[j] = Math.min(dp[j], dp[j - 2] + costs[j - 1] + 4);
            if (j - 3 >= 0) dp[j] = Math.min(dp[j], dp[j - 3] + costs[j - 1] + 9);
        }

        return dp[n];
    }
}

Intuition

Use dynamic programming (DP) with a rolling array of size 3.

Explanation

Let dp[i] mean minimum cost to reach step i.

Equation:
dp[i]=min(dp[i-1]+1,dp[i-2]+4,dp[i-3]+9)+costs[i-1]

Use modulo 3 to save space dp[i % 3],
since we only need the last three values.

Return dp[n % 3] as the answer.

Complexity

Rolling DP reduces space from O(n) ? O(1).
Time O(n)
Space O(3)

Python
Java
C++
    def climbStairs(self, n: int, costs: List[int]) -> int:
        dp = [0] + [inf] * n
        for i in range(1, n + 1):
            for d in [1,2,3]:
                if i >= d:
                    dp[i] = min(dp[i], dp[i - d] + costs[i - 1] + d * d)
        return dp[n]

Approach

dp[i] represents the minimum total cost to reach step i.
For each index i, the minimum total cost is the min of:

  • Coming from one step behind: costs[i] + dp[i-1] + 1
  • Coming from two steps behind: costs[i] + dp[i-2] + 4
  • Coming from three steps behind: costs[i] + dp[i-3] + 9

We iterate up to n and calcalate dp[i] at each step then return dp[n].

Furthermore, since we only ever look three steps back, we can simplify and optimize this by using thee variables one, two, and three.

Complexity

  • Time complexity: O(n)
  • Space complexity: O(1)

Code

C++
Python
Java
class Solution {
public:
    int climbStairs(int n, vector<int>& costs) {
        int one = 0, two = costs[0] + 1, three = n > 1 ? costs[1] + min(two + 1, 4) : two;
        for (int i = 3; i <= n; i++){
            int curr = costs[i-1] + min({three + 1, two + 4, one + 9});
            one = two;
            two = three;
            three = curr;
        }
        return three;
    }
};
