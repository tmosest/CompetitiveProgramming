Intuition

  • We can apply two operations adding to odd indices and rotating the string any number of times. Since both operations can create cycles, the total number of possible unique strings is finite. Therefore, we can explore all reachable strings using BFS or DFS until no new strings appear.
  • The goal is to find the lexicographically smallest string among all reachable ones.

Approach

We use a BFS traversal starting from the initial string s.
At each step:

  1. Generate a new string by adding a to all odd indices (with digits modulo 10).
  2. Generate another string by rotating s to the right by b positions.
  3. For both results, if we haven’t seen the string before, we add it to the queue.

We track all visited strings in a set to avoid repetition.
Throughout traversal, we keep updating the smallest string seen so far based on lexicographic comparison.

This ensures that every reachable configuration of the string is explored exactly once, and the smallest lexicographic result is found.

Complexity

  • Time complexity: O(n*10(n/2))
  • Space complexity: O(n*10(n/2))

class Solution {
    public String findLexSmallestString(String s, int a, int b) {
        Set<String> vis = new HashSet<>();
        String smallest = s;
        Deque<String> q = new ArrayDeque<>();
        q.offer(s);
        vis.add(s);

        while (!q.isEmpty()) {
            String cur = q.poll();
            if (cur.compareTo(smallest) < 0) smallest = cur;

            StringBuilder sb = new StringBuilder(cur);
            for (int i = 1; i < sb.length(); i += 2)
                sb.setCharAt(i, (char) ((sb.charAt(i) - '0' + a) % 10 + '0'));
            String added = sb.toString();
            if (vis.add(added)) q.offer(added);

            String rotated = cur.substring(cur.length() - b) + cur.substring(0, cur.length() - b);
            if (vis.add(rotated)) q.offer(rotated);
        }
        return smallest;
    }
}
