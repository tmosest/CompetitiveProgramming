? Problem Breakdown

We are given an array of integers, and we need to count the number of subarrays that have an odd sum.

  • Since the count can be large, we return the result modulo (10^9 + 7).
  • A subarray is a contiguous part of the array.
  • Example: 
    Input: arr = [1,3,5]
Output: 4
Explanation: Odd sum subarrays are: [1], [1,3,5], [3], [5]

? Approach Overview

? Key Observations:

  1. Prefix Sum helps in quickly determining the sum of any subarray.
  2. Instead of checking all possible subarrays (which is too slow), we track odd and even prefix sums.
  3. If the current prefix sum is odd, it means there are subarrays ending here with odd sums.

? Strategy:

  • Maintain a prefix sum while traversing the array.
  • Count how many times the prefix sum was odd and use it to count valid subarrays efficiently.

? Complexity Analysis

  • Time Complexity: O(N), as we traverse the array once.
  • Space Complexity: O(1), as we use only a few variables.

? Code Implementation

? Java Solution

class Solution {
    public int numOfSubarrays(int[] arr) {
        long oddCount = 0, prefixSum = 0;
        for(int a : arr){
            prefixSum += a;
            oddCount += prefixSum % 2;
        }
        oddCount += (arr.length - oddCount) * oddCount;
        return (int)(oddCount % 1_000_000_007);
    }
}

Approach 1

1 . Track Prefix Sums:

  • Use odd and even counters to track the number of prefix sums that are odd or even.
  • Initialize even = 1 (prefix sum of 0 is even).

2 . terate Through Array:

  • Maintain a running sum (modulo 2 to check odd/even).
  • If sum is odd:
    Add even to the result (subarrays ending here with odd sum).
    Increment odd.
  • If sum is even:
    Add odd to the result.
    Increment even.

?Complexity Analysis

  • Time complexity:O(n).
  • Space complexity: O(1).

class Solution {
    public int numOfSubarrays(int[] arr) {
        int MOD = 1000000007;
        int odd = 0, even = 1; 
        int result = 0;
        int sum = 0;

        for (int i = 0; i < arr.length; i++) {
            sum += arr[i];
            if (sum % 2 == 1) {
                result = (result + even) % MOD;
                odd++;
            } else {
                result = (result + odd) % MOD;
                even++;
            }
        }

        return result;
    }
}

Approach2:Prefix Sum with Hash Map

1.Track Prefix Sums:

  • Use a hash map to store the frequency of odd and even prefix sums.
  • Initialize the map with {0: 1} because a prefix sum of 0 is even.

2.Iterate Through the Array:

  • Update the running prefixSum by adding the current element.
  • If prefixSum is odd:
    . Add the frequency of even prefix sums to the result.
    . If prefixSum is even:
    . Add the frequency of odd prefix sums to the result.
    . Update the frequency of the current prefixSum % 2 in the hash map.

class Solution {
    public int numOfSubarrays(int[] arr) {
        int MOD = 1000000007;
        Map<Integer, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0, 1); // Prefix sum of 0 is even
        int prefixSum = 0;
        int result = 0;

        for (int num : arr) {
            prefixSum += num;
            if (prefixSum % 2 == 1) {
                // If prefixSum is odd, count the number of even prefix sums
                result = (result + prefixCount.getOrDefault(0, 0)) % MOD;
            } else {
                // If prefixSum is even, count the number of odd prefix sums
                result = (result + prefixCount.getOrDefault(1, 0)) % MOD;
            }
            // Update the frequency of the current prefixSum (odd or even)
            prefixCount.put(prefixSum % 2, prefixCount.getOrDefault(prefixSum % 2, 0) + 1);
        }

        return result;
    }
}

class Solution {
    public int numOfSubarrays(int[] arr) {
        int MOD = 1000000007;
        int odd = 0, even = 1; // even is initialized to 1 because prefix sum of 0 is even
        int result = 0;
        int prefixSum = 0;

        for (int i = 0; i < arr.length; i++) {
            prefixSum ^= arr[i]; // Toggle between odd and even using XOR
            if ((prefixSum & 1) == 1) {
                // If prefixSum is odd, add the number of even prefix sums to result
                result = (result + even) % MOD;
                odd++; // Increment odd prefix sum count
            } else {
                // If prefixSum is even, add the number of odd prefix sums to result
                result = (result + odd) % MOD;
                even++; // Increment even prefix sum count
            }
        }

        return result;
    }
}

Prefix Sum

Intuition

The problem requires us to find the number of subarrays with an odd sum. Instead of iterating over all possible subarrays (which would be inefficient), we can use a prefix sum and count-based approach.

Observations:

  1. If the prefix sum at index i is even, then the count of subarrays ending at i with an odd sum equals the count of previous subarrays with an odd sum.
  2. If the prefix sum at index i is odd, then the count of subarrays ending at i with an odd sum equals the count of previous subarrays with an even sum.
  3. We use two counters: evenCount (to track even prefix sums) and oddCount (to track odd prefix sums).
  4. We initialize evenCount = 1 to handle the case where a subarray itself is odd.

Approach

  1. Initialize oddCount = 0, evenCount = 1, prefixSum = 0, and result = 0.
  2. Iterate over the array:
    • Update prefixSum by adding the current element.
    • If prefixSum is even, add oddCount to the result and increase evenCount.
    • If prefixSum is odd, add evenCount to the result and increase oddCount.
    • Keep the result within modulo 10^9 + 7 to avoid overflow.
  3. Return the final result.

Complexity Analysis

  • Time Complexity: (O(n)) (since we traverse the array once).
  • Space Complexity: (O(1)) (only a few extra variables used).

class Solution {
  int numOfSubarrays(List<int> arr) {
    const int MOD = 1000000007;
    int oddCount = 0, evenCount = 1, prefixSum = 0, result = 0;

    for (int num in arr) {
      prefixSum += num;

      if (prefixSum % 2 == 0) {
        result = (result + oddCount) % MOD;
        evenCount++;
      } else {
        result = (result + evenCount) % MOD;
        oddCount++;
      }
    }
    return result;
  }
}
