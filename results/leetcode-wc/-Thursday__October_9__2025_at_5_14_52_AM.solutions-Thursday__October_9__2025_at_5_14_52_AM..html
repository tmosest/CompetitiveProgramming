LeetCode Problem: XOR After Queries

Problem Statement

You are given an integer array nums and a list of queries q. Each query is represented as a vector [l, r, k, v] where:

  • l = starting index (inclusive)
  • r = ending index (inclusive)
  • k = step size
  • v = multiplier

For each query, update nums by multiplying every kth element in the range [l, r] by v modulo 1e9+7. After processing all queries, return the XOR of all elements in the updated array.

Intuition & Approach

The problem asks us to apply multiple range updates with a step size and then compute the XOR of all elements.

  1. Process queries: For each query [l, r, k, v], we need to visit indices l, l+k, l+2k, ... up to r. Each such index is multiplied by v.
  2. Modulo operation: Since multiplications can make numbers very large, every multiplication is performed modulo 1e9+7.
  3. Final XOR: Once all queries are applied, the final answer is the XOR of all updated elements in nums.

This approach directly simulates the operations in the queries.

Complexity Analysis

  • Time Complexity: O(Q * (N/K)) where Q = number of queries, N = size of nums, K = average step size. In the worst case (k=1), complexity is O(Q * N).
  • Space Complexity: O(1) (in-place updates).

Example Walkthrough

Input:

nums = [2, 3, 5]
q = [[0, 2, 1, 2]]

Step-by-step:

  • Query [0, 2, 1, 2]: multiply every index from 0 to 2 with step 1 by 2.
  • nums becomes [4, 6, 10].

Final XOR:

4 ^ 6 ^ 10 = 0

Output: 0

class Solution {
public:
    const int mod = 1e9 + 7;
    int xorAfterQueries(vector<int>& nums, vector<vector<int>>& q) {
        for (auto &it : q) {
            int l = it[0];
            int r = it[1];
            int k = it[2];
            int v = it[3];
            while (l <= r) {
                nums[l] = (1LL * nums[l] * v) % mod;
                l += k;
            }
        }
        int ans = 0;
        for (auto &it : nums) {
            ans ^= it;
        }
        return ans;
    }
};
