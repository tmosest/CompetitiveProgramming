Solution 1

Kinda simulate the traversal, keeping a stack of nodes (just their values) of which we're still in the left subtree. If the next number is smaller than the last stack value, then we're still in the left subtree of all stack nodes, so just push the new one onto the stack. But before that, pop all smaller ancestor values, as we must now be in their right subtrees (or even further, in the right subtree of an ancestor). Also, use the popped values as a lower bound, since being in their right subtree means we must never come across a smaller number anymore.

public boolean verifyPreorder(int[] preorder) {
    int low = Integer.MIN_VALUE;
    Stack<Integer> path = new Stack();
    for (int p : preorder) {
        if (p < low)
            return false;
        while (!path.empty() && p > path.peek())
            low = path.pop();
        path.push(p);
    }
    return true;
}

Solution 2 ... O(1) extra space

Same as above, but abusing the given array for the stack.

public boolean verifyPreorder(int[] preorder) {
    int low = Integer.MIN_VALUE, i = -1;
    for (int p : preorder) {
        if (p < low)
            return false;
        while (i >= 0 && p > preorder[i])
            low = preorder[i--];
        preorder[++i] = p;
    }
    return true;
}

Intuition

In a BST preorder traversal (Root ? Left ? Right), we encounter nodes in a specific pattern:

In a preorder traversal, the current node is visited before its left and right subtrees.

For a valid BST:

Left subtree nodes must be less than the root.

Right subtree nodes must be greater than the root.

We need to simulate this logic to verify if the given array respects BST preorder constraints.

All values in the left subtree of a node must be less than the node.

All values in the right subtree must be greater than the node.

We can simulate the process using a stack and track the most recent node whose right subtree we're about to traverse.

it avoids constructing the tree and still verifies correctness in linear time.

It leverages stack mechanics to simulate BST traversal efficiently.

If any future node violates the BST preorder property, we know the sequence is invalid.

Approach

Use a stack (pathStack) to keep track of the path from root to current node.

Keep a variable lastPopped to store the lower bound (i.e., the last popped node, which acts as the root of the current right subtree).

For each value in the preorder array:

If the value is less than lastPopped, it's invalid (should not appear in the right subtree).

While the stack is not empty and the top of the stack is less than the current value:

We pop from the stack and update lastPopped.

Finally, push the current value onto the stack.

Lets see with an example

Input: preorder = [5, 2, 1, 3, 6]

Expected Output: true
This is a valid preorder traversal of the BST:

    5
   / \
  2   6
 / \
1   3

Walkthrough Table:

StepValueStacklastPoppedCheckResult
15[5]-°5 > -° ?Push
22[5, 2]-°2 > -° ?Push
31[5, 2, 1]-°1 > -° ?Push
43[5]23 > 2 ?Pop 2, Push 3
56[]56 > 5 ?Pop 5, Push 6

At no point does a value violate the BST preorder property (value < lastPopped), so we return true.

Key Observations
Use a stack to simulate traversal down the tree.

Use a lower bound (lastPopped) to ensure all values in the right subtree are greater than their ancestors.

If we ever see a value less than this lower bound, it's an invalid BST preorder.

Complexity

  • Time complexity: O(n)Ñ Each element is pushed and popped at most once.

  • Space complexity: O(n)Ñ Stack can grow up to size n in the worst case (e.g., sorted input).

class Solution {
    public boolean verifyPreorder(int[] preorder) {

         Deque<Integer> pathStack = new ArrayDeque<>();
        
        // Represents the lower bound (i.e., root of the right subtree)
        int lastPopped = Integer.MIN_VALUE; 

         for (int value : preorder) {

           if (value < lastPopped) {
                return false; // Violates BST property
            }
            // If value is in right subtree of stack top,
            // Keep removing items smaller than value
            // and make the last removed item as new root or we can say lastPopped
       
             while (!pathStack.isEmpty() && value > pathStack.peek()) {
                lastPopped = pathStack.pop(); // We're going right; update lower bound
            }
           
            // At this point either stack is empty or
            // value is smaller than lastPopped/root , push value
            
            pathStack.push(value); // Push current value
        }

    return true;
        
    }
}

# Code  Second solution using O(1) space by resusing input array instead of a stack 

class Solution {
    public boolean verifyPreorder(int[] preorder) {
        int lastPopped = Integer.MIN_VALUE;
        int stackIndex = -1;  // Use preorder[0..stackIndex] as the simulated stack

        for (int value : preorder) {
            if (value < lastPopped) return false; // Violates BST rule

            // Pop values smaller than current to update the root
            while (stackIndex >= 0 && value > preorder[stackIndex]) {
                lastPopped = preorder[stackIndex--];
            }

            // Push current value as part of traversal path
            preorder[++stackIndex] = value;
        }

        return true;
    }
}
