There would be in total: 109999998 palindromes of length [1 <= len(palin) <= 15]

    Single Length:
    --------------

    Double Length:
    --------------
        ___,    ___
         ^       ^

     9 choices   Only choice
        [1-9]    that would be same as
                 the one which placed at

        So, total: 9 * 1 = 9 palindromes of length 2

    Triple Length:
    --------------

          ^     ^     ^

    to [1...9]

// Pre-computating everything so that later can get answer
// for each ith query in O(1) time. But getting MLE as expected.
// However, it's working absolutely fine if value of "intLength" would be upto 12
class Solution {

    // its space in total would exceed > 10^8
    private static Map<Integer, List<String>> palins;
    private static final int MAX_LENGTH = 15; // works perfectly fine upto 12

    static {
        palins = new HashMap<>();


        for(int i = 1; i <= MAX_LENGTH; i += 1) {
            generateAllPalindromicNumbers(new char[i], 0, i - 1, i, false);
        }
    }

    // This function wiill generate all palindrome numbers of fixed length.
    private static void generateAllPalindromicNumbers(char[] runnPalin, int l, int r, int L, boolean canChooseZero) {
        if(l > r) {
            // We successfully got/build one palindrome of length "L"
            // add it into the Map
            palins.putIfAbsent(L, new ArrayList<String>());
            palins.get(L).add(String.valueOf(runnPalin));
            return;
        }

        for(char ch = canChooseZero ? '0' : '1'; ch <= '9'; ch += 1) {
            runnPalin[l] = runnPalin[r] = ch;
            generateAllPalindromicNumbers(runnPalin, l + 1, r - 1, L, true);
        }
    }

    public long[] kthPalindrome(int[] queries, int L) {
        int q = queries.length;
        long[] ans = new long[q];
        List<String> palindroms = palins.get(L);
        int i = 0;
        for(int qth : queries) {
            // If have enough palindromic numbers
            if (palindroms.size() >= qth) {
                ans[i] = Long.valueOf(palindroms.get(qth - 1));
            } else {
                ans[i] = -1;
            }
            i += 1;
        }

        return ans;
    }
}

Generate All (intLength/2) numbers and Use their Mirror Reflection to get (intLength) palindromes

class Solution {

    private List<Long> palins; 

    Solution() {
        palins = new ArrayList<>();
    }

    // Overall time complexity would still be: O(7.2 * 10^8) like last implementation but
    // this is a bit clever way. So, still given TLE.
    private void generateNumbersOfGivenLength(char[] number, int idx, int P, int L, boolean canChooseZero) {
        if (idx == P) {
            String leftPart = String.valueOf(number);
                                                      // If L is odd, this -> L - L % 2 would
                                                      // automatically ignore the "middle digit"
                                                      // to get mirrored.
            String mirrorPart = leftPart.substring(0,  P - L % 2);

            palins.add(Long.valueOf(leftPart + new StringBuilder(mirrorPart).reverse().toString()));
            return;
        }

        for(char ch = canChooseZero ? '0' : '1'; ch <= '9'; ch += 1) {
            number[idx] = ch;
            generateNumbersOfGivenLength(number, idx + 1, P, L, true);
        }
    }

    public long[] kthPalindrome(int[] queries, int L) {
        int q = queries.length;
        long[] ans = new long[q];
                                                    // generating all the numbers of size
                                                    // ceil(L / 2) = P
        int P = (L + 1) / 2;
        generateNumbersOfGivenLength(new char[P], 0, P, L, false);
        int size = palins.size();
        int i = 0;
        for(int qth : queries) {
            // If have enough palindromic numbers
            if (size >= qth) {
                ans[i] = palins.get(qth - 1);
            } else {
                ans[i] = -1;
            }
            i += 1;
        }
        return ans;
    }
}

Accepted Approach: Maths Based Approach

Intuition:
---------


    Let's say, we need to generate all palindromic numbers of length 4(inLength). 
    Instead of generating "intLength" numbers, we will generate numbers of length 
    2(4 / 2 = intLength / 2) and for each of those such numbers (N), to get "intLength"
    palindromic numbers what we can do? we can concate mirror reflection of mirror(N) in N.

    For example: [For even length palindromic numbers]
        If N = "10", its mirror reflection will be "01"
        So, final number will be: N + mirror(N)
                                : "10" + "01"
                                : "1001"

    For example, [For odd length palindromic numbers]
        If N = "121", its mirror reflection will be "21" 
        (mirror is vertically along the exact middle i.e., 2)
        So, final number will be: N + mirror(N)
                                : "121" + "21"
                                : "12121"

    Let's see, how to compute queries[i]th palindromic number efficiently?

    if intLength = 6, So let's generate all the numbers of length (intLength / 2 = 6 / 2 = 3)

             
            intLength/2                 intLength palindromic
              numbers                   numbers

          1st number ---> 100    ==> required palindrome =>> 100001
          2nd number ---> 101    ==> required palindrome =>> 101101
          3rd number ---> 102    ==> required palindrome =>> 102201
          4th number ---> 103    ==> required palindrome =>> 103301
          5th number ---> 104    ==> required palindrome =>> 104401
          ......
          ......
          ......
          ......
          100th number -> 199   ==> required palindrome =>> 199991

          Look, while generating numbers of left-column we also generated
          the required palindromic numbers of length = 6 in the right-column.

        
          Q: How to get any nth number from left-column(i.e., nth intLength/2 length number)?
          A: You must have noticed the pattern in that. :)

             left_part(of req palindrome) = (n - 1) + 10^(P - 1), where P = ceil(intLength / 2.0)

             right_part = can be easily get from the refelection of left_part [handle odd/even case as explained]

             required nth(queries[i]th) palindromic number will be: (left_part + right_part),
                                                                    Here, "+" is string concatenation operator


          Q: How to get total count of palindromic numbers of length "intLength"?
          A: 
                Count of such numbers will be = 9 * 10^(P - 1), where P = ceil(intLength / 2.0)

class Solution {

    // Remember, L is intLength in explantion.
    private Long getPalindromicNumber(int n, int P, int L) {

        int halfDigits = (n - 1) + (int)(Math.pow(10, P - 1)); // left_part in explanation

        String leftPart = String.valueOf(halfDigits);
                                                      // If L is odd, this -> leftPart.length() - L % 2 would
                                                      // automatically ignore the "middle digit"
                                                      // to get mirrored.
        String mirrorPart = leftPart.substring(0,  leftPart.length() - L % 2);

        return Long.valueOf(leftPart + new StringBuilder(mirrorPart).reverse().toString());
    }

    public long[] kthPalindrome(int[] queries, int L) {
        int q = queries.length;
        long[] ans = new long[q];

        int P = (L + 1) / 2; // ceil(L / 2)

        // 10^(P - 1) ==> number of 10s in the multiplication with 9
        final int MAX_PALINS_COUNT = 9 * (int)(Math.pow(10, P - 1));

        for(int i = 0; i < q; i += 1) {
            if(queries[i] > MAX_PALINS_COUNT)
                ans[i] = -1;
            else
                ans[i] = getPalindromicNumber(queries[i], P, L);
        }

        return ans;
    }
}

class Solution {
    public long[] kthPalindrome(int[] queries, int intLength) {
        int n=queries.length;
        long ans[]=new long[n];
        int ans_i=0;
        
        //in length intLength only (intLength+1)/2 palindromes present
        
        //e.g. in 4 length (range between 1000 to 9999) only (90 substring present)
        //as in given example 1001, 1111, 1221, 1331, 1441, 1551,...
        //as we can see it has 10, 11, 12, 13, 14, 15 (only 4/2 length or (4+1)/2)
        
        //e.g. in 3 length (range between 100 to 999) only (90 substring present)
        //as in given example 101, 111, 121, 131, 141, 151,...
        //as we can see it has 10, 11, 12, 13, 14, 15 (only (3+1)/2 length)
        
        //bcz palindrome is made of left substring mirror to right substring
        //so we care about first half and we can made second half from first half easily
        
        // intLength is 4 or 3 we get palindrome_present=2 (we care about)
        int palindrome_present = ( intLength+1 )/2 ;
        
        long l=(long)Math.pow(10,palindrome_present-1); //10
        long r=(long)Math.pow(10,palindrome_present)-1; //99
        
        
        for(int q:queries){
            
            //if queries[ith] is within the bound
            //r-l+1 because 10 to 99 we have all the palindrome (in total we have 99-10 +1)
            if(q<=(r-l+1)){
                
                //first half is the minimum value in range (which is l) + query number -1
                //-1 bcz we have l (10) number palindrome also
                String left_half=Long.toString(l+q-1);
                
                //second half is just mirror image (01)
                String right_half=(new StringBuilder(left_half)).reverse().toString();
                
                //now for intLength 4 we have (1001) and 3 we have (1001)
                //we don't need middle value (right half 0 index) if intLength is odd
                ans[ans_i]=Long.parseLong( left_half+right_half.substring(intLength % 2 ) );
                
            }
            else{
                ans[ans_i]=-1;
            }
            
            ans_i++;
        }
        
        return ans;
    }
}
