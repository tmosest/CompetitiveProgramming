Intution :

  • Here simple intuition is to find the maximum sum of alternate group of zeros sum.
  • To do so, track the current consicutive zero counts and the last consicutive group of zero counts.
  • Keep taking maximum of the currentZeroCount + lastZeroCount groups
  • Also count the total ones and return answer as total one + maximum of alternate zero count sum.

Corener case :
There should be atleast one alternating group of zeros exists -> two groups of zero should be present to be able to covert the zeros to one. To do this we count the zero segments count as well.
Actually we don't have to count the zero segment, rather we can simply check the max convertible one count if it is eaual to last segment zeros or current segment zeros.

Complexity :

  • Time : O(N)
  • Space : O(1)

Code

C++
Java
int maxActiveSectionsAfterTrade(string s) {
    int oneCount = 0, convertedOne = 0, curZeroCount = 0, lastZeroCount = 0;
    for(int i = 0; i < s.size(); ++i){
        if(s[i] == '0') curZeroCount++;
        else{
            if(curZeroCount != 0) lastZeroCount = curZeroCount;
            curZeroCount = 0;
            oneCount++;
        }
        convertedOne = max(convertedOne, curZeroCount + lastZeroCount);
    }
    if(convertedOne == curZeroCount || convertedOne == lastZeroCount) return oneCount;    // corner case 
    return oneCount + convertedOne;
}

Intuition

The most 0s surrounding 1's block is the key point.

Approach

If you follow the rule of the trade mentioned in the problem, you will find for any trade the net gain of 1s are the 0s surrounding 1's block.
It is somewhat like the sliding window algorithm: traverse the input string, and try to find the most count of 0s surrounding 1's block.

Therefore,

  1. we just need to use 2 variables, prev and cur to record the 0s before and after 1's block, respectively;
  2. Whenever encountering a '0, increase 'cur by 1;
  3. Whenever we encounter a 1, check if prev is 0, which means we have NOT find any 1 before, hence we pass the value of cur to prev and reset cur to 0; if prev is positive, which means 1 found before and if cur is also positive, and we find a solution candidate prev + cur, update the value maxGains accordingly;
  4. Repeat the above till the end, then do NOT forget check if both cur and prev are positive and update maxGains once again;
  5. The 1s in the input string + maxGains is the solution.

Complexity

  • Time complexity:

O(n), where n = s.length().

  • Space complexity:

O(1)

Code

Java
Python
    public int maxActiveSectionsAfterTrade(String s) {
        int ones = s.chars().map(i -> i == '1' ? 1 : 0).sum();
        int maxGains = 0, prev = 0, cur = 0;
        for (int i = 0; i < s.length(); ++i) {
            if (s.charAt(i) == '0') {
                ++cur; 
            }else if (prev == 0) {
                prev = cur;
                cur = 0;
            }else if (prev > 0 && cur > 0) {
                maxGains = Math.max(maxGains, prev + cur);
                prev = cur;
                cur = 0;
            }
        }
        if (prev > 0 && cur > 0) {
            maxGains = Math.max(maxGains, prev + cur);
        }
        return ones + maxGains;
    }

Intuition

The main function in the code, maxActiveSectionsAfterTrade, aims to calculate the maximum number of active sections ('1' groups) that can be formed after a single trade operation in the given binary string s.

A trade operation allows us to replace a contiguous segment of '1's that is surrounded by '0's with a longer segment of '1's by expanding into the surrounding '0's.

Algorithm

Step 1: Modify the String
Add '1' at the beginning and end of the string s.

This helps handle edge cases where '0's are at the start or end of s.

Store this modified string as news = "1" + s + "1".

Step 2: Count the Initial Number of '1's
Iterate through the original string s and count the number of '1's.

Store this count in c1 (initial count of active sections).

Initialize ans = c1 (to track the maximum number of active sections).

Step 3: Scan for Expandable '1' Blocks
Start iterating from index 1 to news.size() - 1 (excluding added '1's).

If news[i] == '1':

Find the end of this '1' block by moving k forward until news[k] != '1'.

Step 4: Check if Expansion is Possible
If news[i-1] == '0' and news[k] == '0':

Count left '0's (c2): Move left from i-1 and count '0's.

Count right '0's (c3): Move right from k and count '0's.

Update ans = max(ans, c1 + c2 + c3).

Step 5: Move to the Next Position
Set i = k to move to the next unprocessed part of the string.

If news[i] == '0', simply move i++ to the next index.

Step 6: Return the Maximum Sections
After processing all potential trades, return ans, which stores the maximum number of active sections.

Complexity

  • Time complexity:

O(n)

  • Space complexity:

O(n)

class Solution {
public:
    int maxActiveSectionsAfterTrade(string s) {
        string news='1'+s+'1';
        int c1=0;
        for(auto i:s){
            if(i=='1'){
                c1++;
            }
        }
        int i=1,ans=c1;
        while(i<news.size()-1){
            if(news[i]=='1'){
                int k=i;
                while(k<news.size() && news[k]=='1'){
                    k++;
                }
                if(k<news.size()-1 && news[i-1]=='0' && news[k]=='0'){
                    int c2=0,c3=0,l=i-1;
                    while(l>=0 && news[l]=='0'){
                        c2++;
                        l--;
                    }
                    l=k;
                    while(l<news.size() && news[l]=='0'){
                        c3++;
                        l++;
                    }
                    ans=max(ans,c1+c2+c3);
                }
                i=k;
            }
            else{
                i++;
            }
        }
        return ans;
    }
};

class Solution {
    public int maxActiveSectionsAfterTrade(String s) {
        String news = "1" + s + "1";  
        int c1 = 0;  

        for (char ch : s.toCharArray()) {
            if (ch == '1') {
                c1++;
            }
        }

        int i = 1, ans = c1;
        
        while (i < news.length() - 1) {
            if (news.charAt(i) == '1') {
                int k = i;
                
                while (k < news.length() && news.charAt(k) == '1') {
                    k++;
                }
                
                if (k < news.length() - 1 && news.charAt(i - 1) == '0' && news.charAt(k) == '0') {
                    int c2 = 0, c3 = 0;
                    int l = i - 1;
                    
                    while (l >= 0 && news.charAt(l) == '0') {
                        c2++;
                        l--;
                    }
                    
                    l = k;
                    while (l < news.length() && news.charAt(l) == '0') {
                        c3++;
                        l++;
                    }
                    
                    ans = Math.max(ans, c1 + c2 + c3);
                }
                
                i = k; 
            } else {
                i++;
            }
        }
        
        return ans;
    }
}

Approach

Complexity

  • Time complexity: O(n)
  • Space complexity: O(n)

class Solution {
    public int maxActiveSectionsAfterTrade(String s) {
        char arr[] = s.toCharArray();
        int n = arr.length, count = 0, ans = 0, max = 0;
        List<Integer> al = new ArrayList<>();

        for(int i=0; i<n; i++) {
            if(arr[i] == '0') {
                count++;
            } else {
                ans++;
                if(count > 0) {
                    al.add(count);
                    count = 0;
                }
            }
        }

        if(count > 0) {
            al.add(count);
            count = 0;
        }

        // System.out.println(al);

        for(int i=1; i<al.size(); i++) {
            max = Math.max(max, al.get(i) + al.get(i-1));
        }

        ans += max;
        return ans;
    }
}
