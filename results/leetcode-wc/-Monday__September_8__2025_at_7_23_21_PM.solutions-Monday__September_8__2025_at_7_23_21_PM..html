After reading a few posts on this topic, I guess most of people over-think about this problem.

IMHO, We don't need to implement any graph theory expressively here; rather, it is sufficient to just check if every two adjacent elements also appears adjacently in the sub-sequences. (and of course, some basic boundary checking is also necessary)

in C++:

    bool sequenceReconstruction(vector<int>& org, vector<vector<int>>& seqs) {
        if(seqs.empty()) return false;
        vector<int> pos(org.size()+1);
        for(int i=0;i<org.size();++i) pos[org[i]] = i;
        
        vector<char> flags(org.size()+1,0);
        int toMatch = org.size()-1;
        for(const auto& v : seqs) {
            for(int i=0;i<v.size();++i) {
                if(v[i] <=0 || v[i] >org.size())return false;
                if(i==0)continue;
                int x = v[i-1], y = v[i];
                if(pos[x] >= pos[y]) return false;
                if(flags[x] == 0 && pos[x]+1 == pos[y]) flags[x] = 1, --toMatch;
            }
        }
        return toMatch == 0;
    }

We need to figure out if nums array is the only shortest unique supersequence possible from the sequences array.

sequences array can contain multiple sequences some other sequence.

This makes sense when we see the below example :-

While for sequences = [[1,2],[1,3],[1,2,3]], the only shortest supersequence possible is [1,2,3]. [1,2,3,4] is a possible valid sequence but not the shortest.

Condition 1: if sequences has a value which cannot be in the range of [1, n] then return false

if we consider each sequence in the sequences array as a path which exists in the graph. Then the shortest supersequence and nums will only be equal if the topological sort of the graph returns only one unique sequence.

Input: nums = [1,2,3], sequences = [[1,2],[1,3]]

Output: False : Because you have two possible destinations after processing 1 this will never result in a unique super sequence

Input nums = [4,1,5,2,6,3], seqs = [[5,2,6,3],[4,1,5,2]]

Output: True : At each level of top sort there is only one unique element which matches with nums[level]

Complexity

  • Time complexity: O(N) -> for creating a graph and topological sort

  • Space complexity: O(N) -> N nodes array

class Solution {
    public boolean sequenceReconstruction(int[] nums, List<List<Integer>> sequences) {
        int n = nums.length;

        int[] inDegree = new int[n + 1];
        List<List<Integer>> graph = new ArrayList<>();
        for(int listSize = 0; listSize <= n; listSize++) {
            graph.add(new ArrayList<>());
        }

        for(List<Integer> seq : sequences) {
            for(int index = 1; index < seq.size(); index++) {
                int nodeA = seq.get(index - 1);
                int nodeB = seq.get(index);
                
                if(nodeA < 1 || nodeA > n || nodeB < 1 || nodeB > n) return false;
                
                graph.get(nodeA).add(nodeB);
                inDegree[nodeB]++;
            }
        }

        Queue<Integer> topSort = new LinkedList<>();
        for(int node = 1; node <= n; node++) {
            if(inDegree[node] == 0) {
                topSort.offer(node);
            }
        }

        for(int index = 0; index < n; index++) {
            if(topSort.size() > 1 || nums[index] != topSort.peek()) return false;

            int curr = topSort.poll();
            for(int next : graph.get(curr)) {
                inDegree[next]--;
                if(inDegree[next] == 0) topSort.offer(next);
            }
        }

        return true;
    }
}

  1. Whenever you see a question with partial ordering (a > b, c >d), you should immediately wonder if topological sort can find a mapping to satisfy that ordering.
  2. We want a single possible topological sort. So let's check if we have more than one option at every step.
  3. For a BFS Tpological sort, this means the queue should never have more than one option since more than one option ==> more than one ordering.
  4. Check if the topological sort you are generating matches the one expected in org.
  5. Do a bunch of crappy validation in the middle because the input test cases can be entirely nonsensical :(
class Solution {
    public boolean sequenceReconstruction(int[] org, List<List<Integer>> seqs) {
        // Do a topological sort. It should only have one node with indegree = 0; 
        // If at any point, more than one option for topological ==> false
        if (seqs.size() == 0) {
            return org.length == 0;
        }
        int n = org.length;
        int[] inDegree = new int[n + 1];
        
        List<List<Integer>> adjList = new ArrayList<>();
        for (int i = 0; i < n + 1; i++) {
            adjList.add(new ArrayList<>());
        }
        
        for (List<Integer> seq: seqs) {
            for (int i = 0; i + 1 < seq.size(); i++) {
                int src = seq.get(i);
                int dst = seq.get(i + 1);
                
                if (src <= 0 || src > n) {
                    return false;
                }
                
                if (dst <= 0 || dst > n) {
                    return false;
                }
                
                adjList.get(src).add(dst);
                inDegree[dst] += 1;
            }
        }
        
        Set<Integer> seqNodes = new HashSet<>();
        for (List<Integer> seq: seqs) {
            for (int i = 0; i < seq.size(); i++) {
                int src = seq.get(i);
                seqNodes.add(src);
            }
        }
        
        for (int i = 1; i <= n; i++) {
            if (!seqNodes.contains(i)) {
                return false;
            }
        }
        
        if (seqNodes.size() != org.length) {
            return false;
        }
        
        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 1; i <= n; i++) {
            if (inDegree[i] == 0) {
                q.offer(i);
            }
        }
        
        int nodesVisited = 0;
        while (q.size() > 0) {
            int size = q.size();
            if (q.size() != 1) {
                return false;
            }
            
            int node = q.poll();
            if (org[nodesVisited] != node) {
                return false;
            }
            nodesVisited++;
            for (int nextNode: adjList.get(node)) {
                inDegree[nextNode] -= 1;
                if (inDegree[nextNode] == 0) {
                    q.offer(nextNode);
                }
            }
            
        }
        
        return nodesVisited == n;
    }
}

class Solution {
    public boolean sequenceReconstruction(int[] nums, List<List<Integer>> sequences) {
        int n=nums.length;
        List<Integer>[] g = new ArrayList[n+1];
        int[] indegree = new int[n+1];
        
        //Create Graph
        for(int i=1; i<=n; i++) {
            g[i]=new ArrayList<>();
        }
        
        //Build Graph
        for(List<Integer> seq:sequences) {
            for(int i=0; i<seq.size()-1; i++) {
                int u=seq.get(i), v=seq.get(i+1);
                
                g[u].add(v);
                indegree[v]++;
            }
        }
        
        Queue<Integer> sources = new LinkedList<>();
        
        //Topological Sort
        for(int i=1; i<=n; i++) {
            if(indegree[i] == 0)
                sources.add(i);
        }
        
        if(sources.size() > 1) //if more than one sources in the beginning...which means more than one sequence is possible...
            return false;
        
        int count=0;
        while(!sources.isEmpty()) {
            if(sources.size() > 1) //if more than one sources at any time...which means more than one sequence is possible...
                return false;
            
            int u=sources.poll();
            if(nums[count] != u) //not mandatory check but good to have...checks order with nums array...
                return false;
            count++;
            
            for(int v:g[u]) {
                indegree[v]--;
                if(indegree[v] == 0)
                    sources.add(v);
            }
        }
        return count == n;
    }
}

The problem 207. Course Schedule can be solved using dfs Solution This problem followes the same pattern.
The whole problem is built on the idea that if at any node you have multiple valid sources that can fit in the current position in the order array then you have multiple valid sortOrder.

We will do a simple depth first search and at each node will check for our condition if there is multiple valid sources after that node then we will return false
We will also do the same check at the begining for the same reason

enum State{
    UNVISITED,VISITED,VISITING
}

class Solution {
    Map<Integer,ArrayList<Integer>> adjList;
    State[] vis;
    int[] inDegree;
    boolean dfs(int node)
    {
        if(vis[node] == State.VISITING) return false;
        if(vis[node] == State.VISITED)  return true;
        
        vis[node] = State.VISITING;
        int sourceCount = 0;
        int next = -1;
        for(int adj : adjList.get(node))
        {
            inDegree[adj]--;
            if(inDegree[adj] == 0)
            {
                next = adj;
                sourceCount++;
            }
            
            if(sourceCount == 2)
            {
                return false;
            }
        }
        boolean ret = true;
        
        if(next != -1)
        {
            ret &= dfs(next);
        }
        
        vis[node] = State.VISITED;
        return ret;
    }
    
    
    public boolean sequenceReconstruction(int[] nums, List<List<Integer>> sequences) {
        
        adjList = new HashMap<Integer,ArrayList<Integer>>();
        vis  = new State[nums.length+1];
        inDegree = new int[nums.length+1];
        
        for(int i : nums)
        {
            adjList.computeIfAbsent(i,x->new ArrayList<Integer>());
            vis[i] = State.UNVISITED;
        }
        
        for(List<Integer> seq : sequences)
        {
            for(int i = 0 ; i < seq.size()-1 ; i++)
            {
                int a = seq.get(i);
                int b = seq.get(i+1);
                adjList.get(a).add(b);
                inDegree[b]++;
            }
        }
        //System.out.println(adjList);
        int sourceCount = 0;
        int startNode = -1;
        
        for(int node : adjList.keySet())
        {
            if(inDegree[node] == 0)
            {
                startNode = node;
                sourceCount++;
            }
            
            if(sourceCount == 2)
            {
                return false;
            }
        }
        
        
        if(startNode != -1 )
        {
            return dfs(startNode);
        }
        
        
        return true;
    }
}

Intuition

This question is to verify if the given graph could be constructed into a unique topological order which is the same as int[] nums

Approach

We can use bfs to solve this problem. To check if there is a unique topological order, for each level, we need to confirm that there is only one possible option.

After confirming that the input graph has only one topological order, we need to verify that the input array is the topological order.

To implement bfs, we need to construct the graph first. We also need an indegree map. Each round we do bfs, we offer all the elements which indegree is 0 into the queue.

Complexity

  • Time complexity:

Running bfs, TC: O(V) + O(E)

  • Space complexity:

SC is the largest size of the queue. It's possible that all the vertex has indegree of 0, so worst case is :O(V)

Code

class Solution {
    public boolean sequenceReconstruction(int[] nums, List<List<Integer>> sequences) {
         if(nums == null || nums.length == 0) return false;
        Map<Integer, Set<Integer>> map = new HashMap<>();
        Map<Integer, Integer> indegree = new HashMap<>();
        for(List<Integer> list: sequences){
            for(int i = 0; i < list.size() -1; i++){
                int cur = list.get(i);
                int next = list.get(i+1);
                map.putIfAbsent(cur, new HashSet<>());
                map.putIfAbsent(next, new HashSet<>());
                indegree.putIfAbsent(next, 0);
                indegree.putIfAbsent(cur, 0);
                if(!map.get(cur).contains(next)){
                    map.get(cur).add(next);
                    indegree.put(next, indegree.get(next)+1);
                }
            }
        }
        //for each list, there exist only one vertex
        //as long as nums contains all the nodes, it is fine
        if(map.size() == 0){
            return containsAll(nums, sequences);
        }
        //run bfs to check if the topo order is unique
        Queue<Integer> queue = new ArrayDeque<>();
        List<Integer> topo = new ArrayList<>();
        return bfs(indegree, map, queue, topo, nums);
    }

     private boolean containsAll(int[] nums, List<List<Integer>> sequences){
        Set<Integer> nodes = new HashSet<>();
        for(List<Integer> sequence: sequences){
            for(Integer node: sequence){
                nodes.add(node);
            }
        }
        if(nums.length != nodes.size()) return false;
        for(int num: nums){
            if(!nodes.contains(num)){
                return false;
            }
        }
        return true;
    }

    //1. the topo order shall be unique
    //2. the topo order shall be exactly the same as int[]nums
    private boolean bfs(Map<Integer, Integer> indegree, Map<Integer, Set<Integer>> graph, Queue<Integer> queue, List<Integer> topo, int[] nums){
        //put all elements with indegree 0 into the queue
        for(Integer node: indegree.keySet()){
            if(indegree.get(node) == 0){
                queue.add(node);
            }
        }
        while(!queue.isEmpty()){
            if(queue.size() != 1){
                return false;
            }
            int cur = queue.poll();
            topo.add(cur);
            Set<Integer> neighbors = graph.get(cur);
            if(neighbors != null){
                for(Integer nei: neighbors){
                    indegree.put(nei, indegree.get(nei)-1);
                    if(indegree.get(nei) == 0){
                        queue.offer(nei);
                    }
                }
            }
        }
        if(topo.size() != indegree.size()) return false;
        return same(topo, nums);
    }

    private boolean same(List<Integer> topo, int[] nums){
        if(topo.size() != nums.length) return false;
        for(int i = 0; i < topo.size(); i++){
            if(topo.get(i) != nums[i]) return false;
        }
        return true;
    }
}

    public boolean topologicalSortDFS(int currNode, Set<Integer> visited, Map<Integer, List<Integer>> graph, int[] indegree) {
        int totalSource = 0;

  • I believe this is the most difficult topological sort problem I solved so far. Much more difficult than the hard problem Alien Dictionary.
  • The first difficult part is to understand the problem. It is so bad written. To put it simply, the seqs array represent edges, and the question asks if org is the only answer for a topologically sorted array of nodes in seqs.
  • In other topological sort questions, one sentence is frequently mentioned in the problem description: if there are multiple answers, return any of them. And this question specifically asks, if there are multiple answers, return false.
  • How to tell if there are multiple answers? Since we add neighbor nodes level by level, if at some point, queue has more than one nodes, it means there are multiple nodes at this level, and we can add any nodes in the queue now to the sorted array . In this case, we have multiple answers and we return false.
  • The second difficult part is to figure out there might be length 1 arrays in seqs. So far for all topological sort questions, the edge array is always in the form of [ai, bi]. You would not think there could also be [ai].
  • The third corner case is that seqs might have more or fewer nodes than org. Adding a comparison of indegree size and org length can solve this.
  • Time and space complexity are both O(E+V). E is the number of edges, which equals n * m where n is the length of seqs and m is the length of seqs[0]. V is the number of vertices, which is the size of the graph. It could be different than the length of org.
class Solution {
    public boolean sequenceReconstruction(int[] org, List<List<Integer>> seqs) {
        Map<Integer, List<Integer>> graph = new HashMap<>();
        Map<Integer, Integer> indegree = new HashMap<>();
        for (int i = 0; i < seqs.size(); i++) {
            List<Integer> seq = seqs.get(i);
            // Special case: only one element in seq.
            if (seq.size() == 1) indegree.putIfAbsent(seq.get(0), 0);
            for (int j = 0; j < seq.size() - 1; j++) {
                graph.putIfAbsent(seq.get(j), new ArrayList<>());
                graph.get(seq.get(j)).add(seq.get(j + 1));
                indegree.putIfAbsent(seq.get(j), 0);
                indegree.putIfAbsent(seq.get(j + 1), 0);
                indegree.put(seq.get(j + 1), indegree.get(seq.get(j + 1)) + 1);
            }
        }
        
        // Since we put all elements in seqs in indegree,
        // if org has more or fewer elements, it could not be reconstructed.
        if (indegree.size() != org.length) return false;
        
        Queue<Integer> queue = new LinkedList<>();
        for (int i: indegree.keySet()) {
            if (indegree.get(i) == 0) queue.offer(i);
        }
        
        List<Integer> ans = new ArrayList<>();
        while (!queue.isEmpty()) {
            // If there are more than 1 element in queue,
            // it means we can have multiple answers, 
            // so directly returen false
            if (queue.size() > 1) return false;
            int cur = queue.poll();
            ans.add(cur);
            // If the graph doesn't have key nb,
            // it means it should be the last element to add.
            if (!graph.containsKey(cur)) break;
            for (int nb: graph.get(cur)) {
                indegree.put(nb, indegree.get(nb) - 1);
                if (indegree.get(nb) == 0) queue.add(nb);
            }
        }
        
        if (ans.size() != org.length) return false;
        for (int i = 0; i < ans.size(); i++) {
            if (ans.get(i) != org[i]) return false;
        }
        return true;
    }
}

class Solution {
    public boolean sequenceReconstruction(int[] nums, List<List<Integer>> sequences) {
        // step 1: build graph
        int n = nums.length;
        List<Integer>[] graph = (List<Integer>[]) new List[n];
        Arrays.setAll(graph, i -> new ArrayList<>());
        int[] indegree = new int[n];
        for (List<Integer> edges : sequences) {
            for (int i = 0; i < edges.size() - 1; i++) {
                graph[edges.get(i) - 1].add(edges.get(i + 1) - 1);
                indegree[edges.get(i + 1) - 1]++;
            }
        }

        // step 2: topology sort
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < n; i++)
            if (indegree[i] == 0) queue.offer(i);
        for (int num : nums) {
            if (queue.size() != 1) return false;
            int node = queue.poll();
            if (node != num - 1) return false;
            for (int next : graph[node]) {
                if (--indegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }

        return true;
    }
}
