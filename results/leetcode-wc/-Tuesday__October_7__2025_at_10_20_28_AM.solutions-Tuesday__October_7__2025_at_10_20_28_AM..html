Intuition

We are given several cuboids, and each cuboid has 3 dimensions: width, length, and height. We are allowed to rotate any cuboid — that means we can rearrange the dimensions in any order. So, a cuboid [50, 45, 20] can be treated as [20, 45, 50], or any other permutation.

We are allowed to choose any subset of cuboids and stack them on each other — but with a rule:
For one cuboid to be placed on top of another, all three dimensions of the top one must be less than or equal to those of the bottom one.

So how can we figure out which cuboids can go on top of which? Let’s observe a pattern:

Let’s say we have these three cuboids (after sorting individual dimensions):

  • A: [12, 23, 45]
  • B: [20, 45, 50]
  • C: [37, 53, 95]

Now clearly:

  • A can go on B (all dimensions of A ≤ B)
  • B can go on C (again, all dimensions ≤)

So a valid stack would be: C ? B ? A.

Now look closer — what we’re really doing is:

  • Picking an order of cuboids such that each one is no bigger than the one below it in all dimensions.
  • And among all such orders, we want the maximum total height.

This is very similar to how we pick elements in a sequence where each next item follows some condition relative to the previous one.

If we treat each cuboid like a “step” and want to choose some of them in order such that each step fits on the previous one, we’re essentially forming a chain of compatible cuboids — and maximizing the total height of that chain.

That’s when it clicks — this problem has the same structure as the Longest Increasing Subsequence (LIS), just extended to 3 dimensions and total height instead of length.

Approach

  1. Sort Each Cuboid’s Dimensions Individually
  • Since we can rotate each cuboid, we sort its dimensions so that the smallest is first and largest is last.
    For example, [50, 45, 20] ? [20, 45, 50].
  1. Sort All Cuboids
  • Once each cuboid is normalized, we sort the entire list in descending order of dimensions — so bigger cuboids come first. This helps us process possible base cuboids before the ones that could go on top.
  1. Use Dynamic Programming to Build the Best Stack
    Let’s define:
  • dp[i] = maximum height of stack ending at cuboid i.
    For each cuboid i, we:
  • Set dp[i] = height of cuboid[i] (base case: it's standing alone).
  • Look back at all cuboids j < i:
    If cuboid i can be placed on cuboid j (i.e., all dimensions are ≤), we update:
    dp[i] = max(dp[i], dp[j] + height of cuboid[i])
  1. Return the Maximum Value in dp[]
  • This will be the maximum height we can achieve by stacking a compatible sequence of cuboids.

Complexity

  • Time complexity: O(N^2)
  • Space complexity: O(N)

Code

Java
class Solution {
    public int maxHeight(int[][] cuboids) {
        int n=cuboids.length;
        //as per given qeustion we can rearrange then dimensions of a particular cuboid
        //Step 1:sort dimensions of each cuboid so that we can rotate them freely
        for (int[] cuboid : cuboids) {
            Arrays.sort(cuboid); // sort dimensions of each cuboid
        }
        //since we have to put cuboid stack in a manner that below is bigger in every side of cuboid above it
        //Step 2:sort cuboids based on dimensions for LIS
        Arrays.sort(cuboids, (a,b)->{
            if (a[0] != b[0]) return b[0] - a[0];
            if (a[1] != b[1]) return b[1] - a[1];
            return b[2]-a[2];
        });
        //this matches with behaviour of Longest Increasing Subsequence where we have to find longest subsequence which is increasing, but the case is we have to 3D in place of 1D now
        // Step 3: Apply LIS in 3D based on conditions
        int[] dp=new int[n];
        int max=0;

        for(int i=0; i<n; i++){
            dp[i] = cuboids[i][2]; //at least we can place cuboid i alone:default set if can't change later
            for(int j=0; j<i; j++){
                if (canPlace(cuboids[i], cuboids[j])) {
                    dp[i]=Math.max(dp[i], dp[j]+cuboids[i][2]);
                }
            }
            max = Math.max(max, dp[i]);
        }

        return max;
    }

    //chheck if 'a' can be placed on 'b'
    private boolean canPlace(int[] a, int[] b) {
        return a[0]<=b[0] && a[1]<=b[1] && a[2]<=b[2];
    }
}
