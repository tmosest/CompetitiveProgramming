Code Explanation

Step 1: Setup Two Pointers

int i = 0, j = 1, k = 0;
i is the start index of our best candidate (the best substring found so far).

j is a rival index — another position we’re comparing to i to see if it gives a better result.

k is the offset to compare characters from both substrings starting at i and j.

Step 2: Keep Comparing While Both Substrings Are Valid

while (j + k < s.size())
We compare characters at i + k and j + k. We stop if j + k goes out of bounds.

Step 3: Characters Match — Go Deeper

if (s[i + k] == s[j + k]) {
    k++;
}

If characters match at offset k, just keep comparing next characters.

We increment k and move deeper into both substrings.

Step 4: i Substring is Better

else if (s[i + k] > s[j + k]) {
    j = j + k + 1;
    k = 0;
}

If s[i + k] > s[j + k], it means the substring starting at i is better.

So we skip this rival jand move it forward to start a new comparison.

Reset k to 0 to start fresh comparison with the new j

Step 5: j Substring is Better

else {
    if (i + k + 1 > j) {
        i = j + k - 1;
    } else {
        i = j;
    }
    j = i + 1;
    k = 0;
}

Now s[j + k] > s[i + k], so the rival j is giving a better substring.

We want to move i forward — possibly skipping to rival’s position or slightly earlier.

This helps in avoiding overlaps or re-checking same pairs.

Again, we reset k = 0 and continue.

Step 6: Return the Best Substring

return s.substr(i);
Once the loop ends, we know the best starting index for the substring is i. So return s.substr(i).

Complexity

  • Time complexity: O(n)
  • Space complexity: O(1)

class Solution {
public:
    string lastSubstring(string s) {
        int i = 0, j = 1, k = 0;

        while (j + k < s.size()) {          
            if (s[i + k] == s[j + k]) {
                k++;
            }
            else if (s[i + k] > s[j + k]) {                
                j = j + k + 1;
                k = 0;
            }
            else {
                // if i+k surpass j
                if (i + k + 1 > j) {
                    // i = j + k - 1;
                    i = i + k + 1;
                } 
                else {
                    i = j;
                }

                j = i + 1;
                k = 0;
            }
        }

        return s.substr(i);
    }
};
