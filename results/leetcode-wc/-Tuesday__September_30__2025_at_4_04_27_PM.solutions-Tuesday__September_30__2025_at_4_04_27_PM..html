Intuition

I suggest solving 1504. Count Submatrices With All Ones first, to get the intuition on histograms.

Then, what we do in this question is create a histogram from the input matrix, based on the row condition given (non-increasing rows, values less than or equal to k).

With the histogram ready, we transpose it (it's rotated left, because of how we created it) and pass to numSubmat which counts the submatrices and returns the final result.

class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        m, n = len(grid), len(grid[0])
        dp = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                if grid[i][j] > k:
                    continue
                dp[i][j] = dp[i][j-1] + 1 if j - 1 >= 0 and grid[i][j-1] >= grid[i][j] else 1

        return self.numSubmat(list(zip(*dp)))

    def numSubmat(self, dp: List[List[int]]) -> int:
        m, n = len(dp), len(dp[0])
        res = 0
        for i in range(m):
            st = []
            count = 0
            for j in range(n):
                while st and dp[i][st[-1]] >= dp[i][j]:
                    r = st.pop()
                    l = st[-1] if st else -1
                    count -= (dp[i][r] - dp[i][j]) * (r - l)

                st.append(j)
                count += dp[i][j]
                res += count

        return res

len is the current length of non-increasing subsequence of numbers less than k in row i.

mono[j] is the stack of increasing lengths and their count for column j.

mono_sum[j] is the sum of all lengths in column j.

Say the len for column j is 2, and in the mono[j] we have the following elements:

* * 1 (2)
* 2 1 (3)
3 2 1 (1)
  ^
  |
* 2 1 (current)

That means that we have 6 row above with lengths of 3, 2 and 1, and mono_sum[j] = 1 * 2 + 2 * 3 + 3 * 1 = 11.

We remove length 3 from the stack and increase count of length 2 accordingly. After this, mono[j] looks like this:

* * 1 (2)
* 2 1 (5)

As we do this, we update mono_sum[j], so its value is now 11 - 3 * 1 + 2 * 2 = 12.

Thus, g[i][j] is the right-bottom corner of 12 submatrices that satisfy the condition, so we add mono_sum[j] to the result.

The time and menory complexity is O(m * n), because we have no more than m elements and total operations in monostrack for each of n columns.

C++

long long countSubmatrices(vector<vector<int>>& g, int k) {
    long long m = g.size(), n = g[0].size(), res = 0;
    vector<vector<pair<int, int>>> mono(n);
    vector<int> mono_sum(n);
    for (int i = 0; i < m; ++i)
        for (int j = 0, len = 0; j < n; ++j)
            if (g[i][j] <= k) {
                len = (j && g[i][j - 1] >= g[i][j] ? len : 0) + 1;
                int len_count = 1;
                while (!mono[j].empty() && mono[j].back().first > len) {
                    len_count += mono[j].back().second;
                    mono_sum[j] -= mono[j].back().first * mono[j].back().second; 
                    mono[j].pop_back();
                }
                if (mono[j].empty() || mono[j].back().first != len)
                    mono[j].push_back({len, 0});
                mono[j].back().second += len_count;
                mono_sum[j] += len * len_count;
                res += mono_sum[j];
            }
            else {
                mono[j].clear();
                len = mono_sum[j] = 0;
            }
    return res;
}

Intuition

This is the same methodology as solving "1504. Count Submatrices With All Ones" with a preprocessing step.

Develop a histogram for each row.

For each row, we identify vaild contiguous stretches and step up on count.

Consider row [5,4,3,6,4,2], k = 6
The resulting conversion yields [1,2,3,0,1,2], where (5,4,3) is one stretch, then it resets and followed by (4,2).

Once we have done so for all rows, we now examine column by column.
Column-wise, we have enough information to determine the number of eligible rectangles where the bottom-right corner are anchored at (i,j). We can solve this with the use of monotonic stack column by column.

Approach

Preprocessing to histogram is trivial.

I struggled with forming the montonic stack and this is what I Will focus on. The problem can be split into two cases, strictly increasing and non-increasing.

Scenario 1 - strictly increasing

Starting top down, we know that with each new value, the number of rectangles anchored at that location is histo[i][col] + count at histo[i-1][col].

Why? Imagine a column with these histo values
1
2

  • at "1", we have: one 1x1. Total of 1
  • at "2", we have one 1x1, one 1x2 and one 2x1. The last 2x1 is a direct inheritance of the prior "1". Total of 3

Total number of rectangles for this column is 1+3 =4

Scenario 2 - non-increasing

3
2
1

  • at "3", we have: one 1x1, one 1x2, one 1x3. Total of 3
  • at "2", this being smaller, we are restricted on width. We count the number of rectangles in a 2x2 space anchored at bottom-right. This is a total of 4.
  • at "1", we are now restricted to use width 1. We have to count the number of rectangles in 3x1 space. This is a total of 3.

Total number of rectangles for this column is 3+4+3 = 10

Putting all of this together.

We use a stack while keeping its values strictly increasing. In a decreasing scenario, we remove anything on the stack that is lower than the new value, while keeping track on the height. To gather the total count of rectangles at each i,j, we simply sum up what is in the stack.

Complexity

  • Time complexity:
    O(mn)

  • Space complexity:
    O(mn)

class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        m = len(grid)
        n = len(grid[0])
        histo = [[0] * n for _ in range(m)] #keeping track of counts

        #process the grid
        for i, row in enumerate(grid):
            prior = k
            for j, cell in enumerate(row) :
                if cell > k:
                    histo[i][j] = 0
                    prior = k
                elif cell > prior:
                    histo[i][j] = 1
                    prior = cell
                else: #cell <= prior:
                    histo[i][j] = histo[i][j-1] + 1 if j else 1
                    prior = cell
        
        #process each column
        total = 0
        for j in range(n):
            stack = []
            mytotal = 0
            for i in range(m):
                curr_val = histo[i][j]
                if curr_val == 0:
                    stack = []
                    mytotal = 0
                else:
                    height = 1
                    while stack and stack[-1][0] > curr_val:
                        w, h = stack[-1]
                        mytotal -= w*h
                        height += h
                        stack.pop()

                    stack.append((curr_val, height))
                    mytotal += (curr_val*height)

                #add up all the eligbile matrices
                total += mytotal

        return total

Intuition

Count how many submatrices have elements less than or equal to a given value k. To solve this, we need to track the possible submatrices that end at each element in the grid and sum their values. We can optimize the process by considering how the current row connects to the previous one and how the matrix’s elements extend valid submatrices from previous rows.

Approach

Iterate through each row and calculate the maximum possible length of valid submatrices that can end at each element. For each element, we update the len array to track the length of the submatrices, use a mono vector to store lengths, and a mono_sum array to accumulate the sum of these submatrices.

Complexity

  • Time complexity:
    O(m * n), where m is the number of rows and n is the number of columns. This is because we are iterating over every element in the matrix.

  • Space complexity:
    O(n), as we only need to store the len, mono, and mono_sum arrays, all of which depend on the number of columns.

impl Solution {
    pub fn count_submatrices(g: Vec<Vec<i32>>, k: i32) -> i64 {
        let m = g.len();
        let n = g[0].len();
        let mut res = 0i64;
        let mut mono: Vec<Vec<(i32, i32)>> = vec![vec![]; n];  // Initialize correctly
        let mut mono_sum = vec![0i64; n];

        for i in 0..m {
            let mut len = vec![0; n]; // Initialize length vector for current row

            for j in 0..n {
                if g[i][j] <= k {
                    len[j] = if j > 0 && g[i][j - 1] >= g[i][j] { len[j - 1] + 1 } else { 1 };

                    let mut len_count = 1;
                    while !mono[j].is_empty() && mono[j].last().unwrap().0 > len[j] {
                        len_count += mono[j].last().unwrap().1;
                        mono_sum[j] -= mono[j].last().unwrap().0 as i64 * mono[j].last().unwrap().1 as i64;
                        mono[j].pop();
                    }

                    if mono[j].is_empty() || mono[j].last().unwrap().0 != len[j] {
                        mono[j].push((len[j], 0));
                    }

                    let last = mono[j].last_mut().unwrap();
                    last.1 += len_count;
                    mono_sum[j] += len[j] as i64 * len_count as i64;
                    res += mono_sum[j];
                } else {
                    mono[j].clear();
                    mono_sum[j] = 0;
                }
            }
        }

        res
    }
}

Intuition

The problem requires counting submatrices with a sum less than or equal to k. My initial approach was to develop an efficient algorithm that can process the grid column by column, tracking valid subsequences while maintaining a low computational overhead.

Approach

The solution uses a sophisticated dynamic programming technique with a monotonic stack to count submatrices:

  1. Process the grid column by column
  2. Maintain a tbl_accum_len array to track valid subsequence lengths for each row
  3. Use a monotonic stack (inds_ord) to efficiently manage row indices
  4. For each cell, determine if it can extend an existing subsequence or start a new one
  5. Calculate the number of valid submatrices by tracking cumulative subsequence lengths
  6. Continuously update the result with the count of valid submatrices

Key implementation details:

  • Check if current cell value is less than or equal to k
  • Extend or reset subsequence lengths based on cell values
  • Use a monotonic stack to efficiently process row subsequences
  • Accumulate valid submatrix counts progressively

Complexity

  • Time complexity: O(m*n)

    • m is the number of rows
    • n is the number of columns
    • Each cell is processed once during the column-wise iteration

  • Space complexity: O(m)

    • Uses additional arrays of length m
    • tbl_accum_len stores subsequence information
    • inds_ord is a monotonic stack that can grow up to m elements

The algorithm provides an efficient solution by avoiding nested loops and using a single-pass approach through the grid.

class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        num_rows = len(grid)
        num_cols = len(grid[0])
        max_val = k
        tbl_accum_len = [None for _ in range(num_rows)]

        result = 0
        for col in range(num_cols):  
            inds_ord = [-1]
            lens_range_sum = 0
            for i in range(num_rows):
                val = grid[i][col]
                if tbl_accum_len[i] is not None and grid[i][col - 1] >= val:
                    tbl_accum_len[i] += 1
                elif val <= max_val:
                    tbl_accum_len[i] = 1
                else:
                    tbl_accum_len[i] = None
                    lens_range_sum = 0
                    inds_ord.clear()
                    inds_ord.append(i)
                    continue
                
                curr_len = tbl_accum_len[i]
                while len(inds_ord) > 1:
                    j = inds_ord[-1]
                    prev_len = tbl_accum_len[j]
                    if prev_len < curr_len:
                        break
                    inds_ord.pop()
                    assert inds_ord
                    lens_range_sum -= prev_len * (j - inds_ord[-1])
                assert inds_ord                
                lens_range_sum += curr_len * (i - inds_ord[-1])
                result += lens_range_sum
                inds_ord.append(i)
        
        return result

First calculate the length of the longest non-decreasing subarray starting from each grid[i][j] and store them in a matrix, which can be done in one pass.

The loop through the matrix we saved by their columns,

in subarray [i:j] if a column , we have min(col[i:j]) matrices with its upper left pinned at grid[c][i], and to calcalute the sum of all subarrays, use two monotonic stacks to store the leftmost and rightmost positions of a subarray with the certain element in the column as the minimum. Loop over leftlimits,rightlimits,and column, there are (i-l)*(r-i) choices of subarrays with minimum col[i], sum them over.

class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        m = len(grid)
        n = len(grid[0])
        longest_decreases = [[0 for i in range(n)] for j in range(m)]
        for i,row in enumerate(grid):
            stack = []
            for j,a in enumerate(row):
                if not stack or a <= row[stack[-1]]:
                    stack.append(j)
                else:
                    for p in stack:
                        longest_decreases[i][p] = j - p
                    stack = [j]
            for p in stack:
                longest_decreases[i][p] = n - p
        res = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j]>k:longest_decreases[i][j] = 0
        cols = [[] for i in range(n)]
        for j in range(n):
            for i in range(m):
                cols[j].append(longest_decreases[i][j])
        for col in cols:
            stack = []
            lefts = [-1]*m
            for i,c in enumerate(col):
                while stack and col[stack[-1]]>=c:
                    stack.pop()
                if stack:
                    lefts[i]=stack[-1]
                stack.append(i)
            rights = [m]*m
            stack = []
            for i in range(m-1,-1,-1):
                c = col[i]
                while stack and col[stack[-1]]>c:
                    stack.pop()
                if stack:
                    rights[i]=stack[-1]
                stack.append(i)
            #print(col,lefts,rights)
            for i,(c,l,r) in enumerate(zip(col,lefts,rights)):
                res += c*(i-l)*(r-i)
        return res

As with other matrix problems involving counting submatrices, a dp framework makes sense. A good, similar problem to start with is 1504. Count Submatrices With All Ones. The dp framework derives the count of submatrices with a lower-right corner at a given row and column index, and then those counts are aggregated. To build up that dp, examine the matrix row-by-row to determine valid subarrays, and then link connected subarrays to determine valid submatrices. Iterating through an m x n matrix is O(m x n) at a minimum, and backtracking through previous rows to determine submatrices could get messy, so this solution uses a stack for each column to address that. Let's dive into the solution...

Approach

As touched on in the intro, other submatrix problems provide a foundation for how to tackle this one, and at a high level, the dp process is as follows:
- Iterate through each row in the matrix to determine valid subarrays. Here, the validity criteria are that the maximum element is <= k, and the elements in rows are non-increasing. As noted in the intro, the overall dp framework determines how many submatrices have a lower-right corner at a given row and column index, so a good starting point is to examine the number of valid arrays that end at a given index for a row. Using a sample row of [5,3,2,1,5,1,1] with k = 3, the "row dp" for that array is [0,1,2,3,0,1,2].
- With each "row dp" containing the count of arrays in that row that end at a given index, connect rows together to convert valid arrays into valid submatrices where possible. Starting at a given row and column index, initialize a "matrix count" as the array count for that row/column index, which we'll call the "valid array ct". For the column index, backtrack through previous rows, take the minimum of the current array count and the previous minimum array ct, and add that to the matrix count. Using a matrix of [[6,2],[4,3],[4,1]] with k = 4 as an example, the "row dp" would be [[0,1],[1,2],[1,2]], and using [row, col] of [2, 1] as an example:
-- initialize the matrix count as the row dp value of 2, with the valid array count also as 2
-- backtrack to the previous row (index 1), and the column index is constant as 1. This row's array count is 2, with a minimum seen array count of 2. Add 2 to the matrix count (total = 4)
-- backtrack to the previous row (index 0). This row's array count is 1, which is the new minimum. Add 1 to the matrix count (total = 5)
-- (the process repeats until the beginning of the matrix is reached, or a row's count is 0)

One can see that the final backtracking process can be adapted into a stack framework, where for a given column, we want the "valid array ct" to be increasing. This code adapts the above:
- Initialize row_dp as a dp matrix, initialize col_stack as an array of arrays. A complementary array col_sum will be used to streamline the matrix counts using the stacks in col_stack.
- Iterate through the rows in the input grid and the elements in each row:
-- Compare each element to k. If the value is larger than k, no valid submatrices containing that element will be valid, so eliminate all stacks and clear all sums for the current column index.
-- If the element is <= k, we know we have at least one valid submatrix, this single element. Now let's attempt to connect it to other arrays and elements:
--- If the element is not the first in a row (column index > 0), check the previous element (column index - 1) to determine if the array is non-increasing (if col_idx and (grid[row_idx][col_idx - 1] >= grid[row_idx][col_idx]):). If valid, extend the array by incrementing the row/col value in row_dp.
--- Using row_dp as a start, compare that to the column stack, representing linking previous rows into submatrices. The stack will contain tuples of the form (array ct, row index), so if the array ct from the current row is less than the previous row's array ct, pop the stack to keep it increasing. Then use the stack to adjust the column sum, comparing the array counts and the row indices of adjacent elements in the stack.
--- Once the column sum is recalculated, that represents the number of submatrices with a lower right corner at the current row and column index. So add that count to the answer total.

Once the full matrix is iterated through, that answer total will contain the count of submatrices with a maximum value of k, and with each row non-increasing.

class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        m = len(grid)
        n = len(grid[0])
        row_dp = [[0] * n for _ in range(m)]
        col_stack = []
        for _ in range(n):
            col_stack.append([(0, -1)])
        col_sum = []
        for _ in range(n):
            col_sum.append([0])
                
        ans = 0
        for row_idx in range(m):
            for col_idx in range(n):
                if grid[row_idx][col_idx] > k:
                    col_stack[col_idx] = [(0, row_idx)]
                    col_sum[col_idx] = [0]
                else:
                    row_dp[row_idx][col_idx] = 1
                    if col_idx and (grid[row_idx][col_idx - 1] >= grid[row_idx][col_idx]):
                        row_dp[row_idx][col_idx] += row_dp[row_idx][col_idx - 1]

                    while col_stack[col_idx] and row_dp[row_idx][col_idx] < col_stack[col_idx][-1][0]:
                        col_stack[col_idx].pop()
                        col_sum[col_idx].pop()
                    col_stack[col_idx].append((row_dp[row_idx][col_idx], row_idx))
                    new = col_stack[col_idx][-1][0] * (col_stack[col_idx][-1][1] - col_stack[col_idx][-2][1])
                    col_sum[col_idx].append(col_sum[col_idx][-1] + new)
                    
                    ans += col_sum[col_idx][-1]

        return ans
