Explanation

Case 1: Handle quadrants
Make 4 cells all 1s or all 0s.
The count of 1s is 4 or 0 in the end.

Case 2: Handle middle column and row
Count diff pair and one of 1s
Each diff pair need one operation.

Case 3: Handle center
It has to be 0.

If no diff pair and one % 4 == 2,
we need to change two 1s to 0s.

Complexity

Time O(mn)
Space O(1)

    public int minFlips(int[][] A) {
        int res = 0, one = 0, diff = 0, m = A.length, n = A[0].length;
        // Handle quadrants
        for (int i = 0; i < m / 2; ++i) {
            for (int j = 0; j < n / 2; ++j) {
                int v = A[i][j] + A[i][n - 1 - j] + A[m - 1 - i][j] + A[m - 1 - i][n - 1 - j];
                res += Math.min(v, 4 - v);
            }
        }
        // Handle middle column
        if (n % 2 > 0) {
            for (int i = 0; i < m / 2; ++i) {
                diff += A[i][n / 2] ^ A[m - 1 - i][n / 2];
                one += A[i][n / 2] + A[m - 1 - i][n / 2];
            }
        }
        // Handle middle row
        if (m % 2 > 0) {
            for (int j = 0; j < n / 2; ++j) {
                diff += A[m / 2][j] ^ A[m / 2][n - 1 - j];
                one += A[m / 2][j] + A[m / 2][n - 1 - j];
            }
        }
        // Handle center point
        if (n % 2 > 0 && m % 2 > 0) {
            res += A[m / 2][n / 2];
        }
        // Divisible by 4
        if (diff == 0 && one % 4 > 0) {
            res += 2;
        }
        return res + diff;
    }

Intuition

  1. Quadrant Comparison:
  • By comparing and flipping cells in each quadrant, we ensure that each 2x2 block is palindromic.
  • We calculate how many flips are needed to achieve this and sum them up.
  1. Center Adjustment:
  • When dealing with an odd number of rows or columns, ensure that the center row and column are also palindromic.
  • This requires calculating the difference between the cells and checking how many flips are needed to balance them.
  1. Minimizing Total Flips:
  • We need to handle cases where the total number of flips for the center row and column may not directly match.
  • Calculate the additional flips needed based on the difference between zeros and ones in the center row and column.

Approach

  1. Quadrant Flips:
  • The grid is divided into four quadrants around the center.
  • For each cell (i, j) in the top-left quadrant, we check the corresponding cells in the other three quadrants (bottom-left, top-right, bottom-right).
  • Calculate the number of 1s in these four cells and determine the minimum flips needed to make them all the same (either all 0s or all 1s).
  1. Center Row and Column Handling:
  • For grids with an odd number of rows, handle the center row separately to ensure that all elements in this row form a palindrome.
  • Similarly, handle the center column if the number of columns is odd.
  • If both the number of rows and columns are odd, handle the center cell.
  1. Adjust for Odd Length Rows and Columns:
  • Calculate the minimum flips required to make the center row and column palindromic and adjust the total flips accordingly.

Complexity

  • Time complexity: O(m*n)
    • Iterating over half of the rows and columns, each cell's flips are computed in constant time.
    • This results in a time complexity of O(m * n / 4), which simplifies to O(m * n)
  • Space complexity:O(1)

class Solution {
    public int minFlips(int[][] grid) {
        int ans = 0;
        int m = grid.length;
        int n = grid[0].length;
        // Process each 2x2 block of the grid
        for(int i = 0; i < m/2; i++) {
            for(int j = 0; j < n/2; j++) {
                int cnt = 0;
                // Count the number of 1s in the current 2x2 block
                cnt += grid[i][j];
                cnt += grid[m-1-i][j];
                cnt += grid[i][n-1-j];
                cnt += grid[m-1-i][n-1-j];

                // Calculate flips needed to make all cells the same
                ans += Math.min(cnt, 4-cnt);
            }
        }

         // Handle center row if the number of rows is odd
        int diff = 0;
        int p0 = 0;
        int p1 = 0;
        if(m%2==1) {
            for(int j = 0; j < n/2; j++) {
                if(grid[m/2][j] != grid[m/2][n-j-1]) diff++;
                else {
                    if(grid[m/2][j] == 0) p0++;
                    else p1++;
                }
            }
        }
        if(n%2==1) {
            for(int i = 0; i < m/2; i++) {
                if(grid[i][n/2] != grid[m-i-1][n/2]) diff++;
                else {
                    if(grid[i][n/2] == 0) p0++;
                    else p1++;
                }
            }
        }

         // Adjust for the center cell if both dimensions are odd
        if(n%2==1 && m%2==1) {
            if(grid[m/2][n/2]==1) ans++;
        }

        // Calculate the minimum number of additional flips needed for center row and column
        int ans1 = Integer.MAX_VALUE;
        if(diff%2 == p1%2) {
            ans1 = diff;
        } else {
            if(diff%2==0) {
                if(diff==0) {
                    ans1 = 2;
                } else {
                    ans1 = diff;
                }
            } else {
                ans1 = diff;
            }
        }

        return ans + ans1;
    }
}

Intuition

  1. Every cell in a matrix is part of a "four-cell" group. Only true for cells that aren't part of the central row &/or central column (central row/col not defined for square matrix). The exact formula for the location of the four cells are discussed later.

  2. When you have a square matrix with odd number of rows and odd number of columns then check for the central element Ð if it's 1 then you will have to always make it 0 as this cell can never be part of any "four-cell" group.

  3. For the central row &/or central column in an odd*odd sized matrix :

    • consider only those pairs where both are 1 and doesn't affect the palindromic nature. Then for such pairs,

    • let sum of 1's in row = A

    • let sum of 1's in col = B

    • sum of all 1's = A + B

    • total sum of 1's could either be 0 / multiple of 2 / multiple of 4

    • if it is 0 or multiple of 4, we don't need to do anything extra

    • what about the 1's that would be formed after modifying 0's ? 1's ? We could rather make all 1's ? 0's to prevent disturbing the count of 1's

    • otherwise if the total sum is not a multiple of 4 then you need atleast 1 pair of either (0,1) or (1,0) (from either the central column or central row) so that the total count of 1's is a multiple of 4

    • otherwise you need to operate on one of the pair (1,1) to reduce the count of 1's by 2 thus making it either a multiple of 4 or 0

Approach

  1. Initial Setup
    • Determine the number of rows (row) and columns (col) in the grid.
    • Initialize totalOperations to 0 to keep track of the number of flips.
    • Calculate rowLimit and colLimit which represent the half-way points of the grid (for both rows and columns).
  2. Processing each cell
    • Iterate through each cell only up to the halfway points (rowLimit and colLimit) to avoid redundant checks.
    • For each cell, calculate its corresponding symmetrical cells in the grid. These are:
      • The cell itself grid[i][j]
      • The cell mirrored horizontally grid[i][mCol]
      • The cell mirrored vertically grid[mRow][j]
      • The cell mirrored diagonally grid[mRow][mCol]
    • Count the number of 1s among these four cells.
    • If there are two 1s, two operations are needed (to make it palindromic).
    • If there is one or three 1s, one operation is needed.
  3. Handling Odd Row or Column Lengths:
    • If the number of rows is odd, check the middle row to ensure it's palindromic.
    • Similarly, if the number of columns is odd, check the middle column.
    • Track mismatches and count the pairs of 1s.
  4. Ensure Total Number of 1's is Divisible by 4:
    • Check the total pairs of 1s from rows and columns. If the sum is not divisible by 4 and there are no mismatches, add two operations to ensure divisibility.
  5. Final Adjustments:
    • If both the number of rows and columns are odd, handle the center cell separately.

Complexity

  • Time complexity: O(m*n)
  • Space complexity: O(1)

public class Main {
    public static int minFlips(int[][] grid) {
        int row = grid.length;
        int col = grid[0].length;
        int totalOperations = 0;
        int rowLimit = (int) Math.ceil(row / 2.0);
        int colLimit = (int) Math.ceil(col / 2.0);
        int[] data = new int[4];
        
        // Process each cell in the grid
        for (int i = 0; i < rowLimit; i++) {
            for (int j = 0; j < colLimit; j++) {
                int mCol = col - 1 - j;
                int mRow = row - 1 - i;
                data[0] = grid[i][j];
                data[1] = grid[i][mCol];
                data[2] = grid[mRow][j];
                data[3] = grid[mRow][mCol];
                
                int countOnes = 0;
                for (int d : data) {
                    if (d == 1)
                        countOnes++;
                }
                
                if (countOnes == 2)
                    totalOperations += 2;
                else if (countOnes == 1 || countOnes == 3) {
                    totalOperations += 1;
                }
            }
        }
        
        // Handle central row at odd index
        int pairedOnesInRow = 0;
        boolean atleastOneMismatchInRow = false;
        if (row % 2 != 0) {
            int r = rowLimit - 1;
            int i = 0, j = col - 1;
            while (i < j) {
                if (grid[r][i] != grid[r][j]) {
                    totalOperations++;
                    atleastOneMismatchInRow = true;
                } else if (grid[r][i] == 1 && grid[r][j] == 1) {
                    pairedOnesInRow += 2;
                }
                i++;
                j--;
            }
        }
        
        // Handle central column at odd index
        int pairedOnesInCol = 0;
        boolean atleastOneMismatchInCol = false;
        if (col % 2 != 0) {
            int c = colLimit - 1;
            int i = 0, j = row - 1;
            while (i < j) {
                if (grid[i][c] != grid[j][c]) {
                    totalOperations++;
                    atleastOneMismatchInCol = true;
                } else if (grid[i][c] == 1 && grid[j][c] == 1) {
                    pairedOnesInCol += 2;
                }
                i++;
                j--;
            }
        }
        
        // Ensure the number of 1's is divisible by 4
        if ((pairedOnesInRow + pairedOnesInCol) % 4 != 0 && !atleastOneMismatchInCol && !atleastOneMismatchInRow) {
            totalOperations += 2;
        }
        
        // Adjust for the center cell if both row and column lengths are odd
        if ((row % 2 != 0) && (col % 2 != 0)) {
            totalOperations += grid[rowLimit - 1][colLimit - 1] == 1 ? 1 : 0;
        }
        
        return totalOperations;
    }
}

Intuition

Every grid whose number of columns and rows is greater than 2 and even can be split in 4 rectangles (two in the top and two in the bottom). Every cell in the each of those rectangles will always have 3 other symetric cells in the other 3 rectangles.

Approach

Iterate over each cell in the upper left rectangle and make the 4 symetric cells palindromic, while also tracking the number of 1s (after changes to make them palindromic) and number of necessary flips.

If the grid is smaller than 2 x 2, or if the number of rows and/or columns is not even, then we can tackle the middle row and or column separately, also making then palindromic and incrementing number of 1s and flips.

Regarding the requirement to make number of flips a multiple of 4, that only matters if the grid does not have even number of rows and columns, or is less than 2 x 2. And that is exactly why this requiremnt exists, as 4 symetric cells will always have a total number of 1s that is a multiple of 4.

See comments in the code for more detail.

Complexity

  • Time complexity:
    O(n2)

  • Space complexity:
    O(1)

Code

class Solution {

    public int minFlips(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        int flips = 0;
        int ones = 0;
        int middleRow = m / 2;
        int middleColumn = n / 2;

        // In this code block we will address all symmetric 4 cells
        // making them palindromic.
        // The idea is simple, if the grid number of rows and columns is 2
        // or greater, then we can imagine the grid is split in 4 rectangles,
        // two at the top and two at the bootom. Then, all we need to do is
        // iterate over each cell of the upper left rectangle, and, for each
        // cell, there will be 3 other symmetric cells (one in each of the other
        // three rectangles). We then make them all palindromic, count the number
        // of ones (after making them palindromic), and count the number of flips.
        // Notice the number of rows or columns may be odd. If that is true, then
        // the middle row and/or middle column won't be addressed by this code block,
        // but that is fine, as they are addressed after that.
        if (m > 1 && n > 1) {
            for (int i = 0; i < middleRow; i++) {
                for (int j = 0; j < middleColumn; j++) {

                    // These are the coordinates for the 4 symmetric cells
                    int x1 = i;
                    int y1 = j;
                    int x2 = x1;
                    int y2 = n - j - 1;
                    int x3 = m - i - 1;
                    int y3 = y1;
                    int x4 = x3;
                    int y4 = y2;

                    // Number of 1s in those 4 cells
                    int os = 0;
                    os += grid[x1][y1];
                    os += grid[x2][y2];
                    os += grid[x3][y3];
                    os += grid[x4][y4];

                    // They are already palindromic, nothing to be done here.
                    if (os == 0) continue;
                    
                    if (os == 4) {
                        // They are already palindromic, and all 1s, count them and move on.
                        ones+= 4;
                    } else if (os >= 2) {
                        flips += 4 - os;
                        ones+= 4;
                        grid[x1][y1] = 1;
                        grid[x2][y2] = 1;
                        grid[x3][y3] = 1;
                        grid[x4][y4] = 1;
                    } else {
                        flips += os;
                        grid[x1][y1] = 0;
                        grid[x2][y2] = 0;
                        grid[x3][y3] = 0;
                        grid[x4][y4] = 0;
                    }
                }
            }
        }
        
        // We need to track how many flips are going to be made
        // specifically in the middle row or middle column.
        // This will be used later to do adjustments if the total
        // number of ones is not a multiple of 4.
        int middleFlips = 0;

        // Here we will make the middle row palindromic (if number of rows is odd).
        // We will increment ones and flips as needed.
        // Notice these cells have only 1 symmetric cell (set of 3), instead of 3 (set of 4).
        if (m % 2 == 1) {
            int start = 0;
            int end = n - 1;
            while (start < end) {
                if (grid[middleRow][start] != grid[middleRow][end]) {
                    grid[middleRow][start] = 1;
                    grid[middleRow][end] = 1;
                    ones += 2;
                    flips++;
                    middleFlips++;
                } else if (grid[middleRow][start] == 1) {
                    ones += 2;
                }
                start++;
                end--;
            }
        }

        // Here we will make the middle column palindromic (if number of columns is odd).
        // We will increment ones and flips as needed.
        // Notice these cells have only 1 symmetric cell (set of 3), instead of 3 (set of 4).
        if (n % 2 == 1) {
            int start = 0;
            int end = m - 1;
            while (start < end) {
                if (grid[start][middleColumn] != grid[end][middleColumn]) {
                    grid[start][middleColumn] = 1;
                    grid[end][middleColumn] = 1;
                    ones += 2;
                    flips++;
                    middleFlips++;
                } else if (grid[start][middleColumn] == 1) {
                    ones += 2;
                }
                start++;
                end--;
            }
        }

        // This is the center cell, which will exist only if number of rows and columns are odd.
        // The previous logic did not read it to account for the number of ones, so here we do that.
        // Notice its value really doesn't matter, it won't have an effect on whether the grid is palindromic or not,
        // as it has 0 symmetric cells.
        if (m % 2 == 1 && n % 2 == 1 && grid[middleRow][middleColumn] == 1) ones++;

        // If r is 0 then we simply return the number of flips.
        // Otherwise, then we will have do some extra flips in the grid in special
        // cells that easily allow that. They are:
        //   - The center cell (if number of rows and columns are odd).
        //     Its value can be 1 or 0, that won't change wether the whole grid is palindromic or not.
        //   - The middle row and middle column cells (in case of odd number of rows or cells).
        //     We can change then in numbers of 2s because addind 2 or subtracting 2 from a middle row
        //     will not "damage" columns. Addind 2 or subtracting 2 from a middle column will also not "damage" columns.
        int r = ones % 4;

        // If the condition below is true, then that means for sure the central cell exists and it is set to 1.
        // We can then easily set it to 0 (and increment the number of flips) to help to make the total number of
        // flips a multiple of 4.
        if (r == 1 || r == 3) {
            grid[middleRow][middleColumn] = 0;
            flips++;
        }
        // If the condition below is true, then it means for sure there is a middle row or column, and one of
        // its pair of symmetric cells can be changed. Notice though we need first to check if we have already
        // done flips in them. Because if we have, then it would be just a matter of setting then to 0 instead of 1
        // (notice the middle row and logic arbitrarily sets the value to 1 when they differ).
        if ((r == 2 || r == 3) && middleFlips == 0) {
            flips += 2;
        }
        return flips;
    }

}

        int flips = 0, totalOnes = 0, diff = 0;
        int rows = grid.length, cols = grid[0].length;

        for (int i = 0; i < rows / 2; ++i) {
            for (int j = 0; j < cols / 2; ++j) {

                flips += Math.min(onesCount, 4 - onesCount);
            }

        if (cols % 2 > 0) {
            for (int i = 0; i < rows / 2; ++i) {
                // Check if the cells are different
                if (grid[i][cols / 2] != grid[rows - 1 - i][cols / 2]) {
                    diff++;
                }
                totalOnes += grid[i][cols / 2] + grid[rows - 1 - i][cols / 2];
            }

        if (rows % 2 > 0) {
            for (int j = 0; j < cols / 2; ++j) {
                // Check if the cells are different

                    diff++;
                }
                totalOnes += grid[rows / 2][j] + grid[rows / 2][cols - 1 - j];
            }
        }

        if (cols % 2 > 0 && rows % 2 > 0) {

class Solution {
    public int minFlips(int[][] grid) {
        int n = grid.length, m = grid[0].length;
        int res = 0;
        // all row pairs and col pairs
        for (int i = 0; i < n / 2; i++)
            for (int j = 0; j < m / 2; j++) {
                int cnt = grid[i][j] + grid[i][m - 1 - j] + grid[n - 1 - i][j] + grid[n - 1 - i][m - 1 - j];
                res += Math.min(cnt, 4 - cnt);
            }
        // center row
        int cnt = 0, cnt1 = 0;
        if (n % 2 == 1)
            for (int i = 0; i < m / 2; i++) {
                cnt += grid[n / 2][i] == grid[n / 2][m - 1 - i] ? 0 : 1;
                cnt1 += grid[n / 2][i] == grid[n / 2][m - 1 - i] && grid[n / 2][i] == 1 ? 1 : 0;
            }
        // center col
        if (m % 2 == 1)
            for (int i = 0; i < n / 2; i++) {
                cnt += grid[i][m / 2] == grid[n - 1 - i][m / 2] ? 0 : 1;
                cnt1 += grid[i][m / 2] == grid[n - 1 - i][m / 2] && grid[i][m / 2] == 1 ? 1 : 0;
            }
        res += cnt;
        res += cnt > 0 ? 0 : (cnt1 % 2) * 2;
        // center/center grid
        if (m % 2 == 1 && n % 2 == 1 && grid[n / 2][m / 2] == 1)
            res++;
        return res;
    }
}
