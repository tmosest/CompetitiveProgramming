Approach

  1. Initialization of Variables :
  • ans: This variable is initialized to zero and will hold the count of valid substrings that meet the criteria specified.
  • The outer loop iterates through each character of the string s, setting up the starting point of a substring at index i.
  1. Outer Loop (i) :
  • This loop runs from 0 to s.size() - 1. Each iteration represents a new starting point for the substring.
  • At the beginning of each iteration, we reset the vowel counters (a, e, m, o, u) and the consonant counter (c) to zero.
  1. Inner Loop (j) :
  • The inner loop starts at the current index i and extends to the end of the string, thus examining all possible substrings that begin with the character at index i.
  • Each iteration of this inner loop examines the character at index j.
  1. Character Classification :
  • The inner loop contains a series of conditional statements that check the current character s[j]:
  • If s[j] is a vowel ('a', 'e', 'i', 'o', or 'u'), the corresponding counter (a, e, m, o, or u) is incremented.
  • If s[j] is not a vowel (i.e., it is a consonant), the consonant counter (c) is incremented.
  1. Condition Check :
  • After updating the counters for each character added to the current substring, the code checks whether all five vowel counters (a, e, m, o, u) are greater than 0 (indicating that each vowel has been encountered at least once).
  • It also checks if the consonant counter (c) is equal to k.
  • If both conditions are satisfied, it increments the ans counter by 1, indicating that a valid substring has been found.
  1. Completing the Process :
  • The outer loop continues, and for each starting point i, the inner loop explores all possible substrings starting from that point.
  • By the time both loops finish executing, ans contains the total count of valid substrings.
  1. Return Statement :
  • Finally, the function returns the value of ans, which represents the number of substrings that meet the specified criteria.

}

Approach

  • Two-Pointer and Sliding Window Technique: Use two pointers, l_left and l_right, to create a sliding window that maintains the number of consonants and checks if all vowels are present.
  • Dictionary for Vowel Count: Maintain a dictionary map to count the number of each vowel in the current window.
  • Count Consonants: Keep track of the number of consonants in the window using the variable cons_count.
  • Move r Pointer to Expand the Window: As we move the r pointer to the right, add vowels to the map and increment cons_count for consonants.
  • Adjust Window Using l_right: When the number of consonants exceeds k, move l_right to the right until cons_count is equal to k again at this point it is stored in l_left (because its actually l_left). Now extra vowels at the left end are removed from map l_right is moved further.
  • Check Valid Substring: Once cons_count == k and all vowels are present (len(map) == 5), add the number of valid substrings between l_left and l_right to the result.
  • Output the Final Count: The final answer will be the number of such valid substrings found.

class Solution:
    def countOfSubstrings(self, w: str, k: int) -> int:
        n = len(w)
        cons_count = 0 # count of constants
        ans = 0

        vowels = ("a", "e", "i", "o", "u")
        map = defaultdict(int)

        l_right = 0
        l_left = 0
        for r in range(n):
           
            if w[r] in vowels:
                map[w[r]] += 1
            else:
                cons_count += 1

            while cons_count > k and l_right < r:# lets make cons_count ==k
                if w[l_right] in vowels:
                    map[w[l_right]] -= 1
                    if map[w[l_right]] == 0:
                        del map[w[l_right]]

                else:
                    cons_count -= 1
                l_right += 1
                l_left = l_right # l_left is extreme left at which cons_count==k

            # even if cons_count==k , some vowels at left side can be removed 
            # l_right is extreme right at which cons_count==k 
            while cons_count == k and l_right < r:
                if w[l_right] in vowels:
                    if map[w[l_right]] - 1 > 0:
                        map[w[l_right]] -= 1
                        l_right += 1
                    else:
                        break
                else:
                    break

            if len(map) == 5 and cons_count == k:
                ans += (l_right - l_left + 1)  # number sub strings between l_right , l_left

        return ans

Here's the plan:

  1. We map characters in word to integers; s: vowels aeiou are mapped to 0, 1, 2, 3, 4 respectively and consonants are mapped to 5.

  2. We use two pointers, left and rght, to iterate this integer list the string while maintaining the count of characters in char_cnt, which keeps track of the count of vowels and consonants in the current window.

  3. We shrink the window by moving the left pointer and adjusting the counts whenever the number of non-vowels exceeds k.

  4. Once the number of non-vowels equals k, we check whether the current window contains at least one of each vowel.

  5. For every valid window (with exactly k consonants and each vowel present), we increment ans by the number of valid substrings starting from the start position to left.

class Solution:
    def countOfSubstrings(self, word: str, k: int) -> int:
        
        n, start, left, ans = len(word), 0, 0, 0
        word = list(map(lambda x: 'aeiou'.index(x)          # <--1)
                            if x in 'aeiou' else 5, word))

        char_cnt = [0, 0, 0, 0, 0, 0]
        
        for rght in range(n):                               # <--2) 
            char_cnt[word[rght]]+= 1

            while left < rght and char_cnt[5] > k:          # <--3) 
                idx = word[left]
                char_cnt[idx] -= 1
                left += 1
                start = left

            while char_cnt[5] == k and left < rght:         # <--4)
                iidx = word[left]
                if idx < 5:
                    if char_cnt[idx] > 1:
                        char_cnt[idx]-= 1
                        left += 1
                    else: break
                else: break

            if char_cnt[5] == k and min(char_cnt[:5]) > 0:  # <--5)
                ans += (left - start + 1)

        return ans

Intuition

The sliding window technique is well-suited for problems where we need to manage substrings. The key here is to maintain a window where the number of consonants does not exceed a given limit k, while ensuring that all 5 vowels are present in the substring.

Approach

We expand the window by adding one character at a time and shrink it whenever the number of consonants exceeds the limit k. Additionally, we shrink the window further if the number of vowels still satisfies the condition of having all 5 vowels, counting the valid substrings along the way.

Complexity

  • Time complexity:
    The time complexity is O(n) where n is the length of the input string, since each character is processed at most twice (once when expanding the window and once when shrinking it).

  • Space complexity:
    The space complexity is O(1) because we only need a few fixed variables and a small set for the vowels.

class Solution:
    def countOfSubstrings(self, word: str, k: int) -> int:
        v=set("aeiou")
        vs=defaultdict(int)

        l=0

        ans=0

        # if n<5+k:return 0
        for r in range(n):
            if word[r] in v:
                vs[word[r]]+=1
            else:cc+=1

            while cc>k:
                if word[l] in vs :
                    vs[word[l]]-=1
                    if vs[word[l]]==0:del vs[word[l]]
                else:cc-=1
                l+=1
            if len(vs)==5 and cc==k:
                ans+=1
                lf=l
                vs2=vs.copy()
                cc2=cc
                while len(vs2)==5:
                    if word[lf] in vs2 :

                    else:cc2-=1
                    lf+=1
                    if cc2==k and len(vs2)==5:ans+=1
                    if cc<k:break
        return ans

#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int countOfSubstrings(string word, int k) {
        unordered_set<char> vowels = {'a', 'e', 'i', 'o', 'u'};
        unordered_map<char, int> vowelCount;
        int consonantCount = 0, l = 0, n = word.length(), ans = 0;

        for (int r = 0; r < n; r++) {
            if (vowels.count(word[r])) {
                vowelCount[word[r]]++;
            } else {
                consonantCount++;
            }

            while (consonantCount > k) {
                if (vowelCount.count(word[l])) {
                    vowelCount[word[l]]--;
                    if (vowelCount[word[l]] == 0) vowelCount.erase(word[l]);
                } else {
                    consonantCount--;
                }
                l++;
            }

            if (vowelCount.size() == 5 && consonantCount == k) {
                ans++;
                int lf = l;
                auto vowelCountCopy = vowelCount;
                int consonantCountCopy = consonantCount;

                while (vowelCountCopy.size() == 5) {
                    if (vowelCountCopy.count(word[lf])) {
                        vowelCountCopy[word[lf]]--;
                        if (vowelCountCopy[word[lf]] == 0) vowelCountCopy.erase(word[lf]);
                    } else {
                        consonantCountCopy--;
                    }
                    lf++;
                    if (consonantCountCopy == k && vowelCountCopy.size() == 5) ans++;
                    if (consonantCountCopy < k) break;
                }
            }
        }

        return ans;
    }
};

import java.util.HashMap;
import java.util.HashSet;

class Solution {
    public int countOfSubstrings(String word, int k) {
        HashSet<Character> vowels = new HashSet<>();
        vowels.add('a');
        vowels.add('e');
        vowels.add('i');
        vowels.add('o');
        vowels.add('u');

        HashMap<Character, Integer> vowelCount = new HashMap<>();
        int consonantCount = 0, l = 0, n = word.length(), ans = 0;

        for (int r = 0; r < n; r++) {
            if (vowels.contains(word.charAt(r))) {
                vowelCount.put(word.charAt(r), vowelCount.getOrDefault(word.charAt(r), 0) + 1);
            } else {
                consonantCount++;
            }

            while (consonantCount > k) {
                if (vowelCount.containsKey(word.charAt(l))) {
                    vowelCount.put(word.charAt(l), vowelCount.get(word.charAt(l)) - 1);
                    if (vowelCount.get(word.charAt(l)) == 0) {
                        vowelCount.remove(word.charAt(l));
                    }
                } else {
                    consonantCount--;
                }
                l++;
            }

            if (vowelCount.size() == 5 && consonantCount == k) {
                ans++;
                int lf = l;
                HashMap<Character, Integer> vowelCountCopy = new HashMap<>(vowelCount);
                int consonantCountCopy = consonantCount;

                while (vowelCountCopy.size() == 5) {
                    if (vowelCountCopy.containsKey(word.charAt(lf))) {
                        vowelCountCopy.put(word.charAt(lf), vowelCountCopy.get(word.charAt(lf)) - 1);
                        if (vowelCountCopy.get(word.charAt(lf)) == 0) {
                            vowelCountCopy.remove(word.charAt(lf));
                        }
                    } else {
                        consonantCountCopy--;
                    }
                    lf++;
                    if (consonantCountCopy == k && vowelCountCopy.size() == 5) ans++;
                    if (consonantCountCopy < k) break;
                }
            }
        }

        return ans;
    }
}

Time Complexity: O(n^2)

In this approach, the outer loop iterates through each starting index, while the inner loop expands the substring. Each time the inner loop runs, it examines characters from the starting index to the end, leading to a quadratic number of operations.

Space Complexity: O(1)

The space used is constant for the fixed-size set of vowels.

Code

class Solution {
    public int countOfSubstrings(String word, int k) {
        int n = word.length();
        int totalCount = 0;

        HashSet<Character> vowelsSet = new HashSet<>();
        vowelsSet.add('a');
        vowelsSet.add('e');
        vowelsSet.add('i');
        vowelsSet.add('o');
        vowelsSet.add('u');

        for (int start = 0; start < n; start++) {
            HashSet<Character> vowelsInWindow = new HashSet<>();
            int consonantCount = 0;

            for (int end = start; end < n; end++) {
                char c = word.charAt(end);
                
                if (vowelsSet.contains(c)) {
                    vowelsInWindow.add(c);
                } else if (Character.isLetter(c)) {
                    consonantCount++;
                }
                
                if (vowelsInWindow.size() == 5 && consonantCount == k) {
                    totalCount++;
                }

                if (consonantCount > k) {
                    break;
                }
            }
        }
        
        return totalCount;
    }
}
