Intuition

The problem asks for the lexicographically smallest string after performing certain removal operations. This suggests exploring different removal possibilities and comparing the resulting strings. Since the operations can interact and the goal is optimal, dynamic programming seems like a suitable approach to break the problem down into smaller, overlapping subproblems: finding the smallest string for every possible substring.

Approach

We define dp[i][j] as the lexicographically smallest string obtainable from the substring s[i...j-1]. We iterate through all possible substring lengths, and for each substring, we consider two main options. First, we can keep the character s[i] and append it to the optimal result for the rest of the substring s[i+1...j-1] (which is dp[i+1][j]). Second, we can try to remove s[i] by pairing it with some s[k] (where i < k < j) if they are consecutive and the substring s[i+1...k-1] can be entirely removed (i.e., dp[i+1][k] is empty). If such a removal is possible, the result is the optimal string from s[k+1...j-1] (which is dp[k+1][j]). We take the lexicographically smaller result from these options and store it in dp[i][j]. The final answer is dp[0][n].

Complexity

  • Time complexity:
    The time complexity is O(N3áL), where N is the length of the string s, and L is the average length of strings being compared or concatenated (which can be up to N). There are O(N2) states in the DP table. Each state dp[i][j] involves an outer loop for k which runs up to N times. Inside this loop, string concatenations and comparisons occur. In the worst case, string operations can take O(N) time. A more precise analysis might consider the string operations more carefully, but a cubic dependency on N for the loops is clear, with string operations adding another factor. If string comparisons and concatenations are considered O(N), it leads to O(N4). However, if we consider the sum of lengths of strings involved, it's often closer to O(N3) for this type of DP structure when string results are built. The provided solution's structure with an explicit inner loop for k suggests at least O(N3) iterations, and each involves string operations.

  • Space complexity:
    The space complexity is O(N2áL), where N is the length of the string s, and L is the average length of strings stored in the DP table. The DP table dp has N2 entries, and each entry stores a string that can be up to N characters long.

class Solution {
    private boolean isConsec(char a, char b) {
        int diff = Math.abs(a - b);
        return diff == 1 || diff == 25;
    }
    public String lexicographicallySmallestString(String s) {
        int n = s.length();
        String[][] dp = new String[n + 1][n + 1];
        for (int i = 0; i <= n; i++) {
            for (int j = 0; j <= n; j++) {
                dp[i][j] = "";
            }
        }
        for (int len = 1; len <= n; len++) {
            for (int i = 0; i + len <= n; i++) {
                int j = i + len;
                String res = s.charAt(i) + dp[i + 1][j];
                for (int k = i + 1; k < j; k++) {
                    if (isConsec(s.charAt(i), s.charAt(k)) && dp[i + 1][k].equals("")) {
                        if (dp[k + 1][j].compareTo(res) < 0) {
                            res = dp[k + 1][j];
                        }
                    }
                }
                dp[i][j] = res;
            }
        }
        return dp[0][n];
    }
}

class Solution {
    /**
     * Checks if two characters are consecutive in the alphabet, considering circularity (e.g., 'a' and 'z').
     *
     * @param a The first character.
     * @param b The second character.
     * @return true if the characters are consecutive, false otherwise.
     */
    private boolean isConsec(char a, char b) {
        // Calculate the absolute difference in ASCII values.
        int diff = Math.abs(a - b);
        // Consecutive if difference is 1 (e.g., 'a', 'b') or 25 (e.g., 'a', 'z' in a 26-letter alphabet).
        return diff == 1 || diff == 25;
    }

    /**
     * Finds the lexicographically smallest string that can be obtained by repeatedly removing
     * adjacent characters that are consecutive in the alphabet (circularly).
     *
     * @param s The input string consisting of lowercase English letters.
     * @return The lexicographically smallest string after optimal removals.
     */
    public String lexicographicallySmallestString(String s) {
        int n = s.length();
        // dp[i][j] will store the lexicographically smallest string that can be formed
        // from the substring s[i...j-1] (inclusive of i, exclusive of j).
        String[][] dp = new String[n + 1][n + 1];

        // Initialize the dp table. An empty string is a valid state if a substring can be entirely removed.
        // It also serves as a base for comparisons, as any non-empty string is lexicographically larger.
        for (int i = 0; i <= n; i++) {
            for (int j = 0; j <= n; j++) {
                // dp[i][i] (substring of length 0) will naturally be "",
                // which is correct as an empty substring results in an empty string.
                dp[i][j] = "";
            }
        }

        // Iterate over substring lengths, from 1 to n.
        for (int len = 1; len <= n; len++) {
            // Iterate over all possible starting indices 'i' for substrings of current 'len'.
            for (int i = 0; i + len <= n; i++) {
                int j = i + len; // 'j' is the exclusive end index of the substring s[i...j-1].

                // Option 1: Keep the first character s.charAt(i).
                // The result would be s.charAt(i) concatenated with the smallest string
                // obtainable from the rest of the substring s[i+1...j-1].
                // dp[i+1][j] already stores the optimal result for s[i+1...j-1].
                String res = s.charAt(i) + dp[i + 1][j];

                // Option 2: Try to remove s.charAt(i) with some s.charAt(k) where i < k < j.
                // This is possible if s.charAt(i) and s.charAt(k) are consecutive, AND
                // the entire substring between them (s[i+1...k-1]) can be completely removed.
                for (int k = i + 1; k < j; k++) {
                    // Check if s[i] and s[k] are consecutive.
                    // Check if the substring s[i+1...k-1] (represented by dp[i+1][k]) can be entirely removed.
                    // If dp[i+1][k] is an empty string, it means s[i+1...k-1] can be cleared,
                    // making s[i] and s[k] effectively adjacent for a potential removal.
                    if (isConsec(s.charAt(i), s.charAt(k)) && dp[i + 1][k].equals("")) {
                        // If s[i] and s[k] (and the part between them) are removed,
                        // the resulting string is the optimal string from s[k+1...j-1], which is dp[k+1][j].
                        // We compare this potential result with the current best 'res'.
                        if (dp[k + 1][j].compareTo(res) < 0) {
                            res = dp[k + 1][j];
                        }
                    }
                }
                // Store the lexicographically smallest result found for the substring s[i...j-1].
                dp[i][j] = res;
            }
        }

        // The final answer is the smallest string obtainable from the entire input string s[0...n-1].
        return dp[0][n];
    }
}

class Solution {
    public String lexicographicallySmallestString(String s) {
        int n = s.length();
        StringBuilder[][] dp = new StringBuilder[n][n];

        return findSmallestString(0, n-1, s, dp).toString();
    }

    private StringBuilder findSmallestString(int l, int r, String s, StringBuilder[][] dp) {
        if (l == r){
            new StringBuilder().append(s.charAt(l));
        }
        if (l > r){
            return new StringBuilder();
        }
        if (dp[l][r] != null){
            return dp[l][r];
        }
        StringBuilder result = new StringBuilder().append(s.charAt(l));
        result.append(findSmallestString(l+1, r, s, dp));
        char ch1 = s.charAt(l);
        for(int j=l+1; j<= r; j++){
            char ch2 = s.charAt(j);
            boolean condition = ((ch1-'a')-(ch2-'a')+26)%26 == 1 || ((ch1-'a')-(ch2-'a')+26)%26 == 25;
            if (condition && findSmallestString(l+1, j-1, s, dp).length() == 0){
                StringBuilder temp = findSmallestString(j+1, r, s, dp);
                if (temp.compareTo(result) < 0){
                    result = temp;
                }
            }
        }
        return dp[l][r] = result;
    }
}
