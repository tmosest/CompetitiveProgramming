We do not care about the order (it's already strictly increasing), so we can just count numbers in each array. Numbers that appear n times present in all n arrays, and therefore should be included into the result.

Python 3

class Solution:
    def longestCommomSubsequence(self, arrs: List[List[int]]) -> List[int]:
        return [n for (n, cnt) in Counter(n for arr in arrs for n in arr).items() if cnt == len(arrs)]

Java

public List<Integer> longestCommomSubsequence(int[][] arrays) {
    int cnt[] = new int[101];
    for (var arr : arrays)
        for (var n : arr)
            ++cnt[n];
    return IntStream.range(0, 101).filter(i -> cnt[i] == arrays.length).boxed().collect(Collectors.toList());
}

C++

vector<int> longestCommomSubsequence(vector<vector<int>>& arrays) {
    vector<int> cnt(101), res;
    for (auto &arr : arrays)
        for (int n : arr)
            if (++cnt[n] == arrays.size())
                res.push_back(n);
    return res;
}

Follow-up Solution

What if we can have duplicates? We would use a hash map to track the count of each element. Or, we could use a two pointers approach to find common elements between pairs of arrays.

The set_intersection function, under the hood, uses two pointers.
C++

vector<int> longestCommomSubsequence(vector<vector<int>>& a) {
    for (int i = 1; i < a.size(); ++i)
        a[0].erase(set_intersection(begin(a[0]), end(a[0]),
                begin(a[i]), end(a[i]), begin(a[0])), end(a[0]));
    return a[0];
}

The idea is to use divide and conquery to find common subsequences between each pair.. Why does this work? Since we have sorted arrays, we can only have 1 longest-common-subsequence.

Also does anyone notice the typo longestCommomSubsequence :)

public List<Integer> longestCommomSubsequence(int[][] arrays) {
        return helper(arrays, 0, arrays.length-1);
    }
    
    private List<Integer> helper(int[][] arrays, int st, int end) {
        List<Integer> res = new ArrayList();
        if (st>end) return res;
        if (st==end) {
            int[] list = arrays[st];
            for (int num: list) {
                res.add(num);
            }
            return res;
        }
        int mid = st + (end-st)/2;
        return merge(helper(arrays, st, mid), helper(arrays, mid+1, end));
    }
    
    private List<Integer> merge(List<Integer> l1, List<Integer> l2) {
        List<Integer> res = new ArrayList();
        int p1 = 0, p2 = 0;
        while (p1<l1.size() && p2<l2.size()) {
            if (l1.get(p1)<l2.get(p2)) {
                p1++;
            } else if (l1.get(p1) > l2.get(p2)) {
                p2++;
            } else {
                res.add(l1.get(p1));
                p1++;
                p2++;
            }
        }
        return res;
    }

Time Complexity : O(M*logN) where M is the max length of an individual array and N is the length of the input.

import java.util.ArrayList;
import java.util.List;

public class Solution {

    private static final int[] RANGE_OF_VALUES = {1, 100};

    public List<Integer> longestCommonSubsequence(int[][] arrays) {
        int[] frequency = new int[RANGE_OF_VALUES[1] + 1];
        List<Integer> longestCommonSubsequence = new ArrayList<>();

        for (int[] numbers : arrays) {
            for (int value : numbers) {
                ++frequency[value];
            }
        }

        for (int value = RANGE_OF_VALUES[0]; value <= RANGE_OF_VALUES[1]; value++) {
            if (frequency[value] == arrays.length) {
                longestCommonSubsequence.add(value);
            }
        }

        return longestCommonSubsequence;
    }
}
