C++ Solution

class Solution {
public:
    int countCollisions(string dir) {
        
        int res(0), n(size(dir)), i(0), carsFromRight(0);
        
        while (i < n and dir[i] == 'L') i++; // skipping all the cars going to left from beginning as they will never collide
        
        for ( ; i<n; i++) {
            if (dir[i] == 'R')  carsFromRight++;
            else {
                // if dir[i] == 'S' then there will be carsFromRight number of collission
                // if dir[i] == 'L' then there will be carsFromRight+1 number of collision (one collision for the rightmost cars and carsFromRight collision for the cars coming from left)
                res += (dir[i] == 'S') ? carsFromRight : carsFromRight+1;
                carsFromRight = 0;
            }
        }
        return res;
    }
};

/*
In the case LLRR : there will be no collisions since two cars are moving towards Left and two cars moving towards right
<- <- -> ->
 L  L  R  R 

In the case RRRRLL : 
->  ->  -> ->  <- <- 
R    R   R  R  L  L 
0    1   2  3  4  5

 Cars 3 and 4 collide and become stationary (S), since cars 0, 1, 2 are moving towards this stationary car so they will all 
 collide and cars 4 and 5 are moving towards the same stationary card from the left direction so even they will collide and 
 become stationary (S). We will store cars 0,1,2, 3 in stack and when current car is driving towards left we pop 3 and change 
 the current car’s state to stationary and pop rest of the cars driving towards it from the right direction and calculate the 
 collision value. 

In the case RSLRL: 

-> |  <-  -> <-
R  S  L    R  L 
0  1  2    3  4

Car 0 collides with the stationary car 1, car 2 collides with the stationary car 1 and cars 3 and 4 collide with each other. 

*/
    public int countCollisions(String directions) {
        
        int collisions = 0;
        Stack<Character> stack = new Stack();
        stack.push(directions.charAt(0));
        for(int i = 1;i<directions.length();i++){
            char curr = directions.charAt(i);
      
            if((stack.peek()== 'R' && curr == 'L')  ){
                
                collisions+=2;
                stack.pop();
                curr = 'S';
     

            }else if((stack.peek() == 'S' && curr == 'L')){
                curr = 'S';
                collisions+=1;
            }
        
            while(!stack.isEmpty() && ((stack.peek() == 'R' && curr == 'S') )){
                collisions+=1;
              stack.pop();
            }
            
            stack.push(curr);
        }
        
        return collisions;
    }

Intuition

The cars that cannot collide are:

Cars moving left ('L') at the beginning

Cars moving right ('R') at the end

These cars will never meet any other car. All other cars either move into each other or into stationary cars, which causes a collision.

Approach

Ignore all initial 'L' characters from the start (these can't collide).

Ignore all ending 'R' characters from the end (these also can't collide).

Between these positions, count all 'L' and 'R' characters (they will eventually collide into someone).

'S' characters stay in place and cause others to crash into them.

Complexity

Time Complexity:
O(n) — One pass from both ends and a linear scan in between.

Space Complexity:
O(1) — Constant extra space used.

class Solution {
public:
    int countCollisions(string directions) {
        int i=0,count=0;
        while(i<directions.length()&&directions[i]=='L'){
            i++;
        }
        int j=directions.length()-1;
        while(j>=0&&directions[j]=='R'){
            j--;
        }
        for(int k=i;k<=j;k++){
            if(directions[k]=='L'||directions[k]=='R'){
                count++;
            }
        }
        return count;
    }
};
