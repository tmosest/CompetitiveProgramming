? Maximum Profit with At Most K Transactions (Including Short Selling)

? Problem Statement

  • Input: Integer array prices[], where prices[i] is the stock price on day i, and integer k.

  • Goal: Make at most k transactions, where a transaction is either:

    • Normal: Buy on day i, sell on day j (i < j) ? profit prices[j] - prices[i].
    • Short Sell: Sell on day i, buy back on day j (i < j) ? profit prices[i] - prices[j].

  • Constraints: Must complete one transaction before starting another; no simultaneous buy/sell on same day.

  • Output: Maximum total profit.

?? Solution Approach

We use a 3D DP with memoization (top-down).

  1. State Definition: dp[i][t][s] = maximum profit from day i with t transactions remaining and state s:

    • s = 0 ? No position (free to buy or short-sell).
    • s = 1 ? Holding long (we have bought and waiting to sell).
    • s = 2 ? Holding short (we have sold first, waiting to buy back).

  2. Transitions:

    • If s = 0 (flat):

      • Buy long: -prices[i] + solve(i+1, t, 1)
      • Short sell: +prices[i] + solve(i+1, t, 2)
      • Skip: solve(i+1, t, 0)

    • If s = 1 (long):

      • Sell: +prices[i] + solve(i+1, t-1, 0)
      • Hold: solve(i+1, t, 1)

    • If s = 2 (short):

      • Buy back: -prices[i] + solve(i+1, t-1, 0)
      • Hold: solve(i+1, t, 2)

  3. Memoization:

    • Use a 3D array Long dp[n][k+1][3] to store intermediate results and avoid recomputation.

  4. Base Case:

    • If i == n (past last day):

      • If s == 0 ? 0 profit; else -∞ (invalid).

? Code for reference

Java
class Solution {
   static public long maximumProfit(int[] prices, int k) {
        long ans = 0;
        int n = prices.length;
        Long[][][] dp = new Long[n][k + 1][3];
        long res = solve(0, k, 0, n, prices, dp);
        return res;
    }

    static long solve(int i, int k, int decider, int n, int[] prices, Long[][][] dp) {
        if (i == n) {
            if (k >= 0 && decider == 0)
                return 0;
            return Integer.MIN_VALUE;
        }

        if (dp[i][k][decider] != null) {
            return dp[i][k][decider];
        }

        long take = Integer.MIN_VALUE, dontTake = Integer.MIN_VALUE;
        if (k > 0) {
            if (decider == 1) { 
                take = prices[i] + solve(i + 1, k - 1, 0, n, prices, dp);
            } else if (decider == 2) { 
                take = -prices[i] + solve(i + 1, k - 1, 0, n, prices, dp);
            } else {
                take = Math.max(prices[i] + solve(i + 1, k, 2, n, prices, dp),
                        -prices[i] + solve(i + 1, k, 1, n, prices, dp));
            }
        }

        dontTake = solve(i + 1, k, decider, n, prices, dp);
        return dp[i][k][decider] = Math.max(take, dontTake);
    }
}

? Time & Space Complexity

  • Time: O(n * k * 3) states * O(1) transition = O(nk).
  • Space: O(n * k * 3) for DP + recursion stack = O(nk).

? Step 1: 3D Tabulation DP (No Space Optimization)

class Solution {
    public static long maximumProfit(int[] prices, int k) {
        int n = prices.length;
        long[][][] dp = new long[n + 1][k + 1][3];

        for (int K = 0; K <= k; K++) {
            dp[n][K][0] = 0; 
            dp[n][K][1] = Integer.MIN_VALUE;
            dp[n][K][2] = Integer.MIN_VALUE;
        }

        for (int i = n - 1; i >= 0; i--) {
            for (int K = 0; K <= k; K++) {
                for (int decider = 0; decider < 3; decider++) {
                    long take = Integer.MIN_VALUE;
                    long dontTake = dp[i + 1][K][decider];

                    if (K > 0) {
                        if (decider == 1) {
                            take = prices[i] + dp[i + 1][K - 1][0];
                        } else if (decider == 2) {
                            take = -prices[i] + dp[i + 1][K - 1][0];
                        } else {
                            take = Math.max(
                                prices[i] + dp[i + 1][K][2],
                                -prices[i] + dp[i + 1][K][1]
                            );
                        }
                    }

                    dp[i][K][decider] = Math.max(take, dontTake);
                }
            }
        }

        return dp[0][k][0];
    }
}

? Step 2: Space Optimized (from 3D to 2D)

You’ll notice we only access dp[i + 1] to fill dp[i]. So we can keep only 2 layers, reducing space from O(n * k * 3) to O(2 * k * 3) => O(k) space complexity.

Java
class Solution {
    public static long maximumProfit(int[] prices, int k) {
        int n = prices.length;
        long[][] curr = new long[k + 1][3];
        long[][] next = new long[k + 1][3];

        for (int K = 0; K <= k; K++) {
            next[K][0] = 0;
            next[K][1] = Integer.MIN_VALUE;
            next[K][2] = Integer.MIN_VALUE;
        }

        for (int i = n - 1; i >= 0; i--) {
            for (int K = 0; K <= k; K++) {
                for (int decider = 0; decider < 3; decider++) {
                    long take = Integer.MIN_VALUE;
                    long dontTake = next[K][decider];

                    if (K > 0) {
                        if (decider == 1) {
                            take = prices[i] + next[K - 1][0];
                        } else if (decider == 2) {
                            take = -prices[i] + next[K - 1][0];
                        } else {
                            take = Math.max(
                                prices[i] + next[K][2],
                                -prices[i] + next[K][1]
                            );
                        }
                    }

                    curr[K][decider] = Math.max(take, dontTake);
                }
            }

            long[][] temp = next;
            next = curr;
            curr = temp;
        }

        return next[k][0];
    }
}

class Solution {
public:
    vector<int> prices;
    long long mn = -1e14;
    vector<vector<vector<long long>>> dp;
    long long f(int i, int k, int state){
        if(i == prices.size()){
            return state == 0 ? 0 : mn;
        }
        if(dp[i][k][state] != mn) return dp[i][k][state];

        long long p = prices[i];
        long long profit = mn;
        // 1) do nothing today
        profit = max(profit, f(i + 1, k, state));

        // 2) If neither sold nor bought earlier
        if(state == 0){
            // start 2 type of transaction
            // a) buy, losing p
            profit = max(profit, f(i+1, k, 1) - p);
            // b) sell, gaining p
            profit = max(profit, f(i+1, k, 2) + p);
        }
        else if(k > 0){ // have transactions left
            // complete 1 transaction
            if(state == 1){
                // already bought then sell incurring profit of p
                profit = max(profit, f(i+1, k-1, 0) + p);
                
            }
            else{
                // already sold then buy incurring loss of p
                 profit = max(profit, f(i+1, k-1, 0) - p);
            }
        }
        return dp[i][k][state] = profit;
    }
    
    long long maximumProfit(vector<int>& prices, int k) {
        this->prices = prices;
        dp.assign(prices.size() + 1, vector<vector<long long>> (k + 1, vector<long long> (3, mn)));
        return f(0, k, 0);  
    }
};

class Solution {
public:
    long long maximumProfit(vector<int>& prices, int _k) {
        int n = prices.size();
        long long mn = -1e14;
        vector<vector<vector<long long>>> dp(n + 1, vector<vector<long long>> (_k + 1, vector<long long> (3, mn)));

        // Base case: at day n, only state 0 is valid (free, no holdings)
        for(int k = 0; k <= _k; k++){
            dp[n][k][0] = 0;
        }
        for(int i = n-1; i >= 0; i--){
            for(int k = 0; k <= _k; k++){
                // State 0: do nothing, or start new buy/sell
                dp[i][k][0] = dp[i + 1][k][0];
                dp[i][k][0] = max(dp[i][k][0], dp[i + 1][k][1] - prices[i]); // start a buy
                dp[i][k][0] = max(dp[i][k][0], dp[i + 1][k][2] + prices[i]); // start a sell
                // States 1 and 2: carry forward
                dp[i][k][1] = dp[i + 1][k][1]; 
                dp[i][k][2] = dp[i + 1][k][2];
                if(k > 0){ // transactions left
                    // State 1: currently holding after buy, try max(not selling, selling)
                    dp[i][k][1] = max(dp[i + 1][k][1], dp[i + 1][k - 1][0] + prices[i]);
                    // State 2: currently holding after sell, try max(not buying, buying)
                    dp[i][k][2] = max(dp[i + 1][k][2], dp[i + 1][k - 1][0] - prices[i]);
                } 
            }
        }
        return dp[0][_k][0];
    }
};

Space Optimization

  • we see that to compute dp[i][k][state], we only ever reference dp[i+1][...][...]. So we don't need to store all n days — just two 2D arrays:
    • curr: representing values for day i
    • next: representing values for day i+1
      This reduces space complexity from O(n*k*3) to O(2*k*3), i.e., O(k).

class Solution {
public:
    long long maximumProfit(vector<int>& prices, int _k) {
        int n = prices.size();
        long long mn = -1e14;

        vector<vector<long long>> curr(_k + 1, vector<long long>(3, mn));
        vector<vector<long long>> next(_k + 1, vector<long long>(3, mn));

        // Base case at day n
        for(int k = 0; k <= _k; k++){
            next[k][0] = 0;
        }

        for(int i = n - 1; i >= 0; i--){
            for(int k = 0; k <= _k; ++k){
                // State 0
                curr[k][0] = next[k][0];
                curr[k][0] = max(curr[k][0], next[k][1] - prices[i]); // start buy
                curr[k][0] = max(curr[k][0], next[k][2] + prices[i]); // start sell

                // States 1 and 2 carry forward
                curr[k][1] = next[k][1];
                curr[k][2] = next[k][2];

                if(k > 0){
                    // Complete transactions
                    curr[k][1] = max(curr[k][1], next[k - 1][0] + prices[i]); // sell the bought stock
                    curr[k][2] = max(curr[k][2], next[k - 1][0] - prices[i]); // buy the sold stock
                }
            }

            next = curr;
        }

        return next[_k][0];
    }
};

Intuition

DP

  • res[j] — the best total profit after completing j transactions (could be normal or short).

  • bought[j] — the best profit if you are currently holding a "bought" position in the j-th transaction (meaning you bought normally, waiting to sell).

  • sold[j] — the best profit if you are currently holding a "short sold" position in the j-th transaction (meaning you sold short, waiting to buy back).

Explanation

  • Update res[j]:
    Either keep the old max profit res[j],
    or sell the stock now if you were holding a "bought" position: bought[j-1] + a (complete normal transaction),
    or buy back the stock now if you were holding a "short sold" position: sold[j-1] - a (complete short selling transaction).

  • Update bought[j-1]:
    Either keep holding from before,
    or buy the stock now starting a new normal transaction: res[j-1] - a.

  • Update sold[j-1]:
    Either keep holding from before,
    or sell short the stock now starting a new short selling transaction: res[j-1] + a.

Complexity

Time O(nk)
Space O(k)

    public long maximumProfit(int[] A, int k) {
        long[] res = new long[k + 1], bought = new long[k], sold = new long[k];
        Arrays.fill(bought, -1000000000);
        for (int a : A) {
            for (int j = k; j >= 1; j--) {
                res[j] = Math.max(res[j], Math.max(bought[j - 1] + a, sold[j - 1] - a));
                bought[j - 1] = Math.max(bought[j - 1], res[j - 1] - a);
                sold[j - 1] = Math.max(sold[j - 1], res[j - 1] + a);
            }
        }

        long ans = 0;
        for (long v : res)
            ans = Math.max(ans, v);
        return ans;
    }

Intuition:

This is a variation of the stock buy-sell problem where each transaction can be either:

  • Normal (buy-sell): Buy on day i, sell on day j where i < j
  • Short selling (sell-buy): Sell on day i, buy back on day j where i < j

We use Dynamic Programming (DP) to store the maximum profit at each transaction count and day:

  • dp[t][i]: Maximum profit up to day i with at most t transactions

We optimize space using two 1D arrays for previous and current profits.

Track two variables at each transaction level:

  • best_buy: Best profit if we decide to buy on day i
  • best_short: Best profit if we decide to short sell on day i

Example:

Input:

prices = [3, 2, 6, 5, 0, 3], k = 2
  • Max 2 transactions allowed.
  • Use DP and track best buy/short options dynamically.

Code:

typedef long long ll;
class Solution {
public:
    ll maximumProfit(vector<int>& prices, int k) {
        int n = prices.size();
        if (n < 2 || k == 0) return 0;

        vector<ll> dp_prev(n, 0), dp_cur(n, 0);

        for (int t = 1; t <= k; t++) {
            ll best_buy = -prices[0];   // Max profit if we buy on day i
            ll best_short = prices[0];      // Max profit if we short sell on day i
            dp_cur[0] = 0;

            for (int i = 1; i < n; i++) {
                ll a = dp_cur[i - 1];                // No action on day i
                ll b = best_buy + prices[i];         // Sell after buying
                ll c = best_short - prices[i];           // Buy back after shorting

                dp_cur[i] = max({a, b, c});

                best_buy = max(best_buy, dp_prev[i - 1] - prices[i]);
                best_short = max(best_short, dp_prev[i - 1] + prices[i]);
            }

            swap(dp_prev, dp_cur);
        }

        return dp_prev[n - 1];
    }
};

Time & Space Complexity:

  • Time Complexity: O(K * N), where K is max transactions, N is number of days
  • Space Complexity: O(N) using rolling arrays

? Summary:

  • A twist on the classic buy-sell stock problem.
  • Track best_buy and best_short to support both buy-sell and short-buy paths.
  • Optimized with rolling DP arrays to reduce space usage.
