Intuition:

Trick is to fill the bags with less remaining capacity, as these require less water and more number of bags will be be filled first.

If we sort in increasing order on the basis of difference between current and orginal, then our work will be to reduce difference to 0 with the help of additionalRocks.

C++

int maximumBags(vector<int>& C, vector<int>& R, int add) {
    int n = size(R), cnt=0;
    for(int i = 0;i < n; i++) R[i] = C[i] - R[i];
    sort(begin(R), end(R));
    for(int i = 0;i < n && R[i] - add <= 0; i++) cnt++, add -= R[i];
    return cnt;
}

Intuition

We want to maximize the number of bags that end up exactly full after distributing our extra rocks. A natural greedy idea is to fill the bags that need the fewest rocks first—this way we “spend” as little of our additionalRocks budget as possible per bag.

Approach

Intuition

We want to maximize the number of bags that end up exactly full after distributing our extra rocks. A natural greedy idea is to fill the bags that need the fewest rocks first—this way we “spend” as little of our additionalRocks budget as possible per bag.

Approach

  1. Compute remaining capacity
    For each bag i, compute

    rem[i]=capacity[i]-rocks[i].

    This is how many more rocks are needed to fill bag i.

  2. Sort by ascending need
    Sort the rem array so that the bags requiring the fewest extra rocks come first.

  3. Greedy fill
    Iterate through the sorted rem array, and for each r in rem:

    • If additionalRocks >= r, use r rocks to fill that bag (increment our count of filled bags, decrement additionalRocks by r).
    • Otherwise, break out of the loop—no further bag can be filled with the remaining rocks.

  4. Return the count of bags we managed to fill.

This works because by always choosing the bag with the smallest requirement next, we maximize the total number of bags filled under a fixed rock-budget.

Complexity

  • Time complexity:

    • Computing the rem array takes O(n).
    • Sorting rem takes O(nlogn).
    • The final loop is O(n).
      Overall:

    O(n)+O(nlogn)+O(n)=O(nlogn).

  • Space complexity:

    • We use an extra array of length n to hold rem: O(n).
    • Sorting in-place may use O(logn) stack for quicksort, but asymptotically we still say O(n).

C++
class Solution {
    public int maximumBags(int[] capacity, int[] rocks, int additionalRocks) {
        int n = capacity.length;
        int[] rem = new int[n];

        // 1) Compute how many rocks each bag still needs.
        for (int i = 0; i < n; i++) {
            rem[i] = capacity[i] - rocks[i];
        }

        // 2) Sort so we can fill the easiest bags first.
        Arrays.sort(rem);

        // 3) Greedily fill until we run out of extra rocks.
        int cntFilled = 0;
        for (int need : rem) {
            if (additionalRocks >= need) {
                additionalRocks -= need;
                cntFilled++;
            } else {
                break;
            }
        }

        return cntFilled;
    }
}

}

?Intuition

  • We want to fill as many bags as possible using the given number of additionalRocks. Priority should be given to bags that need the least number of rocks.

?Approach

  • Calculate how many rocks each bag needs to be full: diff[i] = capacity[i] - rocks[i].

  • Sort the diff array to prioritize bags needing fewer rocks.

  • Traverse the sorted array and keep filling bags as long as additionalRocks allow.

  • Count how many bags were fully filled.

?Complexity

  • Time complexity : O(n log n).
  • Space complexity : O(n).

Code

class Solution {
public:
    int maximumBags(vector<int>& capacity, vector<int>& rocks, int additionalRocks) {
        int n = capacity.size();
        // storing capacity[i]-rocks[i] in diff array
        vector<int> diff(n,0);
        for(int i=0; i<n; i++){
            diff[i] = capacity[i]-rocks[i];
        }

        int count = 0; // bag is full
        sort(diff.begin(),diff.end());
        for(int i=0; i<n; i++){
            if(diff[i] == 0) count++;
            else if(diff[i] <= additionalRocks) {
                additionalRocks -= diff[i];
                diff[i] = 0;
                count++;
            }
        }
        return count;
    }
};
