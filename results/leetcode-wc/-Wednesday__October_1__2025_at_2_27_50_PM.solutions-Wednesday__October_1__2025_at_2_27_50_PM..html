Explanation

State:

dp[v] = number of zigzag arrays ending at value v.

Transition:

Odd step ? dp[v] = sum(dp[u]) for u < v.

Even step ? dp[v] = sum(dp[u]) for u > v.

Use prefix sums in left-to-right or right-to-left order to update efficiently.

Result:

res = 2 * sum(dp) % MOD (factor 2 accounts for up/down symmetry).

Complexity

With rolling array + prefix sum trick:
Time O(n(r - l))
Space O(n)

    def zigZagArrays(self, n: int, l: int, r: int) -> int:
        r -= l
        dp = [1] * (r + 1)
        mod = 10 ** 9 + 7
        for i in range(1, n):
            pre = 0
            if i & 1:
                for v in range(r + 1):
                    pre2 = pre + dp[v]
                    dp[v] = pre
                    pre = pre2 % mod
            else:
                for v in range(r, -1, -1):
                    pre2 = pre + dp[v]
                    dp[v] = pre
                    pre = pre2 % mod
        return sum(dp) * 2 % mod

Problem Statement

You are given three integers n, l, and r.

A ZigZag array of length n is defined as follows:

Each element lies in the range [l, r].

No two adjacent elements are equal.

No three consecutive elements form a strictly increasing or strictly decreasing sequence.

Return the total number of valid ZigZag arrays, modulo 1e9 + 7.

Intuition

The forbidden condition is having three consecutive numbers strictly increasing or strictly decreasing.

That means:

If the last step was an increase, the next must be a decrease.

If the last step was a decrease, the next must be an increase.

So the sequence must alternate direction:

Python
... < > < > ...
or
... > < > < ...

This naturally leads to a Dynamic Programming formulation.

? DP State Definitions

Let m = r - l + 1 (number of distinct values).
Index j corresponds to value l + j.

We define two main DP arrays:

up[j] ? Number of sequences ending at j where the last step was an increase (prev < j).

down[j] ? Number of sequences ending at j where the last step was a decrease (prev > j).

At each step we also build:

next_up[j] ? future values of up[j].

next_down[j] ? future values of down[j].

? Transition Rules

To compute next_up[j]:

Previous value must be smaller (i < j).

Previous transition must have been a decrease.

C++
// To end at j with an increase:
//   previous value must be smaller (i < j)
//   previous transition must be a decrease
next_up[j] = sum of down[i] for all i < j;

// To end at j with a decrease:
//   previous value must be larger (i > j)
//   previous transition must be an increase
next_down[j] = sum of up[i] for all i > j;

? Prefix & Suffix Optimization

Directly summing each time would be O(m2) per step.
We optimize with cumulative sums:

Prefix sums for down:

C++
pref[j] = down[0] + down[1] + ... + down[j]
next_up[j] = pref[j-1]

Suffix sums for up:

C++
suff[j] = up[j] + up[j+1] + ... + up[m-1]
next_down[j] = suff[j+1]

Thus, each length step runs in O(m) instead of O(m2).
Overall: O(n * m).

? Base Case

At length = 2:

up[j] = j ? any smaller index can come before j.

down[j] = m - 1 - j ? any larger index can come before j.

At length = 1 we cannot define direction, so we start from length 2.

? Final Answer

After building sequences up to length n:

C++
answer = sum(up) + sum(down)   (mod 1e9+7)

?? Complexity

Time Complexity: O(n * (r-l+1))

Space Complexity: O(r-l+1)

class Solution {
public:
    int zigZagArrays(int n, int l, int r) {
        int mod=1e9+7;
        vector<int> inc(r-l+1,1);
        vector<int> dec(r-l+1,1);
        vector<int> ninc(r-l+1,1);
        vector<int> ndec(r-l+1,1);
        for(int i=0;i<n;i++){
            for(int j=0;j<r-l+1;j++){
                ninc[j]=dec[j];
                ndec[j]=inc[j];
            }
            int ipref=0;
            int dpref=0;
            for(int j=0;j<r-l+1;j++){
                ipref=(ipref+ninc[j])%mod;
                inc[j]=(ipref-ninc[j]+mod)%mod;
                dpref=(dpref+ndec[r-l-j])%mod;
                dec[r-l-j]=(dpref-ndec[r-l-j]+mod)%mod;
            }
        }
        int sum=0;
        for (int x : ninc) sum = (sum + x) % mod;
        for (int x : ndec) sum = (sum + x) % mod;
        return sum;
    }
};

class Solution {
    int mod = 1000000007;

    public int zigZagArrays(int a, int b, int c) {
        int n = a;
        int l = b;
        int r = c;
        int m = r - l + 1;

        // dp layers: current pos and next pos
        int[][] cur = new int[m][2];
        int[][] next = new int[m][2];

        // base case: pos == n ? 1
        for (int i = 0; i < m; i++) {
            next[i][0] = 1;
            next[i][1] = 1;
        }

        for (int pos = n - 1; pos >= 0; pos--) {
            // slope == 0: go right-to-left (depends on num+1 in same row)
            for (int num = r; num >= l; num--) {
                int idx = num - l;
                int way1 = (num - 1 >= l) ? next[(num - 1) - l][1] : 0; // pos+1
                int way2 = (num + 1 <= r) ? cur[(num + 1) - l][0] : 0; // same pos
                cur[idx][0] = (way1 + way2) % mod;
            }
            // slope == 1: go left-to-right (depends on num-1 in same row)
            for (int num = l; num <= r; num++) {
                int idx = num - l;
                int way1 = (num + 1 <= r) ? next[(num + 1) - l][0] : 0; // pos+1
                int way2 = (num - 1 >= l) ? cur[(num - 1) - l][1] : 0; // same pos
                cur[idx][1] = (way1 + way2) % mod;
            }
            // swap layers
            int[][] temp = next;
            next = cur;
            cur = temp;
        }

        int res = next[r - l][1]; // corresponds to helper(0, r, 1)
        return (res + res) % mod;
    }
}
