Intuition

The code collects the indices of even and odd numbers and ensures their counts differ by at most one; otherwise, it returns -1. Then, it tries placing evens at even indices or at odd indices, whichever is valid. The helper function calculates the number of swaps needed to move elements to those target positions. The minimum number of swaps from the valid options is returned.

Approach

1. Goal:

Rearrange the array so that adjacent elements have alternating parity (even-odd-even or odd-even-odd). The only allowed operation is swapping adjacent elements, and we want to find the minimum number of such swaps.

2. Collect Indices:

Traverse the array and collect the indices of all even elements in one vector and all odd elements in another.

3. Check Feasibility:

If the absolute difference in count between even and odd elements is greater than 1 (abs(even.size() - odd.size()) > 1), it is impossible to alternate them, so return -1.

4. Try Valid Arrangements:

  • There are only two valid alternating patterns:

  • Even index ? even number, Odd index ? odd number (i.e., start with even)

  • Even index ? odd number, Odd index ? even number (i.e., start with odd)

  • We try both only if the number of even and odd elements allow them.

5. Helper Function (Swaps Calculation):

We use the helper function to calculate how many adjacent swaps are needed to move all even or all odd numbers to their target alternating positions:

  • If we choose to start with an even number:
    Then the even numbers must go to indices 0, 2, 4, ... (even indices), and odd numbers will go to 1, 3, 5, ...
    So, for each even number, we compute abs(current_index - expected_even_index), and sum it up for all.

  • If we choose to start with an odd number:
    Then the odd numbers must go to indices 0, 2, 4, ... and even numbers to 1, 3, 5, ...
    So, now we apply the same helper function to the odd indices vector, calculating the total distance to their new expected positions.

In both cases, the sum of these distances gives the total number of adjacent swaps needed (since one swap moves the element by one position). The code then returns the minimum of these two values.

Example Walkthrough

Input: nums = [2, 4, 6, 5, 7]

Step 1: Separate even and odd indices

  • We traverse the array and collect the indices of even and odd numbers:

  • Even numbers: 2, 4, 6 ? indices = [0, 1, 2]

  • Odd numbers: 5, 7 ? indices = [3, 4]

  • So we have:

              even = [0, 1, 2]
          odd = [3, 4]

Step 2: Check if a valid alternating pattern is possible

  • We check the count of evens and odds:

              even.size() = 3
          odd.size() = 2
          abs(3 - 2) = 1 ? valid (difference is ² 1)

Step 3: Try both valid patterns and calculate swaps

We can try:

  • Case A: Start with even ? even numbers go to positions 0, 2, 4

  • Case B: Start with odd ? odd numbers go to positions 0, 2, 4

We use the helper function:

helper(vector v) ? returns sum(abs(v[i] - 2*i))
(v = list of original indices, i = target index for that parity)

Case A: Even numbers at positions 0, 2, 4

Now, target positions for evens = [0, 2, 4]
We compute:

        abs(0 - 0) = 0
        abs(1 - 2) = 1
        abs(2 - 4) = 2
        Total = 0 + 1 + 2 = 3 swaps

Case B: Odd numbers at positions 0, 2, 4

Target positions for odds = [0, 2]
We compute:

        abs(3 - 0) = 3
        abs(4 - 2) = 2
        Total = 3 + 2 = 5 swaps

Output: min(3,5) = 3

class Solution {
public:
    int helper(vector<int> v){
        int c=0;
        for(int i=0;i<v.size();i++){
            c+= abs(v[i]-2*i);
        }

        return c;
    }
    
    int minSwaps(vector<int>& v){
        vector<int> even, odd;
        for(int i=0;i<v.size(); ++i){
            if(v[i]%2==0) even.push_back(i);
            else odd.push_back(i);
        }
    
        int n=v.size();
        int c1=even.size();
        int c2=odd.size();
    
        if(abs(c1-c2)>1) return -1;
    
        int ans=INT_MAX;

        if(c1>=c2) ans=min(ans, helper(even));
        if(c2>=c1) ans=min(ans,helper(odd));

        return ans;
    }

Here's the plan:

We address four cases based on the counts of evens and odds. We use the function minSwaps to compute the number of moves required from a list of indices of the odds.

  1. The counts of odds and evens in list nums are equal. In this case, the initial odd could be assigned to either nums[0] or to nums[1].

  2. The count of odds is one greater than the count of evens . In this case, the initial odd is assigned to nums[0].

  3. The count of odds is one less than the count of evens. In this case, the initial odd is assigned to nums[1].

  4. The counts of odds and evens differ by greater than one. In this case, we return -1.

class Solution:
    def minSwaps(self, nums: List[int]) -> int:

        def countSwaps(start):
            return sum(map(abs,map(sub, ones,range(start,n,2))))
     

        ones = [i for i, num in enumerate(nums) if num%2 == 1]
        n, m = len(nums), 2 * len(ones)
       
        if m == n:                                          # 1)
            return min(countSwaps(0), countSwaps(1))

        if m == n + 1:                                      # 2)
            return countSwaps(0)

        if m == n - 1:                                      # 3)
            return countSwaps(1)

        return -1                                           # 4)
