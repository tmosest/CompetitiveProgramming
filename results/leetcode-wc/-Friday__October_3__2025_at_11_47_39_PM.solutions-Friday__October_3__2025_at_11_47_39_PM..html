The water container area is defined as

width*height=(j-i)*min(height[i],height[j])?

Let's observe the following diagram to visualize the Algorithm:

heights=[7,4,7,10,8,3,10,4,12,9,5,8,3]

Each zero-width vertical line represents the elements of height array.

We find the starting container using vertical lines on either end:

The right line limits height of the current container.

The height is limited by which end (height[i],height[j]) is smaller, otherwise the water will overflow.

Thus, any future pairing would have smaller width with no height gain.

Now, move pointer j to the left:

Here, height becomes more than doubled despite losing width. Hence, the container area is becomes larger.
So far, this is the maximum.

Now the left line limits the Area, so move i to the right.

We can skip underwater lines to the first taller line:

We lost more width than we gained in height. Thus, the area becomes a bit smaller.

We must check each container against the current best. Slide j left again:

No improvement, but this shows we can move the same pointer twice when it remains the lower line:

This is the last container.

While not the best here, the optimal container in other examples could be just one index apart if both lines are extremely tall.

In the end, we can find that the maximum area is 77.
Thus, we return 77.

The approach we used is two-pointer and sliding window:

Start from both ends, check area at each step, then shift the lower-valued pointer inward.

When pointers meet, we've exhausted all containers and return the answer.

Intuition

We need to find two vertical lines such that they form a container with the maximum area.
The area is determined by:

  • Width = distance between lines
  • Height = min(height of both lines)

If we fix one line, the farther the other, the more area we can get, but height may limit it.
So we use two pointers:

  • Start with widest container (i=0, j=n-1).
  • Calculate area.
  • Move the pointer with the smaller height inward (because moving the larger height won’t help increase area).
  • Repeat until i < j.

Approach

  1. Initialize two pointers: left = 0, right = n-1.
  2. Compute area at each step:
    area = min(height[left], height[right]) * (right - left)
  3. Update maxArea if larger.
  4. Move the pointer pointing to the smaller height.
  5. Continue until left >= right.

Complexity

  • Time Complexity: O(n) (each pointer moves at most n steps).
  • Space Complexity: O(1) (only variables used).

class Solution {
    public int maxArea(int[] height) {
        int maxArea = 0;
        int i = 0, j = height.length - 1;

        while (i < j) {
            int currArea = Math.min(height[i], height[j]) * (j - i);
            maxArea = Math.max(maxArea, currArea);

            if (height[i] < height[j]) {
                i++;
            } else {
                j--;
            }
        }
        return maxArea;
    }
}
