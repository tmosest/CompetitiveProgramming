There are two solutions to solve this problem, Prim or Kruskal

Prim:

find any node first and from this node, find next node that is not been visited and has the less cost edge, until visited all nodes.
How to find out which edge is the less cost edge?
We can use PriorityQueue(min heap) to sort the edges.

public int minimumCost(int n, int[][] connections) {
        Map<Integer, List<int[]>> graph = new HashMap<>();
        for (int[] connection : connections) {
            int from = connection[0], to = connection[1], cost = connection[2];
            graph.putIfAbsent(from, new ArrayList<>());
            graph.putIfAbsent(to, new ArrayList<>());
            graph.get(from).add(new int[]{to, cost});
            graph.get(to).add(new int[]{from, cost});
        }
        
        int sum = 0;
        Set<Integer> visited = new HashSet<>();
        //{to, cost}
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
        pq.add(new int[]{connections[0][0], 0});
        
        while (!pq.isEmpty()) {
            int[] curr = pq.remove();
            if (visited.contains(curr[0])) 
                continue;
            visited.add(curr[0]);
            sum += curr[1];
            for (int[] next : graph.get(curr[0])) {
                int to = next[0], cost = next[1];
                if (!visited.contains(to)) {
                    pq.add(new int[]{to, cost});
                }
            }
        }
        
        return visited.size() == n ? sum : -1;
    }

Kruskal:

Sort all edges first and start with the less cost edge connect nodes. How to know if two nodes already been connected? We can use UnionFind to figure out.

    public int minimumCost(int n, int[][] connections) {
        UnionFind uf = new UnionFind(n + 1);
        List<int[]> connectionList = new ArrayList<>();
        for (int[] connection : connections)
            connectionList.add(connection);
        
        Collections.sort(connectionList, (a, b) -> a[2] - b[2]);
        int sum = 0, count = 0;
        for (int[] connection: connectionList) {
            int from = connection[0], to = connection[1], cost = connection[2];
            if (uf.find(from) == uf.find(to))
                continue;
            sum += cost;
            count++;
            uf.union(from, to);
        }
        
        return count >= n - 1 ? sum : -1;
    }
    
    class UnionFind {
        int[] parent;
        public UnionFind(int n) {
            parent = new int[n];
            for (int i = 0; i < n; i++)
                parent[i] = i;
        }
        
        public int find(int x) {
            if (parent[x] != x)
                parent[x] = find(parent[x]);
            return parent[x];
        }
        
        public void union(int x, int y) {
            parent[find(x)] = find(y);
        }
    }

Intuition

This problem is good fit for using UnionFind beacuse we need each node to be part of the MST which actually means that we would be left with 1 and only 1 set in the end.

Approach

  1. Create and Initialize UnionFind data structure
  2. Sort the edges in ascending order of their cost/weight
  3. Start iterating on the edges
  4. For each edge do a union b/w the nodes, if union does not happen then that means that both the nodes are already part of the same set(or already part of the MST). If the union happens then merge both the nodes into one set and add their cost/weight to the total cost
  5. At last if there is only 1 set left then that means we have a valid MST otherwise not.

Complexity

  • Time complexity: O(n + mlogm + mlogn) = O(nlogn)
    where n=number of nodes, m=number of edges
    {as per contraints given for this problem the max for both n & m is same}

  • Space complexity: O(n) for parent and size arrays

Code

Java
class Solution {

    public class UnionFind {
        int[] parent;
        int[] size;
        int count;

        public UnionFind(int n) {
            parent = new int[n+1];
            size = new int[n+1];
            count = n;

            for(int i=0; i<n+1; i++) {
                parent[i] = i;
                size[i] = 1;
            }
        }

        public int findRoot(int A) {
            while(A != parent[A]) {
                A = parent[A];
            }

            return A;
        }

        public boolean union(int A, int B) {
            int rootA = findRoot(A);
            int rootB = findRoot(B);

            if(rootA == rootB)
                return false;
            if(size[rootA] >= size[rootB]) {
                parent[rootB] = rootA;
                size[rootA] += size[rootB];
            } else {
                parent[rootA] = rootB;
                size[rootB] += size[rootA];
            }
            count--;
            
            return true;
        }
    }
    public int minimumCost(int n, int[][] connections) {
        UnionFind uf = new UnionFind(n);
        Arrays.sort(connections, (a, b)-> a[2] - b[2]);
        int cost = 0;

        for(int i=0; i<connections.length; i++) {
            int[] edge = connections[i];

            if(uf.union(edge[0], edge[1])) {
                cost += edge[2];
            }
        }

        if(uf.count == 1)
            return cost;
        else
            return -1;
    }
}
