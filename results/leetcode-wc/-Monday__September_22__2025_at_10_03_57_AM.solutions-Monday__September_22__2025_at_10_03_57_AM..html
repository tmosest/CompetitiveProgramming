For simplicity, we add zero to the end of the array (sentinel). For the explanation below, we will be using this example:

We maintain the monotonically increased stack. It's important to know the position of elements in that stack, so instead of values we will store indexes (we can lookup values using the input array). When we need to remove an element from the stack, we use indexes to compute the maximum query size that element is the potential maximum for.

For our example, the top of the stack - 10 - is the maximum for query 0 (2 - 1 - (0 + 1)).

Keep going; 10 is on the top again and it is the maximum for query 0 ((4 - 1) - (2 + 1)).

Now this is interesting:

  • 10 is the maximum for query 1 ((5 - 1) - (2 + 1)).
  • 4 is the maximum for query 3 ((5 - 1) - (0 + 1)).
  • 3 is the maximum for query 4 (5 - 1 - 0)

Finally, we process our sentinel value to empty the stack and compute maximums. For our example, 1 is the maximum for query 5.

Since we compute the maximum query size, we can have gaps. We fill these gaps in the end, making sure that the result array in non-decreasing right-to-left.

C++

vector<int> findMaximums(vector<int>& n) {
    vector<int> res(n.size()), s;
    n.push_back(0);
    for (int i = 0; i < n.size(); ++i) {
        while (!s.empty() && n[s.back()] >= n[i]) {
            int j = s.back(), k = i - 1;
            s.pop_back();
            if (!s.empty())
                k -= s.back() + 1;
            res[k] = max(res[k], n[j]);
        }
        s.push_back(i);
    }
    for (int i = res.size() - 1; i > 0; --i)
        res[i - 1] = max(res[i - 1], res[i]);
    return res;
}

Java

public int[] findMaximums(int[] n) {
    int[] res = new int[n.length];
    Stack<Integer> s = new Stack<>();
    for (int i = 0; i <= n.length; ++i) {
        while (!s.empty() && (i == n.length || n[s.peek()] >= n[i])) {
            int j = s.pop(), k = i - 1;
            if (!s.empty())
                k -= s.peek() + 1;
            res[k] = Math.max(res[k], n[j]);
        }
        s.push(i);
    }    
    for (int i = res.length - 1; i > 0; --i)
        res[i - 1] = Math.max(res[i - 1], res[i]);    
    return res;
}

This is really hard to me... don't know why it's only medium

  1. For each value a[i], note down the index of value < it on the left and right side, keep them in left and right arrays
  2. Then a[i] is the min value between len = left[i]+1... right[i]-1
  3. We update res[len] to be a[i] if a[i] is bigger. The reason is a[i] is the mininum value in a subarray of length = len
  4. Note a[i] will also be a potential max value for subarrays length between 1...len, as long as the subarray contains a[i]:

left[i] (<a[i])..[.......a[i].....]..right[i] (<a[i])

the position of [] can be anywhere to yield a subarray whose min = a[i]

Hence we take max between res[i] and res[i+1]: if there is a bigge value in a bigger subarray, that's a better value for a shorter subarray too

class Solution {
    public int[] findMaximums(int[] a) {
        Deque<Integer> st = new ArrayDeque<>();
        int n = a.length;
        int[] right = new int[n];
        Arrays.fill(right, n);
        for (int i = 0; i < n; i++) {
            process(st, right, a, i );
        }
        st.clear();
        int[] left = new int[n];
        Arrays.fill(left, -1);
        for (int i = n - 1; i >= 0; i--) {
            process(st, left, a, i );
        }
        int[] res = new int[n];
        for (int i = 0; i < n; i++) {
            int len = right[i] - left[i] - 1;
            res[len - 1] = Math.max(res[len - 1], a[i]);           
        }
        for (int i = n - 2; i >= 0; i--) {
            res[i] = Math.max(res[i], res[i + 1]);
        }
        return res;
    }

    protected void process(Deque<Integer> st, int[] pos, int[] a, int i) {
        while (!st.isEmpty() && a[st.peek()] > a[i]) {
            pos[st.peek()] = i;
            st.pop();
        }
        st.push(i);
    }
}
