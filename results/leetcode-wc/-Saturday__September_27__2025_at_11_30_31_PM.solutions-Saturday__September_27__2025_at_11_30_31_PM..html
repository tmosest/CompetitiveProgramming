class Solution {
    public long pickGifts(int[] nums, int k) {
        int n = nums.length;
        PriorityQueue<Integer> pq = new PriorityQueue<>((a,b)->(b-a));    // MAX-HEAP
        
        for(int i = 0; i<n; i++){
            pq.add(nums[i]);
        }
        
        long sum = 0;
        while(k-->0){
            pq.add((int)Math.sqrt(pq.remove()));
        }
        
        while(pq.size()>0){
            sum+=pq.remove();
        }

        return sum;
    }
}

Intuition

Prioritize reducing the largest values repeatedly using their integer square roots to minimize the impact on the total sum while leveraging a max-heap for efficiency.

Approach

1. Convert the array into a max-heap:

  • Use make_heap to rearrange the array so the largest element can be efficiently accessed.
    2. Iterate for k operations:

  • Pop the largest element from the heap (pop_heap).

  • Replace it with its integer square root (sqrt()).

  • Push the updated value back into the heap (push_heap).

3. Terminate early:

  • If the largest element becomes 1, further operations will have no effect since sqrt(1) remains 1.

4. Compute the result:

  • Use accumulate to sum up all the elements in the array, which is now rearranged into a heap but still contains all updated values.

Complexity

  • Time complexity: O(n+klogn)
  • Space complexity: O(1)

? Intuition

The problem requires repeatedly reducing the largest pile of gifts by replacing it with the floor of its square root. This operation needs to be performed k times, or until the largest pile has only one gift left. To efficiently find and update the largest pile during each step, we can use a max heap (implemented using a priority queue in reverse order).

? Approach

1. Initialize Max Heap:

  • Use a max heap to track the largest pile of gifts dynamically.
  • Add all elements from the input array g to the max heap.

2. Process k Operations:

  • For each operation, extract the maximum value from the heap.
  • Compute the floor of the square root of this value and push it back into the heap.
  • Repeat this process k times or stop early if the largest value is 1.

3. Sum Remaining Gifts:

  • After k operations, sum up all remaining values in the heap to get the total gifts left.

4. Return the Result:

  • The sum of the remaining elements is the answer.

? Complexity

1. Time complexity:

  • Building the heap: O(nlogn)
  • Up to k heap operations: O(klogn)
  • Total: O((n+k)logn)

2. Space complexity:

  • O(n) for the heap.

?? Concepts tags

1. Heap (Priority Queue):

  • A heap is used to efficiently retrieve and update the maximum value.
  • In this problem, we use a max-heap (priority queue in Java with Collections.reverseOrder()) to track the pile with the maximum gifts.
  • Operations like poll() and add() ensure O(logn) complexity for accessing and updating the heap.

2. Math:

  • The problem involves calculating the floor of the square root of the maximum pile. This is a mathematical operation and directly impacts the number of gifts left after each operation.

3. Array:

  • The initial input is given as an array of integers.
  • We iterate through the array to populate the heap and later sum up the remaining elements in the heap to calculate the result. Arrays are used as the base structure for heap initialization.

By combining these tags, the solution efficiently handles the problem requirements while maintaining clarity and performance.

class Solution {
    public long pickGifts(int[] g, int k) {
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        for (int val : g)
            maxHeap.add(val);

        for (int i = 0; i < k && maxHeap.peek() > 1; i++) {
            int x = maxHeap.poll();
            maxHeap.add((int) Math.sqrt(x));
        }

        long sum = 0;
        for (int val : maxHeap)
            sum += val;

        return sum;
    }
}
