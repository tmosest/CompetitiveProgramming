For simplicity let's introduce class Node, it will help us get infromation about nodes more quicly than HashTable

	class Node
	{
		Node[] children = new Node[26];
		int count;
		int end;
	}

Here's ordinary Trie implementation with my comments. Feel free to ask questions.

	class Trie
	{
		private Node root;

		public Trie()
		{
			root = new Node();
		}

        // We are iterating through each word character and if Node doesn't have a child we will add it.
		// on each step after adding/stepping the node we increment prefix count
		// after last step we add to words end's counter
		public void insert(String word)
		{
			Node current = root;
			int pos;
			for (char ch : word.toCharArray())
			{
				pos = ch - 'a';
				if (current.children[pos] == null)
				{
					current.children[pos] = new Node();
				}

				current = current.children[pos];
				current.count++;
			}

			current.end++;
		}

        // We are iterating through each word character and if Node doesn't have a child we return 0.
		// In case we iterated entire word, just return end's counter
		public int countWordsEqualTo(String word)
		{
			Node current = root;
			int pos;
			for (char ch : word.toCharArray())
			{
				pos = ch - 'a';
				if (current.children[pos] == null)
				{
					return 0;
				}

				current = current.children[pos];
			}

			return current.end;
		}

        // We are iterating through each word character and if Node doesn't have a child we return 0.
		// In case we iterated entire word, just return count counter
		public int countWordsStartingWith(String prefix)
		{
			Node current = root;
			int pos;
			for (char ch : prefix.toCharArray())
			{
				pos = ch - 'a';
				if (current.children[pos] == null)
				{
					return 0;
				}

				current = current.children[pos];
			}

			return current.count;
		}

        // We are iterating through each word character and if Node doesn't have a child we return
		// In case we iterated entire word, just decrement end's counter
		public void erase(String word)
		{
			Node current = root;
			int pos;
			for (char ch : word.toCharArray())
			{
				pos = ch - 'a';
				current = current.children[pos];
				current.count--;
			}

			current.end--;
		}
	}

Intuition

Compared with the standard implementation of trie without duplicates, this solution replace the "isEnd" flag with "count". A character sequence from root to the current node is a word when count > 0.

For erase, the tricky part is recognize the need to define a helper function with TrieNode return value and perform postorder traversal, which delete trailing characters first and then the check the current character.

In the standard implementation without duplicates, there are 4 scenarios. With duplicates, add the case of count > 0 after decremetn when level == word.length().

Code

class Trie {

    private TrieNode root;

    public Trie() {
        root = new TrieNode();    
    }
    
    public void insert(String word) {
        TrieNode cur = root;
        for (char ch: word.toCharArray()) {
            int index = ch - 'a';
            if (cur.next[index] == null)
                cur.next[index] = new TrieNode();
            cur = cur.next[index];
        }
        cur.count++;
    }
    
    public int countWordsEqualTo(String word) {
        TrieNode cur = root;
        for (char ch: word.toCharArray()) {
            int index = ch - 'a';
            if (cur.next[index] == null)
                return 0;
            cur = cur.next[index];
        }
        return cur.count;
    }
    
    public int countWordsStartingWith(String prefix) {
        TrieNode cur = root;
        for (char ch: prefix.toCharArray()) {
            if (cur.next[ch - 'a'] == null)
                return 0;
            cur = cur.next[ch - 'a'];
        }
        return countTotalWords(cur);
    }

    // Count total number of words in root's subtree, include root itself.
    private int countTotalWords(TrieNode root) {
        if (root == null)
            return 0;
        
        int totalCount = 0;
        for (TrieNode n: root.next) {
            totalCount += countTotalWords(n);
        }
        return totalCount + root.count;
    }
    
    // Decrement only once.
    public void erase(String word) {
        this.root = deleteByRecusion(this.root, word, 0);
    }

    // It is essentially a postorder traversal.
    // Deal with the trailing characters first and then check the current character
    // Note the return type is TrieNode.
    private TrieNode deleteByRecusion(TrieNode node, String word, int level) {
        if (node == null)
            return null;
        
        if (level == word.length()) {
            node.count--;
            if (node.count != 0 || hasChild(node))
                return node;
            else
                return null; // count == 0 && hasChild() == false;
        } else {
            int idx = word.charAt(level) - 'a';
            node.next[idx] = deleteByRecusion(node.next[idx], word, level + 1);
            if (!hasChild(node) && node.count == 0 && level != 0)
                return null;
        }
        return node; // keep the node since it's part of another word.
    }

    private boolean hasChild(TrieNode node) {
        for (TrieNode n: node.next) {
            if (n != null)
                return true;
        }
        return false;
    }
}

class TrieNode {
    int count = 0;
    TrieNode[] next;
    private static final int ALPHABET_SIZE = 26;
    TrieNode() {
        next = new TrieNode[ALPHABET_SIZE];
    }
}
