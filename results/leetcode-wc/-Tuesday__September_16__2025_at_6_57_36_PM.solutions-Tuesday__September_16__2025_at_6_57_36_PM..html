Approach

  • calculate the max target (sum) that can be achieved by taking cieling of each item.
  • If the sum is still less than the target after taking cieling on every item then taget sum cannot be achieved. For example: [3.5, 4.5, 5.001]; target = 16
  • If sum is greater than the target then the difference between them tells you how many floors you need on the price to achive the target. For example if you have [3.5, 4.5, 5.001], target = 13. sum (max target) = 15. It tells you flooring two items will help you get to target.
  • If the number of floors you need to take is more than the number of elements in the array then it means the target sum is extremely low. For example: [3.5, 4.5, 5.001]; target = 8

Once the invalid cases are taken care of:

  • To achieve minimum rounding error, you need to floor items that will have the least difference between (item) - floor(item). In the above case floor(5.0001) + floor(3.5) + ciel(4.5) OR floor(5.0001) + floor(4.5) + ciel(3.5) will have a rounding error of 1.0001. However, if you floor(3.5)+ floor(4.5) + ciel(5.0001) will give a rounding error or (1.999)
  • Sort the items based on the difference in the (item) - floor(item)
  • Once you have the sorted array, floor the required number of items and ciel the rest to achive the target. Calculate the rounding error on the go!

Complexity

  • Time complexity: O(nlogn)
  • Space complexity: O(n)

Code

class Solution {
    public String minimizeError(String[] prices, int target) {
        int sum = 0;
        Double roundingError = 0.0;
        Double[] pricesDouble = new Double[prices.length];
        
        // calculate the max target that can be achieved 
        for (int i = 0; i < prices.length; i++) {
            pricesDouble[i] = Double.valueOf(prices[i]); 
            sum += Math.ceil(pricesDouble[i]);
        }

        // cannot achive target even if you take cieling of every number
        if (sum < target) {
            return "-1";
        }
        
        // how many floors you need to take to achive the target
        int numOfFloors = (sum - target);

        // target is too low and impossible to achive even if we take the floor for all values
        if (numOfFloors > prices.length) {
            return "-1";
        }

        // you need to sort by the min difference between the double & its floor
        // for a case like prices = {["2.146", "3.001"]}, target=6. 
        // The floor should be taken on 3.001 and not 2.146
        Arrays.sort(pricesDouble, new Comparator<Double>() {
            @Override
            public int compare(Double i1, Double i2) {
                Double roundErr1 = i1 - Math.floor(i1);
                Double roundErr2 = i2 - Math.floor(i2);
                return Double.compare(roundErr1, roundErr2);
            }
        });

        for (int i = 0; i < prices.length; i++) {
            Double diff = 0.0;
            // if this is an integer then the rounding error 
            // would be zero and you can just skip the 
            // calculation of diff
            boolean isInteger = (pricesDouble[i] % 1 == 0);
            
            if (!isInteger && numOfFloors != 0) {
                diff = pricesDouble[i] - Math.floor(pricesDouble[i]);
                numOfFloors--;
            } else if (!isInteger){
                diff = Math.ceil(pricesDouble[i]) - pricesDouble[i];
            }
            roundingError += diff;
        }

        // for a case where all doubles were integers
        // and we could not take any floors to achive our target.
        // for the case when the sum of all integers
        // is equal to the target, num floors would be 0.
        if (numOfFloors != 0) {
            return "-1";
        }
        
        return String.format("%.3f", roundingError);
    }
}
