The sum of all subarrays of size k is equal if:

  • arr[i] == arr[i + k]
  • arr[i] == arr[i + 2 * k]
  • and so on.

As we roll a window of size k, we remove element arr[i] and add element arr[i + k].

For the sum to stay the same, the removed and added element must be the same. This can be also proven by a contradiction.

So, for each position i, we collect all elements in the k-cycle.

Then, we determine the median and perform operations to make all elements equal to that median.

C++
We use nth_element instead of sorting to find a median in O(n) in an average case.

long long makeSubKSumEqual(vector<int>& arr, int k) {
    long long sz = arr.size(), res = 0;
    for (int i = 0; i < k; ++i) {
        vector<int> cycle;
        for (int j = i; arr[j] != 0; j = (j + k) % sz) {
            cycle.push_back(arr[j]);
            arr[j] = 0;
        }
        nth_element(begin(cycle), begin(cycle) + cycle.size() / 2, end(cycle));
        for (int n : cycle)
            res += abs(n - cycle[cycle.size() / 2]);
    }
    return res;
}

Python 3
One-liner just for fun. Note that here we use gcd(len(a), k) to get all elements in the cycle instead of looping over a circular array.

class Solution:
    def makeSubKSumEqual(self, a: List[int], k: int) -> int:
        return sum(
            sum(abs(n - c[len(c) // 2]) for n in c)
            for c in [sorted(a[i::gcd(len(a), k)]) for i in range(gcd(len(a), k))]
        )

Java
The complexity is O(sort); we use sort because Java does not provide a standard quickselect implementation.

public long makeSubKSumEqual(int[] arr, int k) {
    long res = 0;
    for (int i = 0; i < k; ++i) {
        List<Integer> cycle = new ArrayList<>();
        for (int j = i; arr[j] != 0; j = (j + k) % arr.length) {
            cycle.add(arr[j]);
            arr[j] = 0;
        }
        Collections.sort(cycle);
        for (int n : cycle)
            res += Math.abs(n - cycle.get(cycle.size() / 2));
    }
    return res;
}

• The problem statement is to make the sum of all subarrays of length k equal changing the elements of the array. The approach used in this problem is to group the elements of the array into k subarrays based on their remainder when divided by k. Then, for each subarray, the median value is calculated and the absolute difference between each element in the subarray and the median is added to the total answer.
• Here is the step-by-step algorithm:
• Initialize a list of k subarrays.
• Calculate the greatest common divisor of n and k, where n is the length of the input array.
• Group the elements of the input array into k subarrays based on their remainder when divided by k.
• For each subarray, sort the elements and calculate the median value.
• For each element in the subarray, calculate the absolute difference between the element and the median value, and add it to the total answer.
• Return the total answer.
• The intuition behind this problem is that by grouping the elements into subarrays based on their remainder when divided by k, we can ensure that each subarray has the same number of elements. Then, by calculating the median value of each subarray, we can find a representative value that is close to the center of the subarray. By minimizing the absolute difference between each element and the median value, we can make the sum of all subarrays of length k equal.

class Solution:
    def makeSubKSumEqual(self,arr, k):
        n = len(arr)
        v = [[] for i in range(n + 1)]
        k = gcd(n, k)
        for i in range(n):
            v[i % k].append(arr[i])
        ans = 0
        for i in range(k):
            v[i].sort()
            x = v[i][len(v[i]) // 2]
            for j in v[i]:
                ans += abs(x - j)
        return ans

    def gcd(a, b):
        if b == 0:
            return a
        return gcd(b, a % b)

Complexity

• The time complexity (TC) of this algorithm is O(n log n), where n is the length of the input array. This is because the algorithm involves sorting each subarray, which takes O(k log k) time, where k is the size of each subarray. Since there are n/k subarrays, the total time complexity is O(n log k). However, since k is the greatest common divisor of n and k, it is at most n/2. Therefore, the time complexity can be simplified to O(n log n).
• The space complexity (SC) of this algorithm is O(n), where n is the length of the input array. This is because the algorithm creates a list of k subarrays, each of which can contain up to n/k elements. Therefore, the total space complexity is O(n).

class Solution {
public:
    long long makeSubKSumEqual(vector<int>& arr, int k) {
        int n = arr.size();
        vector<int> v[n+1];
        k = __gcd(n, k);
        for (int i = 0; i < n; ++i) {
            v[i%k].push_back(arr[i]);
        }
        long long ans = 0;
        for (int i = 0; i < k; ++i) {
            int median = quickselect(v[i], v[i].size() / 2);
            for (auto &j : v[i]) {
                ans += abs(median - j);
            }
        }
        return ans;
    }

    int quickselect(vector<int>& nums, int k) {
        int left = 0, right = nums.size() - 1;
        while (left <= right) {
            int pivotIndex = partition(nums, left, right);
            if (pivotIndex == k) {
                return nums[k];
            } else if (pivotIndex < k) {
                left = pivotIndex + 1;
            } else {
                right = pivotIndex - 1;
            }
        }
        return -1;
    }

    int partition(vector<int>& nums, int left, int right) {
        int pivotIndex = left + (right - left) / 2;
        int pivotValue = nums[pivotIndex];
        swap(nums[pivotIndex], nums[right]);
        int storeIndex = left;
        for (int i = left; i < right; i++) {
            if (nums[i] < pivotValue) {
                swap(nums[i], nums[storeIndex]);
                storeIndex++;
            }
        }
        swap(nums[storeIndex], nums[right]);
        return storeIndex;
    }
};

Approach

? Intuition: In a circular array, if you jump every k steps, you form gcd(n, k) independent cycles.
All elements in the same cycle must be made equal to minimize the operations.

?? Steps:

Find GCD(n, k) — this tells how many cycles we’ll have.

For each cycle:

Collect the elements.

Sort them and find the median.

Count the total operations needed to make all elements in the cycle equal to the median.

Add all operations across all cycles.

? Why Median? Using median minimizes the total sum of absolute differences — that’s why we use it!

? Quick Example:
arr = [1, 3, 1, 1], k = 2

gcd(4, 2) = 2 ? Two cycles:
cycle 1: [1, 1]
cycle 2: [3, 1]

Operations:

  • cycle 1: already equal ? 0 ops
  • cycle 2: make both 3 & 1 to median = 2 ? ops = |3-2| + |1-2| = 2

? Total ops = 2

Complexity

  • Time complexity:O(NlogN)
  • Space complexity:O(N)

class Solution {
    public static int gcd(int a,int b){
        while(b!=0){
            int temp=b;
            b=a%b;
            a=temp;
        }
        return a;
    }
    public long makeSubKSumEqual(int[] arr, int k) {
        long res=0;
        int n=arr.length;
        int gcd=gcd(n,k);
        for(int i=0;i<gcd;i++){
            List<Integer> list=new ArrayList<>();
            for(int j=i;j<n;j+=gcd){
                list.add(arr[j]);
            }
            Collections.sort(list);
            int med=list.get(list.size()/2);
            for(int ele:list){
                res+=Math.abs(ele-med);
            }
        }
        return res;
    }
}
