Why order of days does not matter ?

Because according to problem all pizzas are given to us in starting, so we are only planning that on which day which pizza will we eat so that we can eat maximum.

Intuition

We need to maximize the total weight we gain while eating pizzas optimally. Since we must eat 4 pizzas per day, and we only gain weight from one of them based on the day type:

  • Odd-numbered days ? Pick Z (the heaviest pizza available).
  • Even-numbered days ? Pick Y (the second heaviest pizza in that day’s group of 4).
  • We can process odd or even days in any order. Because we are only planning.
  • We can only take heaviest on odd days, so for maximizing we will process odd days first and then even days.
  • We will take heaviest odd days time.
  • We will take second heaviest even days time because we have to take Y on these days and have to skip Z to form a valid 4 pizzas group.

Picture is given by Ritik Tyagi

Now you can write code yourself either by one loop, two loop or any other trick. We have to do..

  1. Sorting
  2. Take elements form back odd days time
  3. Now even days time skip -> take -> skip -> take ...

Approach

  1. Sort the pizzas in ascending order

  2. Initialization

    • n = pizzas.length, and since n is a multiple of 4, the total number of days is days = n / 4.
    • index = n - 1, pointing to the last (heaviest) pizza in the sorted array.
    • totalWeight = 0, which will store the total weight gained.

  3. Processing odd-numbered days

    • On each odd-numbered day (1st, 3rd, 5th, ...), pick the heaviest pizza (Z).
    • Add pizzas[index] to totalWeight and move index left by one.

  4. Processing even-numbered days

    • On each even-numbered day (2nd, 4th, 6th, ...), pick the second heaviest pizza (Y).
    • Add pizzas[index] to totalWeight and move index left by two (since we have already used two pizzas from this group).

  5. Return totalWeight

    • After processing all days, return the final accumulated weight.

class Solution {
    public long maxWeight(int[] pizzas) {
        Arrays.sort(pizzas);
        int n = pizzas.length, days = n / 4;
        long totalWeight = 0;
        int index = n - 1;

        // Pick heaviest pizza on odd days
        for (int day = 1; day <= days; day += 2) {
            totalWeight += pizzas[index--];
        }

        // Pick second heaviest pizza on even days
        index--;
        for (int day = 2; day <= days; day += 2) {
            totalWeight += pizzas[index];
            index -= 2;
        }
        return totalWeight;
    }
}

Why can’t we use the skipped heavier pizza greedily on even day ?

  • Since n is always a multiple of 4, every four pizzas naturally form a valid set (W, X, Y, Z).
  • When choosing Y on even days, we are skipping a pizza that is heavier than Y (the one immediately to its right).
  • A reasonable question is: Can we somehow use that skipped pizza to maximize weight gain?
  • The answer is NO, because:
    • Every group of 4 must always have a valid Z for odd days.
    • If we attempt to pick the skipped heavier pizza instead of Y, we could disrupt the structure of these groups, violating the problem’s constraints.
    • The grouping ensures that we always have a heavier pizza available when needed.

        return (odd > even ? p[n - odd] : 0) + IntStream.range(0, even).mapToLong(k -> p[n - 1 - k] + p[n - 2 - odd - 2 * k]).sum();
    }
}

Intuition

We’re forced to eat pizzas in groups of 4. Depending on the day:

  • Odd day ? we gain the weight of the largest pizza (Z).

  • Even day ? we gain the weight of the 2nd largest pizza (Y).

    So the puzzle is:
    ? How can we maximize Z’s on odd days and maximize Y’s on even days?

?Key realization:

On odd days, we just want the absolute biggest pizzas.
On even days, we want the next biggest pizzas to appear as Y, which means grouping them smartly so they don’t get wasted as W or X.

Approach

  1. Sort the array ? so we can pick largest elements easily.

  2. Compute total days = n / 4.

  3. Odd days = (days + 1) / 2.

  4. Even days = days - odd.

  5. Start from the end of the sorted array:

  6. For each odd day ? take the largest available (Z).

  7. For each even day ? skip one (which becomes Z but doesn’t count), and take the next (Y).

  8. Repeat until all days are assigned.

This greedy distribution ensures we extract maximum value from the biggest pizzas.

Complexity

  • Time complexity:
    Sorting ? O(nlogn)
    Iteration ? O(n)
    Extra space ? O(1)

  • Space complexity: O(1)

class Solution {
    public long maxWeight(int[] pizzas) {
        int n = pizzas.length;
        int days = n / 4;
        long wt = 0;

        int odd = (days + 1) / 2;   // odd days
        int even = days - odd;      // even days

        Arrays.sort(pizzas);
        int idx = n - 1;

        // Odd days ? pick largest (Z)
        while (odd-- > 0) {
            wt += pizzas[idx--];
        }

        // Even days ? pick second largest (Y)
        idx--; // skip Z
        while (even-- > 0) {
            wt += pizzas[idx];
            idx -= 2; // skip W and X
        }

        return wt;
    }
}
