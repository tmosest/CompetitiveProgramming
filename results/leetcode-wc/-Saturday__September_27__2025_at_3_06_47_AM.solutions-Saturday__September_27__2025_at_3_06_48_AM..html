? Intuition

The list contains numbers as strings, so we can't sort them directly as strings because "10" would be considered smaller than "2", which is incorrect numerically.
To solve this correctly:

  1. Convert each string into an integer.
  2. Sort the list of integers.
  3. Find the k-th largest number using its position in the sorted list.
  4. Return the result as a string, since the function is expected to return a string.

? Approach

  • Step 1: Use a loop or list comprehension to convert each string in the list to an integer.
  • Step 2: Sort the list of integers in ascending order.
  • Step 3: Use the index length - k to access the k-th largest number (since list is 0-indexed).
  • Step 4: Convert the result back to a string before returning.

? Complexity

  • Time complexity: O(n log n) due to sorting.
  • Space complexity: O(n) to store the converted list.

? Python Code

from typing import List

class Solution:
    def kthLargestNumber(self, nums: List[str], k: int) -> str:
        # Step 1: Convert strings to integers
        num_list = [int(num) for num in nums]

        # Step 2: Sort the list in ascending order
        num_list.sort()

        # Step 3: Get the k-th largest element
        kth_largest = num_list[len(num_list) - k]

        # Step 4: Convert the result back to string
        return str(kth_largest)

Example usage:

solution = Solution()
nums = ["3", "6", "1", "10"]
k = 2
print(solution.kthLargestNumber(nums, k))  # Output: "6"

? Java Code

import java.util.*;

public class Solution {
    public String kthLargestNumber(String[] nums, int k) {
        // Step 1: Convert strings to integers
        List<Integer> numberList = new ArrayList<>();
        for (String s : nums) {
            numberList.add(Integer.parseInt(s));
        }

        // Step 2: Sort the list in ascending order
        Collections.sort(numberList);

        // Step 3: Get the k-th largest element
        int kthLargest = numberList.get(numberList.size() - k);

        // Step 4: Convert the result to string
        return String.valueOf(kthLargest);
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        String[] nums = {"3", "6", "1", "10"};
        int k = 2;
        System.out.println(sol.kthLargestNumber(nums, k));  // Output: "6"
    }
}

class Solution {
    public String kthLargestNumber(String[] nums, int k) {
        PriorityQueue<String> heap = new PriorityQueue<>((a, b) -> {
            if(a.length() != b.length()){
                return a.length() - b.length();
            }
            return a.compareTo(b);
        });

        for(String s: nums){
            heap.offer(s);
            if(heap.size() > k){
                heap.poll();
            }
        }
        return heap.peek();
    }
}
