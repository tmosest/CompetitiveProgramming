?[Solution] Crystal Clear | Optimal Greedy | String Transformation | Beginner Friendly | C++, Java, Golang

Intuition

To achieve the lexicographically smallest string with exactly one operation, we need to minimize the string’s characters as early as possible, as earlier positions dominate lexicographical order. The operation replaces a contiguous substring of non-'a' characters with their predecessors (e.g., 'b' to 'a', 'c' to 'b', ..., 'z' to 'y'). Greedily, we target the first non-'a' substring to reduce characters earliest in the string. If the string is all 'a's, replacing an 'a' with its predecessor ('z') increases the string’s value, so we replace the last 'a' with 'z' to keep it minimal while meeting the one-operation requirement. This approach is simple and intuitive, making it accessible for beginners.

Approach

  1. Handle Empty String: Return an empty string if the input is empty.
  2. Check for All 'a's: Iterate through the string to check if all characters are 'a'. If true, replace the last character with 'z'.
  3. Greedy Transformation:
    • Skip leading 'a’s to find the start of the first non-'a' substring.
    • Replace each non-'a' character in this substring with its predecessor until an 'a' or the end is reached.
  4. Efficient Implementation: Use StringBuilder (Java), string (C++), or rune slice (Golang) for efficient string modification.
  5. Return Result: Convert the modified structure to a string and return it.

Complexity

  • Time Complexity: O(n), where n is the string length. Checking for all 'a’s and modifying the first non-'a' substring each take O(n).
  • Space Complexity: O(n) for Java (StringBuilder) and Golang (rune slice) to store the result. C++ modifies the string in-place, using O(1) extra space (excluding output).

Code

Java

class Solution {
    public String smallestString(String s) {
        if (s.isEmpty()) return ""; // Handle empty string
        
        int n = s.length();
        StringBuilder sb = new StringBuilder(s);
        
        // Check if all characters are 'a'
        boolean allAs = true;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) != 'a') {
                allAs = false;
                break;
            }
        }
        
        // If all 'a's, replace last character with 'z'
        if (allAs) {
            sb.setCharAt(n - 1, 'z');
            return sb.toString();
        }
        
        // Find first non-'a' substring and replace with predecessors
        int i = 0;
        while (i < n && s.charAt(i) == 'a') {
            i++;
        }
        while (i < n && s.charAt(i) != 'a') {
            sb.setCharAt(i, (char)(s.charAt(i) - 1));
            i++;
        }
        
        return sb.toString();
    }
}

Golang

func smallestString(s string) string {
    if len(s) == 0 {
        return "" // Handle empty string
    }
    
    // Convert string to rune slice for modification
    runes := []rune(s)
    n := len(runes)
    
    // Check if all characters are 'a'
    allAs := true
    for i := 0; i < n; i++ {
        if runes[i] != 'a' {
            allAs = false
            break
        }
    }
    
    // If all 'a's, replace last character with 'z'
    if allAs {
        runes[n-1] = 'z'
        return string(runes)
    }
    
    // Find first non-'a' substring and replace with predecessors
    i := 0
    for i < n && runes[i] == 'a' {
        i++
    }
    for i < n && runes[i] != 'a' {
        runes[i] = runes[i] - 1
        i++
    }
    
    return string(runes)
}

Output: [c] [a] [a] [a] [c]
- Skip leading non-'a' 'c', find substring 'b', 'a', 'b'
- Replace 'b' -> 'a', 'a' -> 'a', 'b' -> 'a'
- Result: "caabc"

Example 2: Transforming "aaa" to "aaz"
Input:  [a] [a] [a]
                 |
                 v
Output: [a] [a] [z]
- All 'a's, replace last 'a' with 'z'
- Result: "aaz"
