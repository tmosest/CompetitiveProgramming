? Intuition

Alice typed a string, but he might have pressed one key too long, causing one extra duplicate letter in the string.

We need to find how many possible original strings she could have meant to type.

? Approach

  1. Start with count = 1 (the original string is always possible).
  2. Loop through the string and check if current character == previous character.
    • If yes, it means Alice might have pressed this key too long ? increase count by 1.
  3. Return count.

Step-by-Step Execution (word = "abbccc"):

  1. Initialization:

    • n = 6 (length of "abbccc").
    • count = 6 (initial assumption: every character could be a duplicate).

  2. Loop Through the String:

    • Compare each character with the previous one and decrement count if they differ.

3. Final Result:

  • count = 4

?Complexity Analysis

  • Time complexity: O(n) Single loop iterating n-1 times, with O(1) operations per iteration.
  • Space complexity: O(1) Only 3 variables (n, count, i) are used, regardless of input size.

class Solution {
    public int possibleStringCount(String word) {
        int n=word.length();
        int count=n;
        for(int i=1;i<word.length();i++){
            if(word.charAt(i)!=word.charAt(i-1)){
                count--;
            }
        }
        return count;
    }
}
