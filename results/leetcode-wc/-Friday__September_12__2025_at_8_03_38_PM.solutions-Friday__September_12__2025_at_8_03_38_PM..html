? Intuition

  1. Maximize Length: To maximize the length, include all *'0'*s (since they don't affect the value).

  2. Greedy for '1's: Include **'1'**s from the least significant bit (rightmost) to the most significant bit (leftmost). This way, we prioritize smaller contributions first, allowing us to include as many *'1'*s as possible without exceeding k.

? Approach

1. Count All Zeros

  • Include all '0's in the subsequence since they don't affect the value.

2. Process '1's from Right to Left

  • Start from the rightmost bit (least significant) and move left.
  • For each '1', check if adding its value (2^bit_position) to the current value keeps it ≤ k.
    • If yes, include it and update the current value.
    • If no, skip it.
  • Stop early if the current bit's value (pow) exceeds k (since further bits will only be larger).

? Algorithm Steps

  1. Initialize zeros = 0, ones = 0, value = 0, and pow = 1 (for the least significant bit).

  2. Count all '0's in s and store in zeros.

  3. Iterate over s from right to left:

    • If the current character is '1':
      • If value + pow ≤ k, include it (value += pow, ones++).
      • Else, skip it.
      • Update pow *= 2 (move to the next higher bit).
      • If pow > k, break (no further bits can be included without exceeding k).
    • If the current character is '0', just update pow *= 2 (since '0's are already counted).

  4. The result is zeros + ones.

Example Walkthrough ???

Let’s take s = "1001101", k = 6:

  1. Count Zeros: There are 3 '0's (zeros = 3).

  2. Process '1's from Right to Left:

    • i = 6: '1' at position 0 (value = 1), value = 1 (ones = 1).
    • i = 5: '0' (skip, pow = 2).
    • i = 4: '1' at position 2 (value = 4), value = 5 (ones = 2).
    • i = 3: '1' at position 3 (value = 8), 5 + 8 > 6 ? skip.
    • pow = 16 > 6 ? break.

  3. Result: zeros + ones = 3 + 2 = 5.

public class Solution {
    public int longestSubsequence(String s, int k) {
        int n = s.length();
        int zeros = 0;
        int ones = 0;
        long value = 0;
        long pow = 1;

        // Count all zeros
        for (char c : s.toCharArray()) {
            if (c == '0') zeros++;
        }

        // Process from right to left
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == '1') {
                if (value + pow > k) {
                    continue; // Skip this '1' as it would exceed k
                }
                value += pow;
                ones++;
            }
            pow <<= 1;
            // Prevent pow from overflowing; if pow is beyond k, no more '1's can be added
            if (pow > k) {
                // Once pow exceeds k, further bits can't be added as their value is too large
                break;
            }
        }
        return zeros + ones;
    }
}
