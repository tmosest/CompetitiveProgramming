We use a map to add new intervals in O(log n). As we add an interval, we need to merge it with the existing ones, and update the counter. That way, the count function is O(1).

Merging intervals is always tricky. The best is to use pen and paper to go through various scenarios.

When we add an interval, we check for overlapping intervals before and after. We extend left and right accordingly, remove all overlapping intervals, and add the new interval [left, right] in the end. This is an example how we merge [4, 14] interval with the existing ones:

  • Note that all existing overlapping intervals are removed, and their integers substracted from cnt.
    • We remove 3 intervals, and subtract 12 from cnt.
  • We extend the new interval to [2, 15].
  • We add the new interval [2, 15] and add 14 to the count .
    • The new interval resulted in adding 14 - 12 == 2 new integers.

C++

class CountIntervals {
public:
    map<int, int> m;
    int cnt = 0;
    void add(int left, int right) {
        auto it = m.upper_bound(left);
        if (it != begin(m) && prev(it)->second >= left)
            it = prev(it);
        for (; it != end(m) && it->first <= right; m.erase(it++)) {
            left = min(left, it->first);
            right = max(right, it->second);
            cnt -= it->second - it->first + 1;
        }
        cnt += right - left + 1;
        m[left] = right;
    }
    int count() { return cnt; }
};

class CountIntervals {
    TreeMap<Integer, Integer> m = new TreeMap<>();
    int cnt = 0;
    public void add(int left, int right) {
        var it = m.floorEntry(left);
        if (it == null || it.getValue() < left)
            it = m.higherEntry(left);
        for (; it != null && it.getKey() <= right; it = m.higherEntry(left)) {
            left = Math.min(left, it.getKey());
            right = Math.max(right, it.getValue());
            cnt -= it.getValue() - it.getKey() + 1;
            m.remove(it.getKey());
        }
        m.put(left, right);
        cnt += right - left + 1;        
    }
    public int count() { return cnt; }
}

Approach

Use a TreeMap<> where:

Key = left boundary (left) of an interval.
Value = right boundary (right) of an interval.
This allows efficient range merging by checking the nearest overlapping intervals in O(log N), where N is the number of stored intervals.

Implementation Steps
Use a TreeMap<Integer, Integer> to store intervals:
The key represents the left boundary.
The value represents the right boundary.

add(left, right) Merging Logic:
Find the first overlapping interval using floorEntry(right).
Find the next overlapping interval using higherEntry(left).
Merge all overlapping intervals into a new one.
Remove old intervals from the TreeMap and insert the merged interval.

count() Implementation:
Maintain a total count of covered integers.
Update the count when merging intervals.

Complexity

  • Time complexity:
    O(logN)

  • Space complexity:
    O(N)

Code

Java
class CountIntervals {
    TreeMap<Integer, Integer> map; //Left and Right Margin of CountIntervals
    int totalCount; //Stores the unique integers from left to right
    public CountIntervals() {
        map = new TreeMap<>();
        totalCount = 0;
    }
    
    public void add(int left, int right) {
        //Find largest entry that is less than or equal to right to find overlapping interval
        Map.Entry<Integer, Integer> entry = map.floorEntry(right);
        while(entry != null && entry.getValue() >= left){
            int existingLeft = entry.getKey();
            int existingRight = entry.getValue();
            totalCount -= existingRight - existingLeft + 1;
            left = Math.min(existingLeft, left);
            right = Math.max(existingRight, right);
            //Remove existing one
            map.remove(existingLeft);
            //Initialize entry to next one lesser than newly created entry
            entry = map.floorEntry(right);
        }
        //At the end insert merged interval and update total count
        map.put(left, right);
        totalCount += right - left + 1;
    }
    
    public int count() {
        return totalCount;
    }
}
