?Intuition

We want to check if a string looks like a "valid word" — not just in length, but in character type and content.

So, we:

  • Ensure it's long enough (at least 3 characters).
  • Make sure all characters are either letters or digits (no symbols or spaces).
  • Ensure it has both vowels and consonants, so it's not just numbers or all vowels.

This filters out short strings, non-alphanumeric ones, and strings that are only vowels or digits.

? Approach

  1. Check length: If the string is shorter than 3, it can’t be valid.

  2. Loop through characters:

    • If it’s a letter:
      • Check if it’s a vowel ? increase vowel count.
      • Else ? increase consonant count.
    • If it’s not a letter or digit ? return false immediately.

  3. Final check: Return true only if:

    • There is at least one vowel.
    • There is at least one consonant.

? Example: "234Adas"

Let’s check if this word is valid, step by step.

? Step 1: Check the length

  • The word "234Adas" has 7 characters.
    ? That’s more than 3, so the length is fine.

? Step 2: Check the characters

We go through each character one by one:

  • '2' ? It’s a digit ? okay.
  • '3' ? It’s a digit ? okay.
  • '4' ? It’s a digit ? okay.
  • 'A' ? It’s a letter and also a vowel ? good.
  • 'd' ? It’s a letter and a consonant ? good.
  • 'a' ? Another vowel ? good.
  • 's' ? Another consonant ? good.

? All characters are either digits or letters — there are no symbols or invalid characters.

? Step 3: Check for at least one vowel

We saw 'A' and 'a' ? ? yes, vowels are present.

? Step 4: Check for at least one consonant

We saw 'd' and 's' ? ? yes, consonants are present.

? Final Result:
Since the word:

  • Has more than 3 characters

  • Contains only letters and digits

  • Has at least one vowel

  • Has at least one consonant

? It is a valid word.

?Complexity Analysis

  • Time complexity:O(n)
  • Space complexity:O(1)

public class Solution {
    public boolean isValid(String s) {
        int n = s.length();
        if (n < 3) {
            return false;
        }

        int vowels = 0;
        int consonants = 0;

        for (char c : s.toCharArray()) {
            if (Character.isLetter(c)) {
                if ("aeiouAEIOU".indexOf(c) != -1) {
                    vowels++;
                } else {
                    consonants++;
                }
            } else if (!Character.isDigit(c)) {
                return false;
            }
        }
        return vowels >= 1 && consonants >= 1;
    }
}
