? Understanding the Problem

  • We're given an array nums and we need to find the number of subarrays in it which consist of the same number of distinct elements as the entire nums array.
  • For example : for nums = [1,3,1,2,2]
    • The number of distinct elements in the array are [1, 2, 3].
    • So we need to find the number of subarrays with exactly 3 distinct elements.
    • Therefore ?


  • Therefore the number of subarrays with 3 distinct elements are 4.

? Approach 1 ? Using Two Pointers

  • We first count the number of distinct elements in the nums array by using

int k = unordered_set<int>(nums.begin(),nums.end()).size()
  • This works as unordered_set stores unique elements only, so the size of a set containing all the elements of nums is the number of distinct elements in nums.
  • We then use two pointers i and j to traverse through nums and count the number of distinct elements in each subarray by maintaining a temporary unordered_set or map while looping.
  • Lastly we return the number of subarrays with k distinct elements.
  • ? Time Complexity ? O(n2)

class Solution {
    public:
        int countCompleteSubarrays(vector<int>& nums) {
            int k = unordered_set<int>(nums.begin(),nums.end()).size(), res = 0;
            for (int i = 0; i < nums.size(); i++) {
                unordered_set<int> st;
                for (int j = i; j < nums.size(); j++) {
                    st.insert(nums[j]);
                    if (st.size() == k) res++;
                }
            }
            return res;
        }
    };

? Approach 2 ? Using Sliding Window

  • Similar to the first approach we firstly calculate the number of distinct elements in the nums array.
  • We then traverse through nums and keep inserting the elements into our map.
  • Whenever our map reaches size k or the number of distinct elements in the map are the same as the number of distinct elements in nums.
  • We simply count nums.size() - 1 into our result count as from index i till the end of the array, all possible subarrays will be distinct.
  • For example : for nums = [5, 1, 1, 3, 1, 1, 5]

  • Here when we achieve 3 distincts at index 3 we must observe that all the subarrays from index 3 to the end also have 3 distinct elements each.
  • That is the 3 subarrays, [5, 1, 1, 3, 1], [5, 1, 1, 3, 1, 1], [5, 1, 1, 3, 1, 1, 5] have 3 distinct elements each.
  • We then keep removing elements from the left from nums to reduce the size of our current window while maintaining the count of number of distincts as 3.

Why do we keep reducing the window from left?

  • This is because while
  • this is a valid subarray with k distinct elements.
  • These are also subarrays not starting from index 0 which are valid such as ?
  • So inorder to count these subarrays not starting from index 0 we also need to keep reducing our window from the left.
  • Lastly we return the count of the nums.size() - 1 we accumulated throughout the traversal.
  • ? Time Complexity ? O(n)

  • For nums = [1, 3, 1, 2, 2] and k = 3:
    • Initialize left = 0, res = 0, mpp = {}
    • Iterate i from 0 to 4:
      1. i = 0: add 1 ? mpp = {1:1} (size 1) ? no full window
      2. i = 1: add 3 ? mpp = {1:1, 3:1} (size 2) ? no full window
      3. i = 2: add 1 ? mpp = {1:2, 3:1} (size 2) ? no full window

        • while size == k:
          • res += 5 - 3 = 2 ? res = 2
          • remove nums[left] = 1 ? mpp = {1:1, 3:1, 2:1}, left = 1
          • still full ?
            • res += 2 ? res = 4
            • remove nums[left]=3 ? mpp = {1:1, 2:1}, left = 2
      5. i = 4: add 2 ? mpp = {1:1, 2:2} (size 2) ? no full window
    • Return res = 4

class Solution {
public:
    int countCompleteSubarrays(vector<int>& nums, int left = 0, int res = 0) {
        int k = unordered_set<int>(nums.begin(),nums.end()).size();
        unordered_map<int, int> mpp;

        for (int i = 0; i < nums.size(); ++i) {
            mpp[nums[i]]++;
            while (mpp.size() == k) {
                res += nums.size() - i;  
                mpp[nums[left]]--;
                if (mpp[nums[left]] == 0) mpp.erase(nums[left]);
                left++;
            }
        }
        return res;
    }
};

class Solution {
    public int countCompleteSubarrays(int[] nums) {
        int[] arr=new int[2001];
        int count=0;
        for(int i=0;i<nums.length;i++){
            if(arr[nums[i]]==0){
                count++;
            }
            arr[nums[i]]++;
        }
        arr=new int[2001];
        int i=0,j=0;
        int countD=0;

        int res=0;
        while(j<nums.length){
            if(countD==count){
                while(i<j && arr[nums[i]]>1)
                    arr[nums[i++]]--;
                res+=i+1;
            }
            if(arr[nums[j++]]++==0)
                countD++;
        }
        if(countD==count){
            while(i<j && arr[nums[i]]>1)
                arr[nums[i++]]--;
            res+=i+1;
        }
        return res;
    }
}
