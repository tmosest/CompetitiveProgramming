Intuition

  1. If there is an all 0s row, it is one of the solutions.
  2. Otherwise, if there are a pair of two rows that the AND operation between them is 0, then it is one of the solutions.
  3. Since n <= 5, we can use a HashMap/dict to store visited row(which can be converted to an int) and corresponding row number, and traverse all numbers within 2 ^ 5 - 1 = 31 to find current number's pair.
    public List<Integer> goodSubsetofBinaryMatrix(int[][] grid) {
        int R = grid.length;
        if (R == 1) {
            return IntStream.of(grid[0]).sum() == 0 ? List.of(0) : List.of();
        }
        Map<Integer, Integer> rowIndices = new HashMap<>();
        for (int r = 0, C = grid[0].length; r < R; ++r) {
            int r1 = r, num = IntStream.range(0, C).map(k -> grid[r1][k] << k).sum();
            for (int i = 0; i < 32; ++i) {
                if ((i & num) == 0 && rowIndices.containsKey(i)) {
                    return List.of(rowIndices.get(i), r);
                }
            }
            rowIndices.putIfAbsent(num, r);
        }
        return List.of();
    }
    def goodSubsetofBinaryMatrix(self, grid: List[List[int]]) -> List[int]:
        if len(grid) == 1:
            return [0] if all(num == 0 for num in grid[0]) else []
        d = {}
        for r, row in enumerate(grid):
            num = sum(cell << c for c, cell in enumerate(row))
            for i in range(32):
                if (i & num) == 0 and i in d:
                    return [d[i], r]
            d.setdefault(num, r)    
        return []

Analysis

Time: O(m * 2 ^ n), space: O(m).

There are various solution with proof out there, however I couldn't understand any of them, After reading multiple of proofs, I did able to convince myself why only two rows are required. Below is example

  • At first, you try different (3-4) example, and it turns out you need 2 row to check if there bitwise AND is 0, you will have the answer.

If you are able to prove that only 2 row's bitwise AND is only required/necessary condition, you will be convinced.

Lets prove this by contradiction. Check below two points :-

  1. None of the row should contains all zeros, else answer will be only this row.
  2. If you want that 2 row can't lead to solution, that means between each pair of row, there must be one column having both 1(overlapping 1). Example,
    10100
    00100

lets try out all possible types, we are trying to find subset (that we have to pick as answer) where number of rows != 2 and must be >2. If we can't find answer for rows != 2 and >2, that means no solution exist for >2, we would have proved, that row = 2 is only necessary and sufficient confition :-

  • 10000
    Lets say, in our subset (answer) 10000 is one row.
    That means, we must have
    10000
    1XXXX
    1XXXX
    1XXXX
    ... k times

why?
Since, because of condition 2, which says b/w each pair there must be 1, since we have only 1 in original row, we have to have 1 in all below. Now, obivously, this can't lead to solution since, number of 1 in first column = k, (where k = number of rows in subset)

  • 11000
    In this case, because of condition 2, we must have
    11000
    10XXX
    01XXX
    10XXX (k times)

Let k = 6.

note, in order for 2 and 3 row above we must have overlapping 1, so add as below

11000
101XX
011XX
10XXX
01XXX
10XXX

check, number of 1 in first column - 4, which is != k/2, we can't pick 11000.

  • 11100
    This is also not possible for k = 3 or 4 or (k>2) (you can try yourself)

We just proved. How?
We took an example of random row with random number of 1, and try to contruct a subset such that number of rows > 2 and there has to be overlapping of 1 in each pair and by doing so in optimising way, we ended up getting result, where sum of 1 in at least 1 column is > k/2. Means we can't construct such subset with rows > 2 and contains the answer.
Hence only two possiblilty, either all 0, or 2 row with bitwise 0.

class Solution {
    public List<Integer> goodSubsetofBinaryMatrix(int[][] grid) {
        
        int n = grid.length;
        int m = grid[0].length;
        
        for(int i=0;i<n;i++) {
            boolean found = true;
            for(int j=0;j<m;j++) {
                if(grid[i][j] == 1) found = false;
            }
            if(found) return Arrays.asList(i);
        }
        
        HashMap<Integer, Integer> map = new HashMap<>();
        
        for(int i=0;i<n;i++) {
            
            int[] x = grid[i];
            
            int num = convert(x);
            System.out.println(num);
            int ans = neg(x, map, new int[m]);
            if(ans != -1) {
                return Arrays.asList(ans, i);
            }
            map.put(num, i);
            
            System.out.println();
            
        }
            
        return new ArrayList<>();
            
         
    }
    
    private int neg(int[] x, HashMap<Integer, Integer> map, int[] num) {
       
        
        int n = x.length;
        return solve(x, 0, map, num);
        
    }
    
    private int solve(int[] x, int i, HashMap<Integer, Integer> map, int[] num) {
        
        int n = x.length;
        if(i==n) {
            int y = convert(num);
            System.out.println(Arrays.toString(num)+" " + y);
            if(map.containsKey(y)) return map.get(y);
            return -1;   
        }
        
        int ans = -1;
        
        if(x[i] == 0) {
            num[i] = 1;
            ans = solve(x, i+1, map, num);
            num[i] = 0;
        }
        
        if(ans != -1) return ans;
        ans = solve(x, i+1, map, num);
        
        return ans;
        
        
    }
    
    private int convert(int[] x) {
        int n = x.length;
        int ans = 0;
        int j = 0;
        for(int i=n-1;i>=0;i--) {
            if(x[i]==1) ans += 1<<j;
            j++;
        }
        
        return ans;
    } 
    
 }
