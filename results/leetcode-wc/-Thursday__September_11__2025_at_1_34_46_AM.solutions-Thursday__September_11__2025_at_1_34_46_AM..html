Intuition

What is a "state" in bitmask DP?

A state is just a way of describing "where you are" in the problem.

In bitmask DP, the bitmask is used to encode which courses have already been completed.

Example: n = 4 courses ? bitmask of 4 bits.

0000 ? no courses done

0101 ? courses 0 and 2 done

1111 ? all courses done

So the state here = {subset of completed courses}.

Approach

  Key Ideas:
  ----------
  1. State Representation:
     - Use a bitmask (currentMask) to represent which courses have been completed.
       Example for n=4:
         0000 -> no course done
         1010 -> courses {1, 3} done
        1111 -> all courses done (goal state)
 
  2. Transition:
     - At each state, find all "available courses" (indegree = 0 and not yet taken).
     - From these, we can take up to 'k' courses in the current semester.
     - This leads to new states where these courses are marked done, and their children’s indegree decreases.
 
  3. Recursion:
    - For each state (bitmask), recursively explore all possible choices of available courses.
    - Each recursive call represents "one more semester".
 
 4. DP + Memoization:
     - cache[currentMask] stores the minimum semesters needed if the completed set = currentMask.
      - This avoids recomputation for the same subset of completed courses.
 
5. Base Case:
    - If all courses are completed (mask == (1 << n) - 1), return 0 (no more semesters needed).

Complexity

  • Time complexity: Luckily every inDegree state is a representation of a mask and won't differ for any existing mask. Breaking down the problem:
    i) Create a mask for every possible state. O(2^n)
    ii) Generate a combination pair for every set of states. O(C(n,k))
    iii) Create a new inDegree array for each possible state. O(n)
    So probable time Complexity: O(2^n * C(n, k) * n)
    C(n, k) can be max 6435 (15C7 or 15C8)
  • Space complexity: O(2^n + k * C(n, k))

class Solution {
    private List<List<Integer>> graph;
    int []inDegree;
    int []cache;
    private void buildGraph(int n, int [][]relations) {
        for(int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }
        for(int []relation : relations) {
            int from = relation[0] - 1, to = relation[1] - 1;
            inDegree[to] += 1;
            graph.get(from).add(to);
        }
    }

    List<List<Integer>> kCombinations;
    // Generates K combinations for courses
    private void generateKCombinations(int index, List<Integer> courses, int k, List<Integer> buckets) {
        if(k >= courses.size()) { kCombinations.add(new ArrayList<>(courses)); return; }
        if(buckets.size() == k) { kCombinations.add(new ArrayList<>(buckets)); return; }
        
        for(int i = index; i < courses.size(); i += 1) {
            buckets.add(courses.get(i));
            generateKCombinations(i + 1, courses, k, buckets);
            buckets.remove(buckets.size() - 1);
        } 
    }

    private int minNumberOfSemesters(int currentMask, int []inDegree, int n, int k) {
        // Base case: none of the courses are available
        if((currentMask + 1) == (1 << n)) return 0;
        if(cache[currentMask] != -1) return cache[currentMask];
        List<Integer> availableCourses = new ArrayList<>();
        for(int i = 0; i < n; i += 1) {
            // if course is available and inDegree is 0
            if(inDegree[i] == 0 && ((currentMask >> i) & 1) == 0) {  availableCourses.add(i); }
        }
        int minSemesters = Integer.MAX_VALUE;
        kCombinations = new ArrayList<>();
        generateKCombinations(0, availableCourses, k, new ArrayList<>());
        for(List<Integer> combinations : kCombinations) {
            int newMask = currentMask;
            int []newIndegree = new int[n];
            for(int i = 0; i < n; i += 1) { newIndegree[i] = inDegree[i]; }
            for(int combination : combinations) {
                newMask |= (1 << combination);
                for(int child : graph.get(combination)) {
                    newIndegree[child] -= 1;
                }
            }
            minSemesters = Math.min(minSemesters, 1 + minNumberOfSemesters(newMask, newIndegree, n, k));
        }
        return cache[currentMask] = minSemesters;
    }



    public int minNumberOfSemesters(int n, int[][] relations, int k) {
        graph = new ArrayList<>();
        inDegree = new int[n];
        cache = new int[1 << n];
        Arrays.fill(cache, -1);
        buildGraph(n, relations);
        int currentMask = 0; // 0 => all courses are available
        return minNumberOfSemesters(currentMask, inDegree, n, k);
    }
}
