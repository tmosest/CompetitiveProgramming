Problem overview ?

To maximize the sum of a triplet with distinct x[i] values, we can:

  1. Pair each x[i] with its corresponding y[i].
  2. For each unique x[i], keep only the maximum y[i] value.
  3. From these values, select the top 3 maximum values and return their sum.

This can be done efficiently using a hashmap and a max-heap (priority queue).

? Approach 1: Using HashMap + PriorityQueue

Intuition:

  • First, use a HashMap to store the maximum y[i] value for each distinct x[i].

  • Then use a max-heap (PriorityQueue) to extract the top 3 largest values.

class Solution {
public:
    int maxSumDistinctTriplet(vector<int>& x, vector<int>& y) {
        int n = x.size();
        unordered_map<int, int> yx;

        for(int i = 0; i < n; ++i) {
            yx[x[i]] = max(yx[x[i]], y[i]);
        }

        priority_queue<int> maxHeap;
        for(auto& [key, val] : yx) {
            maxHeap.push(val);
        }

        if(maxHeap.size() < 3) return -1;

        int sum = 0;
        for(int i = 0; i < 3; ++i) {
            sum += maxHeap.top();
            maxHeap.pop();
        }
        return sum;
    }
};

??Time complexity:

  • Building map: O(n)

  • Inserting k elements in heap: O(k log k)

  • Popping top 3: O(3 log k) Å O(log k)

  • Total: O(n + k log k) where k = unique elements in x

?Space complexity:

  • HashMap: O(n) worst-case

  • PriorityQueue: O(k) (but only 3 elements matter)

  • Collect values into a vector, sort them descending, and sum top 3.

class Solution {
public:
    int maxSumDistinctTriplet(vector<int>& x, vector<int>& y) {
        int n =x.size();
        unordered_map<int, int>yx;

        for(int i=0; i<n; ++i){
            if(yx.find(x[i])==yx.end())
                yx[x[i]]=y[i];
            else
                yx[x[i]]=max(yx[x[i]], y[i]);
        }

        vector<int> myx;
        for(auto& [key, val] : yx){
            myx.push_back(val);
        }

        if(myx.size()<3) return -1;

        sort(myx.begin(), myx.end(), greater<int>());
        return myx[0]+myx[1]+myx[2];
    }
};

? Approach 3: Greedy Style (Best Approach)

  • We initialize three slots (a, b, c) to store the top 3 values and their corresponding unique x[i] values (ind1, ind2, ind3).
  • For each (x[i], y[i]), we check:
    • If the x[i] matches one of the existing three indices, we update the max if y[i] is better.
    • If it doesn't match any, and y[i] is greater than the current minimum among a, b, and c, we replace the minimum with this new value and update the corresponding index.
  • At the end, if we have found three distinct x[i] values (i.e., no slot is still zero), we return the sum. Otherwise, return -1.

class Solution {
public:
    int maxSumDistinctTriplet(vector<int>& x, vector<int>& y) {
        int n = x.size();
        int a = 0, b = 0, c = 0;
        int ind1 = 0, ind2 = 0, ind3 = 0;

        for(int i = 0; i < n; i++) {
            if(x[i] == ind1) {
                if(y[i] > a) a = y[i];
            } else if(x[i] == ind2) {
                if(y[i] > b) b = y[i];
            } else if(x[i] == ind3) {
                if(y[i] > c) c = y[i];
            } else if(y[i] > a || y[i] > b || y[i] > c) {
                int mini = min({a, b, c});
                if(mini == a) {
                    a = y[i];
                    ind1 = x[i];
                } else if(mini == b) {
                    b = y[i];
                    ind2 = x[i];
                } else {
                    c = y[i];
                    ind3 = x[i];
                }
            }
        }

        if(a == 0 || b == 0 || c == 0)
            return -1;
        return a + b + c;
    }
};

Max Sum of Distinct Triplets

Problem Statement:

You are given two integer arrays x and y, both of size n.

Each pair (x[i], y[i]) represents a key-value pair.

Your task is to:

  • Select three distinct keys from x,
  • For each of those keys, pick the maximum value from y (for all occurrences of the key),
  • Return the maximum possible sum of these three values.

If there are less than three unique keys in x, return -1.

Intuition:

We want to pick the 3 best key-value pairs such that all keys are different and each value is the maximum for its key. This can be done using a hash map:

  • For each key, store its highest value.
  • Then, select the top 3 highest values among all these.

Explanation with Example:

Input:

x = [1, 2, 1, 3, 4]
y = [5, 7, 9, 2, 10]

Let's pair x[i] and y[i]:

(1, 5), (2, 7), (1, 9), (3, 2), (4, 10)

Now, for each unique key, keep the maximum value:

1 -> max(5, 9) = 9
2 -> 7
3 -> 2
4 -> 10

Values to consider: [9, 7, 2, 10]
Pick the top 3: 10 + 9 + 7 = 26

So, the answer is 26.

class Solution {
public:
    int maxSumDistinctTriplet(vector<int>& x, vector<int>& y) {
        int n = x.size();
        unordered_map<int, int> hash;

        // Store max value for each unique key
        for (int i = 0; i < n; i++) {
            auto it = hash.find(x[i]);
            if (it == hash.end()) {
                hash[x[i]] = y[i];
            } else {
                it->second = max(it->second, y[i]);
            }
        }

        if (hash.size() < 3) return -1;

        // Store all max values and sort
        vector<int> vals;
        for (auto it : hash) {
            vals.push_back(it.second);
        }

        sort(vals.begin(), vals.end(), greater<int>());
        return vals[0] + vals[1] + vals[2];
    }
};

Time & Space Complexity:

  • Time Complexity: O(N + M log M)

    • N = length of input arrays
    • M = number of unique keys

  • Space Complexity: O(M) to store key-value pairs
