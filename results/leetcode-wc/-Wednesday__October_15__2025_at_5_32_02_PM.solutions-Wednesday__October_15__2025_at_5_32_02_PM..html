? Solution Explanation: SmallestInfiniteSet Class in C++

? Problem Summary

We are given a virtual infinite set containing all positive integers:
{1, 2, 3, 4, 5, ...}

We need to implement a class that can do the following operations:

  • popSmallest(): Removes and returns the smallest integer from the set.
  • addBack(num): Adds the number num back into the set if it was removed earlier.

?? Implementation Overview

We implement a class called SmallestInfiniteSet using the following data members:

? int current

  • Keeps track of the next smallest number in the infinite sequence.
  • Initially set to 1.
  • Think of this as the default "next number" unless there’s something smaller in the heap.

? priority_queue<int, vector<int>, greater<int>> minHeap

  • A min-heap (priority queue) that stores all the numbers that have been removed (popped) and then added back.
  • Ensures that we always return the smallest added-back number before moving forward with the current.

? unordered_set<int> addedBack

  • A helper structure to avoid adding duplicates to the heap.
  • Keeps track of which numbers have been pushed into the heap so we don’t insert the same number twice.

class SmallestInfiniteSet {
public:

    int current;
    priority_queue<int, vector<int>, greater<int>> minHeap;
    unordered_set<int> addedBack;

    // Constructor initializes the set starting from 1
    SmallestInfiniteSet() {
        current = 1;
    }

    // Removes and returns the smallest number in the set
    int popSmallest() {
        // If we have added-back numbers, use them first
        if (!minHeap.empty()) {
            int smallest = minHeap.top();    // Get the smallest from heap
            minHeap.pop();                   // Remove it from heap
            addedBack.erase(smallest);       // Also remove from the tracking set
            return smallest;
        }
        // Otherwise, return current and move to the next
        return current++;
    }

    // Adds a number back into the set if it's smaller than current
    void addBack(int num) {
        // Only add if it's smaller than current (i.e., already popped)
        // and not already in the minHeap
        if (num < current && addedBack.find(num) == addedBack.end()) {
            minHeap.push(num);       // Push to heap
            addedBack.insert(num);   // Mark it as added
        }
    }
};
