Intuition

Take a look at the binary of n:

If there is an alone 1, like ..00001,
it takes at leat one operation to remove.
and we can remove it in one operation.
So we do res++ and n >>= 2,
remove two last bits.

If there are multiple 1s, like ..0000111,
we can't remove them in one single operation,
so it takes at least two operation to remove,
For example of ..0000111
we can add 1 and then remove 1000.
So we do n++ and remove the last bit 0.

Explanation

By this stratagy in intuition,
we only need to take care of the the continuous 1 in binary of n.
If it's single 1, res += 1
If it's multiple 1s, res += 2

Complexity

Time O(logn)
Space O(1)

Java

    public int minOperations(int n) {
        int res = 0;
        while (n > 0) {
            if ((n & 3) == 3) {
                n++;
                res++;
            } else {
                res += n & 1;
                n >>= 1;
            }
        }
        return res;
    }

    def minOperations(self, n: int) -> int:
        res = 0
        while n > 0:
            if n % 2 == 0:
                n >>= 1
            elif (n & 2) > 0:
                n += 1
                res += 1
            else:
                res += 1
                n >>= 2
        return res

Solution 2: One Line

Reference: https://oeis.org/A007302

Here is a trick to transform multiplt 1s:

For case of single 1: 01
n = 01,
n * 2 = 10,
n * 3 = 11,
n ^ (n * 3) = 10,

For case multiple 1s: ..0011...1
n = 0011111,
n * 2 = 0111110,
n * 3 = 1011101,
n ^ (n * 3) = 1000010,

All 0011..1 turns into two 1s.

For case multiple 1s with some single 0 in the middle
n = 0011101011,
n * 2 = 0111010110,
n * 3 = 1011000001,
n ^ (n * 3) = 1000101010,

Still turns into two 1s on both side,
and the single 0s in the middle will turn into 1s.

So to conclude,
We just need to count bits of n ^ (n * 3).

Java

    public int minOperations(int n) {
        return Integer.bitCount(n ^ (n * 3));
    }

C++

    int minOperations(int n) {
        return __builtin_popcount(n ^ (n * 3));
    }

Python

    def minOperations(self, n: int) -> int:
        return (n ^ (n * 3)).bit_count()

Intuition

We are allowed to add or subtract any power of 2 to/from the number n.
Our goal is to reach 0 using the minimum number of such operations.
This should give hint that we can use DP.

check min at each step store result.

At any point, we can: Subtract the closest smaller power of 2,

or Add the closest larger power of 2.

This flexibility allows a recursive approach: from a given value of n, we recursively explore moving towards 0 using the two closest powers of 2.

Approach

We use Top-Down Dynamic Programming (DP) with memoization.

Base Case:
If n == 0, return 0 operations.

If n is already a power of 2, we only need one operation (subtract it to get 0).

Memoization: Store the results for each value of n to avoid recomputation.

Recursive Step: Compute the nearest power of 2 greater than or equal to n.
Try both options and check which minizes:

option1 (power - n)? this is how much you'd need to add to reach a power of 2.

option2 n - (power / 2) ? this is how much you'd need to subtract to go down to a power of 2.

Recurse on both, take the minimum, and add 1 for the current operation.

Complexity

  • Time complexity: O(log2 n)
    The recursion depth is up to log n, and each recursive call considers 2 options.
    Memoization prevents redundant computations.

  • Space complexity: O(log n)
    For the memoization map and recursion call stack.

Code

Java
class Solution {
    Map<Integer, Integer> memo = new HashMap<>();

    public int minOperations(int n) {
        return dp(n);
    }
    private int dp(int n) {
        
        if (n == 0) return 0;
     
        // Base case: if n is a power of 2, one operation is enough
        if ((n & (n - 1)) == 0) {
            memo.put(n, 1);
            return 1;
        }

        if (memo.containsKey(n)) return memo.get(n);

        // Find the closest power of 2
        int power = 1;
        while (power < n) {
            power <<= 1;
        }

        // Either subtract the lower power of 2 or add the upper power of 2
        int option1 = (int) dp(power - n);     // subtract to reach down to power
        int option2 = (int) dp(n - (power >> 1)); // add to reach up to next power

        int minOps = 1 + Math.min(option1, option2);
        memo.put(n, minOps);
        return minOps;
    }
    
}
