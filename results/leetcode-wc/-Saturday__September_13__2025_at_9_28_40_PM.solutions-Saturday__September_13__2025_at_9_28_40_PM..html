  1. To solve this problem, we can use a dynamic programming approach. Let's define a two-dimensional array dp where dp[i][j] represents the minimum number of operations needed to make the subarray arr1[0:i] strictly increasing, where the last element of arr1 is arr1[i], and the last element of arr2 used in the operation is arr2[j].

  2. Initially, we can set dp[i][j] to a large value or infinity for all elements in the dp array. We'll use Infinity to represent an invalid state.

  3. We'll iterate through the elements of arr1 and arr2, and for each pair of indices (i, j), we'll update dp[i][j] based on the following conditions:

  4. If arr1[i] > arr1[i-1], it means that arr1[i] is greater than the previous element in arr1, and we don't need any operations. So we can set dp[i][j] = dp[i-1][j].

  5. If arr1[i] > arr2[j], it means that we can make arr1[i] greater by assigning it the value of arr2[j]. We'll choose the minimum number of operations between the current value of dp[i][j] and dp[i-1][k] + 1, where k iterates from 0 to j-1.

  6. At the end of the iteration, we'll find the minimum number of operations needed to make the entire arr1 strictly increasing by finding the minimum value in the last row of the dp array.

  7. If there is no way to make arr1 strictly increasing, the minimum number of operations will remain as Infinity, and we'll return -1.

Instead of considering dp[][] be the minimum number of swaps required, let's think of it in another way. Let's instead consider dp[i][j] be the minimum last number of a strictly increasing sequence from 0 ... i indexes of array 1 with j swaps. The intuition is that It is in our best interest in minimizing the last number to leave more rooms for the future numbers from i+1 ... arr1.length-1.
Transitions

For each arr1[i], we have 2 options - we either swap it with an element in arr2, or we don't, but it must be greater than arr1[i-1].
Thus, we have the following transitional states:

Let a = arr1[i] if arr1[i] > arr1[i-1], else INF (don't swap)
Let b = the higher element of dp[i-1][j-1] in arr2, else INF if it does not exist (swap)
Then, dp[i][j] = min(a, b)

Where is the answer?

In the end, we loop through all dp[arr1.length-1][j] from j = 0 ... arr2.length, and the first occurrence of not INF, we return j.

class Solution {
    public int makeArrayIncreasing(int[] A, int[] B) { // A = arr1, B = arr2
        TreeSet<Integer> set = new TreeSet<>(Arrays.stream(B).boxed().toList());
        int[] dp = new int[B.length+1];
        dp[0]=-1;
        int INF = (int)2e9;
        for (int i = 0; i < A.length; i++){
            for (int j = B.length; j >= 0; j--){
                int a = A[i] > dp[j]? A[i] : INF; // option A - don't swap
                Integer b = set.higher(j==0?INF:dp[j-1]); // option B - swap
                dp[j]=Math.min(a, b==null?INF:b); // take the min of A and B
            }
        }
        for (int i = 0; i <= B.length; i++) if (dp[i] != INF){
            return i;
        }
        return -1;
    }
}

class Solution { 
    public int makeArrayIncreasing(int[] arr1, int[] arr2) {
        Arrays.sort(arr2);
        
        int answer = helper(0, -1, arr1, arr2);
        
        return answer < Integer.MAX_VALUE-100 ? answer : -1;
    }
    
    Map<Pair<Integer, Integer>, Integer> dp = new HashMap<>();
    private int helper(int i, int prev, int[] arr1, int[] arr2) {
        if (i == arr1.length) {
            return 0;
        }
        if (dp.containsKey(new Pair<>(i, prev))) {
            return dp.get(new Pair<>(i, prev));
        }

        int operation = Integer.MAX_VALUE-100;

        
        if (arr1[i] > prev) {
            operation = helper(i + 1, arr1[i], arr1, arr2);
        }

       
        int idx = binarySearch(arr2, prev);

        
        if (idx < arr2.length) {
            operation = Math.min(operation, 1 + helper(i + 1, arr2[idx], arr1, arr2));
        }

        dp.put(new Pair<>(i, prev),operation);
        return operation;
    }
    
    private static int binarySearch(int[] arr, int value) {
        int left = 0, right = arr.length-1;
        while (left <= right) {
            int mid = left+(right-left) / 2;
            if (arr[mid] <= value) {
                left = mid + 1;
            } else {
                right = mid-1;
            }
        }
        return left;
    } 
}

The difficulty of this problem lies in defining entries of DP-table properly; I have already try my best to make the explaination as clear as possible although it may look better if LaTex is supported. First of all, let me state the definition of each entry in DP-table:

dp[i][j] : minimum value of arr1[i] so that arr1[0: i] is increasing given we may perform up to j swaps; If we can not make arr1[0: i] increasing with j swaps, then dp[i][j] = MAX

Then for each dp[i][j], consider arr1[i], the last char of arr1[0: i]; As in all dynamic programming problems, we should partition the big problem disjointly to smaller problems; In this problem, for this last char arr1[i] we may either:

  1. not perform swapping on arr1[i];
  2. do perform swapping on arr1[i];

Case 1: if we do not swap arr1[i], then we need following conditions:

  1. dp[i-1][j] < MAX
    Namely, arr1[0: i-1] should be increasing with up to j swaps
  2. dp[i-1][j] < arr1[i];
    Namely arr1[i] is greater than minimum value of arr1[i-1] after up to j swaps

Case 2: if we swap on arr1[i], then we have j-1 swaps for arr1[0: i-1]; Then we need following conditions:

  1. dp[i-1][j-1] < MAX
    Namely, arr1[0: i-1] should be increasing with up to j-1 swaps
  2. swap arr1[i] into a value as small as possible
    Namely, swap arr1[i] into the least element in arr2 (if exist) so that arr1[i] is greater than dp[i-1][j-1]

Notice in case 2 we have to swap even if we will swap into a value greater than arr1[i]; This process follows strictly how we disjointly partition the bigger problem.

Following this logic, we will get a surprisingly efficient and clean Solution:

class Solution {
    public int makeArrayIncreasing(int[] arr1, int[] arr2) {
        TreeSet<Integer> set = new TreeSet<>();
        for (int i : arr2) set.add(i);
        
        int m = arr1.length;
        int p = Math.min(m, arr2.length);   // maximum # of operation we may perform;
        int[][] dp = new int[m][p + 1];
        for (int[] i : dp) Arrays.fill(i, Integer.MAX_VALUE);
        
        // Base Case: first column (0 swap)
        dp[0][0] = arr1[0];
        for (int i = 1; i < m; i++) {
            if (arr1[i] <= arr1[i-1]) break;
            dp[i][0] = arr1[i];
        }
        
        // Base Case: first row (only 1 character)
        for (int j = 1; j <= p; j++) {
            dp[0][j] = Math.min(arr1[0], set.first());
        }
        
       
        for (int i = 1; i < m; i++) {
            for (int j = 1; j <= Math.min(i+1, p); j++) {
              
                // not swap at i
                if (arr1[i] > dp[i-1][j]) dp[i][j] = arr1[i];   // handle the case dp[i-1][j] == MAX
                
                // swap at i
                if (dp[i-1][j-1] == Integer.MAX_VALUE) continue;  // this line will speed up the solution
                
                Integer temp = set.higher(dp[i-1][j-1]);
                if (temp != null) {
                    dp[i][j] = Math.min(dp[i][j], temp);
                }
            }
        }
        
        // check result for arr1 := arr1[0: m-1]
        for (int i = 0; i <= p; i++) {
            if (dp[m-1][i] != Integer.MAX_VALUE) return i;
        }
        return -1;
    }
}

The solution above can be easily optimized into an O(min(m, n))-Space Solution like similar Dynamic Programming algorithms:

class Solution {
    public int makeArrayIncreasing(int[] arr1, int[] arr2) {
        TreeSet<Integer> set = new TreeSet<>();
        for (int i : arr2) set.add(i);
        
        int m = arr1.length;
        int p = Math.min(m, arr2.length);   // maximum # of operation we may perform;
        
        // Base Case: first row (first char)
        int[] dp = new int[p + 1];
        dp[0] = arr1[0];
        for (int j = 1; j <= p; j++) {
            dp[j] = Math.min(arr1[0], set.first());
        }
       
        for (int i = 1; i < m; i++) {
            int[] next = new int[p+1];
            Arrays.fill(next, Integer.MAX_VALUE);
            
            if (arr1[i] > arr1[i-1] && dp[0] != Integer.MAX_VALUE) next[0] = arr1[i];
            
            for (int j = 1; j <= p; j++) {
                if (arr1[i] > dp[j]) next[j] = arr1[i];       // not swap at i
                
                if (dp[j-1] == Integer.MAX_VALUE) continue;   // swap at i
                Integer temp = set.higher(dp[j-1]);
                if (temp != null) {
                    next[j] = Math.min(next[j], temp);
                } 
            }
            
            dp = next;
        }
        
        for (int i = 0; i <= p; i++) {
            if (dp[i] != Integer.MAX_VALUE) return i;
        }
        return -1;
    }
}
