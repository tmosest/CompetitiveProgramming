? Problem Story (Easy Version)

Read it slowly, line by line — you’ll get a clear, deep understanding. Trust me ?

You’re stuck in a grid city ??.

  • Every cell has a cost to step on (like a toll gate ?).
  • Moving to the next row also has a portal fee (given by moveCost) ??.

Your job:

  • Start from any cell in the first row
  • Move down row by row
  • Pay the cell cost + move cost each time
  • Reach the bottom with the least total cost — without selling your kidneys ?

or
? Goal -> Find the minimum total cost path from top to bottom.

? Intuition ( Why DP? )

At each cell (r,c), you can move to any cell in the next row with a cost.
Multiple paths overlap by reaching the same future cells ? classic overlapping subproblems.

The cost from (r,c) depends on the minimum cost from the next row's possible moves (optimal substructure).

Brute-force would be exponential.
DP lets us cache and reuse results for each (r,c), cutting time to O(m * n2).

GOLDEN Rule:?
If a problem has choices, overlapping subproblems,
and you need min/max/sum over paths — it screams DP.

? DP State:

f(r, c) = minimum cost from cell (r, c) to the bottom.

  • From (r, c), you can jump to any (r+1, i), pay moveCost[nums[r][c]][i], and move.
  • Base Case: At the last row? Just pay the cell value and chill.

Diagram to Understand Better

Edit : For every (row, col) you need call n (no of columns) times

? Time & Space Complexity

  • Time: O(m * n2) ? for each cell, try n moves for m rows.
  • Space: O(m * n) ? for the DP table.

class Solution {
    int[][] nums, moves;
    Integer[][] dp;

    public int minPathCost(int[][] grid, int[][] moveCost) {
        nums = grid;
        moves = moveCost;
        dp = new Integer[nums.length][nums[0].length];
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < nums[0].length; i++) {
            ans = Math.min(ans, f(0, i));
        }
        return ans;
    }

    int f(int r, int c) {
        if (r == nums.length - 1) return nums[r][c];
        if (dp[r][c] != null) return dp[r][c];

        int min = Integer.MAX_VALUE;
        for (int i = 0; i < nums[0].length; i++) {
            int move = moves[nums[r][c]][i];
            min = Math.min(min, move + f(r + 1, i));
        }
        return dp[r][c] = nums[r][c] + min;
    }
}

class Solution {
    public int minPathCost(int[][] nums, int[][] moves) {
        int m = nums.length, n = nums[0].length;
        int[][] dp = new int[m][n];

        // Initialize last row costs (no moves from here)
        for (int c = 0; c < n; c++) dp[m - 1][c] = nums[m - 1][c];

        // Fill from second-last row to top
        for (int r = m - 2; r >= 0; r--) {
            for (int c = 0; c < n; c++) {
                dp[r][c] = Integer.MAX_VALUE;
                for (int i = 0; i < n; i++) {
                    int move = moves[nums[r][c]][i];
                    dp[r][c] = Math.min(dp[r][c], nums[r][c] + move + dp[r + 1][i]);
                }
            }
        }

        int ans = Integer.MAX_VALUE;
        for (int c = 0; c < n; c++) ans = Math.min(ans, dp[0][c]);
        return ans;
    }
}

Intuition

Given m = grid.length, n = grid[0].length

the min path cost of grid[i][j] is the minimum of
(1) min path cost of previous grid, plus
(2) cost to move from previous grid to current grid), plus
(3) current grid value

note: current grid is grid[i][j], previous grid is grid[i-1][k] where k = [0, n-1]

Steps

Given dp[i][j] is the min path cost of grid[i][j]
we have the formula:

prev = grid[i-1][k]
dp[i][j] = min(dp[i-1][k] + cost[prev][j] + grid[i][j]) where k is [0,n-1]

base case: dp[0][j] = grid[0][j]

then, the result is min(dp[m-1])

Complexity

time: O(mn^2)
space: O(mn)

public int minPathCost(int[][] grid, int[][] moveCost) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    dp[0] = grid[0];

    for (int i = 1; i < m; i++) {
        for (int j = 0; j < n; j++) {
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = 0; k < n; k++) {
                int cur = grid[i][j], prev = grid[i - 1][k];
                int cost = dp[i - 1][k] + moveCost[prev][j] + cur;
                dp[i][j] = Math.min(dp[i][j], cost);
            }
        }
    }

    int res = Integer.MAX_VALUE;
    for (int i = 0; i < n; i++) {
        res = Math.min(res, dp[m - 1][i]);
    }
    return res;
}

Approach

  1. Recursive :
  • Stand at each column in the first row and move to each column in the next row. Repeat the process recursively for each row.
  1. Tabulation :
  • Stand at each column in the second last row and move to each column in the next row. Repeat the process iteratively for each row.
  1. Tabulation + Space Optimization :
  • No need of 2d Array/vector, two 1D space is enough since we need only current row and the next row in the table

typedef vector<vector<int>> vvi;
class Solution {
private:
    int fun(int idx, int jdx, int m, int n, vvi& grid, vvi& moveCost){
        // base case
        if(idx==m-1) return grid[idx][jdx];

        // explore all paths i.e. move in every column from 0 to n
        int ans = (int)1e9;
        for(int j=0;j<n;j++){
            int x = grid[idx][jdx];
            int cur_cost = moveCost[x][j];
            ans = min(ans, fun(idx+1, j, m, n, grid, moveCost) + cur_cost + x);
        }

        return ans;
    }

        }
        return ans;

class Solution {
public:
    int minPathCost(vvi& grid, vvi& moveCost) {
        int mini = 1e9, m = grid.size(), n = grid[0].size();
        vector<int> next(m+1);

        // base case handling
        for(int j=0;j<n;j++) next[j] = grid[m-1][j];

        for(int idx=m-2; idx>=0; idx--){
            vector<int> cur(n+1);

                    ans = min(ans, next[j] + cur_cost + x);
                }
                cur[jdx] =  ans;
                if(idx==0) mini = min(mini, ans);
            }
            next = cur;
        }

        return mini;
    }
};

Intuition

The problem is a classic dynamic programming problem where we need to find the minimum cost path from any cell in the first row to any cell in the last row. The key insight is that for each cell, we need to consider both the value of the cell itself and the cost of moving to it from the previous row. Since we can move to any column in the next row, we need to try all possible transitions and keep track of the minimum cost.

Approach

  1. Create a 2D DP array where dp[i][j] represents the minimum cost to reach cell (i, j) in the grid
  2. Initialize first row of DP array with the values from first row of grid
  3. For each row (except last):
    • For each cell in current row:
      • For each cell in next row:
        • Calculate total cost = current dp value + next cell value + move cost
        • Update minimum cost in dp[next_row][next_col]
  4. The final answer is the minimum value in the last row of the DP array

Complexity

  • Time Complexity: O(n*m2), where n is the number of rows and m is the number of columns. We need to try all m possible transitions for each cell in the grid.

    • For each row (n - 1 rows)
    • For each cell in current row (m cells)
    • For each possible next column (m possibilities)

  • Space Complexity: O(n * m) to store the DP array. We need to keep track of minimum costs for each cell in the grid.

class Solution {
    fun minPathCost(grid: Array<IntArray>, moveCost: Array<IntArray>): Int {
        val n = grid.size
        val m = grid.first().size
        val dp = Array(n) { IntArray(m) { Int.MAX_VALUE } }
        System.arraycopy(grid[0], 0, dp[0], 0, m)
        for (i in 0..<(n - 1)) {
            for (j in 0..<m) {
                for (k in 0..<m) {
                    dp[i + 1][k] = min(
                        dp[i + 1][k],
                        dp[i][j] + grid[i + 1][k] + moveCost[grid[i][j]][k]
                    )
                }
            }
        }
        return dp.last().min()
    }
}
