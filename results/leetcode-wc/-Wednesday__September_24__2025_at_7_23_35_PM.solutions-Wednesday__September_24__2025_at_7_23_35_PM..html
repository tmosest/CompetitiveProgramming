Approach 1: Binary Search

We remember the position of each candle. Then, we binary-search for the leftmost (first) and rightmost (last) candle for each query.

Now, we know how many total items are between the first and last candle, and how many candles are there.

The time complexity of this solution is O(n log m), where n is the number of queries, and m - the length of the string.

C++

vector<int> platesBetweenCandles(string s, vector<vector<int>>& queries) {
    vector<int> c, res;
    for (int i = 0; i < s.size(); ++i)
        if (s[i] == '|')
            c.push_back(i);
    for (auto &q : queries) {
        auto it_l = lower_bound(begin(c), end(c), q[0]);
        auto it_r = it_l == end(c) ? it_l : prev(upper_bound(it_l, end(c), q[1]));
        res.push_back(it_l < it_r ? *it_r - *it_l - (it_r - it_l) : 0);
    }
    return res;
}

Approach 2: Prefix Sum

We can count candles between two positions in O(1) using a prefix sum array dp. Before we can do that, we need to find the leftmost (first) and rightmost (last) candle for each query.

We can also do it in O(1) by tracking next and prev candle for each position on the table.

The time complexity of this solution is O(n + m), where n is the number of queries, and m - the length of the string.

C++

vector<int> platesBetweenCandles(string s, vector<vector<int>>& queries) {
    vector<int> psum(s.size() + 1), next(s.size() + 1, INT_MAX), prev(s.size() + 1), res;
    for (int i = 0; i < s.size(); ++i) {
        psum[i + 1] = psum[i] + (s[i] == '|');
        prev[i + 1] = s[i] == '|' ? i : prev[i];
    }
    for (int i = s.size() - 1; i >= 0; --i)
        next[i] = s[i] == '|' ? i : next[i + 1];
    for (auto &q : queries) {
        int l = next[q[0]], r = prev[q[1] + 1];
        res.push_back(l < r ? r - l - (psum[r] - psum[l]) : 0);
    }
    return res;
}

Java

public int[] platesBetweenCandles(String s, int[][] queries) {
    int psum[] = new int[s.length() + 1];
    int next[] = new int[s.length() + 1], prev[] = new int[s.length() + 1];
    Arrays.fill(next, Integer.MAX_VALUE);
    int res[] = new int[queries.length];
    for (int i = 0; i < s.length(); ++i) {
        psum[i + 1] = psum[i] + (s.charAt(i) == '|' ? 1 : 0);
        prev[i + 1] = s.charAt(i) == '|' ? i : prev[i];
    }
    for (int i = s.length() - 1; i >= 0; --i)
        next[i] = s.charAt(i) == '|' ? i : next[i + 1];
    for (int j = 0; j < queries.length; ++j) {
        int l = next[queries[j][0]], r = prev[queries[j][1] + 1];
        res[j] = l < r ? r - l - (psum[r] - psum[l]) : 0;
    }        
    return res;
}

class Solution:
    def platesBetweenCandles(self, s: str, queries: List[List[int]]) -> List[int]:
        psum, next, prev = [0] * (len(s) + 1), [inf] * (len(s) + 1), [0] * (len(s) + 1)
        res = []
        for i, ch in enumerate(s):
            psum[i + 1] = psum[i] + (ch == '|')
            prev[i + 1] = i if ch == '|' else prev[i]
        for i, ch in reversed(list(enumerate(s))):
            next[i] = i if ch == '|' else next[i + 1]
        for q in queries:
            l, r = next[q[0]], prev[q[1] + 1]
            res.append(r - l - (psum[r] - psum[l]) if l < r else 0)
        return res

Intuition

The goal is to count the number of plates ('*') that lie between two candles ('|') for each query range [left, right]. A plate is only counted if there is at least one candle to its left and one to its right within the query range.

  1. Instead of scanning the string for each query (which would be inefficient), we preprocess the string to:

    • Store the indices of all candles.

    • Build a prefix sum of plates to quickly count plates between any two indices.

  2. Then, for each query:

    • Use binary search to find the leftmost candle ³ left and rightmost candle ² right.

    • Use the prefix sum to compute the number of plates between these two candle positions.

Approach

  1. Preprocessing

    • Traverse the string once:

      • Store indices of all candles in a list.

      • Build a prefix sum array of plates.

  2. Binary Search

    • For each query:

      • Use binary search to find the first candle ³ left (getLeftMostCandle)

      • Use binary search to find the last candle ² right (getRightMostCandle)

      • If valid candles are found and leftCandle < rightCandle, use the prefix sum to count plates between them.

  3. Answer Construction

    • Store the result for each query in an output array.

Complexity

  • Time complexity:
Let:

n = length of string s

q = number of queries

m = number of candles in the string

? Preprocessing:

O(n) to build prefixOfPlates and candlesIdx

? Per Query:

Each binary search: O(log m)

Plate count using prefix sum: O(1)

Total per query: O(log m)

?Overall:

Time = O(n + q * log m)

  • Space complexity:

      O(n) for prefixOfPlates

  O(m) for candlesIdx

  O(q) for ans

    ?Overall:

      Space = O(n + m + q)

class Solution {
    private int getLeftMostCandle(List<Integer> candles, int left, int right) {
        int low = 0, high = candles.size() - 1;
        while(low <= high) {
            int mid = (low+high)/2;
            if(candles.get(mid) < left) {
                low = mid + 1;
            }
            else {
                high = mid - 1;
            }
        }
        return (low < candles.size() && candles.get(low) <= right) ? candles.get(low) : -1;
    }
    private int getRightMostCandle(List<Integer> candles, int left, int right) {
        int low = 0, high = candles.size() - 1;
        while(low <= high) {
            int mid = (low + high) / 2;
            if(candles.get(mid) > right) {
                high = mid - 1;
            }
            else {
                low = mid + 1;
            }
        }
        return (high >= 0 && candles.get(high) >= left) ? candles.get(high) : -1;
    }
    public int[] platesBetweenCandles(String s, int[][] queries) {
        int n = s.length();
        int[] prefixOfPlates = new int[n];
        int sum = 0;
        List<Integer> candlesIdx = new ArrayList<>();
        for(int i = 0; i < n; i++) {
            if(s.charAt(i) == '|') candlesIdx.add(i);
            sum += (s.charAt(i) == '*' ? 1 : 0);
            prefixOfPlates[i] = sum;
        }
        int q = queries.length;
        int idx = 0;
        int[] ans = new int[q];
        for(int i = 0; i < q; i++) {
            int left = queries[i][0];
            int right = queries[i][1];
            
            int leftMost = getLeftMostCandle(candlesIdx, left, right);
            int rightMost = getRightMostCandle(candlesIdx, left, right);
            
            int leftCandle = leftMost == -1 ? left : leftMost;
            int rightCandle = rightMost == -1 ? left : rightMost;
            
            ans[idx++] = prefixOfPlates[rightCandle] - prefixOfPlates[leftCandle];
        }
        return ans;
    }
}

Intuition

I kept my thinking simple and straight forward:
for each query (x, y), I need know the position of the first candle to the right of x and first candle to the left of y, and the finally number of plates in between.

Approach

I calculate and store 3 pieces of informations before starting to check queries, which are:

  1. an array int[] starPrefix that stores the number of * before the index i including the * at index i.
  2. an array int[] pipeLeftDistance that stores the distance of the first pipe to the left of the index i. I store -1 if there's no pipe to the left, 0 if the pipe is present at index i. E.g. input = "**||****||*" then pipeLeftDistance = [-1, -1, 0, 0, 1, 2, 3, 4, 0, 0, 1]
  3. an array pipeRightDistance that stores the distance of the first pipe to the right of the index j, I store -1 if there's no pipe to the rifht, 0 if the pipe is present at index j. E.g. input = "**||****||*" then pipeRightDistance = [2, 1, 0, 0, 4, 3, 2, 1, 0, 0, -1]

Then for each query queries[i][0, 1] do the following:

  1. find the index pipeAfterX of the first pipe to the right of x = queries[i][0] using int[] pipeRightDistance
  2. find the index pipeBeforeY of the first pipe to the left of y = queries[i][1] using int[] pipeLeftDistance
  3. if either of the indices is -1 then I save the answer as 0
  4. otherwise, I find the number of plates between pipeAfterX and pipeBeforeY using int[] starPrefix, and save it in the answer

Complexity

  • Time complexity: O(n+q)
  • Space complexity: O(n)

Code

class Solution {
    public int[] platesBetweenCandles(String s, int[][] queries) {
        int n = s.length();
        char[] chars = s.toCharArray();
        int[] starPrefix = new int[n]; //storing plates before index i
        int[] pipeLeftDistance = new int[n]; //storing the distance of next pipe
        int[] pipeRightDistance = new int [n]; //storing the distance of previous pipe
        int starCount = 0, lastLeft = -1, lastRight = -1;
        for(int i = 0, j = n - 1; i < n; i++, j--) {
            if(chars[i] == '*'){
                starPrefix[i] = i > 0 ? starPrefix[i - 1] + 1 : 1; //boundary check and saving the incremented number of plates
                if(lastLeft >= 0) lastLeft++; //increment the distance by one since we're moving further away from the last pipe to the left
            } else {
                starPrefix[i] = i > 0 ? starPrefix[i - 1] : 0; //boundary check, and saving the number of plates without incrementing
                lastLeft = 0; //pipe found at the index, so resetting distance to 0
                pipeLeftDistance[i] = 0;//saving distance of the last Left pipe
            }
            pipeLeftDistance[i] = lastLeft; //saving distance of the last left pipe, after incrememting, in case * was found

            //doing the same thing for the right, from the other end of the array
            if(chars[j] == '*'){
                if(lastRight >= 0) lastRight++;
            } else {
                lastRight = 0;
                pipeRightDistance[j] = 0;
            }
            pipeRightDistance[j] = lastRight;
        }
        
        int[] ans = new int[queries.length];
        for(int i = 0; i < queries.length; i++){ //for each query
            int x = queries[i][0], y = queries[i][1]; //start x, end y
            if(pipeRightDistance[x] == -1 || pipeLeftDistance[y] == -1) { //if no pipe pipe pair found 
                ans[i] = 0;
                continue;
            }
            int pipeAfterX = x + pipeRightDistance[x]; //index of first pipe to the right of x
            int pipeBeforeY = y - pipeLeftDistance[y]; //index of first pipe to the left of y
            if(pipeAfterX <= y && pipeBeforeY >= x) { //boundary check
                ans[i] = starPrefix[pipeBeforeY] - starPrefix[pipeAfterX]; //number of plates in between
            } else ans[i] = 0;
        }
        return ans;
    }
}
