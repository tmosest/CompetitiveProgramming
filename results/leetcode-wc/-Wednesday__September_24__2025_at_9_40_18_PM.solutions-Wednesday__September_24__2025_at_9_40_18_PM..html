class Solution {
public:
    int evenNumberBitwiseORs(vector<int>& nums) {
        int result = 0;
        for (int i = 1; i <= 6; i++) {
            for (int num : nums) {
                if ((~num & 1) & ((num >> i) & 1)) {
                    result |= (1 << i);
                    break;
                }
            }
        }
        return result;
    }
};

Performing a bitwise OR on each even element is Trivial, and if there are many elements, it can be very inefficient.

Here is a better solution:

We take advantage of the fact that In a bitwise OR, any bit set to 1 cannot be reverted to 0.

  • In the worst case, we iterate each elements of nums up to the number of bits.
  • However, in the best case, we can stop as soon as we see a SET BIT at each position.
    • SO IF THERE ARE 100?s or even billions of elements, we only to iterate 6 set bits!

Given:

  • Excluding the LSB, so we only need 6.
