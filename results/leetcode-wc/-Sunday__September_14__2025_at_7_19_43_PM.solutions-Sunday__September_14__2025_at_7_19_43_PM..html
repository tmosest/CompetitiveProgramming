Intuition

In any graph, the sum of all node degrees is always even. To make every node's degree even, we only need to focus on the nodes that currently have odd degree.

  • If no nodes have odd degree ? already valid.
  • If 2 nodes have odd degree ? we need to connect them directly, or via an intermediate node.
  • If 4 nodes have odd degree ? we need to pair them into two disjoint edges.
  • Otherwise (>4 odd nodes) ? impossible with at most 2 edges.

This reduces the problem to checking connectivity constraints between a small set of odd-degree nodes.

Approach

  1. Build adjacency sets: Use a hash map (or set per node) to quickly check if an edge already exists.

  2. Find odd-degree nodes: Traverse all nodes and collect those with odd degree.

  3. Check cases:

    • 0 odd nodes ? return true.

    • 2 odd nodes (a, b) ?

      • If a and b are not directly connected ? add edge ? return true.
      • Else, check if there exists any node c that is not connected to both ? (a, c) and (b, c) ? return true.

    • 4 odd nodes (a, b, c, d) ? check if they can be paired without existing edges (try all 3 pairings).

    • Otherwise ? return false.

Complexity

  • Time complexity:

    • Building adjacency: O(m) where m = edges.length.
    • Checking odd nodes: O(n).
    • Edge checks: constant-time O(1) using sets.
    • Overall: O(n + m).

  • Space complexity:

    • Adjacency list: O(n + m).
    • Odd-degree nodes: at most 4.
    • Overall: O(n + m).

from collections import defaultdict
from typing import List

class Solution:
    def isPossible(self, n: int, edges: List[List[int]]) -> bool:
        # Build adjacency sets
        g = defaultdict(set)
        for a, b in edges:
            g[a].add(b)
            g[b].add(a)

        # Find nodes with odd degree
        odd_nodes = [i for i in range(1, n + 1) if len(g[i]) % 2 == 1]

        # Case 0: all degrees even
        if len(odd_nodes) == 0:
            return True

        # Case 2: try direct edge or via another node
        if len(odd_nodes) == 2:
            a, b = odd_nodes
            if b not in g[a]:
                return True
            for c in range(1, n + 1):
                if c not in (a, b) and a not in g[c] and b not in g[c]:
                    return True
            return False

        # Case 4: try all pairings
        if len(odd_nodes) == 4:
            a, b, c, d = odd_nodes
            return ((b not in g[a] and d not in g[c]) or
                    (c not in g[a] and d not in g[b]) or
                    (d not in g[a] and c not in g[b]))

        # Otherwise impossible
        return False

Result

This solution correctly determines whether it is possible to add at most two edges so that all nodes in the graph have even degrees.
