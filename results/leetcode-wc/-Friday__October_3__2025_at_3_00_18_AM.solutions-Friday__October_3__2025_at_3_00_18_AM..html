Intuition

The first observation is we can ignore meetings of the robots because the meeting robots will continue their journey and we don't care about the robot ids.

The second trick is to avoid O(n^2) complexity for sum distance of all pairs.

Eplanation of the line long curr = i * (long)nums[i] - (n - 1 - i) * (long)nums[i]

Note1: let's use long to avoid integer overflow.

Note2: Let's take a look on the example {1,2,3}. All pairs sums will be:
(1,2) + (1,3) + (2,3) = 2 - 1 + 3 - 1 + 3 - 2. So, we use each number in the array n - 1 times. We substtract the number if it is less in the pair (i, j), once array is sorrted it means i number will be bigger (added to sum) i times and less (substructed from the sum) n - 1 - i times.
General formula per number: nums[i] * i - nums[i] * (n - 1 - i);

Note3: the array is sorted, so we always substtruct big numbers less then add big number. So we don't car about abs. The example arr {-2, -1} is (-2, -1) = -2 * 0 - -2 + -1 - -1 * 0 = 2 - 1 = 1

Complexity

  • Time complexity: O(nlogn)
  • Space complexity: O(1)

Code

class Solution {
    public int sumDistance(int[] nums, String s, int d) {
        final int mod = 1_000_000_007;
        for (int i=0; i<nums.length; i++) {
            nums[i] += d * (s.charAt(i) == 'R' ? 1 : -1);
        }
        
        Arrays.sort(nums);
        long sum = 0;
        int n = nums.length;
        for (int i=0; i<n; i++) {
            long curr = i * (long)nums[i] - (n - 1 - i) * (long)nums[i];
            sum += curr;
            sum %= mod;
        }   
        
        return (int) sum ;
    }
}

The logic behind : i*arr[i] - (n-1-i)*arr[i] in calculating Sum of absolute differences of all pairs in a given array:

Let's take an example: [1,2,3,4,5] (After Sorting) (n = no. of elements = 5)

Sum of absolute differences of all pairs in a given array:

(2-1) + (3-1) + (4-1) + (5-1) +
(3-2) + (4-2) + (5-2) +
(4-3) + (5-3) +
(5-4)

= 20

We can write it as:

1x0 + (-1x4) +
2x1 + (-2x3) +
3x2 + (-3x2) +
4x3 + (-4x1) +
5x4 + (-5x0)

which is equal to

1x0 - (1x4) + (i=0 , n-1-i = 4)
2x1 - (2x3) + (i=1 , n-1-i = 3)
3x2 - (3x2) + (i=2 , n-1-i = 2)
4x3 - (4x1) + (i=3 , n-1-i = 1)
5x4 - (5x0) (i=4 , n-1-i = 0)

resulting in 20

  • Time complexity: O(nlogn)

class Solution {
    static int mod = (int)(1e9 + 7);
    public int sumDistance(int[] arr, String s, int d) {
        int n = arr.length;
        
        for(int i=0;i<n;i++){
            if(s.charAt(i)=='R'){
                arr[i]+=d;
            }
            else{
                arr[i]-=d;
            }
        }

        Arrays.sort(arr);

        long sum = 0;
        
        for(int i = 0; i < n; i++) {
            sum = (sum + i*(long)arr[i] - (n-1-i)*(long)arr[i])%mod;
        }
 
        return (int)sum;
    }
}

Intuition

We can ignore the collision, since all robots are same, we can't distinct each other. The robots just keep walking with collision.

Similar problem: https://leetcode.com/problems/last-moment-before-all-ants-fall-out-of-a-plank/

Approach

Sort the final position of all robots and use prefix sum to save time.

The position is sorted(pi-1?<=pi?), so we can use prefix sum.

d=?pi?-p0??+?pi?-p1??+...+?pi?-pi-1??
=(pi?-p0?)+(pi?-p1?)+...+(pi?-pi-1?)
=i*pi?-(p0?+p1?+...+pi-1?)
=i*pi?-·j=0i-1?pj?

Complexity

  • Time complexity: O(N*logN)
  • Space complexity: O(N)

Code

class Solution {
  public int sumDistance(int[] nums, String s, int d) {
    final int modulo = (int) 1e9 + 7;
    final int n = nums.length;
    long[] position = new long[n];
    for (int i = 0; i < n; i++) {
      position[i] = (s.charAt(i) == 'L' ? -1L : 1L) * d + nums[i];
    }

    Arrays.sort(position);
    long distance = 0;
    long prefix = 0;
    for (int i = 0; i < n; i++) {
      distance = (distance + (i * position[i] - prefix)) % modulo;
      prefix += position[i];
    }

    return (int) distance;
  }
}
