? Understanding The Problem

  • We're given a string s and an integer t.
  • We need to perform t operations on s where in one operation we change each characters from [a...y] changes to its next character, that is,
    • a ? b, b ? c, c ? d and so on...
    • When we reach the end or encounter a 'z', it changes to ab.
  • For example : if s = abcyy & t = 2,

? Using Simulation

  • We do not need to create the string directly in t operations as said in the problem as that would be too time expensive.
  • Instead we simulate the process of the length increasing by tracking the frequencies of each letter in the string s.

? Implementation

const int mod = 1e9 + 7;
int mod_add(int a, int b) {a = a % mod; b = b % mod; return (((a + b) % mod) + mod) % mod;}

class Solution {
public:
    int lengthAfterTransformations(string s, int t) {
        int nums[26] = {0};
        for (char ch : s) nums[ch - 'a']++;
        while (t--) {
            int cur[26] = {0};
            for (int j = 0; j < 26; j++) {
                if (j == 25 && nums[j] > 0) {
                    cur[0] = mod_add(cur[0], nums[j]);
                    cur[1] = mod_add(cur[1], nums[j]);
                } else {
                    if (j < 25) cur[j + 1] = mod_add(cur[j + 1], nums[j]);
                }
            }
            for (int j = 0; j < 26; j++) nums[j] = cur[j];
        }
        int ans = 0;
        for (int i : nums) ans = mod_add(ans, i);
        return (int)ans;
    }
};

? Using DP

  • We now use dynamic programming to optimize this further in terms of time complexity.

1?? Step 1 ? Initializing dp array & observing recurrence

C++
Python
Java
vector <int> dp(t + 26);
for (int i = 0; i < 26; i++)
    dp[i] = 1;
for (int i = 26; i < t + 26; i++)
    dp[i] = (dp[i - 26] + dp[i - 25]) % mod;
  • We maintain a dp array where,
    • dp[i] : numbers of characters we get if we start from 'a' and apply i transformations.
  • And there are 2 cases for i here,
    • When i < 26 : We never hit 'z' so dp[i] = 1.
    • When i >= 26 : the last shift can be
      • Transforming a non - 'z' letter ? contributes dp[i - 25]
      • Splitting a 'z' ? contributes dp[i - 26] twice
    • So the recurrence we observe here is :
      • dp[i] = (dp[i – 26] + dp[i – 25]) % mod

2?? Step 2 ? Resizing dp array

C++
Python
Java
for (char ch : s) 
    ans = (ans + dp[ch - 'a' + t]) % mod;
  • Any character ch originally has position (ch - 'a')
  • So we apply t extra shifts on it and get total shifts = (ch - 'a') + t
  • Therefore the maximum size of dp array we need here is (t + 26)

? String Transformation: Detailed Explanation & Optimization

1?? Problem Description

Given a string s and integer t, perform exactly t transformations. In each transformation, every character moves:

  • 'a'–'y' ? replaced by next letter (e.g. 'a'?'b').
  • 'z' ? replaced by "ab" (length +1).

Return the length of the resulting string modulo 10^9+7.

Example:

s = "abcyy", t = 2
  • Step 1: "abcyy" ? "bcdzz"
  • Step 2: "bcdzz" ? "cdeabab" ("z"?"ab")
    Final length = 7

2?? Intuition & First (Naïve) Solution

Instead of building the string, track frequencies of each letter ('a'?index0 … 'z'?index25).

In one step:

  • For 0≤i<25: all freq[i] move to i+1.
  • For i=25: all freq[25] split into +1 at index0 and +1 at index1.

Thus:

for (int step=0; step<t; step++) {
  int[] temp = new int[26];
  // shift a?b, b?c, …, y?z
  for (int j=0; j<25; j++) temp[j+1] = freq[j];
  // z?"ab"
  temp[0] = (temp[0] + freq[25]) % MOD;
  temp[1] = (temp[1] + freq[25]) % MOD;
  freq = temp;
}
  • After t loops, length = sum of freq[].

3?? Populating temp[] in First Solution

int[] freq = new int[26];  // initial counts
for (char c : s.toCharArray()) freq[c-'a']++;
for (int i=0; i<t; i++) {
  int[] temp = new int[26];
  for (int j=0; j<25; j++) temp[j+1] = freq[j];
  temp[0] = (temp[0] + freq[25]) % MOD;
  temp[1] = (temp[1] + freq[25]) % MOD;
  freq = temp;
}

This exactly shifts counts and handles the special 'z' case.

4?? Final Length Calculation (First Solution)

After the loop:

long ans = 0;
for (int x : freq) ans = (ans + x) % MOD;
return (int)ans;

class Solution {
  private static final int MOD = 1_000_000_007;
  public int lengthAfterTransformations(String s, int t) {
    int[] freq = new int[26];
    for (char c : s.toCharArray()) freq[c-'a']++;
    while (t-- > 0) {
      int[] temp = new int[26];
      for (int j=0; j<25; j++) temp[j+1] = freq[j];
      temp[0] = (temp[0] + freq[25]) % MOD;
      temp[1] = (temp[1] + freq[25]) % MOD;
      freq = temp;
    }
    long ans=0;
    for (int x: freq) ans=(ans+x)%MOD;
    return (int)ans;
  }
}

8?? Optimization Idea

Observation: 26 transformations cycle letters:

a?b?c?...?z?a,b (split)

So batch 26 steps at once when t >= 26, instead of one-by-one.

9?? Batch Update Logic (Second Solution)

while (t >= 26) {
  int[] temp = new int[26];
  for (int i=0; i<25; i++) {
    temp[i]   = (temp[i]   + freq[i]) % MOD;  // cycle retains
    temp[i+1] = (temp[i+1] + freq[i]) % MOD;  // shift
  }
  // z ? remains + splits
  temp[25] = (temp[25] + freq[25]) % MOD;
  temp[0]  = (temp[0]  + freq[25]) % MOD;
  temp[1]  = (temp[1]  + freq[25]) % MOD;
  freq = temp;
  t -= 26;
}

This applies all 26 single-step transformations in one pass.

? Final Steps When

For remaining t (<26), each letter only moves at most t positions forward.
If a letter’s index + t ≥ 26 (i.e., it reaches or crosses 'z'), it splits into two characters: 'a' and 'b'.

? Why Does Frequency Double?

When a letter like 'z' transforms after 26 steps, the rule says:

  • 'z' ? 'a' and 'b'

So each occurrence of 'z' leads to 2 new characters instead of 1 — hence, frequency doubles.

? Example

Suppose we have:

  • Input: "y" (i.e., freq['y'] = 1)
  • t = 3
  • Index of 'y' = 24 ? 24 + 3 = 27 ? **crosses **``

After transformation:

  • 'y' ? 'z'
  • 'z' ? 'a', 'b'
    So 'y' eventually results in two characters, hence its frequency is doubled.

1??1?? Example Walkthrough (Optimized)

Example: s = "az", t = 55

? Step 1: Initial Frequency

'a' ? 1 'z' ? 1 
Initial freq: [a->1, z->1]

? Step 2: First Batch (t -= 26)

We process one full cycle:

  • 'a' ? 'a','b'
  • 'z' ? 'z','a','b' (wrap-around case)
'a' ? 1 (from 'a') + 1 (from 'z') = 2
'b' ? 1 (from 'a') + 1 (from 'z') = 2
'z' ? 1 (unchanged)
After 1st batch: [a->2, b->2, z->1]

? Step 3: Second Batch (t -= 26)

Process another cycle:

  • 'a' ? 'a','b'
  • 'b' ? 'b','c'
  • 'z' ? 'z','a','b'
'a' ? 2 (from 'a') + 1 (from 'z') = 3
'b' ? 2 (from 'a') + 2 (from 'b') + 1 (from 'z') = 5
'c' ? 2 (from 'b')
'z' ? 1 (unchanged)
After 2nd batch: [a->3, b->5, c->2, z->1]

t is now reduced to 3.

? Step 4: Final 3 Steps (t < 26)

Now we apply remaining t = 3 steps:

  • 'a' ? 'd' in 3 steps (no wrap, no special addition)
  • 'b' ? 'e' in 3 steps
  • 'c' ? 'f' in 3 steps
  • 'z' ? crosses 26 boundary ? add freq to 'a' and 'b'

? Final Result:

Total number of characters after t = 55 transformations:

Total = 4 (a) + 6 (b) + 2 (c) = 12

class Solution {
    static int MOD = 1000000007;

    static public int lengthAfterTransformations(String s, int t) {
        char[] arr = s.toCharArray();
        int n = arr.length;
        int[] freq = new int[26];
        for (int i = 0; i < n; i++) {
            freq[arr[i] - 'a']++;
        }

        while (t >= 26) {
            int[] temp = new int[26];
            for (int j = 0; j < 25; j++) {
                temp[j + 1] = (freq[j] + temp[j + 1]) % MOD;
                temp[j] = (temp[j] + freq[j]) % MOD;
            }
            temp[25] = (temp[25] + freq[25]) % MOD;
            temp[0] = (temp[0] + freq[25]) % MOD;
            temp[1] = (temp[1] + freq[25]) % MOD;
            freq = temp;
            t -= 26;
        }

        int ans = 0;
        for (int i = 0; i < 26; i++) {
            int diff = 26 - i;
            if (t >= diff) {
                freq[i] = (2 * freq[i]) % MOD;
            }
            ans = (ans + freq[i]) % MOD;
        }

        return ans;
    }
}

? Intuition

Each character in the string can transform over t steps:

  • Characters 'a' to 'y' move to the next character in the alphabet.
  • 'z' splits into both 'a' and 'b'.

We aim to compute the total length of the resulting string after applying these transformation rules t times.

? Approach

  1. Count Characters:
    Initialize an array cnt to hold counts of each character (from 'a' to 'z') in the input string.

  2. Apply Transformations t Times:
    For each transformation:

    • Create a temporary array tmp to hold updated counts.

    • For every character:

      • If it’s 'z' (i = 25), it becomes both 'a' (i = 0) and 'b' (i = 1).
      • Otherwise, the character shifts forward (i ? i+1).

    • Update cnt to the transformed counts.

  3. Calculate Final Length:
    Sum all values in cnt modulo 1e9+7 to get the length of the final string.

Dry Run Example:
For s = "az" and t = 1:

  • Initial counts: 'a': 1, 'z': 1

  • After 1 transformation:

    • 'a' ? 'b'
    • 'z' ? 'a' and 'b'

  • Final string: 'b', 'a', 'b' ? length = 3

?? Complexity

  • Time complexity: O(t * 26)
    Each transformation step processes 26 characters, repeated t times.

  • Space complexity: O(26)
    Constant space for character counts and temporary array.

class Solution {
  int lengthAfterTransformations(String s, int t) {
    const int MOD = 1000000007;
    List<int> cnt = List.filled(26, 0);

    // Count occurrences of each character in the string
    for (int i = 0; i < s.length; i++) {
      cnt[s.codeUnitAt(i) - 'a'.codeUnitAt(0)]++;
    }

    // Perform transformations
    for (int j = 0; j < t; j++) {
      List<int> tmp = List.filled(26, 0);
      for (int i = 0; i < 26; i++) {
        if (i == 25) {
          tmp[0] = (tmp[0] + cnt[i]) % MOD;
          tmp[1] = (tmp[1] + cnt[i]) % MOD;
        } else {
          tmp[i + 1] = (tmp[i + 1] + cnt[i]) % MOD;
        }
      }
      cnt = tmp;
    }

    // Calculate final length
    int len = 0;
    for (int c in cnt) {
      len = (len + c) % MOD;
    }

    return len;
  }
}
