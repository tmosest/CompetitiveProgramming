? Problem: Count Numbers with Non-Decreasing Digits
in Base b between l and r (inclusive)

? GOAL

 Given two large integers `l` and `r` (as strings), and a base `b`,
 count how many numbers in the range [l, r] (inclusive) have
 non-decreasing digits when represented in base `b`.

Since l and r can be up to 100 digits long, we can't process them
directly as integers. Instead, we'll use digit-based operations.

? STEP 1: Why Convert to Base First?

Let's say: r = "3456" and b = 8

We want to count numbers from 1 to 3456 whose base-8 representation
has non-decreasing digits.

? We can't apply digit DP directly on "3456" (it's in base 10).
? So we convert "3456" into its base-8 representation first.

Example:
3456 (base 10) = [6, 6, 0, 0] (base 8)

Now we want to generate all numbers from 1 to 6600 (in base 8)
and apply digit DP over them to count how many are non-decreasing.

? STEP 2: Subtract 1 From l (l - 1)

We compute:
result = count(1 to r) - count(1 to l - 1)

So we must subtract 1 from string l before converting to base b.

How to subtract 1 from a string number:

  1. Start from the end of the char array.
  2. While the digit is '0', replace it with '9'.
  3. When a non-zero digit is found, subtract 1 from it.
  4. Remove any leading zeros from the result.

Example:
l = "1000" ? subtracting 1 ? "0999" ? becomes "999"

? STEP 3: Digit DP Explained

We use Digit Dynamic Programming (Digit DP) to count valid numbers.

Function: solve(i, arr, tight, base, last, dp)

  • i: Current index in the digit array
  • arr: Base-b representation of the number
  • tight: 1 if we're bound by the original number
  • base: The base we're working in
  • last: Last digit placed so far (for non-decreasing check)
  • dp: Memoization cache

Base Case:

  • If i == arr.length, return 1 (valid number)

?? Final Result Flow

  1. Convert r to base-b and apply digit DP ? find(r)
  2. Subtract 1 from l, then convert to base-b and apply DP ? find(l - 1)
  3. Final Result = (find(r) - find(l - 1) + MOD) % MOD

? Complexity

  • Time Complexity: O(n * base * base) + O(n^3)
    where n = number of digits in base-b

  • Space Complexity: O(n * base * base) for DP

? Final Thought

That’s it! You now understand how to count numbers with non-decreasing
digits between two large integers in any base using Digit DP. ?

class Solution {
      public static int countNumbers(String l, String r, int b) {
        long ans1 = find(r.toCharArray(), b);
        char[] start = subTractOne(l.toCharArray());
        long ans2 = find(start, b);
        return (int) ((ans1 - ans2) % 1000000007l);
    }

    static long find(char[] arr, int b) {
        int[] nums = convertNumToBase(arr, b);
        Long[][][] dp = new Long[nums.length][2][11];
        long ans = solve(0, nums, 1, b, 0, dp) - 1;
        return ans;
    }

    static long solve(int i, int[] arr, int tight, int base, int last, Long[][][] dp) {
        if (i == arr.length) return 1l;
        
        if(dp[i][tight][last] != null) return dp[i][tight][last];

        int till = base - 1;
        if (tight == 1) till = arr[i];

        long ans = 0;
        for (int j = 0; j <= till; j++) {
            if (j >= last) ans = (ans + solve(i + 1, arr, tight & (j == arr[i] ? 1 : 0), base, j, dp)) ;
        }

        return dp[i][tight][last] = ans ;
    }

    static char[] subTractOne(char[] arr) {
        int n = arr.length, i = n - 1;
        while (i >= 0 && arr[i] == '0') arr[i--] = '9';
         
        int x = (int) (arr[i] - '0') - 1;
        arr[i] = (char) (x + '0');
        int j = 0, idx = 0;

        while (j < n && arr[j] == '0') j++;
        char[] res = new char[n - j];
        for (int k = j; k < n; k++) res[idx++] = arr[k];

        return res;
    }

    public static int[] convertNumToBase(char[] arr, int base) {
        int n = arr.length;
        int[] num = new int[n];
        int i = 0;
        while (i < n) num[i] = arr[i++] - '0';
        List<Integer> temp = new ArrayList<>();
        int len = n;
        while (len > 0) {
            int rem = 0;
            int[] next = new int[len];
            int newLen = 0;
            int j = 0;
            while (j < len) {
                long cur = rem * 10L + num[j];
                int q = (int) (cur / base);
                rem = (int) (cur % base);
                if (newLen > 0 || q != 0) {
                    next[newLen] = q;
                    newLen++;
                }
                j++;
            }
            temp.add(rem);
            num = next;
            len = newLen;
        }

        int[] res = new int[temp.size()];
        int k = 0, size = temp.size();
        while (k < size) {
            res[k] = temp.get(size - 1 - k);
            k++;
        }
        return res;
    }
}
