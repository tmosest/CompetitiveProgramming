dp[i][j] = max substring length of s1[:j] containing s2[:i] as subsequence. Hence, we will find our answer (min substring) in last row when all the characters of s2 are seen, i.e. i=s2.length() - 1

class Solution {
    /**
    	 a, b, c, d,e,b,d,d,e  s1(9)
    b	-1, 1, 2, 3,4,1,2,3,4
    d	-1,-1,-1, 3,4,5,2,3,4
    e	-1,-1,-1,-1,4,5,6,7,4

s2(3)
    */
    public String minWindow(String s1, String s2) {
        int m = s2.length(); //num of rows, smaller string
        int n = s1.length(); //cols, big string
        if(m>n)return "";
        int[][] dp = new int[m][n];
        //dp[i][j] - min len of s1[:j] substring cantaining s2[:i] as subsequence
        for(int[] row: dp)Arrays.fill(row, -1);
        
        //first row
        for(int j=0; j<n; j++){
            if(s1.charAt(j)==s2.charAt(0))dp[0][j] = 1;
            else if(j>0 && dp[0][j-1]!=-1)dp[0][j] = 1+dp[0][j-1];
            //else keep -1 -- no match
        }
        //for(int j=0; j<n; j++)System.out.println(dp[0][j]);
        for(int i=1; i<m; i++){
            for(int j=1; j<n; j++){
                if(s1.charAt(j) == s2.charAt(i)){
                    //System.out.println(i+","+j);
                    //if(j==0)dp[i][j]=1;
                    if(dp[i-1][j-1] != -1)dp[i][j]=1+dp[i-1][j-1];
                }else if(dp[i][j-1]!=-1)dp[i][j] = 1 + dp[i][j-1];//no match some continued
                
            }
        }
        //get min from last row, not -1 though
        int min_len = Integer.MAX_VALUE;
        String result = "";
        for(int j=0; j<n; j++){
            if(dp[m-1][j]!=-1){
                if(dp[m-1][j]<min_len){
                    min_len = dp[m-1][j];
                    System.out.println(min_len);
                    result = s1.substring(j-min_len+1,j+1);
                }
            }
        }
        return result;
    }
}

We keep calculating length of all possible substring of s which include all the character till ith character of T.

DP[i][j] = Length of substring S till jth which strictly include all the character till ith character of T.

Base condition : We dont have empty character so length will be 0
When there is a match check for the previous length [i-1][j-1] + 1.
When there is no match keep adding current character in [i][j-1] length as that can be our valid string length in future.
If previous length is 0 we won't use it. As it indicates that we didn't find any match for any previous/current T's character at.
At last character of T, we will keep checking for min Length to build a String which include all the character of T.

a b c d e b d d e
0 0 0 0 0 0 0 0 0
b 0 1 2 3 4 1 2 3 4
d 0 0 0 3 4 5 2 3 4
e 0 0 0 0 4 5 6 7 4


class Solution {
   public String minWindow(String s, String t) {
       int n1 = s.length();
       int n2 = t.length();
   	
       int[][] dp = new int[n2+1][n1+1];
       int len = n1+1, endOfWindow = -1;
       
       for(int i = 1; i<=n2; i++){
           for(int j = 1; j<=n1; j++){
               if(t.charAt(i-1) == s.charAt(j-1)){
                   // If we found previous character then only current character is valid 
                   // except when we are looking for first character
                   dp[i][j] = (i != 1 && dp[i-1][j-1] <= 0) ? 0 : 1 + dp[i-1][j-1];
                   
                   // we look for min window at last character of t only
                   if(i == n2 && dp[i][j] != 0 && len > dp[i][j]){
                       len = dp[i][j];
                       endOfWindow = j-1;
                   }
               }
               else
                   dp[i][j] = (dp[i][j-1] > 0) ? 1 + dp[i][j-1] : 0;
           }
       }
       return (len == n1+1) ? "" : s.substring(endOfWindow-len+1, endOfWindow+1);
   }
}

The basic idea is quite simple:
We maintain two pointer left and right. First, keep extending right pointer until we find substring s[left:right] contains T.
Then, shrinking left pointer towards the right until s[left:right] contains T.

class Solution {
    public String minWindow(String s, String t) {
        int minLen = s.length() + t.length();
        String res = "";
        int left = 0, right = 0;
        while (right < s.length()){
            int nextRight = extendRight(s, t, left);
            if (nextRight == -1){
                break;
            }
            right = nextRight - 1;
            left = shrinkLeft(s, t, right) + 1;
            if (minLen > (right - left + 1)){
                minLen = right - left + 1;
                res = s.substring(left, right + 1);
            }
            left++;
        }
        return res;
    }
    
    // return the first right index such that substring s[left:right] contains T as a sequence.
    // return -1 if there no such substring
    private int extendRight(String s, String t, int left){
        int sIdx = left, tIdx = 0;
        while(sIdx < s.length() && tIdx < t.length()){
            if (s.charAt(sIdx) == t.charAt(tIdx)){
                tIdx++;
            }
            sIdx++;
        }
        if (tIdx < t.length()){
            return -1; // s[left:] not contains T as a sequence.
        }
        return sIdx;
    }
    
    // return index of last left, such that s[left:right] contains T.
    private int shrinkLeft(String s, String t, int right){
        int sIdx = right, tIdx = t.length() - 1;
        while(sIdx >= 0 && tIdx >= 0){
            if (s.charAt(sIdx) == t.charAt(tIdx)){
                tIdx--;
            }
            sIdx--;
        }
        return sIdx;
    }
}

Personally I do not appreciate defining the DP-table with one extra row and column for two reasons. First, the definition of the entry of the first row & column can be very tricky and sometimes ambiguous.

Also, almost always the standard DP-solution can be optimized by only storing the previous row/column. Using the DP-table without these "extra row / column" to induce an optimized solution is very straightforward.

Down below is a standard DP Solution with O(m * n)-time & O(m * n)-space. The definition of every entry of DP-table and the relationship between entries are very clear.

class Solution {
    public String minWindow(String s, String t) {
        int m = s.length(), n = t.length();
        
        // dp[i][j] : length of shortest substring ENDING at s[i] s.t. s[0:i] contains t[0:j] 
        //            (or t[0:j] is a subsequence of s[0:i]); It there's no such substring within s[0:i]
        //            exist, then dp[i][j] = 0;
        
        int[][] dp = new int[m][n];
        
        // initize the first column <==> minimum length to cover t[0:0], the first char of t
        dp[0][0] = (s.charAt(0) == t.charAt(0)) ? 1 : 0;
        for (int i = 1; i < m; i++) {
            if (s.charAt(i) == t.charAt(0)) {  // current char matches t[0] ==> only need substring of length 1
                dp[i][0] = 1;
            } else {  
                // current char does not match, see if previous substring matches
                // if previous substring does not match ==> current string can't match ==> dp[i][0] = 0;
                // if previous substring contains a match ==> s[k:i-1] contains t[0:j] ==> now s[k:i] contains t[0:j]
                dp[i][0] = (dp[i-1][0] == 0) ? 0 : dp[i-1][0] + 1;
            }
        }
        
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (s.charAt(i) == t.charAt(j)) {
                    // current char matches t[j] ==> check the result of s[0:i-1] & t[0:j-1]
                    //     if s[0:i-1] does not contain t[0:j-1]  ==>   s[0:i] does not contain t[0:j]
                    //     if s[0:i-1] contains t[0:j-1] ==> s[0:i] contains t[0:j] with 1 extra pair of matching chars 
                    dp[i][j] = (dp[i-1][j-1] == 0) ? 0 : dp[i-1][j-1] + 1;
                } else {
                    // current char does not match t[j], thus can't match any char in t[0:j] 
                    // Thus we should check the result of s[0:i-1] & t[0:j-1]
                    dp[i][j] = (dp[i-1][j] == 0) ? 0 : dp[i-1][j] + 1;
                }
            }
        }
        
        // find the shortest s[left: right] s.t. it covers the whole t := t[0, n-1]
        int left = 0, right = m;
        for (int i = 0; i < m; i++) {
            if (dp[i][n-1] == 0) continue;
            if (right - left + 1> dp[i][n-1]) {
                right = i;
                left = i - dp[i][n-1] + 1;
            }
        }
        
        return right == m ? "" : s.substring(left, right + 1);
    }
}

Naturally, it leads to O(m * n)-time / O(n)-space Solution.

class Solution {
    // Optimal O(m * n)-time / O(n)-space Solution
    public String minWindow(String s, String t) {
        int m = s.length(), n = t.length();
        
        int[] dp = new int[n];
        dp[0] = (s.charAt(0) == t.charAt(0)) ? 1 : 0;
     
        int left = 0, right = m;
        
        for (int i = 1; i < m; i++) {
            int[] next = new int[n];
            
            // first entry
            if (s.charAt(i) == t.charAt(0)) {
                next[0] = 1;
            } else {
                next[0] = (dp[0] == 0) ? 0 : dp[0] + 1;
            }
            
            for (int j = 1; j < n; j++) {
                if (s.charAt(i) == t.charAt(j)) {
                    next[j] = (dp[j-1] == 0) ? 0 : dp[j-1] + 1;
                } else {
                    next[j] = (dp[j] == 0) ? 0 : dp[j] + 1;
                }
            }
            
            if (next[n-1] != 0 && right - left + 1 > next[n-1]) {
                right = i;
                left = i - next[n-1] + 1;
            }
            dp = next;
        }
        
        return right == m ? "" : s.substring(left, right + 1);
    }
}
