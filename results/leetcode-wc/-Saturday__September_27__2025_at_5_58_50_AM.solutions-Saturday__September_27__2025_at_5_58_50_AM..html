class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        pi = 0
        ni = 1
        res = [0] * len(nums)
        
        for n in nums:
            if n > 0:
                res[pi] = n
                pi += 2
            else:
                res[ni] = n
                ni += 2
        
        return res

Step by step algorithm

  1. Initialization:

    pi = 0
ni = 1
res = [0] * len(nums)
    • pi and ni are initialized to 0 and 1 respectively. These variables will be used as pointers to track the positions of positive and negative integers in the result array.
    • res is initialized as a list of zeros with the same length as the input nums.

  2. Iteration through nums:

    for n in nums:
    • This loop iterates through each element n in the input array nums.

  3. Assignment for Positive Integers:

    if n > 0:
    res[pi] = n
    pi += 2
    • If the current element n is greater than 0 (positive), it's assigned to the position indicated by the pi pointer in the result array res.
    • After the assignment, the pi pointer is incremented by 2 to skip the next position for the next positive integer.

  4. Assignment for Negative Integers:

    else:
    res[ni] = n
    ni += 2
    • If the current element n is less than or equal to 0 (negative), it's assigned to the position indicated by the ni pointer in the result array res.
    • After the assignment, the ni pointer is incremented by 2 to skip the next position for the next negative integer.

  5. Return Result Array:

    return res
    • After processing all elements in the input array, the resulting array res is returned.

class Solution:

        pos, neg = [], []

        for n in nums:
            if n > 0:
                pos.append(n)
            else:
                neg.append(n)
        
        res = [0] * len(nums)
        res[0 : len(pos) * 2 : 2] = pos
        res[1 : len(neg) * 2 : 2] = neg

        return res

Approach 1 ( Brute Force )

  1. We will iterate over the nums vector.
  2. If we encounter positive number then putting in v1 and if negative putting in v2.

  1. With the help of while loop iterating both together and putting values in the ans vector, where ind1 in index for v1 and ind2 for v2 and the 1st element should be positive.

Here, we're appending values sequentially thayswhy used push_back()

class Solution {
public:
    vector<int> rearrangeArray(vector<int>& nums) {
        vector<int>v1,v2,ans;
        
        for(int i =0;i<nums.size();i++){
            if(nums[i]>0)v1.push_back(nums[i]);
            else v2.push_back(nums[i]);
        }
        int ind1=0,ind2=0;
        

        while(ind2<nums.size()/2){
            ans.push_back(v1[ind1]);
            ind1++;
            ans.push_back(v2[ind2]);
            ind2++;
        }
        return ans;
    }
};

Approach 2( Optimized )

  1. Here we are directly putting values in the ans vector with the help of 2 pointer approach where initially both the indexes pos and neg are 0 and 1.
  2. If we encounter positive element then will put values in the ans vector with the help of ans[pos] = nums[i] and if found negative element then ans[neg] = nums[i].

NOTE??

Here, we can't use ans.push_back() to add elements because
 we're not appending values sequentially. Instead, we're placing
 values at specific indexes based on the element we have.

The number 1....6 are the order in which the elements where
 pushed into the ans vector.

class Solution {
    public int[] rearrangeArray(int[] nums) {
        List<Integer> pos = new ArrayList();
        List<Integer> neg = new ArrayList();
        
        for(int x: nums) {
            if(x >= 0) pos.add(x);
            else neg.add(x);
        }

        for(int i=0;i<nums.length;i++) {
            if(i%2 == 0) {
                nums[i] = pos.get(i/2);
            } else {
                nums[i] = neg.get(i/2);
            }
        }

        return nums;
    }
}

class Solution {
    public int[] rearrangeArray(int[] nums) {
        int n = nums.length;
        int pos = 0, neg = 1;
        while(pos < n && neg < n) {
            if(nums[pos] >= 0) pos += 2;
            else if(nums[neg] < 0) neg += 2;
            else {
                int temp = nums[pos];
                nums[pos] = nums[neg];
                nums[neg] = temp;
            }
        }
        return nums;
    }
}

? Intuition

The problem asks us to rearrange the array such that:

  • Positive and negative numbers alternate

  • The first element is positive

  • The array contains an equal number of positive and negative integers

Our first thought is that we can use separate indices to place positives and negatives at appropriate positions:

  • Positives at even indices: 0, 2, 4, ...

  • Negatives at odd indices: 1, 3, 5, ...

This way, we maintain the alternating pattern without needing to swap or do any complex logic.

? Approach

  • Initialize a result array ans of the same length.

  • Use two pointers:

    • pos = 0 to place positive numbers at even indices

    • neg = 1 to place negative numbers at odd indices

  • Traverse the input array:

    • If the current element is positive, place it at ans[pos] and increment pos by 2.

    • If it is negative, place it at ans[neg] and increment neg by 2.

    • Return the ans array.

This ensures:

  • All positives are in even indices

  • All negatives are in odd indices

  • The relative order of elements is preserved within their sign group

? Complexity

  • Time Complexity: O(n)
    We iterate through the array once.

  • Space Complexity: O(n)
    We use an auxiliary array to store the rearranged result.

?Code

class Solution {
    public int[] rearrangeArray(int[] arr) {
        int n = arr.length;
        int ans[] = new int[n];
        int pos = 0;
        int neg = 1;
        for(int i=0;i<n;i++){
            if(arr[i]<0){
                ans[neg] = arr[i];
                neg+=2;
            }else{
                ans[pos] = arr[i];
                pos+=2;
            }
        }

        return ans;
    }
}
