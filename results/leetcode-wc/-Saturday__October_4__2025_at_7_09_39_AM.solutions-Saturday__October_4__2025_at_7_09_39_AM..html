Explanation

The code uses bitmask dynamic programming.
need[i] tracks the set of nodes that must be completed before node i, built from the edges using need[j] |= (1 << i).
dp[mask] stores the maximum profit for the set of nodes processed represented by mask, where mask is a bitmask.
Initially, dp[0] = 0 because no nodes are processed and profit is zero.
Then, for each mask, if dp[mask] != -1, the code tries to process every node i that has not yet been processed, checking if all prerequisites need[i] are satisfied by the current mask (i.e., (mask & need[i]) == need[i]).
If node i can be processed, it creates a new state mask2 = mask | (1 << i) and updates dp[mask2] to be the maximum of its current value and dp[mask] + score[i] * pos, where pos is the 1-based position (computed as mask.bit_count() + 1).
Finally, it returns dp[(1 << n) - 1], which is the maximum profit when all nodes are processed.

Complexity

Time O(n * 2^n)
Space O(2^n)

    public int maxProfit(int n, int[][] edges, int[] score) {
        int[] need = new int[n];
        for (int[] e : edges) {
            int i = e[0], j = e[1];
            need[j] |= (1 << i);
        }
        int[] dp = new int[1 << n];
        Arrays.fill(dp, -1);
        dp[0] = 0;
        for (int mask = 0; mask < (1 << n); ++mask) {
            if (dp[mask] == -1) continue;
            int pos = Integer.bitCount(mask) + 1;
            for (int i = 0; i < n; ++i) {
                if (((mask >> i) & 1) == 0 && (mask & need[i]) == need[i]) {
                    int mask2 = mask | (1 << i);
                    dp[mask2] = Math.max(dp[mask2], dp[mask] + score[i] * pos);
                }
            }
        }
        return dp[(1 << n) - 1];
    }

class Solution {
    public int maxProfit(int n, int[][] edges, int[] score) {
        //shouldn't greedy work here as can always choose smallest score available topologically first to save larger for the end, as not forced to go down chosen branches, just unlocks
        //only reason would want to defy is maybe to unlock a branch early, but would only want to reach early if it has a low score
        //so a not greedy case would have something like Node(Score 8) --> node [score 1]    Node(score 5) greedy 5*1 + 8*2 + 3 = 24, vs 8*1 + 1*2 + 5*3 = 25

        //maybe dp then, let dp[mask] = the max score with all nodes marked by mask processed, and not marked unprocessed. for every mask of processed, 
        //the processed will unlock a set of unprocessed to allow, so 

        int[] predMasks = new int[n]; //mark all necessary predecessors to process before node with masks
        for(int[] edge : edges) predMasks[edge[1]] |= (1 << edge[0]);

        int[] dp = new int[1 << n];
        Arrays.fill(dp, -1); //fill all masks with -1 initially to denote impossible/uncalced
        dp[0] = 0;
        for(int mask = 1; mask < 1 << n; mask++) {
            int pos = Integer.bitCount(mask); //as the bit count gives bits processed so if i bits were processed then the last processed bit/node was in ith pos/idx
            for(int lastProcessed = 0; lastProcessed < n; lastProcessed++) {
                if((mask & (1 << lastProcessed)) == 0) continue; //skip values that aren't in the processed mask/set at all
                if((mask & predMasks[lastProcessed]) != predMasks[lastProcessed] || dp[mask & ~(1 << lastProcessed)] == -1) continue; 
                dp[mask] = Math.max(dp[mask], dp[mask & ~(1 << lastProcessed)] + pos*score[lastProcessed]);
            }
        }

        return dp[(1 << n)-1];
    }
}
