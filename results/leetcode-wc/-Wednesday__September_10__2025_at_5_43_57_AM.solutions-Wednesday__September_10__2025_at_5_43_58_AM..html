? Problem Restatement

We’re given a string s and an integer k.
We need to determine if we can select k disjoint substrings such that:

  • Every character in the substring appears only inside it (not outside).
  • The substring is not equal to the entire string.
  • Substrings must be disjoint.

Return true if possible, otherwise false.

Intuition

Think of each character as defining an interval from its first occurrence to its last occurrence.
A substring can only be “special” if it completely contains all occurrences of every character inside it.

Example:

  • "aa" in "aabb" is valid (all as are inside).

  • "aba" in "abac" is not valid (because the last c lies outside).

? This is very similar to partition labels.

So the problem reduces to:

  1. Find all “closed intervals” in the string where all chars inside are fully contained.

  2. Count how many disjoint intervals we can take.

  3. Return true if count ≥ k.

Approach

  1. Record first[c] and last[c] for every character.

  2. For each char, build its minimal valid substring [first[c], last[c]].

    • While scanning inside [start, end], extend end if another char’s last index is outside.

    • If any char starts before start, discard (not closed).

  3. Keep substrings that are valid and not equal to the entire string.

  4. Sort intervals by their end.

  5. Greedily select the maximum number of disjoint substrings (classic interval scheduling).

  6. Check if the count ≥ k.

Complexity

  • Time complexity:
    Sorting intervals: O(nlogn)

  • Space complexity:
    Extra space: O(n)

class Solution {
    public boolean maxSubstringLength(String s, int k) {
        int n = s.length();
        int[] first = new int[26];
        int[] last = new int[26];
        Arrays.fill(first, -1);

        // Step 1: record first and last index of each char
        for (int i = 0; i < n; i++) {
            int c = s.charAt(i) - 'a';
            if (first[c] == -1) first[c] = i;
            last[c] = i;
        }

        List<int[]> intervals = new ArrayList<>();

        // Step 2: find minimal valid substrings
        for (int c = 0; c < 26; c++) {
            if (first[c] == -1) continue;
            int start = first[c], end = last[c];
            boolean valid = true;
            for (int i = start; i <= end; i++) {
                int d = s.charAt(i) - 'a';
                if (first[d] < start) { // d starts before this substring
                    valid = false;
                    break;
                }
                end = Math.max(end, last[d]); // must extend if needed
            }
            if (valid && (start > 0 || end < n - 1)) { 
                // not entire string
                intervals.add(new int[]{start, end});
            }
        }

        // Step 3: sort intervals by end to choose disjoint
        intervals.sort((a, b) -> Integer.compare(a[1], b[1]));
        int cnt = 0, prevEnd = -1;
        for (int[] inter : intervals) {
            if (inter[0] > prevEnd) {
                cnt++;
                prevEnd = inter[1];
            }
        }

        return cnt >= k;
    }
}

Intuition

The problem requires us to find at least k non-overlapping valid segments in the string, where a valid segment contains all occurrences of each character within its first and last appearance. To achieve this, we first determine the first and last occurrence of each character, then identify potential segments where no character appears outside its boundaries. We then sort these segments based on their ending indices and count the number of non-overlapping ones. If we find at least k such segments, we return true; otherwise, we return false.

Approach

Step 1 Initialize first and last occurrence arrays

  • Create arrays to store the first and last position of each character.
  • Fill firstOccur with a large value n and lastOccur with -1.
  • Iterate through the string, updating these arrays.

Step 2 Identify valid segments

  • Loop through the string and find segments starting at the first occurrence of a character.
  • Expand the segment until all characters within it are fully enclosed.
  • If the segment satisfies the conditions, store it.

Step 3 Sort the segments

  • Sort all valid segments based on their ending index to maximize non-overlapping selections.

Step 4 Count non-overlapping segments

  • Iterate through sorted segments and count the number of non-overlapping ones.
  • If the count is at least k, return true; otherwise, return false.

Complexity

  • Time complexity : O(n*log(n))
  • Space complexity : O(1)

    public boolean maxSubstringLength(String s, int k)
    {
        int strLen = s.length();
        if (k == 0)
        {
            return true;
        } 
            

        int[] firstOccur = new int[26];
        int[] lastOccur = new int[26];

        Arrays.fill(firstOccur, strLen);
        Arrays.fill(lastOccur, -1);

        // Step 1: Find first and last occurrence of each character
        for (int pos = 0; pos < strLen; pos++)
        {
            int charIdx = s.charAt(pos) - 'a';
            firstOccur[charIdx] = Math.min(firstOccur[charIdx], pos);
            lastOccur[charIdx] = Math.max(lastOccur[charIdx], pos);
        }

        List<int[]> segments = new ArrayList<>();

        // Step 2: Find valid segments
        for (int start = 0; start < strLen; start++)
        {
            if (start != firstOccur[s.charAt(start) - 'a'])
            {
                continue;
            } 

            int farthest = lastOccur[s.charAt(start) - 'a'];
            int current = start;
            boolean isValid = true;

            while (current <= farthest)
            {
                if (firstOccur[s.charAt(current) - 'a'] < start)
                {
                    isValid = false;
                    break;
                }
                
                farthest = Math.max(farthest, lastOccur[s.charAt(current) - 'a']);
                current++;
            }

            if (isValid && !(start == 0 && farthest == strLen - 1))
            {
                segments.add(new int[]{start, farthest});
            }
        }

        // Step 3: Sort the segments based on ending index
        segments.sort(Comparator.comparingInt(pair -> pair[1]));

        // Step 4: Count non-overlapping segments
        int segmentCount = 0, lastIndex = -1;
        for (int[] bounds : segments)
        {
            if (bounds[0] > lastIndex)
            {
                segmentCount++;
                lastIndex = bounds[1];
            }
        }

        return segmentCount >= k;
    }

Intuition

The problem requires us to find at least k disjoint special substrings in the given string s. A substring is special if all its characters appear as a contiguous block within the string.

To solve this, we first precompute the first and last occurrences of each character in the string. Using this information, we employ a recursive dynamic programming approach to count the maximum number of disjoint special substrings.

Approach

  1. Precompute First and Last Occurrences:

    • Store the first and last occurrence of each character in separate hash maps.

  2. Recursive DP Approach:

    • Define a recursive function solve(s, index, n):
      • Base case: If index == n, return 0.
      • Use memoization to avoid redundant calculations.
      • At each index, we have two choices:
        1. Take the current character if it is the first occurrence:
          • Determine the last index of the current character.
          • Ensure that all characters within this range form a valid special substring.
          • If valid, recursively compute solve(s, lastInd + 1, n).
        2. Skip the current character and move forward.

  3. Final Check:

    • Compute the maximum possible special substrings using solve(s, 0, n).
    • If the count is at least k, return true; otherwise, return false.

Complexity

  • Time Complexity:

    • Precomputing first and last occurrences: O(N)
    • Recursive calls with memoization: O(N2)
    • Total: O(N2) in the worst case.

  • Space Complexity:

    • HashMaps (first, last): O(1) (at most 26 keys)
    • DP array (dp): O(N)
    • Recursion stack: O(N)
    • Total: O(N)

class Solution {
    Map<Character, Integer> first, last;
    int[] dp;

    int solve(String s, int index, int n) {
        if (index == n) return 0;

        if (dp[index] != -1) return dp[index];

        // Take the current character if it's the first occurrence
        char ch = s.charAt(index);
        int op1 = 0;
        if (first.get(ch) == index) {
            int lastInd = last.get(ch);
            int cnt = 1;

            // Increase right bound as much as you can
            for (int i = index + 1; i < lastInd; ++i) {
                lastInd = Math.max(lastInd, last.get(s.charAt(i)));
                // if current index exist outside, no need to take cnt = 1
                if (first.get(s.charAt(i)) < index || last.get(s.charAt(i)) > lastInd) {
                    cnt = 0;
                    break;
                }
            }

            // special condition to check whether substring is full string or not, if it's full string, then cnt = 0;
            if (cnt > 0 && index == 0 && lastInd == n - 1) cnt = 0;

            op1 = cnt + solve(s, lastInd + 1, n);
        }

        // Skip the current character
        int op2 = solve(s, index + 1, n);

        return dp[index] = Math.max(op1, op2);
    }

    public boolean maxSubstringLength(String s, int k) {
        if (k == 0) return true;

        int n = s.length();
        dp = new int[n];
        Arrays.fill(dp, -1);

        // Store first occurrence of each character
        first = new HashMap<>();
        for (int i = 0; i < n; ++i) {
            first.putIfAbsent(s.charAt(i), i);
        }

        // Store last occurrence of each character
        last = new HashMap<>();
        for (int i = n - 1; i >= 0; --i) {
            last.putIfAbsent(s.charAt(i), i);
        }

        // Compute the max number of substrings
        int maxPossible = solve(s, 0, n);

        return maxPossible >= k;
    }
}

         return True

        n = len(s)

        fir_occ = {}
        last_occ = {}
        for i, ch in enumerate(s):

                continue

            k_idx = i
            while k_idx <= j:

        count = 0
        end = -1
        for st, en in candidates:
            if st > end:
                count += 1
                end = en

Intuition

  • The maximum number of substrings is 26, one for each character a-z, with a range from the first and last instance of each character
  • If two substrings overlap (e.g. abab) then we only care about the minimum first character and maximum last character of both strings
  • If a substring fully contains a smaller substring (e.g. aba) then we can safely count the smaller substring and ignore the larger one

Approach

First calculate the first and last instances of each character.

Then starting from the last character in the string and moving backwards through the string after each iteration; verify that for every character until the precalculated last character in the string:

  • That there is not an instance of a character (including the first character) inside of this substring that occurs earlier
  • That we have not already counted a substring inside of this substring
  • If this substring overlaps with another substring, then keep checking until we have also verified to the end of this substring

By moving backwards through the string we will always count the smaller substrings that are fully contained in other substrings first.

class Solution {
    public boolean maxSubstringLength(String s, int k) {
        char[] c = s.toCharArray();
        int[] start = new int['z' + 1];
        int[] end = new int['z' + 1];
        boolean[] included = new boolean['z' + 1];

        // take note of the start and end positions of each character
        for (int i = c.length - 1; i >= 0; i--) start[c[i]] = i;
        for (int i = 0; i < c.length; i++) end[c[i]] = i;

        int count = 0;
        for (int i = c.length - 1; i >= 0; i--) {
            boolean valid = true;
            int lastIndex = end[c[i]];
            for (int j = i; j <= lastIndex; j++) {
                if (included[c[j]]) {
                    // If this character c[j] has previously been counted then we cannot count character c[i]
                    valid = false;
                    break;
                } else if (start[c[j]] < i) {
                    // If there is a character the same as c[j] that starts earlier than i,
                    // then we should skip this iteration and try again from the first instance of c[j]
                    valid = false;
                    break;
                }
                // If this substring of characters overlaps with another substring, then we must extend the substring
                if (end[c[j]] > lastIndex) lastIndex = end[c[j]];
            }
            // Check the edge case that this isn't the entire string
            if (valid && (i != 0 || lastIndex != c.length - 1)) {
                count++;
                if (count >= k) return true;
                included[c[i]] = true;
            }
        }

        return count >= k;
    }
}

Intuition

The problem requires us to determine if we can form at least k non-overlapping valid substrings. The key insight is that each character in the string has a defined segment (from its first to last occurrence). By merging overlapping segments, we can determine the maximum number of non-overlapping substrings.

Approach

Step 1: Identify Character Ranges

Use an array Seg[26][2] to store the first and last occurrence of each character.
Iterate through the string to populate this array.

Step 2: Merge Overlapping Segments

For each character’s segment, extend its boundaries by including all overlapping characters.
This ensures that we correctly group characters into valid substrings.

Step 3: Compute Maximum Non-Overlapping Substrings

Use dynamic programming (dp[26]) to track the maximum number of valid substrings that can be formed.
Traverse the string in reverse order and update dp[ch] based on previously computed results.

Step 4: Return the Result

If the maximum number of valid substrings is at least k, return true; otherwise, return false.

Complexity

  • Time complexity: O(n)

    • O(n) for tracking character ranges.
    • O(n) for merging overlapping segments.
    • O(n) for the dynamic programming step.
    • Overall, the approach runs in O(n) time.

  • Space complexity: O(n)

    • We use a fixed-size array (Seg[26][2] and dp[26]), making space usage constant.

class Solution {
    public boolean maxSubstringLength(String s, int k) {
        int n = s.length();
        if(k == 0) return true;
        int [][] Seg = new int [26][2];
        for(int [] row : Seg) Arrays.fill(row, -1);
        for(int i=0; i<n; i++) {
            int ch= s.charAt(i)-'a';
            if(Seg[ch][0] == -1) Seg[ch][0] = i;
            Seg[ch][1] = i;
        }

        int [] flag = new int [26];
        for(int i=0; i<n; i++) {
            if(Seg[s.charAt(i)-'a'][0] != i) continue;
            int ch = s.charAt(i)-'a';
            int e=Seg[ch][1];
            int st=Seg[ch][0];
            int ptr=i;
            while(ptr < e) {
                e = Math.max(Seg[s.charAt(ptr)-'a'][1], e);
                st = Math.min(Seg[s.charAt(ptr)-'a'][0], st);
                ptr++;
            }
            Seg[ch][1] = e;
            Seg[ch][0] = st;
        }

        int [] dp = new int [26];
        int max=0;
        for(int i=n-1; i>=0; i--) {
            int ch = s.charAt(i)-'a';
            if(Seg[ch][1] != i) continue;
            if(Seg[ch][0] == 0 && Seg[ch][1] == n-1) continue;
            dp[ch]=1;
            for(int j=0; j<26; j++) {
                if(Seg[j][0] > Seg[ch][1]) dp[ch] = Math.max(dp[ch], 1 + dp[j]);
            }   
            max = Math.max(max, dp[ch]);
        }

        return max >= k;
    }
}

        if (k == 0)
            return true;

        int[] firstOccur = new int[26];
        int[] lastOccur = new int[26];

        // Step 1: Find first and last occurrence of each character
        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            firstOccur[c - 'a'] = Math.min(s.indexOf(c), i);
            lastOccur[c - 'a'] = Math.max(s.lastIndexOf(c), i);
        }

        List<int[]> segments = new ArrayList<>();

        // Step 2: Find valid segments
        for (int start = 0; start < n; start++) {
            if (start != firstOccur[s.charAt(start) - 'a']) // not a valid start
                continue;

            int farthest = lastOccur[s.charAt(start) - 'a'];
            int current = start;
            boolean isValid = true;

            while (current <= farthest) {
                if (firstOccur[s.charAt(current) - 'a'] < start) {
                    isValid = false;
                    break;
                }

                farthest = Math.max(farthest, lastOccur[s.charAt(current) - 'a']);
                current++;
            }

            if (isValid && !(start == 0 && farthest == n - 1))
                segments.add(new int[] { start, farthest });
        }

        // Step 3: Sort the segments based on the end Index(similar to what we do in
        // activity selection problem)
        Collections.sort(segments, (a, b) -> a[1] - b[1]);

        // Step 4: Count non-overlapping segments (similar to non overlapping time intervals)
        int count = 0;
        int lastIndex = -1;
        for (int[] segment : segments) {
            if (segment[0] > lastIndex) {
                count++;
                lastIndex = segment[1];
            }
        }

        return count >= k;
    }
}

class Solution {
    void recursion(int curr[], int prefix[][], int start_end[][]) {
        var temp = curr.clone();

        for (var i = 0; i < 26; i++) {
            if (prefix[temp[1]][i] - (temp[0] > 0 ? prefix[temp[0] - 1][i] : 0) > 0) {
                curr[0] = Math.min(curr[0], start_end[i][0]);
                curr[1] = Math.max(curr[1], start_end[i][1]);
            }
        }

        if (temp[0] != curr[0] || temp[1] != curr[1]) {
            recursion(curr, prefix, start_end);
        }
    }
    public boolean maxSubstringLength(String s, int k) {
        var n = s.length();
        var prefix = new int[n][26];
        var start_end = new int[26][2];
        for (var i = 0; i < 26; i++) {
            start_end[i][0] = (int) 1e9;
            start_end[i][1] = -1;
        }

        for (var i = 0; i < n; i++) {
            var c = s.charAt(i) - 'a';

            start_end[c][0] = Math.min(start_end[c][0], i);
            start_end[c][1] = Math.max(start_end[c][1], i);

            for (var j = 0; j < 26; j++)
                prefix[i][j] = (i > 0 ? prefix[i - 1][j] : 0);

            prefix[i][c]++;
        }

        var ranges = new TreeSet<ArrayList<Integer>>((x, y) -> x.get(0) - y.get(0));

        for (var i = 0; i < 26; i++) {
            if (start_end[i][1] == -1)
                continue;
            var curr = new int[] { start_end[i][0], start_end[i][1] };
            recursion(curr, prefix, start_end);

            if (curr[0] == 0 && curr[1] == n - 1)
                continue;

            var tempList = new ArrayList<Integer>();
            tempList.add(curr[0]);
            tempList.add(curr[1]);
            ranges.add(tempList);
        }

        var id = n;
        var dp = new int[n + 1];
        var it = ranges.descendingIterator();

        while (it.hasNext()) {
            var list = it.next();
            while (id > list.get(0)) {
                dp[id - 1] = dp[id];
                id--;
            }

            var temp = 1 + dp[list.get(1) + 1];
            dp[list.get(0)] = Math.max(dp[list.get(0)], temp);
        }

        while (id > 0) {
            dp[id - 1] = dp[id];
            id--;
        }

        return dp[0] >= k;
    }
}

The edge hole of this problem is identifying the end index of each character.
just remember that a interval is valid only when all the characters come inside that interval should have their first and last indices inside the interval : if not we can increase the last index of current interval and if start index of any char inside falls outside the interval , then we can ignore the interval itself(as we would have processed the interval that includes this outlier start index).

n + c*c = O(n)
where n is string length
and c is '26'
  • Space complexity:

class Solution {
    public boolean maxSubstringLength(String s, int k) {
        if (k == 0) return true;
        int n = s.length();
        int[] first = new int[26];
        Arrays.fill(first, n);
        int[] last = new int[26];
        Arrays.fill(last, -1);

        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            int idx = c - 'a';
            if (first[idx] == n) {
                first[idx] = i;
            }
            last[idx] = i;
        }

        List<int[]> intervals = new ArrayList<>();
        for (int i = 0; i < 26; i++) {
            if (first[i] < n) {
                int sStart = first[i];
                int sEnd = last[i];
                boolean isValid = true;
                for(int j = sStart+1 ; j<=sEnd ; j++){
                    int c = s.charAt(j)-'a';
                    if(first[c]<sStart){
                        isValid = false;
                        break;
                    }
                    if(last[c]>sEnd) sEnd = last[c];
                }
                if ( !isValid || (sStart == 0 && sEnd == n - 1)) continue; // Skip the entire string or invalid intervals(as these were covered already  )
                intervals.add(new int[]{sStart, sEnd});
            }
        }

        // Remove overlapping intervals
        intervals.sort((a, b) -> a[1] - b[1]);
        List<int[]> result = new ArrayList<>();
        int lastEnd = -1;
        for (int[] interval : intervals) {
            if (interval[0] > lastEnd) {
                result.add(interval);
                lastEnd = interval[1];
                if (result.size() >= k) break;
            }
        }
        return result.size() >= k;
    }
}

Intuition

Any valid substring starts at first occurance of a character x and ends at last occurence of a chararacter y. (x need not be y).

Approach

Keeping track of states. state[idx][x] = count of char x from 0 to idx.
Keeping track of first[x] = first occurance of x and last[x] = last occurance of x. Keep track of cnt[x] = count of character of x in s.

After finding all intervals: Find maximum non overlapping!

Complexity

  • Time complexity:
    O(n)

  • Space complexity:
    O(n)

class Solution {
    class Node{
        int st; 
        int ed;
        Node(int s, int e){
            st=  s;
            ed = e;
        }
    }
    public boolean maxSubstringLength(String s, int p) {
        if(p<1) return true;
        PriorityQueue<Node> pq = new PriorityQueue<>((a,b) -> a.ed - b.ed);
        int[] cnt = new int[26];
        int[] first = new int[26];
        int[] last = new int[26];
        Arrays.fill(first, -1); Arrays.fill(last, -1);
        int[][] state = new int[s.length()][26];

        state[0][s.charAt(0) - 'a']++;
        cnt[s.charAt(0) - 'a']++;
        first[s.charAt(0) - 'a'] = 0;
        last[s.charAt(0) - 'a'] = 0;

        for(int i=1; i<s.length(); i++){
            if(first[s.charAt(i) - 'a'] == - 1){
                first[s.charAt(i) - 'a'] = i;
            }
            last[s.charAt(i) - 'a'] = i;
            cnt[s.charAt(i) - 'a']++;
            for(int j = 0; j<26; j++){
                state[i][j] = state[i-1][j];
            }
            state[i][s.charAt(i)-'a']++;
        }
        
        for(int i=0; i< s.length(); i++){
            if(first[s.charAt(i) - 'a'] != i) continue;
            int mn = s.length();
            for(int j=0; j<26; j++){
                if(last[j]>= last[s.charAt(i) - 'a']){ // check state at last[j] that is greater than last[char(i)]:
                    //has to have equal occurences of each char. or 0 to last:
                    boolean flag = true;
                    for(int k= 0; k<26; k++){
                        int x = (k == s.charAt(i) - 'a')?1:0; //toughest part: if k is char(i) then we must start at 1 occurance
                        if(state[i][k] == state[last[j]][k]){
                            //its good, doesn't even occur in string
                        }
                        else if(state[i][k] ==x && state[last[j]][k] == cnt[k]){
                            //its good, occurs but ends before that spot and starts from zero.
                        }
                        else{
                            flag = false;
                            break;
                        }
                    }
                    if(flag){ //i -> last j is a valid substring:
                        mn = Math.min(mn, last[j]);
                    }
                }
            }
            if(i==0 && mn == s.length() -1) continue; //reject entire string
            if(mn != s.length()) pq.add(new Node(i, mn));
        }
        int mx = 0;
        
        int ed = -1;
        while(!pq.isEmpty()){
            Node x = pq.poll();
            if(x.st >= ed){
                mx++;
            }
            ed = x.ed;
        }
        
        return mx>=p;
    }
}
