Intuition

  • Start by inserting the first character s[0] as the first segment and mark it as seen using a map.
  • Iterate through the rest of the string and keep building the current segment in string a.
  • If the segment a is not in the map (i.e., it’s unique), push it into the answer, mark it seen, and reset a to start a new segment.
  • Repeat this until the end of the string, collecting all unique segments.
  • Finally, return the list of collected segments.

Approach

  1. Initialize the First Segment
  • Start by taking the first character of the string.
  • Treat it as the first segment.
  • Store it in the answer list.
  • Mark it as seen using a map to ensure future segments don’t repeat.
  1. Prepare for Building Next Segment
  • Create an empty temporary string to build upcoming segments.
  • Begin iterating from the second character (index 1).
  1. Build Segment Character by Character

  • For each character in the remaining string:

      Append it to the temporary string.

  This temporary string keeps growing as you keep adding characters.
  1. Check If the Segment Is Unique
    After each addition, check if this temporary string (current segment) has been seen before using the map:

If not seen:

  • It means this segment is unique.
  • Add it to the answer list.
  • Mark it as seen in the map.
  • Reset the temporary string to empty so you can begin forming a new segment.

If already seen:

  • Continue adding more characters to the temporary string and checking again.
  1. Repeat Until the End of the String
  • Keep repeating the above steps until you reach the end of the string.
  • Each time a new unseen segment is formed, it's added to the result.

LeetCode Solution: Partition Unique Substrings

Problem

Given a string s, you are to partition it into substrings such that each substring hasn't appeared before as a whole. You should return these unique substrings in order.

Example:

Input: s = "abbccccd"
Output: ["a","b","bc","c","cc","d"]

Intuition

We want to partition the string into segments such that:

  • Each segment is a new substring (hasn’t occurred previously).
  • Substrings can be of any length but must be unique so far.

The greedy approach is to always find the smallest possible substring starting at current index that hasn't occurred before, add it to the result, and move forward.

Approach

  1. Use a set to store all previously seen substrings.
  2. Start from index i = 0.
  3. For every position j starting from i, keep appending characters to form cur = s[i..j].
  4. If this cur hasn’t been seen before, add it to the result list, insert into the set, move i to j + 1, and break.
  5. Repeat until i < n.
  6. If no new segment is found, stop.

class Solution {
public:
    vector<string> partitionString(string s) {
        int n = s.size();
        vector<string> segments;
        unordered_set<string> seen; // to track already used substrings
        int i = 0;

        while (i < n) {
            bool found = false;
            string cur;
            for (int j = i; j < n; j++) {
                cur.push_back(s[j]);
                if (seen.count(cur) == 0) {
                    // If the current substring hasn't been seen
                    found = true;
                    segments.push_back(cur);
                    seen.insert(cur);
                    i = j + 1;
                    break; // break as soon as a unique substring is found
                }
            }
            if (!found) break; // No more unique substrings can be formed
        }

        return segments;
    }
};

Explanation with Example

Input: s = "abbccccd"

Step-by-step:

  1. Start at index i=0:
    • Try "a" ? not seen ? add ? segments = ["a"]
  2. Now i=1:
    • Try "b" ? not seen ? add ? segments = ["a", "b"]
  3. Now i=2:
    • Try "b" ? already seen
    • Try "bc" ? not seen ? add ? segments = ["a", "b", "bc"]
  4. Now i=4:
    • Try "c" ? not seen ? add ? segments = ["a", "b", "bc", "c"]
  5. Now i=5:
    • Try "c" ? already seen
    • Try "cc" ? not seen ? add ? segments = ["a", "b", "bc", "c", "cc"]
  6. Now i=7:
    • Try "d" ? not seen ? add ? segments = ["a", "b", "bc", "c", "cc", "d"]

Output: ['a', 'b', 'bc', 'c', 'cc', 'd']

Time Complexity

  • Worst Case: O(n^2) — nested loop when substrings grow in length.

Space Complexity

  • O(n) for storing the segments and seen substrings.
