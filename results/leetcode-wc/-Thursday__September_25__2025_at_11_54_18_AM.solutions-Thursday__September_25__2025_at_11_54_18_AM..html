What is Popcount-Depth?

"Popcount" means counting the number of 1s in the binary representation of a number.

Popcount-Depth is defined as:

Start with a number x.

Repeatedly apply popcount until the number becomes 1.

The depth is the number of steps it takes to reach 1.

? Example:

Let's take x = 7:

Binary of 7 is 111 ? popcount = 3

Binary of 3 is 11 ? popcount = 2

Binary of 2 is 10 ? popcount = 1

We reached 1 in 3 steps ? so depth = 3

? Key Insight:

The maximum number of bits in an integer is 64, so the number of distinct popcount depths is limited.
We can precompute the depth for all numbers from 1 to 64 (popcounts) and store the values that match the required depth k.
?? Digit DP

Now the task becomes:
Count all integers ² n whose binary representation has a number of 1s that has popcount depth = k.
Steps:

Precompute the valid 1-bit counts (popcount values) whose popcount depth is k.

Use digit DP on the binary representation of n to count how many numbers ² n have that many 1s.

Handle the edge case when k == 0 (only 0 has popcount depth 0, and we ignore it since popcount(0) = 0 and 0 is not allowed).

States

  1. dp(i: int, tight: bool, one: int) here i represents the current index of the binary string nums
  2. tight represents if our dp is bounded or not. Ex=> if our number is 945 and we chose 9 then we can only go until 4 but if we would have chosen 8 then we can choose any number upto 9 and it won't exceed the number as 89 < 9x where 0 <= x <= 9.
  3. one represents the number of set bits (1) in the binary string we are choosing.

?? Complexity

Time complexity:
O(len(n) * 64) Å O(64) since binary length of n is at most 64 and popcounts range from 0Ð64.

Space complexity:
O(len(n) * 64) due to memoization (DP cache).

? Code

Python3
class Solution:
    def popcountDepth(self, n: int, k: int) -> int:

        if k == 0:
            return 1
        def compute(i: int) -> int:
            d = 0
            while i > 1:
                i = bin(i).count('1')
                d += 1
            return d
        t = set()
        for c in range(1, 65):
            if compute(c) == k - 1:
                t.add(c)
        
        if not t:
            return 0

        nums = bin(n)[2:]
        
        @cache
        def dp(i: int, tight: bool, one: int) -> int:
            if i == len(nums):
                return 1 if one in t else 0
            
            digit = int(nums[i]) if tight else 1
            ans = 0
            for d in range(digit + 1):
                new_tight = tight and (d == digit)
                ans += dp(i + 1, new_tight, one + d)
            return ans

        count = dp(0, True, 0)

        if k == 1 and 1 in t:
            return count - 1
        
        return count

Intuition

Since n is very large, a simple iteration is too slow, which points towards a Digit DP solution. The main idea is to construct numbers up to n digit-by-digit in binary. While building these numbers, we keep track of their popcount (number of set bits) to see if it leads to the desired popcount-depth.

Approach

First, we pre-compute a set of target popcounts; these are all the numbers (from 1 to 63) whose own popcount-depth is exactly k-1. Then, a recursive Digit DP function counts the numbers up to n whose final popcount is in our target set. The quenostrix variable is used midway to store the input n, which is then converted to a binary string for the DP process.

Complexity

  • Time complexity: O(log2n)

  • Space complexity: O(log2n)

Code

Java
class Solution {
    public long popcountDepth(long n, int k) {
        if(k==0){
            return(n>=1)?1:0;
        }
        int[] j=new int[64];
        Arrays.fill(j,-1);
        Set<Integer> l=new HashSet<>();
        for(int m=1;m<64;m++){
            if(depth(m,j)==k-1){
                l.add(m);
            }
        }
        if(l.isEmpty()){
            return 0;
        }
        String s=Long.toBinaryString(n);
        int o=s.length();
        long[][][] i=new long[o+1][o+2][2];
        for(long[][] p:i){
            for(long[] q:p){
                Arrays.fill(q,-1);
            }
        }
        long r = solution(0,0,false,s,l,i);
        if(k==1){
            return r-1;
        }
        return r;
    }
    
    private int depth(int n, int[] j){
        if(n==1){
            return 0;
        }
        if(j[n]!=-1){
            return j[n];
        }
        int m=Integer.bitCount(n);
        return j[n]=1+depth(m,j);
    }

    private long solution(int a, int b, boolean c, String s, Set<Integer> l, long[][][] i) {
        if(a==s.length()){
            return l.contains(b)?1L:0L;
        }
        int d=c?1:0;
        if(i[a][b][d]!=-1){
            return i[a][b][d];
        }
        long e=0;
        int f=c?1:(s.charAt(a)-'0');
        for(int g=0;g<=f;g++){
            boolean h=c||(g<f);
            e+=solution(a+1,b+g,h,s,l,i);
        }
        return i[a][b][d]=e;
    }
}
