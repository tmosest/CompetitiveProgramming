The range is this problem is limited to 50, so it did not matter much. But with larger n and more ranges, we will need a linear line sweep solution.

C++

bool isCovered(vector<vector<int>>& ranges, int left, int right) {
    int line[52] = {};
    for (auto &r : ranges) {
        line[r[0]] += 1;
        line[r[1] + 1] -= 1;
    }
    for (int i = 1, overlaps = 0; i <= right; ++i) {
        overlaps += line[i];
        if (i >= left && overlaps == 0)
            return false;
    }
    return true;
}

Prefix Sum
C++

We have ranges [l, r] (inclusive) and a fixed universe 1..50. A number x is covered if at least one range includes it. Instead of marking every x inside each range (which is nested work), we use a difference array:

  • Create diff[0..51] (52 length).
    When a range starts at l, we do diff[l] += 1.
    When it ends at r, we do diff[r+1] -= 1 to cancel coverage after r.
  • A single left-to-right prefix sum cover += diff[x] tells how many active ranges cover x at that point.
    If cover > 0, x is covered; if cover == 0, x is not.
  • While scanning, if any x in [left, right] has cover == 0, we can return false. If we finish checking right, return true.

Why r+1? Ranges are inclusive. We want coverage to stop immediately after r, so subtracting at r+1 turns coverage off starting from that index.

Why O(51)? The domain size is fixed: we perform two updates per range and a single pass over 1..50.

public class Solution {
    public bool IsCovered(int[][] ranges, int left, int right) {
        var diff = new int[52];                // indices 1..50; 51 handles r+1 when r==50
        foreach (var seg in ranges) {
            diff[seg[0]]++;
            diff[seg[1] + 1]--;
        }
        int cover = 0;
        for (int x = 1; x <= 50; x++) {
            cover += diff[x];                  // prefix sum ? #active ranges at x
            if (x >= left && x <= right && cover == 0) return false;
            if (x == right) return true;       // already verified the target range
        }
        return true;                            // defensive
    }
}

Correctness sketch

For each range [l, r], we increment coverage starting at l and cancel it at r+1. The running sum cover[x] = sum_{i<=x} diff[i] equals the number of ranges with l <= x <= r. Thus cover[x] > 0 iff x is covered. We check every x in [left, right] during the scan, so if none has cover == 0, all are covered.

Complexity

  • Time: O(#ranges + 50) ? effectively constant O(51) for the domain.
  • Space: O(52) for the difference array.
