? Understanding the Question

  • We're given an array nums and we're asked to find the number of pairs in it at any index i and j such that,
    • i < j
    • nums[i] + nums[j] >= lower and nums[i] + nums[j] <= upper
    • or nums[i] + nums[j] lies in the range [lower, upper].
  • For example : The pair (1, 5) is called as a fair pair for lower = 3 and upper = 6.

? Approach 1 ? Two Pointers

  • This is the Brute Force method in which we can basically traverse over all the possible pairs of nums and directly check for the condition given in the question of pair sums lieing in the range [lower, upper].
  • ? Time Complexity ? O(n2)
  • ? Space Complexity ? O(1)

?? Brute Force Implementation

class Solution {
    public:
        long long countFairPairs(vector<int>& nums, int lower, int upper, long long ans = 0) {
            for(int i = 0 ; i < nums.size(); i++)
                for(int j = i + 1; j < nums.size(); j++)
                    if(nums[i] + nums[j] >= lower && nums[i] + nums[j] <= upper) ++ans;
    
            return ans;
        }
    };

? Approach 2 ? Sorting + Binary Search

  • As we need to find the number of pairs which lie in a particular range, we can think of re-ordering the equation.

  • We therefore traverse i and look for all valid j's that could form a pair with it or have pairwise sum in the given range.

  • The lowest possible value the j can have for any number i is lower - nums[i]. And the highest possible value is upper - nums[i].

  • For example : If nums[i] = 4, and lower = 5, upper = 7.

  • So the minimum value any number nums[j] should have is lower - nums[i] = 5 - 4 = 1.

  • This is because a number smaller than 1, that is, [0, -1, -2...] would be unable to form a fair pair with nums[i] as it would return a sum even smaller than lower or be < lower.

  • Similarly, the maximum value any number nums[j] should have is upper - nums[i] = 7 - 4 = 3.

  • This is because a number larger than 3, that is, [4, 5, 6...] would just exceed the upper range or be > upper.

  • ? Time Complexity ? O(n log n)

  • ? Space Complexity ? O(log n)

class Solution {
    public:
        long long countFairPairs(vector<int>& nums, int lower, int upper) {
            long long ans = 0;
            sort(nums.begin(), nums.end());
            for (int i = 0; i + 1 < nums.size(); i++) {
                int minReq = lower - nums[i], maxReq = upper - nums[i];
                auto high = upper_bound(nums.begin() + i + 1, nums.end(), maxReq);
                auto low = lower_bound(nums.begin() + i + 1, nums.end(), minReq);
                ans += (high - low);
            }
            return ans;
        }
    };

? Approach 3 ? Sorting + Two Pointers

  • Firstly we sort the array. Then, for each nums[i], we use our function countAtMost to count how many later elements nums[j] satisfy : nums[i] + nums[j] <= comp
  • On subtracting the upper range from the lower range we can find the range of numbers which on pairing up with nums[i] would give a sum >= lower and <= upper.

  • If we find a number, such that pairing it with nums[i] exceeds the comp, then we reduce the j or move to a smaller number so that the sum stays within bounds.
  • Note : The version 2 of this is finding elements from lower to right-most and upper + 1 to right-most and their difference gives us the elements within the range lower to upper.
  • This is what the version 2 looks like ?

  • ? Time Complexity ? O(n log n)
  • ? Space Complexity ? O(log n)

???Example Walkthrough

  • For nums = [0,1,7,4,4,5] and lower = 3, upper = 6:
    • Sort nums to get ?
      nums = [0, 1, 4, 4, 5, 7]
    • Compute countAtMost(nums, 6) or <= upper:
      • Initialize ans = 0, i = 0, j = 5
      1. i = 0
        • nums[0] + nums[5] = 0 + 7 = 7 > 6 ? j = 4
        • Now 0 + 5 = 5 ≤ 6 ? stop inner loop
        • ans += j - i = 4 - 0 = 4
      2. i = 1
        • nums[1] + nums[4] = 1 + 5 = 6 ≤ 6 ?
        • ans += 4 - 1 = 3 (total ans = 7)
      3. Next i = 2, but now i = 2 is not < j = 4 after decrement?
        • Actually after previous step, j remains 4, so i = 2 < 4 is true, but:
          • nums[2] + nums[4] = 4 + 5 = 9 > 6 ? j = 3
          • 4 + 4 = 8 > 6 ? j = 2
          • Now i = 2 is not < j = 2, loop exits
        • ans += j - i = 2 - 2 = 0 (still 7)
      • Result: countAtMost(nums, 6) = 7
    • Compute countAtMost(nums, 2) or <= lower - 1:
      • Initialize ans = 0, i = 0, j = 5
      1. i = 0
        • 0 + 7 = 7 > 2 ? j = 4
        • 0 + 5 = 5 > 2 ? j = 3
        • 0 + 4 = 4 > 2 ? j = 2
        • 0 + 4 = 4 > 2 ? j = 1
        • 0 + 1 = 1 ≤ 2 ? stop
        • ans += 1 - 0 = 1
      2. Next i = 1, but now i = 1 is not < j = 1, loop exits
      • Result: countAtMost(nums, 2) = 1
  • Total fair pairs = countAtMost(nums, 6) - countAtMost(nums, 2)
    = 7 - 1 = 6

class Solution {
public:
    long long countAtMost(vector<int>& nums, long long comp){
        long long ans = 0;
        for (int i = 0, j = nums.size() - 1; i < j; i++) {
            while(i < j && nums[i] + nums[j] > comp) --j;
            ans += j - i;
        }
        return ans;
    }

    long long countFairPairs(vector<int>& nums, int lower, int upper){
        sort(nums.begin(), nums.end());
        return countAtMost(nums, upper) - countAtMost(nums, lower - 1);
    }
};

Because nums[i] + nums[j] == nums[j] + nums[i] the i < j condition degrades to i != j.

So, we can sort the array, and use the two-pointer approach to count pairs less than a certain value.

We do it twice for uppper and lower, and return the difference.

Time complexity: O(sort)

C++

long long countLess(vector<int>& nums, int val) {
    long long res = 0;
    for (int i = 0, j = nums.size() - 1; i < j; ++i) {
        while(i < j && nums[i] + nums[j] > val)
            --j;
        res += j - i;
    }        
    return res;
}
long long countFairPairs(vector<int>& nums, int lower, int upper) {
    sort(begin(nums), end(nums));
    return countLess(nums, upper) - countLess(nums, lower - 1);
}

class Solution:
    def countFairPairs(self, nums: List[int], lower: int, upper: int) -> int:
        def countLess(val: int) -> int:
            res, j = 0, len(nums) - 1
            for i in range(len(nums)):
                while i < j and nums[i] + nums[j] > val:
                    j -= 1
                res += max(0, j - i)
            return res
        nums.sort()
        return countLess(upper) - countLess(lower - 1)

import java.util.Arrays;

class Solution {
    public long countFairPairs(int[] v, int lower, int upper) {
        Arrays.sort(v);
        long ans = 0;
        for (int i = 0; i < v.length - 1; i++) {
            int low = lowerBound(v, i + 1, v.length, lower - v[i]);
            int up = upperBound(v, i + 1, v.length, upper - v[i]);
            ans += up - low;
        }
        return ans;
    }
  
    private int lowerBound(int[] v, int start, int end, int target) {
        while (start < end) {
            int mid = start + (end - start) / 2;
            if (v[mid] >= target) end = mid;
            else start = mid + 1;
        }
        return start;
    }

    private int upperBound(int[] v, int start, int end, int target) {
        while (start < end) {
            int mid = start + (end - start) / 2;
            if (v[mid] > target) end = mid;
            else start = mid + 1;
        }
        return start;
    }
}

var countFairPairs = function(v, lower, upper) {
    v.sort((a, b) => a - b);
    let ans = 0;
  
    for (let i = 0; i < v.length - 1; i++) {
        const low = lowerBound(v, lower - v[i], i + 1);

function lowerBound(v, target, start) {
    let end = v.length;
    while (start < end) {
        let mid = Math.floor((start + end) / 2);
        if (v[mid] >= target) end = mid;
        else start = mid + 1;
    }
    return start;
}

function upperBound(v, target, start) {
    let end = v.length;
    while (start < end) {
        let mid = Math.floor((start + end) / 2);
        if (v[mid] > target) end = mid;
        else start = mid + 1;
    }
    return start;
}

Explanation (Step-by-Step)

  1. Sort the Array: Sorting the array allows us to efficiently find ranges of valid pairs.

  2. Iterate Through Elements: We loop through each element, considering it as the first item in a pair.

  3. Binary Search for Bounds: For each element:

    • Use lower_bound or equivalent to find the first position in the sorted array where v[j] can create a sum greater than or equal to lower.
    • Use upper_bound to find where v[j] exceeds the upper limit.

  4. Accumulate the Count: The count of valid pairs for each v[i] is the difference between upper_bound and lower_bound.

Complexity

  • Time Complexity: Sorting the array takes (O(n \log n)). Each query to find bounds runs in (O(\log n)), and we repeat it for each element in the array, resulting in a total time complexity of (O(n \log n)).
  • Space Complexity: (O(1)), aside from the input, as we only store the result.

PROBLEM EXPLANATION
You’re given an array nums and two integers: lower and upper.
Your mission? Find how many index pairs (i, j) exist where:

  • 0 <= i < j < n
  • lower <= nums[i] + nums[j] <= upper

Like choosing allies in battle, we only count those that meet a very specific trust range.

Example:

Input: nums = [0,1,7,4,4,5], lower = 3, upper = 6
Output: 6

There are six fair pairs in total.

?? STRATEGY
Let’s skip brute force. We’re not random Titans swinging wildly.
We sort nums, and for each index i, we want to find how many js (i < j) make the sum with nums[i] lie within [lower, upper].

Here’s the ODM gear:

  • Sort nums.
  • For each i, do two binary searches to find the valid j range:
    • Find how far we can go before nums[i] + nums[j] > upper.
    • Find the first j where nums[i] + nums[j] >= lower.
  • The number of valid pairs for that i is the difference between those indices.

This way, we count fair pairs in O(n log n) time.

? CODE WALKTHROUGH

class Solution:
    def countFairPairs(self, nums: List[int], lower: int, upper: int) -> int:
        nums.sort()  # ODM gear engaged — sort to enable binary search
        res = 0

        for i in range(len(nums)):
            left = bisect_left(nums, lower - nums[i], i + 1)
            right = bisect_right(nums, upper - nums[i], i + 1)
            res += right - left

        return res

Walkthrough: (python)

  • bisect_left finds the first index where sum >= lower.
  • bisect_right finds the first index where sum > upper.
  • The difference gives us how many j values work for each i.

? DRY RUN
Example: nums = [0,1,7,4,4,5], lower = 3, upper = 6
After sorting: [0,1,4,4,5,7]

Let’s look at index i = 0 (nums[i] = 0):

  • lower bound = 3 - 0 = 3
  • upper bound = 6 - 0 = 6
  • So we search in [1, 4, 4, 5, 7] for values between 3 and 6.
  • That’s 3 values (4, 4, 5).

Keep going like this for every index, and total it up.

Final result? 6 fair pairs.

? COMPLEXITY ANALYSIS

Time: O(n log n) — because we sort the array and then use binary search inside a loop.

Space: O(1) — we don’t use any extra data structures, just a few variables and pointers.
