Intuition

Apply dp solution,
dp[i][j] means the maximum steps can go from the first cell.
Initial all dp[i][j] = 0 at first,
and the smallest cell A[i][j] will start with dp[i][j] = 1.

Explanation

Sort pairs [i, j] by value of M[i][j],
and then iterate cells in increasing order.

For each M[i][j],
find out the current maximum steps in the same row and col,
dp[i][j] = max(max steps in row, max steps in col) + 1.

To make this process efficient,
we use res[i] to record the maximum step for row i,
we use res[m + j] to record the maximum step for col j.

Repeat this process until we find the steps for all cells,
return the maximum one.

Complexity

Time O(mnlogmn)
Space O(mn)

Java

    public int maxIncreasingCells(int[][] M) {
        int m = M.length, n = M[0].length;
        Map<Integer, List<int[]>> A = new TreeMap<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int val = M[i][j];
                if (!A.containsKey(val)) {
                    A.put(val, new ArrayList<int[]>());
                }
                A.get(val).add(new int[] {i, j});
            }
        }
        int[][] dp = new int[m][n];
        int[] res = new int[n + m];
        for (int a : A.keySet()) {
            for (int[] pos : A.get(a)) {
                int i = pos[0], j = pos[1];
                dp[i][j] = Math.max(res[i], res[m + j]) + 1;
            }
            for (int[] pos : A.get(a)) {
                int i = pos[0], j = pos[1];
                res[m + j] = Math.max(res[m + j], dp[i][j]);
                res[i] = Math.max(res[i], dp[i][j]);
            }
        }
        int ans = 0;
        for (int a : res)
            ans = Math.max(ans, a);
        return ans;
    }

    int maxIncreasingCells(vector<vector<int>>& M) {
        int m = M.size(), n = M[0].size();
        map<int, vector<int>> A;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                A[M[i][j]].push_back(i * n + j);
        vector<vector<int>> dp(m, vector<int>(n, 0));
        vector<int> res(n + m, 0);
        for (auto& [a, pos] : A) {
            for (int p : pos) {
                int i = p / n, j = p % n;
                dp[i][j] = max(res[i], res[m + j]) + 1;
            }
            for (int p : pos) {
                int i = p / n, j = p % n;
                res[m + j] = max(res[m + j], dp[i][j]);
                res[i] = max(res[i], dp[i][j]);
            }
        }
        return *max_element(res.begin(), res.end());
    }

    def maxIncreasingCells(self, M: List[List[int]]) -> int:
        m, n = len(M), len(M[0])
        A = defaultdict(list)
        for i in range(m):
            for j in range(n):
                A[M[i][j]].append([i, j])
        dp = [[0] * n for i in range(m)]
        res = [0] * (n + m)
        for a in sorted(A):
            for i, j in A[a]:
                dp[i][j] = max(res[i], res[~j]) + 1
            for i, j in A[a]:
                res[~j] = max(res[~j], dp[i][j])
                res[i] = max(res[i], dp[i][j])
        return max(res)

Intuition

If you look at the indices in the traditional way, this problem seems very tough.

However, by starting at the indices with the smallest value and processing the matrix from least to greatest, this problem becomes much easier.

If we traverse in this order, the only information we need as we go through the matrix is the previous max cell move count at the current row/column.

Approach

  • Keep two arrays to track the max move count seen at each row and each column
  • Make an array of indices and sort it by their respective values in the matrix
  • Traverse the sorted array and process all duplicate values together, storing the new max cell count for each index in a separate array
  • Traverse the separate array and update the new max cell count for each row and column

After we do these steps, we can just traverse either the row or column array and find the row/col with the max move count, I just picked the smaller of the two arrays.

class Solution {
    public int maxIncreasingCells(int[][] mat) {
        int n = mat.length, m = mat[0].length, index = 0, right = 0, max = 0;
        int[] rows = new int[n], cols = new int[m], temp = new int[n * m];
        int[][] sorted = new int[n * m][3];

        //store indices grouped with their respective values, and sort them by value
        for(int i = 0; i < n; i++) {
            for(int j = 0; j < m; j++) {
                sorted[index][0] = mat[i][j];
                sorted[index][1] = i;
                sorted[index++][2] = j;
            }
        }
        Arrays.sort(sorted, (a, b) -> a[0] - b[0]);

        //go through indices in ascending order
        while(right < index) {
            //go through all indices with the current value and update their max cell count
            //store this in a separate array so duplicate values wont count twice per row/col
            int left = right, val = sorted[right][0];
            while(right < index && sorted[right][0] == val) temp[right] = Math.max(rows[sorted[right][1]], cols[sorted[right++][2]]) + 1;
            //update each row and col with the new max cell count
            //we update all indices with the current value at the same time so there arent any counting errors
            for(int i = left; i < right; i++) {
                int x = sorted[i][1], y = sorted[i][2], z = temp[i];
                rows[x] = Math.max(rows[x], z);
                cols[y] = Math.max(cols[y], z);
            }
        }
        //find the max value by traversing the smaller of the two row/col arrays
        if(n <= m) for(int x : rows) max = Math.max(max, x);
        else for(int x : cols) max = Math.max(max, x);

        return max;
    }
}
