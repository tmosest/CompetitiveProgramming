? Understanding the Problem

  • We're given two arrays tasks and workers where
    • tasks[i] stores the strength of each task and
    • workers[i] stores the strength of each worker where i is any index such that 0 <= i < n.
  • Each worker from the tasks array can only be assigned a single task and we need to find the maximum number of tasks that can be completed by the workers.
  • A task can only be completed by a worker is workers[i] >= tasks[j], that is, the strength of the worker is >= the strength of the task.
  • We're also provided with some magicalPills where in some cases if workers[i] < tasks[i] then we can feed them a magical pill or use a magical pill to increase their strength such that they'll be able to perform the task if workers[i] + strength >= tasks[i], as each magic pill increases the strength of the worker by the given variable strength.
  • For example : for workers = [3, 4, 5], tasks = [2,3,4] and pills = 0.

  • In this arrangement all the tasks have been assigned a worker who has strength >= the task.
  • So all the tasks are possible, answer = 3.

? Using Binary Search + Greedy

  • The approach here is to assign the k weakest tasks to the k strongest workers and check how many of them will be able to complete these tasks.
  • The variables we'll use here are ?
    • usedPills ? to track the number of magical pills we've used so far, its value is always <= Total pills
    • workersFree ? A multiset to store the available / free workers left while assigning tasks
    • canAssign ? A flag we flip to false the moment any of the k tasks can't be matched under our pill limit.

class Solution {
public:
    int maxTaskAssign(vector<int>& tasks, vector<int>& workers, int pills, int strength) {
        int left = 0, right = min(tasks.size(), workers.size());

        sort(tasks.begin(), tasks.end());
        sort(workers.begin(), workers.end());

        while(left < right) {
            int mid = (left + right + 1) / 2;
            int usedPills = 0;
            multiset<int> workersFree(workers.end() - mid, workers.end());

            bool canAssign = true;
            for(int i = mid - 1; i >= 0; --i) {
                auto it = prev(workersFree.end());

                if(*it < tasks[i]) {
                    it = workersFree.lower_bound(tasks[i] - strength);
                    if(it == workersFree.end()) {
                        canAssign = false;
                        break;
                    }
                    ++usedPills;
                    if(usedPills > pills) {
                        canAssign = false;
                        break;
                    }
                }
                workersFree.erase(it);
            }

            if(canAssign)
                left = mid;
            else
                right = mid - 1;
        }
        return left;
    }
};

? Intuition

The key is to figure out the maximum number of tasks that can be assigned with the available number of pills.
Tasks have difficulty, workers have strength, and pills can boost strength temporarily.
This naturally leads to binary search — test how many tasks we can assign and adjust accordingly.

? Approach

  1. Sort both tasks and workers in ascending order.
  2. Use binary search to find the maximum mid number of tasks that can be completed.
  3. For each mid, check if it is possible to assign mid tasks using a helper function canAssign().
  4. Inside canAssign():
    • Try to assign from the hardest task down.
    • First, try a worker without a pill.
    • If not strong enough, try boosting weaker workers with a pill using a deque.
    • If none can do the task, return false.
  5. Continue until the optimal number of tasks is found.

? Complexity

  • Time complexity: O(nlogn+mlogm+log(min(n,m))·(n+m))

    • Sorting takes O(nlogn+mlogm)
    • Binary search runs log(min(n,m)) times with each check costing O(n+m)

  • Space complexity: O(n+m)
    Due to auxiliary data structures like deque and sorting.

class Solution {
public:
    int maxTaskAssign(vector<int>& tasks, vector<int>& workers, int pills, int strength) {
        sort(tasks.begin(), tasks.end());
        sort(workers.begin(), workers.end());

        int low = 0, high = min(tasks.size(), workers.size());

        while (low < high) {
            int mid = (low + high + 1) / 2;
            if (canAssign(tasks, workers, pills, strength, mid)) {
                low = mid;
            } else {
                high = mid - 1;
            }
        }

        return low;
    }

private:
    bool canAssign(const vector<int>& tasks, const vector<int>& workers,
                   int pills, int strength, int taskCount) {
        deque<int> boosted;
        int w = workers.size() - 1;
        int freePills = pills;

        for (int t = taskCount - 1; t >= 0; --t) {
            int task = tasks[t];

            if (!boosted.empty() && boosted.front() >= task) {
                boosted.pop_front();
            } else if (w >= 0 && workers[w] >= task) {
                --w;
            } else {
                while (w >= 0 && workers[w] + strength >= task) {
                    boosted.push_back(workers[w--]);
                }
                if (boosted.empty() || freePills == 0) {
                    return false;
                }
                boosted.pop_back();
                --freePills;
            }
        }

        return true;
    }
};
