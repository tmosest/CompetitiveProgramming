Intuition

The problem asks us to maximize the alternating sum (nums[0] - nums[1] + nums[2] - ...) by swapping elements. The key constraint is that we can only swap elements at specified pairs of indices.

If we can swap elements at indices a and b, and also at b and c, it implies we can move any number between positions a, b, and c. This reveals that any set of indices connected by these allowed swaps forms a group. Within such a group, we can arrange the numbers originally at those positions in any order we like. The problem then simplifies to: for each independent group of swappable indices, what is the best arrangement of its numbers to maximize its contribution to the total alternating sum?

The alternating sum is maximized by placing large numbers in positions that add to the sum (even indices) and small numbers in positions that subtract from it (odd indices). This leads to a greedy strategy for each group:

Identify a group of mutually swappable indices.

Collect all the numbers available within this group.

Count the number of even and odd indices in the group.

To get the maximum possible sum from this group, assign the largest available numbers to the even-indexed positions and the smallest available numbers to the odd-indexed positions.

The most efficient way to find these groups of "connected" indices is to model them as a graph where indices are vertices and swaps are edges, and then find the connected components. A Disjoint Set Union (DSU) data structure is perfect for this task.

Approach

Find Connected Components using DSU:

We use a Disjoint Set Union (DSU) or Union-Find data structure to group the indices. We initialize the DSU with n elements, where n is the length of nums, so that each index is initially in its own set.

We iterate through the swaps array. For each swap [p, q], we call the union operation on p and q. This merges the sets containing these indices.

After processing all swaps, any two indices in the same set are mutually swappable.

Group Indices and Values by Component:

We create hashmaps to gather all indices and their corresponding values for each component. For example, component_indices will map a component's root to a list of all indices in it, and component_values will map the root to a list of values.

We iterate from i = 0 to n-1. For each index i, we find its root using the DSU's find operation and add i and nums[i] to the corresponding lists in our hashmaps.

Calculate Maximum Sum for Each Component:

We iterate through each component we've identified. For each one:

Count the number of even indices (even_count) in its list of indices.

Sort its list of values in descending order.

The greedy strategy tells us to place the largest numbers at even positions. So, we add the first even_count (largest) values from the sorted list to our total answer.

The remaining smaller values must be placed at odd positions, so we subtract them from our total answer.

Return Total Sum:

The final accumulated value in our total answer is the maximum possible alternating sum.

Complexity

--Time complexity:

O(Sá?(N)+NlogN)

where N is the number of elements in nums and S is the number of swaps.

The DSU operations (processing S swaps and finding roots for N elements) take O((S+N)á?(N)), where ?(N) is the very slow-growing inverse Ackermann function, making it nearly constant time.

The dominant part of the algorithm is sorting the values within each component. In the worst-case scenario where all indices form a single component, we perform a sort on N elements, which takes O(NlogN) time.

--Space complexity:

O(N)
The DSU requires two arrays of size N (parent and compsize).

The hashmaps used to group indices and values will store a total of N indices and N values across all their entries, resulting in O(N) space.

class Solution {
private:
    void merge(int i, int j,vector<int>&compsize, vector<int>&parent){
        int ir=find(parent,i);
        int jr=find(parent,j);
        if(ir!=jr){
            if(compsize[ir]<compsize[jr]){
                swap(ir,jr);
            }parent[jr]=ir;
            compsize[ir]+=compsize[jr];
        }
    }
    int find(vector<int>&parent, int i){
        if(parent[i]==i){
            return i;
        }return parent[i]=find(parent,parent[i]);
    }
public:
    long long maxAlternatingSum(vector<int>& nums, vector<vector<int>>& swaps) {
        int n=nums.size();
        long long ans=0;
        vector<int>parent(n,0);
        for(int i=0;i<n;i++){
            parent[i]=i;
        }
        vector<int>compsize(n,1);
        unordered_map<int,vector<int>>idx;
        unordered_map<int,vector<int>>val;
        for(auto &it: swaps){
            merge(it[0],it[1],compsize,parent);
        }for(int i=0;i<n;i++){
            int root=find(parent,i);
            idx[root].push_back(i);
            val[root].push_back(nums[i]);
        }for( auto &[root,indc]:idx){
            int even=0;
            for(int ind:indc){
                if(ind%2==0){
                    even++;
                }
            }
            auto &value=val.at(root);
            sort(value.rbegin(),value.rend());
            for(int i=0;i<even;i++){
                ans+=value[i];
            }for(int i=even;i<value.size();i++){
                ans-=value[i];
            }
        }return ans;
    }
};
