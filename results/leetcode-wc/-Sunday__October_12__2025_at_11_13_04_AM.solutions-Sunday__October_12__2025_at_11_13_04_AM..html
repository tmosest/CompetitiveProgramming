By multiplying the target value k by 4, we obtain a close lower bound estimate for the value of x such that f(x)=k.

Starting the search at 4k, we perform a forward incremental scan to evaluate f(x).

If a value satisfying f(x)=k is found, we conclude—by the structure of the function—that exactly 5 such consecutive integers exist, and thus return 5.

If the search progresses to a point where f(x)>k without finding an exact match, we return 0, indicating that no such x satisfies the condition.

Because the approximation 4k is very close to the actual solution, the total number of iterations required is strictly bounded, typically fewer than 20.

const preimageSizeFZF = k => {
    const trailingZeroes = n => {
        let sum = 0;
        for (let i = 1; i <= 13; i++) {
            sum += Math.floor(n / (5 ** i))
        }
        return sum
    }

    let start = k * 4;
    let H = 0;

    while (H <= k) {
        H = trailingZeroes(start);
        if (H === k) {
            return 5;
        }
        start++;
    }

    return 0; 

};

We can optimize this using binary search, which cuts the the iteration to only 4 or 5.

For any given 'K', our answer will be 5 or 0.

5 -> When it's possible to achieve 'K' zeros
0 -> When there isn't any number whose factorial will have 'K' Zeros

0 to 4 -> 0 zeros
5 to 9 -> 1 zeros
10 to14 -> 2 zeros
15 to 19 -> 3 zeros
20 to 24 -> 4 zeros

No Range available for 5 zeros.

25 to 29 -> 6 zeros
30 to 34-> 7 zeros
35 to 39 -> 8 zeros
40 to 44 -> 9 zeros
45 to 49 -> 10 zeros

No Range available for 11 zeros.

50 to 55 -> 12 zeros

As you can see there are either 5 values for avery 'K' or none. Therefore we will simply use binary search to check if it's possible to achive 'K' Zeros we return 5 and if it's not we return Zero.

class Solution {
    public int preimageSizeFZF(int k) {
        
        long low = 0;
        long high = (long)Math.pow(10,10);
        
        while(low<=high){
            long mid  = low + (high-low)/2;
            long val = mid;
            long ans = 0;
            while(val!=0){
                val/=5;
                ans+=val;
            }
            if(ans==k){
                return 5;
            }else if(ans>k){
                high = mid-1;
            }else{
                low = mid+1;
            }
        }
        
        return 0;
    }
}
