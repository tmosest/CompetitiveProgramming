? Problem: Minimum Increments in Tree Leaves to Match Maximum Path Sum

? Intuition

The problem is to find the minimum number of nodes in a tree whose cost needs to be increased such that all root-to-leaf paths have the same sum (equal to the maximum path sum in the original tree).

Each leaf node represents the end of a path, and we want every path from the root to these leaves to have the same cost. So, we need to identify:

  • The maximum sum path among all root-to-leaf paths.
  • The deficit in other paths compared to this max path.
  • The number of non-leaf nodes whose values are less than their parent path sum and contribute to this difference.

? Approach

  1. Build Tree Representation:

    • Convert the given edges list into an adjacency list.

  2. First DFS (dfs1):

    • Calculate the sum from the root to every node.
    • This is a standard DFS where each node accumulates the sum from its parent.

  3. Second DFS (dfs2):

    • Traverse from root again and record the minimum increment needed at each node to make its path's sum equal to the maximum root-to-leaf path sum.
    • At leaves, this value is directly target - sum[u].

  4. Third DFS (dfs3):

    • Count how many nodes need an increase compared to their parent path.
    • For every node, if arr[u] > arr[parent], it means we increased it, so count it.

? Key Observations

  • The root-to-leaf paths can differ, and we only need to make the shorter cost paths equal to the max path.
  • Changes should be counted where increase happens (compared to parent).

? Time and Space Complexity

  • Time Complexity: O(n)

    • All DFS traversals visit each node exactly once.

  • Space Complexity: O(n)

    • For adjacency list, cost sum array, and DFS stack.

typedef long long ll;
class Solution {
public:
    void dfs1(int u,int p,vector<vector<int>>&adj,vector<int>&cost,vector<ll> &sum){
        for(auto v:adj[u]){
            if(v==p)continue;
            sum[v]=sum[u]+cost[v];
            dfs1(v,u,adj,cost,sum);
        } 
    }

    ll dfs2(int u,int p,vector<vector<int>>&adj,vector<ll> &sum,ll target,vector<int>&arr){
        bool isLeaf=true;
        ll mini=LLONG_MAX;
        for(int v:adj[u]){
            if(v==p)continue;
                isLeaf=false;
                mini=min(mini,dfs2(v,u,adj,sum,target,arr));
        }
        if(isLeaf){
            mini=target-sum[u];
        }
        return arr[u]=mini;
    }

    void dfs3(int u,int p,vector<vector<int>>&adj,vector<int>&arr,int &ans){
        ll parent=0;
        if(p==-1){
            parent=0LL;
        }
        else{
            parent=arr[p];
        }
        if(arr[u]>parent){
            ans++;
        }
        for(auto it:adj[u]){
            if(it==p){
                continue;
            }
            dfs3(it,u,adj,arr,ans);
        }
    }

    int minIncrease(int n, vector<vector<int>>& edges, vector<int>& cost) {
        vector<vector<int>> adj(n);
        for (auto it : edges) {
            adj[it[0]].push_back(it[1]);
            adj[it[1]].push_back(it[0]);
        }

        vector<ll>sum(n);
        sum[0]=cost[0];
        dfs1(0,-1,adj,cost,sum);

        ll target=LLONG_MIN;
        for(int u=0;u<n;u++){
            bool leaf= (u==0 ? adj[u].empty() : adj[u].size()==1);
            if(leaf)
                target=max(target,sum[u]);
        }

        vector<int>arr(n,0);
        int ans=0;
        dfs2(0,-1,adj,sum,target,arr);
        dfs3(0,-1,adj,arr,ans);

        return ans;
    }
};

? Example

Input:
n = 5
edges = [[0,1],[1,2],[1,3],[3,4]]
cost = [1,2,3,4,5]

Output:
1

The longest path is 1 -> 2 -> 3 -> 4. The other path needs increment to match its sum.

? Edge Cases

  1. Only One Node:

    • No increment needed.

  2. All Leaf Paths Equal:

    • No increment needed.

  3. Skewed Tree:

    • Works for left-heavy or right-heavy trees.
