Approach

The problem can be approached using dynamic programming (DP) with memoization. The idea is to explore all possible sequences that can be constructed using the characters "F", "W", and "E", while tracking the points and determining if the sequence wins.

Key Points:

  1. Fight function: The fight(a, b) function simulates a battle between two characters a and b. Based on predefined rules, it returns +1 if a wins, -1 if a loses, and 0 if there is a draw.
  2. Dynamic Programming (dp):
    1. dp(i, prev, point) is a recursive function that computes the number of valid sequences starting from index i of string s, where prev is the last character in the sequence, and point is the score accumulated so far.
    2. We iterate over possible choices for the current character, and ensure that it’s not the same as the previous one to avoid invalid sequences.
    3. The base case occurs when we have processed all characters of s, at which point we return 1 if the score point is greater than 0, and 0 otherwise.

Complexity

  • Time complexity: O(n * 3 * p),
  • Space complexity:O(n * 3 * p),

class Solution:
    def countWinningSequences(self, s: str) -> int:
        def fight(a, b):
            if a == "F":
                if b == "E":
                    return 1
                elif b == "W":
                    return -1
            elif a == "W":
                if b == "F":
                    return 1
                elif b == "E":
                    return -1
            else:
                if b == "W":
                    return 1
                elif b == "F":
                    return -1
            return 0

        @cache
        def dp(i, prev, point):
            if i == len(s):
                return int(point > 0)
            res = 0
            for c in "FWE":
                if c == prev:
                    continue
                res += dp(i + 1, c, point + fight(c, s[i]))
                res %= 1_000_000_007
            return res
        
        return dp(0, '', 0)

Modulus mod

The solution involves modulo arithmetic to avoid overflow. mod = 1e9 + 7 is a common prime number used for modular operations.

Main Function:

  1. The main function is countWinningSequences().
  2. It starts by converting the input string s so that:
    'F' ? 'A'
    'E' ? 'B'
    'W' ? 'C'
  3. These new values ('A', 'B', 'C') are then mapped to numerical values (0, 1, 2), corresponding to 'A' being "0", 'B' being "1", and 'C' being "2".

Dynamic Programming Table dp:

  1. A 3D DP table is initialized with size n + 500 (to allow extra space), where n is the length of the string s.

The dimensions are:

  1. The first index ind tracks the current position in the string.
    The second index last + 1 tracks the last chosen option ('A', 'B', 'C') converted to indices 0, 1, 2.
  2. The third index score + 1000 tracks the current score but shifted by 1000 to handle negative scores.

Recursive Function:

  1. The function total_count() is a recursive DP function, where:

ind is the current index in the string s.
last is the last chosen event ('A', 'B', or 'C'). It helps avoid selecting the same event consecutively.
score keeps track of the score at that point.

Base Case:

  1. If we reach the end of the string (ind >= s.length()), return 1 if the score is positive (score > 0), otherwise return 0.

Memoization:

  1. If the value at dp[ind][last + 1][score + 1000] is already calculated (i.e., not -1), return that cached value.

Recursive Transitions:

  1. For each character in the string (converted to 0, 1, or 2 for 'A', 'B', 'C'), the algorithm tries multiple transitions based on the current event and the last chosen event:

  2. If the current event is 'A' (i.e., val == 0), it attempts transitions:

  3. If the last event wasn’t 'A', it moves to the next index with 'A' and keeps the score unchanged.

  4. If the last event wasn’t 'B', it moves to the next index with 'B' and decreases the score by 1.

  5. If the last event wasn’t 'C', it moves to the next index with 'C' and increases the score by 1.

  6. Similar logic applies for 'B' (val == 1) and 'C' (val == 2), but with different score adjustments.

  7. All valid transitions are recursively evaluated, and the results are memoized in the dp table.

Return Result:

  1. After evaluating all valid paths, the result is the total number of ways the string can be traversed such that the score is positive at the end.

  2. You recursively try different combinations of choices based on the transitions allowed by the previous choice and the current score.

  3. The goal is to explore all possible ways to traverse the string so that by the time you reach the end, the score is positive.

  4. For each valid sequence (where the score is positive at the end), the function keeps a count.

        //base case;
        if(ind>=s.length()){
          return score>0?1:0;
        }

        if(dp[ind][last+1][score+1000]!=-1){
            return dp[ind][last+1][score+1000];
        }
        
        int cnt=0;
        int val=s[ind]-'A';

        if(val==0){
            if(last!=0)cnt=(cnt+(total_count(ind+1,0,s,score,dp))%mod)%mod;
            if(last!=1)cnt=(cnt+(total_count(ind+1,1,s,score-1,dp))%mod)%mod;
            if(last!=2)cnt=(cnt+(total_count(ind+1,2,s,score+1,dp))%mod)%mod;
        }
        else if(val==1){
            if(last!=0)cnt=(cnt+(total_count(ind+1,0,s,score+1,dp))%mod)%mod;
            if(last!=1)cnt=(cnt+(total_count(ind+1,1,s,score,dp))%mod)%mod;
            if(last!=2)cnt=(cnt+(total_count(ind+1,2,s,score-1,dp))%mod)%mod;

        else if(val==2){
            if(last!=0)cnt=(cnt+(total_count(ind+1,0,s,score-1,dp))%mod)%mod;

            if(last!=2)cnt=(cnt+(total_count(ind+1,2,s,score,dp))%mod)%mod;
        }

        return dp[ind][last+1][score+1000]=cnt%mod;

class Solution {
    public static Long[][][] dp;
    public static final int mod = 1000000007;

    public int countWinningSequences(String s) {
        int n=s.length();
        dp=new Long[n][4][2*n+1];
        return (int) (rec(s, 0,3, 0)%mod);
    }

    public static long rec(String s, int r,int lst,int pnt) {
        if (r== s.length()) {
            return pnt>0?1:0;
        }
        int nrml=pnt+s.length();
        if(dp[r][lst][nrml]!=null) return dp[r][lst][nrml];
        char a = s.charAt(r);
        long ways=0;
        if(lst!=0){
            ways=(ways+rec(s,r+1,0,update(pnt,a,'F')))%mod;
        }
        if(lst!=1){
            ways=(ways+rec(s,r+1,1,update(pnt,a,'E')))%mod;
        }
        if(lst!=2){
            ways=(ways+rec(s,r+1,2,update(pnt,a,'W')))%mod;
        }
        dp[r][lst][nrml]=ways;
        return ways;
    }
    public static int update(int pnt,char a,char b){
        if(b=='F'&&a=='E'){
            return pnt+1;
        }else if(b=='E'&&a=='W'){
            return pnt+1;
        }else if(b=='W'&&a=='F'){
            return pnt+1;
        }else if(a==b) return pnt;
        else return pnt-1;
    }      
}
