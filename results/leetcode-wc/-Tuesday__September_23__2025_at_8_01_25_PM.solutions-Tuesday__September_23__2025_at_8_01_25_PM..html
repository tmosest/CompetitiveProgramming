Summary

Brilliant Problem. Applying two advanced patterns at the same time, very cool

Intuition

  • Minimum cost should immediately make you think DP
  • String prefix should immediately make you think Trie

Similar Problem

  • This is nearly identical to !139 https://leetcode.com/problems/word-break/description/
  • Instead, we need to return the minimum cost instead of just true/false

Approach

  • For any given index, return the minimum cost for the remaining substring target[index..]
  • Store the possible words we can use in a Trie structure (including the cost if the node endsWords)
  • For a given index, walk down the Trie and keep track of the minimum cost.
  • Cache the minimum cost using a DP array.

class Solution {
    TrieNode root; // root of Trie structure
    Integer[] dp;  // Cached minimum costs
    int n;
    public int minimumCost(String target, String[] words, int[] costs) {
        root = new TrieNode();
        buildTrie(words, costs); // store all words in a Trie data structure with the associated costs

        n = target.length();
        dp = new Integer[n];

        int ans = topDownDP(target, 0);
        if (ans == Integer.MAX_VALUE) {
            ans = -1;
        }
        System.out.println(ans);
        return ans;
    }

    // Return the minimum cost it takes to construct the substring `target[currIndex..]
    public int topDownDP(String target, int currIndex) {
        if (currIndex >= n) {
            return 0; // there are no more letters, so the cost is 0.
        }
        if (dp[currIndex] != null) { // if we've already calculated this index minCost
            return dp[currIndex];
        }

        // The default answer is Integer.MAX_VALUE, meaning "impossible" starting at currIndex
        int ans = Integer.MAX_VALUE;

        TrieNode currNode = root;
        for (int i = currIndex; i < n; i++) {
            char nextChar = target.charAt(i);
            if (!currNode.containsKey(nextChar)) {
                break; // no such word exists in the Trie, no point in continuing
            }
            currNode = currNode.get(nextChar); // step down the Trie

            if (currNode.endsWord) {
                int localAns = topDownDP(target, i + 1);
                // if localAns == Integer.MAX_VALUE, it's impossible to use this word as a substring of `target`
                if (localAns != Integer.MAX_VALUE) {
                    localAns += currNode.cost;
                    ans = Math.min(ans, localAns);
                }
            }
        }

        dp[currIndex] = ans;
        return ans;
    }

    private void buildTrie(String[] words, int[] costs) {
        for (int i = 0; i < words.length; i++) {
            TrieNode nextNode = root;
            for (char c : words[i].toCharArray()) {
                if (!nextNode.containsKey(c)) {
                    nextNode.put(c);
                }
                nextNode = nextNode.get(c);
            }

            if (nextNode.endsWord) {
                nextNode.cost = Math.min(nextNode.cost, costs[i]); // dumb, duplicate word condition.
            } else {
                nextNode.endsWord = true;
                nextNode.cost = costs[i];
            }
        }
    }

    class TrieNode {
        boolean endsWord = false;
        TrieNode[] childrenNodes;
        // Non-standard Trie. This Trie keeps track of costs inside the node
        int cost;
        public TrieNode() {
            childrenNodes = new TrieNode[26];
        }

        public TrieNode get(Character c) {
            return childrenNodes[c - 97];
        }

        public void put(Character c) {
            if (!containsKey(c)) {
                childrenNodes[c - 97] = new TrieNode();
            }
        }

        public boolean containsKey(Character c) {
            return childrenNodes[c - 97] != null;
        }
    }
}

Intuition

To solve the problem of finding the minimum cost to construct a target string using a list of words with associated costs, we need an efficient way to manage and query the words and their costs. A Trie (prefix tree) is an ideal data structure for this purpose, as it allows fast insertion and search operations. By using a Trie, we can store each word with its associated cost and efficiently find the minimum cost to form the target string using dynamic programming.

Approach

Here are the three steps that I followed to solve this question.

  1. Trie Construction:
    Create a Trie and insert each word along with its cost.
    For each character in the word, traverse the Trie. If the corresponding child node does not exist, create it.
    At the end of each word, store the cost in the Trie node. If the node already has a cost, update it to the minimum of the existing cost and the new cost.

  2. Dynamic Programming:
    Use a dynamic programming (DP) array dp where dp[i] represents the minimum cost to form the substring target[i:].
    Initialize the DP array with Integer.MAX_VALUE to signify that the target substring has not yet been formed.
    Define a recursive function to search the Trie and update the DP array. For each character in the target, traverse the Trie and check if the current prefix can form part of the target.
    If a word in the Trie ends at a current prefix, recursively calculate the cost to form the remaining target substring and update the DP array with the minimum cost.

  3. Result:
    The value dp[0] gives the minimum cost to form the entire target string. If dp[0] remains Integer.MAX_VALUE, it means the target cannot be formed with the given words.

Complexity

  • Time complexity:

n is the length of the target string and m is the total length of all words. Building the Trie takes O(m) time. Searching the target string in the Trie and updating the DP array takes O(nám) time in the worst case.

  • Space complexity:

The Trie requires O(m) space to store all words.
The DP array requires O(n) space.

class Solution {
    public int minimumCost(String target, String[] words, int[] costs) {
        Trie t = new Trie();
        for (int i = 0; i < words.length; i++) t.insert(words[i], costs[i]);

        int[] dp = new int[target.length()];
        Arrays.fill(dp, Integer.MAX_VALUE);

        t.search(target, dp, 0);

        return dp[0] == Integer.MAX_VALUE ? -1 : dp[0];
    }
}

class Trie {
    class Node {
        Node[] children;
        int cost;
        boolean eow;

        public Node() {
            this.children = new Node[26];
            for (int i = 0; i < 26; i++) children[i] = null;
            this.cost = Integer.MAX_VALUE;
            this.eow = false;
        }
    }

    Node root = new Node();

    public void insert(String word, int c) {
        Node treeRoot = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';

            if (treeRoot.children[idx] == null) {
                treeRoot.children[idx] = new Node();
            }

            if (i == word.length() - 1) {
                treeRoot.children[idx].cost = Math.min(c, treeRoot.children[idx].cost); 
                treeRoot.children[idx].eow = true;
            }
            treeRoot = treeRoot.children[idx];
        }
    }

    public int search(String word, int[] dp, int index) {
        if (index == word.length()) return 0;
        if (dp[index] != Integer.MAX_VALUE) return dp[index];

        Node treeRoot = root;

        for (int i = index; i < word.length(); i++) {
            char ch = word.charAt(i);
            int idx = ch - 'a';

            if (treeRoot.children[idx] == null) break;

            treeRoot = treeRoot.children[idx];

            if (treeRoot.eow == true) {
                int res = search(word, dp, i + 1);
                if (res == Integer.MAX_VALUE) continue;
                dp[index] = Math.min(dp[index], treeRoot.cost + res);
            }
        }
        return dp[index];
    }
}

Intuition

Treat this as a graph to find the shortest path from 0 to n. Using Tire to store the next available path and its cost.

Approach

Normal Tire code to addWord. When try to find, using dijkstra algorithm to find the next shortest (lowest cost) can reach node (length), end when we reach the end of the string. Since dijkstra will always find the shortest, the first found out one will be the lowest cost one.

Complexity

  • Time complexity: O(n * log n)
  • Space complexity: O(n)

class Solution {
    public int minimumCost(String target, String[] words, int[] costs) {
        Tire tire = new Tire('0');
        for (int i = 0; i < words.length; i++) {
        	tire.addWord(tire, words[i], costs[i]);
        }
        return findT(target, tire);
    }

    public static int findT(String word, Tire root) {
		int n = word.length();
        int[] distTo = new int[n + 1];
        boolean[] visited = new boolean[n + 1];
        Arrays.fill(distTo, Integer.MAX_VALUE);
        distTo[0] = 0;

        Queue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(i -> i[1]));
        pq.add(new int[] {0, 0});
		
		while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            if (curr[0] == n)
            	return distTo[n];
            if (visited[curr[0]])
            	continue;
            visited[curr[0]] = true;
            
            Tire cur = root;
            for (int i = curr[0]; i < word.length(); i++){
            	char ch = word.charAt(i);
                int p = ch - 'a';
                if (cur.child[p] == null) {
                    break;
                }
                cur = cur.child[p];
                if (cur.cost > 0) {
                	if (distTo[i + 1] - cur.cost > distTo[curr[0]]) {
                        distTo[i + 1] = distTo[curr[0]] + cur.cost;
                        pq.add(new int[] {i + 1, cur.cost + distTo[curr[0]]});
                    }
                }
            }
        }
		return distTo[n] == Integer.MAX_VALUE ? -1 : distTo[n];
    }
}

class Tire {
	char current;
	Tire[] child;
	int cost;
	
	public Tire(char c) {
		current = c;
		child = new Tire[26];
		cost = 0;
	}
	
	public void addWord(Tire root, String word, int cost) {
		Tire cur = root;
        for (char ch : word.toCharArray()){
            int p = ch - 'a';
            if (cur.child[p] == null){
                cur.child[p] = new Tire(ch);
            }
            cur = cur.child[p];
        }
        if (cur.cost == 0 || cur.cost > cost)
            cur.cost = cost;
    }
}

class Solution {

    private static class TrieNode {
        private boolean isEnd;
        private int cost;
        private TrieNode[] children;

        private TrieNode() {
            this.children = new TrieNode[26];
            this.cost = -1;
        }
    }

    private static class Trie {
        TrieNode root;

        private Trie() {
            root = new TrieNode();
        }

        private void addWord(String str, int cost) {
            TrieNode curr = root;
            int length = str.length();
            for (int i = 0; i < length; i++) {
                char currChar = str.charAt(i);
                int index = currChar - 'a';
                if (curr.children[index] == null) {
                    curr.children[index] = new TrieNode();
                }
                curr = curr.children[index];
            }
            curr.isEnd = true;
            if (curr.cost == -1) {
                curr.cost = cost;
            } else {
                curr.cost = Math.min(curr.cost, cost);
            }
        }

        private int search(String target, int[] minCost, int index) {
            int length = target.length();
            if (index == length) {
                return 0;
            }
            if (minCost[index] != -1) {
                return minCost[index];
            }
            
            TrieNode currNode = root;
            for (int i = index; i < length; i++) {
                char currChar = target.charAt(i);
                if (currNode.children[currChar - 'a'] == null) {
                    break;
                }
                currNode = currNode.children[currChar - 'a'];
                if (currNode.isEnd) {
                    int result = search(target, minCost, i + 1);
                    if (result == -1) {
                        continue;
                    }
                    if (minCost[index] == -1) {
                        minCost[index] = currNode.cost + result;
                    } else {
                        minCost[index] = Math.min(minCost[index], currNode.cost + result);
                    }
                }
            }
            return minCost[index];
        }
    }

    public int minimumCost(String target, String[] words, int[] costs) {
        if (target == null || target.length() == 0) {
            return 0;
        }
        int length = target.length();
        Trie trie = new Trie();
        for (int i = 0; i < words.length; i++) {
            trie.addWord(words[i], costs[i]);
        }

        int[] minCost = new int[length];
        Arrays.fill(minCost, -1);
        
        trie.search(target, minCost, 0);

        // System.out.println(Arrays.toString(minCost));
        return minCost[0];
    }
}

Intuition

Look-alike LC-140 task. We can use trie for faster sub-string match.

Approach

We build a trie from the words. Then we do a Top-Down DP. For each index go through Trie. If we find the end of the word - we can try to search starting with its end.

Complexity

  • Time complexity:
    O(target.length()*words.length)

  • Space complexity:
    O(target.length()2)

Code

class Solution {
    static Node root;
    public int minimumCost(String target, String[] words, int[] costs) {
        root = new Node();
        for (int i = 0; i < words.length; i++) {
            insert(words[i].getBytes(), costs[i]);
        }
        Integer[] dp = new Integer[target.length()];
        int res = recursion(dp, target.getBytes(), 0);
        return res == Integer.MAX_VALUE ? -1 : res;
    }

    static int recursion(Integer[] dp, byte[] b, int ix) {
        if (ix == b.length) {
            return 0;
        }
        if (dp[ix] != null) {
            return dp[ix];
        }
        int res = Integer.MAX_VALUE;
        Node n = root;
        for (int i = ix; i < b.length; i++) {
            int j = b[i] - 'a';
            if (n.children[j] == null) {
                break;
            }
            n = n.children[j];
            if (n.cost != Integer.MAX_VALUE) {
                int tmp = recursion(dp, b, i + 1);
                if (tmp != Integer.MAX_VALUE) {
                    res = Math.min(res, tmp + n.cost);
                }
            }
        }

        return dp[ix] = res;
    }

    static void insert(byte[] b, int cost) {
        Node n = root;
        for (int i = 0; i < b.length; i++) {
            int ix = b[i] - 'a';
            if (n.children[ix] == null) {
                n.children[ix] = new Node();
            }
            n = n.children[ix];
        }

        n.cost = Math.min(n.cost, cost);
    }
}

class Node {
  Node[] children;
  int cost;

  Node() {
    cost = Integer.MAX_VALUE;
    children = new Node[26];
  }
}

class TrieNode {
    Map<Character, TrieNode> children;
    int cost;

    public TrieNode() {
        children = new HashMap<>();
        cost = Integer.MAX_VALUE;
    }
}

class Trie {
    TrieNode root;

    public Trie() {
        root = new TrieNode();
    }

    public void insert(String word, int cost) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            if (!node.children.containsKey(c)) {
                node.children.put(c, new TrieNode());
            }
            node = node.children.get(c);
        }
        node.cost = Math.min(node.cost, cost);
    }
}

class Solution {
    public int minimumCost(String target, String[] words, int[] costs) {
        int n = target.length();
        Trie trie = new Trie();

        // Insert all words into Trie with their respective costs
        for (int i = 0; i < words.length; ++i) {
            trie.insert(words[i], costs[i]);
        }

        // Initialize dp array with Integer.MAX_VALUE
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        // Process the target string to find the minimum cost
        for (int i = 0; i < n; ++i) {
            if (dp[i] == Integer.MAX_VALUE) continue;
            TrieNode node = trie.root;
            for (int j = i; j < n; ++j) {
                char c = target.charAt(j);
                if (!node.children.containsKey(c)) break;
                node = node.children.get(c);
                if (node.cost != Integer.MAX_VALUE) {
                    dp[j + 1] = Math.min(dp[j + 1], dp[i] + node.cost);
                }
            }
        }

        return dp[n] == Integer.MAX_VALUE ? -1 : dp[n];
    }
}

Trie and DP, and why this doesn't TLE.
Samuel

Intuition

As this is a minimization problem, we are directed towards dynamic programming. Also, since this problem
involves searching in a set of strings, we use a trie.

Approach

My approach was to try an O(n2) solution and see if it will pass... and it did! You will see why in the complexity analysis.

First, we construct a trie with every word in words, modifying the trie to hold additional data about the cost of including a word. Then, we initialize a dynamic programming array representing the minimum cost to construct each prefix of target.

We do a linear search for each starting point in target, updating our Trie search and DP states accordingly. The answer is then dp[target.length].

Complexity

  • Time complexity: O(nn?). The worst possible test case is:
words = [a, aa, aaa, ...]
target = aaa...aaa.

This maximizes the number of matches for each subarray in target. But note that words in the worst case has only distinct elements. Since we are given that sum(words[i].length) <= 50_000, and deriving from the well known identity 1+2+É+N=O(N2) we can conclude that there are at most N? unique strings in words in the worst case and thus a total running time of O(nn?). See item 4 in this codeforces blog post for more information.

  • Space complexity: O(words.length+target.length), for the trie structure and dynamic programming array.

class Solution {
    static final int INF = Integer.MAX_VALUE / 2;
    public int minimumCost(String target, String[] words, int[] costs) {
        TrieNode trie = new TrieNode();
        for (int i = 0; i < words.length; i++) {
            trie.insert(words[i].toCharArray(), costs[i], 0);
        }
        int[] dp = new int[target.length() + 1];
        for (int i = 1; i < dp.length; i++) dp[i] = INF;
        for (int a = 0; a < target.length(); a++) {
            TrieNode node = trie;
            for (int b = a + 1; b <= target.length(); b++) {
                node = node.get(target.charAt(b-1));
                if (node == null) break;
                if (node.match()) dp[b] = Math.min(dp[b], dp[a] + node.cost());
            }
        }
        return dp[target.length()] == INF ? -1 : dp[target.length()];
    }
}

class TrieNode {
    TrieNode[] next;
    boolean terminal;
    int cost = Integer.MAX_VALUE;
    public void insert(char[] s, int cost, int i) {
        if (i == s.length) { this.terminal = true; this.cost = Math.min(cost, this.cost); }
        else {
            char at = s[i];
            if (next == null) next = new TrieNode[26];
            if (next[at - 'a'] == null) next[at - 'a'] = new TrieNode();
            next[at - 'a'].insert(s, cost, i+1);
        }
    }
    public TrieNode get(char c) {
        if (next == null) return null;
        return next[c - 'a'];
    }
    public boolean match() {
        return this.terminal;
    }
    public int cost() {
        return this.cost;
    }
}

class Solution {

    class Trie {
        Trie suffix = null;
        Trie dict = null;
        Trie[] child = new Trie[26];
        int wordId = -1;
    }

    Trie root = null, cur = null;

    private void createTrie(String[] words, int[] costs) {

        //initializing the root
        root = new Trie();
        root.suffix = root.dict = root;

        //creating the trie for all the words
        for (int i = 0; i < words.length; i++) {

            Trie u = root;

            for (char ch : words[i].toCharArray()) {

                if (u.child[ch - 'a'] == null)
                    u.child[ch - 'a'] = new Trie();

                u = u.child[ch - 'a'];
            }

            if (u.wordId < 0 || costs[u.wordId] > costs[i])
                u.wordId = i;
        }

        //creating the suffix and dictionary/output link
        Queue<Trie> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {

            Trie u = queue.poll();

            for (int i = 0; i < 26; i++) {

                Trie v = u.child[i];

                if (v == null) continue;

                Trie p = u.suffix;
                while (p != root && p.child[i] == null)
                    p = p.suffix;

                if (u != root && p.child[i] != null)
                    v.suffix = p.child[i];
                else
                    v.suffix = root;

                v.dict = v.suffix.wordId >= 0 ? v.suffix : v.suffix.dict;
                queue.offer(v);
            }
        }

        cur = root;
    }

    public int minimumCost(String target, String[] words, int[] costs) {

        createTrie(words, costs);

        int n = target.length(), INF = 1000_000_000;
        int dp[] = new int[n + 1];


        for (int i = 1; i <= n; i++) {

            int ch = target.charAt(i - 1) - 'a';
            dp[i] = INF;

            //finding the longest suffix that is also an output/dict
            Trie start = root; //It will  point to the longest suffix that is also a dict
            while (cur != root && cur.child[ch] == null)
                cur = cur.suffix;

            if (cur.child[ch] != null) {
                cur = cur.child[ch];
                start = cur.wordId >= 0 ? cur : cur.dict;
            }
            

            //traversing the longest to the shortest words ending with t[i - 1]
            while (start != root) {
                int j = start.wordId;
                dp[i] = Math.min(dp[i], costs[j] + dp[i - words[j].length()]);
                start = start.dict;
            }
        }

        return dp[n] == INF ? -1 : dp[n];
    }
}
