Intuition

  • Need to apply binary search by assuming each of the sub-string size from 1 to s.size and find the optimal length

Approach

  • Clasical binary search code where we need to minimise the answer
  • The important part of this problem is the isValid function that check if a particular mid length substring is answer or not

    • To check this we break this in to two cases:

    • Case 1: When mid is equal to 1
      • in this case we have only two possible substring possible - one with start char is 1 where other with start char is 0. (i.e 10101010... or 01010101.... )
      • so simply check in which of the above two we can possibly filp with in given numOps operations
      • To do this you can simply consider start char as '1' once and keep on fliping it and check the number of mismatch with the original string. The number of missmatch will be the operation needed to covert the string to 101010... Similarly we can start with start char equal to '0' and keep on counting the number of missmatch
    • Case 2: When mid is not equal to 1

      • In this case we count the continous chars in s

      • when there is mis match then for the total cont char we need to break it in to multiple smaller part where each part have less then equal to mid count of continuous char

      • To do this we just need to divede the count by (mid + 1) and that many number of flip is needed

      • For example :
        Let say we have 1000001 and mid equal to 2 and ops is 2
        the continuos count o zeros here is 5 and so we can split it in to two group by fliping the the last of first (mid +1) chars of '0' that is the 3rd zero we can flip it to 1 resulting in 1001001. We can get this by (count)/(mid + 1).

Complexity :

  • Time : O(N.logN)
  • Space : O(1)

bool check(string& s, int numOps, int mid, char startChar){
    for(int i = 0; i < s.size(); ++i){
        if(startChar == s[i]) numOps--;
        startChar = (startChar == '0')?'1':'0';
    }
    return (numOps >= 0);
}

bool isValid(string& s, int numOps, int mid){
    if(mid == 1) return check(s, numOps, mid, '1') || check(s, numOps, mid, '0');
    int count = 0;
    for(int i = 0, last = -1; i < s.size(); ++i){
        if(s[i] == last) count++; 
        else{
            numOps -= count/(mid+1);
            last = s[i];
            count = 1;
        }
    }
    if(count > mid) numOps -= count/(mid+1);
    return (numOps >= 0);
}

int minLength(string s, int numOps) {
    int start = 1, end = s.size(), mid, ans = s.size();
    while(start <= end){
        mid = start + (end - start)/2;
        if(isValid(s, numOps, mid)){
            ans = mid;
            end = mid - 1;
        }else start = mid + 1;
    }
    return ans;
}

Find minimum == Binary Search ?

Intuition

Most problems that ask to find minimum or maximum are either greedy or binary search
In this case it’s binary search

Approach

First split s into runs of equal characters
So s = “0011011100” would turn into [2, 2, 1, 3, 2]

Say we want to try to see if we can make the longest substring in s equal to an arbitrary length L

Then we only have to worry about the current runs in s that have length > L
If the current run has length R > L, then we need R/(L+1) operations to split R into lengths of <= L

Try with small cases on your own to see why this is the case

So if we sum all these number of operations over the runs in s, then we can compare it to numOps and see if it’s possible to make the longest substring of s length L
i.e. if sum > numOps then it’s not possible; if sum <= numOps then it’s possible

This means we can binary search over the length of L to find the minimum

BUT THERE IS AN EDGE CASE WHEN BINARY SEARCHING
If we’re currently checking for L = 1, we need to switch our counting strategy because something like s = “0110” messes it up
Because L = 1, s is just alternating between 0’s and 1’s
So find the number of operations to make s start with 0, and the number of operations to make s start with 1, and take the minimum of the two

Code

class Solution {
    public int minLength(String s, int numOps) {
        int n = s.length();
        if(n == 1) {
            return 1;
        }


        int[] runs = getRuns(s);
        
        int maxRun = 0;
        for(int r : runs) {
            maxRun = Math.max(maxRun, r);
        }


        if(numOps == 0) {
            return maxRun;
        }


        int low = 1;
        int high = maxRun;
        int ans = maxRun;


        while(low <= high) {
            int mid = (low + high) / 2;
            int cost = 0;
            if(mid == 1) {
                int cnt = 0;
                for(int i = 0; i < n; i++) {
                    if(i % 2 == 0) {
                        if(s.charAt(i) == '1') cnt++;
                    } else {
                        if(s.charAt(i) == '0') cnt++;
                    }
                }
                
                int cnt1 = 0;
                for(int i = 0; i < n; i++) {
                    if(i % 2 == 1) {
                        if(s.charAt(i) == '1') cnt1++;
                    } else {
                        if(s.charAt(i) == '0') cnt1++;
                    }
                }
                cost = Math.min(cnt1, cnt);
            } else {
                cost = qwe(runs, mid);
            }
            


            if(cost <= numOps) {
                ans = mid;
                high = mid - 1; 
            } else {
                low = mid + 1;
            }
        }


        return ans;
    }


    public int[] getRuns(String s) {
        List<Integer> list = new ArrayList<>();
        int n = s.length();
        
        int count = 1;
        for (int i = 1; i < n; i++) {
            if (s.charAt(i) == s.charAt(i - 1)) {
                count++;
            } else {
                list.add(count);
                count = 1;
            }
        }
        list.add(count);
        
        int[] runs = new int[list.size()];
        for(int i = 0; i < list.size(); i++) {
            runs[i] = list.get(i);
        }
        return runs;
    }


    public int qwe(int[] runs, int L) {
        int total = 0;
        for(int r : runs) {
            total += (r) / (L+1);
        }
        return total;
    }
}
