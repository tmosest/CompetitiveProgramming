class Solution {
public:
    using ll = long long;
    ll sumOfLargestPrimes(const string &s) {
        vector <ll> primes;
        for (ll i = 0; i < s.size(); i++) {
            ll temp = 0;
            for (ll j = i; j < s.size(); j++) {
                temp = temp * 10 + (s[j] - '0');
                if (isPrime(temp)) {
                    primes.emplace_back(temp);
                }
            }
        }

        sort(primes.begin(), primes.end());
        primes.erase(unique(primes.begin(), primes.end()), primes.end());
        ll m = primes.size();
        if (m < 3) 
            return accumulate(primes.begin(), primes.end(),0ll);
        return primes[m - 1] + primes[m - 2] + primes[m - 3];
}

    bool isPrime(ll n) {
        if (n < 2) return false; 
        for (ll i = 2; i*i <= n; i++)
            if (n % i == 0) return false;
        return true;
    }
};

Approach

The solution aims to find all unique prime numbers that can be formed from substrings of the input string s, and then sum the largest three of these primes.

1. The is_prime(num) Function

This is a helper function designed to determine if a given number num is prime.

  • It first handles base cases:
    • Numbers less than or equal to 1 are not prime, so it returns False.
    • The numbers 2 and 3 are prime, so it returns True for these.
  • Next, it includes an optimization:
    • If num is divisible by 2 or 3 (and isn't 2 or 3 itself), it cannot be prime, so it returns False. This check quickly eliminates many composite numbers.
  • For numbers greater than 3, the function uses the property that all prime numbers can be expressed in the form 6k±1.
    • It initializes a variable i to 5.
    • It then enters a while loop that continues as long as i * i <= num. We only need to check for divisors up to the square root of num. If num has a divisor larger than its square root, it must also have a corresponding divisor smaller than its square root.
    • Inside the loop, it checks if num is divisible by i or by i + 2. If it is divisible by either, num is not prime, and the function returns False.
    • i is then incremented by 6 in each iteration, ensuring that the checks num % i and num % (i + 2) cover potential divisors of the form 6k±1 (e.g., 5 and 7, then 11 and 13, then 17 and 19, and so on).
  • If the loop completes without finding any divisors, num is prime, and the function returns True.

2. The sumOfLargestPrimes(self, s: str) Method

This is the main method that orchestrates the process of finding prime numbers from substrings and summing them.

  • It initializes an empty set called primes. A set is used to store the prime numbers found because sets automatically ensure that each prime number is stored only once, even if it's formed multiple times from different substrings.
  • It gets the length of the input string s and stores it in n.

Generating Numbers from Substrings and Checking Primality

The core logic for finding primes involves iterating through all possible substrings of s, converting these substrings into integer values, and then using the is_prime helper function to check if they are prime. The provided solution generates numbers in a specific way:

  • It uses a for loop where i ranges from 0 to n-1. The variable i represents the starting index of a substring.
  • Inside this loop, a variable c is initialized with the integer value of the single character s[i]. For example, if s[i] is '7', c becomes 7.
  • This single-digit number c is immediately checked for primality using is_prime(c). If it's prime, it's added to the primes set.
  • Then, a nested for loop starts, where j ranges from i + 1 to n-1. This inner loop is responsible for extending the number c by appending subsequent digits from the string s.
    • In each iteration of this inner loop, c is updated: c = c * 10 + int(s[j]). This effectively takes the existing number c, shifts it one decimal place to the left (by multiplying by 10), and then adds the integer value of the next character s[j]. For instance, if c was 2 and s[j] is '3', c becomes 2*10+3=23.
    • This newly formed multi-digit number c is then checked for primality using is_prime(c). If it's prime, it's added to the primes set.

This nested loop structure ensures that all contiguous substrings are effectively converted into numbers and checked. For example, if s = "123":

  1. i = 0 (s[0] = '1'):
    • c = int('1') = 1. is_prime(1) is false.
    • Inner loop j:
      • j = 1 (s[1] = '2'): c = 1 * 10 + int('2') = 12. is_prime(12) is false.
      • j = 2 (s[2] = '3'): c = 12 * 10 + int('3') = 123. is_prime(123) is false (it's 3*41).
  2. i = 1 (s[1] = '2'):
    • c = int('2') = 2. is_prime(2) is true. primes gets 2.
    • Inner loop j:
      • j = 2 (s[2] = '3'): c = 2 * 10 + int('3') = 23. is_prime(23) is true. primes gets 23.
  3. i = 2 (s[2] = '3'):
    • c = int('3') = 3. is_prime(3) is true. primes gets 3.
    • Inner loop does not run.

The problem statement notes that "any leading zeros are ignored" when converting a substring to an integer. The method c = c * 10 + int(s[j]) handles this naturally. If s[i] is '0', c starts as 0. If the next digit s[j] is '7', c becomes 0*10+7=7.

Sorting and Summing the Primes

Once all substrings have been processed and the primes set contains all unique prime numbers found:

  • The set primes is converted into a list.
  • This list is then sorted in descending order (largest to smallest) using sorted(list(primes), reverse=True).
  • A slice [:3] is taken from this sorted list. This operation retrieves:
    • The three largest prime numbers if there are three or more primes in the list.
    • All prime numbers if there are fewer than three (e.g., 0, 1, or 2 primes). For example, if the sorted list is [11, 2], [:3] will result in [11, 2]. If the list is empty, [:3] results in an empty list.
  • Finally, the sum() function is called on this slice.
    • If three or more primes were found, it sums the three largest.
    • If fewer than three primes were found, it sums all of them.
    • If no primes were found, the slice is an empty list, and sum([]) correctly returns 0.

Example Walkthrough (s = "12234")

  1. The is_prime function is available.
  2. primes is initialized as an empty set. n is 5.
  3. The loops proceed as described:
    • i = 0 (s[0] = '1'):
      • c = 1. Not prime.
      • c becomes 12 (not prime), then 122 (not prime), then 1223 (prime, added to primes), then 12234 (not prime).
      • primes = {1223}
    • i = 1 (s[1] = '2'):
      • c = 2. Prime, added to primes.
      • c becomes 22 (not prime), then 223 (prime, added to primes), then 2234 (not prime).
      • primes = {1223, 2, 223}
    • i = 2 (s[2] = '2'):
      • c = 2. Prime (already in set).
      • c becomes 23 (prime, added to primes), then 234 (not prime).
      • primes = {1223, 2, 223, 23}
    • i = 3 (s[3] = '3'):
      • c = 3. Prime, added to primes.
      • c becomes 34 (not prime).
      • primes = {1223, 2, 223, 23, 3}
    • i = 4 (s[4] = '4'):
      • c = 4. Not prime.
      • Inner loop does not run.
  4. The final primes set is {2, 3, 23, 223, 1223}.
  5. Sorting and Summing:
    • sorted(list(primes), reverse=True) gives [1223, 223, 23, 3, 2].
    • Slicing [:3] gives [1223, 223, 23].
    • sum([1223, 223, 23]) results in 1469.

This matches the example output, demonstrating the solution correctly identifies the required primes and calculates their sum according to the problem's rules.

class Solution:
    def sumOfLargestPrimes(self, s: str) -> int:
        def is_prime(num):
            if num <= 1:
                return False
            if num <= 3:
                return True
            if num % 2 == 0 or num % 3 == 0:
                return False
            i = 5
            while i * i <= num:
                if num % i == 0 or num % (i + 2) == 0:
                  return False
                i += 6
            return True
        
        primes = set()
        n = len(s)
        for i in range(n):
            c = int(s[i])
            if is_prime(c): primes.add(c)
            for j in range(i + 1, n):
                c = c * 10 + int(s[j])
                if is_prime(c): primes.add(c)

        return sum(sorted(primes, reverse=True)[:3])
