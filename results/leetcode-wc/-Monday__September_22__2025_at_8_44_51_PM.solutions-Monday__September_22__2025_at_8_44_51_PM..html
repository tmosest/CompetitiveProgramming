class Solution {
    
    public int cherryPickup(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;
        return helper(grid, 0, 0, cols-1);
    }
    
    public int helper(int[][] grid, int currRow, int robotACol, int robotBCol) {
        
        if(robotACol < 0 || robotBCol < 0 || robotACol >= grid[0].length || robotBCol >= grid[0].length) return 0;
        
        if(currRow == grid.length) return 0; // last row
        
        int result = 0;
        result += grid[currRow][robotACol];
        result += grid[currRow][robotBCol];
        
        int max = 0; // DFS for next row
        for(int x=robotACol-1;x<=robotACol+1;x++) {
            for(int y=robotBCol-1;y<=robotBCol+1;y++) {
                if(x < y) {
                    max = Math.max(max, helper(grid, currRow+1, x, y));
                }
            }
        }
        
        result += max; // add maximum result
        return result;
    }
}

    public int cherryPickup(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;

        int[][][] dp = new int[m][n][n];
        int ans = 0;

        for(int i=0;i<m;i++)
            for(int j=0;j<n;j++)
                Arrays.fill(dp[i][j], -1);

        dp[0][0][n-1] = grid[0][0] + grid[0][n-1];

        for(int i=1;i<m;i++) {
            for(int j=0;j<n;j++) { // robotA
                for(int k=j+1;k<n;k++) { // robotB
                    int max = -1;
                    for(int x=-1;x<=1;x++) { // we will have total 9 combinations
                        for(int y=-1;y<=1;y++) {

                    if(max != -1)
                        dp[i][j][k] = max + grid[i][j] + grid[i][k];
                    if(ans < dp[i][j][k]) ans = dp[i][j][k];
                }
            }
        }

        return ans;
    }

So, without any further due let's start,
The idea is to use dynamic programming because this is an optimization problem (ie. finding the maximum or minimum of something) and there are quite clearly overlapping sub-problems.

Approach Explanation :-
Overall Summary:

  1. Move both robots at a time row by row. Note we just need to keep track of columns where 2 of the robots were earlier.
  2. At each row: If we looked at robot moves (i + 1, j - 1), (i + 1, j), or (i + 1, j + 1), robot moves have 3 choices for column {-1, 0, +1}
  3. Now, if we consider moving 2 robots to maximize cherry count - we total have maximum 3 (1st robot) * 3 (2nd robot) = 9 choices
  4. If both robots land in the same cube - we have to just take that cherry count once. Case is handled by looking at column value of robot1 and robot2

Detailed Explanation:
In this problem, we will assume that both robots will move to the next row at the same so both of them will keep in the same row. This will be the first insight to solve this problem.
As descriped in the problem statement, we can move into 3 directions (i+1, j-1) , (i+1, j) or (i+1, j+1). All of them in the next row but with different column.

Since we have 3 directions for each robot so at each row there are 9 (3 x 3) states that we can move to. (3 states for the first robot and 3 states for the second robot so it's 3 x 3).

And as the hint states we need to have a DP array of 4 row's. As, it is a 3 dimensional array, there will be a 2 dimensional array which will be n * m i.e. no. of column * no. of column. Where row will befine Robot1 column position & column will decide Robot2 column position
Let me show you this by a diagram what i mean is:

Intially we know, that robot1 is at position "0" & robot2 is at position column - 1 i.e last column.

We need to fill dp[0] i.e. 1st row and in that 1st row, the column position for both the robot will be (0, 2) as 0 signify the column position for robot1 and 2 signify the column position for robot2 in the grid.

When we fill the space we get the value 3 + 1 i.e 4
Now we need to fill the 2nd row. And in 2nd row as well there will be a n * m matrix. If we take the previous position of robot1 to be 0 then we have 3 column that it can go in the next row i.e. col {-1, 0, 1}
As col1 is out of bound we reject that "-1" and only keep "0, 1"

And similar the robot2 is at 2, we can either reach col {1, 2, 3}
As col3 is out of bound we reject it "3" and only keep "1, 2"

Now when we create the combination of all the column that robot1 & robot2 can be, we get 4 values and when we fill it will be:

So, how we will be filling these values and what values will be reciding in each cell.
So, if we see for (0, 1) the value reciding will be grid[0][1] + grid[1][1] + prev But for (1,1) it will be grid[1][1] + prev

1. Recursive + Memoization (Top-Down DP)

Detailed Intuition:

We start with two robots:

  • Robot1 at (0, 0) (top-left corner)
  • Robot2 at (0, m-1) (top-right corner)

At every row, both robots will move down to the next row simultaneously. Each robot has 3 possible moves: diagonally left (j-1), straight down (j), or diagonally right (j+1). Since we have two robots, that gives 3 * 3 = 9 combinations of moves to explore at each step.

Now, the state of the problem can be described by:

  • i: current row index (0 to n-1)
  • j1: current column of robot1
  • j2: current column of robot2

So our function cherry(i, j1, j2) returns the maximum cherries collectable from row i to the last row if robot1 is at (i, j1) and robot2 is at (i, j2).

Step-by-step reasoning:

  1. Bounds check:
    If either j1 or j2 goes outside the grid (less than 0 or greater than m-1), this path is invalid ? return a very negative number (-1e6) so that this path never contributes to max.

  2. Base case (last row):
    If i == n-1 (we reached the bottom row), then the robots collect cherries from their current cells.

    • If they are on the same cell (j1 == j2), only count it once.
    • If they are on different cells, add both cells.
      Return this value.

  3. Recursive case:
    Otherwise, calculate the cherries for the current row:

    • If j1 == j2, current cherries = grid[i][j1].
    • Else, current cherries = grid[i][j1] + grid[i][j2].
      Then explore all 9 combinations of next moves (j1+move1, j2+move2) for move1, move2 ? {-1,0,1}. For each move, call recursion for the next row: cherry(i+1, newJ1, newJ2).
      Add current cherries to the result from the recursive call and take the maximum among all moves.

  4. Memoization:
    Because the same state (i, j1, j2) can be reached from different paths, we use a 3D array dp[i][j1][j2] to store already computed results. This avoids exponential recomputation and reduces time complexity to O(n * m * m * 9) which simplifies to O(n * m^2).

This recursive thinking is very natural because it mirrors how we simulate both robots moving down row by row. Memoization ensures efficiency.

Code (Recursive + Memoization):

Java
class Solution {
    public int cherryPickup(int[][] grid) {
        int n = grid.length;
        int m = grid[0].length;
        int[][][] dp = new int[n][m][m];
        for (int[][] row1 : dp) {
            for (int[] row2 : row1) {
                Arrays.fill(row2, -1);
            }
        }
        // Start from row=0, robot1 at col=0, robot2 at col=m-1
        return cherry(0, 0, m - 1, grid, dp);
    }

    private int cherry(int i, int j1, int j2, int[][] grid, int[][][] dp) {
        int m = grid[0].length;

        // Out of bounds check
        if (j1 < 0 || j1 >= m || j2 < 0 || j2 >= m) {
            return -1000000; 
        }

        // Base case: last row
        if (i == grid.length - 1) {
            if (j1 == j2) return grid[i][j1];
            return grid[i][j1] + grid[i][j2];
        }

        // Memoization check
        if (dp[i][j1][j2] != -1) return dp[i][j1][j2];

        int ans = Integer.MIN_VALUE;

        // Explore all 9 possible moves
        for (int move1 = -1; move1 <= 1; move1++) {
            for (int move2 = -1; move2 <= 1; move2++) {
                int next = cherry(i + 1, j1 + move1, j2 + move2, grid, dp);
                if (j1 == j2) {
                    ans = Math.max(ans, grid[i][j1] + next);
                } else {
                    ans = Math.max(ans, grid[i][j1] + grid[i][j2] + next);
                }
            }
        }

        return dp[i][j1][j2] = ans;
    }
}

2. Bottom-Up Tabulation (Iterative DP)

Detailed Intuition:

Instead of recursion, we can directly fill a DP table iteratively. Again, the state is (i, j1, j2) meaning: maximum cherries robots can collect from row i to bottom if robot1 is at (i, j1) and robot2 is at (i, j2).

The difference is:

  • In recursion, we start at the top (0, 0, m-1) and go down.
  • In tabulation, we start from the bottom (n-1) row (base case) and build upwards row by row until we reach row 0.

Step-by-step reasoning:

  1. Base case initialization:
    On the last row (i = n-1), fill dp[n-1][j1][j2].

    • If j1 == j2, dp[n-1][j1][j2] = grid[n-1][j1].
    • Else, dp[n-1][j1][j2] = grid[n-1][j1] + grid[n-1][j2].

  2. Transition:
    For each row i from n-2 up to 0:
    For each possible j1, j2 positions:

    • Collect cherries from current row (grid[i][j1] + grid[i][j2] or only one if same cell).

    • Then, look at the next row’s states: check all 9 move combinations (j1+move1, j2+move2). Among valid moves, pick the maximum dp[i+1][newJ1][newJ2].

    • So,

      dp[i][j1][j2] = cherriesAtCurrent + max(dp[i+1][newJ1][newJ2])

  3. Final answer:
    After filling the table, our answer will be at dp[0][0][m-1] because robot1 starts at column 0 and robot2 at column m-1 on row 0.

Complexity:

Time: O(n * m * m * 9) ? simplified to O(n * m^2).
Space: O(n * m * m).

This bottom-up method is systematic and avoids recursion depth issues.

Code (Bottom-Up Tabulation):

Java
class Solution {
    public int cherryPickup(int[][] grid) {
        int n = grid.length;
        int m = grid[0].length;
        int[][][] dp = new int[n][m][m];

        // Base case: last row
        for (int j1 = 0; j1 < m; j1++) {
            for (int j2 = 0; j2 < m; j2++) {
                if (j1 == j2) {
                    dp[n - 1][j1][j2] = grid[n - 1][j1];
                } else {
                    dp[n - 1][j1][j2] = grid[n - 1][j1] + grid[n - 1][j2];
                }
            }
        }

        // Fill DP from bottom row up to row 0
        for (int i = n - 2; i >= 0; i--) {
            for (int j1 = 0; j1 < m; j1++) {
                for (int j2 = 0; j2 < m; j2++) {
                    int ans = Integer.MIN_VALUE;

                    // Explore all 9 moves
                    for (int move1 = -1; move1 <= 1; move1++) {
                        for (int move2 = -1; move2 <= 1; move2++) {
                            int newJ1 = j1 + move1;
                            int newJ2 = j2 + move2;
                            if (newJ1 >= 0 && newJ1 < m && newJ2 >= 0 && newJ2 < m) {
                                int val = dp[i + 1][newJ1][newJ2];
                                if (j1 == j2) {
                                    ans = Math.max(ans, grid[i][j1] + val);
                                } else {
                                    ans = Math.max(ans, grid[i][j1] + grid[i][j2] + val);
                                }
                            }
                        }
                    }

                    dp[i][j1][j2] = ans;
                }
            }
        }

        // Start positions: robot1 at col=0, robot2 at col=m-1
        return dp[0][0][m - 1];
    }
}

class Solution {
    public int cherryPickup(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;

        int dp[][][] = new int [rows][cols][cols];
        
        for(int outer2[][] : dp){
            for(int outer[] : outer2){
                Arrays.fill(outer,Integer.MIN_VALUE);
            }
        }

        return helper(0,0,cols-1,grid,dp,rows,cols);
    }


    private static int helper(int r1,int c1,int c2,int [][] grid,int [][][] dp,int rows,int cols){

        if(r1 == rows || c1 == cols || c2 == cols || c1 == -1 || c2 == -1)return Integer.MIN_VALUE;

        if(r1 == rows-1){
            if(c1 == c2){
                return grid[r1][c1];
            }
            else{
                return grid[r1][c1] + grid[r1][c2];
            }
        }

        if(dp[r1][c1][c2] != Integer.MIN_VALUE)return dp[r1][c1][c2] ;
        int val = 0;
        if(c1 == c2){
                val +=  grid[r1][c1];
            }
        else{
                val +=  grid[r1][c1] + grid[r1][c2];
        }

        int max = Integer.MIN_VALUE;
        for(int i = -1;i<=1;i++){
            for(int j = -1;j<= 1;j++){
                int temp = helper(r1+1,c1+i,c2+j,grid,dp,rows,cols);
                max = Math.max(temp,max);
            }
        }

        return dp[r1][c1][c2] = max+ val; 
    }
}
