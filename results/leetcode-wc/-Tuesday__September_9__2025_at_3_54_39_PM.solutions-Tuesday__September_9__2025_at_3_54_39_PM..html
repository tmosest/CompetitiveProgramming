Intuition

The basic pattern of each window is [i0 ... i1 ... j1 ... j0], where j0 = i0 + k - 1, sections of nums are non-decreasing in [i0, i1] and [j1, j0]. We need to find the max num mx in [i1,j1] and then find the first j2 in [j1, j0] that is larger or equal to mx. Similar for the other side. So the minimal subarray to be sorted in the current window is [i2, j2]. Reference: 581 Tutorial Approach 5.

Now, let's consider one side [i0 ... mx ... j1 ... j2 ... j0], and it's symmetric for the other side.

First, maintain a nxt pointer for each index, pointing to the index of next larger-or-equal-to number. This can be done in one pass with a stack.

Next, slide the window. Maintain two pointers: max_ptr indicates the max num in [i0, j1] and hops by nxt; mono_ptr, which is j1, points to the start of the non-decreasing section ending at j0.

Lastly, the result of each window is k - [i0, i2] - [j2, j0].

Complexity

  • Time complexity: O(n)
  • Space complexity: O(n)

class Solution:
    def minSubarraySort(self, nums: List[int], k: int) -> List[int]:
        if k == 1:
            return [0] * (len(nums) - k + 1)

        left = self.oneSide([-num for num in nums[::-1]], k)[::-1]
        right = self.oneSide(nums, k)

        return [max(k-l-r,0) for l,r in zip(left, right)]
    
    def oneSide(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)

        nums.append(inf)
        stack, nxt = [n], [0] * n
        for i in range(n-1, -1, -1):
            while nums[i] > nums[stack[-1]]:
                stack.pop()
            nxt[i] = stack[-1]
            stack.append(i)
        
        res, max_ptr, mono_ptr = [], 0, 0

        for i in range(1,k-1):
            if nums[i] < nums[i-1]:
                mono_ptr = i
        for i in range(n-k+1):
            if nums[i+k-1] < nums[i+k-2]:
                mono_ptr = i+k-1
            if max_ptr < i:
                max_ptr += 1
            while nxt[max_ptr] < mono_ptr:
                max_ptr = nxt[max_ptr]
            res.append(max(i+k - nxt[max_ptr], 0))
        
        return res

This problem uses a deque to get a rolling window of nums of size k, and leverages SortedList from the sortedcontainers library to get those same k values in the rolling window, but sorted. By comparing the two, we can determine the subset (if any) of the k values are unsorted. Let's dive into how to do that...

Approach

As noted in the intro, initialize a SortedList, which we'll call nums_srt, and a deque, which we'll call nums_dq. Loop through the indices and values in nums using enumerate() and populate both nums_srt and nums_dq with values until both are size k.

Once both are size k, compare the k values (this solution uses zip()) in nums_srt and nums_dq to get the minimum (lidx) and maximum (ridx)indices where they mismatch. If there are no mismatches, append 0 to ans. Otherwise, append ridx - lidx + 1 which will be the size of the subarray that needs to be sorted. Use popleft() on nums_dq to remove the leftmost element, and also remove that tuple from nums_srt, which will make each contain (k - 1) elements, ready for the next loop.

Code

from sortedcontainers import SortedList

class Solution:
    def minSubarraySort(self, nums: List[int], k: int) -> List[int]:     
        ans = []

        nums_srt = SortedList()
        nums_dq = deque()
        for idx, val in enumerate(nums):
            nums_srt.add((val, idx))
            nums_dq.append((val, idx))
            if idx >= (k - 1):
                lidx = inf
                ridx = -inf
                for test_idx, (srt_tup, dq_tup) in enumerate(zip(nums_srt, nums_dq)):
                    if srt_tup != dq_tup:
                        lidx = min(lidx, test_idx)
                        ridx = max(ridx, test_idx)

                if lidx != inf:
                    ans.append(ridx - lidx + 1)
                else:
                    ans.append(0)
                
                nums_srt.remove(nums_dq.popleft())
        
        return ans

Intuition

Construct each window, then to find the number of changes sort the array and find the number of elements where suffix and prefix match.

For example lets assume that values in the window are:

1, 1, 3, 8, 3, 5, 8, 9

Sorted values are

1, 1, 3, 3, 5, 8, 8, 9

As you see, 3 first value match and 2 last. So we need to change 8 - 3 - 2 = 5

impl Solution {
  pub fn changes(tmp1: Vec<i32>) -> i32 {
    let mut tmp2 = tmp1.clone();
    tmp2.sort();
    let n = tmp1.len();
    let mut i = 0;

    while i < n && tmp1[i] == tmp2[i] {
      i += 1;
    }

    if i == n {
      return 0;
    }

    let mut j = 0;
    while tmp1[n - j - 1] == tmp2[n - j - 1] {
      j += 1;
    }

    (n - i - j) as i32
  }

  pub fn min_subarray_sort(nums: Vec<i32>, k: i32) -> Vec<i32> {
    let k = k as usize;
    let n = nums.len();
    let mut result = Vec::with_capacity(n - k + 1);

    for i in 0..=n - k {
      let window = nums[i..i + k].to_vec();
      result.push(Self::changes(window));
    }
    return result;
  }
}

Intuition

  • The problem requires finding the minimum length subarray that needs to be sorted to make the entire array sorted.
  • The key insight is that we need to identify the leftmost and rightmost positions where elements are out of place.
  • We can use sliding window technique to efficiently compute how much of each window is already sorted from one end, if any.

Approach

  1. For each sliding window of a given size, compute the length of the longest non-decreasing suffix
  2. Use a monotonic stack to build a "next greater or equal" array in O(n) time
  3. For each window, use the precomputed jumps to quickly find how many elements at the end are already sorted
  4. This allows us to determine the minimum subarray length that needs sorting

Complexity

  • Time complexity: O(n)
  • Space complexity: O(n)

Code

Python3
from typing import List
from math import inf


def compute_sorted_suffix_lengths(nums: list[int], window_size: int) -> list[int]:
    """
    Compute the length of the longest non-decreasing suffix in each sliding window of size window_size.

    For each index i from 0 to len(nums)-window_size, this returns the count of elements at the
    end of window nums[i:i+window_size] that already form a non-decreasing sequence.

    Uses a monotonic stack and next-greater-or-equal jumps to achieve O(n) time complexity.
    """
    n = len(nums)
    if window_size <= 0 or window_size > n:
        raise ValueError("window_size must be between 1 and the length of nums")

    # Special case: window size 1 is always sorted
    if window_size == 1:
        return [0] * n

    # Build next_ge: for each position i, next_ge[i] is the next index j > i with nums[j] >= nums[i]
    # 
    # Example with nums = [3, 1, 4, 2, 5]:
    # 
    # Initial state (after appending inf):
    # nums_extended = [3, 1, 4, 2, 5, inf]
    # indices:        [0, 1, 2, 3, 4, 5]
    # 
    # Building inds_next_ge from right to left:
    # 
    # i=5 (inf): stack=[5], inds_next_ge[5] = None (default, not used)
    # i=4 (5):   stack=[5, 4], inds_next_ge[4] = 5 (5 >= 5, so inds_next_ge points to inf)
    # i=3 (2):   stack=[5, 4, 3], inds_next_ge[3] = 4 (5 >= 2, so inds_next_ge points to index 4)
    # i=2 (4):   pop 3 (2 < 4), stack=[5, 4], inds_next_ge[2] = 4 (5 >= 4)
    # i=1 (1):   stack=[5, 4, 2, 1], inds_next_ge[1] = 2 (4 >= 1, so inds_next_ge points to index 2)
    # i=0 (3):   pop 1 (1 < 3), stack=[5, 4, 2], inds_next_ge[0] = 2 (4 >= 3)
    # 
    # Final inds_next_ge = [2, 2, 4, 4, 5, None]
    # 
    # Visual representation:
    # nums:         [3, 1, 4, 2, 5]
    # indices:      [0, 1, 2, 3, 4]
    #                ?  ?  ?  ?  ?
    # inds_next_ge: [2, 2, 4, 4, 5]  (5 points to inf sentinel)
    # 
    # Meaning: 
    # - From index 0 (value 3): next >= element is at index 2 (value 4)
    # - From index 1 (value 1): next >= element is at index 2 (value 4)
    # - From index 2 (value 4): next >= element is at index 4 (value 5)
    # - From index 3 (value 2): next >= element is at index 4 (value 5)
    # - From index 4 (value 5): next >= element is at index 5 (inf sentinel)
    inds_next_ge = [None] * (n + 1)
    _nums_extended = nums
    _nums_extended.append(inf)
    _inds_ord_val_incr: list[int] = [n]  # indices, with sentinel pointing at the appended inf
    # Traverse from right to left to build next_ge
    for i in range(n, -1, -1):
        val = _nums_extended[i]
        # Pop until top of stack has value >= current
        while _inds_ord_val_incr:
            j = _inds_ord_val_incr[-1]
            if val <= _nums_extended[j]:
                inds_next_ge[i] = j
                break
            _inds_ord_val_incr.pop()
        _inds_ord_val_incr.append(i)
    _nums_extended.pop()

    # Example with nums = [3, 1, 4, 2, 5], window_size = 3:
    # Windows: [3,1,4], [1,4,2], [4,2,5]

    # We need to find the longest sorted suffix in each window    
    suffix_lengths: list[int] = []
    
    # Track the last inversion (where nums[j - 1] > nums[j]) inside the current window
    # Initial scan of first window [3,1,4]:
    # j=1: nums[0]=3 > nums[1]=1, so last_inversion = 1
    # j=2: nums[1]=1 < nums[2]=4, no inversion
    # Final last_inversion = 1
    last_inversion = 0
    for j in range(1, window_size):
        if nums[j - 1] > nums[j]:
            last_inversion = j

    idx_suffix_look_ahead = 0
    for idx_init in range(0, n - window_size + 1):
        idx_last = idx_init + window_size - 1

        # Update inversion if the new element breaks ordering
        # Example: nums = [3, 1, 4, 2, 5]
        # Window 0: [3, 1, 4] (idx_init=0, idx_last=2) - skip update
        # Window 1: [1, 4, 2] (idx_init=1, idx_last=3) - check nums[2]=4 > nums[3]=2, so last_inversion = 3
        # Window 2: [4, 2, 5] (idx_init=2, idx_last=4) - check nums[3]=2 < nums[4]=5, no update
        if idx_init > 0 and nums[idx_last - 1] > nums[idx_last]:
            last_inversion = idx_last

        # Ensure idx_suffix_look_ahead is not left behind
        idx_suffix_look_ahead = max(idx_init, idx_suffix_look_ahead)

        # Jump idx_suffix_look_ahead forward until its inds_next_ge[j] clears the last inversion
        # Window 0: last_inversion=1, idx_suffix_look_ahead=0
        #   inds_next_ge[0]=2 >= 1, so no jumping needed
        # Window 1: last_inversion=3, idx_suffix_look_ahead=1
        #   inds_next_ge[1]=2 < 3, so jump to idx_suffix_look_ahead=2
        #   inds_next_ge[2]=4 >= 3, stop jumping
        # Window 2: last_inversion=3, idx_suffix_look_ahead=2
        #   inds_next_ge[2]=4 >= 3, no jumping needed
        while inds_next_ge[idx_suffix_look_ahead] < last_inversion:
            idx_suffix_look_ahead = inds_next_ge[idx_suffix_look_ahead]

        # The sorted suffix length = elements from inds_next_ge[idx_suffix_look_ahead] to idx_last
        # Window 0: [3, 1, 4] - suffix from inds_next_ge[0]=2 to idx_last=2 ? length = 2-2+1 = 1 (just [4])
        # Window 1: [1, 4, 2] - suffix from inds_next_ge[2]=4 to idx_last=3 ? length = 3-4+1 = 0 (no valid suffix)
        # Window 2: [4, 2, 5] - suffix from inds_next_ge[2]=4 to idx_last=4 ? length = 4-4+1 = 1 (just [5])
        sorted_suffix_len = idx_last - inds_next_ge[idx_suffix_look_ahead] + 1
        suffix_lengths.append(max(sorted_suffix_len, 0))

    return suffix_lengths


class Solution:
    def minSubarraySort(self, nums: list[int], k: int) -> list[int]:
        n = len(nums)
        if k == 1:
            return [0] * (n - k + 1)
        if k <= 0 or k > n:
            raise ValueError("k must be between 1 and the length of nums")

        # Compute sorted suffix lengths for each window
        suffix_lens = compute_sorted_suffix_lengths(nums, k)

        # Compute sorted prefix lengths by reversing and negating the array
        # This leverages the same logic: longest non-decreasing suffix in reversed-negated
        reversed_neg = [-x for x in nums[::-1]]
        prefix_lens = compute_sorted_suffix_lengths(reversed_neg, k)[::-1]

        # Combine prefix and suffix: the middle unsorted length = k - prefix - suffix
        result: list[int] = []
        for pre, suf in zip(prefix_lens, suffix_lens):
            length_to_sort = k - pre - suf
            result.append(max(length_to_sort, 0))

        return result

vector<int> minSubarraySort(vector<int>& nums, int k) {
    int n = nums.size();
    vector<int> res(n - k + 1, 0);
    for (int i = 0; i < n - k + 1; i++) {
        vector<int> curWindow(nums.begin() + i, nums.begin() + i + k);
        sort(begin(curWindow), end(curWindow));
        int start = n, end = 0;
        for (int j = 0; j < k; j++)
            if (nums[i + j] != curWindow[j]) {
                start = min(start, j);
                end = max(end, j);
            }
        if (end - start >= 0)
            res[i] = end - start + 1;
    }
    return res;
}

class Solution {
    void add(list<int> &v, int x) {
        v.push_back(x);
        auto t = v.end();
        for (--t; t != v.begin();) {
            auto tt = prev(t);
            if (*tt <= *t) break;
            swap(*tt, *t);
            t = tt;
        }
    }
public:
    vector<int> minSubarraySort(vector<int>& nums, int k) {
        list<int> v;
        const int n = nums.size();
        vector<int> r;
        for (int i = 0; i < n; ++i) {
            add(v, nums[i]);
            if (v.size() == k) {
                auto t = v.begin();
                int len = 0;
                for (int j = i - k + 1; j <= i && nums[j] == *t; ++j, ++t, ++len)
                ;
                if (len < k) {
                    t = v.end();
                    --t;
                    for (int j = i; j > i - k && nums[j] == *t; --j, --t, ++len)
                    ;
                }
                r.push_back(k - len);
                v.erase(find(v.begin(), v.end(), nums[i - k + 1]));
            }
        }
        return r;
    }
};
