Intuition

Try go from (x, y) to (1,1)
Consider the reverse operation of
(x, y - x)
(x - y, y)
(2 * x, y)
(x, 2 * y)

that is
(x, y + x)
(x + y, y)
(x / 2, y) if x % 2 == 0
(x, y / 2) if y % 2 == 0

Necessary Condition

Assume x and y have a common divisor v bigger than 2,
Since
(x + y) % v == 0
(x / 2) % v == 0 if x is even
(y / 2) % v == 0 if y is even
The new value always can be divided by v

No matter what operation we use,
we can't reach (1,1)

To go from (x,y) to (1,1),
we have the necessary condition :
gcd(x,y) = 2 ^ k

Sufficient Condition

Assume gcd(x,y) = 2 ^ k
If x is even, we can go (x / 2, y)
If y is even, we can go (x, y / 2)
If both odd and x < y, we can go (x, (x+y)/2)
If both odd and x > y, we can go ((x+y)/2, y)
(x, y) can continue go smaller,
until (x, y) both odd and x == y,
that is x == y == 1

Conclusion

Based on the Necessary Condition and Sufficient Condition,
we conclude that
"(1, 1) can go forward to (x, y)"
equals to
"(x, y) can go back to (1, 1)"
equals
gcd(x,y) is pow of 2.

Pow of 2

Many ways to check if x is pow of 2.

Option 1
We can continuely divide x by 2 and
check if stops at 1.

Option 2
Also we can check x lowbit by x & -x.

Complexity

Time O(logX + logY))
Space O(1)

Solution 1

Java
Implement gcd or import java.math.BigInteger

    public boolean isReachable(int x, int y) {
        int v = BigInteger.valueOf(x).gcd(BigInteger.valueOf(y)).intValue();
        while (v % 2 == 0)
            v /= 2;
        return v == 1;
    }

    public boolean isReachable(int x, int y) {

        return v == (v & -v);
    }

	}

Intuition

  • If we move from (targetX, targetY) to the points (targetX, targetY - targetX) or (targetX Ð targetY, targetY), the GCD of the pair remains the same
  • If we move from (targetX, targetY) to the points (2 * targetX, targetY) or (targetX, 2 * targetY), the GCD of the pair remains same or gets doubled.
  • GCD of (1, 1) is 1. From here it can either remain same or get multiplied by 2 each time. Therefore, from the above observations, point (1, 1) can move to point (targetX, targetY) if and only if gcd of (targetX, targetY) is a power of 2.

Approach

  • Find gcd of targetX and targetY
  • Check if gcd is a power of 2. If it is, return True else return False.

Complexity

  • Time complexity: O(gcd) = O(log(min(targetX, targetY)))

  • Space complexity: O(gcd)

Code

Python3:

def isReachable(self, targetX: int, targetY: int) -> bool:
    g = gcd(targetX, targetY)
    return g & (g - 1) == 0 # check g is power of 2

C++:

bool isReachable(int targetX, int targetY) {
    int g = __gcd(targetX, targetY);
    return (g & (g - 1)) == 0; // check g is power of 2
}

Java:

public boolean isReachable(int targetX, int targetY) {
    int g = gcd(targetX, targetY);
    return (g & (g - 1)) == 0; // check g is power of 2
}
private int gcd(int a, int b) {
    if (a == 0) return b;
    return gcd(b % a, a);
}

Intuition

Notice there is double operations for either x or y- coordinates and the corresponding result must be even. Therefore, if the target coordinates is odd, we can only have 1 option: +/-.

Hence we can simplify the operation if we return from target to source.

Also the following operation hint Euclidean Algorithm:
(x, y - x)
(x - y, y)
or
(x, y + x)
(x + y, y)

Based on the above we can implement the following algorithm.

Let us reverse the procedure and start from target to source, if either of the target coordinates is divisible by 2, remove all factor 2s from it then check if they are co-prime now; If yes, return true, otherwise return false.

We also can compute the GCD first, then check if it has only factor 2s, and this makes code shorter.

    public boolean isReachable(int x, int y) {
        while (y != 0) {
            int tmp = x % y;
            x = y;
            y = tmp;
        }
        while (x % 2 == 0) {
            x /= 2;
        }
        return x == 1;
    }
    def isReachable(self, x: int, y: int) -> bool:
        g = gcd(x, y)
        while g % 2 == 0:
            g //= 2
        return g == 1

Or further simplify the above as follows:

    public boolean isReachable(int x, int y) {
        while (y != 0) {
            int tmp = x % y;
            x = y;
            y = tmp;
        }
        return Integer.bitCount(x) == 1;
    }
    def isReachable(self, x: int, y: int) -> bool:
        return gcd(x, y).bit_count() == 1

Analysis:

Both the dividing 2 and gcd(Euclidean Algorithm) operations cost time O(log(max(x, y))), therefore

Time: O(log(max(x, y))), space: O(1).

Q & A
Q1: You have reversed 2*x by x//2. Then why (x-y) is still holding good? Shouldn't it be x+y?
A1: Actually, x + y or x - y will NOT change their GCD. It is because gcd(x + m * y, y) = gcd(x, n * x + y) = gcd(x, y), where m and n are both integers that can be positive, negative or zero.

Proof:

Use contradiction to prove gcd(x + m * y, y) = gcd(x, y) as follow:

Let g = gcd(x, y), then x = a * g, y = b * g and a and b co-prime.

x + m * y = a * g + m * b * g = (a + m * b) * g
y = b * g

if gcd(a + m * b, b) = g' > 1, then a + m * b = p * g' andb = q * g', therefore a + m * b = a + m * q * g' = p * g', so a = (p - m * q) * g', which indicates that a and b have a GCD of g' > 1 and hece a and b not co-prime, which contradicts the previous assumption a and b co-prime.

Similarly we can prove that gcd(x, n * x + y) = gcd(x, y)

End of Q & A

Statement: If a divides b, a divides c, then a divides b - c.
Proof: We can write b = am, c = an, where m, n are integers. We then have b - c = a(m - n). Since m, n are integers, it follows that m - n is an integer. Therefore, the equation b - c = a(m - n) implies that a divides b - c.

  • From the above statement, we conclude that the former two operations (x, y - x) and (x - y, y) do not change gcd(x, y).
  • However, the latter two operations (2 * x, y) and (x, 2 * y) can double gcd(x, y).

Note that gcd(1, 1) = 1 and gcd(1, 1) can be only doubled multiple times. Therefore, we need gcd(targetX, targetY) = 2 ^ k to reach the point (targetX, targetY) from (1, 1).

class Solution {
    public boolean isReachable(int targetX, int targetY) {
        return Integer.bitCount(gcd(targetX, targetY)) == 1;
    }
    private int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
