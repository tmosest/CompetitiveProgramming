Intuition

This problem asks us to pair elements from an array such that the maximum pair sum is minimized. The optimal strategy is to pair the smallest element with the largest, the second smallest with the second largest, and so on. This greedy approach ensures that large values are balanced with small values, minimizing the maximum pair sum.

Approach

We'll use a sort-and-pair strategy with two pointers:

  1. Sorting: Sort the array to enable optimal pairing (smallest with largest)
  2. Two-pointer initialization: Place one pointer at start (smallest), one at end (largest)
  3. Pair formation: Calculate sum of elements at both pointers
  4. Maximum tracking: Keep track of the maximum pair sum encountered
  5. Pointer convergence: Move pointers inward after each pairing until they meet
  6. Return result: The maximum pair sum found is the minimized maximum

This approach works because pairing extremes prevents any single pair from having an excessively large sum.

Complexity

  • Time complexity: O(nlogn)
    Where n is the array length, dominated by the sorting operation. The pairing process is O(n).

  • Space complexity: O(1)
    We only use constant extra space for pointers and the maximum tracker (sorting is typically in-place).

class Solution(object):
    def minPairSum(self, nums):
        nums.sort()
        start, end = 0, len(nums)-1
        count = 0
        while end > start:
            count = max(nums[start] + nums[end], count)
            start += 1
            end -= 1
        return count
