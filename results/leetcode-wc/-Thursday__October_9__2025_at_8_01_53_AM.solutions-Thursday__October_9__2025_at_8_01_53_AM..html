public int wateringPlants(int[] p, int capacity) {
    int res = 0, can = capacity;
    for (int i = 0; i < p.length; ++i) {
        if (can < p[i]) {
            res += i * 2;
            can = capacity;
        }
        can -= p[i];
    }
    return res + p.length;        
}

Intuition

We need to simulate watering plants one by one, moving from left to right.
-> If the current water in the can is enough for the plant ? water it and move forward.
-> If not ? return to the river, refill, and come back to this plant, then continue.

So the key is to keep track of:

  1. Steps taken so far.
  2. Remaining water capacity.
  3. Extra steps needed when refilling.

Approach

  1. Start with steps = 0 and capacity = retainCapacity.
  2. Traverse the plants array one by one:
    • If capacity >= plants[i]:
      • Water the plant.
      • Reduce capacity and move forward (steps += 1).
    • Else (not enough water):
      • Go back to the river and return ? add 2 * steps to the answer.
      • Move forward one step (steps += 1).
      • Reset capacity = retainCapacity - plants[i].
  3. Finally, return the total steps (sumOfSteps + steps).

Complexity

  • Time complexity:
    We loop once over the plants array ? O(n)

  • Space complexity:
    Only a few variables are used ? O(1)

Code

C++
class Solution {
public:
    int wateringPlants(vector<int>& plants, int capacity) {
        int steps = 0;
        int sumOfSteps = 0;
        int retainCapacity = capacity;
        for(int i=0;i<plants.size();i++){
            if(capacity >= plants[i]){
                capacity-=plants[i];
                steps+=1;
            }else{
                sumOfSteps += 2*steps;
                steps+=+1;
                capacity = retainCapacity - plants[i];
            }
        }
        return sumOfSteps + steps;
    }
};

Intuition

Simulate the watering process while tracking steps and refills.

Approach

Iterate through the array, decrementing capacity. If capacity is insufficient, return to refill and continue.

Complexity

  • Time complexity: O(n)
  • Space complexity: O(1)

Code

Java
class Solution {
    public int wateringPlants(int[] plants, int capacity) {
        int l = plants.length;
        int c = 0;
        int d = capacity;
        for(int i=0; i<l; i++){
            if(plants[i] <= capacity){
                capacity -= plants[i];
                c++;
            }
            else{
                capacity = d - plants[i];
                c += 2*i + 1;
            }
        }
        return c;
    }
}
