Imagine you have a string and you want to find the longest chunk where every vowel (a, e, i, o, u) appears an even number of times. Let's break it down step by step with a simple approach:

What We Do

  1. Track Vowel Counts: We’ll keep a bitmask to track the even or odd count of each vowel. Think of this as a way to remember which vowels have been seen an odd number of times and which have been seen an even number of times.

  2. Use an Array ( Map ) for Tracking: We’ll use an array to store the first time we see each possible bitmask. This way, we can easily find the longest substring by comparing the current position with where we first saw the same bitmask before.

How It Works

  1. Bitmask Basics:

    • We use a bitmask where each bit represents whether a vowel has been seen an odd number of times. For example, if the bit for a is set, it means a has been seen an odd number of times.

  2. Array Initialization:

    • We start with an array that has 32 slots (because we have 5 vowels and we need to represent all combinations of odd/even counts for these vowels).
    • Initially, set all values to -2 which means we haven’t seen that bitmask before. Set mapy[0] to -1 to handle the case where the whole substring from the start is valid.

  3. Processing the String:

    • Loop through each character in the string.
    • Update the bitmask based on the character (toggle the corresponding bit if it’s a vowel).
    • Check if we’ve seen this bitmask before. If yes, calculate the length of the substring between the previous and current indices. If not, store the current index as the first occurrence of this bitmask.

  4. Finding the Longest Substring:

    • Track the maximum length of valid substrings where all vowels appear an even number of times by comparing the lengths of valid substrings found.

Time Complexity (TC)

The overall time complexity of the solution is O(n), where n is the length of the string s.

  • Processing Each Character: The loop processes each character in the string exactly once, updating the bitmask and checking the array. This takes O(n) time.

  • Array Operations: Accessing and updating the array mapy is done in constant time O(1) for each character.

Space Complexity (SC)

The space complexity is O(1), which is constant space complexity.

  • Array Size: The array mapy has a fixed size of 32, regardless of the input size. This size is constant and does not depend on the length of the string.

  • Other Variables: The variables max, mask, and prev use constant space.

class Solution:
    def findTheLongestSubstring(self, s: str) -> int:
        mapy = [-2] * 32
        mapy[0] = -1

        max_len = 0
        mask = 0

        for i, char in enumerate(s):
            if char == 'a':
                mask ^= 1
            elif char == 'e':
                mask ^= 2
            elif char == 'i':
                mask ^= 4
            elif char == 'o':
                mask ^= 8
            elif char == 'u':
                mask ^= 16

            prev = mapy[mask]
            if prev == -2:
                mapy[mask] = i
            else:
                max_len = max(max_len, i - prev)

        return max_len

class Solution {
private:
    bool chk_vowel(char ch) {
        return ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u';
    }

public:
    int findTheLongestSubstring(string s) {
        unordered_map<char, int> vowel_position = {{'a', 0}, {'e', 1}, {'i', 2}, {'o', 3}, {'u', 4}};
        unordered_map<int, int> last_occured;
        last_occured[0] = -1;  // Initial state with no vowels
        
        int cur = 0;  // Bitmask to track the parity of vowel counts
        int max_len = 0;

        for (int r = 0; r < s.size(); r++) {
            if (chk_vowel(s[r])) {
                // Toggle the bit for the current vowel
                cur ^= (1 << vowel_position[s[r]]);

                // Uncomment it to see the bits changing
                // bitset<5> b(cur);
                // cout<<b<<endl;
            }

            // If the current state has been seen before, calculate the length
            if (last_occured.find(cur) != last_occured.end()) {
                max_len = max(max_len, r - last_occured[cur]);
            } 
            // Store the first occurrence of this state
            else {
                last_occured[cur] = r;
            }
        }

        return max_len;
    }
};
