? Intuition

Given a string s and an integer k, find the longest subsequence that appears at least k times in s. If multiple subsequences of the same maximum length exist, return the lexicographically largest one.

?Approach: BFS with Greedy Selection

Why BFS?

  • Breadth-First Search (BFS) explores all possible subsequences level by level (from shorter to longer lengths).
  • This ensures that the longest valid subsequence is found before shorter ones.

Why Greedy?

  • By processing characters from 'a' to 'z', the last valid subsequence found at each length is guaranteed to be the lexicographically largest one.

Steps:

  1. Initialize a queue with an empty string " ".
  2. For each level (subsequence length):
    • Poll a candidate from the queue.
    • Append each possible character ('a' to 'z') to it.
    • Check if the new subsequence appears at least k times in s using the isK helper.
    • If valid, update the result and add the new subsequence to the queue.
  3. Terminate when the queue is empty.
  4. Return the last valid subsequence found (lexicographically largest).

Helper Function: isK(subsequence, s, k)

  • Purpose: Checks if subsequence appears at least k times in s.

  • Logic:

    1. Use a two-pointer technique:
      • i tracks progress in subsequence.
      • Every time subsequence is fully matched, increment count and reset i.
    2. Return true if count >= k.

Example:

For subsequence = "let", s = "letsleetcode", k = 2:

  • Match 'l' at 0, 'e' at 1, 't' at 2 ? count = 1.
  • Match 'l' at 4, 'e' at 5, 't' at 7 ? count = 2.
  • Return true.

??? Example Walkthrough (s = "letsleetcode", k = 2)

  1. Level 1 (Length 1):

    • Valid: "l", "e", "t" ? keep "t" (lex largest).

  2. Level 2 (Length 2):

    • From "t", try "te" ? valid ? keep "te".

  3. Level 3 (Length 3):

    • From "te", no valid extensions.
    • From earlier, "let" is valid ? final result.

Output: "let" (longest and lexicographically larger than "ete").

Time Complexity:

  • Worst Case: O(N * 26^{N/K})
    • N = length of s, K = repetition count.
    • BFS explores up to 26^{N/K} possible subsequences.
    • Each isK check takes O(N) time.

Space Complexity:

  • Worst Case: O(L * 26^{N/K})
    • L = N/K (max subsequence length).
    • Queue stores O(26^{N/K}) strings, each of length L.

class Solution {
    public String longestSubsequenceRepeatedK(String s, int k) {
        String r="";
        Queue<String> q=new LinkedList<>();
        for(q.add("");!q.isEmpty();) {
            String c=q.poll();
            for(char ch='a';ch<='z';ch++) {
                String n=c+ch;
                if(isK(n,s,k)) {
                    r=n;
                    q.add(n);
                }
            }
        }
        return r;
    }
    boolean isK(String s,String t,int k) {
        int c=0,i=0;
        for(char ch:t.toCharArray()) {
            if(ch==s.charAt(i)) {
                if(++i==s.length()) {
                    i=0;
                    if(++c==k) return true;
                }
            }
        }
        return false;
    }
}
