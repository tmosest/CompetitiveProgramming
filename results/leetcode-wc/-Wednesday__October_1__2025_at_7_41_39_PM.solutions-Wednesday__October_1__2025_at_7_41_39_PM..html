Approach?

1 . Nested Loops:

  • Use three nested loops to generate all possible combinations of the digits for the hundreds, tens, and units places.
  • Ensure that the same digit is not used more than once in a number.

2 . Constraints:

  • The hundreds place cannot be zero.
  • The units place must be even.

3 . Store Unique Numbers:

  • Use a HashSet to store valid numbers, as it automatically handles duplicates.

4 . Count Unique Numbers:

  • Return the size of the HashSet, which represents the number of unique valid numbers.

?Complexity Analysis

  • Time complexity:O(n3) Due to three nested loops iterating over n elements each.
  • Space complexity:O(1)

class Solution {
    public int totalNumbers(int[] digits) {
        HashSet<Integer> map = new HashSet<>();
        int n = digits.length;
        
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                for (int k = 0; k < n; k++) {
                    if (i != j && i != k && j != k) {
                        if (digits[i] != 0) {
                            if (digits[k] % 2 == 0) {
                                int number = digits[i] * 100 + digits[j] * 10 + digits[k];
                                map.add(number);
                            }
                        }
                    }
                }
            }
        }
        return map.size();
    }
}
