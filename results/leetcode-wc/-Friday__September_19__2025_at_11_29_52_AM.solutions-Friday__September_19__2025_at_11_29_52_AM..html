? The Mission Brief (Problem Overview)

You are given:

  • An integer array arr
  • Three integers: a, b, and c

Your task is to count how many triplets (i, j, k) satisfy all of the following:

  1. 0 <= i < j < k < arr.length
  2. |arr[i] - arr[j]| <= a
  3. |arr[j] - arr[k]| <= b
  4. |arr[i] - arr[k]| <= c

? Sounds tricky? Let’s break it down with logic and discipline.

? What’s the Real Goal? (Simplified Task)

?
We need to find all triplets that:

  • Appear in the correct order (i < j < k)
  • Have values with limited difference (as per a, b, c)

? Rock Lee: "Like forming a balanced squad—compatibility and sequence both matter!" ?

? How We Approach This (Using Loops)

? Rock Lee: "If I can't solve it directly, I will train harder and go one by one!" ?

Here’s the plan:

  1. Loop through each index i
  2. For every i, try each j > i
  3. For each j, try every k > j
  4. Check if:
    • |arr[i] - arr[j]| <= a
    • |arr[j] - arr[k]| <= b
    • |arr[i] - arr[k]| <= c
  5. If all conditions pass ?? count it

That’s the brute-force but correct strategy ?

class Solution:
    def countGoodTriplets(self, arr: List[int], a: int, b: int, c: int) -> int:
        good_triplets = 0
        length = len(arr)

        for i in range(length):  # i is the first index
            for j in range(i + 1, length):  # j must be after i
                if abs(arr[i] - arr[j]) <= a:  # first condition check
                    for k in range(j + 1, length):  # k must be after j
                        # Check all three conditions
                        if abs(arr[j] - arr[k]) <= b and abs(arr[i] - arr[k]) <= c:
                            good_triplets += 1
                            # ? Rock Lee: "Another success from persistence!" ?
        
        return good_triplets

?? Time & Space Complexity

? Time Complexity: O(n^3) – We’re using 3 nested loops to go through every possible triplet.
? Space Complexity: O(1) – Only using one counter for the result.
