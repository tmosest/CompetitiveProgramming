1. DFS approach:

Java
class Solution {
    public TreeNode reverseOddLevels(TreeNode root) {
        // We call the function from lvl 0, and everything starts from lvl 1
        traverse(root.left, root.right, 1);
        return root;
    }

    public void traverse(TreeNode node1, TreeNode node2, int lvl) {
        if (node1 == null || node2 == null) {
            return;
        }
        if (lvl % 2 == 1){
            int temp = node1.val;
            node1.val = node2.val;
            node2.val = temp;
        }

        traverse(node1.left, node2.right, lvl + 1);
        traverse(node1.right, node2.left, lvl + 1);
    }
}

// TC: O(n) -> Every node in the binary tree is visited
// SC: O(h) -> where h is the height of the binary tree

2. BFS Approach:

Java
class Solution {
    public TreeNode reverseOddLevels(TreeNode root) {
        if (root == null) {
            return root;
        }

        Queue<TreeNode> q = new LinkedList<>();
        q.offer(root);
        int level = 0;
        while (!q.isEmpty()) {
            int size = q.size();
            while (size-- > 0) {
                TreeNode node = q.poll();
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }

            level++;
            if (level % 2 == 1 && !q.isEmpty()) {
                int[] nums = new int[q.size()];
                int i = 0;
                for (TreeNode node : q) {
                    nums[i++] = node.val;
                }

                int j = q.size() - 1;
                for (TreeNode node : q) {
                    node.val = nums[j--];
                }
            }
        }

        return root;
    }
}

// TC: O(n), SC: O(n)

? Proof

? Intuition

In a perfect binary tree, each level is completely filled, and nodes on odd levels can be reversed symmetrically. By treating pairs of nodes (left and right subtrees) symmetrically at each level, we can swap their values efficiently without needing additional data structures.

? Approach

1. Recursive Symmetric Traversal:

  • Begin with the left and right children of the root.
  • At each odd level, swap the values of the paired nodes.
  • Recursively traverse further to reverse values in subtrees at the next odd levels.

2. Base Case:

  • Stop when either node is null (reached leaf level).

3. Recursive Swapping:

  • For a pair of nodes, swap their values if the current level is odd.
  • Recursively call the function on their corresponding children (node1.left with node2.right and node1.right with node2.left).

? Complexity

1. Time complexity:

  • O(n), where n is the number of nodes, as each node is visited once.

2. Space complexity:

  • O(h), where h is the height of the tree (logarithmic for a perfect binary tree) due to recursive stack usage.

?? Concept of Tags Used

1. Tree Traversal:

  • Leveraging recursive symmetric traversal for odd-level nodes.

2. Recursion:

  • Efficiently navigating and processing nodes at odd levels.

3. Binary Tree:

  • Utilizing properties of perfect binary trees for symmetric traversal.

    private void levelTraverse(TreeNode node1, TreeNode node2, int level) {
        if (node1 == null || node2 == null)
            return;
        
        if (level % 2 == 0) {
            int val = node1.val;
            node1.val = node2.val;
            node2.val = val;
        }

        levelTraverse(node1.left, node2.right, level + 1);
        levelTraverse(node1.right, node2.left, level + 1);
    }
}
