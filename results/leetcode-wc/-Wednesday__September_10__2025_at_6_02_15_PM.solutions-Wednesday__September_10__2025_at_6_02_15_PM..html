? Understanding The Problem

  • We're given two integers n and m.
  • Considering a grid of m * n, we can paint the rows and column with any of the three colours - red, green or blue.
  • We need to find the number of patterns to paint the grid such that no adjacent cells of the grid have the same color.
  • As this value can be very large so its supposed to be returned modulo 1e9 + 7

class Solution {
public:
    const int mod = 1e9 + 7;
    int dp[1005][250], rowValid[250][250];
    vector<int> good, pattern [250];
    int colorTheGrid(int m, int n) {
        int total = pow(3, m);

        for (int i = 0; i < total; i++) {
            int val = i, valid = 1;
            for (int j = 0; j < m; j++) 
                pattern[i].push_back(val % 3), val /= 3;
            for (int j = 1; j < m; j++) 
                if (pattern[i][j] == pattern[i][j - 1]) valid = 0;
            if (valid) good.push_back(i);
        }
        for (int i : good) dp[1][i] = 1;

        for (int i : good) {
            for (int j : good) {
                rowValid[i][j] = 1;
                for (int k = 0; k < m; k++) 
                    if (pattern[i][k] == pattern[j][k]) 
                        rowValid[i][j] = 0;
            }
        }

        for (int col = 2; col <= n; col++)
            for (int i : good)
                for (int j : good)
                    if (rowValid[i][j]) 
                        dp[col][i] = (dp[col][i] + dp[col - 1][j]) % mod;
                        
        return accumulate(dp[n], dp[n] + total, 0L) % mod;
    }
};

? Intuition

The problem asks us to count how many ways to color an m * n grid with 3 colors, such that no two adjacent cells have the same color. Instead of brute forcing the entire grid we cleverly consider columns one by one. For each column, we list all valid color configurations that obey the vertical adjacency rule. Then, for two consecutive columns, we check which column configurations can be placed side-by-side without violating the horizontal adjacency rule. Using these valid states and transitions, we apply dynamic programming across columns to count all valid grid colorings efficiently.

?? Approach

Step 1 Generate all valid column states

  • Each state represents a vertical arrangement of colors in a column.
  • A valid column state has no two adjacent rows with the same color.
  • Use a recursive or iterative approach to generate all these valid states.

Step 2 Build transitions between states

  • Two column states a and b are compatible if no cells in the same row have the same color.
  • For each valid state a, find all states b that are compatible with it.
  • Store these compatible states as transitions for quick lookup.

Step 3 Initialize DP

  • Start with the first column.
  • The number of ways to color the first column using each valid state is 1.

Step 4 DP across columns

  • For each next column

    • For each previous column state prev, and each compatible next state next

      • Add the count of ways to form prev to next.
      • Take modulo to avoid overflow.

Step 5 Sum results

  • After processing all columns, sum the ways for all states in the last column.
  • Return this sum modulo MOD.

?? Complexity

  • Time complexity : O(N*K2)
  • Space complexity : O(K)

public class Solution 
{
    private static final int MOD = 1_000_000_007;

    public int colorTheGrid(int m, int n) 
    {
        // Step 1: Generate all valid column states (no same color in adjacent rows)
        List<int[]> states = new ArrayList<>();
        generateStates(m, new int[m], 0, states);

        // Step 2: Build transitions between states (no same color in same row)
        Map<String, List<String>> transitions = new HashMap<>();
        for (int[] a : states) 
        {
            String keyA = Arrays.toString(a);
            transitions.putIfAbsent(keyA, new ArrayList<>());
        
            for (int[] b : states) 
            {
                if (isCompatible(a, b)) 
                {
                    transitions.get(keyA).add(Arrays.toString(b));
                }
            }
        }

        // Step 3: Initialize DP for the first column (each valid state counts as 1)
        Map<String, Integer> dp = new HashMap<>();
        for (int[] state : states) 
        {
            dp.put(Arrays.toString(state), 1);
        }

        // Step 4: DP over columns - count ways to build columns sequentially
        for (int col = 1; col < n; col++) 
        {
            Map<String, Integer> newDp = new HashMap<>();
            for (String prev : dp.keySet()) 
            {
                int count = dp.get(prev);
                for (String next : transitions.get(prev)) 
                {
                    newDp.put(next, (newDp.getOrDefault(next, 0) + count) % MOD);
                }
            }

            dp = newDp;
        }

        // Step 5: Sum all possible final column configurations
        int result = 0;
        for (int val : dp.values()) 
        {
            result = (result + val) % MOD;
        }
        
        return result;
    }

    // Generate all valid columns with no adjacent cells of same color vertically
    private void generateStates(int m, int[] current, int row, List<int[]> states) 
    {
        if (row == m) 
        {
            states.add(Arrays.copyOf(current, m));
            return;
        }
        
        for (int color = 1; color <= 3; color++) 
        {
            if (row > 0 && current[row - 1] == color)
            {
                continue;  // avoid vertical conflict
            } 
            
            current[row] = color;
            generateStates(m, current, row + 1, states);
        }
    }

    // Check if two columns are compatible horizontally (no same color in any row)
    private boolean isCompatible(int[] a, int[] b) 
    {
        for (int i = 0; i < a.length; i++) 
        {
            if (a[i] == b[i])
            {
                return false;
            } 
        }

        return true;
    }
}
