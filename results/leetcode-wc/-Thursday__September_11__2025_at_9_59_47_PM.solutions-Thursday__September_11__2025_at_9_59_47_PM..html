Intuition

Assume we do not have to exclude banned numbers from the sum. The solution would be obvious: find the largest k which satisfies ·i=1k?i²M. Knowing that ·i=1k?i=2k(k+1)?, we can find k by solving the following quadratic equation k2+k-2M=0. The positive solution is k=2-1+1+8M??. If this k is larger than n, then take k=n instead. In general k=min(n,2-1+1+8M??).

Now our current sum is 2k(k+1)? and we have used k numbers.

The next step is to exclude the banned numbers from that sum. Let b be the count of banned numbers. There are atmost b numbers to exclude.

The final step is to continue adding numbers from the range [k+1,n] that are not banned, until we exceed M. We will add at most b+1 numbers, because we know that ·i=1k?i²M<·i=1k+1?i. This means that when we calculated the first sum, only 1 number larger than k was needed to exceed M. Now that we have removed at most b numbers from the sum, at most b+1 numbers are needed.

Approach

The first k can be calculated in constant time by the given formula.

Removing the banned numbers from the initial sum can be done in O(b) time.

Adding numbers that are not banned can be done in O(b) time and space by using a hash set.

A slight optimization can be used to save space by only adding banned numbers greater than k into the lookup set, since we only match against those. Space complexity is still O(b) but memory usage is greatly decreased in practice, especially when n is small and M? is large.

Note that this solution expects that all of the numbers in banned are distinct. Else we will be obliged to construct the lookup set before step 2, which means the previous slight optimization can no longer be used.

Complexity

  • Time complexity: O(b) where b is the length of banned

  • Space complexity: O(b) where b is the length of banned

class Solution:
    def maxCount(self, banned: List[int], n: int, max_sum: int) -> int:
        # step 1, find the initial sum
        k = min(n, int((-1 + math.sqrt(1 + 8 * max_sum)) / 2))
        current_sum = int(k * (k + 1) / 2)
        count = k

        # step 2, remove the banned numbers from sum
        banned_set = set(banned)
        for b in banned_set:
            if b <= k:
                current_sum -= b
                count -= 1

        # step 3, add non banned numbers to the sum until
        # we exceed max_sum, or run out of numbers
        for i in range(k + 1, n + 1):
            if current_sum + i > max_sum:
                return count

            if i not in banned_set:
                current_sum += i
                count += 1

        return count

Java

class Solution {
    public int maxCount(int[] banned, int n, long maxSum) {
        // step 1, find the initial sum
        int k = Math.min(n, (int)Math.floor((-1 + Math.sqrt(1 + 8 * maxSum)) / 2));
        long currentSum = (long)k * (k + 1) / 2;
        int count = k;

        // step 2, remove the banned numbers from the sum
        HashSet<Integer> bannedSet = new HashSet<>();
        for (int b : banned) {
            if (!bannedSet.contains(b)) {
                bannedSet.add(b);

                if (b <= k) {
                    currentSum -= b;
                    count -= 1;
                }
            }
        }

        // step 3, add non banned numbers to the sum until
        // we exceed maxSum, or run out of numbers
        for (int i = k + 1; i <= n; i++) {
            if (currentSum + i > maxSum) {
                return count;
            }

            if (!bannedSet.contains(i)) {
                currentSum += i;
                count += 1;
            }
        }

        return count;
    }
}

Approach

Suppose a banned array [a1?,a2?,?,an?] split [1,n] into [1,a1?-1],[a1?+1,a2?-1],?,[an-1?+1,an?-1],[an?+1,n].
Let S([a,b]):=a+(a+1)+(a+2)+?+b. Let curSum denote the current sum. We have the following two cases:

  • curSum+S([am-1?-1,am?+1])²maxSum, we calculate the arithmetic progression and add it to the curSum
  • curSum+S([am-1?-1,am?+1])³maxSum, which is equivalent to solve inequality equation (commented below)

class Solution {
    public int maxCount(int[] banned, int n, long maxSum) {
        Arrays.sort(banned);
        long low = 1l, count = 0l;
        for (int i = 0; i <= banned.length; i++) {
            long high = i < banned.length ? (long)banned[i] : (long)(n + 1);
            if (low < high) {
                long sum = (low + high - 1) * (high - low) / 2l;
                if (sum > maxSum) {
                    // sqrt(2b + a^2 - a + 1/4) - 1/2
                    double maximum = Math.sqrt(2 * (double)maxSum + 
                        (double)low * (low - 1.0) + 0.25) - 0.5;
                    count += (long) maximum - low + 1;
                    break;
                } else {
                    count += high - low;
                    maxSum -= sum;
                }
            }
            low = high + 1;
        }
        return (int)count;
    }
}
