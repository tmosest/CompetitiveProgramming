Intuition

We just need to check consecutive cells in the visiting order.

If 0 ? (x0, y0) and 1 ? (x1, y1), check if (x1, y1) is a valid knight move from (x0, y0).

Repeat for all 0...n*n-2.

If any step breaks the knight move rule, answer is false.

Approach

  1. First check if grid[0][0] == 0 (knight must start from top-left).

  2. Store coordinates of each number in an array pos[] such that pos[val] = {row, col}.

  3. Iterate from i=0 to n*n-2:

    • Get (x, y) = pos[i] and (nx, ny) = pos[i+1].

    • Check if abs(x - nx) and abs(y - ny) forms a knight move:

    • (abs(x - nx), abs(y - ny)) must be either (2, 1) or (1, 2).

  4. If all consecutive pairs satisfy knight move condition ? return true, else false.

Complexity

  • Time complexity:O(n2) ? We scan the grid once to store positions and once to verify moves.
  • Space complexity:O(n2) ? Extra array to store positions.

class Solution {
public:
    bool checkValidGrid(vector<vector<int>>& grid) {
        int n=grid.size();

        vector<int> vis(n*n,0);
        queue<pair<int,int>> q;
        q.push({0,0});

        int delx[]={-2,-2,-1,-1,1,1,2,2};
        int dely[]={-1,1,-2,2,-2,2,-1,1};


        while(!q.empty()){
            int x=q.front().first;
            int y=q.front().second;


            q.pop();

            int val=grid[x][y];
            vis[val]=1;


            for(int i=0;i<8;i++){
                int nx=x+delx[i];
                int ny=y+dely[i];

                if(nx>=0 && nx<n && ny>=0 && ny<n && grid[nx][ny]==val+1 && !vis[grid[nx][ny]]){
                    q.push({nx,ny});
                }
            }


        }
            for(auto it: vis){
                if(it==0)return false;
            }

return true;
    }
};
