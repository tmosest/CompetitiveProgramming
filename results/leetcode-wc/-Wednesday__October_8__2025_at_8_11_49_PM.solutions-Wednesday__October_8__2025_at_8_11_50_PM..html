Huffman-Like Tree
lilongxue
2
Aug 28, 2025
Java

Intuition

The structure of the problem is very like a huffman tree.

Approach

  1. Create a min-heap.
  2. Put all the values of blocks into the heap.
  3. while the heap's size > 1, take out the top 2 values a and b and merge them into one.
  4. The merging is done by letting c = split + Math.max(a, b).
  5. Put c back into the heap.
  6. When the loop is over, the heap's top element is the result.

Complexity

  • Time complexity:
    O(nlgn)
  • Space complexity:
    O(n)

Code

Java
class Solution {
    public int minBuildTime(int[] blocks, int split) {
        PriorityQueue<Integer> heap = new PriorityQueue<Integer>();
        for (int val: blocks) {
            heap.offer(val);
        }


        while (heap.size() > 1) {
            int a = heap.poll(), b = heap.poll();
            int c = split + Math.max(a, b);
            heap.offer(c);
        }


        return heap.peek();
    }
}

Min Cost to Split/Merge Tree

Intuition

if you think of this problem as N nodes (workers) doing works, and then you merge the two smallest times with cost split. This generates a worked with the result.

Approach

  • Priority Queue

Complexity

  • Time complexity:
    O(n*log(n))

  • Space complexity:
    O(n)

Code

class Solution {
    public int minBuildTime(int[] blocks, int split) {
        PriorityQueue<Integer> pq=new PriorityQueue<>();
        for(int n: blocks) pq.add(n);
        while(pq.size()>1) {
            pq.remove();
            pq.add(split+pq.remove());
        }
        return pq.remove();
    }
}

Alternatives

  • Time complexity:
    O(n2)

  • Space complexity:
    O(n2)

class Solution {
    public int minBuildTime(int[] blocks, int split) {
        Arrays.sort(blocks);
        for(int a=0,b=blocks.length-1;a<b;a++,b--) {
            int tmp=blocks[a];
            blocks[a]=blocks[b];
            blocks[b]=tmp;
        }
        return helper(1,0,blocks,split,new int[blocks.length+1][blocks.length]);
    }
    int helper(int w, int left,int[] blocks, int split, int[][] memo) {
        if(left==blocks.length) return 0;
        if(w==0) return Integer.MAX_VALUE/2;
        int b=blocks[left];
        if(w>=blocks.length-left) return b;
        if(memo[w][left]>0) return memo[w][left]-1;
        int min=Math.min(
            Math.max(b,helper(w-1,left+1,blocks,split,memo)),
            split+helper(2*w,left,blocks,split,memo)
            );
        return (memo[w][left]=min+1)-1;
    }
}
