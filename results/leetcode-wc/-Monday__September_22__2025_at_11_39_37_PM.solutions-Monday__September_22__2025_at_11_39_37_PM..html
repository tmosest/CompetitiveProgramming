Approach

Here key thing is if we accumulate the even char of s1 and s2 then both have same charaters and with same frequency. Same is the case for odd index characters.

  1. Take two vecotrs odd and even of size 26.
  2. Traverse s2 & s2 and increment the corresponding char count for s1 and decreament fo s2.
  3. Finally traverse the odd and even and check that there is no char count missmatch ( basically not equal to zero) in the vecotrs. If found so return false. Other wise return true.

C++

bool checkStrings(string s1, string s2) {
    vector<char> odd(26,0), even(26,0);
    for(int i = 0; i < s1.size(); ++i){
        if(i%2) { odd[s1[i] - 'a']++; odd[s2[i] - 'a']--; }
        else { even[s1[i] - 'a']++; even[s2[i] - 'a']--; }
    }
    for(int i = 0; i < odd.size(); ++i){
        if(odd[i] || even[i]) return false;
    }
    return true;
}

public boolean checkStrings(String s1, String s2) {
    int[] odd = new int[26], even = new int[26];
    for (int i = 0; i < s1.length(); ++i) {
        if (i % 2 == 1) {
            odd[s1.charAt(i) - 'a']++;
            odd[s2.charAt(i) - 'a']--;
        } else {
            even[s1.charAt(i) - 'a']++;
            even[s2.charAt(i) - 'a']--;
        }
    }
    for (int i = 0; i < odd.length; ++i) {
        if (odd[i] != 0 || even[i] != 0) return false;
    }
    return true;
}

Intuition

This is the key condition in problem statment
Choose any two indices i and j such that i < j and the difference j - i is even, then swap the two characters at those indices in the string.

even index forms a swappable network
odd index forms a swappable network

Explanation below,

Approach

In each swappable network (odd and even) if the character count are same for both strings s1 ans s2.
Then return True else return False

Complexity

  • Time complexity: O(n)
  • Space complexity: O(n)

                d2_e[s2[i]] += 1

Intuition

The code aims to check if two input strings, s1 and s2, can be made the same by rearranging their characters in a specific way.

Approach

  1. The code starts by checking if s1 and s2 are already the same strings. If they are, it directly returns true, indicating that no further action is needed because they are already equal.

  2. If s1 and s2 are not the same, the code initializes two arrays, odd_count and even_count, each containing 26 elements. These arrays are used to keep track of how many times each letter of the English alphabet (lowercase) appears in the odd and even positions of the two input strings.

  3. Then, for each character, it checks whether its position in the string is odd or even. If the position is odd (e.g., the 1st, 3rd, 5th character, etc.), it updates the odd_count arrays for both strings. If the position is even (e.g., the 2nd, 4th, 6th character, etc.), it updates the even_count arrays for both strings.

  4. After processing all characters, the code checks if the odd_count and even_count arrays are all zeros. If they are, it means that the characters in both strings can be rearranged to make them equal as both s1 and s2 have same characters at even and odd places, so it returns true.

  5. If any element in the odd_count or even_count arrays is not zero, it means that the characters cannot be rearranged to make the strings equal, so the code returns false.

Complexity

  • Time complexity:

O(N)

  • Space complexity:

O(1)

Code

class Solution {
    public boolean checkStrings(String s1, String s2) {
        if(s1.equals(s2))
            return true;
        
        int [] odd_count = new int[26];
        int [] even_count = new int[26];
        for(int i=0; i<s1.length();i++){
            if(i%2 == 1){
                odd_count[s1.charAt(i)-97]++;
                odd_count[s2.charAt(i)-97]--;
            }
            else{
                even_count[s1.charAt(i)-97]++;
                even_count[s2.charAt(i)-97]--;
            }
        }
        
        for(int i=0; i<26;i++){
            if(odd_count[i] != 0 || even_count[i] != 0){
                return false;
            }
        }
        return true;
        
    }
}
