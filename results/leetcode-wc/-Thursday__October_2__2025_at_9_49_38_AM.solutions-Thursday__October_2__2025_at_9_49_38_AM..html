? 3223. Minimum Length of String After Operations | Multiple Approaches (Python, C++, Java, JavaScript, Ruby, Go, C# Solutions)

? Problem

You are given a string s. You can perform the following operation repeatedly:

  1. Choose an index i such that there is at least one identical character to the left and right of s[i].
  2. Remove the closest identical characters on both sides of s[i].

The task is to return the minimum length of the string after all possible operations.

? Intuition

The problem boils down to efficiently handling characters' frequencies:

  1. Characters with even frequencies: These can be fully removed in pairs.
  2. Characters with odd frequencies ≥ 3: We remove pairs until one remains.
  3. We don’t need to simulate the operations, just analyze how much of the string is left after applying these rules.

?? Approach 1: One-Liner Using Counter

  • Leverage Python's Counter to count character frequencies.
  • Add 1 for odd frequencies and 2 for even ones to get the effective length.
Python
class Solution:
    def minimumLength(self, s: str) -> int:
        return sum(1 if x % 2 else 2 for x in Counter(s).values())

? Key Idea:
Iterate through the frequency counts:

  • For odd counts, one character remains.
  • For even counts, all characters can be removed in pairs.

?? Complexity:

  • Time: O(n) for counting characters.
  • Space: O(1) (constant space for 26 English letters).

?? Approach 2: Using a Frequency Array

  • Use an array of size 26 to count occurrences of each character.
  • For each character frequency:
    • If the frequency is even, add 2 to the total length.
    • If the frequency is odd, add 1 to the total length.

class Solution:
    def minimumLength(self, s: str) -> int:
        char_frequency = [0] * 26
        total_length = 0
        for char in s:
            char_frequency[ord(char) - ord('a')] += 1
        for frequency in char_frequency:
            if frequency == 0:
                continue
            if frequency % 2 == 0:
                total_length += 2
            else:
                total_length += 1
        return total_length

? Key Idea:
Track each character's frequency:

  • For even frequencies, characters can be removed in pairs.
  • For odd frequencies, one character remains.

?? Complexity:

  • Time: O(n) for counting characters.
  • Space: O(1) (constant space for 26 English letters).

?? Approach 3: Optimized Pair Reduction

  • Count character frequencies.
  • For each frequency ≥ 3, reduce pairs (-2) iteratively until the frequency is < 3.

from collections import Counter

class Solution:
    def minimumLength(self, s: str) -> int:
        count = Counter(s)
        minus = 0
        for x in count.values():
            while x >= 3:
                minus += 2
                x -= 2
        return len(s) - minus

? Key Idea:
For each character:

  • Subtract 2 for every removable pair until no more pairs can be removed.

?? Complexity:

  • Time: O(n) for counting + constant pair reductions.
  • Space: O(1).

Approach

  • Intitialise the ans with the size of the string
  • Keep tracking the total frequency of each character
  • Once the frequency of any char is greater then one and odd number count then reduce the ans by 2
  • Return ans

Complexity

  • Time complexity: O(N)

  • Space complexity: O(1)

int minimumLength(string s) {
    int ans = s.size();
    vector<int> freq(26, 0);
    for(auto c: s){
        freq[c - 'a']++;
        if(freq[c-'a'] != 1 && freq[c-'a'] % 2 == 1) ans -= 2;
    }
    return ans;
}

Intution

- For each character in the string, count how many times it appears.

  • For a character that occurs f times:

    1. If f is odd: You can delete f - 1 characters. This is because after removing f - 1 characters, one character will remain.
    2. If f is even: You can delete f - 2 characters. This is because after removing f - 2characters, two characters will remain.

class Solution {
public:
    int minimumLength(string s) {
        int n = s.length(), del = 0;
        unordered_map<char, int> mp;
        // Count the frequency of each character
        for(int i = 0; i < n; i++){
            mp[s[i]]++;
        }
        // Calculate the number of characters to be removed
        for(auto ele : mp){
            int freq = ele.second;
            del += (freq%2) ? freq - 1 : freq - 2;
        }
        return n - del;
    }
};
