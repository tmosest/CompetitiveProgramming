class Solution {
    public int minSkips(int[] dist, int speed, int hoursBefore) {
        // Observations: 
        //    1. to skip is always better than not to skip
        //    2. given a fixed number of skips, the best time to reach ith road only depends on the best time to reach i-1 th road, 

        // Definition: 
        //      dp[i][j] / speed: minimum time needed if given j skip, to cover first i roads
        // init: 
        //      dp[0][0] / speed = ceiling of (dist[0] / speed)
        //      dp[0][1..j] = dist[0] / speed
        // transition: 
        //      when including ith road, i.e. from i-1 to i
        //          if skip at i, dp[i][j] / speed = dp[i-1][j-1] / speed + dist[i] / speed
        //          if not skip at i, dp[i][j] / speed = dp[i-1][j] / speed + (dist[i] + X) / speed, 
        //              X is defined as in: (dp[i-1][j] + dist[i] + X) / speed is the ceiling of (dp[i-1][j] + dist[i]) / speed
        //      dp[i][j] / speed = the min of above two choices
        
        // if ith road is the last one, doesn't need the skip to finish
        // dp[n][j] / speed = dp[n-1][j] / speed + dist[i] / speed
        
        // Observations: 
        //    1. speed is a constant, can be removed from equation. 
        //    2. backward traverse on j, to use only 1d array
        //    3. init step can be baked into transition step
        
        //init for i = 0, no need
        int[] dp = new int[dist.length+1]; // 0 .. j skips
        // dp[0] = (dist[0] + speed - 1) / speed * speed; // ceiling of dist[0] / speed
        // for (int i = 1; i < dp.length; i++) {
        //     dp[i] = dist[0];
        // }
        
        for (int i = 0; i < dist.length; i++) {
            for (int j = dp.length - 1; j >= 0; j--) {
                
                // two way of calculate the ceiling
                // int notToSkip = (dp[j] + dist[i]) % speed == 0 ? dp[j] + dist[i] : dp[j] + dist[i] + speed - (dp[j] + dist[i]) % speed; 
                int notToSkip = (dp[j] + dist[i] + speed - 1) / speed * speed;
                int toSkip = j - 1 >= 0 ? dp[j-1] + dist[i] : notToSkip; // if j == 0, cannot skip
                
                if (i == dist.length - 1) {
                    dp[j] = dp[j] + dist[i];
                } else {
                    dp[j] = Math.min(toSkip, notToSkip);
                }
            }
        }
        
        
        for (int j = 0; j < dp.length; j++) {
            if (dp[j] <= hoursBefore * speed ) {
                return j;
            }
        }
        return -1;
        
    }
}

What the question is

I had to rephrase the question to be able to come up with an approach.
This is the question I end up solving:

Given an array, we are allowed to group elements in a subarray together, with a cost of "num of element in the group -1". And the score (hour spent) of a group is the (sum of them rounded up to a multple of speed) divided by speed. Find the minimum cost required so that the score is no greater than "hoursBefore"

I think this version is so much easier to solve. We can use 1D bottom-up DP.
Let dp[i][j] be the min time to with subarray ending in ith element with j cost.
dp[i][j] = min(ceil(dp[i-1][j])+dist[i], dp[i-1][j-1]+dist[i])

Notce that dp[i][j] is only dependent on previous indexes, so we will use 1D DP with the same dp array (no next dp array).

Some other details

Please don't use double when we can just round it up to an integer.
Double loses percision the more computation we throw at it and may result in something like 30.00001 <= 30 returning false, when it should in fact be true.

Time Complexity O(N^2)

Space Complexity O(1 * N)

class Solution {
    public int minSkips(int[] dist, int speed, int hoursBefore) {
        int N = dist.length, INF = (int)1e9;
        int[] dp = new int[N];
        Arrays.fill(dp, INF);
        dp[0]=0; // before we start, we have a time of 0 for 0 cost
        for (int i = 0 ; i<N; i++){
            for (int j = i; j >= 0; j--){ // j (cost) is at most i (num of element-1) so we start from there.
                dp[j]=Math.min(j==0?INF:dp[j-1]+dist[i], ceil(dp[j], speed)+dist[i]);
            }
        }
        for (int i = 0; i < N; i++){ // find the min cost (i) such that the min time is no greater than hoursBefore
            if (ceil(dp[i],speed)/speed<=hoursBefore){
                return i;
            }
        }
        return -1;
    }
    
    private int ceil(int n, int s){
        return n+(s-n%s)%s;
    }
}

class Solution {
    public int minSkips(int[] dist, int speed, int hoursBefore) {
        int n = dist.length;
        double[][] dp = new double[n + 1][n + 1];

        for (int i = 0; i <= n; i++) {
            for (int j = 0; j <= n; j++) {
                dp[i][j] = Double.POSITIVE_INFINITY;
            }
        }

        dp[0][0] = 0;

        for (int i = 1; i <= n; i++) {
            double time = (double) dist[i - 1] / speed;

            for (int j = 0; j <= i; j++) {
                if (j > 0) {
                    dp[i][j] = Math.min(dp[i][j], dp[i - 1][j - 1] + time);
                }
                dp[i][j] = Math.min(dp[i][j], Math.ceil(dp[i - 1][j]) + time - 1e-9);
            }
        }

        for (int skips = 0; skips <= n; skips++) {
            if (dp[n][skips] <= hoursBefore) {
                return skips;
            }
        }
        return -1;
    }
}
