Problem Explanation

You are given a tree with n nodes (n ≤ 500), rooted at node 0, where each node i has a value vals[i] (1 ≤ vals[i] ≤ 10^9) and parent par[i]. The tree is undirected but rooted, with par = -1.

For each node u, you need to find maxScore[u]: the maximum sum of values from any subset of nodes in the subtree rooted at u (including u and all descendants) such that the subset is "good". A subset is good if, across the decimal representations of all selected values, each digit (0-9) appears at most once. Note:

  • A node's value may use multiple digits (e.g., 34 uses 3 and 4).
  • If a single value has duplicate digits (e.g., 22 has two 2's), it cannot be included in any good subset, as it violates the rule even alone.
  • The empty subset is always good (sum 0), but we aim for the maximum sum.
  • Digits are considered across the entire subset's values, so overlapping digits between nodes make them incompatible.

The final answer is the sum of all maxScore[u] for u from 0 to n-1, modulo 10^9 + 7.

Key Insight: This is a tree knapsack problem where nodes are "items" with values and digit "costs" (bitmasks of used digits). We select a subset per subtree with no overlapping digits to maximize the sum. Since n=500 and digits=10 (2^10=1024 states), bitmask DP is feasible, but we need tree-specific optimizations for efficiency.

Examples Recap:

  • In Example 4 (vals=, par=[-1,0,1]): Node 1 (22) uses digit 2 twice, so it cannot be included. For root 0, max is 3+5=8 (nodes 0 and 2).

Approach

We use bottom-up tree DP with bitmasks to track digits. For each subtree rooted at u:

  • Compute a DP array where dp[mask] = maximum sum of a good subset using only digits that are a subset of the bits in mask (mask is a bitmask where bit j set means digit j is allowed).
  • The maxScore[u] is dp (1023 = 2^10 - 1, allowing all digits 0-9), as it covers the maximum over all possible digit subsets.

Why this DP definition?

  • It allows efficient updates: when adding a node with digit mask state, we update dp[m] for all m that can accommodate state (i.e., supersets of state) by adding the node's value to compatible prior sums.
  • Merging subtrees becomes combining their DP arrays implicitly.

Handling Nodes:

  • Compute state = getMask(vals[u]): Bitmask of unique digits in vals[u]. If any digit repeats, return -1 (node cannot be included).
  • To add a node to DP: For all prior combinations using digits disjoint from state, add vals[u] and shift to the new mask.

Tree Traversal and Merging:

  • Use DFS to build the tree adjacency list.
  • Compute subtree sizes (count[u]) during DFS.
  • For efficiency, use small-to-large merging: Build on the DP of the heaviest child (largest subtree size), add the current node u, then incorporate lighter children by adding their nodes individually (traversing the light subtrees).
  • This avoids expensive DP merges for large subtrees.

Why small-to-large?

  • Naive merging of DP arrays (e.g., convolution-like for disjoint masks) would be O(3^10) per merge (~59k operations), leading to O(n * 3^10) in worst-case bushy trees (too slow for n=500).
  • Small-to-large ensures logarithmic merges, with cost O(n log n * 2^10).

Detailed Solution Steps

  1. Build the Tree:

    • Create adjacency list graph from par[] (edges from parents to children).
    • n = par.length.

  2. DFS Function:

    • Takes current node u, returns the DP array for u's subtree.
    • Also updates res[u] (maxScore[u]) and count[u] (subtree size).
    • Steps inside DFS(u):
      • Increment count[u] (include self).
      • Recurse on all children v, collect their DP arrays, update counts, and track the heaviest child (max size, its DP, and index).
      • If no children, initialize dp = new long (all 0).
      • Otherwise, set dp to the heaviest child's DP (reuses computation for the large part).
      • Add current node u: If state = getMask(vals[u]) >= 0, update dp:
        • init = 1023 - state (masks disjoint from state).
        • Enumerate submasks i of init (using i = (i-1) & init for efficiency and in-place safety).
        • For each i, dp[i | state] = max(dp[i | state], dp[i] + vals[u]).
        • Separately, dp[state] = max(dp[state], vals[u]) (handles i=0 case).
        • This effectively sets dp[m] = max(dp[m], prior_sum + vals[u]) for all m superset of state, where prior_sum uses digits <= (m & ~state).
      • Add light children: For each child v != heaviest, call update(v, dp) to incorporate v's subtree node-by-node.
      • Set res[u] = dp.
      • Return dp.

  3. Update Function (for light subtrees):

    • Traverses the subtree rooted at u, adding each node to the passed dp.
    • Compute state = getMask(vals[u]).
    • If state >= 0, perform the same submask update as above to add vals[u].
    • Recurse on all children v of u: update(v, dp).
    • Note: This re-processes nodes in light subtrees, but only O(log n) times per node due to small-to-large.

  4. getMask Function:

    • Extracts digits from x (vals[u]).
    • Builds mask by setting bits for each digit (x % 10).
    • If any digit repeats (bit already set), return -1.
    • Handles positive integers; skips if x=0 (but vals >=1).

  5. Final Answer:

    • Call DFS from root 0, populate result[].
    • Sum all result[i], take modulo 10^9+7.

Correctness:

  • DP updates ensure only disjoint digit sets are combined (via submask checks).
  • Empty subset (sum 0) is implicitly included.
  • Nodes with state=-1 are skipped, correctly excluding them.
  • Small-to-large ensures we reuse heavy computations without redundant merges.

Optimizations

  • Bitmask DP: Limits states to 1024 (2^10), as only 10 digits exist. This is crucial for feasibility.
  • Submask Enumeration: Updates in O(2^10) per node add (enumerates ~1024 submasks), done in-place safely with the reverse order (i-1) & init to avoid overwriting.
  • Small-to-Large Merging: By reusing the heavy child's DP and adding light subtrees node-by-node, we achieve O(log n) re-processing per node. Without this, time could degrade to O(n^2 * 2^10) in stars (bushy trees).
    • Heuristic: Heaviest child by subtree size (count[v]) ensures the "small" side is minimized.
  • Discarding Light DPs: We compute but discard light children's DPs, re-adding their nodes directly—this is cheaper for small sizes.
  • Modulo Handling: Applied only at the end on the sum, as individual sums fit in long (n*10^9 < 2^63).
  • No Extra Data Structures: DP arrays are created per DFS call, but recursion depth is O(n) worst-case (chain), fine for n=500.

Time and Space Complexity

  • Time: O(n log n * 2^10) ≈ 500 * 9 * 1024 ≈ 4.6M operations (fast). The log n comes from small-to-large re-adds; each update costs O(2^10).
  • Space: O(n) for graph, result, count + O(1024 * d) for recursion stack (d = tree depth ≤ n), plus temporary DPs. Total ~O(n + 1024 n) worst-case, but practical for n=500.

class Solution {
    static int mod = (int)1e9 + 7;
    public int goodSubtreeSum(int[] vals, int[] par) {

        int n = par.length;
        List<Integer>[] graph = new ArrayList[n];
        Arrays.setAll(graph, i -> new ArrayList<>());
        for (int i = 1; i < n; i++) 
            graph[par[i]].add(i);

        long[] result = new long[n];
        dfs(vals, graph, 0, result, new int[n]);
        
        long ans = 0;
        for (long x : result) 
            ans += x;
            
        
        return (int) (ans % mod);
    }

    private long[] dfs(int[] vals, List<Integer>[] graph, int u, long[] res, int[] count) {
        count[u]++;
        long[] dp = null;
        int max = 0;
        int maxI = -1;
        for (int v : graph[u]) {
            long[] j = dfs(vals, graph, v, res, count);
            count[u] += count[v];
            if (count[v] > max) {
                max = count[v];
                dp = j;
                maxI = v;
            }
        }
        if (null == dp) 
            dp = new long[1024];

        int state = getMask(vals[u]);
        if (state >= 0) {
            int init = dp.length - 1 - state;
            for (int i = init; i > 0; i = (i - 1) & init) 
                dp[i | state] = Math.max(dp[i | state], dp[i] + vals[u]);
            
            dp[state] = Math.max(dp[state], vals[u]);
        }

        for (int v : graph[u]) {
            if (v != maxI) 
                update(vals, graph, v, dp);
        }

        res[u] = dp[dp.length - 1];
        return dp;
    }

    private int getMask(int x) {
        int mask = 0;
        for (int i = x; i > 0; i /= 10) {
            int j = i % 10;
            if ((mask & (1 << j)) != 0) 
                return -1;
            
            mask |= 1 << j;
        }
        return mask;
    }

    private void update(int[] vals, List<Integer>[] graph, int u, long[] dp) {
        int state = getMask(vals[u]);
        if (state >= 0) {
            int init = dp.length - 1 - state;
            for (int i = init; i > 0; i = (i - 1) & init) 
                dp[i | state] = Math.max(dp[i | state], dp[i] + vals[u]);
            
            dp[state] = Math.max(dp[state], vals[u]);
        }

        for (int v : graph[u]) 
            update(vals, graph, v, dp);
    }
}
