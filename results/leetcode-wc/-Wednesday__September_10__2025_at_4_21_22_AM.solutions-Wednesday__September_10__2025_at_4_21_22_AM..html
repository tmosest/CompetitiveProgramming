? Understanding the Question

  • We're given an array nums and we need to find the number of subarrays in nums which have pairs of identical numbers >= k.
  • For example : if nums = [1, 5, 1, 3]
    • Here for the subarray [1, 5, 1], the number 1 repeats twice, i.e there is one pair of identical number here.

? Approach 1 ? Brute Force

  • In this approach we simply check for the pairs of elements being >= k in all possible subarrays of nums using a nested for loop.
  • ? Time Complexity ? O(n2)
  • ? Space Complexity ? O(n)

class Solution {
public:
    long long countGood(vector<int>& nums, int k, long long cnt = 0) {
        for (int i = 0; i < nums.size(); i++) {
            unordered_map<int, int> mpp;
            long long pairs = 0;
            for (int left = i; left < nums.size(); left++) {
                pairs += mpp[nums[left]];
                mpp[nums[left]]++;
                if (pairs >= k) cnt++;
            }
        }
        return cnt;
    }
};

? Approach 2 ? Sliding Window

  • Here we traverse over the subarrays of nums in one traversal.
  • An important observation that we need to make here is that if a subarray has at least k good pairs, then all subarrays starting at the same point and ending at any element further will also be valid.
  • We use a map mpp in this approach, where the map stores the frequency of elements in the current window.
  • Now we traverse over the nums vector,

1?? Step 1 ? Deducing the Pair Count

k -= mpp[nums[i]]++
  • This is used to remove the count of the current frequency of that element in our window from the number of pairs required for a good subarray.
  • This is because let's say an element is present 2 times, on adding it the 3'rd time in our window, the count of number of pairs increases by 2.
  • So on adding a number, we increase the total number of pairs in the window by what the previous frequency of that number was.
    • Adding any number with frequency x , increases the number of pairs count by x)
    • Adding [3, 3, 3], on adding the first 3, mpp[3] = 1.
    • On adding the second 3, mpp[3] = 2, so number of pairs formed = previous frequency.
    • On adding third 3, mpp[3] = 3, so the number of pairs increased = previous frequency = 2. (it forms a pair with the first & second 3)
  • Therefore we reduce the previous frequency due to the formula
  • Count of pairs increased=Previous Frequency of the number added.

2?? Step 2 ? Shrinking the Window from left

while (k <= 0) k += --mpp[nums[left++]]
  • While we have atleast k pairs of identical elements in our window, we keep reducing the size of the window from the left and keep reducing its frequency to go through the subarrays that are formed without including elements towards the left. This mean that let's say
    • For nums = [1, 1, 3, 1] and k = 2, Here we also need to include the subarray of [1, 3, 1].
    • So inorder to count that subarray good aswell, we need to shrink the window from the left also.

Q.) Why do we subtract left here?

Ans.) As discussed above, a number reduces the number of pairs formed in terms of its existing frequency so we just keep reducing the existing frequency count while traversing and shrinking.

3?? Step 3 ? Count good subarrays starting from [0, left-1] & ending at i

cnt += left
  • This adds the number of valid subarrays ending at i, since all subarrays starting from index 0 to left - 1 and ending at i are considered valid as it has >= k pairs of identicals.
  • ? Time Complexity ? O(n)
  • ? Space Complexity ? O(n)

???Example Walkthrough

  • For nums = [3, 1, 4, 3, 2, 2, 4] and k = 2:
    • At i = 0 or nums[0] = 3:
      • No pairs yet ? k remains 2
      • left remains 0
    • At i = 1 or nums[1] = 1:
      • No pairs yet ? k remains 2
      • left remains 0
    • At i = 2 or nums[2] = 4:
      • No pairs yet ? k remains 2
      • left remains 0
    • At i = 3 or nums[3] = 3):
      • 3 repeats (previous count was 1) ? 1 pair formed
      • Update: k = 2 - 1 = 1
      • left remains 0
    • At i = 4 or nums[4] = 2:
      • First occurrence of 2 ? No new pair ? k remains 1
      • left remains 0
    • At i = 5 or nums[5] = 2:
      • 2 repeats (previous count was 1) ? 1 pair formed
      • Update: k = 1 - 1 = 0
      • Now, window has at least 2 pairs ? The while loop starts :
        • Decrement frequency of nums[left] or nums[0] = 3: frequency goes from 2 to 1.
        • Update: k = 0 + 1 = 1
        • Increment left from 0 to 1
      • Count valid subarrays ending at i:
        • cnt += left ? cnt = 0 + 1 = 1
    • At i = 6 (nums[6] = 4):
      • Process 4: decrease k by current frequency of 4 (which is 1) ? k = 1 - 1 = 0
      • Update frequency of 4: becomes 2
      • While loop is executed :
        • First iteration :
          • nums[left] = nums[1] = 1, decrement its frequency from 1 to 0
          • Update: k = 0 + 0 = 0
          • Increment left from 1 to 2
        • Second iteration :
          • nums[left] = nums[2] = 4, decrement its frequency from 2 to 1
          • Update: k = 0 + 1 = 1
          • Increment left from 2 to 3
      • Count valid subarrays ending at i:
        • cnt += left ? cnt = 1 + 3 = 4.
  • Total cnt = (from i = 5? 1) + (from i = 6? 3) = 4

class Solution {
public:
    long long countGood(vector<int>& nums, int k, long long cnt = 0) {
        unordered_map <int,int> mpp;
        for (int i = 0, left = 0 ; i < nums.size() ; i++) {
            k -= mpp[nums[i]]++;
            while (k <= 0) k += --mpp[nums[left++]];
            cnt += left;
        }
        return cnt;
    }
};

Intuition

We want to count subarrays that have at least k pairs of equal elements. A sliding window with frequency tracking can help maintain the number of pairs dynamically.

Approach

  • Initialize a HashMap to keep track of element frequencies in the current window.
  • Maintain a variable pc to store the number of equal pairs in the window.
  • Expand the window by moving the right pointer:
    • For each new element, increase pc by its current frequency before updating the frequency.
  • Whenever pc >= k, the window is valid:
    • Count all subarrays starting from the current left and ending at or after the right pointer.
    • Shrink the window from the left, updating frequencies and reducing pc accordingly.
  • Continue until the entire array is processed.

Complexity

  • Time complexity:O(n) Ñ each element is added and removed from the window at most once.
  • Space complexity: O(n) Ñ for storing frequencies in the HashMap.

class Solution {
    public long countGood(int[] nums, int k) 
    {
        int len=nums.length,le=0,pc=0;
        long res=0;
        Map<Integer,Integer> hm = new HashMap<>();
        for(int i=0; i<len; i++)
        {
            int fre=hm.getOrDefault(nums[i],0);
            pc+=fre;
            hm.put(nums[i],fre+1);
            while(pc>=k)
            {
                res+=(len-i);
                int f=hm.get(nums[le]);
                if(f==1)
                hm.remove(nums[le]);
                else
                {
                    pc-=(f-1);
                    hm.put(nums[le],f-1);
                }
                le++;
            }
        }
        return res;
    }
}
