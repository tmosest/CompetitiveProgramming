  • First we will be checking positive integers starting from 1 and pick the smallest one that is bigger than the average and does not appear in nums.
  • Because every element is at most 100, we only need to try up to 201.

Approach

if i not in nums

  • This checks whether i is absent in the array nums.
  • If i is already inside nums, skip it.

sum(nums) / len(nums)

  • sum(nums) ? adds all numbers in the array.
  • len(nums) ? counts how many numbers are in the array.
  • Dividing them gives the average of the array.

i > sum(nums)/len(nums)

  • This makes sure the candidate i is strictly greater than the average of the array.
  • If not, skip that number.

APPROACH 2

USE NEXT IN PLACE OF MIN

Why next ?

  • The part (i for i in range(1,202) if ...) makes a list of numbers.
  • next(...) just picks the first number from that list.
  • Since the numbers are checked in increasing order, the first one found is the smallest valid answer.

Intuition

This problem asks us to find the smallest positive integer that is greater than the average of the array and not present in the array. We need to calculate the average first, then systematically check integers starting from 1 until we find one that satisfies both conditions: it's greater than the average and absent from the array.

Approach

We'll use a sequential search with dual condition checking:

  1. Average calculation: Compute the mean of all elements in the array
  2. Sequential iteration: Start checking from 1 and increment until we find our answer
  3. Dual condition check: For each candidate number, verify:
    • It's greater than the calculated average
    • It's not present in the original array
  4. Early termination: Return immediately when both conditions are satisfied

This approach guarantees finding the smallest such integer by checking candidates in ascending order.

Complexity

  • Time complexity: O(n*k)
    Where n is the array length and k is the position of the answer. Each in operation takes O(n) time.

  • Space complexity: O(1)
    We only use a constant amount of extra variables for average and counter.

class Solution(object):
    def smallestAbsent(self, nums):
        avg = sum(nums) / len(nums)
        count = 1
        while True:
            if count > avg and count not in nums:
                return count
            else:
                count += 1
