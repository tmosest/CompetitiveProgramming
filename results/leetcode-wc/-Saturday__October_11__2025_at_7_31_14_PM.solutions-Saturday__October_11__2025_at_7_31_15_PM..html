Brief explanation: The sequence of numbers can be sorted iff for all indices i, sorted(nums)[i] can be connected to nums[i] through a series of swaps. But to use union-find to connect all nums[i] and nums[j] that are not coprime will take quadratic time. To simplify the task, we connect nums[i] to all of its prime factors.

The Union-Find was implemented by dictionary in Python3 for simplicity, and by array in C++ (~150ms) and Java(~60ms) for efficiency.

Problem Simpication

Swappability is transitive. Using notion AB to mean A can swap with B, we say, if AB and BC, then AC. Proof: [A, B, C] -> [B, A, C] -> [C, A, B] -> [C, B, A]

Using the transitive property of the swappability, we can classify numbers in the input array into one or more groups. Within the same group, any number can swap with any other number. Then, the problem can be simplified to check if every number in the nums array is in the same group as the corresponding positioned number in its sorted version. i.e., for any i in the range [0, length of nums), nums[i]~numsorted[i] if and only if they are in the same group.

For example, numbers in [9,10,3,16,5] can be classified into two groups a=[9,3] and b=[10,5,16], its sorted array is [3,5,9,10,16], digits in each position of both arrays are in the same group so that the GCD sort is possible. But list [10,5,9,3,16] that contains the same elements is impossible because the group mismatched at index 0 and 3.

            Possible            Impossible
nums:   [ 9,10, 3,16, 5]     [10,16, 9, 3, 5]
sorted: [ 3, 5, 9,10,16]     [ 3, 5, 9,10,16]
Group:    a, b, a, b, b        -, b, a, -, b

Grouping Algorithm

We use a tree represented by a list of child->parent pairs to form and merge the groups. We first group those numbers under their common prime factors. If a number (10) has multiple (2) prime factors, we then merge the multiple (2) groups into one. e.g., [10, 16] -> 2 (prime), [10, 5] -> 5 (prime) => [10, 16, 5] -> 2. We do this by iterating through all prime numbers from small to large and processing each number that is multiple of the prime. Below diagram illustrates how the numbers in the list [3,5,7,9,10,16,55] are classified into three groups and its tree representation of the result, where child=parent in the child->parent pair denotes the root node.

Implementation

We can use Sieve algorithm to find prime numbers and use a similar technique to build the group tree. The prime number list can be globally precomputed and reused since the problem limits the maximal value in the nums array. We used an int array instead of a Map/Dictionary to gain the speed at the potential cost of space when the maximal value in the nums array is much larger than its size.

class Solution {
    private static final int[] primes;
    // precompute prime numbers
    static {
        primes = new int[5133];
        final int max = 100000 / 2;
        boolean[] notprime = new boolean[max];
        for (int index = 0, i = 2; i < max; i++) {
            if (notprime[i]) continue;
            primes[index++] = i;
            for (int j = (max - 1) / i; j >= 2; j--) notprime[i * j] = true;
        }
    }

    public boolean gcdSort(int[] nums) {
        final var sorted = nums.clone();
        Arrays.sort(sorted);
        final int len = nums.length, max = sorted[len - 1];
        final int[] map = new int[max + 1]; // grouping tree child->parent
        for (int i = 0; i < len; i++) map[nums[i]] = nums[i];

        for (final var p : primes) {
            if (p > max / 2) break;
            int group = p;
            map[p] = p;
            for (int num = p + p; num <= max; num += p) {
                var existing = map[num];
                if (existing == 0) continue; // value doens't exist in array
                if (existing == num) map[num] = group;  // 1st hit, set group, otherwise, group merging
                else if ((existing = root(map, existing)) < group) {
                    map[group] = existing;
                    group = existing;
                } else map[existing] = group;
            }
        }

        for (int i = 0; i < len; i++) if (root(map, nums[i]) != root(map, (sorted[i]))) return false;
        return true;
    }

    private static int root(int[] map, int num) {
        int group;
        while (num != (group = map[num])) num = group;
        return group;
    }
}

Optimization

While precomputing prime number list produces faster code, it limits the general use of the algorithm out of leetcode's problem constraint. As we mentioned early, the prime number list generation and grouping both use a similar sieve algorithm. The two processes can be merged into one so that the solution will work for any numbers as long as we have enough memory.

Complexity

Time: O(N*logN + M*log(logM)) Where N is the size of the input array, and M is the maximal number in the array.
Space: O(n+M)

class Solution {
    
    // Important concepts 
    
      // 1) if a can be swapped with b && a can be swapped with c => b can be swapped with c
      // eg -> a= 3 , b = 9 , c = 15;
      
      // 2) we have to make connected components with numbers having same gcd
    
    // IMPORTANT
    /*
     // 3) gcd of two numbers would be a number that divides both of them
          //  but finding gcd would be a n^2 task   
    
    // 4) so we will pair numbers with there prime factors 
      //  and prime factors start from 2 so the rule of gcd(a,b)>1 will also not be broken
    
    */
    
    int[] par;
    public int findPar(int u){
        if(par[u]==u) return u;
        
        return par[u] = findPar(par[u]);
    }
    

    
    public boolean gcdSort(int[] nums) {
        
        par = new int[100005];
        
        for(int i=0;i<100005;i++){
            par[i] = i;
        }
    
            
        for(int e : nums){
            
            int c = e;
            
            // finding prime factors
            for(int i=2;i<=Math.sqrt(c);i++){
                if(c%i==0){
                    
                    int p1 = findPar(c);
                    int p2 = findPar(i);
                    
                    // union(c,i);
                    
                    if(p1!=p2){
                        par[p2] = p1;
                    }
                    
                    int p3 = findPar(c/i);
                    
                    if(p1!=p3){
                        par[p3] = p1;
                    }
                    
                    // union(c,c/i);
                }
            }
            
        }
        
        // cloning nums
        int[] temp = nums.clone();
        
        Arrays.sort(temp);
        
        for(int i=0;i<nums.length;i++){
            
            // if at a certain point the ith elements in sorted array and nums dont match 
            // => they don't belong to the same component the can not be swapped
            if(nums[i]!=temp[i]){
                if(findPar(nums[i])!=findPar(temp[i])) return false;
            }
        }
        
        return true;
    }
}
