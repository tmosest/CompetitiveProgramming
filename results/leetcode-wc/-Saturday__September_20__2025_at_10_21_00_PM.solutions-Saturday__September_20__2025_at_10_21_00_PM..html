Intuition

The key insight is that each sensor covers a square area with side length 2k + 1 (k cells in each direction plus the center cell). To minimize the number of sensors, we need to optimally tile the entire grid with these coverage squares.

Approach

  1. Calculate the coverage size of each sensor: size = 2k + 1
  2. Determine how many sensors are needed horizontally: divide n by size and round up
  3. Determine how many sensors are needed vertically: divide m by size and round up
  4. The total number of sensors is the product of horizontal and vertical sensor counts

This greedy approach works because placing sensors in a regular grid pattern with maximum spacing ensures optimal coverage without overlap waste.

Complexity

  • Time complexity:
    O(1)

  • Space complexity:
    O(1)

class Solution {
    fun minSensors(n: Int, m: Int, k: Int): Int {
        val size = k * 2 + 1
        val x = n / size + if (n % size == 0) 0 else 1
        val y = m / size + if (m % size == 0) 0 else 1
        return x * y
    }
}
