Note: there is even a simpler combinatorics solution, proposed by geekykant.

What is the appeal of all substrings that end at i-th position?

  • It is the same as the appeal of all substrings that end at i - 1 position, plus:
  • number of substrings (ending at i-th position) that do not contain s[i] character.
    • to count those substrings, we just track the previous (prev) position of s[i] character.

C++
Since we initialize last with zero, we need to do + 1

long long appealSum(string s) {
    long long res = 0, cur = 0, prev[26] = {};
    for (int i = 0; i < s.size(); ++i) {
        cur += i + 1 - prev[s[i] - 'a'];
        prev[s[i] - 'a'] = i + 1;
        res += cur;
    }
    return res;
}

Python 3

class Solution:
    def appealSum(self, s: str) -> int:
        res, cur, prev = 0, 0, defaultdict(lambda: -1)
        for i, ch in enumerate(s):
            cur += i - prev[ch]
            prev[ch] = i
            res += cur
        return res

Intuition

Quite similar to 828. Count Unique Characters of All Substrings of a Given String.
You can take 828 as an another chanllendge to practice more.

Explanation

assume we have string xxxaxxxxb..., with s[i] = a and s[j] = b.
s[i] is th last character a before that b.

We want to count, how many substring ending at s[j] contains character a.
They are xxxaxxxxb, xxaxxxxb, xaxxxxb, axxxxb ....,
i + 1 substring ending with character a at s[i],
so we do res += i + 1.

We repeatly do this for every s[i] and every one of 26 characters.

Complexity

Time O(n)
Space O(26)

Java

    public long appealSum(String s) {
        int last[] = new int[26];
        long res = 0;
        for (int i = 0; i < s.length(); ++i) {
            last[s.charAt(i) - 'a'] = i + 1;
            for (int j: last)
                res += j;
        }
        return res;
    }

C++

Python

Solution3: Count contirbution for each character

This solution is more like what we do for 828. Count Unique Characters of All Substrings of a Given String.
You can take 828 as an another chanllendge to practice more.

In a substring, multiple same character only get one point.
We can consider that the first occurrence get the point.
Now for each character, we count its countribution for all substring.

For each character s[i],
the substring must start before s[i] to contain s[i]
and need to end after the last occurrence of s[i],
otherwise the last occurrence of character s[i] will get the socre.

In total, there are i - last[s[i]] possible start position,
and n - i possible end position,
so s[i] can contribute (i - last[s[i]]) * (n - i) points.

From this formula, we can also the difference between problem 2262 and 828.

Complexity: Time O(n), Space O(26)

Java

    public long appealSum(String s) {
        int last[] = new int[26];
        Arrays.fill(last, -1);
        long res = 0, n = s.length();
        for (int i = 0; i < s.length(); ++i) {
            res += (i - last[s.charAt(i) - 'a']) * (n - i);
            last[s.charAt(i) - 'a'] = i;
        }
        return res;
    }

C++

Python

    def appealSum(self, s: str) -> int:
        last = defaultdict(lambda: -1)
        res, n = 0, len(s)
        for i, c in enumerate(s):
            res += (i - last[c]) * (n - i)
            last[c] = i
        return res

Problem recap:

  • Appeal of a string: number of distinct characters in it.

  • Given a string s, find the total appeal of all its substrings.

  • Substring means any contiguous sequence of characters.

Intuition:
We want to sum the counts of distinct characters for all substrings of s.

A brute force approach would be:

  • Generate all substrings.

  • Count distinct characters in each substring.

  • Sum all these counts.

But that would be very inefficient Ñ O(n3) or O(n2) at best.

Efficient approach in the solution:
The solution cleverly uses the idea of counting the contribution of each character to the appeal of all substrings, instead of explicitly enumerating all substrings.

Key insight:

  • Consider a character c and its occurrences in the string.

  • Each occurrence of c contributes to the appeal of all substrings that include that occurrence.

We want an efficient way to sum up all those contributions for every character.

Complexity:

- Time: O(n), we just iterate once over the string.

- Space: O(1), since prev array size is fixed to 26.

Explanation of the code:

Code

Java
class Solution {
    public long appealSum(String s) {
        int len = s.length();
        int[] prev = new int[26];   // keeps track of the last occurrence index (+1) of each character
        long res = 0, cur = 0;      // res = final result, cur = appeal sum for substrings ending at current index

        for (int i = 0; i < len; i++) {
            // i + 1 - prev[s.charAt(i) - 'a'] calculates how many new substrings 
            // starting after prev occurrence include the character at i
            
            cur += i + 1 - prev[s.charAt(i) - 'a'];
            
            // update last occurrence position of this character to i + 1
            prev[s.charAt(i) - 'a'] = i + 1;

            // add current cumulative appeal for all substrings ending at i to result
            res += cur;
        }
        return res;
    }
}
