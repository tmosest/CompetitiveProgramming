Approach 1 - Bruteforce (global sync)

This solution trades performance for simplicity, it's a "brute force" approach that works by eliminating concurrency entirely rather than managing it properly.

Global Synchronization: The synchronized keyword means only one philosopher can execute the entire eating sequence at a time. This eliminates the possibility of the problematic interleaving that causes deadlock.

Correctness: ? No deadlock possible, no starvation (assuming fair thread scheduling)
Performance: ? Very poor - essentially serializes all eating, so you lose all parallelism benefits

The problem is a classic concurrency control exercise meant to teach you how to:

  • Avoid deadlock through clever resource management
  • Maximize parallelism while preventing race conditions
  • Think about proper synchronization primitives (semaphores, mutexes, condition variables)

Using synchronized on the whole method is like using a sledgehammer, it "solves" the problem but defeats the entire purpose of the question.

class DiningPhilosophers {

    public DiningPhilosophers() {
        
    }

    // call the run() method of any runnable to execute its code
    public synchronized void wantsToEat(int philosopher,
                           Runnable pickLeftFork,
                           Runnable pickRightFork,
                           Runnable eat,
                           Runnable putLeftFork,
                           Runnable putRightFork) throws InterruptedException {
        
        pickRightFork.run();
        pickLeftFork.run();
        eat.run();
        putRightFork.run();
        putLeftFork.run();
    }
}

Approach 2 - Resource Ordering (textbook solution)

Resource Ordering is THE classic textbook solution for the Dining Philosophers problem! I was taught this at my OS class in college.

Instead of every philosopher following the same pattern (pick left, then right), we impose a global ordering on the forks and make everyone respect that ordering.

Philosopher 0: Fork 4 (left) and Fork 0 (right)
Philosopher 1: Fork 0 (left) and Fork 1 (right)
Philosopher 2: Fork 1 (left) and Fork 2 (right)
Philosopher 3: Fork 2 (left) and Fork 3 (right)
Philosopher 4: Fork 3 (left) and Fork 4 (right)

The Rule: Always Pick Lower-Numbered Fork First

Approach 3 - Semaphores

Key Insight: Allow only 4 philosophers to try eating simultaneously

  • This prevents deadlock because at least one philosopher will always
  • be able to acquire both forks.

EXAMPLE SCENARIO:

  • P0, P1, P2, P3 acquire semaphore permits

  • P4 is blocked waiting for a permit (can't even try to eat)

  • P0, P1, P2, P3 compete for 5 forks among themselves

  • Since there are more forks (5) than philosophers trying (4), deadlock is impossible

  • When someone finishes eating, P4 can get their permit and try

PERFORMANCE: Much better than global synchronization!

  • Multiple philosophers can eat simultaneously
  • Only limits the ATTEMPT to eat, not the eating itself

Good existing implementation: https://leetcode.com/problems/the-dining-philosophers/solutions/407358/semaphore-mutex/

Approach 4 - Waiter/Monitor Solution

Key Insight: A centralized "waiter" coordinates access to forks
Philosophers must ask permission before eating and notify when done

The waiter is like a centralized resource manager who:

  • Knows which forks are available
  • Grants permission only when both needed forks are free
  • Wakes up waiting philosophers when resources become available

This demonstrates the classic Monitor Pattern:

  • Mutual Exclusion: waiterLock ensures only one philosopher talks to waiter at a time
  • Condition Synchronization: canEat.await() makes philosophers wait efficiently
  • Signaling: canEat.signalAll() wakes up philosophers when conditions change
public class DiningPhilosophersWaiter {
    private static final int NUM_PHILOSOPHERS = 5;
    
    // The "Waiter" - centralized coordinator
    private final ReentrantLock waiterLock = new ReentrantLock();
    private final Condition canEat = waiterLock.newCondition();
    
    // Fork states tracked by the waiter
    private enum State { THINKING, HUNGRY, EATING }
    private final State[] philosopherStates = new State[NUM_PHILOSOPHERS];
    private final boolean[] forkAvailable = new boolean[NUM_PHILOSOPHERS]; // true = available
    
    public DiningPhilosophersWaiter() {
        // Initialize all philosophers as thinking, all forks available
        for (int i = 0; i < NUM_PHILOSOPHERS; i++) {
            philosopherStates[i] = State.THINKING;
            forkAvailable[i] = true;
        }
    }
    
    public void wantsToEat(int philosopher) throws InterruptedException {
        log(philosopher, "wants to eat - asking waiter for permission");
        
        waiterLock.lock();
        try {
            // Step 1: Tell waiter we're hungry
            philosopherStates[philosopher] = State.HUNGRY;
            log(philosopher, "declared HUNGRY state to waiter");
            
            // Step 2: Wait until waiter says we can eat
            while (!canPhilosopherEat(philosopher)) {
                log(philosopher, "waiting for waiter's permission (forks not available)");
                canEat.await(); // Wait until waiter wakes us up
            }
            
            // Step 3: Waiter granted permission - reserve forks
            reserveForks(philosopher);
            philosopherStates[philosopher] = State.EATING;
            log(philosopher, "??  PERMISSION GRANTED - starting to eat!");
            
        } finally {
            waiterLock.unlock();
        }
        
        // Step 4: Eat (outside the lock - don't hold waiter hostage!)
        try {
            Thread.sleep(2000); // Eating time
            log(philosopher, "finished eating");
        } finally {
            // Step 5: Tell waiter we're done
            finishedEating(philosopher);
        }
    }
    
    private boolean canPhilosopherEat(int philosopher) {
        int leftFork = philosopher;
        int rightFork = (philosopher + 1) % NUM_PHILOSOPHERS;
        
        // Can eat if both required forks are available
        boolean canEat = forkAvailable[leftFork] && forkAvailable[rightFork];
        
        if (canEat) {
            log(philosopher, "waiter confirms: forks " + leftFork + " and " + rightFork + " are available");
        } else {
            String leftStatus = forkAvailable[leftFork] ? "available" : "taken";
            String rightStatus = forkAvailable[rightFork] ? "available" : "taken";
            log(philosopher, "waiter says: fork " + leftFork + " is " + leftStatus + 
                            ", fork " + rightFork + " is " + rightStatus);
        }
        
        return canEat;
    }
    
    private void reserveForks(int philosopher) {
        int leftFork = philosopher;
        int rightFork = (philosopher + 1) % NUM_PHILOSOPHERS;
        
        forkAvailable[leftFork] = false;
        forkAvailable[rightFork] = false;
        
        log(philosopher, "waiter reserved forks " + leftFork + " and " + rightFork);
        showForkStatus();
    }
    
    private void finishedEating(int philosopher) {
        waiterLock.lock();
        try {
            // Release forks back to waiter
            int leftFork = philosopher;
            int rightFork = (philosopher + 1) % NUM_PHILOSOPHERS;
            
            forkAvailable[leftFork] = true;
            forkAvailable[rightFork] = true;
            philosopherStates[philosopher] = State.THINKING;
            
            log(philosopher, "returned forks " + leftFork + " and " + rightFork + " to waiter");
            showForkStatus();
            
            // Wake up all waiting philosophers - let waiter decide who can eat next
            canEat.signalAll();
            log(philosopher, "waiter checking if others can now eat...");
            
        } finally {
            waiterLock.unlock();
        }
    }
    
    private void showForkStatus() {
        StringBuilder status = new StringBuilder("WAITER: Fork status [");
        for (int i = 0; i < NUM_PHILOSOPHERS; i++) {
            status.append(i).append(":").append(forkAvailable[i] ? "?" : "?");
            if (i < NUM_PHILOSOPHERS - 1) status.append(", ");
        }
        status.append("]");
        System.out.println("    " + status);
    }
    
    private void log(int philosopher, String action) {
        String timestamp = LocalTime.now().format(DateTimeFormatter.ofPattern("HH:mm:ss.SSS"));
        System.out.printf("[%s] Philosopher %d: %s%n", timestamp, philosopher, action);
    }
    
    // Philosopher thread
    static class Philosopher extends Thread {
        private final int id;
        private final DiningPhilosophersWaiter table;
        private int mealsEaten = 0;
        
        public Philosopher(int id, DiningPhilosophersWaiter table) {
            super("Philosopher-" + id);
            this.id = id;
            this.table = table;
        }
        
        @Override
        public void run() {
            try {
                while (mealsEaten < 3) { // Each philosopher eats 3 times
                    // Think
                    table.log(id, "? thinking for " + String.format("%.1f", 1 + Math.random() * 2) + " seconds");
                    Thread.sleep((long) (1000 + Math.random() * 2000));
                    
                    // Try to eat
                    table.wantsToEat(id);
                    mealsEaten++;
                    
                    table.log(id, "completed meal #" + mealsEaten + "/3");
                }
                table.log(id, "Finished all meals and leaving!");
            } catch (InterruptedException e) {
                table.log(id, "was interrupted");
                Thread.currentThread().interrupt();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        System.out.println("=== Dining Philosophers Problem - Waiter/Monitor Solution ===");
        System.out.println("Key: A centralized 'waiter' coordinates all fork access");
        System.out.println("Philosophers must ask permission and the waiter prevents conflicts!\n");
        
        DiningPhilosophersWaiter table = new DiningPhilosophersWaiter();
        Philosopher[] philosophers = new Philosopher[NUM_PHILOSOPHERS];
        
        // Start all philosopher threads
        for (int i = 0; i < NUM_PHILOSOPHERS; i++) {
            philosophers[i] = new Philosopher(i, table);
            philosophers[i].start();
        }
        
        // Wait for all philosophers to finish
        for (Philosopher philosopher : philosophers) {
            philosopher.join();
        }
        
        System.out.println("All philosophers finished eating! No deadlock occurred!");
    }
}
