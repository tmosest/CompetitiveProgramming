? Problem: Minimum Arrivals to Discard

You are given two integers w and m, and an integer array arrivals, where arrivals[i] is the type of item arriving on day i (1-indexed).

Items follow these rules:

  1. Each arrival may be kept or discarded (discard only possible on arrival day).

  2. For each day i, consider the window of days [max(1, i - w + 1), i] (the last w days).

    • In this window, each type of item can appear at most m times among the kept arrivals.

  3. If keeping the current item would cause its type to exceed m occurrences in the window, it must be discarded.

? Return the minimum number of arrivals to discard so that every w-day window contains at most m occurrences of each type.

? Intuition

We need to enforce two constraints simultaneously:

  • Look back at the last w days (sliding window).
  • Ensure that no type appears more than m times within this window.

This screams sliding window with frequency counting:

  • Maintain how many of each type we currently keep in the active window.

  • When a new arrival comes in, check if adding it breaks the m-constraint.

    • If no, keep it.
    • If yes, discard it.

  • When sliding the window forward, remove the contribution of the item that leaves the window (if it was kept).

This guarantees minimal discards because we only discard when forced.

? Approach

  1. Use an array kept[i] to mark whether the item at day i was kept (1) or discarded (0).

  2. Maintain a hash map hash[type] ? how many of this type are currently kept in the window.

  3. For each index i:

    • Slide the window:

      • If an old kept item (i - w) leaves the window, decrement its count in hash.

    • Check current item arrivals[i]:

      • If hash[arrivals[i]] < m, we keep it (mark in kept[], increment counter).
      • Otherwise, we discard it (dis++).

  4. Return the total number of discards dis.

?? Complexity Analysis

  • Time: O(n) Ñ single pass over arrivals, each step is constant-time map operations.
  • Space: O(n + U) where U = unique types (for kept[] + frequency map).

? Example Walkthrough

Example

arrivals = [1,1,1,2,2,1], w = 3, m = 2
  • Day 1 (item 1): Window [1] ? type 1 count = 1 ² m ? keep.
  • Day 2 (item 1): Window [1,2] ? type 1 count = 2 ² m ? keep.
  • Day 3 (item 1): Window [1,2,3] ? type 1 count = 2 already. Keeping would make 3 > m ? discard.
  • Day 4 (item 2): Window [2,3,4] ? counts: {1:2 (from day1,day2), 2:1} ? keep.
  • Day 5 (item 2): Window [3,4,5] ? day1 leaves, counts {1:1, 2:1}. Now item 2 count=2 ² m ? keep.
  • Day 6 (item 1): Window [4,5,6] ? counts {2:2, 1:0}. Now item 1 count=1 ² m ? keep.

? Decisions:

kept = [1,1,0,1,1,1]
discards = 1

? Code (C++)

class Solution {
public:
    int minArrivalsToDiscard(vector<int>& arrivals, int w, int m) {
        int n = arrivals.size();
        if (n == 0) return 0;
        
        unordered_map<int,int> hash; // type -> count in current window
        vector<int> kept(n, 0);      // track kept items
        int dis = 0;
        
        for (int i = 0; i < n; i++) {
            int idx = i - w;
            if (idx >= 0 && kept[idx]) {
                hash[arrivals[idx]]--;
            }
            
            int t = arrivals[i];
            if (hash[t] < m) {
                kept[i] = 1;
                hash[t]++;
            } else {
                dis++;
            }
        }
        return dis;
    }
};

? Time Complexity & Points to Remember

  • Time Complexity: O(n)

  • Space Complexity: O(n + U) where U = unique types.

  • Points:

    • Use sliding window to only track the last w days.
    • Maintain frequency counts of types in the window.
    • Discard only when forced to (greedy minimal discards).
