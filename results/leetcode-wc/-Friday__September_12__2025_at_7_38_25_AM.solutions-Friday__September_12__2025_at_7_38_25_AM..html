Intution :

  • This is similar to this problem, that has been asked in daily challenge problem 2-3 days back. This was solved by running line sweep algo.
  • But here the changes is, we need to subtract exact val from each index selected & also we can select any indices in the range given ( don't have to apply the operation on each indices in the range given and this makes this problem a bit simpler)
  • As we can select any indices in the range given, now we can think it up in this way -> consider one item in the nums at a time and then figure out - how many queries required to make it zero. also while doing so we have option to apply a query or skip the query. This implies the corelation with seen problem -> target sum from a given array -> given a target and a set of items check if the target sum is achieved by taking sum of some of the items -> typical Kanpsack dp problem of pick/not-to-pick type.
  • Once we identified that we need to apply dp, then the solution will be:
    • for each items find out the least index of the query where it can be sum up to zero.
    • for any of the items there is no such combination found then return -1
    • take the maximum index as the answer out of all items

Complexity :

  • Time : O(sizeof(nums) * max(nums[i]) * sizeof(queries))
  • Space : O(max(nums[i]) * sizeof(queries))

int solve(vector<vector<int>>& q, int i, int target, int k, vector<vector<int>>& dp){
    if(target == 0) return k;                                            // we found  a valid sum equal to target so return current index of query.
    if(k >= q.size() || target < 0) return q.size() + 1;    // return a larger number to invalidate this flow
    if(dp[target][k] != -1) return dp[target][k];
    int res = solve(q, i, target, k+1, dp);     //skip current query val
    if(q[k][0] <= i && i <= q[k][1]) res = min(res, solve(q, i, target - q[k][2], k+1, dp));   // pick the val if its range is in the range of target index
    return dp[target][k] = res;
}

int minZeroArray(vector<int>& nums, vector<vector<int>>& queries) {
    int ans = -1;
    for(int i = 0; i < nums.size(); ++i){
        vector<vector<int>> dp(nums[i]+1, vector<int>(queries.size() +1, -1));
        ans = max(ans, solve(queries, i, nums[i], 0, dp));
    }
    return (ans > queries.size())?-1: ans;
}

Intuition

We need to find Minimum K so we can use Binary search because, the function of number of Querries to tranform the Given Array into Zero Array, is Monotonic so Binary Search will be valid.

Approach

Using Binary Search we fix the Number of First k Querries.
Then for each possible/current value we find wether it is possible or not to get the Desired Zero Array.

Now as we can select any subset of indices in l to r for ith querry, we will use target sum DP concept for each of the index in given array.

Intuition

The problem requires us to determine the minimum number of queries that, when applied sequentially, can turn nums into a Zero Array (where all elements become 0).

To achieve this, we can observe:

  • Each query allows us to decrement values in a range [li, ri] by vali.
  • We must decide the smallest k (number of queries) that can make nums all zero.
  • The main challenge is ensuring that at every index i, the decrements available in the first k queries allow for an exact match to nums[i].

A binary search approach is well-suited here because:

  1. If we can make the array zero using k queries, then it's also possible with k+1, k+2, ... queries.
  2. If k is too small and doesn't work, increasing it might eventually work.
  3. Using subset sum checking, we verify whether the decrements available at each index can sum up to its value in nums.

Approach

Step 1: Binary Search on the Minimum k

We define:

  • left = 0: Using zero queries (initial case).
  • right = queries.length: Using all queries.
  • Our goal is to find the smallest k such that nums can become a Zero Array.

We perform binary search:

  1. Compute mid = (left + right) / 2, treating mid as the number of queries used.
  2. Check if using the first mid queries can make nums zero using a helper function canMakeZero().
    • If possible, try a smaller k (right = mid - 1).
    • Otherwise, increase k (left = mid + 1).
  3. The minimum valid k found is our answer.

Step 2: Applying Queries

For each mid value from binary search, canMakeZero() checks:

  1. Storing decrement values:

    • Maintain a map (Map<Integer, List<Integer>>) where map[i] stores all decrement values applicable at index i from the first mid queries.
    • Process the first mid queries, adding vali to the list for every j ? [li, ri].

  2. Checking if Each Index Can Be Made Zero:

    • At each index i, we check if map[i] contains a subset whose sum equals nums[i].
    • This is a Subset Sum Problem, which we solve using 0/1 Knapsack Dynamic Programming.

Step 3: Subset Sum Check using Dynamic Programming

To check if we can form nums[i] using elements in map[i], we use a boolean DP array:

  • dp[x] = true means we can form sum x using elements in map[i].
  • dp[0] = true (zero sum is always possible).
  • Iterate over map[i] and update dp values:
    • If num is in the list, update dp[j] |= dp[j - num] for all j ³ num.
  • If dp[nums[i]] is true, we can make nums[i] zero.

If all indices can be zero, the first mid queries are valid.

Complexity

  • Binary Search on k: O(logM), where M is the number of queries.
  • Processing Queries for Each Binary Search Step: O(M).
  • Subset Sum Check Using DP:
    • At worst, requires O(N*S) per check (where S is the max value in nums).
  • Overall Complexity:
    O(logM*(M+N*S))
    This is efficient for moderate constraints.

import java.util.*;

class Solution {
    public int minZeroArray(int[] nums, int[][] queries) {
        return minOperations(nums, queries);
    }

    public int minOperations(int[] nums, int[][] queries) {
        int left = 0, right = queries.length, answer = -1;

        while (left <= right) {
            int mid = (left + right) / 2;
            if (canMakeZero(nums, queries, mid)) {
                answer = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        return answer;
    }

    private boolean canMakeZero(int[] nums, int[][] queries, int k) {
        int n = nums.length;
        Map<Integer, List<Integer>> map = new HashMap<>();

        // Initialize map for each index
        for (int i = 0; i < n; i++) {
            map.put(i, new ArrayList<>());
        }

        // Apply first k queries
        for (int i = 0; i < k; i++) {
            int left = queries[i][0];
            int ri = queries[i][1];
            int vali = queries[i][2];
            for (int j = left; j <= ri; j++) {
                map.get(j).add(vali);
            }
        }

        // Check if each index can be made zero using subset sum
        for (int i = 0; i < n; i++) {
            int target = nums[i];
            List<Integer> values = map.get(i);

            if (!subop(values, target)) {
                return false;
            }
        }
        return true;
    }

    private boolean subop(List<Integer> values, int target) {
        int size = values.size();
        if (target == 0) return true;
        if (size == 0) return false;

        // Subset Sum DP: Check if we can form `target`
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int num : values) {
            for (int j = target; j >= num; j--) {
                dp[j] |= dp[j - num];
            }
        }
        return dp[target];
    }
}
