? Understanding The Problem

  • We're given two arrays words and groups where each element words[i] is linked to a group number groups[i]
  • We need to find the longest subsequence such that
    • Each adjacent pair of words in the subsequence are from different groups
    • Each adjacent pair of words differ by exactly one character
  • For example : words = ["bab", "dab", "cab"], groups = [1, 2, 2]
  • Here the words and groups are set up as

  • As we can see the only letter that differs in the 3 words is the letter at the first index in the three words ('ab' is same in all).
  • So adjacent pairs that have exactly one different character and different group numbers can be both ["bab", "dab"] or ["bab", "cab"].

class Solution {
public:
    bool differByOneChar(string word1, string word2) {
        if (word1.length() != word2.length()) return false;
        int diffCount = 0;
        for (int i = 0; i < word1.length(); i++) 
            diffCount += word1[i] != word2[i];
        return diffCount == 1;
    }
    
    vector<string> getWordsInLongestSubsequence(vector<string>& words, vector<int>& groups) {
        int n = groups.size();
        vector<int> dp(n, 1), parent(n, -1);
        int maxi = 0;
        
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (groups[i] != groups[j] && 
                        differByOneChar(words[i], words[j]) && 
                            dp[i] < dp[j] + 1) {
                    dp[i] = dp[j] + 1;
                    parent[i] = j;
                }
            }
            maxi = max(maxi, dp[i]);
        }
        
        vector<string> result;
        for (int i = 0; i < n; i++) {
            if (maxi == dp[i]) {
                while (i != -1) {
                    result.push_back(words[i]);
                    i = parent[i];
                }
                break;
            }
        }
        reverse(result.begin(), result.end());
        return result;
    }
};

? Intuition

We want the longest subsequence of words where:

  1. Each word differs from the previous by exactly one character (Hamming distance = 1).
  2. The group ID of each word in the subsequence must differ from the previous word's group ID.

?? Approach

  1. Iterate through each word as a starting point.

  2. Use recursion with memoization to:

    • Track the current index, last group, and last word.
    • Try both "taking" and "skipping" the current word.

  3. For the "take" condition:

    • Ensure the current word has the same length as the previous.
    • Hamming distance is exactly 1.
    • Group is different from the previous.

  4. Return the longest valid subsequence found.

? Complexity

  • Time complexity:
    O(n2ám) where n is the number of words and m is the word length (for Hamming distance comparison).

  • Space complexity:
    O(n2) due to memoization cache storing combinations of indices, group IDs, and words.

class Solution:
    def getWordsInLongestSubsequence(self, words, groups):
        from functools import lru_cache

        def hamming_dist(w1, w2):
            return sum(a != b for a, b in zip(w1, w2)) == 1

        n = len(words)
        @lru_cache(None)
        def dfs(i, last_group, last_word):
            if i == n:
                return []
            take = []
            if len(words[i]) == len(last_word) and hamming_dist(last_word, words[i]) and groups[i] != last_group:
                take = [words[i]] + dfs(i + 1, groups[i], words[i])
            skip = dfs(i + 1, last_group, last_word)
            return take if len(take) > len(skip) else skip

        res = []
        for i in range(n):
            curr = [words[i]] + dfs(i + 1, groups[i], words[i])
            if len(curr) > len(res):
                res = curr
        return res
