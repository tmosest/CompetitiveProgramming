Approach:

The problem requires us to count the number of pairs of nodes that are unreachable from each other in an undirected graph. We can approach the problem using the concept of connected components. A connected component is a subgraph where all nodes are reachable from any node in the subgraph. If there are multiple connected components, then any two nodes in different components are unreachable from each other.

We can use a Depth-First Search (DFS) to traverse the graph and count the number of nodes in each connected component. We start with an unvisited node and count the number of nodes reachable from it using DFS. We add the product of this count and the number of visited nodes so far to our answer. We repeat the process with any remaining unvisited nodes until all nodes are visited.

Intuition:

The intuition behind this approach is that any two nodes in the same connected component are reachable from each other, but any two nodes in different connected components are unreachable from each other. Therefore, we count the number of nodes in each connected component and add the product of the counts of nodes in different components to our answer. This way, we count all pairs of nodes that are unreachable from each other. We use DFS to traverse the graph and count the number of nodes in each connected component.

class UnionFind:
    def __init__(self, size):
        self.root = [i for i in range(size)]
        self.rank = [1] * size
        
    def find(self, node):
        if node != self.root[node]:
            self.root[node] = self.find(self.root[node])
        return self.root[node]
    
    def union(self, node1, node2):
        root1 = self.find(node1)
        root2 = self.find(node2)
        if root1 != root2:
            if self.rank[root1] > self.rank[root2]:
                self.root[root2] = root1
            elif self.rank[root1] < self.rank[root2]:
                self.root[root1] = root2
            else:
                self.root[root2] = root1
                self.rank[root1] += 1
                
class Solution:
    def countPairs(self, n: int, edges: List[List[int]]) -> int:
        uf = UnionFind(n)
        for node1, node2 in edges:
            uf.union(node1 - 1, node2 - 1)
        group_sizes = list(Counter([uf.find(i) for i in range(n)]).values())
        ans = 0
        first_group_size = group_sizes[0]
        for i in range(1, len(group_sizes)):
            ans += first_group_size * group_sizes[i]
            first_group_size += group_sizes[i]  
        return ans

class Solution {

    void dfs(int node, unordered_map<int,vector<int>>& gr, ll& cnt, vector<int>& vis){
        vis[node] = 1;
        cnt++;
        for(auto& i: gr[node]){
            if(vis[i]==0) dfs(i,gr,cnt,vis);   
        }
    }
    long long countPairs(int n, vector<vector<int>>& edges) {
        unordered_map<int,vector<int>> gr;
        for(int i=0;i<edges.size();i++){
            gr[edges[i][0]].push_back(edges[i][1]);
            gr[edges[i][1]].push_back(edges[i][0]);
        }
        ll ans = ((ll)n*(n-1))/2;
        vector<int> vis(n,0);
        for(int i=0;i<n;i++){
            if(vis[i]==0){
                ll cnt = 0;
                dfs(i,gr,cnt,vis);
                ans -= (cnt*(cnt-1))/2;
            }
        }
        return ans;
    }
};

Intuition

The problem asks us to find the number of pairs of different nodes that are unreachable from each other in an undirected graph. We can solve this problem by counting the number of pairs of nodes that are reachable from each other, and then subtracting it from the total number of pairs of nodes. A pair of nodes is reachable if there is a path between them.

Approach

We can use DFS to count the number of nodes in each connected component of the graph. For each connected component, the number of pairs of nodes that are reachable from each other is equal to the number of pairs of nodes within the component. The total number of pairs of nodes in the graph is n * (n - 1) / 2. Therefore, the number of pairs of nodes that are unreachable from each other is equal to the total number of pairs of nodes minus the sum of the number of pairs of nodes within each connected component.

Complexity

Time complexity:

  • Building the adjacency list takes O(E) time. ¥
  • The DFS traversal takes O(V + E) time. ¥
  • Counting the number of pairs within each connected component takes O(V) time. ¥
  • Summing up the sizes of all connected components takes O(V) time. ¥
  • Computing the answer by subtracting the number of pairs within each connected
  • component from the total number of pairs takes O(V) time.
  • Therefore, the overall time complexity of the solution is O(V + E).

Space complexity:

  • The adjacency list takes O(E) space. ¥
  • The visited array, sizes array, and any other variables used during the DFS traversal take O(V) space.
  • Therefore, the overall space complexity of the solution is O(V + E)

class Solution {
    public long countPairs(int n, int[][] edges) {
        // Build the adjacency list of the graph
        List<Integer>[] adjList = new ArrayList[n];
        for (int i = 0; i < n; i++) {
            adjList[i] = new ArrayList<>();
        }
        for (int[] edge : edges) {
            int u = edge[0];
            int v = edge[1];
            adjList[u].add(v);
            adjList[v].add(u);
        }

        boolean[] visited = new boolean[n];
        int[] sizes = new int[n];
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                sizes[i] = dfs(i, adjList, visited);
            }
        }

        long ans = 0;
        long sum = 0;
        for (int size : sizes) {
            ans += sum * size;
            sum += size;
        }

        return ans;
    }

    private int dfs(int u, List<Integer>[] adjList, boolean[] visited) {
        visited[u] = true;
        int size = 1;
        for (int v : adjList[u]) {
            if (!visited[v]) {
                size += dfs(v, adjList, visited);
            }
        }
        return size;
    }
}

Intuition

Build the Graph: Represent the nodes and edges as an adjacency 
list to model the connections between nodes.

Find Connected Components: Use DFS to identify all 
connected components in the graph, keeping track of visited nodes
to avoid duplicates.

Count Unreachable Pairs: For each connected component,calculate
 the number of unreachable pairs by multiplying its size with
 the remaining unvisited nodes and accumulate the result.

Complexity

  • Time complexity: Total Time Complexity = O(n + e) (linear in
    terms of nodes + edges).
  • Space complexity: Total Space Complexity = O(n + e).

class Solution {
    List<List<Integer>> graph = new ArrayList<>();

    public long countPairs(int n, int[][] edges) {
        for(int i = 0 ; i < n; i++){
            graph.add(new ArrayList<>());
        }

        for(int  i = 0 ; i < edges.length; i++){
            int v1 = edges[i][0];
            int v2 = edges[i][1];
            addEdge(v1,v2);
        }

        long pairs = 0;
        long prevsize = 0;
        int visited[] = new int[n];
        for(int i = 0; i < visited.length; i++){
            Set<Integer> set = new HashSet<>(); 
            
            if(visited[i] == 0){
                DFS(visited, set, i);
            }
            
            pairs += set.size() * (n - set.size() - prevsize);
            prevsize += set.size();
        }
        return pairs;
    }
    public void addEdge(int v1, int v2){
        graph.get(v1).add(v2);
        graph.get(v2).add(v1);
    }
    public void DFS(int visited[], Set<Integer> set, int start){
        Stack<Integer> st = new Stack<>();
        st.add(start);

        while(!st.isEmpty()){
            int node = st.pop();

            visited[node] = 1;
            set.add(node);

            for(int nbr : graph.get(node)){
                if(visited[nbr] == 0){
                    st.push(nbr);
                }
            }
        }
    }
}
