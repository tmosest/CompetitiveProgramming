Intuition

Observation 1:
"While one truck is driving or picking up garbage, the other two trucks cannot do anything."
We can simply sum up the total running time for each truck,
they don't affect each other.

Observation 2:
"Picking up one unit of any type of garbage takes 1 minute."
We don't care how many units for each type,
we only care the total amount.

Observation 3:
"however, they do not need to visit every house."
We only care the position of the last garbage for each type

Explanation

  1. Firstly sum up the amount of gabages in total.
  2. Second find up the last position for each type.
  3. Calculate the prefix sum array of the travel distance.
  4. Sum up the distance for each type of garbage.

Complexity

Time O(garbage + travel)
Space O(1)

    public int garbageCollection(String[] garbage, int[] travel) {
        int last[] = new int[128], res = 0;
        for (int i = 0; i < garbage.length; ++i) {
            res += garbage[i].length();
            for (int j = 0; j < garbage[i].length(); ++j)
                last[garbage[i].charAt(j)] = i;
        }
        for (int j = 1; j < travel.length; ++j)
            travel[j] += travel[j - 1];
        for (int c : "PGM".toCharArray())
            if (last[c] > 0)
                res += travel[last[c] - 1];
        return res;
    }

Intuition

The total time needed to collect all garbage consists of two parts:

  1. Pickup time: Every unit of garbage (M, P, G) takes exactly 1 minute to collect.
  2. Travel time: Each garbage truck must travel up to the last house that contains its respective type of garbage.

So, the idea is:

  • Count all garbage units for pickup time.
  • Find the last index of each type of garbage (M, P, G).
  • Add travel time for each truck until its last house.

Approach

  1. Pickup count: Loop through all houses and count the total number of garbage units.
  2. Track last indices: Record the last house index where M, P, and G appear.
  3. Prefix sum for travel: Compute cumulative travel time from house 0 to any house using a prefix array.
  4. Total time:
    • Start with pickup time.
    • Add the prefix travel time for each truck’s last house (if it exists).

Complexity

  • Time complexity:

    • Counting garbage units ? O(n)
    • Tracking last indices ? O(n)
    • Building prefix sum ? O(n)
    • Overall: O(n)

  • Space complexity:

    • Prefix sum array ? O(n)
    • Can be optimized to O(1) if we compute directly.
    • Overall: O(n)

Code

Java
class Solution {
    public int garbageCollection(String[] garbage, int[] travel) {
        int n = garbage.length;

        // total pickup time (count all characters)
        int totalPickup = 0;
        for (String g : garbage) {
            totalPickup += g.length();
        }

        // last index of each garbage type
        int lastM = -1, lastP = -1, lastG = -1;
        for (int i = 0; i < n; i++) {
            if (garbage[i].contains("M")) lastM = i;
            if (garbage[i].contains("P")) lastP = i;
            if (garbage[i].contains("G")) lastG = i;
        }

        // Prefix sum of travel times
        int[] prefix = new int[n];
        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i - 1] + travel[i - 1];
        }

        // travel time for each truck
        int total = totalPickup;
        if (lastM != -1) total += prefix[lastM];
        if (lastP != -1) total += prefix[lastP];
        if (lastG != -1) total += prefix[lastG];

        return total;
    }
}
