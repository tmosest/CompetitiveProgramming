Approach

The Gist of the Problem

Imagine you have a set of 10 rods numbered 0 to 9. You also have a collection of rings that are either Red (R), Green (G), or Blue (B). You're given a string that tells you which rod each ring is placed on. The goal is to find out how many rods have rings of all three colors (R, G, and B).

The Java Code Explained

class Solution {
    public int countPoints(String rings) {
        // 1. Initialize an array to store color info for each rod (0-9)
        //    Each rod will have a bitmask to represent its colors
        int[] masks = new int[10];

        // 2. Get the length of the input string
        int n = rings.length();

        // 3. Iterate through the string, processing two characters at a time
        //    (color and rod number)
        for (int i = 0; i < n; i += 2) {
            // 4. Extract the color of the ring
            char color = rings.charAt(i);

            // 5. Extract the rod number and convert it from char to integer
            int rod = rings.charAt(i + 1) - '0';

            // 6. Determine the bitmask value based on the color
            int maskValue = 0;
            if (color == 'R') {
                maskValue = 1;  // Red is represented by the 1st bit (001)
            } else if (color == 'G') {
                maskValue = 2;  // Green is represented by the 2nd bit (010)
            } else if (color == 'B') {
                maskValue = 4;  // Blue is represented by the 3rd bit (100)
            }

            // 7. Update the rod's mask by setting the corresponding color bit
            //    The |= operator performs a bitwise OR and assignment
            masks[rod] |= maskValue;
        }

        // 8. Count the number of rods that have all three colors (R, G, and B)
        int count = 0;
        for (int i = 0; i < 10; i++) {
            // 9. Check if the rod's mask is equal to 7 (1 + 2 + 4 = 7, meaning all 3 bits are set)
            if (masks[i] == 7) {
                count++; // Increment the count if all three colors are present
            }
        }

        // 10. Return the total count of rods with all three colors
        return count;
    }
}

Time and Space Complexity

  • Time Complexity: O(N) where N is the length of the rings string. The code iterates through the string once to process the rings and then iterates through the masks array (which has a fixed size of 10). The string iteration dominates.
  • Space Complexity: O(1) (Constant Space). The masks array has a fixed size of 10, and we use a few integer variables. The space used doesn't depend on the size of the input.

High-Level Solution Architecture

  1. Represent Colors with Bits: Use bit manipulation (bitmasks) to represent the presence of colors on each rod. Each color corresponds to a specific bit.
  2. Process the Input String: Iterate through the input string and update the bitmask for each rod based on the colors of the rings on that rod.
  3. Count Rods with All Colors: Iterate through the array of bitmasks and count the number of rods that have all three color bits set.
