Intuition

For each group size, we need to find an element that divides it and has the smallest index. Since multiple elements might be divisors, we should prioritize the one with the smallest index. To do this efficiently, we can store elements in a hash map with their index and check divisibility for each group size. If no element satisfies the condition, assign -1.

Approach

  1. Storing Elements in a Hash Map
  • First, we store the smallest index of each unique element from elements[] in an unordered map (m).
  • This allows for quick lookups to check if an element exists and retrieve its smallest index in O(1) time.
  1. Iterating Over Each Group in groups[]
  • For each group size groups[i], we need to find a divisor that exists in elements[] and has the smallest index.
  • Instead of checking all elements (which would be O(N * M), slow), we efficiently find all divisors of groups[i] in O(ÃN) time.
  1. Finding the Best Element for Each Group
  • To determine the best element for groups[i], we check all divisors of groups[i]:
  • If a divisor exists in m, we update the smallest index found.
    Since divisors always appear in pairs (e.g., for 8, divisors are {1, 8}, {2, 4}), we only check up to Ãgroups[i], reducing complexity.
  1. Assigning Values to the Result Array
  • If a valid divisor is found in elements[], store the smallest index in the answer.
  • If no valid divisor exists, store -1.

void check(int n , unordered_map<int,int>& m , vector<int>& ans){
        int k=INT_MAX;
        for(int i=1;i*i<=n;i++){
            if(n%i==0 and m.count(i)){
                k=min(k,m[i]);
            }

            if(i!=n/i and n%i==0 and m.count(n/i)){
                k=min(k,m[n/i]);
            }
        }
        
        if(k!=INT_MAX) ans.push_back(k);
        else ans.push_back(-1);
    }

        }

        for(int i=0;i<v.size();i++){
            check(v[i],m,ans);
        }

        return ans;
    }

Intuition

  • Here the first and very obivious solution ( bruteforce approach) is to check each elements divides the groups[i] item, if so return the first elements that divides the same. But this will lead to TLE as order is N x N.
  • Next thought is => can we keep the elements in a map with its index as value and then check if the groups[i] can be devided by any item of elements or not.
  • To do so we need to find all the factors of groups[i] and then check if any of those factor is present in the map or not. If present then take the one with min index.
  • But to do so the bruteforce appraoch is again check all the number from 1 to n if they divides then groups[i] or not and present in the map or not.
    This also will take O(n) for each groups[i]. This can be optimized by finding factors who are less than equal to sqrt(groups[i]) and then populate other larger factor by dividing the smaller factor from the groups[i].

Approach

  • store all the items of element in a map. This is some what we call reverse indexing. Also while doing so we can have duplicate items in elements, so take the item with min index ( or just take the first occurance and ignore rest)
  • Then iterate over groups of items
  • For each groups[i] find all factors and while doing so check if it is present in map or not. If both satisfy then add it to ans[i] and track the min item poddible for ans[i]

Complexity

  • Time complexity: O( max( M x sqrt(k), N)
  • Space complexity: O(N)

Where N is total item count in elements, M is total item count in grops, k is largest item in grops

vector<int> assignElements(vector<int>& groups, vector<int>& elements) {
    vector<int> ans(groups.size(), -1);
    unordered_map<int,int> eleIndex;
    for(int i = 0; i < elements.size(); ++i) eleIndex[elements[i]] = (eleIndex.find(elements[i]) != eleIndex.end())? min(eleIndex[elements[i]], i): i;
    for(int i = 0; i < groups.size(); ++i){ 
        for(int f = 1; f*f <= groups[i]; ++f){
            if(groups[i] % f == 0 && eleIndex.find(f) != eleIndex.end()) ans[i] = min(((ans[i] >= 0)?ans[i]:INT_MAX), eleIndex[f]);
            if(groups[i] % f == 0 && eleIndex.find(groups[i]/f) != eleIndex.end()) ans[i] = min(((ans[i] >= 0)?ans[i]:INT_MAX), eleIndex[groups[i]/f]);
        }
    }
    return ans;
}

class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:

        d, mx = defaultdict(lambda: -1), max(groups)+1

        for i, element in enumerate(elements):
            if element in d: continue

            for num in range(element, mx, element):
                if num in d: continue
                d[num] = i

        return list(map(lambda x: d[x], groups))
