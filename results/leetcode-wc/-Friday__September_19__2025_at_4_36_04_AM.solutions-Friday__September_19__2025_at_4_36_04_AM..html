Approach

The Problem

Imagine you have a mixed bag of letters and numbers (a string). Our job is to fish out all the different numbers from that bag and count how many unique ones we found. The catch? Numbers can have leading zeros (like "007"), and we only want to count "7" once. Think of it like sorting your candy stash after Halloween Ð you only care about the different types, not how many of each you have! ?

Code Breakdown, Line by Line ???

import java.math.BigInteger; // Import the BigInteger class - we'll need it for potentially large numbers

class Solution {
    public int numDifferentIntegers(String word) {
        Set<BigInteger> set = new HashSet<>(); // ?? We create a set to store the unique numbers. A set is like a special container that only holds one of each item (no duplicates!). We use BigInteger because our numbers might be huge.
        String currNum = ""; // This variable will hold the current number we're building as we go through the string.

        for (int i = 0; i < word.length(); i++) { // ??? We start a loop that goes through each character in the input string 'word'.
            char c = word.charAt(i); // We grab the current character and call it 'c'.
            StringBuilder currNumB = new StringBuilder(); // We initialize string builder to store the number.
            
            while (i < word.length() && Character.isDigit(c)) { // ? This is the core! While we're still within the string *and* the current character 'c' is a digit (0-9)...
                currNumB.append(c); // ...we add the digit to our current number ('currNum').
                i++; if (i < word.length()) c = word.charAt(i); // We move to the next character in the string. It is to prevent errors.
            }
            currNum = currNumB.toString(); //Convert the number builder to string to replace the first zero.
            
            if (!currNum.isEmpty()) { // If we actually found a number (it's not empty)...
                String numWz = currNum.replaceFirst("^0+", ""); // We remove leading zeros from our string, so "007" becomes "7". This is the secret sauce to make sure we only count "7" once.
                if (numWz.isEmpty()) { // If after removing the zeros the string is empty it means the string was "0000"
                    set.add(BigInteger.ZERO); // if after removing the zeros the string is "" we add the number zero
                } else {
                    set.add(new BigInteger(numWz)); // We convert the cleaned-up number (as a string) into a BigInteger (because numbers can be big), and we add it to our set.
                }
                currNum = ""; // Reset currNum for the next number.
            }
        }

        return set.size(); // Finally, we return the size of the set. This tells us how many unique numbers we found.  Ta-da! ?
    }
}

Time and Space Complexity:

  • Time Complexity: O(N*M) where N is the length of the input string 'word', and M is the maximum length of the number substrings.
    • Think of it like this: We walk through the word once (the outer loop, O(N)). For each potential number, we might look at multiple digits (the inner while loop, O(M)). In the worst case, we might have a very long number.
  • Space Complexity: O(K) where K is the number of unique numbers found in the string.
    • We use a HashSet to store the unique numbers. The space used by the set will depend on how many distinct numbers there are. If we have a string full of different numbers, the set will grow.

Actions

Here's the overall plan of attack:

  1. Initialization: Set up a HashSet to store unique numbers and a temporary string builder to store current number..
  2. Iterate through the string: Go through the input string, character by character.
  3. Identify numbers: When you find a digit, start building a number.
  4. Remove leading zeros: Clean up the number by removing any leading zeros.
  5. Add to the set: Add the cleaned-up number to the set (as a BigInteger).
  6. Repeat: Continue until you've processed the entire string.
  7. Return the count: Return the size of the set Ð that's your answer!

        String currNum = "";

        for (int i = 0; i < word.length(); i++) {

            }

    }
