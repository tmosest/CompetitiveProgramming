Intuition : Just count the frequency of each character and start from 9 to 0 and check if it is occurring more than once or not if so then keep pushing it in your ans variable untill its frequency drops to 1 or less and also keep account of the number occuring exactly once after all operations.

Time Complexity : O(n)
Space Complexity : O(n)

CPP

class Solution {
public:
    string largestPalindromic(string s) {
        vector<int> v(10);
        for(char c:s)v[c-'0']++;
        string ans;
        int single=-1;
        for(int i=9;i>=0;i--){
            if(ans.empty() && i==0) continue;
            while(v[i]>1){
                ans.push_back(i+'0');
                v[i]-=2;
            }
            if(v[i]==1 && single==-1)single=i;
        }
        string res=string(ans.rbegin(),ans.rend());
        if(ans.empty() && single==-1) return "0";
        if(single!=-1)
            ans.push_back(single+'0');
        ans+=res;
        return ans;
    }
};

Intuition

Return the largest palindromic integer (in the form of a string) that can be formed using digits taken from num. It should not contain leading zeroes.

Notes:

  • You do not need to use all the digits of num, but you must use at least one digit.
  • The digits can be reordered.

Approach

My approach involves finding the largest palindromic integer using hashing and a greedy algorithm. Let's go through the steps:

Step 1: Hash all the elements of the given number string.

Step 2: Check the base case: if all the elements are '0' in the number, return "0".

Step 3:

  • Iterate from the last to the first in the hash array.
  • Check if an odd frequency of an element is present in the hash. If found, store it in the middle variable. Use a flag variable to ensure the middle element is not chosen again.
  • Divide the frequency by 2 and append the element to the first string until the frequency becomes 0. This process generates the first half of the largest palindromic number up to the least element in the original number.

Step 4: Check if the middle element of the palindromic number is present using the middle_flag variable. If present, append the middle variable to the first string.

Step 5: Store the last part of the largest palindromic number by reversing the first string (which contains the first half) and appending it to the first string. Then return the first string.

Here my approach is find to largest palindromic integer by using hashing and greedy.

Let's illustrate this with an example:

num = "11122233344455777"
Hash values:
1 - 3
2 - 3
3 - 3
4 - 3
5 - 2
7 - 3

The largest element is 7 with a frequency of 3, which is odd. Middle element = 7.
7 frequency is 3, which is divided by 2. The value is 1
Now 7 is append 1 time in first string. (middle element is not change)

5 frequeny is 2, which is divided by 2. The value is 1
Now 5 is append 1 time in first string

4 frequeny is 3, which is divided by 2. The value is 1
Now 4 is append 1 time in first string

3 frequeny is 3, which is divided by 2. The value is 1
Now 3 is append 1 time in first string

2 frequeny is 3, which is divided by 2. The value is 1
Now 2 is append 1 time in first string

1 frequeny is 3, which is divided by 2. The value is 1
Now 1 is append 1 time in first string
  • Process frequencies and generate the first half of the palindromic number: "754321".
  • Reverse it to get the last part: "123457".

The final result is "7543217123457"

Complexity

  • Time complexity: O(n) --> Traversing the array takes O(n)

  • Space complexity: O(n) --> The hash array has a constant size (10 in this case) and does not depend on the size of the input. The StringBuilder objects first and last can grow up to the size of the input array, making the overall space complexity linear with respect to the input size.

Code

class Solution {
    public String largestPalindromic(String num) {
        char[] ch = num.toCharArray();
        int n = ch.length;
        int[] hash = new int[10];
        for(int i = 0 ; i < n ; i++){
            hash[ch[i] - '0']++;
        }
        if(hash[0] == n){
            return "0";
        }
        StringBuilder first = new StringBuilder();
        char middle = 'a';
        boolean middle_flag = true;
        for(int i = 9 ; i >= 0 ; i--){
            if(middle_flag && hash[i] % 2 != 0){
                middle_flag = false;
                middle = (char)(i + '0');
            }
            int freq = hash[i] / 2;
            while(freq-- > 0){
                first.append(i);
            }
        }
        if(first.length() > 0 && first.charAt(0) == '0'){
            return String.valueOf(middle);
        }
        StringBuilder last = new StringBuilder(first);
        if(!middle_flag){
            first.append(middle);
        }
        first.append(last.reverse());
        return new String(first);
    }
}

Intuition

We use a Greedy Approach i.e. build the string using the largest numbers. Since it needs to be a palindrome, we build only the left side of the string and then duplicate it on the right side.

Approach

QUESTION TIME!!! (The solution is in the questions!)

Lets call the left side string as leftSideAnswer and the final answer as finalAnswer

Q1. How do we build the string greedily?

We sort the numbers in descending order, that way we have largest first and smallest last. Then we take those numbers one by one and build the left side of the string.
We are only building left side string, lets call it leftSideAnswer. Since we only build left side first, we will only append a number half the times. So if 5 comes count times, where count = 4 we only append it count/2 = 2 times in leftSideAnswer we are building.

Q2. What if a number comes only 1 time?

This means this number needs to be in the middle of the final string finalAnswer. To do this, we build the left side leftSideAnswer (as discussed in Q1) and then append this single number to the left side leftSideAnswer, and then duplicate it to finally complete finalAnswer.

Q3. What if multiple numbers come only 1 time.

Lets say numbers 4,9,7 come come only 1 time, well we gonna be greedy again. To make the number as big as possible, we need the biggest digits. BUT, out of 4,9,7 we can only put any one at the middle (for plaindrome). SOOO.... we keep track of the biggest number call it singleMax among these singles (4,6,7), then we append this singleMax to our leftSideAnswer.

Q4. What if a number comes odd times, wont this number be in the middle then?

GREAT QUESTION! Yes, this number can come in middle, BUT only if it is greater than our singleMax. Lets say 9 comes 3 times So everytime we append 9 to leftSideAnswer , count/2 times; then we check if it comes odd times. If it does, then it is a competitor for our singleMax . REMEMEBER in (Q3) we there was competition among 4,6,7 for singleMax, well now 9 is competing too. Since, 9 is greater than 4,6,7 , the current winner for singleMax is 9. So 9 will be in the middle.

Q5. So if we are keeping counts of each digit, do we need a hash map?

Well, yeah...kinda. The thing is that converting these charaacter to numbers and then sorting them and then adding them to a map is kinda pain in the back side. SO... we will be smarter.
See, we know that each digit will be between 0 and 9, we create an array of length 10.

int[] counts = new int[10]

Here we will store the counts of all digits. This is a hash map...kinda. Every index i is the digit and its value count[i] is the digit's count.
This is how we do it...

for(char ch: num.toCharArray())counts[ch-'0']++;

NEXT, we dont even need to sort anything, we just start a for loop from 9. But we do these operations from Q1 to Q4 only if counts[i] > 0 ,i.e. if this digit even exists in our question string num

for(int i = 9; i>=0; i--)

VOILA! we have a sorted array hashmap .....kinda. without actually going through the hassle of converting characters to integers and putting them on hashmap.
Now the code compiles all of it from Q1 to Q5.

class Solution {
    public String largestPalindromic(String num) {
        int[] counts = new int[10];
        for(char ch: num.toCharArray())counts[ch-'0']++;

        StringBuilder ans = new StringBuilder();
        int singleMax = -1;

        for(int i = 9; i>=0; i--){
            int currCount = counts[i];
            if(currCount == 0)continue;
            if(ans.length()==0 && i==0)continue;
            if(currCount==1){
                singleMax = Math.max(singleMax, i);
                continue;
            }
            else if(currCount >=2) {
                for(int j = 1; j<= currCount/2; j++) ans.append(i);
                if(currCount%2 != 0) singleMax = Math.max(singleMax, i);
            }
        }
        
        int leftLength = ans.length();
        if(singleMax != -1)ans.append(singleMax);
        for(int i=leftLength-1; i>=0; i--){
            ans.append(ans.charAt(i));
        }

        return ans.length()==0?"0":ans.toString();
    }
}
