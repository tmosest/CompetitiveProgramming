Approach

First consider a sub-problem:

Given min_stability, can we create a spanning tree that has at least min_stability?

Let's call this function check(min_stability).

check(min_stability) is monotone.

i.e., If we can create a spanning tree with min stability x, then we can create a spanning tree with min stability x - 1.

This means once we have check(min_stability), we can binary search the answer.

Now our focus is how to craft check(min_stability).

Observation 1: check(min_stability) is False for all min_stability greater than min(s_i) for must-have edges.

Proof:

A must edge needs to be included in the final spanning tree and cannot be upgraded.

Therefore, the final spanning tree cannot have a stability greater than the minimum s_i value for a must have edge.

Observation 2: If the must-have edges form a cycle, we can't have an answer.

This one is very obvious from Example 3 of the problem.

By the definition of a tree, there will not be cycles.

Observation 3: After including the must-have edges, there is a greedy method to select other edges to form spanning tree of min_stability.

Use union find to keep track of the connected components.

The goal is to check if there can be a spanning tree of min_stability, not to actually form a spanning tree.

^ This means if we can select edges (before or after upgrade) such that they have at least min_stability, and we end up with a single connected component, the required spanning tree exists.

First, all edges that have stability >= min_stability can be "included" for free.

Then, all edges that have stability * 2 >= min_stability can be considered. "eligible edge"

For each eligible edge, check if adding them connects two components. i.e., for edge (u, v), check if (u, v) is not connected in our union find structure.

Also check if we have enough upgrades left (i.e., we only have k upgrades).

If the edge connects two components and we have enough upgrades, then it is optimal to include this edge. In other words, upgrading this edge does not "waste" our number of upgrades. *(Proof below)

At the end, look at all edges selected and ensure that they connect to a single component. If they are able to connect to a single component, then a spanning tree with min_stability exists. Remember, we are checking if we can have this spanning tree, not constructing one.

class Solution:
    def maxStability(self, n: int, edges: List[List[int]], k: int) -> int:
        initial_uf = UnionFind(n)
        # Observation 1: Find minimum s_i for must-have edges.
        min_s = inf
        for u, v, s, must in edges:
            if not must: continue
            min_s = min(min_s, s)

            # Observation 2: The must-have edges form a cycle.
            if not initial_uf.union(u, v):
                return -1
        
        def check(min_stability: int) -> bool:
            # Observation 1
            if min_stability > min_s:
                return False
            
            # This copies the initial state, where all `must-have edges`
            # are connected.
            uf = UnionFind(n)
            uf.rank, uf.root = initial_uf.rank[:], initial_uf.root[:]

            # Observation 3: List of edges to consider an upgrade
            upgrade = []
            for u, v, s, must in edges:
                if must: continue
                # Observation 3
                if s >= min_stability:
                    uf.union(u, v)
                elif s * 2 >= min_stability:
                    upgrade.append((u, v))

            r = k  # number of upgrades remaining
            # The following edge selection method will not waste our chances to
            # upgrade. See proof below.
            for u, v in upgrade:
                if uf.is_connected(u, v): continue
                if not r: return False
                uf.union(u, v)
                r -= 1
            
            # Observation 3
            return all(uf.find(i) == uf.find(0) for i in range(n))

        left, right = -1, max(s for _, _, s, _ in edges) * 2
        while left < right:
            mid = left + (right - left + 1) // 2
            if check(mid):
                left = mid
            else:
                right = mid - 1
        return left

class UnionFind:
    def __init__(self, n: int) -> None:
        self.rank = [1] * n
        self.root = [i for i in range(n)]

    def find(self, x: int) -> int:
        if x == self.root[x]:
            return x
        self.root[x] = self.find(self.root[x])
        return self.root[x]

    def union(self, x: int, y: int) -> bool:
        root_x = self.find(x)
        root_y = self.find(y)
        if root_x == root_y:
            return False
        if self.rank[root_x] > self.rank[root_y]:
            self.root[root_y] = root_x
        elif self.rank[root_x] < self.rank[root_y]:
            self.root[root_x] = root_y
        else:
            self.root[root_x] = root_y
            self.rank[root_y] += 1
        return True

    def is_connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)

Observation 4: Our way of selecting edge to upgrade does not waste our upgrade chances.

You may notice that we select edges to upgrade this way.

You may be wondering why it works. i.e., why does this greedy approach not "waste" our number of upgrades?

Proof:

  1. We only connect nodes u and v if they belong to separate components.
if uf.is_connected(u, v): continue

  1. Because of point #1, the number of connected components is reduced by 1 every time when we connect the edge.

  2. There cannot be an edge, such that, when we connect u and v, we reduce the number of connected components by more than 1. i.e., a single edge cannot connect 3 components.

  3. This concludes that our edge connecting approach is optimal in terms of using our upgrades.

Intuition

Approach

  1. Sort Edges Intelligently

Sort edges in this order:

First by must[i] in descending order, so mandatory edges (must[i] = 1) come first (we must include these).
If must[i] values are equal, sort by weight in descending order.
Why? Because to maximize the maximum weight, we want larger weights considered earlier.

  1. Kruskal’s Algorithm (Reverse Style)

Use Disjoint Set Union (DSU) to build a reverse Kruskal-style MST:

Traverse edges from highest to lowest weight.
Keep adding edges as long as they connect different components.

  1. Track Non-Mandatory Edges

While building the MST:

If an edge has must[i] = 0 and is included in the MST, store its weight in a priority queue (min-heap).
These are the edges we might choose to double.

  1. Double k Lowest Non-Mandatory Weights

After building the MST:

We are allowed to double up to k weights of the non-mandatory edges.
So pick the k smallest weights from the min-heap and double them.
Now, among all the MST edges:
Keep track of the Minimum edge weight after doubling.

  1. Compare Mandatory vs Non-Mandatory Minimum Weights

Among MST edges:
Track the Minimum weight among the must[i] = 1 edges.
Track the Minimum among doubled must[i] = 0 edges.
The final answer is the minimum of these two Minimum if no of comp =1 otherwise -1.

Complexity

  • Time complexity:

elog(e)-> for sorting;
ack*N -> for dsu;

so over all complexity = ack*N + elog(e)(where ack is ackerman constant).

class Solution {
    public int maxStability(int n, int[][] edges, int k) {
        par = new int [n];
        rank = new int[n];
        for(int i = 0;i<n;i++){
            par[i] = i;
        }

        int comp = n;

        Arrays.sort(edges,(a,b)->(b[3]==a[3]?Integer.compare(b[2],a[2]):Integer.compare(b[3],a[3])));
        int minOne = (int)1e9;
        int minZero = (int)1e9;

        PriorityQueue<Integer> pq = new PriorityQueue<>();
        for(int [] e: edges){
            boolean union = union(e[0],e[1]);
            
            if(e[3]==1 && !union) return -1;

            if(union){
                comp--;
                
                if(e[3]==0){
                    pq.add(e[2]);
                }else{
                    minOne = Math.min(minOne,e[2]);
                }
            }
            
        }
        while(!pq.isEmpty()){
            if(k-->0){
                minZero = Math.min(minZero, pq.poll()*2);
            }else{
                minZero = Math.min(minZero,pq.poll());
            }
        }
        if(comp!=1) return -1;
        return Math.min(minOne, minZero);
    }

    int par[];
    int rank[];

    boolean union(int u, int v){
        int parU = get(u);
        int parV = get(v);
        if(parU==parV) return false;
        if(rank[parU]>=rank[parV]){
            par[parV] = parU;
            if(rank[parU]==rank[parV]) rank[parU]++;
        }else{
            par[parU] = parV;
        }
        return true;
    }


    int get(int u){
        if(par[u]==u) return u;

        return par[u] = get(par[par[u]]);
    }
}
