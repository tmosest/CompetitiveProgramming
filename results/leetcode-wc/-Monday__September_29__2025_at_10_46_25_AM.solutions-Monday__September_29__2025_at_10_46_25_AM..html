Intuition

Each word can be represented as a bitmask (an integer where each of the 26 bits corresponds to a letter of the alphabet: 1 if the letter is present, 0 if not).
Example:

  • "a" ? 000...001
  • "b" ? 000...010
  • "ab" ? 000...011

With this representation, the operations become very simple:

  • Add a letter ? turn on one bit.
  • Remove a letter ? turn off one bit.
  • Replace a letter ? turn off one bit and turn on another.

Thus, instead of working with strings, we work with integers and bit operations, turning the problem into finding connected components in a graph where nodes are masks and edges are one-bit transformations.

Approach

  1. Convert every word into a 26-bit mask.
  2. Store frequencies of masks in a map (so duplicates are merged into one node).
  3. Traverse the graph using DFS:
    • From a mask, generate neighbors by:
      • Removing one letter ? mask ^ (1 << i)
      • Adding one letter ? mask | (1 << i)
      • Replacing one letter ? (mask ^ (1 << i)) | (1 << j)
    • Only continue traversal if the neighbor mask exists in the map and has not been visited.
  4. For each connected component, compute its total size by summing counts of its masks.
  5. The number of groups = number of connected components.
  6. The size of the largest group = maximum size among components.

Complexity

  • Time complexity:
    • Building masks: O(náL), where L²26.
    • DFS traversal: for each mask we may try up to 262 neighbors, but only existing ones matter.
    • Overall: O(ná262) in the worst case, but very fast in practice due to constant-time bit operations.
  • Space complexity:
    • Storing masks, counts, and visited set: O(n).

function groupStrings(words: string[]): number[] {
    const toMask = (word: string): number => {
        let mask = 0;
        for (const ch of word) {
            mask |= 1 << (ch.charCodeAt(0) - 97);
        }
        return mask;
    };

    const masks = words.map(toMask);
    const maskCount = new Map<number, number>();

    for (const m of masks) {
        maskCount.set(m, (maskCount.get(m) || 0) + 1);
    }

    const visited = new Set<number>();

    const dfs = (cur: number): number => {
        const stack = [cur];
        let size = 0;

        while (stack.length) {
            const node = stack.pop()!;
            if (visited.has(node)) continue;
            visited.add(node);

            size += maskCount.get(node)!;

            for (let i = 0; i < 26; i++) {
                if (node & (1 << i)) {
                    const neighbor = node ^ (1 << i);
                    if (maskCount.has(neighbor) && !visited.has(neighbor)) {
                        stack.push(neighbor);
                    }
                }
            }

            for (let i = 0; i < 26; i++) {
                if (!(node & (1 << i))) {
                    const neighbor = node | (1 << i);
                    if (maskCount.has(neighbor) && !visited.has(neighbor)) {
                        stack.push(neighbor);
                    }
                }
            }

            for (let i = 0; i < 26; i++) {
                if (node & (1 << i)) {
                    for (let j = 0; j < 26; j++) {
                        if (!(node & (1 << j))) {
                            const neighbor = (node ^ (1 << i)) | (1 << j);
                            if (maskCount.has(neighbor) && !visited.has(neighbor)) {
                                stack.push(neighbor);
                            }
                        }
                    }
                }
            }
        }

        return size;
    };

    let groups = 0;
    let maxGroupSize = 0;

    for (const m of maskCount.keys()) {
        if (!visited.has(m)) {
            groups++;
            maxGroupSize = Math.max(maxGroupSize, dfs(m));
        }
    }

    return [groups, maxGroupSize];
}
