? Intuition

Whenever we find an element nums[j] == key, every index i that lies within distance k (i.e., in the range [j-k, j+k]) could be affected and hence qualifies as a k-distant index.

So, the idea is:

  • Find every index j where nums[j] == key.
  • From each such j, mark or collect all indices from max(0, j-k) to min(n-1, j+k).

We need to ensure:

  • No duplicate indices.
  • Indices are sorted in the result.

? Approach 1: Brute Force (Enumerate All Pairs)

Steps:

  1. Loop through every index i.
  2. For each i, loop through every index j.
  3. Check if nums[j] == key and |i - j| <= k.
  4. If found, add i to the result list and break inner loop.

Pros: Easy to understand.
Cons: Inefficient for large arrays.

? Time Complexity: O(n^2)

  • You check every possible (i, j) pair.

? Space Complexity: O(1)

  • Output array is excluded.

? Approach 2: Optimized One-Pass with Marking

Key Idea:

  • For each index j where nums[j] == key, add all indices i in [j-k, j+k] to the result.
  • Use a pointer r to avoid duplicate additions by skipping already added indices.

Steps:

  1. Initialize res = [] and a pointer r = 0.

  2. Traverse the array.

  3. When you find nums[j] == key:

    • Compute the interval [max(j-k, r), min(j+k, n-1)].
    • Add all indices in this interval to res.
    • Update r = min(j+k+1, n) to avoid re-adding same indices.

  4. Return res.

? Example Walkthrough

Input: nums = [3,4,9,1,3,9,5], key = 9, k = 1
Steps:

  • nums[2] == 9: Add indices [1,2,3]
  • nums[5] == 9: Add indices [4,5,6]
  • Combined: [1,2,3,4,5,6]

class Solution {

    public List<Integer> findKDistantIndices(int[] nums, int key, int k) {
        List<Integer> res = new ArrayList<>();
        int r = 0; // unjudged minimum index
        int n = nums.length;
        for (int j = 0; j < n; ++j) {
            if (nums[j] == key) {
                int l = Math.max(r, j - k);
                r = Math.min(n - 1, j + k) + 1;
                for (int i = l; i < r; ++i) {
                    res.add(i);
                }
            }
        }
        return res;
    }
}
