Intuition & Approach

  • Clearly its a DP problem, as we need to select any possible set of sub array and current selection of subarry is dependent on the next subarray to select

  • In DP there are multiple template we have to solve it or approach it. Here we will talk about -> 1. identify states 2. evaluate state transitions 3. base conditions/termination contions

    1. Identify statesThree state to track :

    • i -> iterator track the current item under consideration

    • k -> no of subarray yet to pick

    • status -> if we are continue picking items( value 1) or we have broken last subarray and new subarray need to start ( value 0)

    1. Evaluate state transitions:
    • When we have status == 1 :
      • we can continue picking current item as the last subarry part
      • start a new subarry
      • break current sub array by not picking the current item and setting the status to 0
    • When we have status == 0 :
      • We can start a new sub array
      • We can skip the current item as well
    1. Base conditions:
    • When we reach end and we already found k sub arrays ( i.e. k == 0 -> no subarray to selection remaining). => in this case we consider this as valid case and return 0
    • When we reach the end but the k is not equal to zero that means its a invalid end. so reject this flow by returning very small number so that it will be overriden by valid solution with larger valure.
    • When we have k less than 0 => we have selected more sub array then the required number hence this is also invalid flow and return very small number as mention above.

Complexity

  • Time complexity: O(N.K.2)
  • Space complexity: O(N.K.2)

int[][][] dp;

int solve(int[] nums, int m, int k, int i, int status){ 
    if(i >= nums.length && k == 0) return 0;          // when reach end with k == 0 means we found all blocks and return 0 as valid sub array sets
    if(i >= nums.length || k < 0) return -20000000;   // we reach end with out k == 0 or we got k less than 0 which is invalid selection, so return a smallest value so that this flow is considered as invalid and don't consider as the answer.
    if(dp[i][k][status] != -1) return dp[i][k][status];
    int res = -20000000;
    if(status == 1 ) res = Math.max(res, nums[i] + solve(nums, m, k, i+1, 1));  // continue taking sum of current item 

    if(i+m <= nums.length){         // start a new sub array -> so take sum of m items and cont recursion
        int sum = 0;
        for(int t = i; t < i+m; ++t) sum += nums[t];
        res = Math.max(res, sum + solve(nums, m, k-1, i+m, 1));
    }
    return dp[i][k][status] = Math.max(res, solve(nums, m, k, i+1, 0));  // skip the current item and set status to zero as we are breaking the last sub array.
}

public int maxSum(int[] nums, int k, int m) {
    dp = new int[2001][k+1][2];
    Arrays.stream(dp).forEach(grid -> Arrays.stream(grid).forEach(row -> Arrays.fill(row, -1)));
    return solve(nums, m, k, 0, 0);
}

Approach

1. Define the DP function:

dp[i][j] : The maximum sum that can be obtained by selecting j subarrays from the first i elements of the array

2. Prefix sum array:

Compute the pre array, where pre[i] is the sum of nums[0...i-1] This allows calculating the sum of any subarray in O(1) time

3. Transition formula:

dp[i][j] = max(dp[i-1][j], pre[i] + max(dp[x][j-1] - pre[x])),
where:

  • x belongs to [0, i-m]
  • dp[i-1][j] : Case where no subarray is selected ending at i-1
  • pre[i] + max(dp[x][j-1] - pre[x]) : Case where a subarray is selected ending at i-1, with a length of at least m
    We need to find x such that dp[x][j-1] - pre[x] is maximized

4. Initialization:

dp[i][0] = 0 for all i (selecting 0 subarrays has a sum of 0)

class Solution:
    def maxSum(self, nums: List[int], k: int, m: int) -> int:
        n = len(nums)
        
        pre = [0] * (n + 1)
        for i in range(n):
            pre[i + 1] = pre[i] + nums[i]
            
        dp = [[float(-inf)] * (k + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = 0
        
        for j in range(1, k + 1):
            max_prev = float(-inf)
            for i in range(1, n + 1):
                if i >= m:
                    max_prev = max(max_prev, dp[i - m][j - 1] - pre[i - m])
                    dp[i][j] = max(dp[i - 1][j], pre[i] + max_prev)
                else:
                    dp[i][j] = dp[i - 1][j]
                    
        return dp[n][k]
