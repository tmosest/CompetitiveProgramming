Intuition

Approach

It is given in the question that we have an undirected tree from which we want to deleted edges such that the components created after deletion have the same sum.

Now, the property of undirected tree is such that there is only 1 unique path to reach each node from our chosen root since each node has only 1 parent except our
root node(No Parent).

So, when we delete an edge from the undirected tree, it is deleting an edge between a parent and it's child. This result's in 2 components:- The original Tree that the parent was part of, and the newly created Subtree with the child as root.

So, whenever we delete an edge 1 new component is created apart from the already present original tree.

The question asks us to find the maximum number of edges that can be deleted which is basically the maximum number of components that can be created having same sum.

So, how do we find the maximum number of components?

Well, we know that each component has the same sum. So, we can derive :-

(Total Sum of Tree) / (Number of Components) = Sum of each Component

We also know that the Sum of Each component must be an integer as well and Total Sum of Tree should be divisible by by the Number of Components that is :-

(Total Sum Of Tree) % (Number Of Components) == 0

So, all the possible (Number Of Components) are nothing but all the factors of (Total Sum Of Tree)

To Find the (Total Sum Of Tree), we sum up all the values in nums array that is given as input.

We then create an array of factors that contains all the factors of the (Total Sum Of Tree).

We iterate this array of factors and try each factor as possible (Number Of Components) . We know the sum of each component from the first formula.

Now, we will perform dfs and each node will return the sum of itself and all the nodes reachable from it (dfs returns sum of subtree with the node as root). If the sum returned from node is equal to the component sum expected, we will increase the count of components created and the parent of that node will not add the child sum to it's sum, else it will add.

If the count of connected components is equal to the factor we are trying for, it is a possible ans and we will store the max of all such possible answers and return it.

Complexity

  • Time complexity:
To Find Factors it takes root O(ÃN), to Do DFS i takes O(N),

So when we iterate for all possible factors of total sum, the max sum possible is (50) * (2 * 10^4) which is 10^6. the find factors for 10^6 it taks Ã(10^6), which is 10^3.

So we try 10^3 factors and for each try we perform dfs (worst case 2 * 10^4).

So the time complexity is (10^ 3) * (2 * 10^4) = 2 * 10^7, this is acceptable solution.

  • Space complexity:
O(N),

Since we create adjacency list.

class Solution {

    public void get_factors(ArrayList<Integer> factors, int sum) {

        for (int i = 1; i * i <= sum; ++i) {

            if (sum % i == 0) {

                factors.add(i);
                factors.add(sum / i);
            }
        }
    }

    public int dfs(ArrayList<ArrayList<Integer>> adj, int[] nums, int csum, int[] count, int i, int parent) {

        int sum = nums[i];

        for (int j : adj.get(i)) {

            if (j != parent) {

                int x = dfs(adj, nums, csum, count, j, i);

                if (x == csum) 
                    count[0]++;
                else
                    sum += x;
            }
        }

        return sum;
    }

    public int componentValue(int[] nums, int[][] edges) {
        
        int sum = 0;
        int ans = 0;
        ArrayList<ArrayList<Integer>> adj = new ArrayList<>();
        ArrayList<Integer> factors = new ArrayList<>();

        for (int i : nums) {

            sum += i;
            adj.add(new ArrayList<>());
        }
        
        for (int[] i : edges) {

            adj.get(i[0]).add(i[1]);
            adj.get(i[1]).add(i[0]);
        }
        
        get_factors(factors, sum);

        for (int i : factors) {

            int[] count = new int[1];

            if (dfs(adj, nums, sum / i, count, 0, -1) == (sum / i))
                count[0]++;
            
            if (count[0] == i)
                ans = Math.max(i - 1, ans);
        }
       
        return ans;
    }
}
