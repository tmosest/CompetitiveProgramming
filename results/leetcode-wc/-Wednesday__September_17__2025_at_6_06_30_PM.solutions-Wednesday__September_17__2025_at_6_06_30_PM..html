We can check every 1/4 of the rectangle recursively, eleminating every rectangle that doesn't have any ships. Base case if when both points are the same - in this case return 1.

O(n) - we can check every cell. Space is O(lgn) - memory required for the call stack.

    public int countShips(Sea sea, int[] topRight, int[] bottomLeft) {
        int res = 0;
        //only continue with rectangles that are valid and have ships
        if (topRight[0] >= bottomLeft[0]
                && topRight[1] >= bottomLeft[1]
                && sea.hasShips(topRight, bottomLeft)) {

            //this is rect of 1 point only - return 1
            if (topRight[0] == bottomLeft[0]
                    && topRight[1] == bottomLeft[1])
                return 1;
            //center point
            int newX = (bottomLeft[0] + topRight[0])/2;
            int newY = (bottomLeft[1] + topRight[1])/2;

            //split into 4 squares
            //up-right
            res+= countShips(sea, topRight, new int[] {newX + 1, newY + 1});
            //up-left
            res+= countShips(sea,
                    new int[] {newX, topRight[1]},
                    new int[] {bottomLeft[0], newY + 1});

            //bottom-left
            res+= countShips(sea, new int[] {newX, newY}, bottomLeft);
            //bottom-right
            res+= countShips(sea,
                    new int[] {topRight[0], newY},
                    new int[] {newX + 1, bottomLeft[1]});
        }
        return res;
    }

Idea:

  • Divide the initial grid into quadrants and recursively search in them. This is Divide & Conquer approach
  • If the rectangle doesn't contain any ship, then exit from the call
  • Else if the 2 corners coincide then there is a ship, count it in and exit
  • Else recurse into the quadrants as shown in the figure and add up the ships

T/S: O(s (lg max(m, n) - lg s))/O(lg max(m, n)), where m x n are dimensions of the initial rectangle, s = number of ships

public int countShips(Sea sea, int[] topRight, int[] bottomLeft) {
	if (!sea.hasShips(topRight, bottomLeft))
		return 0;

	var x1 = topRight[0];
	var y1 = topRight[1];
	var x2 = bottomLeft[0];
	var y2 = bottomLeft[1];

	if (x1 == x2 && y1 == y2)
		return 1;

	var midX = (x1 + x2) / 2;
	var midY = (y1 + y2) / 2;

	return countShips(sea, point(midX, y1), point(x2, midY + 1)) + // Q1: top-left quadrant
		   countShips(sea, topRight, point(midX + 1, midY + 1)) +  // Q2: top-right quadrant
		   countShips(sea, point(x1, midY), point(midX + 1, y2)) + // Q3: bottom-right quadrant
		   countShips(sea, point(midX, midY), bottomLeft);         // Q4: bottom-left quadrant
}

private int[] point(int x, int y) {
	return new int[]{x, y};
}

Intuition and Approach

I initially got confused by the restriction that "topRight!=bottomLeft" and thought I could not pass equal topRight and bottomLeft to sea.hasShips(). Actually we can. By doing so, we can tell if a point has a ship (1 for true, and 0 for fault).

Brute forcely, we can interate from bottomLeft x,y to topRight x,y and for every point call sea.hasShips(). This will not pass because sea.hasShips() has a built-in time complexity. We will get an error message that hasShips() is called too many times.

class Solution {
    public int countShips(Sea sea, int[] topRight, int[] bottomLeft) {

        int count = 0;
        
        for(int i = bottomLeft[0]; i <= topRight[0]; i++) {
            for(int j = bottomLeft[1]; j <= topRight[1]; j++) {
                if(sea.hasShips(new int[]{i,j}, new int[]{i,j})) count++;
            }
        }

        return count;
    }
}

Divide conquer gives a better way to divide the problem to subproblems. For subproblems, we can use sea.hasShips() to see if there is any ship. If false, we can just return that subproblem to 0 without wasting time diving deep into the subproblems.

A trick here is not to divide like this. This will leave many ships to be counted repeatedly.

Instead to divide like this to avoid repeating counting.

Complexity

  • Time complexity:
    Worst case, ships are at every point. O(mn).

class Solution {
    public int countShips(Sea sea, int[] topRight, int[] bottomLeft) {

        int x1 = bottomLeft[0], y1 = bottomLeft[1], x2 = topRight[0], y2 = topRight[1];

        if(!sea.hasShips(topRight, bottomLeft)) return 0;

        if(x1 == x2 && y1 == y2) return 1;

        int midX = (x1 + x2) / 2;
        int midY = (y1 + y2) / 2;

        return countShips(sea, new int[]{midX, midY}, bottomLeft) + 
            countShips(sea, topRight, new int[]{midX+1, midY+1}) +
            countShips(sea, new int[]{midX, y2}, new int[]{x1,midY+1}) +
            countShips(sea, new int[]{x2, midY}, new int[]{midX+1, y1});
    }
}

This approach presents a solution which divides a rectangle into 2 halves. You can also divide it into 4 halves as other solutions propose but I feel dividing into 2 is more natural in a real interview.

    private class Rectangle {
        // bottom-left coordinates
        int x1, y1;
        // top-right coordinates
        int x2, y2;

        Rectangle(int x1, int y1, int x2, int y2) {
            this.x1 = x1;
            this.y1 = y1;
            this.x2 = x2;
            this.y2 = y2;
        }

        public Rectangle[] half() {
            Rectangle h1, h2;
            // x-coordinate is same
            if (x1 == x2) {
                int x = x1;
                int my = y1 + (y2 - y1) / 2;
                h1 = new Rectangle(x, y1, x, my);
                h2 = new Rectangle(x, my+1, x, y2);
            } else if (y1 == y2) {
                // y-coordinate is same
                int y = y1;
                int mx = x1 + (x2 - x1) / 2;
                h1 = new Rectangle(x1, y, mx, y);
                h2 = new Rectangle(mx+1, y, x2, y);
            } else {
                // we can half using either x or y coordinate
                // using x-coordinate half here
                int mx = x1 + (x2 - x1) / 2;
                h1 = new Rectangle(x1, y1, mx, y2);
                h2 = new Rectangle(mx+1, y1, x2, y2);
            }
            return new Rectangle[]{h1, h2};
        }

        public int[] tr() { return new int[]{x2, y2}; }

        public int[] bl() { return new int[]{x1, y1}; }

        public boolean canHalf() { return !(x1 == x2 && y1 == y2); }

        public String toString() { return Arrays.asList(x1, y1, x2, y2).toString(); }
    }

    // Keep dividing the rectangle until it is reduced to a single point
    // Only proceed with dividing if the rectangle has ships
    private int countShips(Sea sea, Rectangle r) {
        if (!r.canHalf())
            return sea.hasShips(r.tr(), r.bl()) ? 1 : 0;
        int ships = 0;
        for (Rectangle half: r.half()) {
            if (sea.hasShips(half.tr(), half.bl()))
                ships += countShips(sea, half);
        }
        return ships;
    }

    public int countShips(Sea sea, int[] tr, int[] bl) {
        return countShips(sea, new Rectangle(bl[0], bl[1], tr[0], tr[1]));
    }

Intuition

This problem reminds me blocked-ijk matrix multiplication, only matrices are not square and blocking is recursive.

Important points:

  • Intersection = point in the matrix
  • Matrix is not square
  • There is no need to search every ship, only to count them

Approach

In my approach, I utilize classic Breadth-First-Search algorithm based on a queue.

There are two types of counter

  • cellCount - numer of ships found when we narrowed to coordinates
  • lastFound - number of blocks containing ships at latest bfs level

I divide the original "sea" matrix in blocks, put it in the queue and then process them in the following way:

  • Block does not have any ships - drop it
  • Block does have ships - we .partition() it in blocks again
  • Block does have ships and is 1x1 size .isCell() - we found ship in cell

We stop when there are 10 ships in "cells"(we narrow)

Complexity

  • Time complexity:

Average: O(logn)
Best: O(10)(when 10 ships are evenly distributed)

  • Space complexity:

Average: O(sqrt(n))
Best: O(10)(when all ships are next to each other)

Code

/**
 * // This is Sea's API interface.
 * // You should not implement it, or speculate about its implementation
 * class Sea {
 *     public boolean hasShips(int[] topRight, int[] bottomLeft);
 * }
 */

class Solution {
    public int countShips(Sea sea, int[] topRight, int[] bottomLeft) {
        //0 - x
        //1 - y

        // Early finish trick
        int cellCount = 0;
        int lastFound = 0;

        Queue<SeaBlock> bfsQeue = new LinkedList<>();
        bfsQeue.addAll(new SeaBlock(sea, topRight[0], topRight[1], bottomLeft[0], bottomLeft[1]).partition());
        while (bfsQeue.size() != 0 && (cellCount + lastFound) < 10 ) { // 10 ships is the top we can have
            lastFound = 0;
            SeaBlock block = bfsQeue.poll();
            if (block.isCell()) {
                System.out.println(block.toString() + " cell");
                cellCount++; // There i a ship in this cell
                continue;
            } else {
                for (SeaBlock subBlock: block.partition()) {
                    if (subBlock.hasShips()) { // Only if there is a ship in this block
                        lastFound++;
                        System.out.println(subBlock.toString() + " more");
                        bfsQeue.add(subBlock); // Add block to deeper search
                    }
                }
            }
        }
        return cellCount + lastFound;
        return cellCount + lastFound;
    }

    private static class SeaBlock {
        private final Sea sea;
        private final int topRightX;
        private final int topRightY;
        private final int bottomLeftX;
        private final int bottomLeftY;

        SeaBlock(final Sea sea,
                final int topRightX,
                final int topRightY,
                final int bottomLeftX,
                final int bottomLeftY) {
                    this.sea = sea;
                    this.topRightX = topRightX;
                    this.topRightY = topRightY;
                    this.bottomLeftX = bottomLeftX;
                    this.bottomLeftY = bottomLeftY;
        }

        boolean isCell() {
            return (topRightX == bottomLeftX && topRightY == bottomLeftY);
        }

        boolean hasShips() {
            return sea.hasShips(new int[]{topRightX, topRightY}, new int[]{bottomLeftX, bottomLeftY}); 
        }

        List<SeaBlock> partition() { // Assume square~ish, partition by 2x2
            List<SeaBlock> partitions = new LinkedList<>();
            // Preferred step
            int blockYSize = (topRightY - bottomLeftY)/2;
            int blockXSize = (topRightX - bottomLeftX)/2;

            int blockTopRightY = topRightY;
            while (blockTopRightY >= bottomLeftY) {
                int blockYActualStep = Math.min(blockYSize, blockTopRightY - bottomLeftY);
                int blockBottomLeftY = (blockTopRightY - blockYActualStep); // end of block Y

                int blockTopRightX = topRightX;
                while(blockTopRightX >= bottomLeftX) {
                    int blockXActualStep = Math.min(blockXSize, blockTopRightX - bottomLeftX); 
                    int blockBottomLeftX = blockTopRightX - blockXActualStep; // end of block X

                    partitions.add(new SeaBlock(sea, 
                                                blockTopRightX,
                                                blockTopRightY,
                                                blockBottomLeftX,
                                                blockBottomLeftY
                                                )
                                  );
                    blockTopRightX = blockBottomLeftX - 1; // -1 is the beginning of new block 
                }
                blockTopRightY = blockBottomLeftY - 1;
            }
            System.out.println(this.toString() + " : " + partitions.size());
            return partitions;
        }

        @Override
        public String toString() {
            return "(" + topRightX +
                    "," + topRightY +
                  ", (" + bottomLeftX +
                   ", " + bottomLeftY + ")";
        }
    }
}

        if(topRight == bottomLeft) {
            ans += sea.hasShips(topRight, bottomLeft);
            return;
        }
        if(ans >= 10) return;

        vector<int> mid(2), l(2), r(2);
        mid[0] = (topRight[0]+bottomLeft[0])/2;
        mid[1] = (topRight[1]+bottomLeft[1])/2;
        if(checkAndQuery(sea, mid, bottomLeft))
            count(sea, mid, bottomLeft, ans);

        if(ans >= 10) return;
        l[0] = bottomLeft[0];
        l[1] = mid[1]+1;
        r[0] = mid[0];
        r[1] = topRight[1];
        if(checkAndQuery(sea, r, l))
            count(sea, r, l, ans);
