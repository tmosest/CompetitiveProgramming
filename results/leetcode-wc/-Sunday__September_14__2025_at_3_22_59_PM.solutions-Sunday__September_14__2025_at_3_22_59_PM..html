Intuition

For the first number, it could be any number from 1 to k.
So my intuition is to check the first occurrence of all number from 1 to k.

Explanation

We check the first occurrences of all number from A[0].
Assume A[i] is the rightmost one among them,
which is the first occurrence of a number in [1,k].

That means from A[0] to A[i],
we have seen all numbers at least once.
In other words, A[0] to A[i] forms our first complete set including all numbers.

This complete set can satisfy any number from 1 to k,
as the first number in the sequence.

Then we continue this process, to find out the next complete set.
We continue doing this, and assume we can find x complete sets in total.
There may ramian some elements, but the rest can not form one more set of all numebr.

Then we can take any sequence of length x,
x + 1 is the length of the shortest sequence of rolls,
that cannot be taken from rolls.

We simply returns x + 1.

Prove

Assume there are x complete sets in the rolls.

  1. We can take any sequence of length x
    we can take any number from a complete set

  2. We can't take all sequence of length x + 1
    We can contruct one sequence S that we can't take.

S[0] is the last element in the first complet set
S[1] is the last element in the second complet set
...

S[x] is one element which is not in the incomplete set after x complete set

With 1) and 2),
we prove that x + 1 is the length of the shortest sequence of rolls
that cannot be taken from rolls.

Complexity

Time O(n)
Space O(k)

    public int shortestSequence(int[] A, int k) {
        int res = 1;
        Set<Integer> s = new HashSet<>();
        for (int a : A) {
            s.add(a);
            if (s.size() == k) {
                res++;
                s.clear();
            }
        }
        return res;
    }

For a sequence of size 1, all k dice must appear in rolls.
For a sequence of size 2, all k dice must appear after all k dice appear in rolls.
... and so on.

So, we go through rolls and count unique dice.

When we have all k dice, we increase the number of sequences seq and reset the counter.

Implementation note: instead of resetting the counter, we use the sequence number to check if a dice has appeared for the current sequence.
When we have all dice, we increase seq, so all dice must appear again.

Java

public int shortestSequence(int[] rolls, int k) {
   int seq = 0, cnt = 0, dice[] = new int[k + 1];
   for (var r : rolls)
       if (dice[r] == seq) {
           dice[r] = seq + 1;
           if (++cnt % k == 0)
               ++seq;
       }
   return seq + 1;
}

C++

    int seq = 0, cnt = 0, dice[100001] = {};

Since i found it difficult to understand the question in the first go, so we will begin from understanding the question.

Understanding the question:

In our question we are given an integer array rolls where rolls[i] is the result of i'th roll. We have a dice which has k sides number from 1 to k(inclusive).

Basically we need to find the length of shortest sequence that cannot be created using our rolls array.
Eg:

Input: rolls = [4,2,1,2,3,3,2,4,1], k = 4
Output: 3

All sequence of length 1 : [1], [2] , [3] , [4] can be formed since all these are present in our rolls array
All sequence of length 2 :
[1,1] : (Pos 3, Pos 9)
[1,2] : (Pos 3, Pos 7)
[1,3] : (Pos 3, Pos 6)
[1,4] : (Pos 3, Pos 8)
[2,1] : (Pos 2, Pos 9)
[2,2] : (Pos 2, Pos 7)
[2,3] : (Pos 2, Pos 6)
[2,4] : (Pos 2, Pos 8)
.
.
.
All sequence of length 3:
[1,1,1] : (Pos 3, Pos 9, Not Found ) : This results in an impossible sequence .
[2,2,2] : (Pos 2, Pos 7, Not Found ) : This results in an impossible sequence.
[1,4,2] : (Pos 3, Pos 8, Not found) : This results in an impossible sequence.

Therefore the shortest length of imossible sequence is 3.

Deriving intution for the solution :

If any of the element in the range [1,k] is not present in our rolls array then the length of shortest impossible sequence will be 1.

Eg:

Input: rolls = [1,1,3,2,2,2,3,3], k = 4
Output: 1

Since for this it would be impossible to find a sequence [4] therefore the answer is 1 .

Thus we can say that if suppose we get an index i upto which we have find all our elements from [1,k] i.e (rolls[0]....rolls[i] contains all the elements from [1,k]) then we can ensure that all the sequences of length 1 are possible, lets mark this index as idx1.

Now let us suppose we get an index i (i>idx1) upto which we have find all our elemnts from [1,k] i.e (rolls[idx1+1]..........rolls[i] contains all the elements from [1,k]) then we can ensure that all the sequences of length 2 are possible.

Here we can surely say that all our sequence of length 2 will be possible because we can surely say that all the integers in the range[0,idx1] contains all our integers from range[1,k] (This subarray will contribute for the first element of our sequence) and all the integers in the range[idx1+1,idx2] again contains all the integers (This subarray will contribute for the second element of our sequence).

Let us consider an example :

Input: rolls = [4,2,1,2,3,3,2,4,1], k = 4
Output: 3

(Digit 1) (Digit 2)
|--------| |------|
4 2 1 2 3 3 2 4 1

Here our subarray (Digit1) can make all the sequences of length 1.

If we consider taking first digit from digit1 and second digit from digit2 then all the combinations of length 2 can be created. Thus all the sequences of length 2 are also be created and thus possible.

Since we are unable to find third such subarray which contains all the elements. Therefore it would be impossible to create all the sequences of length 3.

Thus our answer is 3.

Final Solution

By doing this we can calculate the maximum length upto which all our sequences will be valid and thus our answer will be maximum sequence length + 1;

class Solution {
    public int shortestSequence(int[] rolls, int k) {
        int len = 0;
        Set<Integer> set = new HashSet<>();
        for(int i:rolls)
        {
            set.add(i);
            if(set.size()==k)
            {
                set = new HashSet<>();
                len++;
            }
        }
        return len+1;
    }
}

Time Complexity : O(n)

Space Complexity : O(k)

class Solution {
