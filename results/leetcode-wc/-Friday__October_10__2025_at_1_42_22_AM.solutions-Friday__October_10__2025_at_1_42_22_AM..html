Approach

1.Initialize variables :
. maxEndingHere: Tracks the maximum subarray sum ending at the current index.
. minEndingHere: Tracks the minimum subarray sum ending at the current index.
. maxSoFar: Stores the overall maximum subarray sum found so far.
. minSoFar: Stores the overall minimum subarray sum found so far.

2.Iterate through the array :

. For each element, update maxEndingHere and minEndingHere:
.maxEndingHere = max(nums[i], maxEndingHere + nums[i])
. minEndingHere = min(nums[i], minEndingHere + nums[i])
. Update maxSoFar and minSoFar:
. maxSoFar = max(maxSoFar, maxEndingHere)
. minSoFar = min(minSoFar, minEndingHere)

3.Compute the result:
The maximum absolute sum is max(abs(maxSoFar), abs(minSoFar)).

?Complexity Analysis

  • Time complexity:O(n)
  • Space complexity:O(1)

Example Walkthrough:


. maxSoFar = 5 (from subarray [2, 3]).
. minSoFar = -3 (from subarray [1, -3]).
. Maximum absolute sum = max(abs(5), abs(-3)) = 5.

class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int n = nums.length;
        int maxEndingHere = nums[0];
        int minEndingHere = nums[0];
        int maxSoFar = nums[0];
        int minSoFar = nums[0];
        
        // Kadane's algorithm to find max and min subarray sums
        for (int i = 1; i < n; i++) {
            maxEndingHere = Math.max(nums[i], maxEndingHere + nums[i]);
            minEndingHere = Math.min(nums[i], minEndingHere + nums[i]);
            maxSoFar = Math.max(maxSoFar, maxEndingHere);
            minSoFar = Math.min(minSoFar, minEndingHere);
        }
        
        // The maximum absolute sum is the maximum of the absolute values of maxSoFar and minSoFar
        return Math.max(Math.abs(maxSoFar), Math.abs(minSoFar));
    }
}

Approach 2:Prefix Sum Method

1.Initialization:
prefixSum: Tracks the running sum of the array.
minPrefixSum: Tracks the minimum prefix sum encountered so far.
maxPrefixSum: Tracks the maximum prefix sum encountered so far.
maxAbsSum: Stores the maximum absolute sum found so far.

2.Loop Through the Array:
. For each element:
.Update prefixSum by adding the current element.
. Update maxAbsSum as the maximum of:
The current maxAbsSum.
The absolute difference between prefixSum and minPrefixSum.
The absolute difference between prefixSum and maxPrefixSum.
Update minPrefixSum and maxPrefixSum with the current prefixSum.
3.Return the Result:

After the loop, maxAbsSum contains the maximum absolute sum of any subarray.

?Complexity Analysis

  • Time complexity:O(n)
  • Space complexity:O(1)

class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int prefixSum = 0;
        int minPrefixSum = 0;
        int maxPrefixSum = 0;
        int maxAbsoluteSum = 0;
        
        for (int i = 0; i < nums.length; i++) {
            prefixSum += nums[i]; // Update prefix sum
            // Update maxAbsoluteSum
            maxAbsoluteSum = Math.max(maxAbsoluteSum, Math.abs(prefixSum - minPrefixSum));
            maxAbsoluteSum = Math.max(maxAbsoluteSum, Math.abs(prefixSum - maxPrefixSum));
            // Update minPrefixSum and maxPrefixSum
            minPrefixSum = Math.min(minPrefixSum, prefixSum);
            maxPrefixSum = Math.max(maxPrefixSum, prefixSum);
        }
        
        return maxAbsoluteSum;
    
    }
}

SOLUTION - 1

Intuition ?

Imagine you’re on a roller coaster ?. Your emotions (sum of elements) can skyrocket ? (when you get a big positive subarray) or plummet ? (when you hit a deep negative subarray). The goal? Find the wildest ride—whether it’s the highest peak or the lowest drop—and take its absolute value!

So, we need to track:

  1. Max happiness (highest sum of any subarray) ?
  2. Max sadness (lowest sum of any subarray) ?

The answer is the absolute wildest experience!

Approach ?

We’ll use Kadane’s Algorithm—the legend of subarray sums! It works like this:

  1. Maintain two running sums:
    • max_ending_here ? ? Tracks the best positive sum.
    • min_ending_here ? ? Tracks the worst negative sum.
  2. Update max_sum whenever max_ending_here reaches a new high.
  3. Update min_sum whenever min_ending_here reaches a new low.
  4. Reset max_ending_here if it ever drops below 0 (because negatives won’t help us).
  5. Reset min_ending_here if it ever rises above 0 (because positives won’t help us).
  6. Return max(|max_sum|, |min_sum|) to find the craziest subarray ride! ?

Complexity Analysis ?

  • Time Complexity: ?? O(N) ? One-pass through the array!
  • Space Complexity: ? O(1) ? Just a few variables, no extra storage!

Code ??

class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int max_sum = 0, min_sum = 0, max_ending_here = 0, min_ending_here = 0;

        for (int num : nums) {
            max_ending_here += num;
            min_ending_here += num;

            max_sum = Math.max(max_sum, max_ending_here);
            min_sum = Math.min(min_sum, min_ending_here);

            if (max_ending_here < 0) max_ending_here = 0;
            if (min_ending_here > 0) min_ending_here = 0;
        }

        return Math.max(max_sum, Math.abs(min_sum));
    }
}

Instead of finding subarrays explicitly, we track cumulative balance changes (prefix sum) ? and find the biggest gap between our lowest and highest points. That difference gives us the maximum absolute sum of any subarray! ?

Approach ?

? We maintain three variables:

  1. prefixSum ? The running sum (your current balance).
  2. minPrefixSum ? The lowest balance ever recorded.
  3. maxPrefixSum ? The highest balance ever recorded.

? As we traverse the array:

  • Update prefixSum (our bank balance).
  • Keep track of minPrefixSum (poorest moment).
  • Keep track of maxPrefixSum (richest moment).

? The answer is simply: maxPrefixSum - minPrefixSum

This gives the biggest rise or drop in your journey! ??

Complexity Analysis ?

  • Time Complexity: ?? O(N) ? One pass through the array.
  • Space Complexity: ? O(1) ? No extra storage needed!

Code ??

class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int minPrefixSum = 0, maxPrefixSum = 0;
        int prefixSum = 0;

        for (int num : nums) {
            prefixSum += num;

            minPrefixSum = Math.min(minPrefixSum, prefixSum);
            maxPrefixSum = Math.max(maxPrefixSum, prefixSum);
        }

        return maxPrefixSum - minPrefixSum;
    }
}
