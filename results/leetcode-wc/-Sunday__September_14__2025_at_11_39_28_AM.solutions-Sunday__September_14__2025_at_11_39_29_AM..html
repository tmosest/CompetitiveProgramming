Preword

I noticed most solution will check from small to big,
which is also good.

Here I add another solution,
where we can check from big to small.

Intuition

If total sum < taregt, return -1.
If the some sum >= target,
we can always make up target.

Explanation

Check if sum >= taregt,
we can return -1 directly if not.

Then sort the A from small to big.
This step can use counting sort with O(n).

Then check the biggest element a:

If tot - a >= target,
we can skip a and make up target with smaller integers.
For example, A = [1,2,16] and taregt = 3, we don't need 16.

If a <= target,
we will pick a,
we update tot -= a and target -= a.

Otherwise,
we need a and a > target,
we need to split a into two a / 2.
the operation res++.

We keep doing the above checks,
until target = 0,
which means we find all integers we need,
finally we return res.

Complexity

Time O(sort), can improve to O(n + 30) by counting sort.
Space O(sort) extra space for quick sort.

Java

    public int minOperations(List<Integer> A, int target) {
        long tot = 0;
        for (int a : A) {
            tot += a;
        }
        if (tot < target) {
            return -1;
        }
        Collections.sort(A);
        int res = 0;
        while (target > 0) {
            int a = A.remove(A.size() - 1);
            if (tot - a >= target) {
                tot -= a;
            } else if (a <= target) {
                tot -= a;
                target -= a;
            } else {
                A.add(a / 2);
                A.add(a / 2);
                res++;
            }
        }
        return res;
    }

        if (tot < target)
            return -1;
        sort(A.begin(), A.end());
        while (target > 0) {
            int a = A.back();
            A.pop_back();

                target -= a;

Intuition

First thing first, the operation chain performed does not change the total sum of the input array. So if the target is more that total sum of array, return -1.
Also, if you perform maximum possilbe operations, then you will end up with 1 array of length sum of array, so if the target is less or equal to the sum of array, it is guranteed that there will be a solution.
eg: [4] => [2, 2] => [1, 1, 2] => [1, 1, 1, 1]

Approach

any number can be written into sum of unique powers of 2 and to have minimum operation we want to know if we can build each unique power of 2.
We will start with lowest power.
If it is present in the input array, remove it and move forward.
If it is not present in the input array, then find the next highest power of 2 and keep performing operation until we receive the number.

The tricky part here is that it is possible to get a higher power of 2 by adding the lower power.
eg: suppose in the input we have [8, 8, 1] and we want to target 17.
Now 17 = 16 + 1
We don't have 16 in the input but we have 2 8 which can give 16.

So after you have consumed the lower power of 2, group all the remainging values and roll up to the higher power.

class Solution {
    public int minOperations(List<Integer> nums, int target) {
        long sum = 0;
        int max = 0;
        for (int num : nums) {
            max = Math.max(max, num);
            sum += num;
        }
        
        if (sum < target) {
            return -1;
        } else if (sum == target) {
            return 0;
        }
        
        TreeMap<Integer, Integer> freqs = new TreeMap<>();
        for (int num : nums) {
            freqs.put(num, freqs.getOrDefault(num , 0) + 1);
        }
        
        int ops = 0;
        for (int i = 0, pow = 1; i < 32 && pow < max && target > 0; i++, pow *= 2) {
            boolean need = (((target >> i) & 1) == 1);
            
            if (need) {
                target -= pow;
                
                if (freqs.containsKey(pow)) {
                    int freq = freqs.remove(pow);
                    if (freq > 1) {
                        freqs.put(pow, freq - 1);
                    }
                } else {
                    int key = freqs.ceilingKey(pow);
                    int freq = freqs.remove(key);
                    if (freq > 1) {
                        freqs.put(key, freq - 1);
                    }
                    
                    while (key != pow) {
                        ops++;
                        key /= 2;
                        freqs.put(key, freqs.getOrDefault(key , 0) + 1);
                    }
                }
            }
            
            for (int x = 1; x <= pow; x *= 2) {
                if (freqs.getOrDefault(x, 0) > 1) {
                    int f = freqs.get(x);
                    freqs.put(x * 2, freqs.getOrDefault(x * 2, 0) + f / 2);
                    freqs.put(x, 1);
                }
            }
            
        }
        
        return ops;
    }
}
