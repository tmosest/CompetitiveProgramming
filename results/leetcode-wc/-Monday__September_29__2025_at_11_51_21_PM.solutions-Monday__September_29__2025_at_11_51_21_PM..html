Intuition

  • Every subarray’s “score” is its largest number minus its smallest number.
  • The single best score we can ever get is by using the array’s overall smallest and overall largest elements —no other subarray can beat that gap.
  • Because we are allowed to pick the same subarray again and again, we can just pick that max-minus-minslicektimes.
  • So the answer is: (globalmax-globalmin)*k.

Approach

  1. Scan the array once to find its minimum and its maximum.
  2. Compute their difference.
  3. Multiply that difference by k and return the result.

Complexity

  • Time complexity: O(n)
    where n is the length of nums (we do a single pass to find min and max).
  • Space complexity: O(1)

Approach

In the question we have to find total sum of difference of maximum and minimum values of any K subsets such that the total sum is maximum. So for maximum total sum we always want highest and lowest values of original array to be in our subset array. Since in the question it is mentioned that same subset array can be considered multiple number of times. So the optimal way will be to always consider the complete array as subset array as it will always have the highest and lowest values of the original array. This will make our total sum maximum.
So when we consider complete array as subset K times, our result will be K times difference of highest and lowest values of the original array and this will be the optimal answer.

Complexity

  • Time complexity: O(n)
  • Space complexity: O(1)

class Solution {
    public long maxTotalValue(int[] nums, int k) {
        int max = 0 ;
        int min = Integer.MAX_VALUE ;
        for(int n : nums ){
            max = Math.max(max , n);
            min = Math.min(min , n );
            
        }
        return (long) k*(max - min);
        
    }
}
