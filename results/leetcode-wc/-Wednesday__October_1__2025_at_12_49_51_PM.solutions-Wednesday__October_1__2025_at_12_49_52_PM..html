For each lock, we store the time to break it with the first, second, and so on, swing in A.

Then, we run the Hungarian algorightm to assign locks to swings, minimizing the total number of seconds.

The code of the Hungarian algorithm was taken from the CP-A web size "as is".

int A[81][81] = {};
int findMinimumTime(vector<int>& s) {
    for (int i = 0; i < s.size(); ++i)
        for (int j = 0; j < s.size(); ++j)
            A[i + 1][j + 1] = (s[i] + j) / (j + 1);
    return hungarian(s.size(), s.size());
}
int hungarian(int n, int m) {
    vector<int> u (n+1), v (m+1), p (m+1), way (m+1);
    for (int i=1; i<=n; ++i) {
        p[0] = i;
        int j0 = 0;
        vector<int> minv (m+1, INT_MAX);
        vector<bool> used (m+1, false);
        do {
            used[j0] = true;
            int i0 = p[j0],  delta = INT_MAX,  j1;
            for (int j=1; j<=m; ++j)
                if (!used[j]) {
                    int cur = A[i0][j]-u[i0]-v[j];
                    if (cur < minv[j])
                        minv[j] = cur,  way[j] = j0;
                    if (minv[j] < delta)
                        delta = minv[j],  j1 = j;
                }
            for (int j=0; j<=m; ++j)
                if (used[j])
                    u[p[j]] += delta,  v[j] -= delta;
                else
                    minv[j] -= delta;
            j0 = j1;
        } while (p[j0] != 0);
        do {
            int j1 = way[j0];
            p[j0] = p[j1];
            j0 = j1;
        } while (j0);
    }
    return -v[0];    
}

It was clear that this was a matching/assignment/optimization problem. "Energy" starts at 1, and then from there we hack away at a lock, taking ceiling(energylock_strength?) time. Then energy increases by 1, and we attack another lock, and so on. I'll admit I tried some things with either sorting or heaps, and those linear-style approaches failed on some case here or there. The nearest problem (just what came to me) was a daily problem from a couple of months ago, 2463. Minimum Total Distance Traveled, which led me to the approach used here. The scipy package has plenty of useful functions, and the one we'll use here is linear_sum_assignment(). The function will optimize the assignment but we still need to properly construct the inputs and also properly utilize the outputs, so let's dive into that...

Approach

For starters, import optimize from scipy, and also import numpy. The linear cost optimization function comes from scipy, and the input to that is a numpy matrix as opposed to a standard python matrix (list of lists).

Next, we'll construct a cost matrix. Recall from the intro, energy starts at one, and then we attack a lock until that lock is broken, using some turns/time. Then energy increases by one, and we attack another lock, once again using turns/time determined by energy, and so on until all locks are broken. It should be clear that the order that the locks are attacked is what needs to be optimized (to minimize time). Here a double-loop process is used to construct the cost matrix, loop through turn_energy, which is the array from 1 through the number of locks (range(1, n + 1)). Then loop through each strength value (s), and the cost (time needed) to attack that lock on that turn is math.ceil(s/turn_energy). When both loops complete, the result will be an n x n matrix containing the cost to attack each lock on each turn.

With the cost matrix constructed as a standard python list of lists, convert it into a numpy array/matrix using numpy.array(costs). Now pass that into the linear sum optimization function, using optimize.linear_sum_assignment(costs). This will return row and column indices for the optimal assignment, so we need to pull those from the costs input to get the actual time values resulting from the optimal assignment. Sum those and that will be the minimum time to break the locks.

Code

from scipy import optimize
import numpy

class Solution:
    def findMinimumTime(self, strength: List[int]) -> int:
        n = len(strength)
        costs = []
        for turn_energy in range(1, n + 1):
            turn_cost = []
            for s in strength:
                turn_cost.append(math.ceil(s/turn_energy))
            costs.append(turn_cost)
        costs = numpy.array(costs)
        return int(sum(costs[optimize.linear_sum_assignment(costs)]))

Intuition

Inspired by @adamrbeier's Python method, we can create a separate Hungarian Algorithm solver to solve this problem.

Approach

Each row represents the "cost times" of strength at the corresponding updateX. We apply the Hungarian Algorithm solver to compute the minimum cost.

The Hungarian Algorithm solver reuses the implementation provided in the reference (make sure you read this reference which includes plenty of knowhow about Hungarian Algorithm). Its interface is designed based on the structure of Google OR-Tools.

Complexity

  • Time Complexity: O(n3)
  • Space Complexity: O(n2)

Code

C++
class HungarianAlgorithm {
private:
    vector<vector<int>> cost;
    vector<int> assignment;
    int optimalCost;

public:
    HungarianAlgorithm() {}

    int getRightMate(const int& row) { return assignment[row]; }

    int getAssignmentCost(const int& row) { return cost[row][assignment[row]]; }

    int getOptimalCost() { return optimalCost; }

    void addArcWithCost(const int& row, const int& col, const int& val) {
        if (row >= cost.size()) {
            cost.resize(row + 1,
                        vector<int>(cost.empty() ? 0 : cost[0].size(), 0));
        }
        if (col >= cost[0].size()) {
            for (auto& rowVec : cost) {
                rowVec.resize(col + 1, 0);
            }
        }
        cost[row][col] = val;
    }

    void solve() {
        int m = cost.size(), n = cost[0].size();
        vector<int> u(m + 1), v(n + 1), p(n + 1), way(n + 1);
        for (int i = 1; i <= m; ++i) {
            p[0] = i;
            int j0 = 0;
            vector<int> minv(n + 1, INT_MAX);
            vector<bool> used(n + 1, false);
            do {
                used[j0] = true;
                int i0 = p[j0], delta = INT_MAX, j1;
                for (int j = 1; j <= n; ++j)
                    if (!used[j]) {
                        int cur = cost[i0 - 1][j - 1] - u[i0] - v[j];
                        if (cur < minv[j]) minv[j] = cur, way[j] = j0;
                        if (minv[j] < delta) delta = minv[j], j1 = j;
                    }
                for (int j = 0; j <= n; ++j)
                    if (used[j])
                        u[p[j]] += delta, v[j] -= delta;
                    else
                        minv[j] -= delta;
                j0 = j1;
            } while (p[j0] != 0);
            do {
                int j1 = way[j0];
                p[j0] = p[j1];
                j0 = j1;
            } while (j0);
        }

        assignment.resize(n);
        for (int j = 1; j <= n; ++j) {
            assignment[p[j] - 1] = j - 1;
        }

        optimalCost = -v[0];
    }
};

class Solution {
private:
    HungarianAlgorithm* solver;

public:
    Solution() { solver = new HungarianAlgorithm(); }

    int findMinimumTime(vector<int>& strength) {
        for (int i = 0; i < strength.size(); ++i) {
            for (int j = 0; j < strength.size(); ++j) {
                int updateX = i + 1;
                solver->addArcWithCost(i, j, ceil(strength[j] * 1.0 / updateX));
            }
        }
        solver->solve();
        return solver->getOptimalCost();
    }
};

Intuition

Assign each worker to a task in a way that minimizes the total time. Since different tasks take different amounts of time for each worker, I need to find the best match between them to get the smallest sum of task times.

Approach

I use the Hungarian algorithm, which assigns workers to tasks optimally by maintaining potential values (arrays lx and ly), tracking matches (matchX and matchY), and adjusting costs using a BFS-based approach with a queue and slack array to efficiently find augmenting paths and improve the assignments in the big O notation mentioned below:

Complexity

  • Time complexity:
    O(n3)

  • Space complexity:
    O(n2)

Code

C
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>
#include <stdbool.h>
#include <string.h>

#define INF 1000000000

typedef struct {
    int n, *matchX, *matchY, *prev;
    bool *visX, *visY;
    int *lx, *ly, **g, *slack;
} Hungarian;

Hungarian* createHungarian(int _n, int _m) {
    int n = _n > _m ? _n : _m;
    Hungarian* h = (Hungarian*)malloc(sizeof(Hungarian));
    h->n = n;
    h->matchX = (int*)malloc(n * sizeof(int));
    h->matchY = (int*)malloc(n * sizeof(int));
    h->prev = (int*)malloc(n * sizeof(int));
    h->visX = (bool*)malloc(n * sizeof(bool));
    h->visY = (bool*)malloc(n * sizeof(bool));
    h->lx = (int*)malloc(n * sizeof(int));
    h->ly = (int*)malloc(n * sizeof(int));
    h->slack = (int*)malloc(n * sizeof(int));

    h->g = (int**)malloc(n * sizeof(int*));
    for (int i = 0; i < n; i++) {
        h->g[i] = (int*)malloc(n * sizeof(int));
        memset(h->g[i], 0, n * sizeof(int));
    }

    memset(h->matchX, -1, n * sizeof(int));
    memset(h->matchY, -1, n * sizeof(int));
    memset(h->lx, 0, n * sizeof(int));
    memset(h->ly, 0, n * sizeof(int));

    return h;
}

void addEdge(Hungarian* h, int u, int v, int w) {
    h->g[u][v] = w > 0 ? w : 0;
}

bool check(Hungarian* h, int v, int* q, int* front, int* rear) {
    h->visY[v] = true;
    if (h->matchY[v] != -1) {
        q[(*rear)++] = h->matchY[v];
        h->visX[h->matchY[v]] = true;
        return false;
    }
    while (v != -1) {
        h->matchY[v] = h->prev[v];
        int temp = v;
        v = h->matchX[h->prev[v]];
        h->matchX[h->prev[temp]] = temp;
    }
    return true;
}

void bfs(Hungarian* h, int i) {
    int q[h->n], front = 0, rear = 0;
    memset(h->visX, 0, h->n * sizeof(bool));
    memset(h->visY, 0, h->n * sizeof(bool));
    for (int j = 0; j < h->n; j++) h->slack[j] = INF;

    q[rear++] = i;
    h->visX[i] = true;

    while (1) {
        while (front < rear) {
            int u = q[front++];
            for (int v = 0; v < h->n; v++) {
                if (!h->visY[v]) {
                    int delta = h->lx[u] + h->ly[v] - h->g[u][v];
                    if (h->slack[v] >= delta) {
                        h->prev[v] = u;
                        if (delta) {
                            h->slack[v] = delta;
                        } else if (check(h, v, q, &front, &rear)) {
                            return;
                        }
                    }
                }
            }
        }

        int a = INF;
        for (int j = 0; j < h->n; j++)
            if (!h->visY[j] && h->slack[j] < a)
                a = h->slack[j];

        for (int j = 0; j < h->n; j++) {
            if (h->visX[j]) h->lx[j] -= a;
            if (h->visY[j]) h->ly[j] += a;
            else h->slack[j] -= a;
        }

        for (int j = 0; j < h->n; j++)
            if (!h->visY[j] && h->slack[j] == 0 && check(h, j, q, &front, &rear))
                return;
    }
}

int solve(Hungarian* h) {
    for (int i = 0; i < h->n; i++)
        for (int j = 0; j < h->n; j++)
            if (h->g[i][j] > h->lx[i])
                h->lx[i] = h->g[i][j];

    for (int i = 0; i < h->n; i++)
        bfs(h, i);

    int res = 0;
    for (int i = 0; i < h->n; i++)
        if (h->matchX[i] != -1)
            res += h->g[i][h->matchX[i]];
    return res;
}

int findMinimumTime(int* strength, int n) {
    Hungarian* h = createHungarian(n, n);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            addEdge(h, i, j, 1000000 - (strength[i] + j) / (j + 1));

    int result = n * 1000000LL - solve(h);

    // Free allocated memory
    free(h->matchX);
    free(h->matchY);
    free(h->prev);
    free(h->visX);
    free(h->visY);
    free(h->lx);
    free(h->ly);
    free(h->slack);
    for (int i = 0; i < h->n; i++) free(h->g[i]);
    free(h->g);
    free(h);

    return result;
}

Intuition

Solution Using the Hungarian Algorithm:
We can model this problem as a minimum-cost assignment problem where we are trying to optimally assign the factors X (starting from 1) to the locks.

Cost Matrix Construction:

We can create a matrix of size n x n where n is the number of locks.
The value in each cell cost[i][j] represents the time required to break lock i using the factor X = j + 1. This time is given by the formula ceil(strength[i] / (j + 1)), which is the minimum number of minutes required to accumulate enough energy to break the lock.

Hungarian Algorithm:

We need to find the optimal assignment of X values (from 1 to n) to the locks such that the total time is minimized. This is a classic problem that can be solved using the Hungarian algorithm, which efficiently finds the minimum-cost matching in a bipartite graph.

Assignment Problem:

The problem boils down to assigning each lock to an increasing factor X (starting from 1) in such a way that the total time is minimized. The Hungarian algorithm guarantees that we will find the optimal assignment that minimizes the total cost (total time).
Optimal Solution:

By applying the Hungarian algorithm to the cost matrix, we will get the optimal assignment that minimizes the total time required for Bob to break all the locks.

Approach

Hungarian Algorithm

template <typename T>
struct hungarian
{ // km
    int n;
    vector<int> matchx;
    vector<int> matchy;
    vector<int> pre;
    vector<bool> visx;
    vector<bool> visy;
    vector<T> lx;
    vector<T> ly;
    vector<vector<T>> g;
    vector<T> slack;
    T inf;
    T res;
    queue<int> q;
    int org_n;
    int org_m;

    hungarian(int _n, int _m)
    {
        org_n = _n;
        org_m = _m;
        n = max(_n, _m);
        inf = numeric_limits<T>::max();
        res = 0;
        g = vector<vector<T>>(n, vector<T>(n));
        matchx = vector<int>(n, -1);
        matchy = vector<int>(n, -1);
        pre = vector<int>(n);
        visx = vector<bool>(n);
        visy = vector<bool>(n);
        lx = vector<T>(n, -inf);
        ly = vector<T>(n);
        slack = vector<T>(n);
    }

    void addEdge(int u, int v, int w)
    {
        g[u][v] = max(w, 0); 
    }

    bool check(int v)
    {
        visy[v] = true;
        if (matchy[v] != -1)
        {
            q.push(matchy[v]);
            visx[matchy[v]] = true;
            return false;
        }
        while (v != -1)
        {
            matchy[v] = pre[v];
            swap(v, matchx[pre[v]]);
        }
        return true;
    }

    void bfs(int i)
    {
        while (!q.empty())
        {
            q.pop();
        }
        q.push(i);
        visx[i] = true;
        while (true)
        {
            while (!q.empty())
            {
                int u = q.front();
                q.pop();
                for (int v = 0; v < n; v++)
                {
                    if (!visy[v])
                    {
                        T delta = lx[u] + ly[v] - g[u][v];
                        if (slack[v] >= delta)
                        {
                            pre[v] = u;
                            if (delta)
                            {
                                slack[v] = delta;
                            }
                            else if (check(v))
                            {
                                return;
                            }
                        }
                    }
                }
            }
            T a = inf;
            for (int j = 0; j < n; j++)
            {
                if (!visy[j])
                {
                    a = min(a, slack[j]);
                }
            }
            for (int j = 0; j < n; j++)
            {
                if (visx[j])
                { // S
                    lx[j] -= a;
                }
                if (visy[j])
                { // T
                    ly[j] += a;
                }
                else
                { // T'
                    slack[j] -= a;
                }
            }
            for (int j = 0; j < n; j++)
            {
                if (!visy[j] && slack[j] == 0 && check(j))
                {
                    return;
                }
            }
        }
    }

    int solve()
    {
        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < n; j++)
            {
                lx[i] = max(lx[i], g[i][j]);
            }
        }

        for (int i = 0; i < n; i++)
        {
            fill(slack.begin(), slack.end(), inf);
            fill(visx.begin(), visx.end(), false);
            fill(visy.begin(), visy.end(), false);
            bfs(i);
        }

        for (int i = 0; i < n; i++)
        {
            if (g[i][matchx[i]] > 0)
            {
                res += g[i][matchx[i]];
            }
            else
            {
                matchx[i] = -1;
            }
        }
        return res;
    }
};

class Solution {
    
public:
    int findMinimumTime(vector<int>& strength) {
        const int n = strength.size();
        hungarian<int> h(n, n);
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                h.addEdge(i, j, 1000000 - (strength[i] + j) / (j + 1));
            }
        }
        return n * 1000000LL - h.solve();
    }
};
