? Problem Breakdown

We are given a preorder traversal string of a binary tree where:

  • The number of dashes (-) before a node represents its depth.
  • A node at depth D will have its children at depth D+1.
  • A node with only one child will always have a left child first.

Our goal is to reconstruct the binary tree and return its root.

Example:

Input:

traversal = "1-2--3--4-5--6--7"

Output:

[1,2,5,3,4,6,7]

? Approach Overview

  • Preorder DFS Parsing:

    • Read numbers from the traversal string.
    • Count dashes to determine depth.
    • Recursively attach children to parent nodes.

  • Recursive Helper Function:

    • Extract number values.
    • Determine child placement (left or right).
    • Move to the next node using depth tracking.

? Why This Approach?

  1. Recursive Parsing Ensures Correct Structure:

    • Each node is placed at the correct depth and order.

  2. Efficient String Parsing:

    • We traverse the string once (O(n)).

  3. Minimal Space Usage:

    • Only O(n) additional space for recursion.

? Complexity Analysis

  • Time Complexity: O(n) ? We traverse the string once.
  • Space Complexity: O(n) ? For recursion stack.

? Code Implementations

? Java Solution

class Solution {
    private String s;
    private int idx, level;
    
    public TreeNode recoverFromPreorder(String traversal) {
        this.s = traversal;
        this.idx = 0;
        this.level = 0;
        TreeNode node = new TreeNode(-1);
        this.helper(node, 0);
        return node.left;
    }

    private void helper(TreeNode parent, int lvl) {
        while (this.idx < this.s.length() && lvl == level) {
            int num = 0;
            while (this.idx < this.s.length() && Character.isDigit(this.s.charAt(this.idx))) {
                num = num * 10 + (this.s.charAt(this.idx++) - '0');
            }
            TreeNode node = new TreeNode(num);
            if (parent.left == null)
                parent.left = node;
            else
                parent.right = node;
            
            this.level = 0;
            while (this.idx < this.s.length() && this.s.charAt(this.idx) == '-') {
                this.level++;
                this.idx++;
            }
            this.helper(node, lvl + 1);
        }
    }
}

Intuition

The problem requires reconstructing a binary tree from a preorder traversal with depth encoding. The traversal uses hyphens (-) to denote depth levels, followed by integer values representing node values.

The key observations are:

  1. Preorder Traversal: The given string follows a preorder traversal, meaning the root appears first, followed by the left subtree and then the right subtree.
  2. Depth Representation: The number of hyphens before a node value indicates its depth in the tree.
  3. Stack-based Construction: We can use a stack to keep track of the nodes at different depths and properly attach new nodes to their respective parents.

Approach

  1. Iterate through the string:

    • Count consecutive - characters to determine the depth of the next node.
    • Extract the node's numerical value.

  2. Maintain a stack:

    • Ensure the stack contains only nodes corresponding to valid ancestors.
    • If the stack's size exceeds the current depth, pop elements to move up the tree.

  3. Attach nodes:

    • The last node in the stack is the parent at the correct depth.
    • Attach the new node as the left child if available; otherwise, assign it as the right child.

  4. Return the root:

    • The first node inserted into the stack is the root of the tree.

Complexity

  • Time Complexity: (O(n)) — We process each character in the input string exactly once.
  • Space Complexity: (O(n)) — In the worst case, the stack stores all nodes (skewed tree case).

/**
 * Definition for a binary tree node.
 * class TreeNode {
 *   int val;
 *   TreeNode? left;
 *   TreeNode? right;
 *   TreeNode([this.val = 0, this.left, this.right]);
 * }
 */
class Solution {
  TreeNode? recoverFromPreorder(String traversal) {
    List<TreeNode?> nodeStack = [];
    int currentIndex = 0;
    
    while (currentIndex < traversal.length) {
      int depth = 0;
      while (currentIndex < traversal.length && traversal[currentIndex] == '-') {
        depth++;
        currentIndex++;
      }

      int nodeValue = 0;
      while (currentIndex < traversal.length && traversal[currentIndex] != '-') {
        nodeValue = nodeValue * 10 + int.parse(traversal[currentIndex]);
        currentIndex++;
      }

      TreeNode newNode = TreeNode(nodeValue);
      
      while (nodeStack.length > depth) {
        nodeStack.removeLast();
      }

      if (nodeStack.isNotEmpty) {
        if (nodeStack.last!.left == null) {
          nodeStack.last!.left = newNode;
        } else {
          nodeStack.last!.right = newNode;
        }
      }

      nodeStack.add(newNode);
    }
    
    return nodeStack.isNotEmpty ? nodeStack.first : null;
  }
}

Without stack


class Solution {
  int index = 0; // Tracks the current position in the traversal string

  TreeNode? recoverFromPreorder(String traversal) {
    if (traversal.isEmpty) return null;
    return _helper(traversal, 0);
  }

  TreeNode? _helper(String traversal, int depth) {
    if (index >= traversal.length) return null;

    // Count the number of dashes at the current position
    int dashCount = 0;
    while (index < traversal.length && traversal[index] == '-') {
      dashCount++;
      index++;
    }

    // If the number of dashes does not match the expected depth, return null
    if (dashCount != depth) {
      index -= dashCount; // Backtrack the index
      return null;
    }

    // Parse the node value
    int val = 0;
    while (index < traversal.length && traversal[index] != '-') {
      val = val * 10 + int.parse(traversal[index]);
      index++;
    }

    // Create the current node
    TreeNode node = TreeNode(val);

    // Recursively construct the left and right subtrees
    node.left = _helper(traversal, depth + 1);
    node.right = _helper(traversal, depth + 1);

    return node;
  }
}

Summary

  • Stack-based approach helps efficiently track node relationships.
  • Constant space trimming ensures the stack always maintains valid ancestors.
