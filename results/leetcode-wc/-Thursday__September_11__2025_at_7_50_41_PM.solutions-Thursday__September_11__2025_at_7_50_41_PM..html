Intuition

We are given an integer n and we need to return the smallest super palindrome greater than n. I began by writing down the first few super palindromes, they go in the order 1, 22, 212, 333, 4444, 23332, 32323, 44144, 55555, 244442...

If we observe these numbers, what we can find is that all the unique digits add upto the length of the string. Take for example 23332, the unique digits are 2 and 3 and their sum is equal to 5. This applies for all the numbers. So what comes to my mind is combination sum of numbers, wherein if we are given an integer n and it has x digits, then we find the different combinations of numbers which add up to x.

So for 5, we have 1 and 4, 2 and 3 and 5. Now, in each case, each number a occurs a times in the integer, so for 1 and 4, 1 occurs once and 4 occurs four times. This way we need to find permutations of the string 14444 which are palindromes. We precompute all the different super palindromes and then store them in the array and sort the array. We then simply search the array for the smallest super palindrome greater than n.

Approach

We begin by precomputing all the super palindromes from length 2 till length 16, we do this because the largest possible value of n can be 1e15, which has 16 digits.

We first begin by running a loop from 2 till 16. We then call the function which calculates all the combination sums for each number from 2 till 16. We can select each digit only once for each number. But there is a way this can be optimised.

We need to form a palindrome. If the length of a string is odd, it should have only one character which has odd number of occurances and the remaining characters should occur even number of times. If the length of string is even, we can not have even one character with odd number occurances. So, when iterating i over 2 till 16, if i % 2 == 0, we consider only the even digits, namely 2, 4, 6, 8 and when i % 2 == 1, we consider all the digits from 1 to 9.

So we create two arrays, arr1 = [2,4,6,8] and arr2 = [1,2,3,4,5,6,7,8,9]. If i is odd, we call the combination sum function and the array which is the parameter is arr2. Else if i is even, the parameter for the combination sum is arr1. We also restrict the number of odd digits chosen to 1 for when i is odd. This way, we only find the combinatoins which will result in a super palindrome.

Now, we need to arrange the digits such that they are a palindrome. There is the brute force approach, where we find all the different permutations of a string and then check if it is a palindrome or not. This is not optimal since there 16! possible permutations possible for a string which has 16 digits. We can easily use a clever way to find all the palindromes.

A palindrome is basically a string concatenated with its reverse. So basically all the characters of the string occur even number of times in a palindrome with an even length. If it is of odd length, only the middle character appears odd number of times, all the other characters occur an even number of times.

So when we calculate the combination sum, we have an array with all the numbers which add up to the number. But remember, the numbers are also the number of times that they must occur in the string. So the array for combination sum of 5 has [[1,4], [2,3], [5]].

So what we do is we create an empty string. Then we append each character in the combination sum array x/2 times. Let's take for example [1,4]. The string s is currently empty, s = "". We now traverse through this array and append each element of the array x/2 times. for 1, this comes out to be 0 times and for 4, this comes out to be 2 times. So, the string becomes s = "44".

Let's take another example, this time i = 6. For this, we get the combination sum array equal to [[2,4], [6]]. For [2,4], the string becomes s = "244" and for [6], s = "666".

Now that we have s for all the different cases, we find all the different permutations for each string. Four different cases are as follows:

  1. s = "44". permutations = {"44"}.
  2. s = "244". permutations = {"244", "424", "442"}.
  3. s = "2666". permutations = {"2666", "6266", "6626", "6662"}.
  4. s = "23". permutations = {"23", "32"}.

Now we make the palindrome. If the current value of i is odd, we concatenate the odd integer behind the achieved strings and then concatenate teh reverse of the achieved strings after to get the palindromes. The examples are as below:

  1. arr = [1, 4]. perm = "44". Append 1 to perm and then reverse perm and append it back to perm. We now are left with perm = "44144". We append this to an array which stores all teh permutations.
  2. arr = [2, 3]. perm = "23". Append 3 to perm and then reverse perm and append it back to perm. We now are left with perm = "23332". We have another permutation perm = "32". Repeating the same process we are left with perm = "32323". We store both of these to all the saved super palindromes.
  3. arr = [2, 4]. perm = "244". Since i is even, we simply reverse perm and append it to perm and are left with perm = "244442". All of the different permutations formed are "424424" and "442244". All these are appended to the saved palindromes array.

This loop repeats for all i from 2 till 16 and we have an array which has 2295 super palindromes. We sort this array and this is our pre-computed super palindrome array.

Now all that is left to do is find the smallest super palindrome greater than the given n. We binary search over the sorted array to find the index at which it is located and we return the palindrome at the index that we have found.

void findSubsets(vector<int>& arr, int index, int target, vector<int>& curr, vector<vector<int>>& result, int max_odds, int odd_count) {
    if (index >= (int)arr.size()) {
        if (target == 0) {
            result.push_back(curr);
        }
        return;
    }

    if (odd_count + (arr[index] % 2) <= max_odds) {
        curr.push_back(arr[index]);
        findSubsets(arr, index + 1, target - arr[index], curr, result, max_odds, odd_count + (arr[index] % 2));
        curr.pop_back();
    }

    findSubsets(arr, index + 1, target, curr, result, max_odds, odd_count);
}

vector<vector<int>> perfectSum(vector<int>& arr, int target, int max_odds) {
    vector<vector<int>> result;
    vector<int> curr;
    findSubsets(arr, 0, target, curr, result, max_odds, 0);
    return result;
}

int mainLogicInit(vector<long long>& L1) {
    vector<int> arr1 = {2, 4, 6, 8};
    vector<int> arr2 = {1, 2, 3, 4, 5, 6, 7, 8, 9};
    set<string> L;

    for (int i = 2; i < 17; i++) {
        vector<vector<int>> res;
        if (i % 2 == 0) {
            res = perfectSum(arr1, i, (int)arr1.size());
        } else {
            res = perfectSum(arr2, i, 1);
        }

        bool x = false;
        int t = 0;
        for (auto& arr : res) {
            string s = "";
            x = false;
            for (auto val : arr) {
                if (val % 2 == 1) {
                    x = true;
                    t = val;
                }
                s += string(val / 2, char('0' + val));
            }

            sort(s.begin(), s.end());
            do {
                if (x) {
                    L.insert(s + to_string(t) + string(s.rbegin(), s.rend()));
                } else {
                    L.insert(s + string(s.rbegin(), s.rend()));
                }
            } while (next_permutation(s.begin(), s.end()));
        }
    }

    L1.clear();
    for (auto& str : L) {
        L1.push_back(stoll(str));
    }
    sort(L1.begin(), L1.end());
    return 0;
}

class Solution {
public:
    long long specialPalindrome(long long n) {
        static vector<long long> L1;
        static bool initialized = false;
        if (!initialized) {
            mainLogicInit(L1);
            initialized = true;
        }

        if (n == 0) {
            return 1;
        }
        auto x = upper_bound(L1.begin(), L1.end(), n) - L1.begin();
        return L1[x];
    }
};
