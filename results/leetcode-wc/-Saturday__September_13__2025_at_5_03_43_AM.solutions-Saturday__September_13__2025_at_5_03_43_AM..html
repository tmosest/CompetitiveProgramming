Intuition

The goal is to find the k smallest sums, where a sum is formed by picking one element from each of the m input rows.
Since k is relatively small (at most 200), we don't need to compute all possible sums, which could be massive.
Instead, we can efficiently find the smallest sums one by one.

The core idea is to maintain a running collection of the smallest sums found so far. We can use a max heap of size k for this.

Algorithm

The algorithm processes the matrix row by row, maintaining a heap that stores the k smallest sums found so far.

  1. Initialization:

    • A max heap maxHeap is initialized and seeded with 0. This 0 represents the starting sum before any rows are processed. The use of a max heap means that the largest element is always at the top.

    • The number of columns to consider from each row is capped at k because we only care about finding the k smallest sums. Any elements beyond the k-th smallest in a sorted row won't contribute to the overall k smallest sums.

  2. Iterating Through Rows:

    • The code iterates through each row in the input matrix mat.

    • For each row, a new max heap nextHeap is created to store the new candidate sums.

    • It then combines the current smallest sums from maxHeap with the elements of the current row.

    • For every sum prevSum in maxHeap and every element row[c] in the current row, a new sum prevSum + row[c] is calculated.

    • These new sums are added to nextHeap.

    • To ensure nextHeap always contains at most k elements, if its size exceeds k, the largest element (the top of the max heap) is removed using nextHeap.poll(). This maintains a running collection of the k smallest sums.

  3. Final Result:

    • After processing all rows, the maxHeap (which is now nextHeap from the last iteration) holds the k smallest possible sums. The k-th smallest sum is the largest element in this collection, which is at the top of the max heap.

    • The return value is maxHeap.peak(), which retrieves the largest element from the final max heap, giving you the k-th smallest sum.

This approach effectively prunes the search space by only considering sums that are smaller than the largest sum found so far, without having to generate all possible combinations.

Complexity

  • Time: O(m * n * k * log(k))
  • Space: O(k)
public int kthSmallest(int[][] mat, int k) {
    int C = Math.min(mat[0].length, k);

    var maxHeap = new PriorityQueue<Integer>(Collections.reverseOrder());
    maxHeap.add(0);
    for (var row : mat) {
        // max heap for the i-th row
        var nextHeap = new PriorityQueue<Integer>(Collections.reverseOrder());
        for (int prevSum : maxHeap) {
            for (int c = 0; c < C; c++) {
                nextHeap.add(prevSum + row[c]);
                // keep next max heap size <= k
                if (nextHeap.size() > k) {
                    nextHeap.poll();
                }
            }
        }
        maxHeap = nextHeap;
    }
    return maxHeap.peek();
}

public class Solution {
    public int kthSmallest(int[][] mat, int k) {
        int m = mat.length, n = mat[0].length;
        if (m == 1) return mat[0][k - 1];

        int[] ans = kSmallestSumPairs(mat[0], mat[1], k);
        for (int r = 2; r < m; r++) {
            ans = kSmallestSumPairs(ans, mat[r], k);
        }
        return ans[k - 1];
    }

    private int[] kSmallestSumPairs(int[] arr1, int[] arr2, int k) {
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        for (int c = 0; c < Math.min(arr1.length, k); c++) {
            minHeap.offer(new int[]{arr1[c] + arr2[0], c, 0});
        }

        List<Integer> ansList = new ArrayList<>();
        while (k > 0 && !minHeap.isEmpty()) {
            int[] current = minHeap.poll();
            ansList.add(current[0]);
            if (current[2] + 1 < arr2.length) {
                minHeap.offer(new int[]{arr1[current[1]] + arr2[current[2] + 1], current[1], current[2] + 1});
            }
            k--;
        }

        int[] ans = new int[ansList.size()];
        for (int i = 0; i < ansList.size(); i++) {
            ans[i] = ansList.get(i);
        }
        return ans;
    }
}
