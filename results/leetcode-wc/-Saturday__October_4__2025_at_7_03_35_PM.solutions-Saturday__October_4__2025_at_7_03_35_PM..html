? Intuition

You are given an array nums and a number k.
You need to find a subsequence (not necessarily contiguous, but order must be preserved) of length k that has the maximum possible sum.

? Approach

  1. Pair each element with its index ? [value, index].
  2. Sort in descending order of values.
  3. Select the top k elements (largest values).
  4. Sort these k elements by their original indices to maintain order.
  5. Extract the values to form the result.

??? Example Walkthrough

Input: nums = [2, 1, 3, 3], k = 2

Step 1: Pair each number with its index

So we can remember where each number came from.

int[][] numsWithIndices = new int[nums.length][2];
for (int i = 0; i < nums.length; i++) {
    numsWithIndices[i] = new int[]{nums[i], i};
}

Now we have:
[ [value, index], [value, index], ... ]

numsWithIndices = [
    [2, 0],  // 2 at index 0
    [1, 1],  // 1 at index 1
    [3, 2],  // 3 at index 2
    [3, 3]   // 3 at index 3
]

Step 2: Sort by value descending

We want the largest values first.

Arrays.sort(numsWithIndices, (a, b) -> b[0] - a[0]);

Now the top k elements in this array are the k largest numbers.

numsWithIndices = [
    [3, 2],  // largest value first
    [3, 3],
    [2, 0],
    [1, 1]
]

Step 3: Sort those k elements by their original index

This puts them back in the original order, as required by a subsequence.

Arrays.sort(numsWithIndices, 0, k, (a, b) -> a[1] - b[1]);

This ensures we keep only the top k numbers but in the order they appeared in nums.
(Sort first k=2 by original index

numsWithIndices (first 2) = [
    [3, 2],  // index 2
    [3, 3]    // index 3
]
(Already in order since 2 < 3)

Step 4: Extract only the values

Now we just return those values.

int[] result = new int[k];
for (int i = 0; i < k; i++) {
    result[i] = numsWithIndices[i][0];
}
result = [3, 3]

Output: [3, 3] (which has the largest sum 6 while preserving order).

class Solution {
    public int[] maxSubsequence(int[] nums, int k) {
        // Step 1: Create array of [value, index] pairs
        int[][] valueWithIndex = new int[nums.length][2];
        for (int i = 0; i < nums.length; i++) {
            valueWithIndex[i] = new int[]{nums[i], i}; // Store value and its original index
        }
        
        // Step 2: Sort by value in descending order
        Arrays.sort(valueWithIndex, (a, b) -> b[0] - a[0]);
        // This compares values (a[0] and b[0]) and sorts bigger values first
        
        // Step 3: Take first k elements and sort them by original index
        Arrays.sort(valueWithIndex, 0, k, (a, b) -> a[1] - b[1]);
        // This sorts only the first k elements by their original indices (a[1])
        
        // Step 4: Extract the values in order
        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = valueWithIndex[i][0]; // Take just the value part
        }
        
        return result;
    }
}
