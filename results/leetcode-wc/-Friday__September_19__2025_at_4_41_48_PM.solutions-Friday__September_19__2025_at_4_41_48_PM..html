Intuition

The key to solving this problem efficiently is to realize that the average value lies within the range of the minimum and maximum elements in the array. We will use a binary search to find the maximum average value within this range.

Approach

Initialization:

Determine the minimum and maximum values of the array (minVal and maxVal). These will be the bounds of our binary search.
Initialize a sums array to hold the prefix sums (cumulative sums from the start of the array to each position).

Binary Search:

We perform a binary search within the range [minVal, maxVal] to find the maximum average value. Let mid be the mid-point of this range.
We want to know if it is possible to have a subarray of length at least k with an average value at least mid.

Convert to Difference Array:

To check whether an average value of mid is possible, we subtract mid from each element in nums. We store the prefix sums of this difference array in sums.
Now the problem becomes finding a subarray of length at least k that has a positive sum in the difference array. This subarray corresponds to a contiguous subarray in nums that has an average value of at least mid.

Sliding Window Technique:

We iterate through the sums array, maintaining a window of length k.
maxSum is the maximum sum we've found for windows of length at least k.
minSum is the minimum prefix sum we've found within the window.
If maxSum > 0, that means we found a subarray of length at least k with a positive sum in the difference array, which means an average value of at least mid is possible in nums.
If we find a valid subarray, we update minVal to mid; otherwise, we update maxVal to mid.

Result:

The binary search will converge to the maximum average value, and we return minVal.

Complexity

  • Time complexity:

The time complexity of this algorithm is O(nlogm), where n is the length of the array and m is the range between the maximum and minimum values of the array.

  • Space complexity:

The space complexity of this algorithm is mainly determined by the additional data structures used. In this case, the main additional data structure is the sums array, which has a length of nums.length + 1.
Thus, the space complexity of the algorithm is O(n), where n is the length of the input array nums. Other variables used in the algorithm take constant space and do not depend on the size of the input, so they don't affect the overall space complexity.

Code

class Solution {
    public double findMaxAverage(int[] nums, int k) {

        // the average value lies within the range of the minVal and maxVal
        double maxVal = Integer.MIN_VALUE, minVal = Integer.MAX_VALUE;
        for (int num : nums) {
            maxVal = Math.max(maxVal, num);
            minVal = Math.min(minVal, num);
        }

        //The length of sums is nums.length + 1 
        //because sums is a prefix sum array, 
        //include an extra element at beginning
        //to represent the sum of the first 0 elements.
        double[] sums = new double[nums.length + 1];

        while (maxVal - minVal > 1e-5) {
            
            double mid = (maxVal + minVal) / 2;

            //To check whether an average value of mid is possible, 
            //subtract mid from each element in nums. 
            //Then store the prefix sums of this difference array in sums.
            for (int i = 0; i < nums.length; i++) {
                //sums[i] represents the sum of 
                //the first i numbers in the difference array
                sums[i + 1] = sums[i] + nums[i] - mid;
            }

            //Now the problem becomes 
            //finding a subarray of length at least k 
            //that has a positive sum in the difference array
            double minSum = 0, maxSum = 0;
            boolean valid = false;
            //iterate through sums, maintaining a window of length k.
            for (int i = k; i < sums.length; i++) {
                maxSum = Math.max(maxSum, sums[i] - minSum);
                //update the minSum for the next iteration after i++
                minSum = Math.min(minSum, sums[i - k + 1]);
                //If maxSum > 0, 
                //that means we found a subarray of length at least k 
                //with a positive sum in the difference array, 
                //which means an avg of at least mid is possible in nums.
                if (maxSum > 0) {
                    valid = true;
                    break;
                }
            }

            //update boundaries
            if (valid) {
                minVal = mid;
            } else {
                maxVal = mid;
            }
        }

        return minVal;
    }
}
