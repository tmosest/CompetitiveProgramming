So we can divide this question in three parts :

  1. Division with its own multiple for eg. 8 / 4 = 2
  2. Division without repeating numbers after decimal for eg. 41 / 2 = 20.5
  3. Division with repeating numbers after decimal for eg. 14 / 3 = 4.(6) or 47 / 18 = 2.6(1)
    Note : Here the repeating part is in bracket.

For 1st Part we can normally divide the numbers and add it to the ans string and return if the remainder is 0.

//Code: 
int q = num / den;
int r = num % den;
ans += q;
if(r == 0) return ans;

For 2nd part we need to add a Ò.Ó if remainder is not zero and then make the remainder 10 times everytime and append the quotient to the ans string.

//Code:
while(r != 0)
	r *= 10;
	q = r / den;
	r = r % den;
	ans += q;

For the 3rd part we need to use and unordered_map so that we can store the the position from where the repeating of number starts in front of the remainder. If the remainder is already in the map then we insert the Ò(Ó opening bracket at the position of that rem and lastly append a Ò)Ó closing bracket and break out of the loop and return the ans.

//Code :
unordered_map<int, int> mp;
while(r != 0)
	if(mp(r) is in map)
		int pos = mp[r];
		ans.insert(pos, "(");
		ans += ')';
		break;
	else
		mp[r] = ans.length();
		r *= 10;
		q = r / den;
		r = r % den;
		ans += q;

We need to handle the case where there are negative numbers. So if numerator is negative and denominator is positive or numerator is positive and denominator is negative we need to add a Ò-Ò negative symbol in the ans.

if (numerator > 0 ^ denominator > 0)

Final Code :

class Solution {
public:
    string fractionToDecimal(int numerator, int denominator) {
        if(!numerator) return "0";
        string ans = "";
        if (numerator > 0 ^ denominator > 0) ans += '-';
        long num = labs(numerator), den = labs(denominator);
        long q = num / den;
        long r = num % den;
        ans += to_string(q);
        
        if(r == 0) return ans;
        
        ans += '.';
        unordered_map<long, int> mp;
        while(r != 0){
            if(mp.find(r) != mp.end()){
                int pos = mp[r];
                ans.insert(pos, "(");
                ans += ')';
                break;
            }
            else{
                mp[r] = ans.length();
                r *= 10;
                q = r / den;
                r = r % den;
                ans += to_string(q);
            }
        }
        return ans;
    }
};

Intuition

The problem requires converting a fraction represented by a numerator and a denominator into its decimal string representation. The tricky part is handling repeating decimals, which should be enclosed in parentheses. The core idea is to simulate the division manually and use a map to detect when a remainder repeats, which indicates the start of a recurring cycle. By tracking the position of each remainder in the result string, we can insert parentheses at the correct positions once repetition is detected.

Approach

First, we handle the sign of the result. If the numerator and denominator have opposite signs, the result is negative, and we store this information for later use. Then we convert both the numerator and denominator to their absolute values and cast them to long to handle potential overflow, particularly for edge cases like Integer.MIN_VALUE.

We begin the division by computing the integer part (quotient) and append it to a StringBuilder. If there's no remainder, it means the fraction can be represented as a terminating decimal, and we return the result with a negative sign if needed.

If a remainder exists, we know that the decimal part is non-terminating. We append a decimal point and then simulate the long division. During this process, we use a Map to store each remainder along with the corresponding index in the StringBuilder. If a remainder repeats, we know we've entered a repeating cycle. We then insert a "(" at the index where this remainder was first seen and append ")" at the end to mark the repeating part. This ensures the result is correctly formatted. Finally, we return the string with the appropriate sign.

Complexity

  • Time complexity: O(n)
  • Space complexity: O(n)

class Solution {
    public String fractionToDecimal(int numerator, int denominator) {
        boolean isNegative = ((numerator>0 && denominator<0) || (denominator>0 && numerator<0)) ? true : false;
        StringBuilder ans = new StringBuilder();
        long num = Math.abs((long)numerator);
        long den = Math.abs((long)denominator);
        long q = num/den;
        ans.append(q);
        long r = num%den;
        if(r==0) {
            if(isNegative) ans.insert(0, "-");
            return ans.toString();
        }
        else{
            ans.append(".");
            Map<Long,Integer> map = new HashMap<>();
            while(r!=0){
                if(map.containsKey(r)){
                    int index = map.get(r);
                    ans.insert(index, "(");
                    ans.append(")");
                    break;
                }
                else{
                    map.put((long)r,ans.length());
                    r = r*10;
                    q = r/den;
                    r = r%den;
                    ans.append(q);
                }
            }
        }
    if(isNegative) ans.insert(0, "-");
    return ans.toString();
    }
}
