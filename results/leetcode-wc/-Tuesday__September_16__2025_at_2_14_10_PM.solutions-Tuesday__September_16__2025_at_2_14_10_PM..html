Intuition

  • Obsever that a 0 is valid if the total left sum is close to total right sum. There will be 3 cases for any 0 at index i:
    • left_sum[i] == right_sum[i]: in this case either start move to left or right first will always return a valid move. Thus, we have 2 choices.
    • left_sum[i] == right_sum[i] + 1: this time left is 1 more than right, so we can only move from left first to get a valid move. Thus, we have 1 choice.
    • left_sum[i] == right_sum[i] - 1: this time left is 1 less than right, so we can only move from right first to get a valid move. Thus, we have 1 choice.
  • How to efficiency get the sum from the left and right of an element -> Sense of Prefix Sum comes into play.

class Solution:
    def countValidSelections(self, nums: List[int]) -> int:
        n, res = len(nums), 0
        left, right = [0 for _ in range(n)], [0 for _ in range(n)]
        for i in range(1, n):
            left[i] = left[i - 1] + nums[i - 1]
            right[-i - 1] = right[-i] + nums[-i]
        for i, num in enumerate(nums):
            if num != 0: continue
            if left[i] == right[i]: res += 2
            if abs(left[i] - right[i]) == 1: res += 1
        return res

Approach

  • Initial Sum Calculation:
    • Find the first zero in the array and calculate left sum up to that point
    • Calculate right sum from first zero to the end
  • Iterate Through Zeros:
    • Update running sums as we move through array:
      • Add current number to left sum
      • Subtract current number from right sum
  • Check Valid Selections:
    • When a zero is encountered:
      • If left sum equals right sum: add 2 (both -1 and 1 work)
      • If left sum differs by 1 from right sum: add 1 (either -1 or 1 works)
  • Return total count of valid selections

Complexity

  • Time complexity: O(n)
  • Space complexity: O(1)

class Solution {
    public int countValidSelections(int[] nums) {
        int index = 0;
        int left = 0;
        int right = 0;
        
        for (int i = 0; i < nums.length; i++) {
            left += nums[i];
            if (nums[i] == 0) {
                index = i;
                break;
            }
        }
        
        for (int i = index; i < nums.length; i++) right += nums[i];        

        int count = 0;
        for (int i = index; i < nums.length; i++) {
            left += nums[i];
            right -= nums[i];
            
            if (nums[i] != 0) continue;
            
            if (left == right) count += 2;
            else if (left - 1 == right || left + 1 == right) count += 1;
        }
        
        return count;
    }
}
