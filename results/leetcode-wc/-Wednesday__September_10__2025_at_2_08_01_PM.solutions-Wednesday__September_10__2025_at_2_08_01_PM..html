Intuition

We don't need to check all possible sequences,
but only some big nodes.

Explanation

For each edge (i, j) in edges,
we find a neighbour ii of node i,
we find a neighbour jj of node i,
If ii, i, j,jj has no duplicate, then that's a valid sequence.

Ad the intuition mentioned,
we don't have to enumearte all neignbours,
but only some nodes with big value.

But how many is enough?
I'll say 3.
For example, we have ii, i, j now,
we can enumerate 3 of node j biggest neighbour,
there must be at least one node different node ii and node i.

So we need to iterate all edges (i, j),
for each node we keep at most 3 biggest neighbour, which this can be done in O(3) or O(log3).

Complexity

Time O(n + m)
Space O(n + m)

Java

    public int maximumScore(int[] A, int[][] edges) {
        int n = A.length;
        PriorityQueue<Integer>[] q = new PriorityQueue[n];
        for (int i = 0; i < n; i++)
            q[i] = new PriorityQueue<>((a, b) -> A[a] - A[b]);
        for (int[] e : edges) {
            q[e[0]].offer(e[1]);
            q[e[1]].offer(e[0]);
            if (q[e[0]].size() > 3) q[e[0]].poll();
            if (q[e[1]].size() > 3) q[e[1]].poll();
        }
        int res = -1;
        for (int[] edge : edges)
            for (int i : q[edge[0]])
                for (int j : q[edge[1]])
                    if (i != j && i != edge[1] && j != edge[0])
                        res = Math.max(res, A[i] + A[j] + A[edge[0]] + A[edge[1]]);  
        return res;
    }

Top 3 Neighbors Solution

Heap (Priority Queue)
Java

Intuition

We need 3 adjacent nodes. Let's fix the middle one and try finding best score if it exsist in middle of our maximum sequence.
First I tried using only node for each and find maximum, but it raised a critical condition what is the node we chose is same as the other node in edge or it is already chosen by it. Since it can go wrong in two ways chosing 3 neighbours should be optimal.

Approach

Save the top three nodes for each node. Now while iterating via edges array check top 3 of both and find maximum for that particular edge. Skip combinations where all nodes are not unique.

Complexity

  • Time complexity: O(n) where n is length of edges array.
  • Space complexity: O(n + m) where m is no. of nodes.

Code

Java
class Solution {
    public int maximumScore(int[] scores, int[][] edges) {
        int n = scores.length;
        List<PriorityQueue<int[]>> list = new ArrayList<>();
        for(int i=0; i<n; i++) list.add(new PriorityQueue<>((a,b) -> Integer.compare(b[1],a[1])));
        for(int[] i: edges){
            list.get(i[0]).add(new int[]{i[1],scores[i[1]]});
            list.get(i[1]).add(new int[]{i[0],scores[i[0]]});
        }
        List<List<Integer>> top = new ArrayList<>();
        for(int i=0; i<n; i++){
            top.add(new ArrayList<>());
            int j = 0;
            while (list.get(i).size()>0 && j<3){
                int[] remove = list.get(i).remove();
                top.get(i).add(remove[0]);
                j++;
            }
        }
        int ans = -1;
        for(int[] i: edges){
            int curr = -1;
            for(int j=0; j<top.get(i[0]).size(); j++){
                for(int k=0; k<top.get(i[1]).size(); k++){
                    int a = top.get(i[0]).get(j);
                    int b = top.get(i[1]).get(k);
                    if(a != i[1] && a != b && b != i[0]){
                        int score = scores[i[0]] + scores[i[1]] + scores[a] + scores[b];
                        curr = Math.max(curr,score);
                    }
                }
            }
            ans = Math.max(ans,curr);
        }
        return ans;
    }
}
