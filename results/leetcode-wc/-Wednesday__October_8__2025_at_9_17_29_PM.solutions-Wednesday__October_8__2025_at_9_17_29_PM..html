? Understanding The Problem

  • We're given an array which consists of some words of length 2 each.
  • We need to find the longest palindrome that we can form by concatenating these words in any order.
  • For example : for words = ["lc","cl","gg"], we can form :

  • Which is a palindrome as the reverse of lcggcl == lcggcl

? Using Greedy + Hashmap O(n*L)

  • Here is a simple 5 Step Approach for solving this with the help of hashmaps & greedy :

1?? Step 1 ? Build The Map

  • We firstly store all the strings from words into a hashmap so that we can access their frequencies easily.

  • As on inserting words[i] to the start and its reverse to the end of the string, a palindrome is maintained.

  • Here we can either pre-pend or append "xyz" it doesn't matter but we will still end up with a palindrome.
  • So we now traverse over every words[i] and create its reversed copy in s while traversing.
  • s is the reverse of words[i].

3?? Step 3 ? words[i] is a palindrome

  • Now we check whether words[i] or w is a palindrome itself.
  • If the word is a palindrome itself it means that :
    • If it has a frequency >= 2 it can be added on left & right end.
    • Else it can also be added in the middle if it has a odd frequency.
  • For example : for words = ["lc", "cl", "gg", "gg]

  • But if there were 3 "gg" present here instead of 2 then,

  • So what we do here basically now is that for a large number of strings present which are a palindrome itself ("aa", "bb"...), instead of going through all the palindrome occurences of this string in the array, we can simply compute all possible insertions using its frequency in the array.
  • As palindrome strings with a frequency >= 2 can be inserted on left & right.
  • This means that any palindrome string with an even frequency can be inserted on left & right.
  • That is, let's say a palindrome string has frequency 4, it can be inserted 2 times on left and 2 times on right.
  • For example : words = ["aa", "aa", "pq", "qp", "aa", "aa"]
  • So on adding one "aa" from right & one from left we get "aapqqpaa"
  • On again adding similarly, we get the result as "aaaapqqpaaaa". Which is the longest palindrome possible here.
  • So we can simply count the number of insertion as (freq / 2), that is, insertions one from the left and one from the right so basically half of it.
  • If the string has an odd frequency though and its palindrome, then we can also insert it in the middle.
  • For example : words = ["aa", "aa", "aa", "pq", "qp", "aa", "aa"]
  • After all 4 "aa" strings were inserted we got the result as "aaaapqqpaaaa".
  • We can now instead the last "aa" in the middle and string will still remain a palindrome "aaaapqaaqpaaaa".

class Solution {
public:
    int longestPalindrome(vector<string>& words) {
        unordered_map<string, int> mpp;
        for (string w : words) mpp[w]++;

        int count = 0, alreadyPalindrome = 0;
        for (auto& [w, freq] : mpp) {
            string s = w;
            reverse(s.begin(), s.end());
            if (w == s) {
                count += (freq / 2) * 4;
                if (freq % 2) alreadyPalindrome = 1;
            } else if (w < s && mpp.count(s)) {
                count += min(freq, mpp[s]) * 4;
            }
        }
        return count + alreadyPalindrome * 2;
    }
};

class Solution {
public:
    int longestPalindrome(vector<string>& words, int count = 0) {
        vector<vector<int>> mpp(26, vector<int>(26, 0));
        int middle = 0;

        for (auto &s : words) {
            int x = s[0] - 'a', y = s[1] - 'a';
            if (mpp[y][x] > 0) {
                mpp[y][x]--;
                count += 4;
                if (x == y) middle--;
            } else {
                mpp[x][y]++;
                if (x == y) middle++;
            }
        }

        if (middle > 0) count += 2;
        return count;
    }
};

? Intuition

We are given a list of two-letter words. Our task is to form the longest possible palindrome by concatenating these words.

A palindrome reads the same forwards and backwards. So, if we can pair a word with its reverse (like "ab" with "ba"), it will contribute to the palindrome. Also, if a word is already a palindrome (like "aa"), we can use it in the center.

?? Approach

  1. Frequency Map: Count the frequency of each word using a hash map.

  2. Pair Matching:

    • For words that are not palindromes (e.g., "ab"), look for their reverse ("ba") and form pairs.
    • For palindromic words (e.g., "aa"), use as many pairs as possible (even count), and keep track if an odd one can go in the center.

  3. Length Calculation:

    • Each pair contributes 4 characters to the result.
    • If there's one palindromic word left (like one "aa"), it can be placed in the middle, adding 2 to the total length.

? Complexity

  • Time complexity: O(n) Ñ We iterate over all words once and process them in constant time.
  • Space complexity: O(n) Ñ For storing word frequencies.

class Solution {
  int longestPalindrome(List<String> words) {
    Map<String, int> freq = {};
    for (String word in words) {
      freq[word] = (freq[word] ?? 0) + 1;
    }

    int palindromeLength = 0;
    bool hasOddCenteredWord = false;
    Set<String> visited = {};

    for (String word in freq.keys) {
      if (visited.contains(word)) continue;
      String reversed = word[1] + word[0];
      int count = freq[word]!;

      if (word == reversed) {
        palindromeLength += (count ~/ 2) * 4;
        if (count % 2 == 1) hasOddCenteredWord = true;
      } else if (freq.containsKey(reversed)) {
        int pairs = min(count, freq[reversed]!);
        palindromeLength += pairs * 4;
        visited.add(reversed);
      }

      visited.add(word);
    }

    if (hasOddCenteredWord) palindromeLength += 2;
    return palindromeLength;
  }
}
