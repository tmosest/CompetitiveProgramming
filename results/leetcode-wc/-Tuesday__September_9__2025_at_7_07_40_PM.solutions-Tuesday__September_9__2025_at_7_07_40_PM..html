? Problem Breakdown

We are given two traversal arrays of a binary tree:

  • Preorder Traversal ? Root ? Left ? Right
  • Postorder Traversal ? Left ? Right ? Root

We need to reconstruct the original binary tree from these traversals.
Since multiple valid trees may exist, we can return any of them.

Example:

Input:

preorder = [1, 2, 4, 5, 3, 6, 7]  
postorder = [4, 5, 2, 6, 7, 3, 1]

Output:

        1
      /   \
     2     3
    / \   / \
   4   5 6   7

? Approach Overview

? Why is this problem tricky?

  • We don’t have an inorder traversal, which is usually required for unique reconstruction.
  • The same preorder & postorder arrays can represent multiple valid trees.

? Key Idea:

  1. The first element of preorder is always the root.
  2. The second element of preorder is the left child of the root.
  3. Find this left child in postorder to determine the left and right subtree boundaries.
  4. Recursively build the left and right subtrees.

? Why This Approach?

? Utilizes both preorder and postorder efficiently
? O(N) time complexity using recursion
? No need for additional data structures
? Elegant and simple recursive approach

? Complexity Analysis

  • Time Complexity: O(N) ? Each node is processed once.
  • Space Complexity: O(N) ? Recursion stack for tree construction.

? Code Implementation

? Java Solution

class Solution {
    public TreeNode constructFromPrePost(int[] preorder, int[] postorder) {
        int[] index = new int[]{0};
        return construct(preorder, postorder, index, 0, preorder.length - 1);
    }
    private TreeNode construct(int[] preorder, int[] postorder, int[] index, int l, int h){
        if(index[0] >= preorder.length || l > h)
            return null;

        TreeNode root = new TreeNode(preorder[index[0]++]);
        if(l == h) return root;

        int i;
        for(i = l; i <= h; i++){
            if(postorder[i] == preorder[index[0]]) break;
        }
        if(l <= h){
            root.left = construct(preorder, postorder, index, l, i);
            root.right = construct(preorder, postorder, index, i + 1, h - 1);
        }
        return root;
    }
}

? C++ Solution

class Solution {
public:
    TreeNode* constructFromPrePost(vector<int>& pre, vector<int>& post) {
        int index = 0;
        return construct(pre, post, index, 0, pre.size() - 1);
    }
    
private:
    TreeNode* construct(vector<int>& pre, vector<int>& post, int& index, int l, int h) {
        if (index >= pre.size() || l > h) 
            return nullptr;

        TreeNode* root = new TreeNode(pre[index++]);
        if (l == h) return root;

        int i = l;
        while (i <= h && post[i] != pre[index]) i++;

        if (i <= h) {
            root->left = construct(pre, post, index, l, i);
            root->right = construct(pre, post, index, i + 1, h - 1);
        }

        return root;
    }
};

? Python3 Solution

class Solution:
    def constructFromPrePost(self, pre: List[int], post: List[int]) -> Optional[TreeNode]:
        index = [0]  # Mutable index to track preorder position
        return self.construct(pre, post, index, 0, len(pre) - 1)

    def construct(self, pre, post, index, l, h):
        if index[0] >= len(pre) or l > h:
            return None

        root = TreeNode(pre[index[0]])
        index[0] += 1
        if l == h:
            return root

        i = l
        while i <= h and post[i] != pre[index[0]]:
            i += 1

        if i <= h:
            root.left = self.construct(pre, post, index, l, i)
            root.right = self.construct(pre, post, index, i + 1, h - 1)

        return root

? JavaScript Solution

var constructFromPrePost = function(pre, post) {
    let index = 0;
    
    function construct(l, h) {
        if (index >= pre.length || l > h) return null;

        let root = new TreeNode(pre[index++]);
        if (l === h) return root;

        let i = l;
        while (i <= h && post[i] !== pre[index]) i++;

        if (i <= h) {
            root.left = construct(l, i);
            root.right = construct(i + 1, h - 1);
        }

        return root;
    }

    return construct(0, pre.length - 1);
};

Intuition

The problem requires reconstructing a binary tree from its preorder and postorder traversal arrays. The preorder traversal lists the nodes in the order of root, left subtree, and then right subtree, while the postorder traversal lists them in the order of left subtree, right subtree, and then root. My initial thought is to use the properties of these traversals to recursively build the tree: starting with the root from the preorder array and determining the size of the left subtree using the position of its first child in the postorder array.

Approach

  1. Recursive Helper Function:

    • Implement a recursive function (helper) that takes parameters for the current ranges in both preorder and postorder arrays.
    • Base case: If the start index exceeds the end index for preorder, return null (indicating no subtree).

  2. Constructing Nodes:

    • In each recursive call:
      • Create a new TreeNode using the current root value from the preorder array.
      • If there is only one node (i.e., preStart equals preEnd), return this node.
      • Find the index of the left child (the next element in preorder) in the postorder array to determine how many nodes belong to the left subtree.
      • Use this information to make recursive calls for both left and right subtrees.

  3. Return Result:

    • The main function (constructFromPrePost) initializes everything and calls helper to construct and return the entire tree.

class TreeNode {

class Solution {
public:
    TreeNode* constructFromPrePost(vector<int>& preorder, vector<int>& postorder) {
        return helper(preorder, postorder, 0, preorder.size() - 1, 0, postorder.size() - 1);
    }

    TreeNode* helper(vector<int>& preorder, vector<int>& postorder,
                     int preStart, int preEnd,
                     int postStart, int postEnd) {
        if (preStart > preEnd) return nullptr;
        
        TreeNode* node = new TreeNode(preorder[preStart]);
        
        if (preStart == preEnd) return node; // Leaf node
        
        // Find index of left child in postorder
        int leftChildInPostorder = find(postorder.begin() + postStart, postorder.begin() + postEnd + 1, preorder[preStart + 1]) - postorder.begin();
        int leftSubtreeSize = leftChildInPostorder - postStart + 1;
        
        node->left = helper(preorder, postorder,
                             preStart + 1,
                             preStart + leftSubtreeSize,
                             postStart,
                             leftChildInPostorder);
        
        node->right = helper(preorder, postorder,
                              preStart + leftSubtreeSize + 1,
                              preEnd,
                              leftChildInPostorder + 1,
                              postEnd - 1);
        
        return node;
    }
};

Complexity

  • Time complexity: O(n) where n is the number of nodes in the binary tree. Each node is processed once during DFS traversal and once during mapping indices.

  • Space complexity: O(n) due to storing indices of elements from inorder traversal and recursion stack space used during DFS.
