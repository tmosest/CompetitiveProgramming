Intuition

Need to find the next bigger element,
a classical mono stack problem.

Explanation

It iterates through the array from left to right,
using each element as a potential right endpoint (r) for a bowl.

A stack stores indices of elements in decending order of their values.
When a new element A[r] is processed,
the algorithm pops elements from the stack
that are less than or equal to A[r].
Each popped element's index (l) forms a potential bowl with A[r].
If the length of this potential bowl r - l + 1 >= 3, it's counted.

Finally, the algorithm checks if the new element A[r] forms a bowl
with the new top of the stack.
The current index r is then pushed onto the stack.

Complexity

This process efficiently finds all valid "bowl" subarrays
without re-evaluating elements,
as the monotonic stack ensures that
each element is compared and processed correctly only once.

Time O(n)
Space O(n)

    def bowlSubarrays(self, A: List[int]) -> int:
        res = 0
        s = []
        for r, a in enumerate(A):
            while s and A[s[-1]] <= a:
                l = s.pop()
                if r - l + 1 >= 3:
                    res += 1
            if s and r - s[-1] + 1 >= 3:
                res += 1
            s.append(r)
        return res

Problem intuition (Code kya kar raha hai?)

  • Ye function bowlSubarrays(int[] nums) ek array me aise “bowl”-shaped subarrays (minimum 3 length wale) count karta hai jaha:
  • Koi element apne aage ya peeche ek strictly greater element se bound hota hai.
  • Matlab ek subarray ka start ? peak ya end ? peak shape ban raha hai.
  • Socha jaa sakta hai jaise array ke elements ek histogram (bars) hain, aur tumhe check karna hai ki kitni jagah ek “bowl like structure” banta hai.

Key idea

  • Har element ke liye do cheezein nikalni padengi:
  • Next Greater Element (NGE) ? us element ke baad pehli bar jo usse bada element mile.
  • Previous Greater Element (PGE) ? us element ke pehle pehli bar jo usse bada element mile.
  • In dono ka use karke tum decide karte ho ki:
  • start ? nextGreater[start] ek subarray bana sakta hai jisme start ke baad bada element boundary hai.
  • previousGreater[end] ? end ek subarray bana sakta hai jisme end ke pehle bada element boundary hai.
  • Agar subarray length >= 3 hai, toh usse count kar lo.

Step by step flow

  1. findNextGreater(nums)
    • Har index ke liye uske right side pe pehli badi value ka index return karta hai.
    • Ye kaam monotonic stack se hota hai:
      • Stack me decreasing elements ke index store karte ho.
      • Jab bhi current element bada milta hai ? stack ke elements ka NGE current index ban jata hai.

Example:

nums = [2, 1, 4, 3]
NGE array: [2, 2, -1, -1]

  1. findPreviousGreater(nums)

    • Har index ke liye uske left side pe pehli badi value ka index return karta hai.
    • Stack ulta traverse hota hai (right ? left).
    • Same monotonic stack ka logic.

Example:

nums = [2, 1, 4, 3]
PGE array: [-1, 0, -1, 2]

  1. Counting subarrays

    • Har element ke liye check karo:
      • start ? NGE[start] ka length ≥ 3 ? ek bowl ban gaya ? res++
        PGE[end] ? end ka length ≥ 3 ? ek bowl ban gaya ? res++

Visualization (bowl intuition)

Soch lo nums = [2, 1, 4, 3]

Index: 0 1 2 3
Nums: 2 1 4 3

Index 0 (2) ? Next Greater hai index 2 (4), subarray [2,1,4] length 3 ? ek bowl.

Index 1 (1) ? Next Greater hai index 2 (4), subarray [1,4] length 2 ? chhota hai, ignore.

Index 3 (3) ? Previous Greater hai index 2 (4), subarray [4,3] length 2 ? chhota hai, ignore.

Yaha sirf ek hi bowl milta hai.

Intuition summary

Har element ke liye left aur right boundary find karo (using greater elements).

Agar boundary ke beech subarray ki length ≥ 3 hai, toh wo ek valid bowl hai.

Monotonic stack use karke efficient O(n) me Next/Previous Greater nikalte hai

Complexity

  • Time complexity:

O(n)

  • Space complexity:

O(n)

class Solution {
    public long bowlSubarrays(int[] nums) {
        int n = nums.length;
        long res = 0;
        if(n < 3) return res;

        int[] nextGreater = findNextGreater(nums);
        int[] previousGreater = findPreviousGreater(nums);

        for(int start = 0; start < n; start++) {
            int end = nextGreater[start];
            if(end != -1 && (end - start + 1) >= 3) {
                res++;
            }
        }


        for(int end = 0; end < n; end++) {
            int start = previousGreater[end];
            if(start != - 1 && (end - start + 1) >= 3) {
                res++;
            } 
        }

        return res;
    }

    private int[] findNextGreater(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        Arrays.fill(res, -1);
        Stack<Integer> st = new Stack<>();

        for(int i = 0; i < n; i++) {
            while(!st.isEmpty() && nums[st.peek()] < nums[i]) {
                res[st.pop()] = i;
            }
            st.add(i);
        }

        return res;
    }

    private int[] findPreviousGreater(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        Arrays.fill(res, -1);

        Stack<Integer> st = new Stack<>();

        for(int i = n - 1; i >= 0; i--) {
            while(!st.isEmpty() && nums[st.peek()] < nums[i]) {
                res[st.pop()] = i;
            }
            st.add(i);
        }

        return res;
        
    }
}
