? Intuition

1 . Grouping Principle:

  • The problem requires dividing a string into equal-sized groups of length k.
  • If the string length isn't a multiple of k, the last group is padded with a specified character (fill) to reach size k.

2 . Key Insight:

  • The number of groups is determined by ceiling division of the string length by k.
  • Each group is constructed by sequentially picking characters from the string, and padding is applied only when necessary.

? Approach

1 . Calculate Number of Groups:

  • Use integer arithmetic: groups = (n + k - 1) / k to compute the ceiling of n / k without floating-point operations.

2 . Initialize Result Array:

  • Create a String[] of size groups to store the divided strings.

3 . Build Each Group:

  • For each group index i:

    • Initialize a StringBuilder to construct the group.

    • For each position j in the group (0 to k-1):

      • Calculate the index in the original string: index = i * k + j.

      • If index is within bounds, append the character from s.

    • Otherwise, append the fill character (padding).

  • Convert the StringBuilder to a String and store it in the result array.

4 . Return the Result:

  • After processing all groups, return the array of grouped strings.

class Solution {
    public String[] divideString(String s, int k, char fill) {
        int n = s.length();
        int groups = (n + k - 1) / k;
        String[] result = new String[groups];
        
        for (int i = 0; i < groups; i++) {
            StringBuilder group = new StringBuilder();
            for (int j = 0; j < k; j++) {
                int index = i * k + j;
                if (index < n) {
                    group.append(s.charAt(index));
                } else {
                    group.append(fill); // Padding
                }
            }
            result[i] = group.toString();
        }
        
        return result;
    }
}
