? Understanding the Question

  • We're given two integers n (the length of array) and maxi the maximum value.
  • We need to count how many arrays arr of length n satisfy:
    • 1 ≤ arr[i] ≤ maxi for all i
    • arr[i] is divisible by arr[i-1] for every i > 0
  • Return the result modulo 109+7.

? Approach Overview

DP Part:

  • Let dp[v][k] = number of strict divisor-chains of length k ending at value v.
  • Base Case: For all v, dp[v][1] = 1 (chain of length 1).
  • Transition: For each i in [1...maxi], for each multiple j such that i*j ≤ maxi,
for k in [1..m-1]: 
  dp[i*j][k+1] += dp[i][k]
  • Where m = min(n, 14) since no chain longer than 14 is useful due to the limits.

Combinatorics Part:

  • Any chain of length k can be “spread” into an array of length n by choosing which k - 1 of the n - 1 transitions actually occur ? that's (k-1n-1?).
  • Total answer is the sum:
    result=∑v=1maxi?∑k=1m?dp[v][k]·(k-1n-1?)

? Step-wise Explanation

1?? Step 1 ? Mod Power Function

  • This is used to calculate abmodm.
  • It's used in mod inverse in this problem to compute the binomial coefficients.

2?? Step 2 ? Factorial by Memoization

ll fact(ll n) {
        if (n == 0) return 1;
        if (factMemo[n]) return factMemo[n];
        factMemo[n] = (n * fact(n - 1)) % mod;
        return factMemo[n];
    }
  • This function is used to calculate the factorials of numbers.
  • We also use memoization here to avoid recomputing factorials again and again.

3?? Step 3 ? Mod Inv Function

ll mod_inv(ll a, ll b) {
        return (((fact(a) * power(fact(b), mod - 2)) % mod) * power(fact(a - b), mod - 2)) % mod;
    }
  • This function is used to compute the modular inverse of the factorials that we're computing on.

4?? Step 4 ? DP Table

for (int i = 1; i <= maxi; i++) {
    dp[i][1] = 1;
    for (int j = 2; j * i <= maxi; j++)
        for (int k = 1; k < min(n, 14); k++)
            dp[i*j][k+1] += dp[i][k];
}
  • We initialize dp[i][1] = 1 for all i from [1, maxi] because the base case is that each number can start a sequence of length 1.
  • For each i we try all possible multiples using i*j.
  • We update dp[i*j][k+1] using dp[i][k] ? and keep extending our divisor chains or sequences.

? Why up to 14?

  • From the constraints, n ≤ 104, so the maximum number we work with maxi is 104.
  • As we are building strictly increasing divisor chains.
  • The maximum length of such a chain is limited because ?
  • Each number in the chain must be a strict multiple of the previous.
  • So, even in the best case (starting from 1, then 2, then 4, then 8, ...), each step at least doubles the number.
  • That gives a maximum of log2? (104) ≈ 13.3, so the longest possible chain is at most 14.

5?? Step 5 ? Computing Final Result

ll res = 0;
for (int i = 1; i <= maxi; i++)
    for (int j = 1; j <= min(n, 14); j++)
        res = (res + pick(n - 1, j - 1) * dp[i][j]) % mod;
  • For every valid sequence of length j ending at value i, we:
  • Multiply dp[i][j] with how many ways to position j elements in an array of size n: i.e. (j-1n-1?).

???Example Walkthrough

  • For n = 4 and maxi = 6:
    • We want to find how many arrays of length 4 where:
      • Each element ≤ 6
      • For i > 0: arr[i] % arr[i-1] == 0
  • Step 1: Initialize dp[i][1] = 1 for all i in [1, 6]
    • This means arrays of length 1 ending at any number 1 to 6 are valid.
  • Step 2: Build up to length 2 to 4 using multiples
    • For example:
      • For i = 1:
        • j = 2, i*j = 2, update dp[2][2] += dp[1][1]
        • j = 3, i*j = 3, update dp[3][2] += dp[1][1]
        • ... up to i*j ≤ 6
      • For i = 2:
        • j = 2, i*j = 4, update dp[4][2] += dp[2][1]
        • j = 3, i*j = 6, update dp[6][2] += dp[2][1]
      • And so on...
  • Final DP structure :
    • dp[1][1] = 1, dp[2][1] = 1, ... dp[6][1] = 1
    • dp[2][2] = 2 (from 1 and 2), dp[3][2] = 2, dp[4][2] = 2, ...
    • Higher levels like dp[6][3] or dp[4][3] are built similarly.
  • Step 3: Compute total using combinations
    • For each i in [1, 6] and len in [1, 4]:
      • res += dp[i][len] * (len-1n-1?)
      • We use modular inverse + factorials for computing (ba?)
        ? i.e., mod_inv(n - 1, n - len)
  • Example final additions:
    • If dp[2][3] = 3 and n = 4, then:
      • Contribution = 3 * (13?) = 3 * 3 = 9
    • All such values are added to res
  • Final answer is the total modulo 1e9 + 7 from all dp[i][len] * (len-1n-1?)

const int mod = 1e9 + 7;
int factMemo[100000] = {};
int dp[100000][15];
using ll = long long;
class Solution {
public:
ll power(ll a, ll b, ll m = mod) {ll res = 1;while (b > 0) {if (b & 1)res = (res * a) % m;a = (a * a) % m;b = b >> 1;}return res;}
    ll fact(ll n) {
        if (n == 0) return 1;
        if (factMemo[n]) return factMemo[n];
        factMemo[n] = (n * fact(n - 1)) % mod;
        return factMemo[n];
    }
    ll mod_inv(ll a, ll b) {
        return (((fact(a) * power(fact(b), mod - 2)) % mod) * power(fact(a - b), mod - 2)) % mod;
    }

    int idealArrays(int n, int maxi) {
        for (int i = 1; i <= maxi; i++)
            for (int j = 1; j <= min(n, 14); j++)
                dp[i][j] = 0;
        for (int i = 1; i <= maxi; i++) {
            dp[i][1] = 1;
            for (int j = 2; j * i <= maxi; j++)
                for (int k = 1; k < min(n, 14); k++)
                    dp[i*j][k+1] += dp[i][k];
        }
        ll res = 0;
        for (int i = 1; i <= maxi; i++)
            for (int j = 1; j <= min(n, 14); j++)
                res = (res + mod_inv(n - 1, n - j) * dp[i][j]) % mod;
        return res;
    } 
};
