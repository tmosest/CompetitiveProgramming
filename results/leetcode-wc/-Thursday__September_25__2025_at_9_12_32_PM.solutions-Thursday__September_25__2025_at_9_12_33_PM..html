? Equal Sum Grid Partition II — Detailed Explanation

Let's walk through the solution step by step, assuming you’re explaining to a beginner or an interviewer. ?

1. ? Problem Understanding

  • Grid: an m x n matrix of positive integers.

  • Goal: Make one horizontal or vertical cut such that:

    1. Both parts are non-empty.
    2. Their sums are equal, or can be made equal by discounting (removing) one cell from either part.
    3. If you remove a cell, that section must stay connected (4-directionally).

  • Return: true if such a cut exists, else false.

2. ? Intuition & Preprocessing

To enable efficient checking of conditions, we precompute:

  1. rowSum & colSum and totalSum in a single pass:

    • rowSum[i] = sum of row i.
    • colSum[j] = sum of column j.
    • total = sum of all elements.

  2. Track min/max positions for each value ************v:

    • We use Integer[] arrays instead of HashMaps for performance, because v ≤ 10^5.

    • Arrays:

      Integer[] minRow = new Integer[MAXV+1];
Integer[] maxRow = new Integer[MAXV+1];
Integer[] minCol = new Integer[MAXV+1];
Integer[] maxCol = new Integer[MAXV+1];

    • Populate them while reading the grid:

      if (minRow[v] == null) {
  minRow[v] = maxRow[v] = i;
  minCol[v] = maxCol[v] = j;
} else {
  minRow[v] = Math.min(minRow[v], i);
  maxRow[v] = Math.max(maxRow[v], i);
  minCol[v] = Math.min(minCol[v], j);
  maxCol[v] = Math.max(maxCol[v], j);
}

    • This helps determine whether a value v = diff exists and where it lies spatially.

3. ?? Horizontal Cut Logic (Row-Wise)

Loop over i = 0 to n-2 (cut between row i and i+1):

  1. Maintain prefix sum: top += rowSum[i], then bottom = total - top.

  2. If top == bottom ? ? return true.

  3. Else calculate diff = |top - bottom|.

  4. Try to remove a cell with value diff from heavier side:

    • If top > bottom: remove from top segment.
    • If bottom > top: remove from bottom segment.

? Example

Let's take a 2*3 matrix:

[1 2 4]
[2 3 5]

Total sum = 17

Try cut after row 0:

Top half  = [1 2 4] ? sum = 7
Bottom    = [2 3 5] ? sum = 10
Diff = 3

Check if value 3 exists and can be removed from bottom:

  • Yes, 3 is at index (1,1) — middle of row ? ? splitting occurs:
Bottom becomes:
[2]   [5]

This is no longer connected. Hence, not valid.

? How to Check if Cell Can Be Removed

To maintain connectedness:

  • If section has multiple rows and columns: any removal is okay.

  • If only 1 row (like top is row 0), we can only remove cell at either start or end column:

    • i.e., removal allowed only if minCol[diff] == 0 || maxCol[diff] == m - 1 (border check).

  • Similarly, if only 1 column, we check minRow[diff] == 0 || maxRow[diff] == n - 1.

  • If you try to remove a cell from middle, it splits the connected region into two (? not valid).

4. ?? Vertical Cut Logic (Column-Wise)

Loop over j = 0 to m-2:

  1. left += colSum[j], right = total - left

  2. If equal ? ? return true

  3. Else diff = |left - right|

  4. Remove value diff from heavier side if it maintains connectivity:

    • If left side has only 1 column, then check if value diff lies at top or bottom (not in middle!)

? Tabular Example

Try vertical cut after column 0:

Left = [1 3] ? sum = 4
Right = [2 4] ? sum = 6
Diff = 2
  • Value 2 is at (0,1) — top of right segment ? ? border ? allowed.

Same logic follows for vertical cut using columns and minCol/maxCol arrays.

6. ? Time & Space Complexity

  • Time: O(m·n) for grid scan + O(m+n) for all cuts ? Total: O(m·n)

  • Space:

    • O(m + n) for rowSum and colSum
    • O(V) where V = 10^5 for min/max arrays

7. ? Edge Cases Recap

  • Single row or single column ? only border cell removable
  • No matching diff ? return false
  • Removing from middle causes disconnected section ? ? invalid
  • Both sections must be non-etly

class Solution {
    static public boolean canPartitionGrid(int[][] grid) {
        int n = grid.length;
        int m = grid[0].length;

        long totalRowSum = 0L, totalColSum = 0L;
        long[] prefixRowWise = new long[n];
        long[] prefixColWise = new long[m];

        int MAXV = 100000;
        Integer[] minRow = new Integer[MAXV + 1];
        Integer[] maxRow = new Integer[MAXV + 1];
        Integer[] minCol = new Integer[MAXV + 1];
        Integer[] maxCol = new Integer[MAXV + 1];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                int v = grid[i][j];
                long val = v;
                prefixRowWise[i] += val;
                prefixColWise[j] += val;

                if (minRow[v] == null) {
                    minRow[v] = maxRow[v] = i;
                    minCol[v] = maxCol[v] = j;
                } else {
                    if (i < minRow[v]) minRow[v] = i;
                    if (i > maxRow[v]) maxRow[v] = i;
                    if (j < minCol[v]) minCol[v] = j;
                    if (j > maxCol[v]) maxCol[v] = j;
                }
            }
        }

        for (long r : prefixRowWise) totalRowSum += r;
        totalColSum = totalRowSum;

        long currentRowUpperSum = 0L;
        for (int i = 0; i < n - 1; i++) {
            currentRowUpperSum += prefixRowWise[i];
            long lowerSegmentSum = totalRowSum - currentRowUpperSum;
            if (currentRowUpperSum == lowerSegmentSum) return true;
            if (currentRowUpperSum > lowerSegmentSum) {
                long diff = currentRowUpperSum - lowerSegmentSum;
                if (diff <= MAXV && minRow[(int)diff] != null) {
                    if (i == 0 || m == 1) {
                        if (diff == grid[0][0] || diff == grid[0][m - 1] || diff == grid[i][0]) return true;
                    } else if (minRow[(int)diff] <= i) {
                        return true;
                    }
                }
            } else {
                long diff = lowerSegmentSum - currentRowUpperSum;
                if (diff <= MAXV && maxRow[(int)diff] != null) {
                    if (i == n - 2 || m == 1) {
                        if (diff == grid[i + 1][0] || diff == grid[i + 1][m - 1] || diff == grid[n - 1][0]) return true;
                    } else if (maxRow[(int)diff] > i) {
                        return true;
                    }
                }
            }
        }

        long currentColLeftSum = 0L;
        for (int j = 0; j < m - 1; j++) {
            currentColLeftSum += prefixColWise[j];
            long rightSegmentSum = totalColSum - currentColLeftSum;
            if (currentColLeftSum == rightSegmentSum) return true;

            if (currentColLeftSum > rightSegmentSum) {
                long diff = currentColLeftSum - rightSegmentSum;
                if (diff <= MAXV && minCol[(int)diff] != null) {
                    if (j == 0 || n == 1) {
                        if (diff == grid[0][0] || diff == grid[n - 1][0]) return true;
                    } else if (minCol[(int)diff] <= j) {
                        return true;
                    }
                }
            } else {
                long diff = rightSegmentSum - currentColLeftSum;
                if (diff <= MAXV && maxCol[(int)diff] != null) {
                    if (j == m - 2 || n == 1) {
                        if (diff == grid[0][j + 1] || diff == grid[n - 1][j + 1]) return true;
                    } else if (maxCol[(int)diff] > j) {
                        return true;
                    }
                }
            }
        }

        return false;
    }
}

Intuition

  • We need to determine if a 2D grid can be partitioned either horizontally or vertically such that the sums of both parts are equal.
  • If a direct split doesn't work, we check whether moving a single value (diff) from one part to the other could balance the two.
  • We precompute row and column sums and use prefix sums (rowPrefix, colPrefix) to check partition possibilities efficiently.
  • We use maps (rowMap, colMap) to track positions of each unique value in rows and columns to find if a value can be moved.

Approach

  • Let m = number of rows, n = number of columns.
  • Compute:
    • rowSums: total of each row.
    • colSums: total of each column.
    • rowPrefix: prefix sums of rows.
    • colPrefix: prefix sums of columns.
  • Maintain:
    • rowMap: maps each value to the rows it occurs in.
    • colMap: maps each value to the columns it occurs in.
  • Vertical partition check:
    • For each column index j from 1 to n-1:
      • Calculate left = colPrefix[j-1], right = colPrefix[n-1] - left.
      • If equal, return true.
      • Else calculate diff = |left - right|.
      • If left > right, try moving diff from left to right:
        • If only one column on the left (j == 1), check corners directly.
        • Otherwise, use colMap to check if diff exists in left columns.
      • If right > left, try moving diff from right to left:
        • If only one column on the right (j == n-1), check corners.
        • Otherwise, use colMap to check if diff exists in right columns.
  • Horizontal partition check:
    • Repeat the same logic using i and rowPrefix, rowMap.

Edge Cases

  • Grid has only 1 row (m == 1) or 1 column (n == 1):
    • Can't partition further in that dimension but might move one value.
  • When moving a value:
    • Ensure it's not moving into the same region.
    • Make sure its position allows it to actually cross the partition boundary.
  • Only one row or column on one side:
    • Check corners (top-left, bottom-left, etc.) directly for matching diff.

Complexity

  • Time complexity:
    • O(m * n * log K), where K = number of unique values due to TreeSet operations and double traversal.
  • Space complexity:
    • O(K * m + K * n) for rowMap and colMap.

class Solution {
    // Maps to store positions of values by row and column
    HashMap<Long, TreeSet<Integer>> rowMap = new HashMap<>();
    HashMap<Long, TreeSet<Integer>> colMap = new HashMap<>();
    int m, n;
    public boolean canPartitionGrid(int[][] grid) {
        m = grid.length;
        n = grid[0].length;

        long[] rowSums = new long[m];     // Sum of each row
        long[] colSums = new long[n];     // Sum of each column
        long[] rowPrefix = new long[m];   // Prefix sum of rowSums
        long[] colPrefix = new long[n];   // Prefix sum of colSums

        // Step 1: Compute row sums and column sums
        // Also store row positions for each value
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                long val = grid[i][j];
                rowMap.putIfAbsent(val, new TreeSet<>());
                rowMap.get(val).add(i);
                rowSums[i] += val;
                colSums[j] += val;
            }
        }

        // Step 2: Store column positions for each value
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                long val = grid[i][j];
                colMap.putIfAbsent(val, new TreeSet<>());
                colMap.get(val).add(j);
            }
        }

        // Step 3: Compute prefix sums for row and column totals
        rowPrefix[0] = rowSums[0];
        colPrefix[0] = colSums[0];
        for (int i = 1; i < m; i++) rowPrefix[i] = rowPrefix[i - 1] + rowSums[i];
        for (int j = 1; j < n; j++) colPrefix[j] = colPrefix[j - 1] + colSums[j];

        // Step 4: Try vertical partitions (cutting columns)
        for (int j = 1; j < n; j++) {
            long left = colPrefix[j - 1];                // Sum of columns on the left
            long right = colPrefix[n - 1] - left;        // Sum of columns on the right

            if (left == right) return true;              // Equal partition

            long diff = Math.abs(left - right);          // Difference to balance

            if (left > right) {
                if (j == 1) {
                    if (grid[0][0] == diff || grid[m - 1][0] == diff) return true;
                } else if (colMap.containsKey(diff)) {
                    Integer pos = colMap.get(diff).lower(j); // Column < j
                    if (pos != null && (pos == j - 1 || pos == 0 || m != 1)) return true;
                }
            } else {
                if (j == n - 1) {
                    if (grid[0][j] == diff || grid[m - 1][j] == diff) return true;
                } else if (colMap.containsKey(diff)) {
                    Integer pos = colMap.get(diff).higher(j - 1); // Column > j - 1
                    if(m==1 && grid[0][n-1]==diff) return true;
                    if (pos != null && (pos == j || pos == n - 1 || m != 1)) return true;
                }
            }
        }

        // Step 5: Try horizontal partitions (cutting rows)
        for (int i = 1; i < m; i++) {
            long top = rowPrefix[i - 1];                // Sum of rows above
            long bottom = rowPrefix[m - 1] - top;       // Sum of rows below

            if (top == bottom) return true;             // Equal partition

            long diff = Math.abs(top - bottom);

            if (top > bottom) {
                if (i == 1) {
                    if (grid[0][0] == diff || grid[0][n - 1] == diff) return true;
                } else if (rowMap.containsKey(diff)) {
                    Integer pos = rowMap.get(diff).lower(i); // Row < i
                    if (pos != null && (pos == i - 1 || pos == 0 || n != 1)) return true;
                }
            } else {
                if (i == m - 1) {
                    if (grid[i][0] == diff || grid[i][n - 1] == diff) return true;
                } else if (rowMap.containsKey(diff)) {
                    Integer pos = rowMap.get(diff).higher(i - 1); // Row > i - 1
                    if (pos != null && (pos == i || pos == m - 1 || n != 1)) return true;
                }
            }
        }

        return false;
    }
}
