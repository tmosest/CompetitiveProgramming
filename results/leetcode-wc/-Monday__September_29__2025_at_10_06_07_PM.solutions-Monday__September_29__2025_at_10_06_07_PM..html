? Understanding the Problem

  • We're given an n * m array moveTime which represents the time that will be taken to move to a particular room or cell.
  • We can start from room (0, 0) at time t = 0 and we need to find the minimum possible time to reach (n - 1, m - 1), that is, the minimum possible time to reach the bottom right corner of the grid from the top left corner of the grid.
  • Also, moving from one cell to the other costs 1 second.
  • For example : For moveTime = [[0,4],[4,4]],
  • There are basically 2 possible ways here,

  • And as we can see, it takes equal time to reach the bottom right corner from both the ways so picking any one of the ways is optimal here.
  • If we pick Way 1 then, it takes us
    • 4 seconds to reach (0, 1) + 1 second to move + 1 second to move to (n - 1, m - 1)
    • That is, 4 + 1 + 1 = 6
    • So the minimum time required to reach (n - 1, m - 1) is 6.

class Solution {
public:
    int minTimeToReach(vector<vector<int>>& moveTime) {
        int n = moveTime.size(), m = moveTime[0].size();
        vector<vector<int>> dp(n, vector<int>(m, INT_MAX));
        priority_queue<vector<int>, vector<vector<int>>, greater<vector<int>>> minh;
        minh.push({0, 0, 0});
        moveTime[0][0] = 0;

        vector<vector<int>> directions = {{1, 0}, {0, 1}, {-1, 0}, {0, -1}};
        while (!minh.empty()) {
            auto current = minh.top();
            minh.pop();
            int currTime = current[0];
            int currRow = current[1];
            int currCol = current[2];
            if (currTime >= dp[currRow][currCol]) continue;
            if (currRow == n - 1 && currCol == m - 1) return currTime;
            dp[currRow][currCol] = currTime;

            for (auto& direction : directions) {
                int nextRow = currRow + direction[0];
                int nextCol = currCol + direction[1];
                if (nextRow >= 0 && nextRow < n &&
                    nextCol >= 0 && nextCol < m &&
                    dp[nextRow][nextCol] == INT_MAX) {
                    int nextTime = max(moveTime[nextRow][nextCol], currTime) + 1;
                    minh.push({nextTime, nextRow, nextCol});
                }
            }
        }
        return -1;
    }
};

? Intuition

The goal is to reach the bottom-right cell of a grid (n x m) from the top-left while minimizing the total time. Each cell has a moveTime[x][y], which may cause a delay before entering it. A DFS traversal is used to explore all possible paths while pruning longer paths to the same cell.

? Approach

  • Use DFS with backtracking to explore all paths from (0,0) to (n-1,m-1).

  • Maintain a bestTime matrix to store the minimum time taken to reach each cell and prune paths that take more time.

  • At each cell, choose one of the 4 directions (up, right, down, left) and compute the next visit time:

    • If the cell is not yet available (based on its moveTime), wait until it is.
    • For the starting cell, ensure any immediate move accounts for delays.

  • Mark cells as visited/unvisited during recursion to avoid cycles.

Dry Run Example:
Let’s say:

moveTime = [
  [0, 2],
  [1, 3]
]

  • Start at (0,0) at time = 0.

  • From (0,0), options are:

    • Move to (1,0) with wait = 1, time = 1 ? time + 1 = 2.
    • Move to (0,1) with wait = 2, must wait till 2, then time = 3.

Track the minimum of all such paths to reach (1,1).

?? Complexity

  • Time complexity: O(n * m * 4^k) in worst-case due to DFS (where k is the number of steps in a path), but effective pruning via bestTime reduces redundant paths.
  • Space complexity: O(n * m) for both visited and bestTime matrices.

class Solution {
  int minTimeToReach(List<List<int>> moveTime) {
    int n = moveTime.length;
    int m = moveTime[0].length;
    List<List<bool>> visited = List.generate(n, (_) => List.filled(m, false));
    
    List<List<int>> bestTime = List.generate(n, (_) => List.filled(m, 1 << 30));
    List<List<int>> dir = [
      [-1, 0],
      [0, 1],
      [1, 0],
      [0, -1]
    ];
    
    int ans = 1 << 30;

    void _helper(int i, int j, int time) {
      // Prune worse paths
      if (time >= bestTime[i][j]) return;
      bestTime[i][j] = time;

      if (i == n - 1 && j == m - 1) {
        ans = min(ans, time);
        return;
      }

      for (List<int> d in dir) {
        int x = i + d[0];
        int y = j + d[1];
        if (x >= 0 && x < n && y >= 0 && y < m && !visited[x][y]) {
          visited[x][y] = true;
          int wait = moveTime[x][y];
          int nextTime = wait > time ? wait + 1 : time + 1;
          if (i == 0 && j == 0 && wait <= time) {
            nextTime = 1 + wait;
          }
          _helper(x, y, nextTime);
          visited[x][y] = false;
        }
      }
    }

    visited[0][0] = true;
    _helper(0, 0, 0);
    return ans;
  }
}

? Intuition & Approach

  • We represent the dungeon as a grid graph: each cell (i,j) is a node.
  • Cost to enter (i,j) = 1s (move) plus wait until moveTime[i][j] if current time+1 < moveTime[i][j].
  • Dijkstra’s algorithm with a min-heap (PriorityQueue<Pair>) finds the minimum arrival time to each cell.

? Step-by-Step Explanation (Code)

  1. Setup

    int r = moveTime.length, c = moveTime[0].length;
int[][] minimumTime = new int[r][c];
for (int[] row : minimumTime)
    Arrays.fill(row, Integer.MAX_VALUE);
PriorityQueue<Pair> pq = new PriorityQueue<>((a,b) -> a.steps - b.steps);
minimumTime[0][0] = 0;
pq.add(new Pair(-1, 0, 0));

  2. Main Loop with Early Exit

    while (!pq.isEmpty()) {
    Pair top = pq.poll();
    int i = top.i, j = top.j;
    int nextStep = top.steps + 1;

    // Explore neighbors
    if (i + 1 < r) update(i+1, j, pq, nextStep, moveTime, minimumTime);
    if (i - 1 >= 0) update(i-1, j, pq, nextStep, moveTime, minimumTime);
    if (j + 1 < c) update(i, j+1, pq, nextStep, moveTime, minimumTime);
    if (j - 1 >= 0) update(i, j-1, pq, nextStep, moveTime, minimumTime);

    // Early exit optimization
    if (minimumTime[r-1][c-1] != Integer.MAX_VALUE)
        return minimumTime[r-1][c-1] + 1;
}
return minimumTime[r-1][c-1] + 1;
    • Because we use a min-heap, the first time we set minimumTime[n-1][m-1] is guaranteed to be the smallest possible arrival time.
    • We can break/return immediately, pruning any further unnecessary exploration.

  3. update Helper

    static void update( ... ) {
    // if we arrive before the room is available, wait
    if (nextStep < moveTime[i][j])
        nextStep = moveTime[i][j];
    // only proceed if this path improves our best known time
    if (minimumTime[i][j] > nextStep) {
        minimumTime[i][j] = nextStep;
        pq.add(new Pair(nextStep, i, j));
    }
}

class Solution {
   static public int minTimeToReach(int[][] moveTime) {
        int r = moveTime.length, c = moveTime[0].length;
        int[][] minimumTime = new int[r][c];
        for (int[] is : minimumTime) {
            Arrays.fill(is, Integer.MAX_VALUE);
        }

        PriorityQueue<Pair> pq = new PriorityQueue<>((a, b) -> a.steps - b.steps);
        pq.add(new Pair(-1, 0, 0));
        minimumTime[0][0] = 0;

        while (!pq.isEmpty()) {
            Pair top = pq.poll();
            int i = top.i, j = top.j, nextStep = top.steps + 1;
            if (i + 1 < r) update(i + 1, j, pq, nextStep, moveTime, minimumTime);
            if (i - 1 >= 0) update(i - 1, j, pq, nextStep, moveTime, minimumTime);
            if (j - 1 >= 0) update(i, j - 1, pq, nextStep, moveTime, minimumTime);
            if (j + 1 < c)  update(i, j + 1, pq, nextStep, moveTime, minimumTime);
            if(minimumTime[r-1][c-1] != Integer.MAX_VALUE) return minimumTime[r-1][c-1] + 1;
        }
        return minimumTime[r-1][c-1] + 1;
    }

    static void update(int i, int j, PriorityQueue<Pair> pq, int nextStep, int[][] moveTime, int[][] minimumTime){
        if (nextStep < moveTime[i][j]) nextStep = moveTime[i][j];
        if (minimumTime[i][j] > nextStep) {
            pq.add(new Pair(nextStep, i, j));
            minimumTime[i][j] = nextStep;
        }
    }

}

class Pair {
    int steps = 0, i = -1, j = -1;

    public Pair(int steps, int i, int j) {
        this.steps = steps;
        this.i = i;
        this.j = j;
    }
}

? Intuition

The task is to reach the bottom-right cell of a grid, where each cell has a minimum time constraint for entering it. This resembles Dijkstra's algorithm where edge weights depend dynamically on arrival time — a priority queue ensures we always process the shortest-time path first. ??

? Approach

  • Use Dijkstra's algorithm with a min-heap (priority queue).
  • Each cell has a minimum required arrival time moveTime[i][j], so we wait there until curr_time ≥ moveTime[i][j].
  • On moving to a neighbor, update its time as max(curr_time, moveTime[nrow][ncol]) + 1.
  • Track the shortest time to each cell with a 2D distance array.
  • Return once the bottom-right corner is reached.

? Complexity

  • Time complexity: O(m·n·log(m·n)) — each cell is pushed to the priority queue possibly once.
  • Space complexity: O(m·n) — for the distance matrix and priority queue.

class Solution {
public:
    int minTimeToReach(vector<vector<int>>& moveTime) {
        int m = moveTime.size(), n = moveTime[0].size();

        priority_queue<pair<int, pair<int, int>>, vector<pair<int, pair<int, int>>>, greater<>> pq;
        pq.push({0, {0, 0}});

        vector<vector<int>> dis(m, vector<int>(n, INT_MAX));
        dis[0][0] = 0;

        int dir[5] = {-1, 0, 1, 0, -1};

        while (!pq.empty()) {
            auto [curr, pos] = pq.top(); pq.pop();
            int row = pos.first, col = pos.second;

            if (row == m - 1 && col == n - 1)
                return curr;

            for (int i = 0; i < 4; i++) {
                int nrow = row + dir[i], ncol = col + dir[i + 1];
                if (nrow >= 0 && ncol >= 0 && nrow < m && ncol < n) {
                    int nextTime = max(curr, moveTime[nrow][ncol]) + 1;
                    if (nextTime < dis[nrow][ncol]) {
                        dis[nrow][ncol] = nextTime;
                        pq.push({nextTime, {nrow, ncol}});
                    }
                }
            }
        }

        return -1;
    }
};
