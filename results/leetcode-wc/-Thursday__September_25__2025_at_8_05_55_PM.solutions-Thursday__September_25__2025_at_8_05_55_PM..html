Explanation

Find the longest increasing prefix subarray.
If the A is strict increasing,
return n * (n + 1) / 2.

The check the all increasing suffix array one elment by one element,
and find out the longest smaller increasing prefix by moving the pointer i.

Complexity

Time O(n)
Space O(1)

Java

    public long incremovableSubarrayCount(int[] A) {
        int n = A.length, i = 0;
        while (i + 1 < n && A[i] < A[i + 1]) {
            i++;
        }
        if (i == n - 1) {
            return n * (n + 1) / 2;
        }
        long res = i + 2;
        for (int j = n - 1; j >= 0; j--) {
            if (j < n - 1 && A[j] >= A[j + 1]) {
                break;
            }
            while (i >= 0 && A[i] >= A[j]) {
                i--;
            }
            res += i + 2;
        }
        return res;
    }

Intuition

There are two steps involved in solving this problem:

  1. Since we are removing a subarray from the array, the smallest subarray we must always remove will be the one which leaves an increasing left subarray and increasing right subarray. We can use two pointers and simple traversals to find our anwer here.

    • Example: [1, 2, 3, 4, 3, 9, 8, 1, 6, 7, 8] in this case the left increasing subarray is [1, 2, 3, 4] and right increasing subarray is [1, 6, 7, 8]. Inclusion of 3 in a solution containing left subarray will invalidate the answer and similarily inclusion of 8 in right subarray will as well. Thus all of anwers must at minimum remove [3, 9, 8].

  2. Then for each element on the left subarray we must find the smallest subarray starting from that element which must be removed to form an increasing array. All subarrays greater than this one are our answers as well. We can use upper bound binary search to find our anwer here.

    • Example: [1, 2, 3, 4, 3, 9, 8, 1, 6, 7, 8] consider 1 in the left subarray. We will apply binary search on [1, 6, 7, 8] to find first element larger than 1. Thus we get 6. Meaning, If we start our subarray from 2 then it must atleast go on till 1 to leave an increasing sequence behind. There can be total four such arrays that start from 2.

  3. In above step we have considered all subarrays that start after 1 but not those which also contain 1. These subarrays will be equal to the number of elements in right increasing subarray plus 1 (for the whole array).

Small Optimization: If our whole array is increasing we can simply return n * (n + 1)/2 as answer as it is the number of all unique possible subarrays.

Approach

Traverse from left carrying and index and prev pointer. When index is smaller than or equal to prev we stop and prev is the last element of our left increasing subarray.

If we reach the end then return n * (n + 1)/2.

Similarily traverse from right and perform the operation in reverse to find the first element of our right increasing subarray.

Now for every element in the left increasing subarray we will find its upper bound in the right increasing subarray. For each element we will add to ans this nums.length - val + 1 as it is the number of possible subarrays from that element.

In the end we add nums.length - r + 1 to aur answer to account for all subarrays stating from 0th index.

Complexity

  • Time complexity: O(NlogN)
    N to traverse through left increasing subarray and we perform binary search at each element for logN
  • Space complexity: O(1) Extra space taken

class Solution {
    public long incremovableSubarrayCount(int[] nums){
        int l = 0, r = nums.length-1;
        int idx = 1;
        while(idx < nums.length && nums[l] < nums[idx]){
            idx++;
            l++;
        }
        if(idx == nums.length){
            return nums.length*(nums.length+1)/2;
        }
        idx = nums.length-2;
        while(idx > 0 && nums[r] > nums[idx]){
            idx--;
            r--;
        }
        long ans = 0;
        for(int i = 0; i <= l; i++){
            int val = bs(nums, r, nums.length-1, nums[i]);
            val = nums.length - val + 1;
            ans = ans + val;
        }
        ans = ans + nums.length - r + 1;
        return ans;
    }

    public int bs(int[] nums, int l, int r, long x){
        int ans = -1;
        while(l <= r){
            int mid = (l+r)/2;
            if(nums[mid] <= x){
                l = mid+1;
            }else{
                ans = mid;
                r = mid-1;
            }
        }
        if(ans == -1) return nums.length;
        return ans;
    }


}

Approaches

(Also explained in the code)

  1. Finding the First Increasing Sequence:
    • Move the pointer 'r' until the elements are in increasing order.
    • If the entire array is in increasing order, return the count of all possible subarrays.
  2. Iterating Backward:
    • Traverse the array backward and find the count of "incremovable" subarrays.
    • Use binary search to find the position of the current element in the increasing sequence.
    • Increment the count based on the position found.
  3. Return the Total Count: Return the total count of "incremovable" subarrays.

Complexity

  • Time complexity:
    O(nlogr)

  • Space complexity:
    O(1)

class Solution {
public:
    long long incremovableSubarrayCount(vector<int>& nums) {
        long long ans = 1;  // Initialize the count with 1 (single element is always "incremovable")
        int r = 1;          // Initialize a pointer r to 1
        int n = nums.size(); // Get the size of the input vector

        // Move the pointer r until elements are in increasing order
        while (r < n && nums[r] > nums[r - 1]) {
            r++;
        }

        // If the entire array is in increasing order, return the count of all possible subarrays
        if (r == n) {
            return 1LL * n * (n + 1) / 2;
        }

        int lst = 1e9 + 1; // Set a large initial value for 'lst' (to ensure comparison with first element)
        ans += r;          // Increment the count by the current value of pointer r

        // Iterate through the array from the end to count "incremovable" subarrays
        for (int i = n - 1; i >= 0; i--) {
            if (nums[i] >= lst) { // If the current element is greater than or equal to 'lst', break the loop
                break;
            }
            int low = 0, high = r - 1; // Initialize pointers for binary search
            int left = -1; // Initialize 'left' to -1

            // Binary search to find the position of the current element in the increasing sequence
            while (low <= high) {
                int mid = (low + high) >> 1; // Calculate mid index
                if (nums[mid] < nums[i]) {
                    left = mid; // Update 'left' if the current element is greater
                    low = mid + 1; // Adjust the search range
                } else {
                    high = mid - 1; // Adjust the search range
                }
            }

            ans += (left + 2); // Increment the count by (left + 2)
            lst = nums[i]; // Update 'lst' with the current element
        }
        return ans; // Return the total count of "incremovable" subarrays
    }
};
