class Solution {
    public String makeFancyString(String s) {
        char[] chars = s.toCharArray();
        char last = chars[0];
        int count = 1;
        int pos = 1;

        for (int i = 1; i < chars.length; i++) {
            if (chars[i] != last) {
                last = chars[i];
                count = 0;
            }

            if (++count > 2) continue;

            chars[pos++] = chars[i];
        }

        return new String(chars, 0, pos);
    }
}

? Problem Breakdown – What Are We Solving?

You're given a string s, and your task is to delete the fewest number of characters so that no character appears 3 times in a row.

? In short: "No three consecutive letters should be the same."

? Allowed: "aab", "abb", "cc"

? Not Allowed: "aaa", "bbbb", "eeeff"

Return the resulting fancy string, which is guaranteed to be unique after deletion.

? Core Insight – When to Delete?

If you are iterating through each character, you only need to look back at the previous two characters in your result so far.

If both previous characters are the same as the current one ? skip it (to avoid three in a row).

Otherwise ? keep it.

You don’t need to go back further or check the whole string again — this local pattern check is enough!

? Why This Works?

The key idea is that no fancy string can have 3+ repeated chars in a row. So:

2 same characters are fine ? keep both.

When a third same character comes ? we must skip it.

We greedily include only when safe, and this gives us the longest fancy string with minimal deletions.

#include <stdlib.h>
#include <string.h>

char* makeFancyString(char* s) {
    int len = strlen(s);
    if (len == 0) {
        return s;
    }
    
    char* result = (char*)malloc((len + 1) * sizeof(char));
    int resultIndex = 0;
    
    for (int i = 0; i < len; i++) {
        if (resultIndex >= 2 && result[resultIndex - 1] == s[i] && result[resultIndex - 2] == s[i]) {
            continue;
        }
        result[resultIndex++] = s[i];
    }
    result[resultIndex] = '\0';
    
    return result;
}
