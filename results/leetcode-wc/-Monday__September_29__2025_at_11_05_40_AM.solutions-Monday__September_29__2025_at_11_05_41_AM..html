Intuition

We will force certain positions in the result string according to the requirements of the T type constraints, and for the remaining positions, we initially assign the smallest character (e.g., 'a').
Then, for each F type constraint, we check if the subarray of size m corresponding to it is equal to str2 Ð that is, whether the positions in that subarray (either forced by T constraints or assigned by default) create a string identical to str2.
If it does (i.e., violates the F constraint), we need to fix it by changing a non-forced position in that subarray so that the value at that position is different from the corresponding character in str2

Approach

1. Initialize the result string:

Create a string word of length n (the length of str1), initially assigning all characters to a (the smallest character).

2. Process T constraints:

Iterate through str1:

  • If str1[i] = 'T', this means word[i...i+m-1] must be equal to str2. Assign word[i+j] = str2[j] for j from 0 to m-1
  • If there is a conflict (e.g., word[i+j] has already been assigned a different value than str2[j]), return an empty string (no solution).

3. Process F constraints:

Iterate through str1:

  • If str1[i] = 'F', this means word[i...i+m-1] must not be equal to str2. Check if word[i...i+m-1] is equal to str2
  • If it is, find the last free position (not forced by a T constraint) in word[i...i+m-1]. Change the character at that free position to b (the smallest character other than a)

4. Return the result:

Return the string word after processing all constraints

class Solution:
    def generateString(self, str1: str, str2: str) -> str:
        n = len(str1)
        m = len(str2)
        L = n + m - 1  
        
        word = [None] * L
        forced = [False] * L
        
        for i in range(n):
            if str1[i] == 'T':
                for j in range(m):
                    pos = i + j
                    if word[pos] is not None and word[pos] != str2[j]:
                        return ""
                    word[pos] = str2[j]
                    forced[pos] = True
        
        free = [False] * L
        for i in range(L):
            if word[i] is None:
                word[i] = 'a'
                free[i] = True
        
        def interval_equals(i: int) -> bool:
            for j in range(m):
                if word[i + j] != str2[j]:
                    return False
            return True
        
        for i in range(n):
            if str1[i] == 'F':
                if interval_equals(i):
                    fixed = False
                    for j in range(m - 1, -1, -1):
                        pos = i + j
                        if free[pos]:
                            word[pos] = 'b'
                            free[pos] = False  
                            fixed = True
                            break
                    if not fixed:
                        return ""
        
        return "".join(word)
