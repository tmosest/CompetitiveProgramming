class Solution(object):
    def mostPoints(self, questions):
        dp = [0] * len(questions)
        for i in range(len(questions) - 1, -1, -1):
            index = i + questions[i][1] + 1
            if index < len(questions):
                dp[i] = dp[index] + questions[i][0]
            else:
                dp[i] = questions[i][0]
            if i < len(questions) - 1:
                dp[i] = max(dp[i + 1], dp[i])
        return dp[0]

Intuition

The problem requires us to determine the maximum points we can earn while adhering to the constraints of brainpower usage. Since each question either contributes points or allows us to skip, this is a typical dynamic programming problem where the optimal substructure property holds.

We need to decide at each step whether to take the current question (and skip the next few due to brainpower usage) or to skip it and move to the next question.

Approach

  • Define an array dp, where dp[i] stores the maximum points we can earn starting from question i.
  • Traverse the questions array in reverse order (bottom-up DP).
  • For each question at index i:
    • Option 1: Take the current question and move to the next allowed question (i + brainpower + 1).
    • Option 2: Skip the current question and move to i + 1.
    • Store the maximum of these two choices in dp[i].
  • The final result will be stored in dp[0], representing the maximum points from the beginning.

Complexity Analysis

  • Time Complexity: (O(n)), since we iterate through the questions array once.
  • Space Complexity: (O(n)), for storing results in the dp array (can be optimized to (O(1)) with a rolling variable approach).

class Solution {
  int mostPoints(List<List<int>> questions) {
    int n = questions.length;
    List<int> dp = List.filled(n + 1, 0);

    for (int i = n - 1; i >= 0; i--) {
      int points = questions[i][0];
      int brainpower = questions[i][1];
      int next = i + brainpower + 1;

      int take = points + (next < n ? dp[next] : 0);
      int skip = dp[i + 1];

      dp[i] = take > skip ? take : skip;
    }

    return dp[0];
  }
}
