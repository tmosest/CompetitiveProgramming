Problem: Minimum Operations to Make Array Zero

Given an array nums, in each operation, we can choose a positive integer and replace all of its occurrences in nums with 0, if and only if there is no smaller element between any two of its occurrences.

Our goal is to minimize the number of such operations to make the entire array zero.

? Sparse Tree Visualization (Intuition)

Let us understand using the example:

Input: [2, 3, 1, 2, 3, 2]

Total = 5 operations ?

? Intuition

We can remove all occurrences of a number x in one operation if between any two occurrences of x, there is no smaller number than x.

? If such a smaller number exists between x's positions, then you must split and handle the segments separately.

We could do this with Segment Trees, but it becomes complicated.

? Optimized Approach: Monotonic Increasing Stack

We simplify the problem using a greedy approach with a monotonic increasing stack.

? Key Idea:

  • Keep pushing elements into a stack.
  • If we encounter a smaller element, pop all elements greater than it (they can't be part of the same valid group).
  • Use a boolean array isNumEncountered to track whether a number is already seen in the current group.
  • If a number hasn't been seen in the current group ? increase ans ?

? Dry Run on [2, 3, 1, 2, 3, 2]

We maintain:

  • stack = Monotonic increasing values
  • isNumEncountered[] = To check if current value is already active
  • ans = Count of operations

class Solution {
    public static int minOperations(int[] nums) {
        int n = nums.length;
        int ans = 0;
        boolean[] isNumEncountered = new boolean[100001];
        int[] monoStack = new int[n];
        int size = 0;

        for (int i = 0; i < n; i++) {
            int curr = nums[i];

            if (curr == 0) {
                while (size > 0) {
                    isNumEncountered[monoStack[--size]] = false;
                }
                continue;
            }

            while (size > 0 && monoStack[size - 1] > curr) {
                isNumEncountered[monoStack[--size]] = false;
            }

            if (!isNumEncountered[curr]) {
                ans++;
                isNumEncountered[curr] = true;
            }

            monoStack[size++] = curr;
        }

        return ans;
    }
}

? Time and Space Complexity

  • ? Time Complexity: O(n)
    ? Each number is pushed/popped at most once.
  • ? Space Complexity: O(n)
    ? Stack + boolean lookup array.

? Summary

  • Break the problem into valid segments using the minimum number rule.

  • Either recurse by splitting segments or use a monotonic increasing stack.

  • Stack-based method is linear and elegant.

  • Whenever a new element is pushed, check if it's seen already:

    • ? If not seen, increment operations.
    • ? If already seen in current stack, skip it.
