class Solution {
    public int getMaxRepetitions(String s1, int n1, String s2, int n2) {
        int[] next = new int[s2.length() + 1];
        int[] count = new int[s2.length() + 1];
        int j = 0, cnt = 0;
        for (int k = 1; k <= n1; k++) {
            for (int i = 0; i < s1.length(); i++) {
                if (s1.charAt(i) == s2.charAt(j)) {
                    j++;
                    if (j == s2.length()) {
                        j = 0;
                        cnt++;
                    }
                }
            }
            count[k] = cnt;
            next[k] = j;
            for (int start = 0; start < k; start++) {
                if (next[start] == j) {
                    int prefixCount = count[start];
                    int patternCount = (count[k] - count[start]) * ((n1 - start) / (k - start));
                    int suffixCount = count[start + (n1 - start) % (k - start)] - count[start];
                    return (prefixCount + patternCount + suffixCount) / n2;
                }
            }
        }
        return count[n1] / n2;
    }
}

. If we have, then we've found a repeating pattern
. The number of times we see s2 in the pattern is (count[k] - count[start])
. The number of times we see s2 outside the pattern is (count[start + (n1 - start) % (k - start)] - count[start])
. The number of times we see s2 in total is (prefixCount + patternCount + suffixCount)

class Solution {
    public int getMaxRepetitions(String A, int a, String B, int b) {
        int m = A.length(), n = B.length();
        int[][] x = new int[m][n];
        int[][] y = new int[m][n];
        for (int i = 1, j = 1; true; i++){
            int ii = i%m, jj = j%n, xx = x[ii][jj], yy = y[ii][jj];
            x[ii][jj]=i;
            y[ii][jj]=j;
            if (xx > 0){ // ultra jump to the end!
                int k = (a*m-i)/(i-xx);
                i += k*(i-xx);
                j += k*(j-yy);
            }
            if (i == a*m){ // reached the end
                return j/(n*b);
            }
            if (A.charAt(ii)==B.charAt(jj)){ // subsequence check
                j++;
            }
        }
    }
}

public class Solution {
    public int getMaxRepetitions(String s1, int n1, String s2, int n2) {
        int n = s1.length();
        int m = s2.length();
        if(n * n1 < m * n2) return 0;
        int[][] dp = new int[s2.length()][2];
        
        for(var v : dp) Arrays.fill(v, -1);

        int s1count = 0;
        int s2count = 0;
        int s1idx = 0;
        int s2idx = 0;
        while(s1count < n1){
            s1count++;
            for(char ch : s1.toCharArray()){
                if(ch == s2.charAt(s2idx)){
                    s2idx++;
                    if(s2idx == s2.length()){
                        s2idx = 0;
                        s2count++;
                    }
                }
            }

            if(dp[s2idx][0] != -1){
                int prevs1count = dp[s2idx][0];
                int prevs2count = dp[s2idx][1];

                int cyclelength = s1count - prevs1count;
                int cyclecount = (n1 - s1count) / cyclelength ;

                s1count += cyclecount * cyclelength;
                s2count += cyclecount *(s2count - prevs2count);

            }

            dp[s2idx][0] = s1count;
            dp[s2idx][1] = s2count;
        }
        return s2count / n2;
    }
}

Intuition

To solve this problem, we need to determine how many times we can form the string str2 from str1. Given the constraints of the problem, we must find an efficient way to simulate the formation of str2 from repeated sequences of s1. One way to achieve this is by tracking how many times characters from s2 can be matched within the repeated sequences of s1. By recognizing patterns and cycles, we can significantly reduce the number of iterations required to find the solution.

Approach

Initialize Counters and State Tracking:

Use counters s1Count and s2Count to keep track of how many times we have iterated through s1 and fully matched s2, respectively.
Use s2Index to track the current position in s2 that we are trying to match with characters from s1.
Use a map (recall) to store the state (s2Index) and corresponding counts (s1Count, s2Count) to detect cycles.
Simulate Matching:

Iterate through s1 and try to match characters with s2 using the s2Index.
If a character from s1 matches the current character from s2 (pointed by s2Index), move s2Index to the next character.
If s2Index reaches the end of s2, increment s2Count and reset s2Index to zero.
Cycle Detection:

After processing each repetition of s1, check if the current state (s2Index) has been seen before using the map.
If a state is repeated, a cycle is detected. Calculate the number of full cycles that can fit into the remaining repetitions of s1 and adjust s1Count and s2Count accordingly.
If the state is new, store the current state in the map.
Calculate Result:

Finally, compute the number of complete [s2, n2] repetitions that can be formed from the total s2Count.

Complexity

  • Time complexity:

Time complexity: O(n1ás1.length())
In the worst case, we might need to iterate through the entire string s1 up to n1 times. Each iteration involves traversing the length of s1, leading to the time complexity.

  • Space complexity:

Space complexity: O(s2.length())
The space complexity is determined by the size of the map recall, which can store up to s2.length() unique states (s2Index values).

import java.util.HashMap;
import java.util.Map;
class Solution {
    public int getMaxRepetitions(String s1, int n1, String s2, int n2) {
        if (n1 == 0) return 0;
        int s1Count = 0, s2Count = 0, s2Index = 0;
        Map<Integer, int[]> recall = new HashMap<>();
        while (s1Count < n1) {
            for (int i = 0; i < s1.length(); i++) {
                if (s1.charAt(i) == s2.charAt(s2Index)) {
                    s2Index++;
                    if (s2Index == s2.length()) {
                        s2Count++;
                        s2Index = 0;
                    }
                }
            }
            s1Count++;
            if (recall.containsKey(s2Index)) {
                int[] previous = recall.get(s2Index);
                int prevS1Count = previous[0];
                int prevS2Count = previous[1];
                
                int cycleLength = s1Count - prevS1Count;
                int cycleS2Count = s2Count - prevS2Count;
                
                int remainingCycles = (n1 - s1Count) / cycleLength;
                
                s1Count += remainingCycles * cycleLength;
                s2Count += remainingCycles * cycleS2Count;
            } else {
                recall.put(s2Index, new int[]{s1Count, s2Count});
            }
        }
        return s2Count / n2;
    }
}

    //          ^

    // aaa  x2     aa  === 3 times
    // aaba x2     aa  === 3 times

    // AabA aAba Aaba
    //           ^
    // again match s1[0] == s2[0]
    // so for every 2 s1 we find 3 s2

    // Instead of looping blindly N1 times over S1, we want to find patterns (substring that repeats)
    // Then next time we find the PATTERN, we skip over it and cnt += numS2InPattern

    // To find pattern, record the mapping s1[x] == x2[y] the SECOND TIME the same match happens, the PATTERN ENDS!
    // it started at the FIRST MATCH!
    public int getMaxRepetitions(String s1, int n1, String s2, int n2) {
        int i = 0, j = 0;
        int s1N = s1.length();
        int s2N = s2.length();
        int cnt = 0;
        int[][] s2ToS1ToLastPatternEnd = new int[s2N][s1N];
        int[][] s2ToS1ToLastPatternCnt = new int[s2N][s1N];
        for (int k = 0; k < s2N; k++) Arrays.fill(s2ToS1ToLastPatternEnd[k], -1);
        int maxChars = n1 * s1N;
        for (; i < maxChars; i++) {
            int x = i % s1N;
            int y = j % s2N;
            char c1 = s1.charAt(x);
            char c2 = s2.charAt(y);

            // acb acb acb acb        ab
            if (c1 == c2) {
                if (y == s2N - 1) cnt++;
                int pLen = i - s2ToS1ToLastPatternEnd[y][x];

                if (s2ToS1ToLastPatternEnd[y][x] != - 1 && i + pLen < maxChars) { // pattern found again! enough chars to match all of it
                    cnt += cnt - s2ToS1ToLastPatternCnt[y][x];
                    i += pLen;
                }
                s2ToS1ToLastPatternEnd[y][x] = i; // pattern end
                s2ToS1ToLastPatternCnt[y][x] = cnt; // cnt at pattern end
                j++;
            }
        }

        return cnt / n2;
    }

class Solution {
    public int getMaxRepetitions(String s1, int n1, String s2, int n2) {
        int[] next = new int[s2.length() + 1];
        int[] count = new int[s2.length() + 1];
        int j = 0, cnt = 0;
        for (int k = 1; k <= n1; k++) {

                    return (prefixCount + patternCount + suffixCount) / n2;
                }
            }
        }
        return count[n1] / n2;
    }

        start = {}
        s1_round, s2_round, s2_idx = 0, 0, 0
        while s1_round < n1:
            s1_round += 1
