Intuition

To make a string alternating, we need to flip the characters at specific positions. The key is to observe that there are two possibilities for the starting character: '0' or '1'. We need to count the number of operations needed to make the string alternating starting with '0' and '1', and then return the minimum of these two counts.

Approach

  1. Initialize two counts: count1 for starting with '0' and count2 for starting with '1'.
  2. Use the count function to count the number of operations needed for each starting character. This function takes the string s and the previous character c_pre and returns the count of operations needed.
  3. Compare count1 and count2 and return the minimum of the two.

Complexity

  • Time complexity: The time complexity is O(n), where n is the length of the input string.
  • Space complexity: The space complexity is O(1) as we are using a constant amount of space.

class Solution {
    public int minOperations(String s) {
        char c_0 = s.charAt(0);
        int count1 = count(s, c_0);
        int count2 = count(s, c_0=='0'?'1':'0')+1;
        return Math.min(count1, count2);
    }

    private int count(String s, char c_pre){
        int count = 0;
        for(int i=1; i<s.length(); i++){
            char current = s.charAt(i);
            if(current==c_pre){
                count++;
                c_pre = c_pre == '0' ? '1' : '0';
            }else{
                c_pre = current;   
            }
        }
        return count;
    }
}

Approach

  1. Initialize Counters:

    • Create two counters: countForAlternate0 and countForAlternate1 to track the number of changes needed for two possible alternating patterns:
      • countForAlternate0: Counts changes for making the string start with 0 and alternate with 1s.
      • countForAlternate1: Counts changes for making the string start with 1 and alternate with 0s.

  2. Iterate Through String:

    • Iterate through each character in the string:
      • If the index is even:
        • If the character is '0', increment countForAlternate1 (need to change to 1).
        • If the character is '1', increment countForAlternate0 (need to change to 0).
      • If the index is odd:
        • If the character is '0', increment countForAlternate0 (already a 0, no need to change).
        • If the character is '1', increment countForAlternate1 (already a 1, no need to change).

  3. Find Minimum Operations:

    • After the loop, return the minimum value between countForAlternate0 and countForAlternate1, representing the minimum operations required to make the string alternating.

  4. Key Idea:

    • The code exploits the fact that there are only two possible alternating patterns.
    • It efficiently tracks the changes needed for both patterns simultaneously and chooses the one with the least operations.

  5. Time and Space Complexity:

    • Time complexity: O(n), where n is the length of the string, as it iterates through the string once.
    • Space complexity: O(1), as it uses a constant amount of extra space for the counters.

class Solution {
public:
    int minOperations(string s) {
        int countForAlternate0 = 0;
        int countForAlternate1 = 0;
        
        for (int i = 0; i < s.size(); i++) {
            if (i % 2 == 0) {
                if (s[i] == '0') {
                    countForAlternate1++;
                } else {
                    countForAlternate0++;
                }
            } else {
                if (s[i] == '1') {
                    countForAlternate1++;
                } else {
                    countForAlternate0++;
                }
            }
        }
        
        return min(countForAlternate0, countForAlternate1);
    }
};

Approach

  1. Initialize Variables:

    • Store the string length in n.
    • Initialize a counter operationsCount to 0 to track the number of changes needed.

  2. Iterate Through String:

    • Iterate through each character in the string:
      • Check if the current character is different from the expected one based on the index (even indices should be '0', odd indices should be '1').
      • If they differ, increment operationsCount.

  3. Calculate Minimum Operations:

    • After the loop, consider two possibilities:
      • Changing characters to match the pattern starting with '0' (represented by operationsCount).
      • Changing characters to match the pattern starting with '1' (represented by n - operationsCount, as the remaining characters would need to change).
    • Return the minimum of these two values, representing the least number of operations required.

  4. Key Idea:

    • The code exploits the fact that there are only two possible alternating patterns, and the difference between them is exactly half the string length.
    • It efficiently tracks the changes needed for one pattern and infers the changes for the other.

  5. Time and Space Complexity:

    • Time complexity: O(n), where n is the length of the string, as it iterates through the string once.
    • Space complexity: O(1), as it uses a constant amount of extra space for the variables.

class Solution {
public:
    int minOperations(string s) {
        int n = s.size();
        int operationsCount = 0;

        for (int i = 0; i < n; i++) {
            // Check if the current character is different from the expected one based on the index
            if (s[i] - '0' != i % 2) {
                operationsCount++;
            }
        }

        // Return the minimum of operationsCount and (n - operationsCount)
        return min(operationsCount, n - operationsCount);
    }
};

Intuition

When alternating starting from 0, 
the digit '0' should appear at all even positions (0, 2, 4, 6, etc.), 
while the digit '1' should appear at all odd positions (1, 3, 5, 7, etc.).

If the minimum is obtained by counting in an alternating sequence starting from '1',
that case is handled with 'n - count'.

C++

class Solution {
public:
    int minOperations(string s) {
        int n = s.size(), count = 0;;
        if(n == 1) return 0;
        for(int i = 0; i < n; i++) {
            if(i%2 == 0 and s[i] == '1') count++;
            if(i%2 == 1 and s[i] == '0') count++;
        }
        return min(count, n-count);     //  "n - count", is to handle 1,0,1,0,. case
    }
};

class Solution:
    def minOperations(self, s: str) -> int:
        start10 = 0
        for i, c in enumerate(s):
            if int(c) == i % 2:
                start10 += 1

        return min(start10, len(s) - start10)

Step by step algorithm

1. Initialize a Counter (start10)
start10 = 0
  • Explanation: start10 is initialized to 0. This variable will be used to count the number of positions where the character in the string s needs to be changed to "1" for the sequence "1010..." to be achieved.
2. Iterate through the String
for i, c in enumerate(s):
  • Explanation: for i, c in enumerate(s): iterates through each character c in the string s and keeps track of its index i using enumerate.
3. Check if Change is Needed
if int(c) == i % 2:
  • Explanation: if int(c) == i % 2: checks if the current character c (interpreted as an integer) needs to be changed to "1" to achieve the alternating sequence "1010...". This is determined by comparing the character value with the parity of its index (i % 2), where an even index corresponds to "1" and an odd index corresponds to "0".
4. Update Counter (start10)
start10 += 1
  • Explanation: start10 += 1 increments the start10 counter if a change is needed at the current position.
5. Return the Minimum
return min(start10, len(s) - start10)
  • Explanation:return min(start10, len(s) - start10) returns the minimum between the number of changes needed to create "1010..." (start10) and the number of changes needed to create "0101...". This ensures that the function returns the minimum number of operations required to achieve the desired alternating sequence.
