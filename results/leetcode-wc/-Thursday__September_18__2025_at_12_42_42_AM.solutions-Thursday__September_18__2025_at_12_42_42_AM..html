Counting Stepping Numbers with Digit DP

A stepping number has adjacent digits that differ by exactly 1.
Example: 1210, 8987 are stepping; 1203, 133 are not.

We want:

#{x?[low,high]??i≥1, ?di?-di-1??=1}(mod109+7).

Because low/high can be long strings, we count by digits rather than enumerating numbers.

1) High-level strategy (Digit DP over the bound)

We compute:

  • F(N) = number of stepping numbers in [0,N].

  • Then the answer for [low,high] is

    F(high)-F(low)+[low is stepping],

    and we take modulo 109+7.

public int countSteppingNumbers(String low, String high) {
    int ans = 0;
    if (check(low.toCharArray())) ans++;  // add back 'low' if it is stepping
    return ((ans + countSteppingNumbers(high)) % mod 
           + (mod - countSteppingNumbers(low))) % mod;
}
  • countSteppingNumbers(N) returns F(N).
  • subtract F(low) (this counts numbers ≤ low but excluding low if tight is exact)
  • add 1 if low itself is stepping (check).

2) What the digit DP is counting

Let N be a decimal string with length ?.
We build numbers from left to right (most-significant to least) under two constraints:

  1. tight: whether the prefix we’ve chosen is still equal to N’s prefix.

    • If tight = 1, the next digit can’t exceed N[idx].
    • If tight = 0, we can use any digit 0..9.

  2. leading zeros: whether we haven’t started the real number yet (still placing 0s on the left).

    • While leadingZero = 1, we may keep placing 0s (not starting), or place a nonzero to start the number.
    • Once started (leadingZero = 0), the stepping rule applies:
      if last digit is d, the next digit must be d-1 or d+1.

We define a DP state:

f(idx,tight,leadingZero,lastDigit)

= number of valid completions from position idx to the end of N, under the above rules.
For “no last digit yet” we use a sentinel lastDigit = 10.

int[][][][] dp = new int[len + 1][2][2][11]; // idx, tight, leadingZero, lastDigit
for (int[][][] a1 : dp)
    for (int[][] a2 : a1)
        for (int[] a3 : a2)
            Arrays.fill(a3, -1);
return recur(0, 1, 1, 10, num, dp);

3) Base case

At idx == len, we finished choosing all digits.
Return 1 iff we have already started the number (i.e., not all leading zeros).
Returning 0 when still leading zeros prevents counting the empty/zero-length number.

if (idx == num.length()) {
    return leadingZero == 1 ? 0 : 1;
}

4) Transition (how do we choose the next digit?)

Let

limit={digit N[idx]9?if tight=1,if tight=0.?

We enumerate the next digit d?{0,…,limit}.
Then

nextTight=(tight=1 ? d=limit)?1:0.

Two branches:

A) Still leading zeros (not started yet):

  • If d=0: we stay in leading zeros, last digit stays sentinel (10).
  • If d>0: we start the number; last digit becomes d.

B) Already started:

  • We can only place d if ?d-lastDigit?=1.
  • Then continue with leadingZero=0, lastDigit=d.
int limit = (tight == 1 ? num.charAt(idx) - '0' : 9);
long ans = 0;

for (int d = 0; d <= limit; d++) {
    int nextTight = (tight == 1 && d == limit) ? 1 : 0;

    if (leadingZero == 1) {
        // stay in zeros OR start number
        ans = (ans + recur(idx+1, nextTight, d == 0 ? 1 : 0, d == 0 ? 10 : d, num, dp)) % mod;
    } else {
        // must satisfy step constraint
        if (Math.abs(lastDigit - d) == 1) {
            ans = (ans + recur(idx+1, nextTight, 0, d, num, dp)) % mod;
        }
    }
}
return dp[idx][tight][leadingZero][lastDigit] = (int) ans;

The memoization guard at the top ensures each state is computed once:

if (dp[idx][tight][leadingZero][lastDigit] != -1)
    return dp[idx][tight][leadingZero][lastDigit];

6) Why the range formula works

Let

F(N)=#{x?[0,N]?x stepping}.

Then

#{x?[low,high]}=F(high)-F(low)+[low is stepping].

  • F(high) counts everything up to high.
  • F(low) counts everything up to low (excluding low itself in the DP path unless it’s added explicitly).
  • If low is stepping, we add it back once.

The check is a simple linear pass:

boolean check(char[] num) {
    for (int i = 1; i < num.length; i++)
        if (Math.abs(num[i] - num[i-1]) != 1) return false;
    return true;
}

7) Dry run

Let’s compute F(N) for N = "210" (so length ?=3) to show the mechanics.

  • Start: idx=0, tight=1, lead=1, last=10.
    limit = N[0] = 2. We try d=0,1,2.

  1. d=0 (still leading zeros):

    • nextTight = 0 (since 0 < limit 2),
    • recurse with idx=1, tight=0, lead=1, last=10.

  2. d=1 (start number):

    • nextTight = 0 (1 < 2),
    • recurse with idx=1, tight=0, lead=0, last=1.

  3. d=2 (start number at the bound):

    • nextTight = 1 (2 == 2),
    • recurse with idx=1, tight=1, lead=0, last=2.

Let’s expand branch (2), which is common and shows the stepping rule:

  • State: idx=1, tight=0, lead=0, last=1.
    Now limit = 9 (not tight). Valid next digits satisfy ?d-1?=1 ? d ? {0,2}.

    a) Choose d=0: nextTight=0, go to idx=2, tight=0, lead=0, last=0.
    At idx=2, valid next digits must satisfy ?d-0?=1 ? d=1 only (since tight=0, limit 9).
    Then idx=3 base case returns 1. So this yields the number 1 0 1 (= 101), which is stepping.

    b) Choose d=2: nextTight=0, go to idx=2, tight=0, lead=0, last=2.
    Now valid next digits satisfy ?d-2?=1 ? d ? {1,3}.

    • d=1 gives 1 2 1 (=121), stepping.
    • d=3 gives 1 2 3 (=123), stepping.

You can similarly expand the other branches. The DP will memoize repeated subcalls (e.g., many idx=2, tight=0, lead=0, last=1 instances).

Key observation: the DP never enumerates more than O(?·2·2·11) states, even though the numeric range up to N may be huge.

8) Correctness (why this counts exactly the intended numbers)

  • Stepping condition enforcement: After the first nonzero digit, we only transition to digits whose absolute difference from the previous is 1. No other paths contribute.
  • Boundedness: The tight flag guarantees we never exceed N at any prefix; once we go smaller, we’re free for the remaining digits.
  • No spurious “empty” number: The base case returns 0 if we never left leading zeros.
  • All lengths covered: Leading zeros allow numbers shorter than ? to be represented (e.g., 00057 means 57). Once we start (nonzero), all subsequent positions are real digits.

Thus the DP is both sound (counts only valid numbers) and complete (counts all valid numbers ≤ N).

9) Complexity

Let ?=number of digits of N.

  • States: (?+1)*2*2*11≈44?.
  • Per state work: iterate d = 0..limit, at most 10 iterations.

So

Time=O(10·44?)=O(?),Space=O(44?)=O(?).

This is why digit DP scales effortlessly to very large N.

10) Full code

class Solution {

    static int mod = 1_000_000_007;

    public int countSteppingNumbers(String low, String high) {
        int ans = 0;
        if (check(low.toCharArray())) ans++;
        return ((ans + countSteppingNumbers(high)) % mod 
               + (mod - countSteppingNumbers(low))) % mod;
    }

    int countSteppingNumbers(String num) {
        int len = num.length();
        int[][][][] dp = new int[len + 1][2][2][11]; // idx, tight, leadingZero, lastDigit
        for (int[][][] a1 : dp)
            for (int[][] a2 : a1)
                for (int[] a3 : a2)
                    Arrays.fill(a3, -1);
        return recur(0, 1, 1, 10, num, dp);
    }

    int recur(int idx, int tight, int leadingZero, int lastDigit, String num, int[][][][] dp) {
        if (idx == num.length())
            return leadingZero == 1 ? 0 : 1;

        if (dp[idx][tight][leadingZero][lastDigit] != -1)
            return dp[idx][tight][leadingZero][lastDigit];

        int limit = (tight == 1 ? num.charAt(idx) - '0' : 9);
        long ans = 0;

        for (int d = 0; d <= limit; d++) {
            int nextTight = (tight == 1 && d == limit) ? 1 : 0;

            if (leadingZero == 1) {
                ans = (ans + recur(idx + 1, nextTight, d == 0 ? 1 : 0, d == 0 ? 10 : d, num, dp)) % mod;
            } else {
                if (Math.abs(lastDigit - d) == 1) {
                    ans = (ans + recur(idx + 1, nextTight, 0, d, num, dp)) % mod;
                }
            }
        }
        return dp[idx][tight][leadingZero][lastDigit] = (int) ans;
    }

    boolean check(char[] num) {
        for (int i = 1; i < num.length; i++)
            if (Math.abs(num[i] - num[i - 1]) != 1) return false;
        return true;
    }
}

11) Common pitfalls

  • Counting the empty number (all zeros) — avoided by the base case returning 0 if leadingZero=1.
  • Dropping shorter lengths — handled naturally by leading zeros.
  • Double counting low — avoided by the F(high) - F(low) + [low stepping] pattern.
  • Overflow — every addition is modulo 109+7.
  • State explosion — only 44·len states; memoization prevents recomputation.

class Solution {
    String num;
    int mod = 1000000007;
    Long dp[][][][];
    public int countSteppingNumbers(String A, String B) {
        
        dp= new Long[A.length()][2][11][2];
        num = A;
        long cnt1= f(0,true, -1, true);

        
        dp= new Long[B.length()][2][11][2];
        num = B;
        long cnt2= f(0,true, -1, true);
        
        boolean add = true;
        for(int i = 1; i< A.length();i++){
            int prev = A.charAt(i-1) -'0';
            int curr = A.charAt(i) -'0';
            if(Math.abs(prev-curr) != 1) {
                add = false;
                break;
            }
        }
        
        long cnt = (cnt2 - cnt1 + mod)%mod;
        
        
        if(add) cnt = (cnt + 1)%mod;  
        return (int)((cnt+mod)%mod);
        
    }
    
    public long f(int idx, boolean bound, int prev, boolean isZero){

        if(idx == num.length()){
            return 1;
            
        }
        
        if(dp[idx][bound ? 0:1][prev+1][isZero ? 0:1] != null) return dp[idx][bound ? 0:1][prev+1][isZero ? 0:1];
        
        long ans = 0;
        
        int max = 9;
        if(bound){
            max = num.charAt(idx) - '0';
        }
        
        for(int i = 0; i<= max; i++){
            if(prev == -1 || Math.abs(prev - i) == 1 || isZero){
                ans = (ans +  f(idx+1, bound && i == max , i, isZero && (i==0)))%mod;
            }
        }
        
        return dp[idx][bound ? 0:1][prev+1][isZero ? 0:1]=ans;
    }
}
