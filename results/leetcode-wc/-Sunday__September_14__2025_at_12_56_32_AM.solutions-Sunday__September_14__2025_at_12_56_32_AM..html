Intuition

We employ a recursive approach to explore various job scheduling options, taking into account job dependencies and minimizing the difficulty. The solution is memoized to optimize repeated computations.

Approach

Base Cases:

  1. If the number of jobs is less than the number of days (len(jobDifficulty) < d), it's impossible to create a valid schedule. Return -1.
  2. If the sum of job difficulties is zero (sum(jobDifficulty) == 0), all jobs have zero difficulty, and the minimum difficulty is 0.

Complexity

Without Memoization:

  • Time Complexity: Exponential, O(2^n), where n is the size of the problem.
  • Space Complexity: O(n), where n is the depth of the recursive call stack.

With Memoization:

  • Time Complexity: Improved to O(n * d), where n is the size of the problem and d is the depth of recursion.
  • Space Complexity: O(n * d), additional space for the memoization table.

class Solution {
    public int minDifficulty(int[] jobDifficulty, int d) {
        if (jobDifficulty.length < d) {
            return -1;
        }
        int len = jobDifficulty.length;
        int sum = 0;
        for (int i = 0; i < jobDifficulty.length; i++) {
            sum += jobDifficulty[i];
        }
        if (sum == 0) {
            return 0;
        }
        return helper(jobDifficulty, d, 0);
    }

    private int helper(int[] jd, int daysLeft, int idx) {
        int len = jd.length;
        if (daysLeft == 1) {
            int num = 0;
            for (int i = idx; i < len; i++) {
                num = Math.max(num, jd[i]);
            }
            return num;
        }

        int max = jd[idx];
        daysLeft--;
        int stop = len - idx - daysLeft + 1;

        int res = Integer.MAX_VALUE;
        for (int i = 1; i < stop; i++) {
            max = Math.max(max, jd[idx + i - 1]);
            int other = helper(jd, daysLeft, idx + i);
            res = Math.min(res, other + max);
        }
        return res;
    }
}

class Solution {
    public int minDifficulty(int[] jobDifficulty, int d) {
        if (jobDifficulty.length < d) {
            return -1;
        }
        int len = jobDifficulty.length;
        int sum = 0;
        for (int i = 0; i < jobDifficulty.length; i++) {
            sum += jobDifficulty[i];
        }
        if (sum == 0) {
            return 0;
        }
        int[][] memo = new int[d + 1][len];
        helper(jobDifficulty, d, 0, memo);
        
        return memo[d][0];
    }

    private void helper(int[] jd, int daysLeft, int idx, int[][] memo) {
        int len = jd.length;
        if (memo[daysLeft][idx] != 0) {
            return;
        }
        if (daysLeft == 1) {
            int num = 0;
            for (int i = idx; i < len; i++) {
                num = Math.max(num, jd[i]);
            }
            memo[daysLeft][idx] = num;
            return;
        }
        int max = jd[idx];
        daysLeft--;
        int stop = len - idx - daysLeft + 1;
    
        int res = Integer.MAX_VALUE;
        for (int i = 1; i < stop; i++) {
            max = Math.max(max, jd[idx + i - 1]);
            int other = memo[daysLeft][idx + i];
            if (other == 0) {
                helper(jd, daysLeft, idx + i, memo);
                other = memo[daysLeft][idx + i];
            }
            res = Math.min(res, other + max);   
        }
        memo[daysLeft + 1][idx] = res;
    }

}

Intuition

We need to split the jobDifficulty array into d contiguous subarrays (days).

  • The difficulty of one day = maximum job difficulty of that segment.

  • The total schedule difficulty = sum of each day’s difficulty.

  • Our goal: minimize this total.

Naively trying all partitions is exponential, but notice:

  • Once we fix the jobs for day 1, the problem reduces to a smaller subproblem (remaining jobs in d-1 days).

  • This naturally leads to recursion + memoization (DP).

Approach

  1. Base case:

    • If n < d, return -1 (not enough jobs).

    • If d == 1, we must take all remaining jobs in one day, so return the max of that segment.

  2. Recurrence:

    • Iterate over possible split points i where day 1 ends.

    • Keep track of the maximum difficulty in [idx … i] for day 1.

    • Recurse on the remaining jobs [i+1 … end] with d-1 days.

    • Take the minimum over all choices.

  3. Memoization:

    • Store results in dp[idx][d] to avoid recomputation.

Dry Run (Example)

Input:

jobs = [6,5,4,3,2,1], d = 2

  • Start at idx=0, d=2.

  • Try splits:

    • Day1 = [6], max=6 ? recurse on [5,4,3,2,1] with d=1 ? max=5 ? total=6+5=11

    • Day1 = [6,5], max=6 ? recurse on [4,3,2,1], d=1 ? max=4 ? total=6+4=10

    • Day1 = [6,5,4], max=6 ? recurse on [3,2,1], d=1 ? max=3 ? total=9

    • Day1 = [6,5,4,3], max=6 ? recurse on [2,1], d=1 ? max=2 ? total=8

    • Day1 = [6,5,4,3,2], max=6 ? recurse on [1], d=1 ? max=1 ? total=7 minimum.

Answer = 7.

class Solution {
    int n;
    public int minDifficulty(int[] jobDifficulty, int d) {
        n = jobDifficulty.length;
        if( n < d ) return -1;
        
        int[][] dp = new int[n][d + 1];
        for(int[] row : dp) {
            Arrays.fill(row, -1);
        }

        return solve(jobDifficulty, dp, 0, d);

    }

    private int solve(int[] jobs,int[][]dp, int idx, int d) {
        if( d == 1 ) {
            int maxD = jobs[idx];   // you can take here zero also if you want to
            for( int i = idx + 1; i < n; i++ ) {
                maxD = Math.max( maxD, jobs[i] );
            }
            return maxD;
        }

        if( dp[idx][d] != -1 ) return dp[idx][d];

        int maxD = jobs[idx];
        int res  = Integer.MAX_VALUE;

        for( int i = idx; i <= ( n - d ); i++ ) {

            maxD = Math.max( maxD, jobs[i] );
            int tempRes = maxD + solve( jobs ,dp ,i + 1, d - 1 ); 

            res = Math.min( res, tempRes );
        }

        return dp[idx][d] = res;

    }

}
