? Understanding the Problem

  • We're given some points on a n * n grid and we need to find the number of points such that there exist a point directly to the top, left, bottom and right of it.
  • For example : In the given test case 1

  • So there is only one point here which has atleast one building in each direction.

? General Approach

  • The main observation here is that points on top and bottom lie should lie on the same x-axis and points on the left and right should lie on the same y-axis.
  • Points on top & bottom
    • Have same x coordinate. But greater and lower y coordinates respectively.
  • Points on left & right
    • Have same y coordinate. But greater and lower x coordinates respectively.

? Brute Force [TLE]

  • The brute force approach is to simply check for all points whether there lies a point on the top, bottom, left or right.
  • But due to the high constraints of the problem upto 1e5, this gives us Time Limit Exceeded verdict.

?? Brute Force Implementation

C++
class Solution {
public:
    int count = 0;
    int countCoveredBuildings(int n, vector<vector<int>>& grid) {
        for (int i = 0 ; i < grid.size() ; i++) 
            if (isBuilding(grid, grid[i][0], grid[i][1])) ++count;
        
        return count;
    }
    
    bool isBuilding(vector<vector<int>>& grid, int x, int y) {
        bool up = 0, down = 0, left = 0, right = 0;
        for (int i = 0; i < grid.size(); i++) {
            if (grid[i][0] == x && grid[i][1] == y) continue;
            if (grid[i][0] == x && grid[i][1] < y) up = true;
            if (grid[i][0] == x && grid[i][1] > y) down = true;
            if (grid[i][1] == y && grid[i][0] < x) left = true;
            if (grid[i][1] == y && grid[i][0] > x) right = true;
        }
        return up && down && left && right;
    }
};

? Using Binary Search

  • The optimal approach here is to store all the points in a hashmap so that we can access / fetch them in O(1) constant time.
  • Then we use equal_range function or basically the function used to find the number of elements lieing in a particular range.
  • We use this to find the number of points on top, bottom, left and right & using this we calculate whether there are points on all 4 sides or not.

? How do we check whether points are present?

  • Similar to how lower_bound and upper_bound works, equal_range also points to the end if we're finding a value >= a number but there is no such value present.
  • Similarly for the beginning if we're finding a value <= a number but no such value exists then it points to the start of the array.
  • We just make sure that if it doesn't point to the end / start then we count it as a valid occurence.

?? BS + Map Implementation

C++
class Solution {
public:
    int countCoveredBuildings(int n, vector<vector<int>>& grid, int count = 0) {
        unordered_map<int,set<int>> st1, st2;
        for (auto& p : grid) {
            st1[p[0]].insert(p[1]);
            st2[p[1]].insert(p[0]);
        }
        
        for (auto& p : grid) {
            auto& it1 = st1[p[0]];
            auto& it2 = st2[p[1]];
            auto[downy, uph] = it1.equal_range(p[1]);
            auto[downx, upx] = it2.equal_range(p[0]);
            bool up = downy != it1.begin();
            bool down = uph != it1.end();
            bool left = downx != it2.begin();
            bool right = upx != it2.end();
            if (up && down && left && right) ++count;
        }
        return count;
    }
};

Intuition

At first glance, this problem might seem to require checking each building's neighboring positions one by one.
However, upon closer reading, we realize the building is covered if there is at least one building somewhere to its left, right, above, and below, not necessarily adjacent.
Thus, we can precompute the minimum and maximum coordinates for each row and each column to answer these checks in constant time.

Approach

First pass: for each building (x, y),

  • Precompute for each x the minimum and maximum y ? stored in yRangeGivenX.
  • Precompute for each y the minimum and maximum x ? stored in xRangeGivenY.

Second pass: for each building (x, y),

  • If x is strictly between the minimum and maximum x in column y (i.e., there are buildings above and below),
  • and y is strictly between the minimum and maximum y in row x (i.e., there are buildings left and right),
  • then it is a covered building.

Count all such covered buildings.

Note: using array than dict is much faster for Python

Complexity

  • Time complexity: O(N), where N is the number of buildings.
    One pass to build the min/max maps.
    One pass to check each building.

  • Space complexity: O(N) to store the min/max for each unique x and y.

class Solution {
    public int countCoveredBuildings(int n, int[][] buildings) {
        Map<Integer, int[]> yRangeGivenX = new HashMap<>();
        Map<Integer, int[]> xRangeGivenY = new HashMap<>();
        
        for (int[] b : buildings) {
            int x = b[0], y = b[1];
            yRangeGivenX.putIfAbsent(x, new int[]{Integer.MAX_VALUE, Integer.MIN_VALUE});
            yRangeGivenX.get(x)[0] = Math.min(yRangeGivenX.get(x)[0], y);
            yRangeGivenX.get(x)[1] = Math.max(yRangeGivenX.get(x)[1], y);

            xRangeGivenY.putIfAbsent(y, new int[]{Integer.MAX_VALUE, Integer.MIN_VALUE});
            xRangeGivenY.get(y)[0] = Math.min(xRangeGivenY.get(y)[0], x);
            xRangeGivenY.get(y)[1] = Math.max(xRangeGivenY.get(y)[1], x);
        }
        
        int count = 0;
        for (int[] b : buildings) {
            int x = b[0], y = b[1];
            if (xRangeGivenY.get(y)[0] < x && x < xRangeGivenY.get(y)[1] &&
                yRangeGivenX.get(x)[0] < y && y < yRangeGivenX.get(x)[1]) {
                count++;
            }
        }
        
        return count;
    }
}
