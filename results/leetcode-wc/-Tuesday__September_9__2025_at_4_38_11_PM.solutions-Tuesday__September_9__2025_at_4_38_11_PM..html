DP based off choosing which subtree roots to invert. With Explanation.

It feels like a dp problem initially as we are taking the sum of different subtrees so that makes it seem like we should be able to break it into

dp[root] = some root term + sum(dp[children] terms)

however, we can alternate between flipping all of the subtree from pos to neg, so need to take that into account.

in order to do that, will need to know when we can and when we can't flip, so in addition to doing dp on the subtree root parameter, also add a parameter "x", where x is the amount of nodes down until we can invert again.

This will allow us to do a pattern like
dp[root][x] = root term + sum(dp[children][x-1])
as long as x > 0, as when it's > 0, we can't invert just yet as there still lingers an ancestor k-x above which was inverted.

for the x = 0 case, can simply split into two different calculations:
- trying to invert
- not inverting
if we don't immediately invert, then we take root term + sum(dp[children][0]), as x still remains 0 for children because we haven't added a new closer ancestor to push distance farther down the tree

if we do invert then need to somehow propogate this up the tree to all in the child subtrees.

Cant simply do -root_term - sum(dp[children]), as dp has the goal of maximizing sum, which means negating it would minimize the sum! This is the opposite of what we want.

So could solve this by calcing a min and max for dp as -1*min should be max, however we can also just keep it one single dp and add a sign paramter so the later maximizing for dp sums takes into account the flipped sign and returns the max sum with said flipped sign

So this gives a 3D dp state of dp[i][x][s] = the max sum of subtree vals rooted at 'i' where can make the next flip at x further deep into the tree with the current sign "flip state" = s.

have dp[i][x][s] = s*nums[i] + (sum[dp[child][x-1][s]]) for all x > 0

for x = 0 have
dp[i][0][s]
= MAX(snums[i] + sum[dp[child][0][s]], -snums[i] + sum[dp[child][k-1][-s]]) as the second term in max represents flipping the sign, so add -snum instead of snum, flip sign to -s for all future children, and reset the flip distance all the way back to k-1 for children.

Code

Java
class Solution {
    public long subtreeInversionSum(int[][] edges, int[] nums, int k) {

        int n = nums.length;
        int[] deg = new int[n];
        for(int[] edge : edges) {
            deg[edge[0]]++;
            deg[edge[1]]++;
        }
        int[][] tree = new int[n][];
        for(int i = 0; i < n; i++) tree[i] = new int[deg[i]];
        Arrays.fill(deg, 0);
        for(int[] edge : edges) {
            tree[edge[0]][deg[edge[0]]++] = edge[1];
            tree[edge[1]][deg[edge[1]]++] = edge[0];
        }
        
        long[][][] dp = new long[n][k][2];
        for(long[][] mat : dp) for(long[] row : mat) Arrays.fill(row, 1L << 36);

        return compute(0, -1, 0, k, 1, tree, nums, dp);
    }


    private long compute(int node, int parent, int x, int k, int sign, int[][] tree, int[] nums, long[][][] dp) {
        if(dp[node][x][(sign + 1)/2] != (1L << 36)) return dp[node][x][(sign + 1)/2];
        long res = sign*nums[node];
        int next = x == 0 ? 0 : x-1;
        for(int child : tree[node]) {
            if(child == parent) continue;
            res += compute(child, node, next, k, sign, tree, nums, dp);
        }
        if(x == 0) {
            long inverseSum = -sign*nums[node];
            for(int child : tree[node]) {
                if(child == parent) continue;
                inverseSum += compute(child, node, k-1, k, -sign, tree, nums, dp);
            }
            res = Math.max(res, inverseSum);
        }
        return dp[node][x][(sign + 1)/2] = res;
    }
}
