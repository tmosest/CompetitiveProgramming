Looking for the last step where length m was found coming from the front is the same as looking for the first step where length m was found coming from the back.
So coming from back instead of adding 1s we have to remove them, or we can say we are adding walls in between the 1s. So if at any step we find two walls which are at a distance of m, means that there are m 1s in between those two walls. Then this step we would be the answer.
TreeSet.ceiling(pos) finds nearest righside wall from pos.
TreeSet.floor(pos) finds nearest leftside wall from pos.
Here the set contains positions of walls.

        }

class Solution {
public:
    int findLatestStep(vector<int>& arr, int m) {
        int n = arr.size();
        int ans = -1; // This will store the latest step where we found a segment of length m
        
        // Arrays to keep track of lengths of segments ending at each position and counts of these lengths
        vector<int> lenAtIndex(n + 2, 0); // lenAtIndex[i] will store the length of the segment ending at index i
        vector<int> countLen(n + 2, 0);    // countLen[len] will store the count of segments with length len

        for (int i = 0; i < n; ++i) {
            int leftLen = lenAtIndex[arr[i] - 1]; // Length of segment ending just before arr[i]
            int rightLen = lenAtIndex[arr[i] + 1]; // Length of segment starting just after arr[i]

            int newLen = leftLen + rightLen + 1; // New length of the segment that includes arr[i]

            // Update the lengths at arr[i], arr[i] - leftLen, and arr[i] + rightLen
            lenAtIndex[arr[i]] = newLen;
            lenAtIndex[arr[i] - leftLen] = newLen;
            lenAtIndex[arr[i] + rightLen] = newLen;

            // Update countLen array to reflect the change in segment lengths
            countLen[leftLen]--;
            countLen[rightLen]--;
            countLen[newLen]++;

            // Check if there is any segment of length m after this step
            if (countLen[m] > 0) {
                ans = i + 1; // Update ans to the current step (1-based index)
            }
        }

        return ans;
    }
};

? Approach and Intuition

(Use C++ code for reference.)

  1. Understanding the Problem Context:

    • We're given an array arr which indirectly represents a binary array where each position in arr indicates a change from 0 to 1.
    • m specifies the length of the contiguous segment of 1s we're interested in finding.

  2. Data Structures Used:

    • lenAtIndex: This vector keeps track of the length of consecutive 1s segments that end at each position (adjusted for 1-based indexing).
    • countLen: This vector counts how many segments of each length are currently active.

  3. Processing Each Position in arr:

    • For each position arr[i], compute the length of the contiguous 1s segment ending at arr[i] using leftLen and rightLen.
    • Update lenAtIndex to reflect the new length of the segment at arr[i] and potentially merge it with neighboring segments.
    • Update countLen to reflect the changes in segment lengths:
      • Decrease counts of the lengths that are affected by the merge.
      • Increase count for the newly merged length.
    • Check if there exists any segment of length m after each update. If so, update ans to the current step (i+1).

  4. Return Result:

    • ans holds the latest step where a segment of length m was found.

Imagine an array of length n initialized with all 0s. As we process each element in arr, we flip the corresponding position to 1 and merge adjacent segments of 1s. We update lengths and counts to check if a segment of length m exists after each step.

Let’s walk through an example:

  • arr = [3, 5, 1, 2, 4]
  • m = 1
  • n = 5

Initial State

Array:    [0, 0, 0, 0, 0]
lenAtIndex: [0, 0, 0, 0, 0, 0, 0]  (size n+2 = 7 for boundaries)
countLen:  [0, 0, 0, 0, 0, 0, 0]
ans = -1

Step 1: Process arr[0] = 3

  • Flip position 3 (0-based index 2) to 1.
Array:    [0, 0, 1, 0, 0]
  • leftLen = lenAtIndex[2] = 0 (no segment to the left).
  • rightLen = lenAtIndex[4] = 0 (no segment to the right).
  • newLen = 0 + 0 + 1 = 1 (new segment of length 1).
  • Update:
    • lenAtIndex[3] = 1 (segment ends at 3).
    • lenAtIndex[3 - 0] = 1 (start of segment at 3).
    • lenAtIndex[3 + 0] = 1 (end of segment at 3).
lenAtIndex: [0, 0, 0, 1, 0, 0, 0]
  • Update counts:
    • countLen[0]-- (no change, stays 0).
    • countLen[0]-- (no change, stays 0).
    • countLen[1]++ (now 1 segment of length 1).
countLen: [0, 1, 0, 0, 0, 0, 0]
  • Check: countLen[m=1] = 1 > 0, so ans = 1.

Step 2: Process arr[1] = 5

  • Flip position 5 (index 4) to 1.
Array:    [0, 0, 1, 0, 1]
  • leftLen = lenAtIndex[4] = 0.
  • rightLen = lenAtIndex[6] = 0.
  • newLen = 0 + 0 + 1 = 1.
  • Update:
    • lenAtIndex[5] = 1.
    • lenAtIndex[5 - 0] = 1.
    • lenAtIndex[5 + 0] = 1.
lenAtIndex: [0, 0, 0, 1, 0, 1, 0]
  • Update counts:
    • countLen[0]-- (stays 0).
    • countLen[0]-- (stays 0).
    • countLen[1]++ (now 2 segments of length 1).
countLen: [0, 2, 0, 0, 0, 0, 0]
  • Check: countLen[1] = 2 > 0, so ans = 2.

Step 3: Process arr[2] = 1

  • Flip position 1 (index 0) to 1.
Array:    [1, 0, 1, 0, 1]
  • leftLen = lenAtIndex[0] = 0.
  • rightLen = lenAtIndex[2] = 0.
  • newLen = 0 + 0 + 1 = 1.
  • Update:
    • lenAtIndex[1] = 1.
lenAtIndex: [0, 1, 0, 1, 0, 1, 0]
  • Update counts:
    • countLen[1]++ (now 3 segments of length 1).
countLen: [0, 3, 0, 0, 0, 0, 0]
  • Check: countLen[1] = 3 > 0, so ans = 3.

Step 4: Process arr[3] = 2

  • Flip position 2 (index 1) to 1.
Array:    [1, 1, 1, 0, 1]
  • leftLen = lenAtIndex[1] = 1.
  • rightLen = lenAtIndex[3] = 1.
  • newLen = 1 + 1 + 1 = 3 (merges left and right segments).
  • Update:
    • lenAtIndex[2] = 3.
    • lenAtIndex[2 - 1] = 3 (start at index 1).
    • lenAtIndex[2 + 1] = 3 (end at index 3).
lenAtIndex: [0, 3, 3, 3, 0, 1, 0]
  • Update counts:
    • countLen[1]-- (remove left segment, now 2).
    • countLen[1]-- (remove right segment, now 1).
    • countLen[3]++ (add new segment, now 1).
countLen: [0, 1, 0, 1, 0, 0, 0]
  • Check: countLen[1] = 1 > 0, so ans = 4.

Step 5: Process arr[4] = 4

  • Flip position 4 (index 3) to 1.
Array:    [1, 1, 1, 1, 1]
  • leftLen = lenAtIndex[3] = 3.
  • rightLen = lenAtIndex[5] = 1.
  • newLen = 3 + 1 + 1 = 5.
  • Update:
    • lenAtIndex[4] = 5.
    • lenAtIndex[4 - 3] = 5 (start at index 1).
    • lenAtIndex[4 + 1] = 5 (end at index 5).
lenAtIndex: [0, 5, 3, 3, 5, 5, 0]
  • Update counts:
    • countLen[3]-- (now 0).
    • countLen[1]-- (now 0).
    • countLen[5]++ (now 1).
countLen: [0, 0, 0, 0, 0, 1, 0]
  • Check: countLen[1] = 0, no segment of length 1, so ans remains 4.
