Intuition

  • Given: An array nums of length N.
  • We must build sequences of length M by choosing any index i ? [0,n) multiple times.
  • Each sequence yields a product P of the chosen values and a bitmask sum S=(∑2i)
  • We only count those sequences whose S has exactly K set(one)-bits (popcount). Meaning we must choose K unique i in each sequence of length M. As only then we can get K set bits in S.

This does seems to have some real shit to be done with combinatorics. Put on your seat belts. It might get to a long explanation!

Approaches

Approach 1: Brute Force:

Choose all subsets of length M with repeated elements allowed, check if they have K unique elements. Add the maintained product to final sum.

Learning:

While setting ith bit for a Long integer, i wasn't able to use (1 << i). Instead used (long)Math.pow(2, i).

Complexity

  • Time complexity:
    O(NM) In each recursion call, exploring N options, where N is the array length. Depth of recursion will go to M.

  • Space complexity:
    O(M) Recursion stack.

Code
class Solution {
    long ans; 
    int K, int MOD = 1000000007;
    int[] nums;
    public int magicalSum(int m, int k, int[] nums) {
        this.nums = nums; 
        this.K = k;
        ans = 0;
        helper(m, 0l, 1l);
        return (int)ans;
    }
    private void helper(int picksLeft, long maskSoFar, long prodSoFar) {
        if (picksLeft == 0) {
            if (Long.bitCount(maskSoFar) == K) {
                ans = (ans + prodSoFar) % MOD;
            }
            return;
        }
        // In every call, we will just choose 1 element any from array.
        for (int i = 0; i < nums.length; i++) {
            helper(picksLeft - 1, maskSoFar + (long)Math.pow(2, i), (prodSoFar * nums[i]) % MOD);
        }
    }
}

Approach 2: Memoization:

Simple memoization over (picksLeft, maskSoFar, prodSoFar) still can bloat in both time and memory.

2.1 Naive Memo

  • You might think “just cache every (picksLeft, maskSoFar, prodSoFar) result, and you’ll only visit each once.” In principle, yes—but:
  • Mask(of which picks you’ve done) is an long mask, there are potentially 2N possible values.
  • Pick-count dimension: You still have to consider all picksLeft = 0…M.

Core insight / Hint:

  • What if we group by “how many times we pick each index” instead of “the order of picks".
  • The order of those picks doesn’t matter for the final product or bit-mask popcount—only how many of each index you chose.

Ex: m = 2, k = 1, nums = [4,3,2]

  • With Naive approach we will end up selecting each number twice. Thus P = (Sum of squares of nums) = (42+32+22)
  • Dry run the code With Optimized approach. You will see the change.

Before: for each of M picks, branch into N choices ? NM leaves.

After: for each index i, loop C=0…M ? at most M+1 branches per i, and just N indices ? total branches ≈ N*(M+1).

Overall transitions ≈ O(N*M) per DP state, not O(NM)

  • If you pick nums[i] exactly c times out of m remaining slots, there are (mCc) ways to interleave them.

We also need to tracking the Bitmask Efficiently

We still need to know whether our final combination has exactly K bits set. Instead of recomputing on each of the orderings:

  • Maintain a single integer flag whose binary bits represent how many picks “carry over” to the next index.
  • When you pick index i exactly c times:
    • Add c to flag.
    • Contribution to K: (flag + c) % 2 tells you if you added an odd number of new “1”-bits at this position.
    • Carry to next: (flag + c) >>> 1 shifts out the bit you just counted, preparing for the next index.

This constant-time bitwise “add, count, shift” replaces any expensive popcount over large masks.

Complexity
  • Time complexity: O(M*M*N)

class Solution {
    private static final int MOD = 1_000_000_007;
    private int M, K, N;
    private int[] nums;
    private long[][] comb;               // comb[n][r] = nCr % MOD
    private Map<State, Integer> memo;    // memoization cache

    public int magicalSum(int M, int K, int[] nums) {
        this.M = M;
        this.K = K;
        this.nums = nums;
        this.N = nums.length;
        
        // 1) Precompute nCr up to M via Pascal’s triangle
        comb = new long[M+1][M+1];
        for (int n = 0; n <= M; n++) {
            comb[n][0] = comb[n][n] = 1;
            for (int r = 1; r < n; r++) {
                comb[n][r] = (comb[n-1][r-1] + comb[n-1][r]) % MOD;
            }
        }

        memo = new HashMap<>();
        return dp(M, K, 0, 0);
    }

    // Recursive DP
    private int dp(int m, int k, int i, int flag) {
        if (m < 0 || k < 0 || m + Integer.bitCount(flag) < k) {
            return 0; // Prune invalid states
        }
        if (m == 0) { // Base case: no picks left
            return (k == Integer.bitCount(flag)) ? 1 : 0;
        }
        if (i >= N) return 0; // No more numbers to pick

        State st = new State(m, k, i, flag);
        if (memo.containsKey(st)) 
            return memo.get(st);

        long res = 0;
        // Try picking 'c' copies of nums[i], for c = 0..m
        for (int c = 0; c <= m; c++) {
            // ways to choose positions * nums[i]^c
            long mul = (comb[m][c] * modPow(nums[i], c)) % MOD;
            // update flag: add c to flag, then shift right by 1
            int newFlag = flag + c;
            int nextFlag = newFlag >>> 1;          // divide by 2
            int bitContribution = newFlag & 1;     // newFlag % 2

            // recurse on remaining picks and adjusted k/flag
            res = (res + mul * dp(m - c, k - bitContribution, i + 1, nextFlag)) % MOD;
        }

        int ans = (int) res;
        memo.put(st, ans);
        return ans;
    }

    // Fast modular exponentiation
    private long modPow(long base, int exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) 
                result = (result * base) % MOD;
            base = (base * base) % MOD;
            exp >>= 1;
        }
        return result;
    }

    // State key for memoization
    private static class State {
        final int m, k, i, flag;
        State(int m, int k, int i, int flag) {
            this.m = m; this.k = k; this.i = i; this.flag = flag;
        }
        @Override
        public boolean equals(Object o) {
            if (!(o instanceof State)) return false;
            State s = (State) o;
            return m == s.m && k == s.k && i == s.i && flag == s.flag;
        }
        @Override
        public int hashCode() {
            int h = m;
            h = h * 31 + k;
            h = h * 31 + i;
            h = h * 31 + flag;
            return h;
        }
    }
}
