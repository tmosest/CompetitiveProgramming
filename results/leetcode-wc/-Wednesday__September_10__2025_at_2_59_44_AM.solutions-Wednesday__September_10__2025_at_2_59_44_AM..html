Intuition

How I thought ?

First I thought is there any pattern/formula to find out
checked some examples couldn't figure it out
then I thought how to solve using brute force, for that I thought may be we have to iterate for each sec and calculate for total trips for that sec and compare with given total

Then It hit me - times is linearly increasing 1,2,3...
EUREKA!! ITS a Binary Search

based on constraints its clear that start is 1
but for end -- I first Thought its totalTrips
but that failed here time = [5,10,10], totalTrips = 9
My Output = 9
Expected = 25

after 10 min head smashing i understood how for given example cases it worked with totalTrips -> its actually totalTrips*1 (Multiplied with min element)

Note:I just ignored the length 1 cases by simply returning 
time[0]*totalTrips

so final end is totalTrips*min element of given time array
s = 1
e = totalTrips*min

Finding Time trips for given Time:
I actually found it during the inital trails
for any time t we can find how many times a bus taking t1 time runs
ex: [1,2,3]
for time t = 1 -> no of trips == 1/1 + 1/2 + 1/3 = 1
for time t = 2 -> no of trips == 2/1 + 2/2 + 2/3 = 3
.
.

BS:
as we know everything we need for a BS its only implementation

if trips at time mid < totalTrips -> start = mid +1

if mid >= totalTrips -> then i could be possible answer so end = mid

Approach

Complexity

  • Time complexity: O(nlogn) Ig
  • Space complexity:O(1)

class Solution {
    public long cal(int[] arr,long m){
        long ans = 0;
        for(int i:arr){
            ans += m/i;
        }
        return ans;
    }
    public long minimumTime(int[] time, int t) {
        if(time.length ==1){
            return (long)time[0]*t;
        }
        long min = Integer.MAX_VALUE;
        for(int i:time){
            min = Math.min(min,i);
        }
        long s = 0;
        long e = t*min;
        while(s<e){
            long m = s + (e-s)/2;
            long l = cal(time,m);
            if(l < t){
                s = m+1;
            }
            else{
                e = m;
            }
        }
        return s;
    }
}
