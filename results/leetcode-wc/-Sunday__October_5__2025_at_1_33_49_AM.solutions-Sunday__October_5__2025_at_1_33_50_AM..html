Problem Statement

Given an undirected tree represented as an edge list, we need to determine the maximum time required to traverse from the root node to any other node in the tree, following specific traversal rules:

If a node has an even index, the traversal time to its child nodes increases by 2.

If a node has an odd index, the traversal time to its child nodes increases by 1.

The goal is to compute the time taken for each node to be reached from the root node.

Example

Input:

edges = [[0, 1], [1, 2], [1, 3], [3, 4], [3, 5]]

Tree Representation:

                             0
                             |
                             1
                            / \
                            2  3
                              / \
                             4   5

Output:

[6, 4, 4, 2, 0, 0]

Explanation:

Node 0 takes 6 time to reach (maximum from its children).

Node 1 takes 4 time.

Node 3 takes 2 time.

Leaves (Nodes 4 and 5) take 0 time as they are endpoints.

Intuition

Since we are dealing with a tree, our objective is to determine the maximum depth while considering traversal time constraints based on even/odd node indices. We use depth-first search (DFS) to determine the longest path efficiently.

We store the path information because if we are calculating the time for a specific node, and that node belongs to the path, we must ignore that maximum path to avoid incorrect calculations.

Approach

  1. Build the Tree: Construct an adjacency list from the edge list.

  2. Depth-First Search (DFS) - Compute Maximum Path:

    • Traverse the tree from any leaf node to compute the longest path.
    • Store the two longest paths for each node.
    • Use a DFS helper function to determine the longest traversal time.

  3. Propagate the Result: Use another DFS to calculate the time taken for each node from the root, considering its parent’s maximum path.

Complexity

  • Time complexity: O(n)
- Each edge is processed once, and since there are n-1 edges in a tree with n nodes, this takes O(n) time.
- Bottom-Up DFS : This function performs a Depth-First Search (DFS) traversal of the tree. Since DFS visits each node once and explores all edges, the total time complexity is O(n).
- Top-Down DFS : Similar to the bottom-up DFS, this function also traverses the tree exactly once. The total time complexity is O(n).
  • Space complexity: O(n)
  • The adjacency list uses O(n) space since each node stores a list of its neighbors.
  • The time array has dimensions n*3, which results in O(n) space.
  • Recursive stack space - O(n)

import java.util.*;

class Solution {
    // Adjacency list to store the tree structure
    List<List<Integer>> adj;
    // 2D array to store marking time for each node
    int[][] time;
    // Variable to track whether the current node is odd
    boolean isOdd = false;

    public int[] timeTaken(int[][] edges) {
        int n = edges.length + 1; // Since there are (n-1) edges in a tree with n nodes
        adj = new ArrayList<>();
        time = new int[n][3]; // Stores {max time, second max time, child contributing to max}

        // Initialize adjacency list
        for (int i = 0; i < n; i++) {
            adj.add(new ArrayList<>());
        }

        // Build adjacency list from the given edges
        for (int[] edge : edges) {
            adj.get(edge[0]).add(edge[1]);
            adj.get(edge[1]).add(edge[0]);
        }

        // Step 1: Perform a bottom-up DFS to compute downward marking times
        computeDownwardMarkingTimes(0, -1);

        // Step 2: Perform a top-down DFS to compute final marking times
        int[] ans = new int[n];
        ans[0] = time[0][0]; // Root node marking time
        computeFinalMarkingTimes(0, -1, ans);

        return ans;
    }

    /**
     * First DFS (Bottom-Up)
     * Computes the marking time from child nodes to parent.
     * Stores the longest and second longest marking times for each node.
     */
    private int computeDownwardMarkingTimes(int node, int parent) {
        int[] temp = new int[3];
        temp[2] = -1; // Initialize to -1 (no child contributing yet)

        for (int neighbor : adj.get(node)) {
            if (neighbor == parent) continue; // Skip parent node to prevent cycles

            int newPath = computeDownwardMarkingTimes(neighbor, node) + (isOdd ? 1 : 2);

            // Update the longest and second longest marking times for the node
            if (temp[0] < newPath) {
                temp[1] = temp[0]; // Update second max time
                temp[0] = newPath; // Update max time
                temp[2] = neighbor; // Store the child contributing to max time
            } else if (temp[1] < newPath) {
                temp[1] = newPath; // Update second max time
            }
        }

        isOdd = node % 2 == 1; // Update odd/even status
        time[node] = temp;
        return Math.max(temp[0], temp[1]);
    }

    /**
     * Second DFS (Top-Down)
     * Adjusts marking times considering parent contributions.
     */
    private void computeFinalMarkingTimes(int node, int parent, int[] ans) {
        for (int neighbor : adj.get(node)) {
            if (neighbor == parent) continue; // Skip parent node

            // Compute marking time considering parent contribution
            int newPath;
            if (time[node][2] == neighbor) {
                newPath = time[node][1] + (node % 2 == 0 ? 2 : 1);
            } else {
                newPath = time[node][0] + (node % 2 == 0 ? 2 : 1);
            }

            ans[neighbor] = Math.max(time[neighbor][0], newPath);

            // Update the longest and second longest marking times for the node
            if (time[neighbor][0] < newPath) {
                time[neighbor][1] = time[neighbor][0]; // Update second max time
                time[neighbor][0] = newPath; // Update max time
                time[neighbor][2] = node; // Store the child contributing to max time
            } else if (time[neighbor][1] < newPath) {
                time[neighbor][1] = newPath; // Update second max time
            }

            // Recursive call for the child node
            computeFinalMarkingTimes(neighbor, node, ans);
        }
    }
}
