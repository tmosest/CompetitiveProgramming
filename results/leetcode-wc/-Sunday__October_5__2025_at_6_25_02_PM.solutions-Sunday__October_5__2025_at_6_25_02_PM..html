Intuition

This problem asks us to determine if a number n is palindromic when represented in every base from 2 to n-2. A strictly palindromic number must read the same forwards and backwards in all these base representations. We need to convert n to each base and check if the resulting string is a palindrome.

Approach

We'll use base conversion with palindrome validation:

  1. Base iteration: Check every base from 2 to n-2 (as required by definition)
  2. Base conversion: For each base, convert n using repeated division and modulo operations
  3. String construction: Build the base representation by prepending remainders
  4. Palindrome check: Compare the string with its reverse using slicing
  5. Early termination: Return false immediately if any base representation is not palindromic
  6. Complete validation: Return true only if all bases produce palindromes

This approach systematically validates the palindrome property across all required bases.

Complexity

  • Time complexity: O(n*logn)
    We check O(n) bases, and each base conversion takes O(log n) time for digit extraction.

  • Space complexity: O(logn)
    We store the string representation of n in each base, which has at most log n digits.

class Solution(object):
    def isStrictlyPalindromic(self, n):
        for i in range(2, n - 1):
            temp = n
            digits = ''
            while temp > 0:
                rem = temp % i
                digits = str(rem) + digits
                temp = temp // i
            if digits != digits[::-1]:
                return False
        return True

However, it is mathematically proven that no number greater than or equal to 4 can satisfy this condition because in base n-2, the representation of n is always "12", which is not a palindrome. Thus, the solution simply returns False for all n >= 4.
